# 総額賃金管理について

## 概要

総額賃金管理（Total Wage Management）は、企業が従業員に支払う賃金・給与の総額を経営戦略と連動させて管理する手法です。単に人件費を削減するのではなく、企業の生産性向上と従業員の処遇改善を両立させることを目的とした戦略的な賃金管理システムです。

近年、働き方改革や人材確保競争の激化により、効果的な賃金管理の重要性が高まっています。総額賃金管理は、限られた原資を最も効果的に配分し、組織の目標達成と従業員満足度の向上を同時に実現するための重要な経営手法となっています。

## 1. 基本概念・定義

### 総額賃金管理の定義
- **定義**: 企業の業績や生産性と連動させて、賃金・賞与・各種手当を含む人件費総額を戦略的に管理・配分する経営手法
- **特徴**: 個別の賃金決定ではなく、全体最適の観点から賃金総額を管理
- **重要性**: 経営の持続可能性と従業員モチベーションの両立を実現

### 総額人件費の構成要素
- **定義**: 企業が従業員に支払うすべての金銭的報酬の合計
- **特徴**: 基本給、諸手当、賞与、法定福利費、退職金等を含む
- **重要性**: 経営における最大の固定費であり、戦略的管理が不可欠

### 賃金配分の原則
- **定義**: 限られた賃金原資を効果的に配分するための基本的な考え方
- **特徴**: 公平性、競争力、業績連動性、持続可能性を考慮
- **重要性**: 従業員の納得性と組織の活性化に直結

## 2. 総額賃金管理の方式・種類

### 管理方式の分類基準
総額賃金管理は、管理の対象範囲、決定方法、配分方式によって以下のように分類されます。

### 売上高人件費率管理方式
| 項目 | 内容 |
|------|------|
| 特徴 | 売上高に対する人件費の比率を一定に保つ方式 |
| 適用範囲 | サービス業、小売業など労働集約型産業に適している |
| 注意点 | 売上変動が激しい場合は従業員の生活保障に配慮が必要 |

**計算式:**
```
目標人件費総額 = 予想売上高 × 目標人件費率
```

### 付加価値人件費率管理方式
| 項目 | 内容 |
|------|------|
| 特徴 | 企業が生み出した付加価値に対する人件費の比率で管理 |
| 適用範囲 | 製造業など付加価値創造を重視する企業に適している |
| 注意点 | 付加価値の算出方法を明確に定義する必要がある |

**計算式:**
```
付加価値 = 売上高 - 外部購入費用
目標人件費総額 = 付加価値 × 目標労働分配率
```

### 利益連動型管理方式
| 項目 | 内容 |
|------|------|
| 特徴 | 営業利益や経常利益と連動して人件費総額を決定 |
| 適用範囲 | 業績変動が大きい企業、成果主義を重視する企業 |
| 注意点 | 最低保障額の設定など、従業員の生活安定への配慮が必要 |

## 3. 具体的計算例・事例

### ケース1: 中堅製造業A社の売上高人件費率管理

#### パターンA: 業績好調時（売上高120億円）
- **前提条件**: 
  - 目標人件費率: 25%
  - 前年度売上高: 100億円
  - 当年度売上高: 120億円
- **計算過程**: 
  - 目標人件費総額 = 120億円 × 25% = 30億円
  - 前年度人件費総額 = 100億円 × 25% = 25億円
  - 増加可能額 = 30億円 - 25億円 = 5億円
- **結果**: 5億円を賞与増額、昇給原資、新規採用に配分

#### パターンB: 業績低迷時（売上高90億円）
- **前提条件**: 
  - 目標人件費率: 25%
  - 前年度売上高: 100億円
  - 当年度売上高: 90億円
- **計算過程**: 
  - 目標人件費総額 = 90億円 × 25% = 22.5億円
  - 前年度人件費総額 = 100億円 × 25% = 25億円
  - 削減必要額 = 25億円 - 22.5億円 = 2.5億円
- **結果**: 賞与減額、残業抑制、自然減による調整

### ケース2: サービス業B社の付加価値人件費率管理

#### 標準的なケース
- **前提条件**: 
  - 売上高: 50億円
  - 外部購入費用: 20億円
  - 目標労働分配率: 50%
- **計算過程**: 
  - 付加価値 = 50億円 - 20億円 = 30億円
  - 目標人件費総額 = 30億円 × 50% = 15億円
  - 一人当たり付加価値 = 30億円 ÷ 300人 = 1,000万円
  - 一人当たり人件費 = 15億円 ÷ 300人 = 500万円
- **結果**: 労働生産性と人件費のバランスが適正と判断

## 4. 総額賃金管理の導入・運用プロセス

### 導入プロセスの流れ
1. **現状分析**: 
   - 現在の人件費構造の詳細分析
   - 同業他社とのベンチマーク比較
   - 組織の課題と目標の明確化

2. **制度設計**: 
   - 管理方式の選定（売上高連動、付加価値連動等）
   - 目標指標の設定（人件費率、労働分配率等）
   - 配分ルールの策定

3. **労使協議**: 
   - 制度の目的と仕組みの説明
   - 従業員代表との協議
   - 合意形成と労働協約の締結

4. **試行運用**: 
   - パイロット部門での試行
   - 問題点の抽出と改善
   - 本格導入への準備

5. **本格導入**: 
   - 全社展開
   - 定期的なモニタリング
   - PDCAサイクルによる改善

### 関連する制度・規則
- **根拠法令**: 労働基準法、最低賃金法
- **所管官庁**: 厚生労働省
- **関連制度**: 成果主義賃金制度、職務給制度、年俸制

## 5. 実務上の注意点

### 導入時の重要ポイント
- **透明性の確保**: 算定基準や配分ルールを明確にし、従業員に開示する
- **最低保障の設定**: 業績悪化時でも一定の生活保障を確保する仕組みを設ける
- **定期的な見直し**: 経営環境の変化に応じて、目標値や配分方法を柔軟に調整する

### よくある誤解・トラブル
- **誤解1: 総額賃金管理は人件費削減が目的**
  - 正しい理解: 適正な配分により生産性向上と処遇改善の両立を図る手法
- **誤解2: 個人の頑張りが報われない**
  - 正しい理解: 総額管理の中で成果に応じた配分を行うことが可能

## 6. よくある質問（Q&A）

### Q1. 総額賃金管理を導入すると、個人の昇給はどうなりますか？

**A1.** 総額賃金管理においても、個人の昇給は可能です。ただし、全体の賃金総額の枠内で、成果や貢献度に応じてメリハリのある配分を行います。

#### 配分の具体例
例えば、賃金総額が5%増加した場合：
- 高成果者: 7-10%の昇給
- 標準的成果者: 3-5%の昇給
- 低成果者: 0-2%の昇給

このように、限られた原資を効果的に配分することで、成果に応じた処遇を実現します。

### Q2. 業績が悪化した場合、賃金はどの程度下がる可能性がありますか？

**A2.** 業績悪化時の対応は、制度設計により異なりますが、一般的には以下のような段階的対応を行います。

#### 段階的対応の例
1. **第1段階**: 賞与の減額（基本給は維持）
2. **第2段階**: 残業抑制による時間外手当の削減
3. **第3段階**: 昇給の凍結または抑制
4. **第4段階**: 役員報酬のカット
5. **最終段階**: 労使協議による一時的な基本給の減額

多くの企業では、基本給の80-90%程度を最低保障として設定し、従業員の生活安定に配慮しています。

## 7. まとめ・今後の展望

総額賃金管理は、企業の持続的成長と従業員の処遇改善を両立させる重要な経営手法です。適切に運用することで、以下のような効果が期待できます：

- **経営の安定性向上**: 人件費の変動を業績と連動させることで、経営の安定性が向上
- **従業員のモチベーション向上**: 業績向上が処遇改善につながることで、従業員の意欲が向上
- **労使関係の改善**: 透明性の高い制度により、労使の信頼関係が強化

今後は、働き方の多様化、AI・自動化の進展、グローバル競争の激化などを背景に、より柔軟で戦略的な総額賃金管理が求められるでしょう。特に、生産性向上への投資と人材への投資のバランスを取りながら、持続可能な賃金管理システムの構築が重要になります。

## 9. 専門用語集

このドキュメントで使用された専門用語について、50音順で解説します。

### あ行
**一人当たり付加価値（ひとりあたりふかかち）**
- **読み方**: ひとりあたりふかかち
- **意味**: 企業の付加価値を従業員数で除した値。従業員一人が生み出す付加価値額を示す生産性指標
- **関連用語**: 労働生産性、付加価値、労働分配率

**一人当たり人件費（ひとりあたりじんけんひ）**
- **読み方**: ひとりあたりじんけんひ
- **意味**: 人件費総額を従業員数で除した値。従業員一人当たりの平均的な人件費水準を示す
- **関連用語**: 人件費総額、平均賃金

### か行
**外部購入費用（がいぶこうにゅうひよう）**
- **読み方**: がいぶこうにゅうひよう
- **意味**: 原材料費、外注加工費、仕入商品原価など、企業が外部から購入する財・サービスの費用
- **関連用語**: 付加価値、売上原価

**基本給（きほんきゅう）**
- **読み方**: きほんきゅう
- **意味**: 諸手当を除いた賃金の基本部分。通常、年齢・勤続年数・職能・職務などにより決定される
- **関連用語**: 固定給、諸手当、賞与

### さ行
**最低保障（さいていほしょう）**
- **読み方**: さいていほしょう
- **意味**: 業績悪化時でも従業員に保障される最低限の賃金水準。通常、基本給の一定割合で設定
- **関連用語**: 生活保障、基本給

**成果主義（せいかしゅぎ）**
- **読み方**: せいかしゅぎ
- **意味**: 従業員の成果や業績に応じて処遇を決定する人事管理の考え方
- **関連用語**: 業績評価、成果配分

**総額人件費（そうがくじんけんひ）**
- **読み方**: そうがくじんけんひ
- **意味**: 基本給、諸手当、賞与、法定福利費、退職金など、企業が従業員に支払うすべての人件費の合計
- **関連用語**: 人件費率、労働分配率

### た行
**付加価値（ふかかち）**
- **読み方**: ふかかち
- **意味**: 企業が事業活動を通じて新たに生み出した価値。売上高から外部購入費用を差し引いて算出
- **関連用語**: 売上高、外部購入費用、労働分配率

### な行
**年俸制（ねんぽうせい）**
- **読み方**: ねんぽうせい
- **意味**: 1年間の賃金総額をあらかじめ決定し、それを分割して支払う賃金制度
- **関連用語**: 月給制、成果主義

### は行
**売上高人件費率（ばいじょうだかじんけんひりつ）**
- **読み方**: ばいじょうだかじんけんひりつ
- **意味**: 売上高に対する人件費の割合。人件費÷売上高×100で算出
- **関連用語**: 人件費、売上高、経営指標

**賞与（しょうよ）**
- **読み方**: しょうよ
- **意味**: 基本給とは別に支給される一時金。ボーナスとも呼ばれ、業績に応じて変動することが多い
- **関連用語**: 基本給、業績連動、一時金

### ま行
**メリハリのある配分（めりはりのあるはいぶん）**
- **読み方**: めりはりのあるはいぶん
- **意味**: 成果や貢献度に応じて、配分に差をつけること。高成果者により多く配分する方法
- **関連用語**: 成果配分、一律配分

### ら行
**労使協議（ろうしきょうぎ）**
- **読み方**: ろうしきょうぎ
- **意味**: 労働者（従業員）側と使用者（経営）側が、労働条件等について話し合い、合意を形成すること
- **関連用語**: 労働組合、団体交渉、労働協約

**労働生産性（ろうどうせいさんせい）**
- **読み方**: ろうどうせいさんせい
- **意味**: 労働投入量に対する生産量の比率。付加価値÷従業員数で表される場合が多い
- **関連用語**: 一人当たり付加価値、生産性向上

**労働分配率（ろうどうぶんぱいりつ）**
- **読み方**: ろうどうぶんぱいりつ
- **意味**: 企業が生み出した付加価値のうち、人件費として分配される割合。人件費÷付加価値×100で算出
- **関連用語**: 付加価値、人件費、経営指標

### わ行
**割増賃金（わりましちんぎん）**
- **読み方**: わりましちんぎん
- **意味**: 時間外労働、休日労働、深夜労働に対して支払われる通常賃金に上乗せされる賃金
- **関連用語**: 時間外手当、残業代、労働基準法
