# マーケティングリサーチの分類について

## 概要
マーケティングリサーチは、企業が市場や消費者に関する情報を体系的に収集・分析し、意思決定に活用するための重要な手法です。その実施方法は、調査対象の範囲（全数調査・標本調査）と、標本の選定方法（有意抽出法・無作為抽出法）という2つの軸で分類されます。本資料では、これらの分類について詳しく解説し、実務での活用方法を明確にします。

## 1. 基本概念・仕組み

### マーケティングリサーチの本質
- **定義**: 市場環境、消費者行動、競合状況などに関する情報を科学的手法により収集・分析し、マーケティング上の意思決定を支援する活動
- **動作原理**: 調査設計→データ収集→データ分析→意思決定への活用というプロセスを経る
- **特徴**: 客観性、再現性、体系性を重視した科学的アプローチ

### 調査手法の分類体系
- **従来の調査との違い**: 経験や勘に基づく判断から、データに基づく科学的判断への転換
- **改善点**: 統計的手法の導入により、結果の信頼性と一般化可能性が向上
- **限界**: コスト、時間、技術的制約により、すべての情報を完全に収集することは不可能

## 2. 調査範囲による分類

### 分類の基準
調査対象となる母集団（調査したい全体）のうち、どの程度の範囲を実際に調査するかによって分類されます。

### 全数調査（悉皆調査・センサス）
**特徴:**
- 母集団のすべての要素を調査対象とする
- 統計的な誤差（標本誤差）が存在しない
- 最も正確で包括的なデータが得られる

**実施条件:**
```
1. 母集団のサイズが小さい（数百～数千程度）
2. 調査予算と時間が十分にある
3. すべての調査対象へのアクセスが可能
4. 調査結果の完全性が必須である
```

**📊 具体的な実施例**
**例1: 自社顧客満足度調査**
- 前提条件: 法人顧客100社すべてを対象
- 調査期間: 3ヶ月

**実施手順:**
```
1. 全100社のリストアップと担当者確認
2. 各社への調査協力依頼（回収率向上のため事前連絡）
3. オンラインまたは訪問による調査実施
4. 未回答企業への督促（最低3回）
```

**結果: 回収率95%（95社/100社）**
- 5社は倒産・連絡不能により調査不可
- 母集団カバー率95%の高精度データ取得

💡 **実際の現場では**: 全数調査でも100%の回収は困難。90%以上の回収率で実質的な全数調査とみなすことが多い。

### 標本調査（サンプリング調査）
**特徴:**
- 母集団から一部を抽出して調査する
- 統計的推論により全体を推定
- コストと時間を大幅に削減可能

**算出方法:**
```
必要標本数 n = (Z²×p×(1-p))/e²

Z: 信頼水準に対応する標準正規分布の値（95%信頼水準で1.96）
p: 母比率の推定値（不明な場合は0.5）
e: 許容誤差
```

**📊 具体的な計算例**
**例: 新商品の購入意向調査**
- 前提条件: 信頼水準95%、許容誤差5%
- 母比率は不明のため0.5と仮定

**計算過程:**
```
n = (1.96²×0.5×0.5)/0.05²
n = (3.8416×0.25)/0.0025
n = 0.9604/0.0025
n = 384.16
```

**結果: 必要標本数は385名**

💡 **実際の現場では**: 回収率を考慮し、必要数の1.5～2倍に調査を実施。385名必要なら600～800名に調査票を送付。

## 3. 標本選定方法による分類

### 有意抽出法（非確率抽出法）
**定義:** 調査者の判断や便宜性に基づいて標本を選定する方法

#### 典型的調査法（典型抽出法）
- **意味**: 母集団の典型的・代表的と思われる対象を調査者が選定
- **設定例**: 「平均的な30代主婦」として特定の人物を選定
- **影響**: 調査者の主観が強く反映される
- **推奨場面**: 探索的調査、仮説構築段階

**具体例:**
```
【化粧品の使用実態調査】
対象: 30代女性会社員
選定: 人事部データから「典型的」と思われる5名を抽出
基準: 
- 年収400-600万円
- 既婚・子供なし
- 都市部在住
```

#### 便宜的抽出法（コンビニエンスサンプリング）
- **意味**: 調査しやすい対象から標本を選定
- **設定例**: 街頭でたまたま通りかかった人にインタビュー
- **影響**: 特定の属性に偏りやすい
- **推奨場面**: 予備調査、緊急調査

**実施例:**
```
【駅前での購買行動調査】
場所: 新宿駅南口
時間: 平日18-20時
対象: 通行人から無作為に声かけ
問題点: サラリーマン層に偏る可能性大
```

#### 割当法（クォータサンプリング）
- **意味**: 母集団の構成比に合わせて標本数を割り当て
- **設定例**: 年代別人口比に応じて各年代から一定数を選定
- **影響**: 構成比は正確だが、各層内での選定に偏りが生じる可能性
- **推奨場面**: 迅速な市場調査が必要な場合

**割当表の例:**
| 年代 | 母集団構成比 | 標本数(n=1000) | 実際の選定方法 |
|------|-------------|----------------|----------------|
| 20代 | 20% | 200名 | 街頭調査 |
| 30代 | 25% | 250名 | ネット調査 |
| 40代 | 30% | 300名 | ネット調査 |
| 50代 | 25% | 250名 | 電話調査 |

### 無作為抽出法（確率抽出法）
**定義:** すべての要素が等しい確率で選ばれる可能性を持つ抽出方法

#### 単純無作為抽出法
- **意味**: 乱数表や乱数発生器を用いて完全にランダムに選定
- **実施手順**: 
  1. 母集団リストに通し番号を付与
  2. 乱数を発生させて該当番号を選定
- **影響**: 最も偏りが少ない
- **推奨場面**: 母集団が均質で、リストが完備している場合

**実施例:**
```python
# 顧客ID 10001～20000から500名を抽出
import random
customer_ids = range(10001, 20001)
sample = random.sample(customer_ids, 500)
```

#### 系統抽出法（等間隔抽出法）
- **意味**: 一定間隔で機械的に標本を選定
- **計算式**: 抽出間隔 k = N/n（N:母集団数、n:標本数）
- **影響**: リストに周期性がある場合は偏りが生じる
- **推奨場面**: 大規模な母集団リストがある場合

**具体例:**
```
母集団: 5000名の会員リスト
必要標本数: 250名
抽出間隔: k = 5000/250 = 20

手順:
1. 1～20の中から開始番号をランダムに決定（例:7）
2. 7番目、27番目、47番目...と20名おきに抽出
```

#### 層化抽出法（層別抽出法）
- **意味**: 母集団を層（グループ）に分けてから各層から無作為抽出
- **設定方法**: 重要な属性（年齢、地域、収入等）で層化
- **影響**: 各層の特性を確実に反映できる
- **推奨場面**: 母集団が異質な集団の組み合わせの場合

**層化の例:**
| 地域 | 母集団数 | 構成比 | 比例配分 | 最適配分 |
|------|----------|--------|----------|----------|
| 関東 | 20,000 | 40% | 400名 | 450名 |
| 関西 | 15,000 | 30% | 300名 | 280名 |
| 中部 | 10,000 | 20% | 200名 | 180名 |
| その他 | 5,000 | 10% | 100名 | 90名 |

#### 多段抽出法（多段階抽出法）
- **意味**: 複数の段階を経て最終的な標本を選定
- **実施例**: 市区町村→町丁目→世帯→個人の順に抽出
- **影響**: 調査の効率性は高いが、誤差が累積する
- **推奨場面**: 全国規模の大規模調査

**実施フロー:**
```
第1段階: 全国から50市区町村を無作為抽出
↓
第2段階: 各市区町村から5地点を無作為抽出
↓
第3段階: 各地点から20世帯を系統抽出
↓
第4段階: 各世帯から1名を無作為抽出
= 合計5,000名の標本
```

## 4. 実装例・適用事例

### 全数調査の実装例
```
【B2B企業の顧客ロイヤルティ調査】
対象: 取引先全300社
方法: 
1. 経営層向けオンライン調査（NPS含む）
2. 現場担当者向け電話インタビュー
3. 年間取引データとの突合分析

結果活用:
- 離反リスクの高い顧客の特定
- カスタマーサクセス施策の優先順位付け
- 営業戦略の見直し
```

### 標本調査×無作為抽出の実装例
```
【新サービスのコンセプトテスト】
母集団: 自社アプリユーザー50万人
標本設計:
- 層化: 利用頻度（高/中/低）×年代（3区分）= 9層
- 各層から比例配分で合計3,000名を抽出
- 調査方法: アプリ内アンケート

分析手法:
- 層別の受容性分析
- 価格感度測定（PSM分析）
- 導入意向のロジスティック回帰分析
```

### 実際の適用事例

#### 事例1: 大手飲料メーカーA社
- **課題**: 新フレーバーの市場投入前評価
- **適用方法**: 
  - 第1段階: 有意抽出（社内テスト）
  - 第2段階: 割当法による街頭調査（n=500）
  - 第3段階: 層化無作為抽出による本調査（n=3000）
- **結果**: 段階的にリスクを低減しながら市場性を検証
- **効果**: 開発コスト40%削減、的中率85%達成

#### 事例2: ECサイトB社
- **課題**: 100万人のユーザー行動分析
- **適用方法**: 
  - 購買履歴による層化（RFM分析）
  - 各層から2%を系統抽出（n=20,000）
  - 詳細な行動ログ分析とアンケート調査
- **結果**: 全数分析の1/50のコストで95%の精度達成
- **効果**: 月次での定期調査が可能になり、施策PDCAが高速化

## 5. メリット・デメリット

### 全数調査のメリット・デメリット

**メリット**
**1. 完全な情報取得**
- **理由**: すべての対象を調査するため、見落としがない
- **効果**: 意思決定の確実性が最大化
- **具体例**: M&A時のデューデリジェンスで全取引先を調査

**2. 統計的推論が不要**
- **理由**: 標本誤差が存在しない
- **効果**: 複雑な統計処理なしに結論が得られる
- **具体例**: 社員満足度調査で全員の声を直接把握

**デメリット**
**1. 高コスト・長期間**
- **理由**: 調査対象数に比例してコストと時間が増大
- **影響**: 大規模調査では現実的に実施困難
- **対策**: 重要な意思決定時のみ実施、または段階的実施

**2. 調査品質の低下リスク**
- **理由**: 大量の調査による疲弊、管理の困難さ
- **影響**: 回答の質が低下、無回答増加
- **対策**: 調査員の十分な確保と研修、IT活用による効率化

### 標本調査のメリット・デメリット

**メリット**
**1. 経済性・迅速性**
- **理由**: 限定された対象のみ調査
- **効果**: コスト削減率80-95%、期間短縮率70-90%
- **具体例**: 全国1億人から2000人の調査で十分な精度

**2. 調査の深掘りが可能**
- **理由**: 対象が少ないため、詳細な調査が可能
- **効果**: 質的データも含めた豊富な情報取得
- **具体例**: 2時間の詳細インタビューも実施可能

**デメリット**
**1. 標本誤差の存在**
- **理由**: 一部から全体を推定するため
- **影響**: 結果に不確実性が残る
- **対策**: 適切な標本サイズの確保、信頼区間の明示

**2. 標本の代表性の問題**
- **理由**: 抽出方法により偏りが生じる可能性
- **影響**: 誤った結論に至るリスク
- **対策**: 無作為抽出の徹底、事後的な重み付け補正

### 有意抽出法と無作為抽出法の比較

| 観点 | 有意抽出法 | 無作為抽出法 |
|------|------------|--------------|
| 統計的推論 | 不可能 | 可能 |
| 実施の容易さ | 容易 | やや困難 |
| コスト | 低い | やや高い |
| 調査期間 | 短い | やや長い |
| 結果の一般化 | 困難 | 可能 |
| 適用場面 | 探索的調査 | 検証的調査 |

## 6. 選択・導入の指針

### 調査手法選択の基準
| 観点 | 全数調査 | 標本調査（無作為） | 標本調査（有意） |
|------|---------|-------------------|------------------|
| 精度 | ◎ | ○ | △ |
| 速度 | △ | ○ | ◎ |
| コスト | △ | ○ | ◎ |
| 実施難易度 | △ | ○ | ◎ |

### 適用判断フローチャート
1. **母集団サイズは1000以下か？** 
   - Yes → 全数調査を検討
   - No → 次の判断へ

2. **統計的な一般化が必要か？**
   - Yes → 無作為抽出法を選択
   - No → 有意抽出法で効率化

3. **予算・時間は十分か？**
   - Yes → より精度の高い手法を選択
   - No → 効率性を重視した手法を選択

### 実務での組み合わせ戦略

```
【段階的アプローチ】
Phase 1: 有意抽出による仮説構築
  ↓（インサイト発見）
Phase 2: 無作為抽出による仮説検証  
  ↓（定量的検証）
Phase 3: 重要セグメントの全数調査
  ↓（詳細把握）
最終意思決定
```

### 問題1
マーケティングリサーチにおける「母集団」の定義として最も適切なものはどれか？

- A) 実際に調査を行った対象者の全体
- B) 調査結果を適用したい対象の全体
- C) 調査に協力してくれた人の全体
- D) 標本として選ばれた人の全体

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
母集団とは、調査結果を適用したい（一般化したい）対象の全体を指します。例えば「日本の20代女性の化粧品購買行動」を知りたい場合、日本在住の20代女性全員が母集団となります。<br>
<br>
Aが間違いの理由：実際に調査を行った対象者は「標本」であり、母集団ではありません<br>
Cが間違いの理由：調査に協力してくれた人は「有効回答者」であり、母集団の定義とは異なります<br>
Dが間違いの理由：標本として選ばれた人の全体は「標本」そのものであり、母集団ではありません<br>
<br>
【補足】実務では、母集団の定義を明確にすることが調査設計の第一歩となります。
</details>

### 問題2
全数調査（悉皆調査）を実施すべき状況として、最も適切なものはどれか？

- A) 全国の消費者1億人の購買行動を調査する場合
- B) 自社の重要取引先50社の満足度を調査する場合
- C) 新商品のコンセプトについて消費者の反応を見る場合
- D) 市場トレンドを素早く把握したい場合

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
重要取引先50社という限定された数の調査対象で、かつ各社との関係が重要である場合は、全数調査が適切です。すべての取引先の声を漏れなく把握することで、個別対応も可能になります。<br>
<br>
Aが間違いの理由：1億人規模では物理的・経済的に全数調査は不可能です<br>
Cが間違いの理由：コンセプトテストは標本調査で十分であり、全数調査は過剰です<br>
Dが間違いの理由：素早い把握が必要な場合は、時間のかかる全数調査は不適切です<br>
<br>
【補足】実務では、母集団が数百程度までなら全数調査を検討する価値があります。
</details>

### 問題3
標本調査における必要標本数の計算で、信頼水準95%、許容誤差3%、母比率0.5の場合、必要標本数は約何名か？

- A) 384名
- B) 600名
- C) 1,067名
- D) 2,401名

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
計算式：n = (Z²×p×(1-p))/e²<br>
n = (1.96²×0.5×0.5)/0.03²<br>
n = (3.8416×0.25)/0.0009<br>
n = 0.9604/0.0009<br>
n = 1,067.1<br>
したがって、必要標本数は約1,067名です。<br>
<br>
Aが間違いの理由：これは許容誤差5%の場合の標本数です<br>
Bが間違いの理由：計算が正しく行われていません<br>
Dが間違いの理由：これは許容誤差2%の場合の標本数です<br>
<br>
【補足】許容誤差を小さくするほど、必要標本数は急激に増加します。
</details>

### 問題4
有意抽出法の一種である「割当法（クォータサンプリング）」の説明として正しいものはどれか？

- A) 調査者が典型的と考える対象を主観的に選ぶ方法
- B) 母集団の構成比に合わせて標本数を割り当てる方法
- C) 調査しやすい対象から順に選んでいく方法
- D) 完全にランダムに対象を選ぶ方法

## 9. 専門用語集

### アルファベット・数字

**NPS (Net Promoter Score)**
- **読み方**: エヌピーエス
- **意味**: 顧客ロイヤルティを測る指標。「この商品・サービスを友人に薦める可能性」を0-10点で評価し、推奨者の割合から批判者の割合を引いて算出
- **関連用語**: 顧客満足度、顧客ロイヤルティ

**PSM分析 (Price Sensitivity Measurement)**
- **読み方**: ピーエスエム分析
- **意味**: 価格感度測定法。4つの質問により、消費者が感じる適正価格帯を把握する手法
- **関連用語**: 価格調査、需要予測

**RFM分析**
- **読み方**: アールエフエム分析
- **意味**: Recency（最終購買日）、Frequency（購買頻度）、Monetary（購買金額）の3指標で顧客を分類する手法
- **関連用語**: 顧客セグメンテーション、CRM

### あ行

**有意抽出法（ゆういちゅうしゅつほう）**
- **読み方**: ゆういちゅうしゅつほう
- **意味**: 調査者の判断により、意図的に調査対象を選定する標本抽出方法。非確率抽出法とも呼ばれる
- **関連用語**: 無作為抽出法、標本調査

**有効回答（ゆうこうかいとう）**
- **読み方**: ゆうこうかいとう
- **意味**: 調査で回収された回答のうち、分析に使用できる適切な回答。無効票を除いたもの
- **関連用語**: 回収率、無効票

### か行

**回収率（かいしゅうりつ）**
- **読み方**: かいしゅうりつ
- **意味**: 調査票を配布した数に対する、回収できた調査票の割合。調査の質を左右する重要指標
- **関連用語**: 有効回答率、督促

**確率抽出法（かくりつちゅうしゅつほう）**
- **読み方**: かくりつちゅうしゅつほう
- **意味**: すべての要素が既知の確率で選ばれる可能性を持つ抽出方法。無作為抽出法と同義
- **関連用語**: 有意抽出法、標本理論

**割当法（かっとうほう）**
- **読み方**: かっとうほう
- **意味**: 母集団の属性別構成比に合わせて、各カテゴリーから一定数の標本を割り当てる有意抽出法の一種
- **関連用語**: クォータサンプリング、有意抽出法

### さ行

**悉皆調査（しっかいちょうさ）**
- **読み方**: しっかいちょうさ
- **意味**: 調査対象となる母集団のすべての要素を漏れなく調査する方法。全数調査と同義
- **関連用語**: 全数調査、センサス

**信頼水準（しんらいすいじゅん）**
- **読み方**: しんらいすいじゅん
- **意味**: 標本から得られた推定値が、真の値を含む確率。通常95%または99%が用いられる
- **関連用語**: 信頼区間、許容誤差

**信頼区間（しんらいくかん）**
- **読み方**: しんらいくかん
- **意味**: ある信頼水準において、母集団の真の値が含まれると考えられる区間
- **関連用語**: 信頼水準、区間推定

**層化抽出法（そうかちゅうしゅつほう）**
- **読み方**: そうかちゅうしゅつほう
- **意味**: 母集団を同質的な層（グループ）に分けてから、各層から無作為に標本を抽出する方法
- **関連用語**: 層別抽出法、比例配分

### た行

**多段抽出法（ただんちゅうしゅつほう）**
- **読み方**: ただんちゅうしゅつほう
- **意味**: 複数の段階を経て最終的な調査対象を選定する抽出方法。大規模調査で用いられる
- **関連用語**: 多段階抽出法、クラスター抽出

**単純無作為抽出法（たんじゅんむさくいちゅうしゅつほう）**
- **読み方**: たんじゅんむさくいちゅうしゅつほう
- **意味**: 母集団から完全にランダムに標本を選ぶ最も基本的な無作為抽出法
- **関連用語**: 乱数表、無作為抽出

**典型的調査法（てんけいてきちょうさほう）**
- **読み方**: てんけいてきちょうさほう
- **意味**: 調査者が母集団の典型的・代表的と考える対象を主観的に選定する有意抽出法の一種
- **関連用語**: 有意抽出法、典型抽出法

### は行

**標本（ひょうほん）**
- **読み方**: ひょうほん
- **意味**: 母集団から抽出された、実際に調査を行う対象の集合。サンプルとも呼ばれる
- **関連用語**: 母集団、標本調査

**標本誤差（ひょうほんごさ）**
- **読み方**: ひょうほんごさ
- **意味**: 標本調査において、標本から得られた推定値と母集団の真の値との差。サンプリングエラー
- **関連用語**: 非標本誤差、標準誤差

**標本調査（ひょうほんちょうさ）**
- **読み方**: ひょうほんちょうさ
- **意味**: 母集団から一部を抽出して調査し、その結果から全体を推定する調査方法
- **関連用語**: 全数調査、サンプリング調査

**標本分布（ひょうほんぶんぷ）**
- **読み方**: ひょうほんぶんぷ
- **意味**: 同じ母集団から同じサイズの標本を繰り返し抽出したときの統計量の分布
- **関連用語**: 中心極限定理、標準誤差

**比例配分（ひれいはいぶん）**
- **読み方**: ひれいはいぶん
- **意味**: 層化抽出法において、各層の大きさに比例して標本数を配分する方法
- **関連用語**: 最適配分、層化抽出法

**便宜的抽出法（べんぎてきちゅうしゅつほう）**
- **読み方**: べんぎてきちゅうしゅつほう
- **意味**: 調査しやすい対象から標本を選定する有意抽出法の一種。コンビニエンスサンプリング
- **関連用語**: 有意抽出法、アクセシビリティサンプリング

**母集団（ぼしゅうだん）**
- **読み方**: ぼしゅうだん
- **意味**: 調査結果を適用したい（一般化したい）対象全体。ポピュレーション
- **関連用語**: 標本、全数調査

**母比率（ぼひりつ）**
- **読み方**: ぼひりつ
- **意味**: 母集団において、ある特性を持つ要素の割合
- **関連用語**: 標本比率、比率の推定

### ま行

**無作為抽出法（むさくいちゅうしゅつほう）**
- **読み方**: むさくいちゅうしゅつほう
- **意味**: すべての要素が等しい確率で選ばれる可能性を持つ抽出方法。確率抽出法と同義
- **関連用語**: 有意抽出法、ランダムサンプリング

### や行

**許容誤差（きょようごさ）**
- **読み方**: きょようごさ
- **意味**: 標本調査において許容できる推定値と真の値との最大差。誤差限界とも呼ばれる
- **関連用語**: 信頼水準、標本サイズ

### ら行

**乱数表（らんすうひょう）**
- **読み方**: らんすうひょう
- **意味**: 無作為抽出を行うために用いる、ランダムに並んだ数字の表
- **関連用語**: 乱数発生器、単純無作為抽出

### その他

**系統抽出法（けいとうちゅうしゅつほう）**
- **読み方**: けいとうちゅうしゅつほう
- **意味**: 母集団リストから一定間隔で機械的に標本を抽出する方法。等間隔抽出法とも呼ばれる
- **関連用語**: 抽出間隔、無作為抽出法

**全数調査（ぜんすうちょうさ）**
- **読み方**: ぜんすうちょうさ
- **意味**: 調査対象となる母集団のすべての要素を調査する方法。悉皆調査、センサスと同義
- **関連用語**: 標本調査、国勢調査
