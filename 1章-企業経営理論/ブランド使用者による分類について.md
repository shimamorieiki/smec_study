# ブランド使用者による分類について

## 概要

ブランドは、その使用者（開発・管理主体）によって大きく分類することができます。この分類は、製造業者、小売業者、消費者それぞれの立場から見たブランド戦略を理解する上で重要な概念です。本資料では、特に「ナショナルブランド」と「プライベートブランド」を中心に、ブランド使用者による分類について詳しく解説します。

## 1. 基本概念・定義

### ブランドとは
- **定義**: 製品・サービスを識別し、競合他社と差別化するための名称、記号、デザイン、またはこれらの組み合わせ
- **機能**: 識別機能、品質保証機能、象徴機能、資産価値機能
- **重要性**: 企業の競争優位性確立、顧客ロイヤリティの構築、価格プレミアムの獲得

### ブランド使用者による分類の意義
- **定義**: ブランドを開発・管理・使用する主体によってブランドを分類する方法
- **目的**: 流通構造の理解、マーケティング戦略の立案、消費者行動の分析
- **影響**: 価格設定、プロモーション戦略、流通チャネル選択に大きく関わる

## 2. ブランドの分類・種類

### 分類基準
ブランドは、誰が開発・管理・使用するかによって、主に以下の3つに分類されます：

1. **ナショナルブランド（NB：National Brand）**
2. **プライベートブランド（PB：Private Brand）**
3. **ジェネリックブランド（Generic Brand）**

### ナショナルブランド（NB）の詳細

| 項目 | 内容 |
|------|------|
| 定義 | 製造業者（メーカー）が開発・管理するブランド |
| 別称 | メーカーブランド、製造業者ブランド |
| 特徴 | ・全国規模での展開<br>・大規模な広告宣伝<br>・統一的な品質管理<br>・高いブランド認知度 |
| 価格帯 | 一般的に高価格帯（広告費・開発費を含むため） |
| 流通 | 複数の小売店で販売される |
| 例 | 花王「メリット」、資生堂「TSUBAKI」、明治「おいしい牛乳」 |

### プライベートブランド（PB）の詳細

| 項目 | 内容 |
|------|------|
| 定義 | 小売業者や卸売業者が企画・開発し、自社で販売するブランド |
| 別称 | ストアブランド、自主企画商品、流通業者ブランド |
| 特徴 | ・特定の小売チェーンでのみ販売<br>・NBより低価格設定が可能<br>・小売業者の利益率が高い<br>・顧客の囲い込みが可能 |
| 価格帯 | NBより20-30%程度安い価格設定が一般的 |
| 流通 | 開発した小売業者の店舗のみで販売 |
| 例 | セブンプレミアム、トップバリュ（イオン）、みなさまのお墨付き（西友） |

### ジェネリックブランドの詳細

| 項目 | 内容 |
|------|------|
| 定義 | ブランド名を持たない、または最小限のブランド要素しか持たない商品 |
| 別称 | ノーブランド商品、無印商品 |
| 特徴 | ・最低限のパッケージ<br>・広告宣伝費ゼロ<br>・極めて低価格<br>・品質は基本的なレベル |
| 価格帯 | 最も低価格（NBの50%以下も可能） |
| 流通 | 主にディスカウントストアで販売 |
| 例 | 無地の包装の日用品、バルク販売商品 |

## 3. NBとPBの詳細比較

### 多面的な比較分析

| 比較項目 | ナショナルブランド（NB） | プライベートブランド（PB） |
|----------|------------------------|------------------------|
| 開発主体 | 製造業者（メーカー） | 小売業者・卸売業者 |
| 製造 | 自社製造が基本 | 委託製造が多い |
| 価格 | 高価格帯 | 低～中価格帯 |
| 品質 | 高品質・安定品質 | 品質は様々（近年は高品質化） |
| 広告宣伝 | 大規模な全国広告 | 店頭プロモーション中心 |
| 開発コスト | 高い（R&D、広告費） | 比較的低い |
| 利益率（小売） | 20-25% | 30-40% |
| 商品開発期間 | 長期（1-3年） | 短期（3-6ヶ月） |
| リスク | メーカーが負担 | 小売業者が負担 |
| 顧客ロイヤリティ | ブランドへの忠誠心 | 店舗への忠誠心 |

### 具体的な事例分析

#### 事例1: インスタントコーヒー市場

**NBの例：ネスカフェ ゴールドブレンド（ネスレ日本）**
- 価格：100g 約1,000円
- 特徴：豊かな香り、挽き豆包み製法
- 広告：テレビCM、著名人起用
- 流通：全国のスーパー、コンビニで販売

**PBの例：セブンプレミアム ゴールド 香りのインスタントコーヒー**
- 価格：90g 約600円（NBの約60%の価格）
- 特徴：フリーズドライ製法、深いコク
- 広告：店頭POPのみ
- 流通：セブン&アイグループ店舗限定

#### 事例2: シャンプー市場

**NBの例：パンテーン（P&G）**
- 価格：400ml 約800円
- 特徴：プロビタミン処方、髪質別ラインナップ
- 広告：グローバル展開、有名女優起用
- 開発：世界規模のR&D

**PBの例：トップバリュ モイスチャーシャンプー**
- 価格：500ml 約400円
- 特徴：基本的な洗浄・保湿機能
- 広告：チラシ、店頭表示
- 開発：製造委託先と共同開発

## 4. 戦略的な選択と活用

### メーカーの戦略

#### NB強化戦略
1. **ブランド価値向上**
   - 継続的なイノベーション
   - プレミアム化戦略
   - ブランドエクステンション

2. **流通対策**
   - 小売業者との協力関係構築
   - カテゴリーマネジメント提案
   - 独自の販売支援

#### PB対応戦略
1. **差別化戦略**
   - 技術的優位性の確立
   - 感性価値の訴求
   - 新カテゴリー創造

2. **協調戦略**
   - PB製造の受託
   - 技術提供による収益確保
   - Win-Winの関係構築

### 小売業者の戦略

#### PB開発の狙い
1. **収益性向上**
   - 粗利益率の改善
   - 価格決定権の確保
   - 仕入原価の削減

2. **差別化**
   - 独自商品による競合店との差別化
   - 顧客の囲い込み
   - ストアロイヤリティの向上

3. **カテゴリー支配**
   - 売場構成の自由度向上
   - NBとの価格比較による価値訴求
   - プライスリーダーシップ

### 消費者の購買行動

#### NB選択の理由
- ブランドへの信頼感
- 品質の安定性
- ステータスシンボル
- 広告による親近感

#### PB選択の理由
- 価格の安さ
- 十分な品質
- 店舗への信頼
- 合理的な消費志向

## 5. 最新動向と将来展望

### PBの進化

#### 第1世代PB（1970年代～）
- 低価格志向
- 品質は二の次
- シンプルなパッケージ

#### 第2世代PB（1990年代～）
- NBと同等品質
- 価格は2-3割安
- デザイン性向上

#### 第3世代PB（2000年代～）
- プレミアムPBの登場
- NBを超える品質
- こだわりの原材料
- 例：セブンプレミアムゴールド

#### 第4世代PB（2010年代～）
- サステナビリティ重視
- オーガニック・エシカル
- 機能性特化
- デジタル連携

### 市場環境の変化

1. **消費者意識の変化**
   - 賢い消費志向
   - 品質重視
   - 環境配慮

2. **技術革新の影響**
   - EC・D2Cブランドの台頭
   - パーソナライゼーション
   - サプライチェーンの効率化

3. **NBとPBの境界の曖昧化**
   - コラボレーション商品
   - 限定商品の共同開発
   - 相互OEM

## 6. 実務上の注意点

### メーカー側の注意点

1. **PB製造受託時の検討事項**
   - 自社NBとの競合関係
   - 技術流出のリスク
   - 製造キャパシティ
   - 収益性の確保

2. **ブランド管理**
   - ブランドイメージの維持
   - 品質管理の徹底
   - 知的財産権の保護

### 小売業者側の注意点

1. **PB開発時の検討事項**
   - 適切なカテゴリー選定
   - 製造委託先の選定
   - 在庫リスクの管理
   - 品質保証体制

2. **売場構成**
   - NBとPBの最適な構成比
   - 価格帯のバランス
   - 陳列方法の工夫

## 7. よくある質問（Q&A）

### Q1. なぜPBはNBより安く提供できるのですか？

**A1.** PBが安く提供できる主な理由は以下の通りです：

1. **広告宣伝費の削減**
   - NBは売上の5-10%を広告費に使用
   - PBは店頭プロモーションのみで済む
   - 年間数億円の削減が可能

2. **流通コストの削減**
   - 中間流通業者を介さない
   - 物流の効率化
   - 在庫管理の最適化

3. **開発コストの効率化**
   - 既存商品の模倣が可能
   - 開発期間の短縮
   - パッケージの簡素化

4. **利益構造の違い**
   - メーカー利益分が不要
   - 小売マージンの調整が可能

### Q2. PBの品質は本当にNBと同等なのでしょうか？

**A2.** 現代のPBの品質については以下の点が重要です：

1. **製造元の実態**
   - 多くのPBは大手メーカーが製造
   - NBと同じ工場・製造ラインを使用
   - 品質管理基準も同等

2. **品質の多様性**
   - 価格帯により品質レベルは異なる
   - プレミアムPBはNBを超える場合も
   - カテゴリーにより品質差は様々

3. **品質保証**
   - 小売業者の信用に関わるため品質管理は厳格
   - 第三者認証取得も増加
   - トレーサビリティの確保

### Q3. メーカーはなぜライバルとなるPBを製造するのですか？

**A3.** メーカーがPB製造を受託する戦略的理由：

1. **経営上のメリット**
   - 製造設備の稼働率向上
   - 安定的な売上確保
   - 固定費の効率的回収

2. **取引関係の維持**
   - 小売業者との良好な関係構築
   - NBの棚確保への影響力
   - 情報収集の機会

3. **リスク分散**
   - NB依存からの脱却
   - 複数の収益源確保
   - 市場変化への対応力向上

4. **戦略的判断**
   - 他社に製造させるよりは自社で管理
   - 技術力のアピール
   - 新規参入障壁の構築

## 8. まとめ・今後の展望

ブランド使用者による分類は、現代の流通構造を理解する上で不可欠な概念です。ナショナルブランドとプライベートブランドは、それぞれ異なる特徴と戦略的意義を持ち、消費者に多様な選択肢を提供しています。

今後は、デジタル技術の進化、サステナビリティへの意識の高まり、パーソナライゼーションのニーズ拡大により、NBとPBの関係性はさらに複雑化し、新たなブランド形態も登場することが予想されます。企業は、これらの変化に柔軟に対応しながら、消費者価値を最大化する戦略を構築することが求められています。

<summary>解答</summary>

<br>
Aは誤りで、むしろメーカーとの交渉力を高めます。<br>

Dは目的ではなく、むしろ在庫リスクが課題となります。
</details>

</details>

## 10. 専門用語集

このスライドで使用された専門用語について、50音順で解説します。

### あ行

**オムニチャネル**
- **読み方**: おむにちゃねる
- **意味**: 実店舗、ECサイト、モバイルアプリなど、あらゆる販売チャネルを統合し、顧客に一貫した購買体験を提供する戦略
- **関連用語**: マルチチャネル、O2O

**オーガニック**
- **読み方**: おーがにっく
- **意味**: 有機栽培された原材料を使用した商品。化学肥料や農薬を使用せず、環境に配慮した生産方法
- **関連用語**: エシカル、サステナビリティ

### か行

**カテゴリーマネジメント**
- **読み方**: かてごりーまねじめんと
- **意味**: 商品カテゴリーを戦略的事業単位として管理し、消費者価値を最大化する小売マネジメント手法
- **関連用語**: 棚割り、品揃え

**カニバリゼーション**
- **読み方**: かにばりぜーしょん
- **意味**: 自社の商品同士が競合し、互いの売上を奪い合う現象。共食い現象とも呼ばれる
- **関連用語**: 製造業者のパラドックス

**協調戦略**
- **読み方**: きょうちょうせんりゃく
- **意味**: 競合他社や取引先と協力関係を構築し、相互利益を追求する戦略
- **関連用語**: Win-Win、アライアンス

### さ行

**サステナビリティ**
- **読み方**: さすてなびりてぃ
- **意味**: 持続可能性。環境・社会・経済の3つの観点から、将来世代のニーズを損なうことなく現在のニーズを満たすこと
- **関連用語**: SDGs、CSR

**ジェネリックブランド**
- **読み方**: じぇねりっくぶらんど
- **意味**: ブランド名を持たない、または最小限のブランド要素しか持たない低価格商品
- **関連用語**: ノーブランド、無印商品

**ストアブランド**
- **読み方**: すとあぶらんど
- **意味**: プライベートブランドの別称。特定の小売店が独自に企画・販売する商品ブランド
- **関連用語**: PB、自主企画商品

**ストアロイヤリティ**
- **読み方**: すとあろいやりてぃ
- **意味**: 消費者が特定の店舗に対して持つ愛着や忠誠心。店舗への継続的な来店意向
- **関連用語**: 顧客ロイヤリティ、ブランドロイヤリティ

### た行

**ディスカウントストア**
- **読み方**: でぃすかうんとすとあ
- **意味**: 低価格を最大の訴求点とし、経費を削減して安値販売を行う小売業態
- **関連用語**: 量販店、激安店

**デファクト・スタンダード**
- **読み方**: でふぁくと・すたんだーど
- **意味**: 事実上の標準。市場競争の結果として広く普及し、実質的な標準となった規格や仕様
- **関連用語**: 公的標準、業界標準

### な行

**ナショナルブランド（NB）**
- **読み方**: なしょなるぶらんど
- **意味**: 製造業者が開発・管理し、全国規模で展開される商品ブランド
- **関連用語**: メーカーブランド、製造業者ブランド

### は行

**パーソナライゼーション**
- **読み方**: ぱーそならいぜーしょん
- **意味**: 個々の顧客の嗜好や購買履歴に基づいて、商品やサービスを個別最適化すること
- **関連用語**: One to Oneマーケティング、カスタマイゼーション

**プライベートブランド（PB）**
- **読み方**: ぷらいべーとぶらんど
- **意味**: 小売業者や卸売業者が企画・開発し、自社で販売する独自商品ブランド
- **関連用語**: ストアブランド、自主企画商品

**ブランドエクステンション**
- **読み方**: ぶらんどえくすてんしょん
- **意味**: 既存の成功したブランド名を新しい商品カテゴリーに拡張する戦略
- **関連用語**: ブランド拡張、ライン拡張

**プレミアムPB**
- **読み方**: ぷれみあむぴーびー
- **意味**: 高品質・高付加価値を追求し、NBと同等以上の価格帯で展開されるプライベートブランド
- **関連用語**: 第3世代PB、高級PB

### ま行

**マーチャンダイジング**
- **読み方**: まーちゃんだいじんぐ
- **意味**: 商品計画。消費者ニーズに合った商品を、適切な場所・時期・価格・数量で提供する活動
- **関連用語**: MD、商品政策

### ら行

**流通業者ブランド**
- **読み方**: りゅうつうぎょうしゃぶらんど
- **意味**: プライベートブランドの別称。流通業者（小売・卸売）が開発するブランド
- **関連用語**: PB、ストアブランド

### アルファベット

**D2C（Direct to Consumer）**
- **読み方**: ディーツーシー
- **意味**: 製造者が卸売業者や小売業者を介さず、直接消費者に商品を販売するビジネスモデル
- **関連用語**: EC、ダイレクトマーケティング

**EC（Electronic Commerce）**
- **読み方**: イーシー
- **意味**: 電子商取引。インターネットを通じて商品やサービスを売買すること
- **関連用語**: ネット通販、オンラインショッピング

**OEM（Original Equipment Manufacturing）**
- **読み方**: オーイーエム
- **意味**: 相手先ブランドによる生産。他社ブランドの製品を製造すること
- **関連用語**: 受託製造、PB製造

**R&D（Research and Development）**
- **読み方**: アールアンドディー
- **意味**: 研究開発。新製品や新技術の開発のための研究活動
- **関連用語**: 商品開発、技術開発

**SKU（Stock Keeping Unit）**
- **読み方**: エスケーユー
- **意味**: 在庫管理単位。商品を管理する最小単位
- **関連用語**: アイテム、品番

**Win-Win**
- **読み方**: ウィンウィン
- **意味**: 関係する全ての当事者が利益を得られる状況や関係
- **関連用語**: 相互利益、協調戦略
