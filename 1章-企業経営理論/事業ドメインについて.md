# 事業ドメインについて

## 概要

事業ドメイン（Business Domain）とは、企業が事業活動を展開する領域や範囲を意味する概念です。企業が「何の事業を行うか」「どの市場で競争するか」を明確にする戦略的な枠組みであり、経営資源の配分や競争優位性の構築において重要な役割を果たします。企業ドメインと事業ドメインは密接に関連しながらも、その範囲と焦点において明確な違いがあります。

## 1. 基本概念・定義

### ドメインの意味と重要性
- **定義**: 企業が活動する事業領域の範囲と境界を示す概念
- **特徴**: 企業の存在意義、方向性、競争領域を規定
- **重要性**: 経営資源の配分、戦略的意思決定、組織アイデンティティの基盤

### ドメインの構成要素
- **顧客層（WHO）**: 誰に価値を提供するか
- **顧客ニーズ（WHAT）**: どのような価値・機能を提供するか
- **技術（HOW）**: どのような方法・技術で提供するか

## 2. ドメインの定義方法

### 機能的定義（Functional Definition）

#### 概念と特徴
機能的定義とは、企業が顧客に提供する「機能」や「価値」を中心にドメインを定義する方法です。

| 項目 | 内容 |
|------|------|
| 焦点 | 顧客ニーズ・提供価値 |
| 視点 | 顧客視点・市場視点 |
| 特徴 | 柔軟性が高い、環境変化に対応しやすい |
| リスク | 定義が曖昧になりやすい |

#### 機能的定義の例
1. **コミュニケーション事業**
   - 物理的定義：電話機メーカー
   - 機能的定義：人々のコミュニケーションを支援する事業
   - 展開可能性：電話→メール→SNS→メタバース

2. **移動支援事業**
   - 物理的定義：自動車メーカー
   - 機能的定義：人々の移動を快適にする事業
   - 展開可能性：自動車→カーシェア→MaaS→自動運転サービス

### 物理的定義（Physical Definition）

#### 概念と特徴
物理的定義とは、企業が扱う「製品」や「技術」を中心にドメインを定義する方法です。

| 項目 | 内容 |
|------|------|
| 焦点 | 製品・サービス・技術 |
| 視点 | 企業視点・内部視点 |
| 特徴 | 明確で理解しやすい、管理しやすい |
| リスク | 環境変化への対応が遅れやすい |

#### 物理的定義の例
1. **フィルムメーカー**
   - 物理的定義：写真フィルムの製造・販売事業
   - 限界：デジタルカメラの普及で市場が縮小
   - 課題：新たな事業領域への転換が困難

2. **新聞社**
   - 物理的定義：紙の新聞の発行・販売事業
   - 限界：インターネットの普及で購読者減少
   - 課題：デジタル化への対応の遅れ

## 3. 機能的定義と物理的定義の比較

### 詳細比較表

| 比較項目 | 機能的定義 | 物理的定義 |
|----------|-----------|-----------|
| **定義の中心** | 顧客ニーズ・提供価値 | 製品・技術・サービス |
| **範囲の広さ** | 広い（抽象的） | 狭い（具体的） |
| **環境適応性** | 高い | 低い |
| **戦略的柔軟性** | 高い | 低い |
| **事業拡張性** | 容易 | 困難 |
| **組織の理解** | やや困難 | 容易 |
| **経営資源配分** | 複雑 | 単純 |
| **イノベーション** | 促進しやすい | 制限されやすい |

### 各定義のメリット・デメリット

#### 機能的定義のメリット
1. **市場機会の拡大**: 顧客ニーズを軸に新たな事業機会を発見しやすい
2. **持続的成長**: 技術や製品の陳腐化に左右されにくい
3. **イノベーション促進**: 既存の枠にとらわれない発想が生まれやすい

#### 機能的定義のデメリット
1. **資源分散リスク**: 事業領域が広がりすぎる可能性
2. **組織の混乱**: 明確な境界がないため組織運営が複雑化
3. **競争優位の希薄化**: 専門性が薄れる可能性

#### 物理的定義のメリット
1. **明確な方向性**: 組織メンバーが理解しやすい
2. **専門性の追求**: 特定領域での競争優位を構築しやすい
3. **効率的運営**: 経営資源の集中投下が可能

#### 物理的定義のデメリット
1. **市場縮小リスク**: 製品・技術の陳腐化で事業が行き詰まる
2. **機会損失**: 新たな市場機会を見逃しやすい
3. **組織の硬直化**: 変化への対応が遅れやすい

## 4. 企業ドメインと事業ドメインの比較

### 企業ドメイン（Corporate Domain）

#### 定義と特徴
企業ドメインとは、企業全体としての活動領域や存在意義を示す概念です。

| 項目 | 内容 |
|------|------|
| 範囲 | 企業全体の活動領域 |
| 視点 | 全社的・長期的視点 |
| 決定主体 | 経営トップ・取締役会 |
| 時間軸 | 長期（10年以上） |
| 目的 | 企業の存在意義・方向性の明確化 |

### 事業ドメイン（Business Domain）

#### 定義と特徴
事業ドメインとは、個別事業や事業部門レベルでの活動領域を示す概念です。

| 項目 | 内容 |
|------|------|
| 範囲 | 個別事業・事業部門の活動領域 |
| 視点 | 事業別・中期的視点 |
| 決定主体 | 事業部長・事業責任者 |
| 時間軸 | 中期（3-5年） |
| 目的 | 事業の競争領域・戦略の明確化 |

### 企業ドメインと事業ドメインの関係性

#### 階層構造
```
企業ドメイン（全社レベル）
  ├── 事業ドメインA（事業部門A）
  ├── 事業ドメインB（事業部門B）
  └── 事業ドメインC（事業部門C）
```

#### 相互関係の特徴
1. **整合性**: 事業ドメインは企業ドメインと整合性を保つ必要がある
2. **補完性**: 複数の事業ドメインが相互に補完し合う
3. **シナジー**: 事業間のシナジー効果を追求

### 類似点と相違点

#### 類似点
1. **戦略的概念**: 両者とも経営戦略の重要な要素
2. **境界設定**: 活動領域の範囲と境界を明確化
3. **資源配分**: 経営資源配分の基準となる
4. **競争優位**: 競争優位性構築の基盤
5. **組織アイデンティティ**: 組織の存在意義を規定

#### 相違点

| 比較項目 | 企業ドメイン | 事業ドメイン |
|----------|------------|------------|
| **対象範囲** | 企業全体 | 個別事業 |
| **抽象度** | 高い（抽象的） | 低い（具体的） |
| **変更頻度** | 低い | 中程度 |
| **意思決定レベル** | 経営トップ | 事業部門長 |
| **時間軸** | 長期（10年以上） | 中期（3-5年） |
| **多角化との関係** | 多角化の方向性を規定 | 個別事業の展開を規定 |
| **評価基準** | 企業価値・社会的価値 | 事業収益性・市場シェア |

## 5. 具体的事例分析

### ケース1: 富士フイルムのドメイン転換

#### 背景と課題
- **従来の物理的定義**: 写真フィルムメーカー
- **市場環境の変化**: デジタルカメラの普及でフィルム市場が急速に縮小
- **2000年の売上**: フィルム関連が全体の60%

#### ドメインの再定義
- **新たな機能的定義**: 「映像と情報の文化を創造する企業」
- **コア技術の活用**: フィルム技術を基盤とした新事業展開

#### 事業展開の結果
1. **ヘルスケア事業**: 医療用画像診断システム、医薬品
2. **高機能材料事業**: 液晶ディスプレイ用フィルム
3. **ドキュメント事業**: 複合機、ソリューションサービス
4. **成果**: 2020年にはフィルム事業は全体の1%未満に

### ケース2: Amazonの事業ドメイン拡大

#### 初期の事業ドメイン（1995年）
- **物理的定義**: オンライン書店
- **機能的定義**: 便利なオンラインショッピング体験の提供

#### 段階的な事業ドメイン拡大
1. **第1段階（1998-2000年）**: 書籍→音楽・DVD→あらゆる商品
2. **第2段階（2002-2006年）**: 小売→マーケットプレイス→クラウドサービス（AWS）
3. **第3段階（2007-現在）**: デジタルコンテンツ→AIアシスタント→物流革新

#### 企業ドメインの進化
- **現在の定義**: 「地球上で最も顧客中心の企業」
- **事業ドメインの多様化**: 小売、クラウド、エンターテインメント、物流

## 6. 実務上の注意点

### ドメイン設定時の重要ポイント

#### 1. バランスの重要性
- **広すぎるリスク**: 経営資源が分散し、競争優位を失う
- **狭すぎるリスク**: 市場機会を逃し、成長が制限される
- **最適解**: 自社の強みを活かせる適度な範囲設定

#### 2. 環境変化への対応
- **定期的な見直し**: 3-5年ごとにドメインの妥当性を検証
- **早期警戒指標**: 市場縮小、技術革新、顧客ニーズ変化の兆候を監視
- **柔軟な修正**: 環境変化に応じた迅速なドメイン修正

#### 3. 組織能力との整合性
- **コアコンピタンス**: 自社の強みを活かせるドメイン設定
- **資源制約**: 利用可能な経営資源の範囲内での設定
- **組織文化**: 組織メンバーが共感できるドメイン設定

### よくある誤解・失敗パターン

#### 誤解1: ドメインは一度決めたら変更しない
- **正しい理解**: ドメインは環境変化に応じて進化させるべき動的な概念
- **対応策**: 定期的なレビューと必要に応じた修正

#### 誤解2: 機能的定義は常に物理的定義より優れている
- **正しい理解**: 状況に応じて適切な定義方法を選択すべき
- **対応策**: 事業特性、競争環境、組織能力を考慮した選択

#### 誤解3: 事業ドメインは企業ドメインと無関係に設定できる
- **正しい理解**: 両者は密接に関連し、整合性が必要
- **対応策**: 企業ドメインを踏まえた事業ドメイン設定

## 7. よくある質問（Q&A）

### Q1. スタートアップ企業の場合、どのようにドメインを設定すべきですか？

**A1.** スタートアップ企業では、初期は比較的狭い物理的定義から始め、成長とともに機能的定義へ移行することが推奨されます。

#### 段階的アプローチ
1. **創業期**: 明確な製品・サービスで物理的定義
2. **成長期**: 顧客ニーズを深く理解し、機能的要素を追加
3. **拡大期**: 機能的定義を中心に事業領域を拡張
4. **成熟期**: 企業ドメインと事業ドメインの体系化

### Q2. 多角化企業の場合、企業ドメインはどの程度広く設定すべきですか？

**A2.** 多角化企業の企業ドメインは、すべての事業に共通する価値や理念を包含できる程度に広く、かつ企業のアイデンティティを明確に示せる程度に具体的であるべきです。

#### 設定のポイント
1. **共通価値の抽出**: 全事業に共通する顧客価値や社会的価値を特定
2. **シナジーの考慮**: 事業間のシナジーを生み出せる範囲設定
3. **成長余地の確保**: 将来の事業展開を制限しない柔軟性
4. **具体例**: 3M「イノベーションで生活を豊かにする」（多様な事業を包含）

### Q3. ドメインの変更はどのようなタイミングで行うべきですか？

**A3.** ドメイン変更は以下のシグナルが複数現れた時に検討すべきです。

#### 変更検討のシグナル
1. **市場シグナル**
   - 主力市場の成長率低下（3年連続マイナス成長など）
   - 代替品・新技術の脅威が顕在化
   - 顧客ニーズの質的変化

2. **競争シグナル**
   - 新規参入者による市場構造の変化
   - 競争ルールの根本的変化
   - 業界再編の動き

3. **内部シグナル**
   - 成長の停滞（売上・利益の頭打ち）
   - 従業員のモチベーション低下
   - イノベーション創出の停滞

## 8. まとめ・今後の展望

### ドメイン設定の重要性
事業ドメインの適切な設定は、企業の持続的成長と競争優位の構築において極めて重要です。機能的定義と物理的定義のバランス、企業ドメインと事業ドメインの整合性を保ちながら、環境変化に柔軟に対応することが求められます。

### 今後のトレンド
1. **デジタル変革の加速**: AIやIoTなどの技術革新によるドメイン再定義の必要性
2. **サステナビリティ**: SDGsを踏まえた社会的価値を含むドメイン設定
3. **エコシステム型事業**: 単独企業から企業間連携を前提としたドメイン設定
4. **顧客体験中心**: 製品・サービスから顧客体験全体へのドメイン拡張

- D) ビジョン（Vision）、ミッション（Mission）、バリュー（Value）

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
事業ドメインは、エイベルの三次元事業定義に基づき、顧客層（WHO：誰に）、顧客ニーズ（WHAT：何を）、技術（HOW：どのように）の3つの要素で構成されます。<br>

Dが間違いの理由：経営理念の要素であり、ドメインの構成要素ではない

### 問題3
物理的定義の最大のリスクは何か。

- A) 定義が曖昧になりやすい
- B) 組織の理解が困難になる
- C) 環境変化への対応が遅れやすい
- D) 経営資源が分散しやすい

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
物理的定義は製品や技術を中心とした具体的な定義のため、技術革新や市場環境の変化により、定義した製品・技術が陳腐化した際に、新たな事業領域への転換が困難になるリスクがあります。<br>
<br>
Aが間違いの理由：定義が曖昧になりやすいのは機能的定義のリスク<br>
Bが間違いの理由：物理的定義はむしろ理解しやすい<br>
Dが間違いの理由：経営資源が分散しやすいのは機能的定義のリスク
</details>

### 問題4
企業ドメインと事業ドメインの関係について、正しい説明はどれか。

- A) 企業ドメインと事業ドメインは完全に独立している
- B) 事業ドメインは企業ドメインと整合性を保つ必要がある
- C) 企業ドメインは事業ドメインの単純な合計である
- D) 事業ドメインが先に決まり、後から企業ドメインが決まる

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
事業ドメインは企業ドメインの枠組みの中で設定され、両者は整合性を保つ必要があります。企業ドメインが全社的な方向性を示し、個別の事業ドメインはその範囲内で具体的な事業展開を規定します。<br>
<br>
Aが間違いの理由：両者は密接に関連しており、独立していない<br>
Cが間違いの理由：企業ドメインは単純な合計以上の全社的視点を含む<br>
Dが間違いの理由：通常は企業ドメインが先に設定される
</details>

### 問題6
ドメインの設定において「広すぎる」場合の主なリスクは何か。

- A) 市場機会を逃す
- B) 経営資源が分散し競争優位を失う
- C) 組織が硬直化する
- D) イノベーションが起きにくくなる

<summary>解答</summary>
<strong>正解: B</strong><br>

## 10. 専門用語集

### あ行

**イノベーション**
- **読み方**: いのべーしょん
- **意味**: 新しい技術や アイデアを用いて新たな価値を創造し、社会や市場に変革をもたらすこと
- **関連用語**: 破壊的イノベーション、持続的イノベーション

**エコシステム**
- **読み方**: えこしすてむ
- **意味**: 複数の企業や組織が相互に連携し、共生関係を構築しながら価値を創造するビジネスの仕組み
- **関連用語**: プラットフォーム、ビジネスエコシステム

### か行

**企業ドメイン**
- **読み方**: きぎょうどめいん
- **意味**: 企業全体としての活動領域や存在意義を示す概念。長期的視点で企業の方向性を規定する
- **関連用語**: 事業ドメイン、経営理念、ビジョン

**機能的定義**
- **読み方**: きのうてきていぎ
- **意味**: 企業が顧客に提供する価値や機能を中心に事業領域を定義する方法
- **関連用語**: 物理的定義、顧客価値、事業定義

**競争優位**
- **読み方**: きょうそうゆうい
- **意味**: 競合他社と比較して優れた地位を築き、高い収益性や市場シェアを維持できる状態
- **関連用語**: 差別化、コスト優位、持続的競争優位

**経営資源**
- **読み方**: けいえいしげん
- **意味**: 企業が事業活動を行うために必要な人材、資金、技術、情報、ブランドなどの資源
- **関連用語**: 経営資源配分、資源ベース理論

**コアコンピタンス**
- **読み方**: こあこんぴたんす
- **意味**: 企業が持つ中核的な能力や強みで、競争優位の源泉となる独自の技術やノウハウ
- **関連用語**: ケイパビリティ、組織能力

### さ行

**事業ドメイン**
- **読み方**: じぎょうどめいん
- **意味**: 個別事業や事業部門レベルでの活動領域を示す概念。中期的視点で事業の競争領域を規定する
- **関連用語**: 企業ドメイン、事業定義、SBU

**シナジー効果**
- **読み方**: しなじーこうか
- **意味**: 複数の事業や要素が組み合わさることで、個別の総和以上の価値を生み出す相乗効果
- **関連用語**: 範囲の経済、事業間連携

**持続的成長**
- **読み方**: じぞくてきせいちょう
- **意味**: 短期的な利益追求ではなく、長期にわたって安定的に成長を続けること
- **関連用語**: サステナビリティ、長期経営

### た行

**多角化**
- **読み方**: たかくか
- **意味**: 企業が新しい事業分野に進出し、事業の範囲を拡大する戦略
- **関連用語**: 関連多角化、非関連多角化、事業ポートフォリオ

**デジタル変革（DX）**
- **読み方**: でじたるへんかく
- **意味**: デジタル技術を活用してビジネスモデルや組織、企業文化を変革すること
- **関連用語**: デジタルトランスフォーメーション、IT活用

### は行

**物理的定義**
- **読み方**: ぶつりてきていぎ
- **意味**: 企業が扱う製品やサービス、技術を中心に事業領域を定義する方法
- **関連用語**: 機能的定義、製品志向、技術志向

**プラットフォーム**
- **読み方**: ぷらっとふぉーむ
- **意味**: 複数の利用者や事業者が相互に価値を交換できる基盤となるビジネスモデル
- **関連用語**: エコシステム、ネットワーク効果

### ま行

**ミッション**
- **読み方**: みっしょん
- **意味**: 企業の存在意義や社会的使命を表す基本的な理念
- **関連用語**: ビジョン、経営理念、企業ドメイン

### ら行

**リソース**
- **読み方**: りそーす
- **意味**: 企業が利用できる経営資源全般を指す用語
- **関連用語**: 経営資源、アセット、ケイパビリティ

### アルファベット

**MaaS (Mobility as a Service)**

- **意味**: 様々な交通手段を統合して一つのサービスとして提供する新しいモビリティの概念
- **関連用語**: サービス化、モビリティ

**SDGs (Sustainable Development Goals)**
- **読み方**: えすでぃーじーず

- **関連用語**: サステナビリティ、CSR、ESG

**SWOT分析**
- **読み方**: すうぉっとぶんせき

- **関連用語**: 環境分析、戦略立案
