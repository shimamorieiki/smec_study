# 男女雇用機会均等法について

## 概要

男女雇用機会均等法（正式名称：雇用の分野における男女の均等な機会及び待遇の確保等に関する法律）は、1985年に制定され、1986年4月1日から施行された日本の労働法規です。職場における男女差別の禁止と、男女が均等に能力を発揮できる雇用環境の整備を目的としています。

制定当初は努力義務規定が中心でしたが、1997年、2006年、2016年の大幅な改正を経て、現在では募集・採用から退職に至るまでの雇用管理全般において、性別を理由とする差別的取扱いを禁止する強行法規となっています。また、セクシュアルハラスメント対策やマタニティハラスメント対策の義務化など、職場環境の整備に関する規定も充実しています。

## 1. 基本概念・定義

### 男女雇用機会均等法の目的
- **定義**: 雇用の分野における男女の均等な機会及び待遇の確保を図るとともに、女性労働者の就業に関して妊娠中及び出産後の健康の確保を図る等の措置を推進すること
- **特徴**: 
  - 直接差別の禁止（性別を理由とする差別的取扱いの禁止）
  - 間接差別の禁止（性別以外の事由を要件としているが、実質的に性別を理由とする差別となるおそれがある措置の禁止）
  - ポジティブ・アクションの推進
- **重要性**: 労働者の能力を性別にかかわらず発揮できる環境整備により、企業の競争力向上と社会全体の活力向上に寄与

### 直接差別と間接差別
- **直接差別の定義**: 性別を理由として差別的取扱いをすること
- **間接差別の定義**: 性別以外の事由を要件とする措置であって、他の性の構成員と比較して、一方の性の構成員に相当程度の不利益を与えるもの
- **重要性**: 形式的な平等だけでなく、実質的な平等の確保を目指す

## 2. 禁止される差別の種類

### 雇用管理の各段階における差別禁止
男女雇用機会均等法では、雇用管理の全段階において性別を理由とする差別的取扱いを禁止しています。

### 募集・採用における差別禁止（第5条）
| 項目 | 内容 |
|------|------|
| 特徴 | 労働者の募集及び採用について、性別にかかわりなく均等な機会を与えなければならない |
| 適用範囲 | すべての事業主（規模・業種を問わない） |
| 注意点 | 「男性のみ」「女性のみ」といった性別を限定した募集は原則禁止 |

### 配置・昇進・降格・教育訓練における差別禁止（第6条）
| 項目 | 内容 |
|------|------|
| 特徴 | 配置、昇進、降格、教育訓練、福利厚生、職種・雇用形態の変更、退職勧奨、定年、解雇、労働契約の更新について性別を理由とする差別的取扱いを禁止 |
| 適用範囲 | 雇用管理のあらゆる段階 |
| 注意点 | 「総合職は男性のみ」「一般職は女性のみ」といった運用は違法 |

### 間接差別の禁止（第7条）
| 項目 | 内容 |
|------|------|
| 特徴 | 厚生労働省令で定める3つの措置について、合理的な理由がない場合は間接差別として禁止 |
| 適用範囲 | ①身長・体重・体力要件、②転勤要件、③転勤経験要件 |
| 注意点 | 業務遂行上の必要性など合理的な理由の立証責任は事業主側にある |

## 3. 具体的な違反事例と適法事例

### ケース1: 募集・採用における事例

#### パターンA: 違法な募集例
- **前提条件**: 一般事務職の募集において「女性限定」と明記
- **判断**: 男女雇用機会均等法第5条違反
- **結果**: 行政指導の対象となり、是正が必要

#### パターンB: 適法な募集例  
- **前提条件**: 女性の採用が男性と比較して相当程度少ない職種において、女性に有利な取扱いをする
- **判断**: ポジティブ・アクション（第8条）として適法
- **結果**: 男女間格差の改善に向けた積極的改善措置として認められる

### ケース2: 配置・昇進における事例

#### パターンA: 違法な配置例
- **前提条件**: 営業職への配置を男性社員に限定し、女性社員は事務職のみに配置
- **判断**: 男女雇用機会均等法第6条違反
- **結果**: 配置基準の見直しと、既存女性社員への営業職転換機会の提供が必要

#### パターンB: 間接差別となる昇進要件
- **前提条件**: 管理職昇進の要件として「全国転勤が可能であること」を設定
- **判断**: 合理的理由がない場合は第7条違反（間接差別）
- **結果**: 業務上の必要性を検証し、必要最小限の要件に見直すことが必要

### ケース3: 妊娠・出産を理由とする不利益取扱い

#### 違法な取扱い例
- **前提条件**: 妊娠を報告した女性社員を正社員から契約社員に変更
- **判断**: 男女雇用機会均等法第9条違反（妊娠・出産等を理由とする不利益取扱いの禁止）
- **結果**: 原職復帰と損害賠償請求の可能性

## 4. 事業主の義務と手続き

### セクシュアルハラスメント対策の義務（第11条）
1. **事業主の方針の明確化及びその周知・啓発**
   - セクハラ防止方針の明文化
   - 就業規則等への記載
   - 研修・講習等の実施

2. **相談体制の整備**
   - 相談窓口の設置
   - 相談担当者の配置
   - 外部機関の活用も可

3. **事後の迅速かつ適切な対応**
   - 事実関係の迅速・正確な確認
   - 被害者への配慮措置
   - 行為者への適正な措置
   - 再発防止措置

### マタニティハラスメント対策の義務（第11条の3）
- **根拠法令**: 2016年改正により新設
- **対象事項**: 妊娠・出産・育児休業等に関するハラスメント防止措置
- **必要な措置**: セクハラ対策と同様の体制整備

### 紛争解決の手続き
1. **企業内での自主的解決**（第15条）
   - 苦情処理機関の活用
   - 労使協議による解決

2. **都道府県労働局長による援助**（第17条）
   - 助言・指導・勧告
   - 無料・迅速な解決支援

3. **調停**（第18条～第27条）
   - 紛争調整委員会による調停
   - 当事者双方の同意が必要
   - 調停案の提示

## 6. よくある質問（Q&A）

### Q1. 女性だけに結婚退職制度を設けることは可能ですか？

**A1.** 違法です。男女雇用機会均等法第6条により禁止されています。

#### 詳細説明
結婚を理由とする退職制度を女性のみに適用することは、性別を理由とする差別的取扱いに該当します。過去には慣行として存在しましたが、現在では明確に違法とされています。男女問わず適用される制度であっても、実質的に女性のみが退職を余儀なくされる運用は違法となる可能性があります。

### Q2. 重量物を扱う業務に女性を配置しないことは差別になりますか？

**A2.** 原則として差別になりますが、労働基準法の母性保護規定に該当する場合は例外となります。

#### 詳細説明
労働基準法第64条の3では、妊産婦等に対する危険有害業務の就業制限が定められています。しかし、妊娠していない女性一般に対して一律に重量物取扱い業務から排除することは、男女雇用機会均等法違反となります。個人の能力や希望を考慮せず、性別のみを理由に配置を制限することは認められません。

### Q3. ポジティブ・アクションとして女性を優遇することはどこまで許されますか？

**A3.** 男女間に事実上の格差が存在する場合に、その格差解消のために必要な範囲で認められます。

#### 詳細説明
男女雇用機会均等法第8条及び第14条により、以下の条件下でポジティブ・アクションが認められます：
- 雇用の分野における男女間の事実上の格差が存在すること
- 格差解消のために必要な措置であること
- 合理的な範囲内であること
例えば、女性管理職比率が極端に低い企業において、女性向けの管理職育成研修を実施することは適法です。

### Q4. セクハラの相談を受けた場合、どのように対応すべきですか？

**A4.** 事業主には迅速かつ適切な対応義務があり、以下の手順で対応する必要があります。

#### 詳細説明
1. **相談者への配慮**: プライバシー保護、不利益取扱いの禁止
2. **事実確認**: 相談者、行為者、第三者からの聴取
3. **暫定措置**: 必要に応じて配置転換等の措置
4. **事実認定と対応**: 
   - セクハラと認定された場合：行為者への処分、被害者への配慮措置
   - 認定されない場合：関係改善のための措置
5. **再発防止**: 研修実施、規程見直し等

## 7. 今後の展望

男女雇用機会均等法は、社会情勢の変化に応じて進化を続けています。今後は以下の点が重要になると考えられます：

- **多様性の推進**: 性別だけでなく、LGBTQを含む性的マイノリティへの配慮
- **働き方改革との連動**: テレワーク、フレックスタイム等の活用による実質的平等の推進
- **国際的基準への対応**: ILO条約等の国際基準に沿った法整備
- **無意識の偏見（アンコンシャス・バイアス）への対応**: より深層的な差別の解消
- **男性の育児参加促進**: 男女共同参画社会の実現に向けた施策の充実
