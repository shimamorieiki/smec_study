# スリーサークルモデルについて

## 概要

スリーサークルモデル（Three Circle Model）は、ハーバード大学のジョン・デイビス教授とレナート・タジウリ教授によって1982年に開発された、ファミリービジネス（同族経営企業）の複雑性を理解するための分析フレームワークです。このモデルは、ファミリービジネスに関わる3つの主要なシステム（家族・所有・経営）の相互関係を視覚的に表現し、それぞれの立場から生じる利害関係や課題を明確にすることを目的としています。

## 1. 基本概念・定義

### スリーサークルモデルの構成要素

スリーサークルモデルは、以下の3つの円（サブシステム）で構成されています：

#### 1. ファミリー（家族）
- **定義**: 創業家および血縁・婚姻関係にある家族メンバー
- **特徴**: 感情的な結びつき、長期的な関係性、家族の価値観や伝統
- **重要性**: ファミリービジネスの文化的基盤と継続性を提供

#### 2. ビジネス（経営）
- **定義**: 企業の日常的な経営活動と管理機能
- **特徴**: 効率性、収益性、競争力、成長戦略
- **重要性**: 企業の存続と発展に直接的に関わる

#### 3. オーナーシップ（所有）
- **定義**: 企業の株式所有と支配権
- **特徴**: 議決権、配当受領権、企業価値の享受
- **重要性**: 企業の方向性と重要な意思決定を左右

## 2. 7つのセクター（領域）

3つの円が重なり合うことで、7つの異なるセクターが形成されます：

### セクター1: 家族メンバーのみ
| 項目 | 内容 |
|------|------|
| 立場 | 家族の一員だが、経営にも所有にも関与していない |
| 特徴 | 家族の価値観を共有するが、ビジネスには直接関わらない |
| 関心事 | 家族の調和、家族の評判、将来の雇用機会 |
| 課題 | ビジネスの情報から疎外される可能性、期待と現実のギャップ |

### セクター2: 従業員のみ
| 項目 | 内容 |
|------|------|
| 立場 | 企業で働いているが、家族でも株主でもない |
| 特徴 | 専門的スキルを持つ外部人材 |
| 関心事 | 雇用の安定、キャリア発展、公平な処遇 |
| 課題 | 家族優先の人事に対する不満、昇進機会の制限 |

### セクター3: 株主のみ
| 項目 | 内容 |
|------|------|
| 立場 | 株式を所有しているが、家族でも従業員でもない |
| 特徴 | 純粋な投資家としての立場 |
| 関心事 | 投資収益率、配当、企業価値の向上 |
| 課題 | 経営への影響力の限界、情報の非対称性 |

### セクター4: 家族従業員
| 項目 | 内容 |
|------|------|
| 立場 | 家族メンバーであり、企業で働いているが株式は持たない |
| 特徴 | 家族の一員として企業に貢献 |
| 関心事 | 職務上の成功、家族内での立場、将来の所有権 |
| 課題 | 能力と期待のバランス、家族と仕事の境界線 |

### セクター5: オーナー家族
| 項目 | 内容 |
|------|------|
| 立場 | 家族メンバーであり株主だが、経営には関与しない |
| 特徴 | 所有権を通じて企業に関与 |
| 関心事 | 企業価値の保全、配当収入、家族の影響力維持 |
| 課題 | 経営への介入の程度、情報収集の必要性 |

### セクター6: オーナー従業員
| 項目 | 内容 |
|------|------|
| 立場 | 株主であり従業員だが、家族ではない |
| 特徴 | 従業員持株会やストックオプションを通じた所有 |
| 関心事 | 企業業績、雇用安定、株式価値 |
| 課題 | 家族との力関係、意思決定への参画度 |

### セクター7: オーナー経営者（中心部）
| 項目 | 内容 |
|------|------|
| 立場 | 家族メンバーであり、株主であり、経営に従事 |
| 特徴 | 3つすべての立場を持つ最も複雑なポジション |
| 関心事 | すべての利害関係のバランス、承継計画、企業の長期的成功 |
| 課題 | 役割の衝突、過度の責任、客観的判断の困難さ |

## 3. 具体的な活用事例

### ケース1: 創業家2代目の承継問題

#### 状況設定
創業者（65歳）が引退を考えており、3人の子供（長男：40歳・営業部長、長女：38歳・非従業員、次男：35歳・外部企業勤務）がいる。株式は創業者が60%、妻が20%、長男が20%を保有。

#### パターンA: 長男への単独承継
- **前提条件**: 長男がセクター7（オーナー経営者）の立場
- **分析過程**: 
  - 長男：既に経営と所有に関与、スムーズな移行が期待
  - 長女：セクター5（オーナー家族）として配当を期待
  - 次男：セクター1（家族のみ）から疎外感を感じる可能性
- **結果**: 家族間の公平性と事業の継続性のバランスが課題

#### パターンB: 3人での共同経営
- **前提条件**: 全員を経営に参加させる
- **分析過程**:
  - 長女・次男をセクター4（家族従業員）に移行
  - 株式も均等に分配し、全員をセクター7に
  - 意思決定の複雑化、役割分担の明確化が必要
- **結果**: 公平性は保たれるが、経営効率が低下するリスク

### ケース2: 外部人材の登用と既存家族従業員との調整

#### 状況設定
業績拡大により専門的な CFO が必要となり、外部から採用を検討。現在、創業者の弟が財務担当役員。

#### 分析
- **創業者の弟**: セクター7からセクター5への移行を提案
- **新CFO**: セクター2（従業員のみ）として採用、将来的にセクター6も検討
- **調整ポイント**: 役職、報酬、権限の明確化
- **解決策**: 創業者の弟を会長職に、新CFOに実務権限を委譲

## 4. モデルの実践的活用方法

### ステップ1: 現状分析
1. **関係者のマッピング**
   - すべての利害関係者をリストアップ
   - 各人が属するセクターを特定
   - 人数の偏りや空白セクターを確認

2. **利害関係の整理**
   - 各セクターの期待と要求を明文化
   - 潜在的な対立点を事前に把握
   - 優先順位の設定

### ステップ2: 課題の特定
1. **役割の衝突**
   - 特にセクター7の人物の負担を評価
   - 家族としての愛情vs経営者としての合理性
   - 所有者としての権利vs従業員としての義務

2. **コミュニケーションの断絶**
   - セクター間の情報共有不足
   - 意思決定プロセスの不透明性
   - 期待値のズレ

### ステップ3: 解決策の立案
1. **ガバナンス体制の構築**
   - 家族会議の定期開催
   - 取締役会の機能強化
   - 株主総会の活性化

2. **役割と責任の明確化**
   - 職務記述書の作成
   - 権限規程の整備
   - 評価基準の設定

### ステップ4: 実行とモニタリング
1. **段階的な実施**
   - 小さな変更から始める
   - 関係者の反応を観察
   - 必要に応じて修正

2. **定期的な見直し**
   - 年次でのモデル再評価
   - 新たな課題の発見
   - 継続的な改善

## 5. 実務上の注意点

### 感情面への配慮
- **ポイント1**: ビジネスの論理だけでなく、家族の感情も重視する
- **ポイント2**: 変化に対する抵抗を予測し、十分な説明時間を設ける
- **ポイント3**: 外部のファシリテーターやコンサルタントの活用を検討

### 公平性と透明性
- **ポイント1**: 意思決定プロセスを明確にし、全関係者に共有
- **ポイント2**: 評価基準を客観的に設定し、恣意性を排除
- **ポイント3**: 情報開示のルールを定め、情報格差を最小化

### 長期的視点
- **ポイント1**: 短期的な利益より、世代を超えた企業の持続性を重視
- **ポイント2**: 後継者育成計画を早期に策定
- **ポイント3**: 企業文化と家族の価値観の調和を図る

### よくある誤解・トラブル
- **誤解1**: 「家族だから話し合わなくても分かり合える」→ 明確なコミュニケーションが不可欠
- **誤解2**: 「能力があれば外部人材でも受け入れられる」→ 家族の感情的な抵抗を過小評価しない
- **誤解3**: 「株式を均等に分ければ公平」→ 経営への関与度に応じた配分も検討すべき

## 6. よくある質問（Q&A）

### Q1. スリーサークルモデルは大企業のファミリービジネスにしか適用できないのでしょうか？

**A1.** いいえ、企業規模に関わらず適用可能です。

#### 詳細説明
スリーサークルモデルは、従業員数名の小規模事業から、グローバル企業まで幅広く活用できます。小規模企業では、一人が複数の役割を担うことが多く、むしろモデルの重要性が高まります。例えば、夫婦で経営する飲食店では、両者ともセクター7に属し、役割の衝突が起きやすいため、モデルを使った分析が有効です。

### Q2. 家族でない従業員を経営陣に加える際、どのような点に注意すべきですか？

**A2.** 役割・権限・評価基準の明確化と、家族メンバーとの関係構築が重要です。

#### 詳細説明
外部人材（セクター2）を経営陣に登用する際は、以下の手順を推奨します：

1. **準備段階**
   - 家族メンバーへの事前説明と合意形成
   - 明確な職務記述書の作成
   - 報酬体系の透明化

2. **導入段階**
   - 段階的な権限委譲
   - メンター制度の活用
   - 定期的な面談実施

3. **定着段階**
   - 成果の可視化
   - 家族行事への適切な参加
   - 将来的な株式付与の検討（セクター6への移行）

### Q3. 相続で株式が分散した場合、どのように経営の一体性を保てばよいでしょうか？

**A3.** 株主間協定の締結と、議決権の集約メカニズムの構築が有効です。

#### 詳細説明
株式が複数の家族メンバー（セクター3、5、7）に分散した場合の対策：

1. **株主間協定**
   - 株式の譲渡制限条項
   - 先買権の設定
   - 議決権行使の事前協議義務

2. **持株会社の活用**
   - 家族持株会社による間接保有
   - 議決権の一元化
   - 配当政策の調整

3. **種類株式の発行**
   - 議決権制限株式の活用
   - 黄金株の設定
   - 段階的な承継計画

## 7. まとめ・今後の展望

スリーサークルモデルは、ファミリービジネスの複雑な人間関係と利害関係を整理し、持続的な成長を実現するための強力なツールです。このモデルを活用することで、感情的な対立を予防し、合理的な意思決定を促進できます。

今後、日本においても事業承継問題がさらに深刻化する中、スリーサークルモデルの重要性は増していくでしょう。特に、デジタル化やグローバル化が進む中で、伝統的な家族経営と現代的な経営手法の融合が求められています。外部人材の活用、プロフェッショナル経営への移行、そして家族の価値観の継承という、一見相反する要素をバランスよく実現することが、ファミリービジネスの成功の鍵となります。

## 8. 理解度確認クイズ（4択問題20問）

### 問題1
スリーサークルモデルを構成する3つの円（サブシステム）として正しい組み合わせはどれか？

- A) 家族・従業員・顧客
- B) 家族・経営・所有
- C) 経営・財務・人事  
- D) 株主・債権者・従業員

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
スリーサークルモデルは、ファミリー（家族）、ビジネス（経営）、オーナーシップ（所有）の3つの円で構成されています。<br>
<br>
Aが間違いの理由：顧客は利害関係者ですが、モデルの基本構成要素ではありません<br>
Cが間違いの理由：これらは経営の機能別分類であり、ファミリービジネスの構造分析には適しません<br>
Dが間違いの理由：これは一般的な企業の利害関係者分類であり、ファミリービジネス特有の視点が欠けています
</details>

### 問題2
スリーサークルモデルにおいて、3つの円が重なり合うことで生まれるセクター（領域）の数はいくつか？

- A) 3つ
- B) 5つ
- C) 7つ
- D) 9つ

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
3つの円が重なり合うことで、7つの異なるセクターが形成されます。各円の独立部分が3つ、2つずつの重なりが3つ、3つすべての重なりが1つで、合計7つです。<br>
<br>
Aが間違いの理由：3つは円の数であり、セクターの数ではありません<br>
Bが間違いの理由：重なり部分を正しく数えていません<br>
Dが間違いの理由：数学的に3つの円の重なりで生じる領域は最大7つです
</details>

### 問題3
創業者の息子が、株式を保有し、かつ取締役として経営に参加している場合、どのセクターに属するか？

- A) セクター4（家族従業員）
- B) セクター5（オーナー家族）
- C) セクター6（オーナー従業員）
- D) セクター7（オーナー経営者）

<details>
<summary>解答</summary>
<strong>正解: D</strong><br>
家族メンバーであり、株主であり、経営に従事している場合は、3つすべての円が重なる中心部のセクター7（オーナー経営者）に属します。<br>
<br>
Aが間違いの理由：家族従業員は株式を保有していない家族メンバーです<br>
Bが間違いの理由：オーナー家族は経営に関与していない株主家族です<br>
Cが間違いの理由：オーナー従業員は家族ではない株主従業員です
</details>

Cが間違いの理由：株式を保有していないと明記されています<br>

</details>

創業者の配偶者が株式の一部を保有しているが、経営には一切関与していない場合、どのセクターに属するか？

### 問題7
ファミリービジネスにおいて、セクター7（オーナー経営者）の人物が直面する最も大きな課題は何か？

- A) 資金調達の困難さ
- B) 役割の衝突と過度の責任
- C) 技術革新への対応
- D) 人材採用の困難さ

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
セクター7の人物は、家族・株主・経営者という3つの立場を同時に持つため、それぞれの役割間での衝突や、すべての利害関係のバランスを取る過度の責任が最大の課題となります。<br>
<br>
Aが間違いの理由：資金調達は一般的な経営課題であり、セクター7特有の課題ではありません<br>
Cが間違いの理由：技術革新は業界共通の課題であり、立場の複雑さとは関係ありません<br>
Dが間違いの理由：人材採用も一般的な課題であり、役割の衝突という本質的な問題ではありません
</details>

### 問題8
スリーサークルモデルを活用する際の最初のステップは何か？

- A) 解決策の立案
- B) 関係者のマッピングと各人のセクター特定
- C) 外部コンサルタントの採用
- D) 株式の再配分

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
モデル活用の第一歩は、すべての利害関係者をリストアップし、各人がどのセクターに属するかを特定する現状分析です。<br>
<br>
Aが間違いの理由：現状を把握する前に解決策を立案することはできません<br>
Cが間違いの理由：外部支援の必要性は、まず内部分析を行ってから判断します<br>
Dが間違いの理由：株式再配分は、問題分析後の解決策の一つに過ぎません
</details>

### 問題9
家族会議、取締役会、株主総会をそれぞれ設置・活性化することは、スリーサークルモデルのどの側面に対応しているか？

- A) コスト削減
- B) ガバナンス体制の構築
- C) 市場競争力の強化
- D) 技術革新の促進

<details>

## 9. 専門用語集

### アルファベット

**CEO (Chief Executive Officer)**
- **読み方**: シーイーオー
- **意味**: 最高経営責任者。企業の経営方針や戦略を決定し、執行する最高位の役職
- **関連用語**: 取締役、社長、代表取締役

**CFO (Chief Financial Officer)**
- **読み方**: シーエフオー
- **意味**: 最高財務責任者。企業の財務戦略の立案と執行を統括する役職
- **関連用語**: 財務担当役員、経理部長

### あ行

**オーナーシップ**
- **読み方**: おーなーしっぷ
- **意味**: 企業の所有権。株式保有を通じた企業支配と、それに伴う権利と責任
- **関連用語**: 株主、所有と経営の分離

**オーナー経営者**
- **読み方**: おーなーけいえいしゃ
- **意味**: 企業の所有者であると同時に経営者でもある人物。ファミリービジネスでは家族メンバーであることも多い
- **関連用語**: 創業者、同族経営者

### か行

**家族会議**
- **読み方**: かぞくかいぎ
- **意味**: ファミリービジネスにおいて、家族メンバーが企業経営について話し合う公式・非公式の会合
- **関連用語**: ファミリーカウンシル、家族憲章

**株主間協定**
- **読み方**: かぶぬしかんきょうてい
- **意味**: 株主同士で締結する、株式の譲渡制限や議決権行使に関する取り決め
- **関連用語**: 株式譲渡制限、先買権

**ガバナンス**
- **読み方**: がばなんす
- **意味**: 企業統治。企業が適切に運営されるための仕組みや体制
- **関連用語**: コーポレート・ガバナンス、内部統制

### さ行

**事業承継**
- **読み方**: じぎょうしょうけい
- **意味**: 現経営者から後継者へ事業を引き継ぐこと。経営権、所有権、理念の承継を含む
- **関連用語**: 後継者育成、世代交代

**種類株式**
- **読み方**: しゅるいかぶしき
- **意味**: 通常の株式とは異なる権利内容を持つ株式。議決権制限株式や優先配当株式など
- **関連用語**: 普通株式、議決権制限株式

**ステークホルダー**
- **読み方**: すてーくほるだー
- **意味**: 利害関係者。企業活動に影響を与え、または影響を受ける個人や組織
- **関連用語**: 利害関係者、株主、従業員

**スリーサークルモデル**
- **読み方**: すりーさーくるもでる
- **意味**: ファミリービジネスの構造を家族・経営・所有の3つの円で表現した分析モデル
- **関連用語**: ファミリービジネス、同族経営

### た行

**同族経営**
- **読み方**: どうぞくけいえい
- **意味**: 創業家や特定の家族が企業の所有と経営を支配している経営形態
- **関連用語**: ファミリービジネス、オーナー企業

### は行

**ファミリービジネス**
- **読み方**: ふぁみりーびじねす
- **意味**: 家族が所有し、経営に関与している企業。世界の企業の多数を占める
- **関連用語**: 同族経営、家族経営

**プロフェッショナル経営**
- **読み方**: ぷろふぇっしょなるけいえい
- **意味**: 専門的な知識と経験を持つ職業経営者による企業経営
- **関連用語**: 所有と経営の分離、職業経営者

### ま行

**持株会社**
- **読み方**: もちかぶがいしゃ
- **意味**: 他の会社の株式を保有し、その会社を支配することを主な事業とする会社
- **関連用語**: ホールディングカンパニー、親会社

### や行

**役割の衝突**
- **読み方**: やくわりのしょうとつ
- **意味**: 一人の人物が複数の立場を持つことで生じる、相反する期待や要求の対立
- **関連用語**: 利益相反、ロールコンフリクト

### ら行

**利害関係者**
- **読み方**: りがいかんけいしゃ
- **意味**: 企業活動に利害関係を持つ個人や組織。株主、従業員、顧客、地域社会など
- **関連用語**: ステークホルダー、利害関係者理論
