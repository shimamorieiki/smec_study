# ISO26000について

## 概要

ISO26000は、2010年11月に発行された国際標準化機構（ISO）による社会的責任（Social Responsibility）に関する国際規格です。この規格は、組織の社会的責任に関する世界初の包括的な国際ガイダンス文書として、あらゆる種類・規模の組織が社会的責任を理解し、実践するための手引きを提供しています。

従来の認証規格とは異なり、ISO26000は第三者認証を目的としない「ガイダンス規格」という位置づけで、組織が自主的に社会的責任を果たすための原則と実践方法を示しています。持続可能な発展への貢献を目指す組織にとって、重要な指針となる規格です。

## 1. 基本概念・定義

### 社会的責任（Social Responsibility）
- **定義**: 組織の決定及び活動が社会及び環境に及ぼす影響に対して、透明かつ倫理的な行動を通じて組織が担う責任
- **特徴**: 
  - ステークホルダーの期待に配慮する
  - 適用される法令を遵守し、国際行動規範と整合する
  - 組織全体で統合され、組織の関係の中で実践される
- **重要性**: 持続可能な発展への貢献、組織の長期的な成功、社会からの信頼獲得

### ステークホルダー（Stakeholder）
- **定義**: 組織の何らかの決定又は活動に利害関係をもつ個人又はグループ
- **特徴**: 
  - 内部ステークホルダー（従業員、株主等）
  - 外部ステークホルダー（顧客、取引先、地域社会、NGO等）
  - 将来世代も含まれる
- **重要性**: 組織の社会的責任を果たす上で、その期待と関心の理解が不可欠

### 持続可能な発展（Sustainable Development）
- **定義**: 将来の世代の人々が自らのニーズを満たす能力を危険にさらすことなく、現在のニーズを満たす発展
- **特徴**: 
  - 経済的側面、社会的側面、環境的側面の統合
  - 長期的視点での意思決定
  - 世代間の公平性の確保
- **重要性**: 組織の社会的責任の最終目標

## 2. 7つの原則

### ISO26000の社会的責任の原則
ISO26000では、社会的責任を実践する上で尊重すべき7つの原則を定めています。

### 原則1: 説明責任（Accountability）
| 項目 | 内容 |
|------|------|
| 定義 | 組織は、自らの決定及び活動によって社会、経済及び環境に与える影響について説明責任を負うべきである |
| 実践方法 | 定期的な報告書の発行、情報開示、監査の実施 |
| 具体例 | CSR報告書、統合報告書の発行、第三者検証の実施 |

### 原則2: 透明性（Transparency）
| 項目 | 内容 |
|------|------|
| 定義 | 組織は、社会及び環境に影響を与える自らの決定及び活動について透明であるべきである |
| 実践方法 | 積極的な情報公開、ステークホルダーとの対話 |
| 具体例 | ウェブサイトでの情報公開、説明会の開催、問い合わせ窓口の設置 |

### 原則3: 倫理的な行動（Ethical behavior）
| 項目 | 内容 |
|------|------|
| 定義 | 組織は、倫理的に行動すべきである |
| 実践方法 | 倫理規程の策定、コンプライアンス体制の構築、倫理研修の実施 |
| 具体例 | 企業行動憲章の制定、内部通報制度の整備、倫理委員会の設置 |

### 原則4: ステークホルダーの利害の尊重（Respect for stakeholder interests）
| 項目 | 内容 |
|------|------|
| 定義 | 組織は、自らのステークホルダーの利害を尊重し、配慮し、対応すべきである |
| 実践方法 | ステークホルダー・エンゲージメント、対話の場の設定 |
| 具体例 | ステークホルダー・ダイアログ、アンケート調査、諮問委員会の設置 |

### 原則5: 法の支配の尊重（Respect for the rule of law）
| 項目 | 内容 |
|------|------|
| 定義 | 組織は、法の支配を尊重することが義務であることを受け入れるべきである |
| 実践方法 | 法令遵守体制の整備、法務部門の強化、定期的な法令チェック |
| 具体例 | コンプライアンス・マニュアルの作成、法令研修の実施、監査の実施 |

### 原則6: 国際行動規範の尊重（Respect for international norms of behavior）
| 項目 | 内容 |
|------|------|
| 定義 | 組織は、法の支配の尊重という原則に従うと同時に、国際行動規範も尊重すべきである |
| 実践方法 | 国際条約・宣言の理解と実践、グローバル・スタンダードの採用 |
| 具体例 | 国連グローバル・コンパクトへの参加、OECD多国籍企業行動指針の遵守 |

### 原則7: 人権の尊重（Respect for human rights）
| 項目 | 内容 |
|------|------|
| 定義 | 組織は、人権を尊重し、その重要性及び普遍性の両方を認識すべきである |
| 実践方法 | 人権方針の策定、人権デュー・ディリジェンスの実施 |
| 具体例 | 人権方針の公表、サプライチェーンの人権リスク評価、救済メカニズムの構築 |

## 3. 7つの中核主題

### 中核主題の概要
ISO26000では、組織が取り組むべき社会的責任の分野として7つの中核主題を定めています。

### 中核主題1: 組織統治（Organizational governance）
**定義**: 組織がその目的を追求する上で、決定を下し、決定事項を実施するためのシステム

**主な課題**:
- 意思決定プロセスと構造
- リーダーシップとコミットメント
- 報酬とインセンティブ
- 資源の効率的利用

**実践例**:
- 取締役会の多様性確保（女性役員比率30%達成）
- CSR委員会の設置と定期開催（四半期ごと）
- 役員報酬とESG指標の連動（ESG目標達成度を報酬の20%に反映）

### 中核主題2: 人権（Human rights）
**定義**: すべての人間が生まれながらにして持つ基本的権利

**主な課題**:
1. デュー・ディリジェンス
2. 人権に関する危機的状況
3. 加担の回避
4. 苦情解決
5. 差別及び社会的弱者
6. 市民的及び政治的権利
7. 経済的、社会的及び文化的権利
8. 労働における基本的原則及び権利

**実践例**:
- サプライチェーン監査の実施（年2回、主要取引先100社対象）
- 人権ホットラインの設置（24時間対応、多言語対応）
- 障害者雇用率の向上（法定雇用率2.3%を上回る3.0%達成）

### 中核主題3: 労働慣行（Labor practices）
**定義**: 組織内及び組織の管理下で行われる労働に関連するすべての方針及び慣行

**主な課題**:
1. 雇用及び雇用関係
2. 労働条件及び社会的保護
3. 社会対話
4. 労働における安全衛生
5. 職場における人材育成及び訓練

**実践例**:
- 働き方改革の推進（月平均残業時間を20時間以下に削減）
- 労働安全衛生マネジメントシステムISO45001の認証取得
- 年間研修予算を売上高の1%確保（一人当たり年間40時間の研修実施）

### 中核主題4: 環境（The environment）
**定義**: 組織の決定及び活動の環境への影響

**主な課題**:
1. 汚染の予防
2. 持続可能な資源の利用
3. 気候変動の緩和及び気候変動への適応
4. 環境保護、生物多様性、及び自然生息地の回復

**実践例**:
- カーボンニュートラル目標の設定（2050年までにScope1-3でネットゼロ）
- 再生可能エネルギー100%達成（2030年目標）
- 水使用量の削減（2025年までに2020年比30%削減）
- 生物多様性保全活動（植林10万本/年）

### 中核主題5: 公正な事業慣行（Fair operating practices）
**定義**: 組織と他の組織との関係における倫理的な行動

**主な課題**:
1. 汚職防止
2. 責任ある政治的関与
3. 公正な競争
4. バリューチェーンにおける社会的責任の推進
5. 財産権の尊重

**実践例**:
- 贈収賄防止方針の策定と全社員研修（年1回実施、受講率100%）
- 政治献金の透明性確保（ウェブサイトで全額開示）
- 独占禁止法研修の実施（営業部門は年2回必須）
- CSR調達方針の策定とサプライヤー評価（年1回実施）

### 中核主題6: 消費者課題（Consumer issues）
**定義**: 製品及びサービスを消費者に提供する際の組織の責任

**主な課題**:
1. 公正なマーケティング、事実に即した偏りのない情報、及び公正な契約慣行
2. 消費者の安全衛生の保護
3. 持続可能な消費
4. 消費者に対するサービス、支援、並びに苦情及び紛争の解決
5. 消費者データ保護及びプライバシー
6. 必要不可欠なサービスへのアクセス
7. 教育及び意識向上

**実践例**:
- 製品安全性テストの強化（第三者機関による検証実施）
- カスタマーサポートセンターの24時間365日対応
- 個人情報保護の国際認証（ISO27001）取得
- ユニバーサルデザイン製品の開発（全製品の50%以上）

### 中核主題7: コミュニティへの参画及びコミュニティの発展（Community involvement and development）
**定義**: コミュニティへの参画及び貢献を通じた、コミュニティの発展への支援

**主な課題**:
1. コミュニティへの参画
2. 教育及び文化
3. 雇用創出及び技能開発
4. 技術の開発及び技術へのアクセス
5. 富及び所得の創出
6. 健康
7. 社会的投資

**実践例**:
- 地域雇用の創出（新規事業所開設時は地元採用率70%以上）
- 教育支援プログラム（年間1,000名の学生にインターンシップ提供）
- 地域NPOとの協働プロジェクト（年間10件以上）
- 社会貢献活動への参加（全社員の参加率80%以上）

## 4. 実施プロセス

### ISO26000導入の5つのステップ

#### ステップ1: 社会的責任の認識
- **目的**: 組織と社会的責任の関係性を理解する
- **実施内容**:
  - 経営層のコミットメント獲得
  - 社会的責任の重要性の理解
  - 組織の特性と社会的責任の関連性分析
- **必要期間**: 1-2ヶ月
- **成果物**: 経営層による社会的責任方針の表明

#### ステップ2: ステークホルダーの特定及びステークホルダー・エンゲージメント
- **目的**: 重要なステークホルダーを特定し、対話を行う
- **実施内容**:
  - ステークホルダー・マッピング
  - 影響度と関心度による優先順位付け
  - エンゲージメント計画の策定
  - 対話の実施
- **必要期間**: 2-3ヶ月
- **成果物**: ステークホルダー・マップ、エンゲージメント報告書

#### ステップ3: 中核主題の検討及び重要課題の特定
- **目的**: 7つの中核主題から自組織の重要課題を特定する
- **実施内容**:
  - 各中核主題の関連性評価
  - マテリアリティ分析の実施
  - 重要課題の優先順位付け
  - KPIの設定
- **必要期間**: 2-3ヶ月
- **成果物**: マテリアリティ・マトリックス、重要課題一覧

#### ステップ4: 社会的責任の組織全体への統合
- **目的**: 特定した重要課題を組織運営に統合する
- **実施内容**:
  - 推進体制の構築
  - 方針・規程の策定
  - 目標・KPIの設定
  - アクションプランの策定
  - 社内教育・研修の実施
- **必要期間**: 3-6ヶ月
- **成果物**: CSR推進体制図、CSR方針、中期CSR計画

#### ステップ5: 実施、コミュニケーション、レビュー及び改善
- **目的**: PDCAサイクルによる継続的改善
- **実施内容**:
  - アクションプランの実行
  - 進捗モニタリング
  - ステークホルダーへの報告
  - 内部監査の実施
  - マネジメントレビュー
- **必要期間**: 継続的実施
- **成果物**: CSR報告書、改善計画書

### デュー・ディリジェンスのプロセス
1. **方針のコミットメント**: 人権方針等の策定と公表
2. **影響の特定と評価**: 負の影響の特定、分析、優先順位付け
3. **適切な措置の実施**: 予防・軽減措置の実行
4. **追跡調査**: 対応の効果測定
5. **情報開示**: ステークホルダーへの報告

## 5. 実務上の注意点

### ISO26000活用の重要ポイント
- **ポイント1**: 認証規格ではないため、自己宣言による適合表明は避ける
- **ポイント2**: 7つの中核主題すべてを検討対象とし、関連性がないと判断する場合はその理由を説明する
- **ポイント3**: ステークホルダー・エンゲージメントを形式的なものにせず、実質的な対話を重視する

### よくある誤解・トラブル
- **誤解1**: 「ISO26000認証取得」という表現
  - 正しい理解: ISO26000は認証規格ではなくガイダンス規格
- **誤解2**: 大企業向けの規格である
  - 正しい理解: あらゆる種類・規模の組織が活用可能
- **誤解3**: CSR部門だけで取り組めばよい
  - 正しい理解: 組織全体での統合的な取り組みが必要

### 他の規格・イニシアチブとの関係
- **ISO14001（環境）**: 中核主題「環境」の実践に活用
- **ISO45001（労働安全衛生）**: 中核主題「労働慣行」の実践に活用
- **ISO9001（品質）**: 中核主題「消費者課題」の実践に活用
- **GRIスタンダード**: CSR報告書作成時の開示基準として併用
- **SDGs**: 社会的責任の取り組みをSDGsと関連付けて説明

## 6. よくある質問（Q&A）

### Q1. ISO26000は認証取得できますか？

**A1.** いいえ、ISO26000は認証を目的とした規格ではありません。

#### 詳細説明
ISO26000は「ガイダンス規格」として開発されており、第三者認証を前提としていません。これは、社会的責任の性質上、画一的な要求事項を設定することが適切でないためです。組織は、ISO26000を参考に自らの社会的責任を定義し、実践することが求められます。ただし、ISO26000への取り組み状況を第三者が評価することは可能で、一部の評価機関がそのようなサービスを提供しています。

### Q2. 中小企業でもISO26000を活用できますか？

**A2.** はい、ISO26000はあらゆる規模の組織で活用できるよう設計されています。

#### 詳細説明
ISO26000は、大企業だけでなく中小企業、NPO、政府機関など、あらゆる種類・規模の組織を対象としています。規格では「規模及び状況に応じた」取り組みを推奨しており、中小企業向けの実施例も含まれています。例えば：
- 段階的アプローチ: すべてを一度に実施するのではなく、優先順位をつけて段階的に取り組む
- 協働による実施: 業界団体や地域の企業と協力して取り組む
- 既存の取り組みの活用: すでに行っている活動をISO26000の枠組みで整理する

### Q3. ISO26000とSDGsの関係はどうなっていますか？

**A3.** ISO26000は2010年発行でSDGs（2015年）より前ですが、両者は補完関係にあります。

#### 詳細説明
ISO26000の7つの中核主題とSDGsの17のゴールには多くの共通点があります：
- ISO26000は「どのように取り組むか（How）」を示すガイダンス
- SDGsは「何を達成すべきか（What）」を示す目標
- 実務では、ISO26000の枠組みを使ってSDGsへの貢献を体系的に進めることが可能

対応関係の例：
- 中核主題「環境」→ SDGs 6, 7, 12, 13, 14, 15
- 中核主題「人権」→ SDGs 1, 2, 3, 4, 5, 8, 10, 16
- 中核主題「労働慣行」→ SDGs 3, 4, 5, 8

### Q4. ステークホルダー・エンゲージメントの具体的な方法は？

**A4.** ステークホルダーの特性に応じて、多様な方法を組み合わせることが重要です。

#### 詳細説明
主な手法と適用例：
1. **対話型**:
   - ステークホルダー・ダイアログ（年1-2回、20-30名規模）
   - ラウンドテーブル（特定テーマで5-10名）
   - 個別面談（重要ステークホルダーと）

2. **調査型**:
   - アンケート調査（従業員満足度調査、顧客満足度調査）
   - インタビュー調査（サプライヤー、地域住民）
   - 第三者評価（専門機関による評価）

3. **情報提供型**:
   - CSR報告書、統合報告書
   - ウェブサイト、SNS
   - 説明会、セミナー

4. **協働型**:
   - 共同プロジェクト（NPOとの協働）
   - アドバイザリーボード（外部有識者の参画）
   - マルチステークホルダー・イニシアチブ

### Q5. ISO26000導入にはどれくらいの期間とコストがかかりますか？

**A5.** 組織の規模と現状により異なりますが、初期導入は6ヶ月-1年程度が一般的です。

#### 詳細説明
**期間の目安**:
- 小規模組織（従業員100名以下）: 6-9ヶ月
- 中規模組織（従業員100-1000名）: 9-12ヶ月
- 大規模組織（従業員1000名以上）: 12-18ヶ月

**コストの内訳**:
1. 内部コスト:
   - 担当者の人件費（専任1-2名、兼任3-5名）
   - 研修・教育費用（全社員向け基礎研修）
   - システム構築費用（データ収集・管理）

2. 外部コスト:
   - コンサルティング費用（300-1000万円/年）
   - ステークホルダー・エンゲージメント費用（100-500万円/年）
   - 報告書作成・検証費用（200-800万円/年）

ただし、既存のマネジメントシステム（ISO9001、ISO14001等）を活用することで、追加コストを大幅に削減可能です。

## 7. まとめ・今後の展望

ISO26000は、組織の社会的責任に関する包括的なガイダンスを提供する重要な国際規格です。認証を目的としないという特徴により、組織は自らの状況に応じて柔軟に活用することができます。

今後の展望として、以下の動向が予想されます：
- **ESG投資の拡大**: ISO26000の枠組みがESG評価の基礎として活用される
- **サプライチェーン管理の強化**: 人権デュー・ディリジェンスの法制化が進む中、ISO26000の重要性が増大
- **SDGsとの統合**: ISO26000とSDGsを統合した経営フレームワークの普及
- **デジタル技術の活用**: AIやブロックチェーンを活用した社会的責任の実践と透明性向上
- **規格の改訂**: 発行から10年以上経過し、近い将来の改訂が検討される可能性

組織にとって、ISO26000は単なるガイドラインではなく、持続可能な経営を実現するための戦略的ツールとして、その重要性を増していくことが確実です。

組織がISO26000の取り組みを継続的に改善するために最も効果的な方法は？

- A) 年1回の経営陣による形式的なレビュー
- B) PDCAサイクルによる定期的な見直しと改善
- C) 外部コンサルタントに全面的に依存する
- D) 一度策定した方針を変更しない

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
ISO26000では、Plan-Do-Check-Act（PDCA）サイクルによる継続的改善を推奨しています。定期的なモニタリング、評価、見直しを通じて、取り組みを改善していくことが重要です。<br>
<br>
Aが間違いの理由：形式的なレビューでは実質的な改善につながりません<br>
Cが間違いの理由：組織自身の主体的な取り組みが不可欠です<br>
Dが間違いの理由：環境変化に応じた柔軟な対応が必要です<br>
<br>
【補足】効果的なPDCAには、明確なKPIの設定、定期的なモニタリング、ステークホルダーからのフィードバックの活用が含まれます。
</details>

## 9. 専門用語集

### アルファベット

**CSR (Corporate Social Responsibility)**
- **読み方**: シーエスアール
- **意味**: 企業の社会的責任。企業が社会に対して責任を持ち、社会とともに発展していくための企業のあり方
- **関連用語**: 社会的責任、サステナビリティ、ESG

**ESG (Environmental, Social and Governance)**
- **読み方**: イーエスジー
- **意味**: 環境・社会・ガバナンスの頭文字。投資判断において企業の持続可能性を評価する指標
- **関連用語**: ESG投資、責任投資、CSR

**GRI (Global Reporting Initiative)**
- **読み方**: ジーアールアイ
- **意味**: サステナビリティ報告書の国際的なガイドラインを策定する非営利団体、およびそのガイドライン
- **関連用語**: サステナビリティ報告書、統合報告書

**ISO (International Organization for Standardization)**
- **読み方**: アイエスオー
- **意味**: 国際標準化機構。各国の標準化団体の世界的な連合体で、国際規格を策定する
- **関連用語**: 国際規格、マネジメントシステム

**KPI (Key Performance Indicator)**
- **読み方**: ケーピーアイ
- **意味**: 重要業績評価指標。目標達成度を評価するための重要な指標
- **関連用語**: パフォーマンス指標、目標管理

**NGO (Non-Governmental Organization)**
- **読み方**: エヌジーオー
- **意味**: 非政府組織。政府から独立した非営利の市民団体
- **関連用語**: NPO、市民社会組織

**NPO (Non-Profit Organization)**
- **読み方**: エヌピーオー
- **意味**: 非営利組織。利益の分配を目的としない組織
- **関連用語**: NGO、市民団体

**OECD (Organisation for Economic Co-operation and Development)**
- **読み方**: オーイーシーディー
- **意味**: 経済協力開発機構。先進国を中心とした国際機関
- **関連用語**: OECD多国籍企業行動指針

**PDCA (Plan-Do-Check-Act)**
- **読み方**: ピーディーシーエー
- **意味**: 計画・実行・評価・改善の継続的改善サイクル
- **関連用語**: マネジメントサイクル、継続的改善

**SDGs (Sustainable Development Goals)**
- **読み方**: エスディージーズ
- **意味**: 持続可能な開発目標。2015年に国連で採択された2030年までの17の国際目標
- **関連用語**: 持続可能な発展、2030アジェンダ

### あ行

**アカウンタビリティ**
- **読み方**: あかうんたびりてぃ
- **意味**: 説明責任。組織が自らの決定や活動について、ステークホルダーに対して説明する責任
- **関連用語**: 説明責任、透明性

### か行

**加担（かたん）**
- **読み方**: かたん
- **意味**: 他者の不法行為や人権侵害に関与したり、それから利益を得たりすること
- **関連用語**: 人権侵害、サプライチェーン

**ガバナンス**
- **読み方**: がばなんす
- **意味**: 組織統治。組織が目的を達成するための意思決定の仕組みやプロセス
- **関連用語**: コーポレート・ガバナンス、組織統治

**国際行動規範（こくさいこうどうきはん）**
- **読み方**: こくさいこうどうきはん
- **意味**: 国際慣習法、国際的に認められた原則、国際条約などから導かれる社会的責任に関する期待
- **関連用語**: 国際法、ソフトロー

### さ行

**サステナビリティ**
- **読み方**: さすてなびりてぃ
- **意味**: 持続可能性。環境・社会・経済の観点から、現在と将来にわたって持続可能であること
- **関連用語**: 持続可能な発展、CSR

**サプライチェーン**
- **読み方**: さぷらいちぇーん
- **意味**: 原材料調達から製造、販売、消費に至るまでの一連の流れ
- **関連用語**: バリューチェーン、調達

**社会的責任（しゃかいてきせきにん）**
- **読み方**: しゃかいてきせきにん
- **意味**: 組織の決定及び活動が社会及び環境に及ぼす影響に対する責任
- **関連用語**: CSR、ISO26000

**ステークホルダー**
- **読み方**: すてーくほるだー
- **意味**: 組織の決定又は活動に利害関係をもつ個人又はグループ
- **関連用語**: 利害関係者、ステークホルダー・エンゲージメント

**ステークホルダー・エンゲージメント**
- **読み方**: すてーくほるだー・えんげーじめんと
- **意味**: 組織がステークホルダーと対話し、その期待や懸念を理解し、活動に反映させるプロセス
- **関連用語**: ステークホルダー対話、参画

### た行

**透明性（とうめいせい）**
- **読み方**: とうめいせい
- **意味**: 組織の決定や活動に関する情報を、ステークホルダーがアクセス可能な形で開示すること
- **関連用語**: 情報開示、アカウンタビリティ

**デュー・ディリジェンス**
- **読み方**: でゅー・でぃりじぇんす
- **意味**: 組織の決定や活動による負の影響を特定し、防止・軽減するための継続的プロセス
- **関連用語**: リスク評価、人権デュー・ディリジェンス

### は行

**バリューチェーン**
- **読み方**: ばりゅーちぇーん
- **意味**: 組織が価値を生み出す一連の活動の連鎖
- **関連用語**: サプライチェーン、価値連鎖

**人権（じんけん）**
- **読み方**: じんけん
- **意味**: すべての人間が生まれながらにして持つ基本的な権利と自由
- **関連用語**: 世界人権宣言、国際人権規約

### ま行

**マテリアリティ**
- **読み方**: まてりありてぃ
- **意味**: 組織とステークホルダーの双方にとって重要な課題
- **関連用語**: 重要課題、マテリアリティ分析

**マルチステークホルダー**
- **読み方**: まるちすてーくほるだー
- **意味**: 複数の異なる立場のステークホルダーが参加する枠組みやプロセス
- **関連用語**: ステークホルダー、協働

### ら行

**倫理的行動（りんりてきこうどう）**
- **読み方**: りんりてきこうどう
- **意味**: 正直、公平、誠実などの価値観に基づいた行動
- **関連用語**: 企業倫理、コンプライアンス
