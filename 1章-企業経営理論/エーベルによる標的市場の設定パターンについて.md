# エーベルによる標的市場の設定パターンについて

## 概要

デレク・F・エーベル（Derek F. Abell）は、企業が市場をセグメント化し、どのセグメントをターゲットとするかを決定する際の体系的なアプローチを提示しました。彼が提唱した5つの標的市場設定パターンは、企業が限られた経営資源を効率的に配分し、競争優位を構築するための重要なフレームワークとなっています。

エーベルの標的市場設定パターンは、市場細分化（セグメンテーション）を前提として、企業がどのセグメントに対してマーケティング活動を展開するかを決定する戦略的選択肢を示したものです。これらのパターンは、企業の規模、資源、競争環境、市場の特性などを考慮して選択されます。

## 1. 基本概念と前提条件

### 市場細分化の3次元モデル

エーベルは市場を以下の3つの次元で定義しました：

- **顧客グループ（Who）**: 誰にサービスを提供するか
- **顧客ニーズ（What）**: どのようなニーズを満たすか
- **技術（How）**: どのような技術・方法で提供するか

### セグメントの要件

効果的なセグメントは以下の要件を満たす必要があります：

- **測定可能性**: セグメントの規模や購買力が測定可能
- **接近可能性**: セグメントに効果的にアプローチできる
- **実質性**: 十分な規模と収益性がある
- **差別化可能性**: 他のセグメントと明確に区別できる
- **実行可能性**: マーケティング活動を実行できる

## 2. エーベルの5つの標的市場設定パターン

### 2.1 単一セグメント集中型（Single-segment Concentration）

| 項目 | 内容 |
|------|------|
| 定義 | 1つの市場セグメントに経営資源を集中投入する戦略 |
| 特徴 | 深い市場知識、専門性の構築、高い市場シェア |
| 適用企業 | 中小企業、ニッチ市場を狙う企業 |
| リスク | セグメント衰退時の影響大、競合参入による収益性低下 |

**具体例：**
- **フェラーリ**: 超高級スポーツカー市場に特化
- **ロレックス**: 高級腕時計市場に集中
- **スターバックス（初期）**: プレミアムコーヒー愛好家層に特化

### 2.2 製品専門型（Product Specialization）

| 項目 | 内容 |
|------|------|
| 定義 | 1つの製品を複数の市場セグメントに提供する戦略 |
| 特徴 | 製品の専門性、規模の経済、製品イメージの確立 |
| 適用企業 | 技術力の高い企業、特定製品に強みを持つ企業 |
| リスク | 代替品の出現、技術革新による陳腐化 |

**具体例：**
- **インテル**: マイクロプロセッサーを様々な市場（PC、サーバー、組込み）に提供
- **ゴア・テックス**: 防水透湿素材を登山用品、スポーツウェア、医療分野に展開
- **3M**: 粘着技術を活用した製品を多市場に展開

### 2.3 市場専門型（Market Specialization）

| 項目 | 内容 |
|------|------|
| 定義 | 特定の顧客グループに複数の製品を提供する戦略 |
| 特徴 | 顧客ニーズの深い理解、顧客との強い関係、クロスセリング機会 |
| 適用企業 | 特定顧客層に強みを持つ企業、B2B企業 |
| リスク | 顧客グループの購買力低下、顧客ニーズの変化 |

**具体例：**
- **大塚商会**: 中小企業向けにIT機器、ソフトウェア、サポートサービスを総合提供
- **ベネッセ**: 子ども・教育市場に通信教育、学習塾、出版など多角的に展開
- **医療機器メーカー**: 病院向けに診断機器、治療機器、消耗品を提供

### 2.4 選択的専門型（Selective Specialization）

| 項目 | 内容 |
|------|------|
| 定義 | 収益性や成長性を基準に複数のセグメントを選択的にカバーする戦略 |
| 特徴 | リスク分散、各セグメントでの収益最大化、柔軟な資源配分 |
| 適用企業 | 中堅・大企業、複数事業を展開する企業 |
| リスク | 経営資源の分散、シナジー効果の不足 |

**具体例：**
- **P&G**: 洗剤は主婦層、髭剃りは男性層、紙おむつは乳幼児の親層
- **ソニー**: ゲーム機は若年層、カメラは写真愛好家、音響機器は音楽愛好家
- **ユニクロ**: ベーシック衣料は一般消費者、ヒートテックは寒冷地住民、エアリズムはスポーツ愛好家

### 2.5 全市場浸透型（Full Market Coverage）

| 項目 | 内容 |
|------|------|
| 定義 | すべての市場セグメントをカバーする戦略 |
| 特徴 | 規模の経済、市場支配力、ブランド認知度の最大化 |
| 適用企業 | 大企業、市場リーダー |
| リスク | 莫大な経営資源が必要、管理の複雑化、カニバリゼーション |

**具体例：**
- **トヨタ自動車**: 軽自動車から高級車まで全セグメントをカバー
- **コカ・コーラ**: 炭酸飲料、水、茶、スポーツドリンクなど全飲料カテゴリー
- **マイクロソフト**: 個人向けから企業向けまで全てのソフトウェア市場

## 3. 各パターンの詳細分析と実務への応用

### 3.1 戦略選択の意思決定プロセス

#### ステップ1: 市場分析
1. 市場規模と成長性の評価
2. 競合状況の分析
3. 顧客ニーズの把握
4. 自社の強み・弱みの評価

#### ステップ2: セグメント評価
```
セグメント魅力度 = (市場規模 × 成長率 × 収益性) / (競争強度 × 参入障壁)
```

#### ステップ3: 資源配分の決定
- 必要投資額の算定
- 期待収益の予測
- リスク評価
- ROIの計算

### 3.2 実際の適用事例

#### 事例1: アマゾンの市場拡大戦略
**初期（1995-2000年）**: 単一セグメント集中型
- オンライン書籍販売に特化
- 本好きのインターネットユーザーをターゲット

**成長期（2000-2010年）**: 選択的専門型
- 音楽、DVD、電子機器へ拡大
- 各カテゴリーで収益性の高いセグメントを選択

**現在（2010年-）**: 全市場浸透型
- あらゆる商品カテゴリーをカバー
- B2C、B2B、クラウドサービスまで展開

#### 事例2: 日本の家電メーカーの戦略転換
**パナソニックの例**：
- 過去: 全市場浸透型（家電全般をカバー）
- 現在: 選択的専門型（車載、住宅、B2B分野に集中）
- 理由: 競争激化により収益性の高い分野に経営資源を集中

## 4. 戦略パターン選択の判断基準

### 4.1 企業規模による選択指針

| 企業規模 | 推奨パターン | 理由 |
|----------|-------------|------|
| スタートアップ | 単一セグメント集中型 | 限られた資源を最大限活用 |
| 中小企業 | 製品専門型/市場専門型 | 専門性による差別化 |
| 中堅企業 | 選択的専門型 | リスク分散と成長機会の追求 |
| 大企業 | 全市場浸透型/選択的専門型 | 規模の経済と市場支配力 |

### 4.2 業界特性による選択指針

**成熟業界**：
- 市場専門型: 既存顧客との関係強化
- 選択的専門型: 収益性の高いニッチ市場への集中

**成長業界**：
- 単一セグメント集中型: 特定セグメントでの地位確立
- 製品専門型: 革新的製品による市場開拓

**衰退業界**：
- 選択的専門型: 残存者利益の追求
- 市場専門型: ロイヤル顧客の維持

## 5. 実務上の注意点とベストプラクティス

### 5.1 よくある失敗パターン

1. **過度な分散**
   - 問題: 経営資源が薄く広く分散し、どのセグメントでも競争力を失う
   - 対策: コアコンピタンスに基づいたセグメント選択

2. **市場変化への対応遅れ**
   - 問題: 選択したセグメントの魅力度低下に気づかない
   - 対策: 定期的な市場評価と戦略見直し

3. **カニバリゼーション**
   - 問題: 複数セグメント展開時に自社製品同士が競合
   - 対策: 明確な製品ポジショニングと価格戦略

### 5.2 成功のための実施ポイント

- **段階的アプローチ**: 単一セグメントから徐々に拡大
- **シナジー追求**: セグメント間の相乗効果を意識
- **撤退基準の明確化**: 各セグメントの撤退条件を事前設定
- **組織体制の整備**: 各セグメントに適した組織構造

## 6. よくある質問（Q&A）

### Q1. 中小企業が全市場浸透型を選択することは可能ですか？

**A1.** 理論的には可能ですが、実務的には推奨されません。

全市場浸透型は莫大な経営資源を必要とするため、中小企業には以下の理由で困難です：
- 資金面: 全セグメントへの投資資金が不足
- 人材面: 各セグメントの専門人材確保が困難
- 管理面: 複雑な事業管理に対応できない

代替案として、特定地域での全市場浸透や、段階的な市場拡大戦略が現実的です。

### Q2. 複数のパターンを同時に採用することは可能ですか？

**A2.** 事業部門ごとに異なるパターンを採用することは可能です。

例えば：
- A事業部: 単一セグメント集中型（新規事業）
- B事業部: 市場専門型（既存の強い顧客基盤）
- C事業部: 選択的専門型（成熟事業）

ただし、全社レベルでの資源配分の最適化と、事業間シナジーの追求が重要です。

### Q3. デジタル時代において、これらのパターンは有効ですか？

**A3.** 基本的な考え方は有効ですが、適用方法に工夫が必要です。

デジタル時代の特徴：
- 市場セグメントの境界が曖昧化
- プラットフォームビジネスの台頭
- データによる超細分化（マイクロセグメンテーション）

新しい適用方法：
- AIを活用した動的セグメンテーション
- プラットフォーム上での選択的専門型
- データドリブンな市場選択

## 7. まとめと今後の展望

エーベルの標的市場設定パターンは、企業の市場戦略立案において今でも重要なフレームワークです。しかし、デジタル化、グローバル化、顧客ニーズの多様化により、これらのパターンの適用には新たな視点が必要となっています。

今後の展望：
- **ハイブリッド型戦略**: 複数パターンの組み合わせ
- **動的戦略**: 市場環境に応じた柔軟な戦略転換
- **エコシステム戦略**: パートナーとの協業による市場カバー
- **サステナビリティ重視**: ESG観点からのセグメント選択

企業は自社の資源、能力、市場環境を総合的に判断し、最適な標的市場設定パターンを選択することが成功への鍵となります。

### 問題2
単一セグメント集中型戦略の最大のリスクは何か？

- A) 管理コストの増大

- C) 特定セグメントへの過度な依存
- D) 規模の経済が働かない

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
単一セグメント集中型の最大のリスクは、1つのセグメントに依存するため、そのセグメントが衰退した場合に企業全体が大きな影響を受けることです。<br>
<br>
Aが間違いの理由：単一セグメントなので管理コストは比較的低い<br>
Bが間違いの理由：むしろ特定セグメントでの強いブランドイメージを構築できる<br>
Dが間違いの理由：特定セグメントに集中することで規模の経済は働きやすい<br>
<br>
【補足】このリスクを軽減するため、セグメントの将来性を慎重に評価し、撤退基準を明確にすることが重要です。
</details>

## 9. 専門用語集

### あ行

**イノベーター理論**
- **読み方**: いのべーたーりろん
- **意味**: E.M.ロジャースが提唱した、新製品や新技術の普及過程を5つの採用者カテゴリーに分類した理論
- **関連用語**: アーリーアダプター、キャズム

**エーベル（Derek F. Abell）**
- **読み方**: デレク・エフ・エーベル
- **意味**: ハーバード・ビジネススクール教授。市場定義の3次元モデルと標的市場設定の5つのパターンを提唱した経営学者
- **関連用語**: 市場細分化、標的市場設定

### か行

**カニバリゼーション**
- **読み方**: かにばりぜーしょん
- **意味**: 自社の新製品が既存製品の売上を奪う現象。共食い現象とも呼ばれる
- **関連用語**: 製品ポートフォリオ、全市場浸透型

**顧客生涯価値（CLV）**
- **読み方**: こきゃくしょうがいかち
- **意味**: 一人の顧客が生涯にわたって企業にもたらす利益の合計。Customer Lifetime Valueの略
- **関連用語**: 市場専門型、顧客維持率

**コアコンピタンス**
- **読み方**: こあこんぴたんす
- **意味**: 企業の中核となる独自の強みや能力。競合他社が模倣困難な競争優位の源泉
- **関連用語**: 製品専門型、競争優位

### さ行

**市場細分化**
- **読み方**: しじょうさいぶんか
- **意味**: 市場を同質的なニーズを持つグループに分割すること。セグメンテーションとも呼ばれる
- **関連用語**: ターゲティング、ポジショニング

**市場専門型**
- **読み方**: しじょうせんもんがた
- **意味**: 特定の顧客グループに対して複数の製品・サービスを提供する標的市場設定パターン
- **関連用語**: クロスセリング、顧客シェア

**選択的専門型**
- **読み方**: せんたくてきせんもんがた
- **意味**: 収益性や成長性を基準に複数のセグメントを選択的にカバーする標的市場設定パターン
- **関連用語**: ポートフォリオ戦略、リスク分散

**全市場浸透型**
- **読み方**: ぜんしじょうしんとうがた
- **意味**: すべての市場セグメントをカバーする標的市場設定パターン。フルカバレッジ戦略とも呼ばれる
- **関連用語**: 規模の経済、市場支配力

### た行

**単一セグメント集中型**
- **読み方**: たんいつせぐめんとしゅうちゅうがた
- **意味**: 1つの市場セグメントに経営資源を集中投入する標的市場設定パターン
- **関連用語**: ニッチ戦略、集中戦略

**ターゲティング**
- **読み方**: たーげてぃんぐ
- **意味**: 細分化された市場セグメントの中から、自社が狙うべき標的市場を選定すること
- **関連用語**: STP戦略、標的市場

### な行

**ニッチ市場**
- **読み方**: にっちしじょう
- **意味**: 大手企業が参入しない、特定のニーズを持つ小規模な市場
- **関連用語**: 単一セグメント集中型、専門化

### は行

**標的市場**
- **読み方**: ひょうてきしじょう
- **意味**: 企業がマーケティング活動の対象として選定した特定の市場セグメント
- **関連用語**: ターゲット市場、STP戦略

**プラットフォームビジネス**
- **読み方**: ぷらっとふぉーむびじねす
- **意味**: 複数の顧客グループを結びつけ、相互作用を促進することで価値を創造するビジネスモデル
- **関連用語**: ネットワーク効果、マルチサイド市場

**ポジショニング**
- **読み方**: ぽじしょにんぐ
- **意味**: 標的市場において、競合と差別化された独自の位置づけを確立すること
- **関連用語**: 差別化、ブランディング

### ま行

**マイクロセグメンテーション**
- **読み方**: まいくろせぐめんてーしょん
- **意味**: デジタル技術を活用して、極めて細かい単位で市場を細分化すること
- **関連用語**: ビッグデータ、パーソナライゼーション

**マルチサイド市場**
- **読み方**: まるちさいどしじょう
- **意味**: 2つ以上の異なる顧客グループが、プラットフォームを介して相互作用する市場
- **関連用語**: プラットフォーム戦略、ネットワーク外部性

### ら行

**リポジショニング**
- **読み方**: りぽじしょにんぐ
- **意味**: 市場環境の変化に応じて、製品やブランドの位置づけを変更すること
- **関連用語**: ブランド再生、市場適応

**臨界点**
- **読み方**: りんかいてん
- **意味**: ネットワーク効果が働き始め、急速な成長が始まる転換点。クリティカルマスとも呼ばれる
- **関連用語**: ネットワーク効果、普及理論

### アルファベット

**B2B（Business to Business）**
- **読み方**: びーつーびー
- **意味**: 企業間取引。企業が企業に対して製品やサービスを提供するビジネス形態
- **関連用語**: B2C、市場専門型

**ROI（Return on Investment）**
- **読み方**: あーるおーあい
- **意味**: 投資収益率。投資に対してどれだけの利益を得られたかを示す指標
- **関連用語**: 投資判断、セグメント評価

**STP戦略**
- **読み方**: えすてぃーぴーせんりゃく
- **意味**: セグメンテーション、ターゲティング、ポジショニングの3つのステップからなるマーケティング戦略立案プロセス
- **関連用語**: マーケティング戦略、市場細分化
