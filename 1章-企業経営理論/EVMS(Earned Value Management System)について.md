# EVMS(Earned Value Management System)について

## 概要
EVMS（Earned Value Management System：アーンドバリューマネジメントシステム）は、プロジェクトの進捗状況を定量的に把握し、コストとスケジュールを統合的に管理する手法です。1960年代に米国国防総省で開発され、現在では世界中の大規模プロジェクトで採用されている標準的なプロジェクト管理手法となっています。プロジェクトの計画値、実績値、出来高を比較することで、プロジェクトの健全性を客観的に評価し、将来の予測を行うことができます。

## 1. 基本概念・仕組み

### EVMSの核となる概念
- **定義**: プロジェクトのスコープ、スケジュール、コストを統合的に管理し、プロジェクトのパフォーマンスを定量的に測定・予測する体系的な手法
- **動作原理**: 計画時点での予算（PV）、実際の出来高（EV）、実際のコスト（AC）の3つの基本値を比較し、差異分析を行う
- **特徴**: 客観的な数値による進捗管理、早期の問題発見、将来予測の精度向上

### 従来の管理手法との関係
- **従来技術との違い**: 単純な予算対実績の比較ではなく、実際の成果物の価値（出来高）を含めた3次元的な分析が可能
- **改善点**: 進捗遅れとコスト超過を同時に把握でき、プロジェクトの真の健全性を評価できる
- **限界**: 品質面の評価は含まれない、初期の正確な計画策定が前提となる

## 2. 主要指標と計算方法

### 基本となる3つの値

### PV（Planned Value：計画価値）
**特徴:**
- ある時点までに完了予定の作業の予算コスト
- プロジェクト開始時に決定される基準値
- ベースラインとして変更管理の対象

**算出方法:**
```
PV = 計画作業量 × 計画単価
```

**📊 具体的な計算例**
**例: ソフトウェア開発プロジェクト（10ヶ月、総予算1,000万円）**
- 5ヶ月目までの計画作業量: 50%
- 計画総予算: 1,000万円

**ステップ1: 5ヶ月目のPV計算**
```
PV = 1,000万円 × 50% = 500万円
```

**結果: 5ヶ月目時点でのPVは500万円**

💡 **実際の現場では**: WBS（作業分解構造）の各要素に予算を割り当て、期間ごとに積み上げてPVを算出します

### EV（Earned Value：出来高）
**特徴:**
- 実際に完了した作業の予算コスト
- 進捗の実績を金額換算した値
- プロジェクトの真の進捗を表す指標

**算出方法:**
```
EV = 実際の完了作業量 × 計画単価
```

**📊 具体的な計算例**
**例: 上記プロジェクトの5ヶ月目時点**
- 実際の完了作業量: 40%
- 計画総予算: 1,000万円

**ステップ1: 5ヶ月目のEV計算**
```
EV = 1,000万円 × 40% = 400万円
```

**結果: 5ヶ月目時点でのEVは400万円（計画より100万円分の作業が遅れている）**

💡 **実際の現場では**: 完了基準を明確に定義し、客観的な進捗測定方法を確立することが重要です

### AC（Actual Cost：実コスト）
**特徴:**
- 実際に発生したコスト
- 人件費、材料費、外注費などすべての実費用
- 予算管理の基本データ

**算出方法:**
```
AC = 実際に支出した累計金額
```

**📊 具体的な計算例**
**例: 上記プロジェクトの5ヶ月目時点**
- 実際の支出額: 450万円

**結果: 5ヶ月目時点でのACは450万円**

💡 **実際の現場では**: 経理システムとの連携により、リアルタイムでACを把握する仕組みが重要です

## 3. パフォーマンス指標の詳細

### 差異分析指標
#### CV（Cost Variance：コスト差異）
- **意味**: 出来高と実コストの差
- **計算式**: CV = EV - AC
- **影響**: 正の値はコスト節約、負の値はコスト超過
- **推奨値**: 0以上（許容範囲は±10%程度）

**計算例**: 
```
CV = 400万円 - 450万円 = -50万円
（50万円のコスト超過）
```

#### SV（Schedule Variance：スケジュール差異）
- **意味**: 出来高と計画価値の差
- **計算式**: SV = EV - PV
- **影響**: 正の値は進捗先行、負の値は進捗遅延
- **推奨値**: 0以上（許容範囲は±10%程度）

**計算例**: 
```
SV = 400万円 - 500万円 = -100万円
（100万円分の作業が遅延）
```

### 効率指標
#### CPI（Cost Performance Index：コスト効率指標）
- **意味**: コスト効率を表す指標
- **計算式**: CPI = EV / AC
- **影響**: 1.0より大きければコスト効率良好
- **推奨値**: 0.95以上

**計算例**: 
```
CPI = 400万円 / 450万円 = 0.89
（1円使って0.89円分の価値しか生み出していない）
```

#### SPI（Schedule Performance Index：スケジュール効率指標）
- **意味**: スケジュール効率を表す指標
- **計算式**: SPI = EV / PV
- **影響**: 1.0より大きければスケジュール順調
- **推奨値**: 0.95以上

**計算例**: 
```
SPI = 400万円 / 500万円 = 0.80
（計画の80%しか進捗していない）
```

## 4. 実装例・適用事例

### 基本実装（Excel VBAでの簡易EVMS）
```vba
' EVMS基本計算関数
Function CalculateEVMS(PV As Double, EV As Double, AC As Double) As Variant
    Dim result(1 To 6, 1 To 2) As Variant
    
    ' 差異分析
    result(1, 1) = "CV (コスト差異)"
    result(1, 2) = EV - AC
    
    result(2, 1) = "SV (スケジュール差異)"
    result(2, 2) = EV - PV
    
    ' 効率指標
    result(3, 1) = "CPI (コスト効率)"
    result(3, 2) = EV / AC
    
    result(4, 1) = "SPI (スケジュール効率)"
    result(4, 2) = EV / PV
    
    ' 予測値（簡易版）
    result(5, 1) = "ETC (残作業コスト予測)"
    result(5, 2) = (1000 - EV) / (EV / AC)
    
    result(6, 1) = "EAC (完了時総コスト予測)"
    result(6, 2) = AC + result(5, 2)
    
    CalculateEVMS = result
End Function
```

### 応用実装（プロジェクト管理ツールとの連携）
```python
# Python実装例
import pandas as pd
import numpy as np
from datetime import datetime, timedelta

class EVMSAnalyzer:
    def __init__(self, project_data):
        self.project_data = project_data
        self.baseline = project_data['baseline']
        self.actuals = project_data['actuals']
        
    def calculate_evms_metrics(self, as_of_date):
        # 基本値の計算
        pv = self._calculate_pv(as_of_date)
        ev = self._calculate_ev(as_of_date)
        ac = self._calculate_ac(as_of_date)
        
        # パフォーマンス指標の計算
        metrics = {
            'PV': pv,
            'EV': ev,
            'AC': ac,
            'CV': ev - ac,
            'SV': ev - pv,
            'CPI': ev / ac if ac > 0 else 0,
            'SPI': ev / pv if pv > 0 else 0,
            'TCPI': self._calculate_tcpi(ev, ac),
            'EAC': self._calculate_eac(ev, ac),
            'VAC': self.baseline['BAC'] - self._calculate_eac(ev, ac)
        }
        
        return metrics
    
    def generate_report(self, metrics):
        """EVMSレポートの生成"""
        report = f"""
        EVMS分析レポート - {datetime.now().strftime('%Y-%m-%d')}
        
        基本指標:
        - PV (計画価値): {metrics['PV']:,.0f}円
        - EV (出来高): {metrics['EV']:,.0f}円
        - AC (実コスト): {metrics['AC']:,.0f}円
        
        パフォーマンス指標:
        - CV (コスト差異): {metrics['CV']:,.0f}円
        - SV (スケジュール差異): {metrics['SV']:,.0f}円
        - CPI (コスト効率): {metrics['CPI']:.2f}
        - SPI (スケジュール効率): {metrics['SPI']:.2f}
        
        予測指標:
        - EAC (完了時総コスト): {metrics['EAC']:,.0f}円
        - VAC (完了時差異): {metrics['VAC']:,.0f}円
        """
        return report
```

## 5. メリット・デメリット

### メリット
**1. 客観的な進捗把握**
- **理由**: 数値化された指標により主観を排除
- **効果**: ステークホルダー間の認識統一、意思決定の迅速化
- **具体例**: 月次報告会での議論時間が平均60分から20分に短縮

**2. 早期の問題発見**
- **理由**: トレンド分析により将来の問題を予測可能
- **効果**: リスクの早期対応、被害の最小化
- **具体例**: CPI低下傾向から3ヶ月前にコスト超過リスクを検知

**3. 予測精度の向上**
- **理由**: 実績データに基づく統計的予測
- **効果**: 予算・工期の見通し精度向上
- **具体例**: プロジェクト完了予測の誤差が±20%から±5%に改善

### デメリット
**1. 導入・運用コスト**
- **理由**: 初期設定、教育、システム構築が必要
- **影響**: 小規模プロジェクトでは費用対効果が低い
- **対策**: 段階的導入、既存ツールの活用、簡易版から開始

**2. 計画精度への依存**
- **理由**: ベースラインの精度がEVMS全体の精度を左右
- **影響**: 不正確な計画では誤った判断を招く
- **対策**: 計画策定プロセスの標準化、過去実績の活用

**3. 品質面の考慮不足**
- **理由**: EVMSは主にコストとスケジュールに焦点
- **影響**: 品質を犠牲にした進捗確保のリスク
- **対策**: 品質指標との併用、品質ゲートの設置

### 問題2
プロジェクトのCPI（Cost Performance Index）が0.8の場合、どのような状態を示しているか？

- A) コストが予算内に収まっている
- B) 1円使って0.8円分の価値しか生み出していない
- C) スケジュールが20%遅れている
- D) プロジェクトの80%が完了している

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
CPI = EV / ACで計算され、0.8という値は1円の投資に対して0.8円分の価値（成果物）しか生み出していないことを示します。これはコスト効率が悪い状態です。<br>
<br>
Aが間違いの理由：CPI < 1.0はコスト超過を示します<br>
Cが間違いの理由：スケジュール遅れはSPI（Schedule Performance Index）で測定します<br>
Dが間違いの理由：プロジェクトの完了率とCPIは直接関係ありません<br>
<br>
【補足】CPIが0.8の場合、このままのペースだと予算を25%（1/0.8-1）超過する可能性があります。
</details>

TCPI（To-Complete Performance Index）の用途として正しいものはどれか？

- A) 過去のコスト効率を評価する
- B) 残作業を予算内で完了するために必要な効率を示す
- C) 現在のスケジュール効率を測定する
- D) プロジェクトの品質を数値化する

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
TCPIは、残りの作業を予算内で完了するために必要なコスト効率を示す指標です。TCPI = (BAC - EV) / (BAC - AC)で計算されます。<br>
<br>
Aが間違いの理由：過去の効率はCPIで評価します<br>
Cが間違いの理由：スケジュール効率はSPIで測定します<br>
Dが間違いの理由：EVMSは品質を直接測定する指標ではありません<br>
<br>
【補足】TCPIが1.2以上の場合、残作業で非常に高い効率が要求され、達成が困難な可能性があります。
</details>

## 9. 専門用語集

このスライドで使用された専門用語について、アルファベット順・50音順で解説します。

### アルファベット

**AC (Actual Cost)**
- **読み方**: エーシー、アクチュアルコスト
- **意味**: 実際に発生したコスト。ある時点までに実際に支出された累計金額
- **関連用語**: PV、EV、コスト管理

**BAC (Budget at Completion)**
- **読み方**: バック、バジェット・アット・コンプリーション
- **意味**: プロジェクト完了時の総予算。プロジェクト開始時に設定される全体予算
- **関連用語**: EAC、VAC、ベースライン

**CPI (Cost Performance Index)**
- **読み方**: シーピーアイ、コスト・パフォーマンス・インデックス
- **意味**: コスト効率指標。EV÷ACで計算され、1.0より大きければコスト効率が良好
- **関連用語**: SPI、効率指標、パフォーマンス測定

**CV (Cost Variance)**
- **読み方**: シーブイ、コスト・バリアンス
- **意味**: コスト差異。EV-ACで計算され、正の値はコスト節約、負の値はコスト超過を示す
- **関連用語**: SV、差異分析、コスト管理

**EAC (Estimate at Completion)**
- **読み方**: イーエーシー、エスティメート・アット・コンプリーション
- **意味**: プロジェクト完了時の予測総コスト。現在の実績から推定される最終コスト
- **関連用語**: BAC、ETC、予測手法

**ETC (Estimate to Complete)**
- **読み方**: イーティーシー、エスティメート・トゥ・コンプリート
- **意味**: 残作業の予測コスト。プロジェクト完了までに必要な追加コストの見積もり
- **関連用語**: EAC、残作業、予測手法

**EV (Earned Value)**
- **読み方**: イーブイ、アーンドバリュー
- **意味**: 出来高。実際に完了した作業の予算コスト。進捗を金額で表現した値
- **関連用語**: PV、AC、進捗管理

**EVM (Earned Value Management)**
- **読み方**: イーブイエム、アーンドバリューマネジメント
- **意味**: アーンドバリュー管理。プロジェクトのパフォーマンスを測定・予測する手法
- **関連用語**: EVMS、プロジェクト管理、パフォーマンス測定

**EVMS (Earned Value Management System)**
- **読み方**: イーブイエムエス、アーンドバリューマネジメントシステム
- **意味**: アーンドバリュー管理システム。EVMを実施するための体系的な仕組み
- **関連用語**: EVM、プロジェクト管理システム

**PV (Planned Value)**
- **読み方**: ピーブイ、プランドバリュー
- **意味**: 計画価値。ある時点までに完了予定の作業の予算コスト
- **関連用語**: ベースライン、計画、WBS

**SPI (Schedule Performance Index)**
- **読み方**: エスピーアイ、スケジュール・パフォーマンス・インデックス
- **意味**: スケジュール効率指標。EV÷PVで計算され、1.0より大きければ進捗順調
- **関連用語**: CPI、効率指標、スケジュール管理

**SV (Schedule Variance)**
- **読み方**: エスブイ、スケジュール・バリアンス
- **意味**: スケジュール差異。EV-PVで計算され、正の値は進捗先行、負の値は遅延を示す
- **関連用語**: CV、差異分析、スケジュール管理

**TCPI (To-Complete Performance Index)**
- **読み方**: ティーシーピーアイ、トゥ・コンプリート・パフォーマンス・インデックス
- **意味**: 残作業効率指標。残りの作業を予算内で完了するために必要な効率
- **関連用語**: CPI、予測、効率管理

**VAC (Variance at Completion)**
- **読み方**: ブイエーシー、バリアンス・アット・コンプリーション
- **意味**: 完了時差異。BAC-EACで計算され、プロジェクト完了時の予算差異を示す
- **関連用語**: BAC、EAC、予測

**WBS (Work Breakdown Structure)**
- **読み方**: ダブリュービーエス、ワーク・ブレークダウン・ストラクチャー
- **意味**: 作業分解構造。プロジェクトの全作業を階層的に分解した構造
- **関連用語**: ワークパッケージ、計画、スコープ管理

### あ行

**アーンドバリュー**
- **読み方**: あーんどばりゅー
- **意味**: 完了した作業の価値を予算ベースで表現したもの。EVの日本語訳
- **関連用語**: 出来高、EV、進捗測定

**アジャイルEVM**
- **読み方**: あじゃいるいーぶいえむ

- **関連用語**: アジャイル開発、スプリント、ベロシティ

### か行

**完了時総コスト予測**
- **読み方**: かんりょうじそうこすとよそく
- **意味**: プロジェクト完了時点での総コストの予測値。EACの日本語訳
- **関連用語**: EAC、予測、コスト管理

**基準計画**
- **読み方**: きじゅんけいかく
- **意味**: プロジェクトの進捗を測定する基準となる計画。ベースラインとも呼ばれる
- **関連用語**: ベースライン、PV、計画

**コスト効率指標**
- **読み方**: こすとこうりつしひょう
- **意味**: 投入したコストに対する成果の効率を示す指標。CPIの日本語訳
- **関連用語**: CPI、効率、パフォーマンス

### さ行

**差異分析**
- **読み方**: さいぶんせき
- **意味**: 計画と実績の差を分析する手法。EVMSではCV、SVなどを用いる
- **関連用語**: CV、SV、分析手法

**出来高**
- **読み方**: できだか
- **意味**: 完了した作業の価値。EVの日本語での一般的な呼称
- **関連用語**: EV、進捗、アーンドバリュー

**進捗率**
- **読み方**: しんちょくりつ

- **関連用語**: 進捗管理、完了率、測定

- **読み方**: すけじゅーるこうりつしひょう
- **意味**: 計画に対する実際の進捗の効率を示す指標。SPIの日本語訳
- **関連用語**: SPI、スケジュール管理、効率

### た行

- **関連用語**: 予測、分析、傾向管理

### は行

- **読み方**: ぱふぉーまんすそくてい

- **関連用語**: 測定、評価、EVMS

- **読み方**: べーすらいん
- **意味**: プロジェクトの基準となる計画。スコープ、スケジュール、コストの基準
- **関連用語**: 基準計画、PV、変更管理

- **関連用語**: スケジュール、進捗管理、チェックポイント

- **関連用語**: リスク管理、予測、不確実性
