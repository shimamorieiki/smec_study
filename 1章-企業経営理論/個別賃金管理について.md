# 個別賃金管理について

## 概要

個別賃金管理とは、企業が従業員一人ひとりの賃金を個別に決定・管理する仕組みです。年功序列型の一律的な賃金管理から、個人の能力・成果・貢献度に応じた賃金決定への転換を図る手法として、多くの企業で導入されています。

個別賃金管理では、従業員の職務内容、能力、成果、市場価値などを総合的に評価し、それぞれに適切な賃金水準を設定します。これにより、優秀な人材の確保・定着を図るとともに、従業員のモチベーション向上と組織の活性化を目指します。

本資料では、個別賃金管理の基本概念から、定期昇給やベースアップなどの具体的な賃金改定方法、実務上の注意点まで、体系的に解説します。

## 1. 基本概念・定義

### 個別賃金管理の定義
- **定義**: 従業員個々人の職務価値、能力、成果等を個別に評価し、それに基づいて賃金を決定・管理する人事管理手法
- **特徴**: 個人差を明確に反映した賃金体系の構築
- **重要性**: 成果主義・能力主義の浸透に伴い、公正な処遇実現のための必須要素

### 定期昇給
- **定義**: 毎年一定時期に実施される、勤続年数や能力向上に基づく個人別の賃金増額
- **特徴**: 個人の成長・習熟を反映した昇給制度
- **重要性**: 従業員の生活安定と成長意欲の維持

### ベースアップ
- **定義**: 賃金表（賃金テーブル）自体を改定し、全従業員の賃金水準を一律に引き上げる制度
- **特徴**: 物価上昇や企業業績を反映した全体的な賃金改善
- **重要性**: 実質賃金の維持・向上と労使関係の安定

## 2. 賃金改定の種類と分類

### 賃金改定の分類基準
賃金改定は、その対象範囲と改定理由により、以下のように分類されます。

### 定期昇給の詳細
| 項目 | 内容 |
|------|------|
| 特徴 | 個人の査定結果に基づく昇給額の決定 |
| 適用範囲 | 原則として全正社員（ただし昇給額は個人差あり） |
| 昇給額の決定要素 | 人事評価結果、勤続年数、職務グレード |
| 実施時期 | 年1回（4月実施が一般的） |
| 注意点 | 査定基準の明確化と公平性の確保が重要 |

#### 定期昇給の種類
1. **自動昇給**: 勤続年数に応じて自動的に昇給
2. **査定昇給**: 人事評価結果に基づく昇給
3. **昇格昇給**: 職務グレードの上昇に伴う昇給

### ベースアップの詳細
| 項目 | 内容 |
|------|------|
| 特徴 | 賃金テーブル全体のスライド式引き上げ |
| 適用範囲 | 全従業員一律（パート・アルバイトを含む場合も） |
| 決定要素 | 物価上昇率、企業業績、業界水準、労使交渉結果 |
| 実施時期 | 春闘後の4月実施が一般的 |
| 注意点 | 一度実施すると固定費増加となるため慎重な判断が必要 |

### その他の賃金改定
1. **臨時昇給**: 特別な成果や貢献に対する昇給
2. **調整昇給**: 市場価値との乖離を是正するための昇給
3. **降給**: 職務変更や評価結果による賃金減額

## 3. 具体的計算例・事例

### ケース1: 製造業A社（従業員500名）の賃金改定

#### パターンA: 定期昇給のみ実施の場合
- **前提条件**: 
  - 30歳、勤続8年、現在の基本給280,000円
  - 人事評価：A評価（5段階中の上から2番目）
  - 定期昇給率：平均2.0%（A評価は2.5%）

- **計算過程**: 
  ```
  定期昇給額 = 280,000円 × 2.5% = 7,000円
  改定後基本給 = 280,000円 + 7,000円 = 287,000円
  ```

- **結果**: 年間84,000円の賃金増加

#### パターンB: ベースアップ1.5% + 定期昇給実施の場合
- **前提条件**: 同上の従業員、ベースアップ率1.5%

- **計算過程**: 
  ```
  ①ベースアップ額 = 280,000円 × 1.5% = 4,200円
  ②ベースアップ後基本給 = 280,000円 + 4,200円 = 284,200円
  ③定期昇給額 = 284,200円 × 2.5% = 7,105円
  ④改定後基本給 = 284,200円 + 7,105円 = 291,305円
  ```

- **結果**: 年間137,160円の賃金増加

### ケース2: サービス業B社（従業員1,000名）の段階的賃金改定

#### 若手社員（25歳、勤続3年、基本給220,000円）
- **定期昇給**: 3.5%（若手は高めの昇給率）
- **ベースアップ**: 1.0%
- **計算結果**: 
  ```
  最終基本給 = 220,000円 × 1.01 × 1.035 = 229,977円
  月額増加額 = 9,977円
  ```

#### 中堅社員（35歳、勤続12年、基本給350,000円）
- **定期昇給**: 2.0%（標準的な昇給率）
- **ベースアップ**: 1.0%
- **計算結果**: 
  ```
  最終基本給 = 350,000円 × 1.01 × 1.02 = 360,570円
  月額増加額 = 10,570円
  ```

#### ベテラン社員（50歳、勤続25年、基本給500,000円）
- **定期昇給**: 1.0%（高年齢層は低めの昇給率）
- **ベースアップ**: 1.0%
- **計算結果**: 
  ```
  最終基本給 = 500,000円 × 1.01 × 1.01 = 510,050円
  月額増加額 = 10,050円
  ```

## 4. 賃金改定の手続き・プロセス

### 年間スケジュール
1. **1月**: 
   - 前年度の業績確定
   - 賃金改定方針の検討開始
   - 業界他社の動向調査

2. **2月**: 
   - 労働組合との事前協議
   - 賃金改定原資の算定
   - 人事評価の最終確定

3. **3月**: 
   - 春闘交渉（ベースアップ率の決定）
   - 定期昇給の査定作業
   - 個別通知書の作成

4. **4月**: 
   - 新賃金での支給開始
   - 従業員への説明会実施
   - 賃金台帳の更新

### 必要な手続きと書類
- **労使協議関連**: 団体交渉議事録、労使協定書
- **個人通知関連**: 賃金改定通知書、同意書（降給の場合）
- **管理関連**: 賃金台帳、給与計算システムへの反映

### 関連する制度・規則
- **根拠法令**: 労働基準法、最低賃金法
- **社内規程**: 就業規則、賃金規程、人事評価規程
- **労使協定**: 賃金協定、36協定（時間外労働に関する協定）

## 5. 実務上の注意点

### 個別賃金管理導入時の重要ポイント
- **ポイント1**: 評価制度の透明性確保 - 評価基準の明文化と周知徹底
- **ポイント2**: 賃金格差の適正管理 - 同一労働同一賃金の観点からの検証
- **ポイント3**: 既得権の取り扱い - 移行措置の設計と従業員への丁寧な説明

### よくある誤解・トラブル
- **誤解1**: 「定期昇給は必ず実施しなければならない」
  - 正しい理解：定期昇給は労使慣行や就業規則に基づく。業績悪化時は見送りも可能
  
- **誤解2**: 「ベースアップは全員同額でなければならない」
  - 正しい理解：率で実施するため、基本給が高い人ほど増額幅は大きくなる

### 法的リスクへの対応
- **最低賃金法の遵守**: 地域別最低賃金を下回らないよう注意
- **不利益変更の禁止**: 合理的理由なく賃金を引き下げることは原則不可
- **差別的取扱いの禁止**: 性別、年齢、国籍等による不当な賃金差別は違法

## 6. よくある質問（Q&A）

### Q1. 定期昇給とベースアップの違いがよくわかりません。両方実施する必要があるのでしょうか？

**A1.** 定期昇給とベースアップは異なる目的を持つ賃金改定方法です。

#### 詳細な違いの説明
- **定期昇給**: 個人の成長・貢献を反映する「個別的」な賃金改定
  - 例：Aさんは5,000円昇給、Bさんは8,000円昇給（評価による差）
  
- **ベースアップ**: 物価上昇等に対応する「全体的」な賃金改定
  - 例：全員の基本給を一律2%引き上げ

両方実施する必要性は企業の状況により異なります。高インフレ期にはベースアップが重要となり、安定期には定期昇給のみで対応する企業も多いです。

### Q2. 人事評価が低い従業員の定期昇給はゼロにしても問題ないでしょうか？

**A2.** 法的には問題ありませんが、いくつかの注意点があります。

#### 実務的な注意点
1. **就業規則の確認**: 定期昇給に関する規定を確認し、「昇給しない場合がある」旨の記載が必要
2. **評価の妥当性**: 低評価の根拠を明確に説明できることが重要
3. **モチベーションへの影響**: 複数年連続でゼロ昇給は離職リスクを高める
4. **最低限の昇給**: 物価上昇を考慮し、最低限の昇給（0.5～1%）を検討する企業も多い

### Q3. ベースアップを実施した年は、定期昇給を見送ってもよいでしょうか？

**A3.** 制度設計上は可能ですが、従業員の理解を得ることが重要です。

#### 検討すべき観点
- **従業員の期待値**: 多くの企業では両方実施が通例となっている
- **競合他社の動向**: 人材獲得競争上、不利にならないか確認
- **労使関係**: 組合がある場合は、事前の協議が不可欠
- **代替案**: ベースアップ率を高めに設定し、定期昇給相当分を含める方法も

### Q4. 中途採用者の初年度の定期昇給はどう扱うべきでしょうか？

**A4.** 在籍期間に応じた按分計算が一般的です。

#### 具体的な計算例
- **4月入社（定期昇給は翌年4月）**: 満額支給
- **10月入社**: 6ヶ月/12ヶ月 = 50%支給
- **1月入社**: 3ヶ月/12ヶ月 = 25%支給

ただし、即戦力採用の場合は、初年度から満額支給する企業もあります。

## 7. まとめ・今後の展望

個別賃金管理は、従業員一人ひとりの能力・成果に応じた公正な処遇を実現する重要な仕組みです。定期昇給による個人の成長反映と、ベースアップによる生活水準の維持を適切に組み合わせることで、従業員満足度の向上と組織の活性化を図ることができます。

今後は、以下の動向に注目が必要です：
- **ジョブ型雇用の拡大**: 職務価値に基づく賃金決定の重要性増大
- **同一労働同一賃金**: 正規・非正規の格差是正への対応
- **AI活用**: 賃金決定における客観性向上とデータ分析の高度化
- **グローバル化**: 国際的な賃金水準を意識した制度設計

企業は、これらの環境変化に対応しながら、自社の経営戦略と従業員のニーズをバランスよく反映した賃金管理制度の構築が求められています。

<summary>解答</summary>

個別賃金管理の本質は、従業員一人ひとりの能力・成果・貢献度を個別に評価し、それに基づいて賃金を決定することです。<br>

### あ行
**一時金（いちじきん）**
- **読み方**: いちじきん
- **意味**: 賞与など、基本給とは別に支給される臨時的な給付
- **関連用語**: 賞与、ボーナス、決算手当

- **読み方**: いんせんてぃぶ
- **意味**: 成果や業績に連動して支給される報奨金
- **関連用語**: 成果給、業績給、歩合給

- **読み方**: きほんきゅう
- **意味**: 諸手当を除いた、賃金の基礎となる部分
- **関連用語**: 本給、基準内賃金

- **関連用語**: 在職期間、勤務年数
