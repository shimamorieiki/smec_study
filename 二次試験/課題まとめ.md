# 概要
このページは、中小企業診断士の二次試験を特に際し常に頭の中に入れておくべきことをチェックシート形式でまとめたもの


- [ ] 本文から読み取れないことは解答に書かない
- [ ] 必須のキーワードが解答に含まれているかが評価の対象なので、重要語句を全部入れる
- [ ] 1つの要素について長々書かない
- [ ] 一度問題文を抽象的に捉え解答の方向性を決めて、そこから具体に戻すようにする(いきなり具体的な事例から考え始めない)
- [ ] 一次試験で出たワードをフレームワークとして考える
- [ ] 1つの問題で2つ以上設問がある場合にはそれらの関連性を考える
- [ ] 本文に書かれていないことは読み取らないようにするが、一方で、本文に書かれていることから一般的に解釈できる内容については読み取る(=本文に書かれている内容だけで回答が作れるとは限らない)
