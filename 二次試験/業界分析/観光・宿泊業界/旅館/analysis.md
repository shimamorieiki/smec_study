# 観光・宿泊業界の特徴

## 1. 1. 夕食・朝食付き

1. 夕食・朝食付きが基本で料理が宿泊体験の中核を成すため、食材原価率が高く料理人の技術が競争力を左右する。

💡 **対策**
- 専門家・コンサルタントへの相談
- 先進事例の研究・ベンチマーキング
- 補助金・支援制度の活用
- 業界団体・組合との連携
- 段階的・計画的な取組み

## 2. 経営規模

2. 多くが中小規模の家族経営で独自の伝統やおもてなしを継承しているため、後継者不足により老舗旅館でも廃業や売却を余儀なくされる。

💡 **対策**
- 農地・事業基盤の集約化
- 協業・共同化による実質規模拡大
- 作業受委託の活用
- 法人化による組織的経営
- ICT活用による効率化

## 3. 3. 温泉

3. 温泉は他の宿泊施設にない独自の魅力でありリピーターを生むため、温泉地の旅館は高い集客力を持つが温泉資源に依存する。

💡 **対策**
- 専門家・コンサルタントへの相談
- 先進事例の研究・ベンチマーキング
- 補助金・支援制度の活用

- 段階的・計画的な取組み

## 4. 4. 一室あたり

4. 一室あたりの面積が広く和室の設えは固定的で柔軟な運用が困難であるため、ホテルに比べて稼働率が低く収益効率が悪化する。
