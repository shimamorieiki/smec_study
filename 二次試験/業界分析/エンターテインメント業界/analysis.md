# エンターテインメント業界の特徴

## 1. 1. 少数

1. 少数のヒット作品が全体の収益の大部分を占める構造であるため、収益の予見性が低く、ヒット作を生み出せないと経営が急速に悪化する。

💡 **対策**
- 専門家・コンサルタントへの相談
- 先進事例の研究・ベンチマーキング
- 補助金・支援制度の活用
- 業界団体・組合との連携
- 段階的・計画的な取組み

## 2. 2. Netflix、Spotify、Steamなど配信プラットフォーム

2. Netflix、Spotify、Steamなど配信プラットフォームが主流になったため、パッケージ販売が減少し、配信プラットフォームへの依存度が高まっている。

- 段階的・計画的な取組み

## 4. 4. 一つ

4. 一つのIPを映画、アニメ、ゲーム、グッズなど多方面で活用する構造であるため、ヒットIPは莫大な収益を生むが、権利処理が複雑化している。

## 5. 労働力・人材不足

5. コンテンツの質はクリエイターの才能と技術に大きく依存するため、優秀なクリエイター確保が競争力を左右するが、人材不足が深刻化している。

💡 **対策**
- 労働環境の改善による人材確保
- 自動化・機械化による省力化
- 外部委託・協業の活用
- 法人化による組織的雇用
- 多様な人材(女性・高齢者・外国人)の活用
