# 教育・学習支援の特徴

## 1. 需要拡大・市場成長

1. 企業のリスキリング・リカレント教育ニーズが高まっているため、DX人材育成やビジネススキル研修の需要が拡大し法人向けビジネスが成長している。

💡 **対策**
- 専門家・コンサルタントへの相談
- 先進事例の研究・ベンチマーキング
- 補助金・支援制度の活用
- 業界団体・組合との連携
- 段階的・計画的な取組み

## 2. 2. オンライン学習プラットフォームや動画教材

2. オンライン学習プラットフォームや動画教材が普及し低価格で利用可能になったため、対面型の資格スクールは価格競争と顧客流出に直面している。

💡 **対策**
- 専門家・コンサルタントへの相談
- 先進事例の研究・ベンチマーキング

3. 資格取得による就職・転職・昇進のメリットが明確であるため、合格実績と合格率が顧客獲得の最重要指標となり広告でアピールされる。

- 専門家・コンサルタントへの相談

## 4. 4. 司法試験・公認会計士・弁理士など難関資格

4. 司法試験・公認会計士・弁理士など難関資格は受講期間が長く受講料も高額なため、顧客の経済的負担が大きく中途解約リスクもある。

- 専門家・コンサルタントへの相談

## 5. 5. 資格制度

5. 資格制度の改正や試験制度の変更により受験者数が変動するため、特定資格への依存度が高い場合は制度変更が経営に大きく影響する。

- 専門家・コンサルタントへの相談

6. 講師の質と指導力が合格率を左右するため、優秀な講師の確保と育成が競争力の源泉となり講師の引き抜きリスクもある。
