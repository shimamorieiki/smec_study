# 高年齢者等雇用安定法について

## 概要

高年齢者等雇用安定法（高年齢者等の雇用の安定等に関する法律）は、少子高齢化が急速に進展し人口が減少する中で、高年齢者の雇用の確保と就業機会の確保を通じて、その職業生活の充実を図ることを目的とした法律です。1971年に制定され、その後の社会情勢の変化に応じて改正を重ねており、現在では65歳までの雇用確保措置の義務化、70歳までの就業確保措置の努力義務化などが規定されています。

この法律は、企業に対して高年齢者の雇用確保を義務づけるとともに、高年齢者の再就職支援、定年退職者等に対する就業機会の確保等の措置を通じて、高年齢者がその意欲と能力に応じて働き続けることができる社会の実現を目指しています。

## 1. 基本概念・定義

### 高年齢者の定義
- **定義**: 55歳以上の者
- **特徴**: 年齢による一律の区分であり、個人の能力や健康状態は考慮されない
- **重要性**: 法律の適用対象を明確にし、企業の義務の範囲を定める基準となる

### 定年の定義
- **定義**: 労働者が一定の年齢に達したことを退職事由とする制度
- **特徴**: 労働契約や就業規則により定められる
- **重要性**: 雇用確保措置の基準となり、60歳を下回ることはできない

### 継続雇用制度
- **定義**: 現に雇用している高年齢者が希望するときは、当該高年齢者をその定年後も引き続いて雇用する制度
- **特徴**: 再雇用制度と勤務延長制度の2種類がある
- **重要性**: 65歳までの雇用確保措置の選択肢の一つとして最も多く採用されている

## 2. 雇用確保措置の種類

### 65歳までの雇用確保措置（義務）

事業主は、以下のいずれかの措置を講じなければなりません：

### ①定年の引上げ
| 項目 | 内容 |
|------|------|
| 特徴 | 定年年齢を65歳以上に引き上げる |
| 適用範囲 | 全労働者に一律適用 |
| 注意点 | 就業規則の変更が必要、賃金制度の見直しも検討要 |

### ②継続雇用制度の導入
| 項目 | 内容 |
|------|------|
| 特徴 | 定年後も引き続き雇用する制度 |
| 適用範囲 | 希望者全員（経過措置あり） |
| 注意点 | 労働条件の変更可能、グループ企業での雇用も可 |

### ③定年の定めの廃止
| 項目 | 内容 |
|------|------|
| 特徴 | 年齢による退職制度を設けない |
| 適用範囲 | 全労働者 |
| 注意点 | 人事管理の抜本的見直しが必要 |

### 70歳までの就業確保措置（努力義務）

2021年4月より、以下のいずれかの措置を講じる努力義務が課されています：

1. **定年の引上げ**（70歳以上）
2. **継続雇用制度の導入**（70歳まで）
3. **定年の定めの廃止**
4. **創業支援等措置**
   - 70歳まで継続的に業務委託契約を締結する制度
   - 70歳まで継続的に社会貢献事業に従事できる制度

## 3. 具体的計算例・事例

### ケース1: 継続雇用制度における賃金設定

#### パターンA: 定年前賃金の70%で再雇用する場合
- **前提条件**: 
  - 定年前年収：600万円
  - 再雇用後の賃金率：70%
  - 高年齢雇用継続給付金の支給
- **計算過程**: 
  - 再雇用後年収：600万円 × 70% = 420万円
  - 月額賃金：420万円 ÷ 12ヶ月 = 35万円
  - 高年齢雇用継続給付金：賃金低下率30%のため、再雇用後賃金の15%を支給
  - 給付金月額：35万円 × 15% = 52,500円
- **結果**: 
  - 労働者の月収：35万円 + 52,500円 = 402,500円
  - 企業の実質負担：35万円（給付金は雇用保険から支給）

#### パターンB: 定年前賃金の60%で再雇用する場合
- **前提条件**: 
  - 定年前年収：600万円
  - 再雇用後の賃金率：60%
  - 高年齢雇用継続給付金の支給
- **計算過程**: 
  - 再雇用後年収：600万円 × 60% = 360万円
  - 月額賃金：360万円 ÷ 12ヶ月 = 30万円
  - 高年齢雇用継続給付金：賃金低下率40%のため、再雇用後賃金の15%を支給
  - 給付金月額：30万円 × 15% = 45,000円
- **結果**: 
  - 労働者の月収：30万円 + 45,000円 = 345,000円
  - 企業の実質負担：30万円

### ケース2: 段階的な定年引上げ計画

#### 5年間で定年を60歳から65歳に引き上げる企業の例
- **前提条件**: 
  - 現在の定年：60歳
  - 目標：65歳定年
  - 実施期間：5年間
- **実施計画**: 
  - 2024年4月：定年61歳
  - 2025年4月：定年62歳
  - 2026年4月：定年63歳
  - 2027年4月：定年64歳
  - 2028年4月：定年65歳
- **結果**: 
  - 段階的実施により、急激な人件費増加を抑制
  - 各年度の影響を予測し、計画的な対応が可能

## 4. 手続き・プロセス

### 雇用確保措置導入の流れ

1. **ステップ1: 現状分析**
   - 詳細説明：現在の定年制度、継続雇用制度の有無、高年齢者の雇用状況を把握
   - 必要書類：就業規則、労働契約書、従業員名簿
   - 注意点：60歳以上の従業員数と今後の見込みを確認

2. **ステップ2: 制度設計**
   - 詳細説明：3つの選択肢から自社に適した措置を選択し、詳細を設計
   - 必要書類：制度設計案、賃金規程案、労働条件通知書案
   - 注意点：労働組合または労働者代表との協議が重要

3. **ステップ3: 労使協議**
   - 詳細説明：労働組合または労働者の過半数代表者と協議
   - 必要書類：協議記録、労使協定書（継続雇用制度の場合）
   - 注意点：対象者基準を設ける場合は労使協定が必要（経過措置）

4. **ステップ4: 就業規則の変更**
   - 詳細説明：選択した措置に応じて就業規則を変更
   - 必要書類：変更後の就業規則、労働者代表の意見書
   - 注意点：労働基準監督署への届出が必要

5. **ステップ5: 実施・運用**
   - 詳細説明：制度の周知、対象者への説明、実際の運用開始
   - 必要書類：制度説明資料、労働条件通知書
   - 注意点：個別の労働条件は労使で十分協議

### 関連する制度・規則
- **根拠法令**: 高年齢者等の雇用の安定等に関する法律
- **所管官庁**: 厚生労働省
- **関連制度**: 
  - 高年齢雇用継続給付金制度
  - 在職老齢年金制度
  - 高年齢者雇用状況報告制度

## 5. 実務上の注意点

### 継続雇用制度運用の重要ポイント
- **ポイント1**: 労働条件の明確化 - 賃金、労働時間、業務内容を書面で明示
- **ポイント2**: グループ企業での継続雇用 - 特殊関係事業主での雇用も可能
- **ポイント3**: 有期労働契約の更新 - 1年更新が一般的だが、自動更新条項に注意

### よくある誤解・トラブル
- **誤解1**: 「継続雇用は同一労働条件でなければならない」→ 正：労働条件の変更は可能
- **誤解2**: 「希望者全員を65歳まで正社員として雇用必須」→ 正：有期契約での再雇用も可能
- **誤解3**: 「定年後は最低賃金でよい」→ 正：同一労働同一賃金の観点から適正な賃金設定が必要

## 6. よくある質問（Q&A）

### Q1. 継続雇用制度で本人が希望しない職種への配置転換は可能ですか？

**A1.** 原則として、合理的な理由があれば配置転換は可能です。

#### 配置転換が認められる場合の要件
継続雇用における労働条件の設定は、企業に一定の裁量が認められています。ただし、以下の点に注意が必要です：

1. **合理性の要件**：配置転換には業務上の必要性など合理的理由が必要
2. **説明義務**：本人に対して配置転換の理由を十分説明する
3. **過度な不利益の禁止**：著しく不合理な労働条件の提示は継続雇用の拒否とみなされる可能性
4. **能力・経験の考慮**：本人の能力や経験を全く考慮しない配置は問題となる可能性

### Q2. 定年を段階的に引き上げる場合、年齢によって異なる定年を設定できますか？

**A2.** 経過措置として段階的な引上げは可能ですが、同一年齢の労働者には同一の取扱いが必要です。

#### 段階的引上げの具体例
例えば、以下のような経過措置は適法です：
- 2024年4月1日時点で58歳の者：定年63歳
- 2024年4月1日時点で57歳の者：定年64歳
- 2024年4月1日時点で56歳以下の者：定年65歳

ただし、同じ生年の労働者に異なる定年を設定することは、合理的理由がない限り違法となります。

### Q3. 継続雇用制度の対象者を選定する基準は設けられますか？

**A3.** 現在は原則として希望者全員が対象ですが、経過措置により一定の場合は基準設定が可能です。

#### 対象者基準に関する経過措置
2013年改正前からの継続雇用制度で労使協定により対象者基準を定めていた場合、以下の経過措置があります：

1. **2025年3月31日まで**：61歳以上の者について基準適用可能
2. **基準の要件**：
   - 労使協定で定めること
   - 客観的かつ具体的な基準であること
   - 恣意的な運用を防ぐ内容であること

基準の例：
- 直近の健康診断で業務遂行に支障がないこと
- 過去○年間の人事評価が一定以上であること
- 出勤率が○%以上であること

## 7. まとめ・今後の展望

高年齢者等雇用安定法は、日本の少子高齢化という社会課題に対応するための重要な法律です。65歳までの雇用確保措置の義務化により、多くの企業で継続雇用制度が導入され、高年齢者の雇用は着実に進展しています。

今後の展望として、以下の動向が予想されます：
- **70歳就業の一般化**：努力義務から将来的には義務化への移行可能性
- **多様な働き方の拡大**：フリーランス、業務委託など雇用以外の選択肢の充実
- **年齢によらない雇用管理**：ジョブ型雇用の普及に伴う年功序列からの脱却
- **生涯現役社会の実現**：個人の意欲と能力に応じた就業機会の確保

企業には、単に法的義務を果たすだけでなく、高年齢者の知識・経験を活かした戦略的な人事管理が求められています。
