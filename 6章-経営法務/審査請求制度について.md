# 審査請求制度について

## 概要

日本の特許制度では、特許出願をしただけでは自動的に審査が開始されません。原則として、出願人または第三者が「審査請求」を行うことによって初めて実体審査が開始されます。これを「審査請求制度」といいます。この制度は、出願される全ての特許出願を審査することによる審査負担を軽減し、真に特許を必要とする発明のみを審査することで、審査の効率化と迅速化を図ることを目的としています。

## 1. 審査請求制度の基本概念・定義

### 審査請求制度とは
- **定義**: 特許出願後、一定期間内に出願人または第三者が特許庁に対して実体審査を請求する制度
- **特徴**: 出願と審査請求を分離することで、出願人に技術動向や事業化の見通しを検討する時間を与える
- **重要性**: 不要な審査を避け、審査の効率化を図るとともに、出願人の利益を保護する

### 審査請求の主体
- **定義**: 審査請求を行うことができる者
- **特徴**: 出願人だけでなく、第三者も請求可能（ただし、第三者による請求は稀）
- **重要性**: 競合他社が審査請求することで、権利化を阻止または無効理由を発見する機会を得られる

### 審査請求期間
- **定義**: 審査請求を行うことができる法定期間
- **特徴**: 出願日から3年以内（2001年10月1日以降の出願）
- **重要性**: 期間内に請求しないと出願は取り下げたものとみなされる

## 2. 審査請求が必要な権利と不要な権利の分類

### 審査請求が必要な権利

#### 特許権
| 項目 | 内容 |
|------|------|
| 特徴 | 発明の保護を目的とし、最も強力な知的財産権 |
| 審査請求期間 | 出願日から3年以内 |
| 注意点 | 期間内に請求しないと取り下げとみなされる |

### 審査請求が不要な権利（出願後自動的に審査される権利）

#### 実用新案権
| 項目 | 内容 |
|------|------|
| 特徴 | 無審査主義を採用（基礎的要件のみ審査） |
| 登録までの期間 | 出願から約4～6ヶ月 |
| 注意点 | 実体審査なしで登録されるため、権利の有効性は不確実 |

#### 意匠権
| 項目 | 内容 |
|------|------|
| 特徴 | 出願後自動的に実体審査が開始される |
| 審査期間 | 出願から約6～8ヶ月 |
| 注意点 | 審査請求は不要だが、実体審査は行われる |

#### 商標権
| 項目 | 内容 |
|------|------|
| 特徴 | 出願後自動的に実体審査が開始される |
| 審査期間 | 出願から約8～10ヶ月 |
| 注意点 | 審査請求は不要だが、実体審査は行われる |

## 3. 具体的計算例・事例

### ケース1: 特許出願の審査請求期限の計算

#### パターンA: 通常の出願の場合
- **前提条件**: 
  - 出願日：2022年4月15日
  - 優先権主張なし
- **計算過程**: 
  - 起算日：2022年4月15日
  - 3年後：2025年4月15日
- **結果**: 2025年4月15日までに審査請求が必要

#### パターンB: 優先権主張を伴う出願の場合
- **前提条件**: 
  - 優先日：2021年10月1日
  - 日本への出願日：2022年9月30日
- **計算過程**: 
  - 審査請求期限の起算日：2022年9月30日（実際の出願日）
  - 3年後：2025年9月30日
- **結果**: 2025年9月30日までに審査請求が必要（優先日からではない）

### ケース2: 審査請求料の計算

#### パターンA: 請求項数が10項の場合
- **前提条件**: 
  - 基本料金：138,000円
  - 加算料金：4,000円×請求項数
  - 請求項数：10項
- **計算過程**: 
  - 基本料金：138,000円
  - 加算料金：4,000円×10項＝40,000円
  - 合計：138,000円＋40,000円＝178,000円
- **結果**: 審査請求料は178,000円

#### パターンB: 請求項数が30項の場合
- **前提条件**: 
  - 基本料金：138,000円
  - 加算料金：4,000円×請求項数
  - 請求項数：30項
- **計算過程**: 
  - 基本料金：138,000円
  - 加算料金：4,000円×30項＝120,000円
  - 合計：138,000円＋120,000円＝258,000円
- **結果**: 審査請求料は258,000円

## 4. 審査請求の手続き・プロセス

### 審査請求の手続きの流れ

1. **ステップ1: 審査請求の検討**
   - 詳細説明：技術動向、事業化の見通し、競合他社の動向を検討
   - 必要書類：出願書類の写し、先行技術調査結果
   - 注意点：一度審査請求すると取り下げできない

2. **ステップ2: 審査請求書の作成**
   - 詳細説明：所定の様式に従って審査請求書を作成
   - 必要書類：審査請求書（特許法施行規則様式第31）
   - 注意点：出願番号、請求人の記載に誤りがないか確認

3. **ステップ3: 審査請求料の納付**
   - 詳細説明：特許印紙または電子納付により手数料を納付
   - 必要書類：納付書（紙出願の場合）
   - 注意点：請求項数に応じた正確な金額を納付

4. **ステップ4: 審査請求書の提出**
   - 詳細説明：特許庁へ提出（電子出願または書面）
   - 必要書類：審査請求書、委任状（代理人の場合）
   - 注意点：提出期限に遅れないよう余裕を持って手続き

### 関連する制度・規則
- **根拠法令**: 特許法第48条の2～第48条の7
- **所管官庁**: 特許庁
- **関連制度**: 早期審査制度、優先審査制度、審査請求料返還制度

## 5. 実務上の注意点

### 実務での重要ポイント
- **ポイント1**: 審査請求期限の管理は知財管理の最重要事項。期限管理システムの導入が推奨される
- **ポイント2**: 第三者による審査請求の可能性を考慮し、重要な出願は早期に審査請求を検討
- **ポイント3**: 審査請求前に請求項の整理・補正を行うことで、審査請求料を削減可能

### よくある誤解・トラブル
- **誤解1**: 「優先権主張をした場合、優先日から3年以内に審査請求が必要」→ 正しくは実際の出願日から3年
- **誤解2**: 「審査請求をすれば必ず特許になる」→ 審査請求は審査開始の要件に過ぎず、特許性の判断は別

## 6. よくある質問（Q&A）

### Q1. 審査請求期限を過ぎてしまった場合、救済措置はありますか？

**A1.** 原則として救済措置はありません。審査請求期限（出願日から3年）を過ぎると、その出願は取り下げたものとみなされます。

#### 例外的な救済措置
ただし、以下の場合には回復が認められる可能性があります：
- 正当な理由がある場合（天災、重大な病気等）
- 期限経過後2ヶ月以内に回復理由書を提出
- 回復手数料（213,000円）の納付

実務上は、期限管理の不備による失効は「正当な理由」として認められないため、確実な期限管理が必要です。

### Q2. 共同出願の場合、審査請求は誰が行う必要がありますか？

**A2.** 共同出願人の誰か一人が審査請求を行えば、出願全体について審査が開始されます。

#### 実務上の注意点
- 共同出願契約で審査請求の費用負担や手続き担当者を明確にしておく
- 一方の出願人が審査請求を希望しない場合でも、他方が単独で請求可能
- 審査請求料は請求を行った者が負担するのが原則だが、契約で別途定めることも可能

### Q3. 分割出願の審査請求期限はどのように計算しますか？

**A3.** 分割出願の審査請求期限は、原出願の出願日から3年または分割出願日から30日のいずれか遅い日までです。

#### 具体例
- 原出願日：2021年4月1日
- 分割出願日：2024年2月1日
- 原出願日から3年：2024年4月1日
- 分割出願日から30日：2024年3月2日
- 審査請求期限：2024年4月1日（いずれか遅い日）

## 7. まとめ・今後の展望

審査請求制度は、日本の特許制度の特徴的な制度であり、出願人に技術・市場動向を見極める時間を与えるとともに、特許庁の審査負担を軽減する重要な役割を果たしています。一方で、実用新案、意匠、商標については審査請求が不要で、出願後自動的に審査が開始される点が大きな違いです。

今後は、国際的な制度調和の観点から、審査請求期間の見直しや、AI技術を活用した審査の効率化などが検討される可能性があります。また、スタートアップ支援の観点から、審査請求料の減免制度の拡充も期待されています。

<summary>解答</summary>

## 9. 専門用語集

### あ行

**意匠権（いしょうけん）**
- **読み方**: いしょうけん
- **意味**: 物品の形状、模様、色彩などのデザインを保護する知的財産権。出願後自動的に審査が開始され、審査請求は不要
- **関連用語**: 部分意匠、関連意匠、秘密意匠

### か行

**拒絶査定（きょぜつさてい）**
- **読み方**: きょぜつさてい
- **意味**: 特許庁の審査官が、出願された発明が特許要件を満たさないと判断して下す処分
- **関連用語**: 拒絶理由通知、意見書、補正書

**拒絶理由通知（きょぜつりゆうつうち）**
- **読み方**: きょぜつりゆうつうち
- **意味**: 審査官が特許要件を満たさないと判断した理由を出願人に通知する文書
- **関連用語**: 意見書、補正書、応答期限

### さ行

**実用新案権（じつようしんあんけん）**
- **読み方**: じつようしんあんけん
- **意味**: 物品の形状、構造、組合せに関する考案を保護する権利。無審査主義を採用
- **関連用語**: 技術評価書、進歩性、実用新案登録

**審査請求（しんさせいきゅう）**
- **読み方**: しんさせいきゅう
- **意味**: 特許出願について実体審査を開始するよう特許庁に請求する手続き
- **関連用語**: 審査請求期限、審査請求料、第三者請求

**審査請求期限（しんさせいきゅうきげん）**
- **読み方**: しんさせいきゅうきげん
- **意味**: 特許出願について審査請求を行うことができる法定期間。出願日から3年以内
- **関連用語**: みなし取下げ、期限管理、回復手続き

**審査請求料（しんさせいきゅうりょう）**
- **読み方**: しんさせいきゅうりょう
- **意味**: 審査請求を行う際に特許庁に納付する手数料。基本料金＋請求項数に応じた加算料金
- **関連用語**: 減免制度、料金納付、特許印紙

**商標権（しょうひょうけん）**
- **読み方**: しょうひょうけん
- **意味**: 商品やサービスに使用する標章（マーク）を保護する権利。出願後自動的に審査開始
- **関連用語**: 指定商品・役務、区分、更新登録

### た行

**第三者請求（だいさんしゃせいきゅう）**
- **読み方**: だいさんしゃせいきゅう
- **意味**: 出願人以外の第三者が行う審査請求。競合他社が早期の権利化阻止等を目的に行うことがある
- **関連用語**: 情報提供、異議申立、無効審判

**特許印紙（とっきょいんし）**
- **読み方**: とっきょいんし
- **意味**: 特許庁への手数料納付に使用される印紙。審査請求料等の納付に使用
- **関連用語**: 予納、電子納付、現金納付

**特許権（とっきょけん）**
- **読み方**: とっきょけん
- **意味**: 発明を独占的に実施できる権利。審査請求が必要で、出願だけでは審査されない
- **関連用語**: 特許要件、新規性、進歩性

**特許査定（とっきょさてい）**
- **読み方**: とっきょさてい
- **意味**: 審査官が出願された発明が特許要件を満たすと判断して下す処分
- **関連用語**: 設定登録、特許料、特許証

### は行

**PCT国際出願（ぴーしーてぃーこくさいしゅつがん）**
- **読み方**: ぴーしーてぃーこくさいしゅつがん
- **意味**: 特許協力条約に基づく国際出願。一つの出願で複数国への出願効果を得られる
- **関連用語**: 国内移行、国際調査、優先権

**分割出願（ぶんかつしゅつがん）**
- **読み方**: ぶんかつしゅつがん
- **意味**: 一つの出願を二以上の出願に分ける手続き。審査請求期限に特別な規定あり
- **関連用語**: 原出願、分割要件、遡及効

### ま行

**みなし取下げ（みなしとりさげ）**
- **読み方**: みなしとりさげ
- **意味**: 審査請求期限内に審査請求がなされなかった出願が、取り下げたものとみなされること
- **関連用語**: 審査請求期限、回復手続き、正当理由

**無審査主義（むしんさしゅぎ）**
- **読み方**: むしんさしゅぎ
- **意味**: 実体的な審査を行わずに権利を付与する制度。日本では実用新案が採用
- **関連用語**: 実用新案、技術評価書、権利行使

### や行

**優先権（ゆうせんけん）**
- **読み方**: ゆうせんけん
- **意味**: 先の出願に基づいて、後の出願の新規性等の判断基準日を先の出願日とする制度
- **関連用語**: パリ条約、優先期間、優先権主張

**優先審査（ゆうせんしんさ）**
- **読み方**: ゆうせんしんさ
- **意味**: 一定の要件を満たす出願について、通常より早く審査を行う制度
- **関連用語**: 早期審査、スーパー早期審査、審査順番待ち期間

### ら行

**料金減免制度（りょうきんげんめんせいど）**
- **読み方**: りょうきんげんめんせいど
- **意味**: 中小企業や個人等が一定要件を満たす場合に、審査請求料等が減額または免除される制度
- **関連用語**: 中小企業、減免申請、証明書類
