# 地域未来投資促進法について

## 法律の概要と背景

地域未来投資促進法（正式名称：地域経済牽引事業の促進による地域の成長発展の基盤強化に関する法律）は、2017年（平成29年）7月に施行された法律です。地域の特性を活かした成長性の高い新たな分野に挑戦する地域中核企業等の取組（地域経済牽引事業）を支援し、地域経済の活性化を図ることを目的としています。

本法は、従来の企業立地促進法を改正・強化したもので、製造業だけでなく、観光・スポーツ・文化・まちづくり、農林水産、地域商社、環境・エネルギー、ヘルスケア・教育サービスなど、幅広い事業分野を対象としています。人口減少が進む中で、地域の特性を生かした事業により地域経済を牽引し、地域の成長発展の基盤を強化することが期待されています。

## 1. 基本概念・定義

### 地域経済牽引事業
- **定義**: 地域の特性を生かして高い付加価値を創出し、地域の事業者に対する相当の経済的効果を及ぼすことにより、地域の経済成長を力強く牽引する事業
- **特徴**: 
  - 地域の特性（技術、特産物、観光資源、エネルギー、インフラ等）を活用
  - 高い付加価値の創出が見込まれる
  - 地域の取引拡大、雇用創出等が期待される
- **重要性**: 地域経済の活性化と持続的発展に寄与

### 地域経済牽引事業促進協議会
- **定義**: 都道府県と市町村が共同で組織し、地域経済牽引事業の促進に関する協議を行う組織
- **特徴**: 
  - 官民連携による支援体制
  - 地域の実情に応じた柔軟な運営
  - 事業者への一元的な支援窓口機能
- **重要性**: 事業の円滑な実施と地域全体での取組推進

### 基本計画
- **定義**: 都道府県と市町村が共同で策定する、地域経済牽引事業の促進に関する基本的な計画
- **特徴**: 
  - 地域の特性と強みを明確化
  - 促進する事業分野を特定
  - 国の同意を得て策定
- **重要性**: 地域の戦略的な産業振興の指針となる

## 2. 支援措置の分類・種類

### 支援措置の分類基準
地域未来投資促進法に基づく支援措置は、事業の性質や必要とする支援内容により、以下のように分類されます。

### 規制の特例措置
| 項目 | 内容 |
|------|------|
| 特徴 | 農地転用許可、市街化調整区域の開発許可等の手続きワンストップ化・迅速化 |
| 適用範囲 | 土地利用調整が必要な事業 |
| 注意点 | 事前に土地利用調整計画の作成が必要 |

### 財政・金融支援
| 項目 | 内容 |
|------|------|
| 特徴 | 地方創生推進交付金の活用、日本政策金融公庫による低利融資 |
| 適用範囲 | 設備投資、技術開発、販路開拓等 |
| 注意点 | 事業計画の承認が前提条件 |

### 税制支援
| 項目 | 内容 |
|------|------|
| 特徴 | 設備投資に対する特別償却または税額控除、固定資産税の減免 |
| 適用範囲 | 先進的な設備投資を行う事業 |
| 注意点 | 設備の要件、投資規模の基準あり |

## 3. 具体的計算例・事例

### ケース1: 製造業による設備投資の税制優遇

#### パターンA: 特別償却を選択した場合
- **前提条件**: 
  - 機械装置の取得価額：1億円
  - 特別償却率：40%
  - 通常の減価償却率：10%（定率法）
- **計算過程**: 
  - 初年度の特別償却額：1億円 × 40% = 4,000万円
  - 初年度の普通償却額：1億円 × 10% = 1,000万円
  - 初年度の合計償却額：4,000万円 + 1,000万円 = 5,000万円
- **結果**: 初年度に5,000万円の償却が可能（通常より4,000万円多い）

#### パターンB: 税額控除を選択した場合
- **前提条件**: 
  - 機械装置の取得価額：1億円
  - 税額控除率：4%（上限あり）
  - 法人税額：2,000万円
- **計算過程**: 
  - 税額控除額：1億円 × 4% = 400万円
  - 控除上限：法人税額 × 20% = 400万円
  - 適用可能な税額控除：400万円（上限内）
- **結果**: 法人税から400万円の控除が可能

### ケース2: 観光事業による地域経済への波及効果

#### 体験型観光施設の整備
- **前提条件**: 
  - 初期投資額：5億円
  - 年間来場者数目標：20万人
  - 客単価：5,000円
- **計算過程**: 
  - 直接的な売上：20万人 × 5,000円 = 10億円/年
  - 地域への経済波及効果（産業連関分析による推計）：
    - 原材料調達による効果：2億円
    - 雇用創出効果：100名（給与総額3億円）
    - 観光客の周辺消費：5億円
- **結果**: 年間20億円の地域経済効果を創出

## 4. 手続き・プロセス

### 地域経済牽引事業計画の承認手続き

1. **ステップ1: 基本計画の確認**
   - 詳細説明：事業を実施する地域の基本計画を確認し、自社の事業が該当するか判断
   - 必要書類：都道府県・市町村が公表している基本計画
   - 注意点：基本計画に記載された促進分野と整合性が必要

2. **ステップ2: 事業計画の作成**
   - 詳細説明：地域経済牽引事業計画を作成し、必要な添付書類を準備
   - 必要書類：
     - 地域経済牽引事業計画申請書
     - 事業の内容を説明する資料
     - 財務諸表（直近3期分）
     - 投資計画書
   - 注意点：数値目標は具体的かつ実現可能なものにする

3. **ステップ3: 都道府県知事への申請**
   - 詳細説明：作成した計画を都道府県知事に提出し、承認を申請
   - 必要書類：ステップ2で準備した全書類
   - 注意点：市町村を経由する場合もあるため、事前確認が必要

4. **ステップ4: 審査・承認**
   - 詳細説明：都道府県による審査を経て、要件を満たす場合は承認
   - 必要書類：追加資料の提出を求められる場合あり
   - 注意点：審査期間は概ね1～2か月程度

### 関連する制度・規則
- **根拠法令**: 地域経済牽引事業の促進による地域の成長発展の基盤強化に関する法律（平成19年法律第40号）
- **所管官庁**: 経済産業省、関係省庁
- **関連制度**: 
  - 地方創生推進交付金
  - ものづくり補助金
  - 地域未来牽引企業認定制度

## 5. 実務上の注意点

### 事業計画作成時の重要ポイント
- **ポイント1**: 地域の特性との関連性を明確に示す
  - 単なる事業拡大ではなく、地域資源の活用が重要
- **ポイント2**: 経済波及効果の算定根拠を明確にする
  - 取引先への影響、雇用創出効果等を定量的に示す
- **ポイント3**: 実現可能性の高い計画とする
  - 過度に楽観的な計画は承認されにくい

### よくある誤解・トラブル
- **誤解1**: 「製造業以外は対象外」
  - 正しい理解：サービス業、観光業等も幅広く対象となる
- **誤解2**: 「大企業は支援を受けられない」
  - 正しい理解：企業規模に関わらず、要件を満たせば支援対象となる
- **誤解3**: 「承認を受ければ自動的に補助金がもらえる」
  - 正しい理解：承認は支援措置を受けるための前提条件であり、個別の支援措置には別途申請が必要

## 6. よくある質問（Q&A）

### Q1. 地域経済牽引事業計画の承認を受けるメリットは何ですか？

**A1.** 主なメリットとして、①税制優遇（設備投資減税）、②規制緩和（農地転用許可等の迅速化）、③財政支援（補助金の優先採択）、④金融支援（低利融資）、⑤情報支援などがあります。

#### メリットの詳細説明
税制面では、機械装置等の取得に対して最大40%の特別償却または4%の税額控除が適用されます。また、自治体によっては固定資産税の減免措置も受けられます。規制面では、工場立地法の緑地面積率の緩和や、農地転用許可、市街化調整区域の開発許可等の手続きがワンストップ化され、通常より迅速に処理されます。

### Q2. どのような事業が地域経済牽引事業として認められますか？

**A2.** 地域の特性を活用し、高い付加価値を創出し、地域への経済波及効果が見込まれる事業が対象です。具体的には、製造業の高度化、観光・スポーツ・文化、農林水産・地域商社、環境・エネルギー、ヘルスケア・教育等の分野が含まれます。

#### 認定基準の詳細
事業が認められるためには、以下の3つの要件を満たす必要があります：
1. 地域の特性を活用していること（地域の強みを生かした事業であること）
2. 高い付加価値を創出すること（付加価値額の目標が年間1億円以上等）
3. 地域の事業者への経済的波及効果があること（取引額の増加率が一定以上等）

## 7. まとめ・今後の展望

地域未来投資促進法は、地域の特性を活かした事業による地域経済の活性化を目指す重要な制度です。製造業のみならず、サービス業や観光業など幅広い分野を対象とし、税制・金融・規制緩和等の総合的な支援措置により、地域経済を牽引する事業の創出・育成を図っています。

今後は、デジタル技術の活用やグリーン分野への投資など、新たな成長分野への展開が期待されています。また、地域間連携やサプライチェーンの強靱化といった観点からも、本制度の重要性は高まっていくと考えられます。事業者においては、地域の特性を十分に理解し、それを活かした独自性のある事業計画を策定することが成功の鍵となるでしょう。
