# UPS(無停電電源装置)について

## 概要
UPS（Uninterruptible Power Supply：無停電電源装置）は、停電や電圧変動などの電源障害から電子機器を保護する装置です。商用電源が停止した際に、内蔵バッテリーから電力を供給し続けることで、接続されたシステムの安全な停止や継続運転を可能にします。データセンター、病院、金融機関、製造業など、電源の安定性が業務継続に不可欠な分野で広く利用されています。

## 1. 基本概念・仕組み

### UPSの基本動作原理
- **定義**: 商用電源の異常時に、瞬時に内蔵バッテリーからの給電に切り替えて、接続機器への電力供給を継続する装置
- **動作原理**: 
  - 通常時：商用電源から電力を供給しながら、同時にバッテリーを充電
  - 停電時：バッテリーから直流電力を交流に変換（インバータ）して供給
  - 復電時：商用電源に自動的に切り替わり、バッテリー充電を再開
- **特徴**: 
  - 瞬断のない電力供給（切替時間0ms〜10ms程度）
  - 電圧・周波数の安定化
  - サージ・ノイズの除去

### 電源障害の種類と対策
- **従来技術との違い**: 
  - 発電機：起動に時間がかかる（数秒〜数十秒）
  - サージプロテクタ：瞬間的な過電圧のみ対応
  - AVR（自動電圧調整器）：停電には対応不可
- **改善点**: 
  - 瞬時切替による無瞬断給電
  - 複数の電源障害への包括的な対応
  - 自動化された障害検知と切替
- **限界**: 
  - バッテリー容量による給電時間の制限
  - 定期的なバッテリー交換の必要性
  - 設置スペースとコスト

## 2. 種類・分類

### 給電方式による分類
UPSは給電方式により、主に3つのタイプに分類されます。それぞれ異なる特性を持ち、用途に応じて選択されます。

### 常時商用給電方式（オフライン方式）
**特徴:**
- 通常時は商用電源をそのまま負荷に供給
- 停電検知後にインバータ給電に切り替え
- 構造がシンプルで低コスト

**算出方法:**
```
切替時間 = 停電検知時間 + リレー切替時間
　　　　 = 2〜4ms + 2〜6ms
　　　　 = 4〜10ms
```

**📊 具体的な計算例**
**例: 500VAのPC環境での選定**
- 前提条件1: PC消費電力 300W（力率0.6）
- 前提条件2: モニター消費電力 50W

**ステップ1: 皮相電力の計算**
```
PC皮相電力 = 300W ÷ 0.6 = 500VA
総皮相電力 = 500VA + 50VA = 550VA
```

**ステップ2: UPS容量の選定**
```
必要容量 = 550VA × 1.2（余裕率） = 660VA
→ 750VA以上のUPSを選定
```

**結果: 750VAのオフライン式UPSを選定**

💡 **実際の現場では**: 低コストで個人用PCや小規模オフィスに適していますが、切替時の瞬断があるため、高可用性が求められるサーバーには不適です。

### ラインインタラクティブ方式
**特徴:**
- AVR（自動電圧調整器）を内蔵
- 軽微な電圧変動はAVRで対応
- 停電時のみバッテリー給電

**算出方法:**
```
電圧補正範囲 = ±10〜15%（商用電源電圧に対して）
AVR応答時間 = 2〜4ms
バッテリー切替時間 = 2〜4ms
```

**📊 具体的な計算例**
**例: 小規模サーバールームでの選定（定格2kVA）**
- 前提条件1: サーバー5台 各300W（力率0.7）
- 前提条件2: ネットワーク機器 200W

**ステップ1: 総消費電力の計算**
```
サーバー総電力 = 300W × 5台 = 1,500W
サーバー皮相電力 = 1,500W ÷ 0.7 = 2,143VA
総皮相電力 = 2,143VA + 200VA = 2,343VA
```

**ステップ2: バックアップ時間の計算**
```
バッテリー容量：12V × 9Ah × 4個 = 432Wh
バックアップ時間 = 432Wh ÷ 1,700W × 0.7（効率） 
                 = 約11分
```

**結果: 3kVAのラインインタラクティブ式UPSで約11分のバックアップ**

💡 **実際の現場では**: 中小規模のサーバールームで広く採用。電圧変動が頻繁な地域では、バッテリー寿命を延ばす効果があります。

### 常時インバータ給電方式（オンライン方式）
**特徴:**
- 常時インバータ経由で給電
- 完全な無瞬断切替（0ms）
- 最も高品質な電力供給

**算出方法:**
```
効率 = 出力電力 ÷ 入力電力 × 100
　　 = 90〜95%（最新機種）
発熱量 = 入力電力 × (1 - 効率)
```

**📊 具体的な計算例**
**例: データセンターでの大容量UPS選定（100kVA）**
- 前提条件1: IT機器負荷 80kW（力率0.9）
- 前提条件2: 必要バックアップ時間 10分

**ステップ1: UPS容量の確認**
```
皮相電力 = 80kW ÷ 0.9 = 88.9kVA
負荷率 = 88.9kVA ÷ 100kVA = 88.9%（適正範囲内）
```

**ステップ2: バッテリー容量の計算**
```
必要電力量 = 80kW × 10分 ÷ 60 = 13.3kWh
バッテリー電圧：480V（40個×12V）
必要容量 = 13.3kWh ÷ 480V ÷ 0.8（放電深度） = 34.6Ah
→ 40Ah以上のバッテリーを選定
```

**結果: 100kVAオンライン式UPS + 480V40Ahバッテリー**

💡 **実際の現場では**: ミッションクリティカルなシステムでは必須。初期投資は高いが、電力品質の向上により機器寿命が延び、トータルコストでは有利になることも。

## 3. 詳細仕様・パラメータ

### 重要な仕様項目
#### 定格容量の詳細
- **意味**: UPSが連続的に供給可能な最大電力
- **設定範囲**: 300VA〜数MVA
- **影響**: 接続可能な機器の総容量を決定
- **推奨値**: 実負荷の1.2〜1.5倍

#### バックアップ時間の詳細
- **意味**: 停電時に給電を継続できる時間
- **設定範囲**: 5分〜数時間
- **影響**: システムの安全停止や発電機起動までの時間確保
- **推奨値**: 
  - PC用：5〜10分（安全なシャットダウン）
  - サーバー用：10〜30分（データ保存と正常停止）
  - 重要設備：30分〜2時間（発電機起動まで）

#### 切替時間の詳細
- **意味**: 商用電源からバッテリー給電への切替に要する時間
- **設定範囲**: 0ms（オンライン）〜10ms（オフライン）
- **影響**: 接続機器の電源保持時間との関係
- **推奨値**: 
  - 一般IT機器：10ms以下
  - 高感度機器：4ms以下
  - 医療機器：0ms（オンライン式）

#### 入力電圧範囲の詳細
- **意味**: UPSが正常動作する入力電圧の範囲
- **設定範囲**: 定格電圧の±10%〜±25%
- **影響**: 電圧変動時のバッテリー使用頻度
- **推奨値**: できるだけ広い範囲（±20%以上）

## 4. 実装例・適用事例

### 基本的な接続構成
```
[商用電源] → [ブレーカー] → [UPS] → [分電盤] → [負荷機器]
                               ↓
                          [バッテリー]
                               ↓
                          [監視システム]
```

### 冗長構成の実装
```
[商用電源A] → [UPS-A] → [STS] → [負荷機器]
                          ↑↓
[商用電源B] → [UPS-B] → [STS]

※STS: Static Transfer Switch（静止型切替スイッチ）
```

### 実際の適用事例
#### 事例1: 中規模病院の電子カルテシステム
- **課題**: 瞬断も許されない24時間365日稼働の電子カルテ
- **適用方法**: 
  - 20kVAオンライン式UPS×2台（N+1冗長）
  - バックアップ時間30分
  - 自家発電装置との連動
- **結果**: 5年間無停止稼働を達成
- **効果**: 
  - 患者データの完全保護
  - 医療ミスリスクの排除
  - 災害時の業務継続性確保

#### 事例2: 製造業の生産ライン制御
- **課題**: 瞬断による生産ライン停止で数千万円の損失
- **適用方法**: 
  - 50kVAラインインタラクティブ式UPS
  - 重要なPLCとサーバーのみ保護
  - リモート監視システム導入
- **結果**: 電源トラブルによる生産停止ゼロ
- **効果**: 
  - 年間5回の瞬断を完全カバー
  - 不良品発生率80%削減
  - ROI（投資回収）2年で達成

#### 事例3: 金融機関のオンライン取引システム
- **課題**: ミリ秒単位の取引処理で収益が左右される
- **適用方法**: 
  - 200kVAオンライン式UPS×4台（2N冗長）
  - フライホイール式との併用
  - AIによる予防保守
- **結果**: 可用性99.9999%（シックスナイン）達成
- **効果**: 
  - 取引機会損失ゼロ
  - 顧客信頼度の大幅向上
  - 規制要件の完全準拠

## 5. メリット・デメリット

### メリット
**1. 電源トラブルからの完全な保護**
- **理由**: 停電・瞬断・電圧変動・周波数変動・ノイズなど、あらゆる電源異常に対応
- **効果**: システムの安定稼働とデータ保護
- **具体例**: 落雷による瞬断でもサーバーは正常稼働を継続

**2. 計画的なシステム停止が可能**
- **理由**: バッテリー給電により、安全な手順でのシャットダウン時間を確保
- **効果**: データ損失やシステム破損の防止
- **具体例**: 停電時に自動的にデータベースをクローズし、OSを正常終了

**3. 電力品質の向上**
- **理由**: 特にオンライン式では、常に安定した電圧・周波数を供給
- **効果**: 接続機器の寿命延長と故障率低下
- **具体例**: 電圧変動±15%の環境でも、出力は±1%以内に安定化

**4. 運用の自動化**
- **理由**: 各種監視・制御機能により、無人での障害対応が可能
- **効果**: 人的コストの削減と対応の迅速化
- **具体例**: 深夜の停電でも自動でサーバーシャットダウンとメール通知

### デメリット
**1. 初期投資コストが高い**
- **理由**: 本体価格に加え、設置工事・バッテリーなどの費用
- **影響**: 小規模事業者には導入障壁
- **対策**: 
  - リース・レンタルの活用
  - 段階的な導入計画
  - 費用対効果の明確化

**2. 定期的なメンテナンスが必要**
- **理由**: バッテリーの劣化、ファンやコンデンサの寿命
- **影響**: 
  - バッテリー交換（3〜5年毎）
  - 年次点検費用
  - メンテナンス時の切替作業
- **対策**: 
  - 予防保守契約の締結
  - 冗長構成での交互メンテナンス
  - リモート監視による状態把握

**3. 設置スペースと環境条件**
- **理由**: 本体・バッテリーの設置スペース、適切な温度管理が必要
- **影響**: 
  - 専用の電気室やラックスペース
  - 空調設備の追加
  - 床荷重の考慮（大型UPS）
- **対策**: 
  - 高密度実装タイプの選択
  - モジュラー型による分散配置
  - 屋外設置対応型の検討

**4. バッテリー寿命と廃棄問題**
- **理由**: 鉛蓄電池の劣化と環境負荷
- **影響**: 
  - 3〜5年でのバッテリー交換
  - 産業廃棄物としての処理コスト
  - 環境規制への対応
- **対策**: 
  - リチウムイオン電池の採用
  - バッテリーリサイクルシステムの活用
  - 寿命予測システムによる最適交換時期の判定

## 6. 選択・導入の指針

### UPS選択の基準
| 観点 | オフライン式 | ラインインタラクティブ式 | オンライン式 |
|------|-----------|----------------------|------------|
| 電力品質 | △ | ○ | ◎ |
| 切替時間 | △（4-10ms） | ○（2-4ms） | ◎（0ms） |
| コスト | ◎ | ○ | △ |
| 効率 | ◎（95%以上） | ○（90-95%） | △（85-95%） |
| 騒音 | ◎（ファンレス可） | ○ | △ |
| 適用規模 | 個人・小規模 | 中規模 | 大規模・重要システム |

### 適用判断フローチャート
1. **負荷の重要度は？** 
   - 人命に関わる・金融取引 → オンライン式
   - 一般業務システム → 次の判断へ

2. **許容できる瞬断時間は？**
   - 0ms必須 → オンライン式
   - 4ms以下 → ラインインタラクティブ式  
   - 10ms以下で可 → オフライン式

3. **予算の制約は？**
   - 初期投資重視 → オフライン式
   - TCO（総所有コスト）重視 → 用途に応じて最適選択

4. **設置環境は？**
   - 電圧変動が激しい → ラインインタラクティブ式以上
   - 安定している → 全タイプ選択可

### 容量選定の実践的指針
```
必要容量 = Σ(各機器の消費電力) ÷ 力率 × 余裕率 × 将来拡張率

余裕率：1.2〜1.3（通常）、1.5（重要システム）
将来拡張率：1.2〜1.5（3〜5年先を想定）
```

## 8. 理解度確認クイズ（4択問題20問）

### 問題1
UPSの基本的な役割として、最も適切なものはどれか？

- A) 電気料金を削減する装置
- B) 停電時に電力供給を継続する装置
- C) 発電を行う装置
- D) 電圧を上昇させる装置

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
UPS（無停電電源装置）の基本的な役割は、停電や電源異常時に内蔵バッテリーから電力を供給し続けることです。<br>
<br>
Aが間違いの理由：UPSは電気料金削減が主目的ではありません<br>
Cが間違いの理由：UPSは発電装置ではなく、蓄電した電力を供給する装置です<br>
Dが間違いの理由：電圧上昇（昇圧）は主目的ではなく、安定した電圧を供給することが目的です<br>
<br>
【補足】実務では、UPSは停電対策だけでなく、電圧変動やノイズからも機器を保護します。
</details>

### 問題2
オンライン方式UPSの切替時間として正しいものはどれか？

- A) 10ミリ秒
- B) 4ミリ秒
- C) 2ミリ秒
- D) 0ミリ秒

<details>
<summary>解答</summary>
<strong>正解: D</strong><br>
オンライン方式（常時インバータ給電方式）は、常にインバータを経由して電力を供給しているため、停電時の切替時間は0ミリ秒（無瞬断）です。<br>
<br>
Aが間違いの理由：10ミリ秒はオフライン方式の典型的な切替時間です<br>
Bが間違いの理由：4ミリ秒はラインインタラクティブ方式の切替時間です<br>
Cが間違いの理由：2ミリ秒という仕様は一般的ではありません<br>
<br>
【補足】医療機器や金融システムなど、瞬断が許されない用途ではオンライン方式が必須です。
</details>

### 問題3
500W（力率0.7）の機器に必要なUPSの皮相電力（VA）はどれか？

- A) 350VA
- B) 500VA
- C) 714VA
- D) 1000VA

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
皮相電力（VA） = 有効電力（W） ÷ 力率<br>
= 500W ÷ 0.7 = 714VA<br>
<br>
Aが間違いの理由：350VAは500W × 0.7で、逆の計算をしています<br>
Bが間違いの理由：500VAは力率を考慮していません<br>
Dが間違いの理由：1000VAは過大な値です<br>
<br>
【補足】実際の選定では、計算値の1.2〜1.3倍の容量を選ぶことが推奨されます。この場合、1000VA程度のUPSを選定するのが適切です。
</details>

### 問題4
ラインインタラクティブ方式の特徴として誤っているものはどれか？

- A) AVR（自動電圧調整器）を内蔵している
- B) 常時インバータで給電している
- C) 電圧変動時はAVRで対応する
- D) オフライン式より切替時間が短い

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
ラインインタラクティブ方式は、通常時は商用電源を使用し、常時インバータで給電しているのはオンライン方式です。<br>
<br>
Aは正しい：AVRを内蔵し、軽微な電圧変動に対応します<br>
Cは正しい：電圧変動時はまずAVRで対応し、停電時のみバッテリー給電に切り替えます<br>
Dは正しい：切替時間は2-4msで、オフライン式（4-10ms）より短いです<br>
<br>
【補足】ラインインタラクティブ方式は、オフライン式とオンライン式の中間的な性能とコストで、中規模システムに適しています。
</details>

### 問題5
UPSのバッテリー交換時期の目安として、一般的に正しいものはどれか？

- A) 1〜2年
- B) 3〜5年
- C) 7〜10年
- D) 15〜20年

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
一般的な鉛蓄電池を使用したUPSのバッテリー寿命は3〜5年が目安です。使用環境（温度、放電頻度）により変動します。<br>
<br>
Aが間違いの理由：1〜2年は短すぎる期間です<br>

## 9. 専門用語集

このドキュメントで使用された専門用語について、アルファベット順・50音順で解説します。

### アルファベット

**AVR (Automatic Voltage Regulator)**
- **読み方**: エーブイアール
- **意味**: 自動電圧調整器。入力電圧の変動を検知し、タップ切替やトランスにより出力電圧を一定範囲内に保つ装置
- **関連用語**: ラインインタラクティブ方式、電圧変動

**N+1構成**
- **読み方**: エヌプラスワンこうせい
- **意味**: 必要なUPS台数（N）に加えて、予備機を1台追加した冗長構成。1台故障時も運用継続可能
- **関連用語**: 2N構成、冗長性、可用性

**ROI (Return On Investment)**
- **読み方**: アールオーアイ
- **意味**: 投資収益率。UPS導入による停電損失回避額を初期投資額で除した値。投資回収期間の指標
- **関連用語**: TCO、費用対効果

**STS (Static Transfer Switch)**
- **読み方**: エスティーエス
- **意味**: 静止型切替スイッチ。2系統の電源を高速（4ms以下）で切り替える半導体スイッチ
- **関連用語**: ATS、冗長電源、無瞬断切替

**TCO (Total Cost of Ownership)**
- **読み方**: ティーシーオー
- **意味**: 総所有コスト。初期費用だけでなく、運用・保守・廃棄までを含めたライフサイクル全体のコスト
- **関連用語**: ランニングコスト、初期投資

**THD (Total Harmonic Distortion)**
- **読み方**: ティーエイチディー
- **意味**: 総合高調波歪率。電圧や電流波形の正弦波からのずれを表す指標。5%以下が望ましい
- **関連用語**: 高調波、電力品質

**UPS (Uninterruptible Power Supply)**
- **読み方**: ユーピーエス
- **意味**: 無停電電源装置。停電や電源異常時にバッテリーから電力を供給し続ける装置
- **関連用語**: 停電対策、バックアップ電源

**VA (Volt-Ampere)**
- **読み方**: ブイエー、ボルトアンペア
- **意味**: 皮相電力の単位。電圧（V）×電流（A）で表される。有効電力（W）を力率で除した値
- **関連用語**: kVA、有効電力、力率

**VPP (Virtual Power Plant)**
- **読み方**: ブイピーピー
- **意味**: 仮想発電所。分散した電源や蓄電池をICTで統合制御し、あたかも1つの発電所のように運用する仕組み
- **関連用語**: スマートグリッド、分散電源

### あ行

**インバータ**
- **読み方**: いんばーた
- **意味**: 直流電力を交流電力に変換する装置。UPSではバッテリーの直流を商用電源と同じ交流に変換する
- **関連用語**: コンバータ、DC/AC変換

**オフライン方式**
- **読み方**: おふらいんほうしき
- **意味**: 常時商用給電方式の別称。通常時は商用電源を直接負荷に供給し、停電時のみバッテリー給電に切り替える方式
- **関連用語**: 常時商用給電方式、スタンバイ方式

**オンライン方式**
- **読み方**: おんらいんほうしき
- **意味**: 常時インバータ給電方式の別称。常にインバータを経由して給電するため、完全な無瞬断を実現する方式
- **関連用語**: 常時インバータ給電方式、ダブルコンバージョン方式

### か行

**過充電**
- **読み方**: かじゅうでん
- **意味**: バッテリーに定格以上の電圧・電流で充電すること。バッテリーの劣化や発熱の原因となる
- **関連用語**: 充電制御、バッテリー管理

**可用性**
- **読み方**: かようせい
- **意味**: システムが正常に稼働している時間の割合。99.999%（ファイブナイン）などで表現される
- **関連用語**: 信頼性、MTBF、MTTR

**瞬断**
- **読み方**: しゅんだん
- **意味**: 瞬間的な電源の遮断。数ミリ秒から数百ミリ秒の短時間停電
- **関連用語**: 瞬停、瞬時電圧低下

**冗長性**
- **読み方**: じょうちょうせい
- **意味**: システムの一部が故障しても、全体の機能を維持できるよう予備を持たせること
- **関連用語**: N+1、2N、フォールトトレラント

### さ行

**サージ**
- **読み方**: さーじ
- **意味**: 雷などにより発生する瞬間的な過電圧。電子機器の故障原因となる
- **関連用語**: 雷サージ、過電圧保護

**充電器**
- **読み方**: じゅうでんき
- **意味**: 商用電源からバッテリーを充電する装置。UPSに内蔵されており、フロート充電を行う
- **関連用語**: 整流器、フロート充電

**常時インバータ給電方式**
- **読み方**: じょうじいんばーたきゅうでんほうしき
- **意味**: 常に整流器→インバータを経由して給電する方式。最高の電力品質を提供
- **関連用語**: オンライン方式、ダブルコンバージョン

**常時商用給電方式**
- **読み方**: じょうじしょうようきゅうでんほうしき
- **意味**: 通常時は商用電源を直接供給し、停電時のみバッテリー給電する方式
- **関連用語**: オフライン方式、スタンバイ方式

### た行

**ダブルコンバージョン方式**
- **読み方**: だぶるこんばーじょんほうしき
- **意味**: AC→DC→ACと2回変換を行う方式。オンライン方式の別称
- **関連用語**: 常時インバータ給電方式、オンライン方式

**蓄電池**
- **読み方**: ちくでんち
- **意味**: 電気エネルギーを化学エネルギーとして蓄え、必要時に放電する装置。バッテリーとも呼ぶ
- **関連用語**: 鉛蓄電池、リチウムイオン電池

**停電**
- **読み方**: ていでん
- **意味**: 電力供給が停止すること。計画停電と事故停電がある
- **関連用語**: 瞬断、電源障害

### な行

**鉛蓄電池**
- **読み方**: なまりちくでんち
- **意味**: 鉛と希硫酸を使用した二次電池。UPSで最も一般的に使用される
- **関連用語**: VRLA、制御弁式鉛蓄電池

**ノイズ**
- **読み方**: のいず
- **意味**: 電源に重畳する不要な電気信号。機器の誤動作の原因となる
- **関連用語**: EMI、電磁波障害

### は行

**バイパス回路**
- **読み方**: ばいぱすかいろ
- **意味**: UPS故障時やメンテナンス時に、商用電源を直接負荷に供給する迂回経路
- **関連用語**: 保守バイパス、自動バイパス

**バックアップ時間**
- **読み方**: ばっくあっぷじかん
- **意味**: 停電時にUPSがバッテリーで給電を継続できる時間
- **関連用語**: 給電時間、停電補償時間

**バッテリー**
- **読み方**: ばってりー
- **意味**: 蓄電池の英語表記。UPSの心臓部となる部品
- **関連用語**: 蓄電池、二次電池

**皮相電力**
- **読み方**: ひそうでんりょく
- **意味**: 電圧と電流の積で表される電力。単位はVA（ボルトアンペア）
- **関連用語**: 有効電力、無効電力、力率

**フライホイール**
- **読み方**: ふらいほいーる
- **意味**: 高速回転する円盤に運動エネルギーとして電力を蓄える装置
- **関連用語**: 運動エネルギー蓄電、短時間停電対策

**フロート充電**
- **読み方**: ふろーとじゅうでん
- **意味**: バッテリーを常に満充電状態に保つ充電方式。自己放電分を補う程度の小電流で充電
- **関連用語**: トリクル充電、均等充電

**変換効率**
- **読み方**: へんかんこうりつ
- **意味**: 入力電力に対する出力電力の比率。高いほど電力損失が少ない
- **関連用語**: 電力効率、損失

### ま行

**無効電力**
- **読み方**: むこうでんりょく
- **意味**: 実際の仕事をしない電力成分。コンデンサやコイルで消費される
- **関連用語**: 有効電力、皮相電力、力率

**無瞬断**
- **読み方**: むしゅんだん
- **意味**: 電源切替時に全く瞬断が発生しないこと。切替時間0ms
- **関連用語**: 瞬断、オンライン方式

### や行

**有効電力**
- **読み方**: ゆうこうでんりょく
- **意味**: 実際に仕事をする電力。単位はW（ワット）
- **関連用語**: 皮相電力、無効電力、力率

### ら行

**ラインインタラクティブ方式**
- **読み方**: らいんいんたらくてぃぶほうしき
- **意味**: AVRを内蔵し、軽微な電圧変動に対応できるUPS方式
- **関連用語**: AVR、電圧安定化

**リチウムイオン電池**
- **読み方**: りちうむいおんでんち
- **意味**: リチウムイオンの移動により充放電する二次電池。高エネルギー密度と長寿命が特徴
- **関連用語**: Li-ion、次世代電池

**力率**
- **読み方**: りきりつ
- **意味**: 皮相電力に対する有効電力の比率。cosφで表される
- **関連用語**: 有効電力、皮相電力、位相差

**冷却**
- **読み方**: れいきゃく
- **意味**: UPSやバッテリーの温度上昇を防ぐこと。ファンや空調により行う
- **関連用語**: 放熱、温度管理

### わ行

**ワット（W）**
- **読み方**: わっと
- **意味**: 有効電力の単位。実際に仕事をする電力を表す
- **関連用語**: kW、有効電力、消費電力
