# LANの接続機器について

## 概要
LAN（Local Area Network）は、限定された地域内でコンピュータやネットワーク機器を相互接続するネットワークです。LANを構築するには、各階層（OSI参照モデル）に対応した様々な接続機器が必要となります。本資料では、これらの機器を体系的に整理し、それぞれの役割、特徴、選定基準について詳しく解説します。

## 1. 基本概念・仕組み

### OSI参照モデルとLAN機器の関係
- **定義**: OSI参照モデルは、ネットワーク通信を7つの階層に分けて定義した国際標準モデル
- **動作原理**: 各階層で異なる役割を持つ機器が連携して通信を実現
- **特徴**: 階層ごとに独立した機能を持ち、上位層は下位層のサービスを利用

### LAN接続機器の分類原理
- **従来技術との違い**: 単純な電気信号の中継から、インテリジェントな通信制御へ進化
- **改善点**: 通信効率の向上、セキュリティ機能の強化、管理機能の充実
- **限界**: 物理的な距離制限、帯域幅の上限、遅延の発生

## 2. OSI階層別の接続機器

### 第1層（物理層）の機器

#### リピータ
**特徴:**
- 電気信号を増幅・整形して中継
- 信号の減衰を補正
- 最大伝送距離を延長

**動作原理:**
```
入力信号 → 増幅回路 → 波形整形 → 出力信号
```

**📊 具体的な適用例**
**例: 100BASE-TXでの距離延長**
- 前提条件1: ケーブル長100mの制限
- 前提条件2: 建物間の距離150m

**ステップ1: リピータなしの場合**
```
PC-A ←--100m--→ × (信号減衰により通信不可)
```

**ステップ2: リピータ導入**
```
PC-A ←--75m--→ リピータ ←--75m--→ PC-B (通信可能)
```

**結果: 最大200mまで延長可能（リピータ1台使用時）**

💡 **実際の現場では**: カスケード接続は最大4台まで、遅延時間の累積に注意

#### ハブ（リピータハブ）
**特徴:**
- 複数ポートを持つマルチポートリピータ
- 受信信号を全ポートに転送（ブロードキャスト）
- コリジョンドメインを共有

**仕様詳細:**
| 項目 | 10BASE-T | 100BASE-TX | 1000BASE-T |
|------|----------|------------|------------|
| 最大ポート数 | 24-48 | 24-48 | 8-16（稀） |
| 最大カスケード | 4段 | 2段 | 1段 |
| 遅延時間 | 5.1μs | 0.51μs | 非推奨 |

### 第2層（データリンク層）の機器

#### スイッチ（スイッチングハブ）
**特徴:**
- MACアドレステーブルによる学習機能
- ポートごとにコリジョンドメインを分離
- 全二重通信のサポート

**MACアドレステーブルの動作:**
```
1. フレーム受信
2. 送信元MACアドレスを学習（ポート番号と関連付け）
3. 宛先MACアドレスを検索
4. 該当ポートのみに転送（ユニキャスト）
```

**📊 具体的な性能比較**
**例: 24ポートスイッチでの帯域幅計算**
- 前提条件1: 各ポート1Gbps
- 前提条件2: 全二重通信

**ステップ1: スイッチングファブリック容量**
```
24ポート × 1Gbps × 2（全二重） = 48Gbps
```

**ステップ2: ノンブロッキング性能の確認**
```
必要容量 48Gbps ≤ ファブリック容量 48Gbps → ノンブロッキング
```

**結果: 全ポート同時通信可能**

💡 **実際の現場では**: オーバーサブスクリプション比率を考慮した設計が重要

#### ブリッジ
**特徴:**
- 2つのネットワークセグメントを接続
- MACアドレスによるフィルタリング
- 異なるメディア間の接続可能

**フィルタリング動作:**
| 送信元 | 宛先 | 動作 |
|--------|------|------|
| セグメントA | セグメントA | 転送しない |
| セグメントA | セグメントB | 転送する |
| セグメントA | ブロードキャスト | 両セグメントに転送 |

### 第3層（ネットワーク層）の機器

#### ルータ
**特徴:**
- IPアドレスによる経路制御
- 異なるネットワーク間の接続
- ブロードキャストドメインの分離

**ルーティングテーブル例:**
```
宛先ネットワーク    ネクストホップ    インターフェース    メトリック
192.168.1.0/24     直接接続          eth0              0
192.168.2.0/24     192.168.1.254     eth0              1
0.0.0.0/0          203.0.113.1       eth1              1
```

**📊 具体的な経路選択例**
**例: 複数経路がある場合の選択**
- 前提条件1: 宛先192.168.10.50
- 前提条件2: 2つの経路が存在

**ステップ1: 経路情報の比較**
```
経路1: 192.168.10.0/24 via 10.0.0.1 メトリック10
経路2: 192.168.10.0/24 via 10.0.0.2 メトリック20
```

**ステップ2: 最適経路の選択**
```
メトリック10 < メトリック20 → 経路1を選択
```

**結果: より低いメトリックの経路を使用**

💡 **実際の現場では**: 動的ルーティングプロトコル（OSPF、BGP）の活用

#### L3スイッチ（レイヤ3スイッチ）
**特徴:**
- ハードウェアによる高速ルーティング
- VLAN間ルーティング機能
- QoS制御機能

**性能比較:**
| 項目 | 従来のルータ | L3スイッチ |
|------|-------------|-----------|
| 転送方式 | ソフトウェア | ASIC |
| 転送性能 | 数Gbps | 数百Gbps |
| 遅延 | 数ms | 数μs |
| 価格 | 中〜高 | 高 |

### 第4層以上の機器

#### ロードバランサ
**特徴:**
- 複数サーバへの負荷分散
- セッション維持機能
- ヘルスチェック機能

**負荷分散アルゴリズム:**
1. **ラウンドロビン**: 順番に振り分け
2. **最小接続数**: 接続数が少ないサーバを選択
3. **重み付け**: サーバ性能に応じた配分
4. **IPハッシュ**: 送信元IPによる固定振り分け

#### ファイアウォール
**特徴:**
- パケットフィルタリング
- ステートフルインスペクション
- アプリケーション層での制御

**フィルタリング規則例:**
```
許可/拒否  送信元IP        宛先IP          プロトコル  ポート
許可      192.168.1.0/24  Any            TCP        80
許可      192.168.1.0/24  Any            TCP        443
拒否      Any            Any            Any        Any
```

## 3. 接続機器の詳細仕様・パラメータ

### スイッチの重要パラメータ
#### バックプレーン容量
- **意味**: スイッチ内部のデータ転送能力
- **設定範囲**: 数Gbps〜数Tbps
- **影響**: 全体的な転送性能の上限を決定
- **推奨値**: ポート数×ポート速度×2（全二重）以上

#### MACアドレステーブルサイズ
- **意味**: 学習可能なMACアドレス数
- **設定範囲**: 1K〜128Kエントリ
- **影響**: 接続可能な端末数の上限
- **推奨値**: 想定接続端末数の1.5倍以上

#### バッファメモリ
- **意味**: パケットの一時保存領域
- **設定範囲**: 数MB〜数GB
- **影響**: バースト転送時の性能
- **推奨値**: ポート数×最大フレームサイズ×10以上

### ルータの重要パラメータ
#### ルーティングテーブルサイズ
- **意味**: 保持可能な経路情報数
- **設定範囲**: 数千〜数百万エントリ
- **影響**: 接続可能なネットワーク数
- **推奨値**: インターネット接続時は80万エントリ以上

#### パケット転送性能（PPS）
- **意味**: 1秒あたりの転送パケット数
- **設定範囲**: 数万〜数千万PPS
- **影響**: 実効転送速度
- **推奨値**: 回線速度÷平均パケットサイズ×1.2以上

## 4. 実装例・適用事例

### 基本的な企業LANの構成
```
インターネット
    |
ファイアウォール
    |
コアスイッチ（L3）
    |
    +------ ディストリビューションスイッチ（L2/L3）
    |                |
    |                +--- アクセススイッチ --- PC
    |                |
    |                +--- アクセススイッチ --- PC
    |
    +------ サーバファーム
             |
             +--- Webサーバ（ロードバランサ経由）
             |
             +--- DBサーバ
```

### 実際の適用事例

#### 事例1: 中規模オフィスビル（従業員500名）
- **課題**: フロア間の通信遅延とセキュリティ確保
- **適用方法**: 
  - 各フロアにL2スイッチを配置
  - フロア間をL3スイッチで接続
  - VLAN設計による部門別セグメント化
- **結果**: 遅延を1ms以下に削減、部門間アクセス制御実現
- **効果**: ネットワーク利用満足度40%向上

#### 事例2: データセンター（サーバ1000台）
- **課題**: 高可用性と拡張性の確保
- **適用方法**:
  - スパインリーフ構成の採用
  - 10/40Gbpsスイッチの導入
  - 仮想化対応スイッチの活用
- **結果**: 99.99%の可用性達成
- **効果**: サーバ追加時の作業時間80%削減

## 5. メリット・デメリット

### インテリジェントスイッチ導入のメリット
**1. セキュリティの向上**
- **理由**: VLAN機能によるネットワーク分離
- **効果**: 不正アクセスリスクの低減
- **具体例**: 財務部門VLANへの他部門からのアクセス遮断

**2. 管理性の向上**
- **理由**: SNMP等による集中管理
- **効果**: 障害対応時間の短縮
- **具体例**: 異常トラフィックの自動検知と通知

### 高機能化のデメリット
**1. コストの増大**
- **理由**: 高性能チップセットの採用
- **影響**: 初期投資額の増加
- **対策**: 段階的な導入計画の策定

**2. 管理の複雑化**
- **理由**: 設定項目の増加
- **影響**: 運用担当者の負担増
- **対策**: 自動化ツールの活用、適切な教育

### 適用判断フローチャート
1. **接続端末数は10台以下？** 
   - Yes → 非管理型L2スイッチ
   - No → 次の判断へ

2. **VLAN機能が必要？**
   - Yes → 管理型L2スイッチ以上
   - No → 非管理型L2スイッチ

3. **異なるネットワーク間の通信が必要？**
   - Yes → L3スイッチまたはルータ
   - No → L2スイッチ

4. **高速なルーティングが必要？**
   - Yes → L3スイッチ
   - No → ルータ

### 問題1
OSI参照モデルの第2層（データリンク層）で動作する機器はどれか？

- A) リピータ
- B) スイッチ
- C) ルータ
- D) ファイアウォール

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
正解はBのスイッチです。スイッチはMACアドレスを使用してフレームの転送を行うため、第2層で動作します。<br>
<br>
Aが間違いの理由：リピータは第1層（物理層）で動作し、電気信号の増幅のみを行います<br>
Cが間違いの理由：ルータは第3層（ネットワーク層）で動作し、IPアドレスを使用します<br>
Dが間違いの理由：ファイアウォールは主に第3層以上で動作します<br>
<br>
【補足】実務では、L2スイッチとL3スイッチを使い分けることが重要です。
</details>

<details>
<summary>解答</summary>

Aが間違いの理由：リピータハブは全ポートに信号を転送し、MACアドレスを認識しません<br>

Dが間違いの理由：ロードバランサは第4層以上の情報を使用して負荷分散を行います<br>
<br>
【補足】現在はブリッジの機能がスイッチに統合されていることがほとんどです。
</details>

Dが間違いの理由：ルータは第3層（ネットワーク層）で動作します<br>

### 問題7
ブロードキャストストームを防ぐプロトコルはどれか？

- A) ARP
- B) STP
- C) DHCP
- D) ICMP

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
正解はBのSTP（Spanning Tree Protocol）です。STPはループを検出して論理的に遮断します。<br>
<br>
Aが間違いの理由：ARPはIPアドレスからMACアドレスを解決するプロトコルです<br>
Cが間違いの理由：DHCPはIPアドレスを自動割り当てするプロトコルです<br>
Dが間違いの理由：ICMPはエラー通知や診断に使用するプロトコルです<br>
<br>
【補足】冗長構成時はSTPまたはその改良版（RSTP、MSTP）が必須です。
</details>

## 9. 専門用語集

### アルファベット

**ACL (Access Control List)**
- **読み方**: エーシーエル
- **意味**: パケットの通過を許可・拒否するルールのリスト。IPアドレス、ポート番号等で制御
- **関連用語**: ファイアウォール、セキュリティポリシー

**ARP (Address Resolution Protocol)**
- **読み方**: アープ
- **意味**: IPアドレスからMACアドレスを取得するプロトコル
- **関連用語**: RARP、NDP（IPv6）

**ASIC (Application Specific Integrated Circuit)**
- **読み方**: エーシック
- **意味**: 特定用途向けに設計された集積回路。L3スイッチで高速転送を実現
- **関連用語**: FPGA、NPU

**BGP (Border Gateway Protocol)**
- **読み方**: ビージーピー
- **意味**: インターネットで使用される外部ルーティングプロトコル
- **関連用語**: OSPF、RIP、EIGRP

**DHCP (Dynamic Host Configuration Protocol)**
- **読み方**: ディーエイチシーピー
- **意味**: IPアドレスを自動的に割り当てるプロトコル
- **関連用語**: 静的IP、DHCPサーバ

**HSRP (Hot Standby Router Protocol)**
- **読み方**: エイチエスアールピー
- **意味**: Cisco独自のルータ冗長化プロトコル
- **関連用語**: VRRP、GLBP

**LACP (Link Aggregation Control Protocol)**
- **読み方**: エルエーシーピー
- **意味**: リンクアグリゲーションの制御プロトコル
- **関連用語**: IEEE 802.3ad、ポートチャネル

**MAC (Media Access Control)**
- **読み方**: マック
- **意味**: データリンク層のアドレス。機器固有の48ビットアドレス
- **関連用語**: IPアドレス、物理アドレス

**OSPF (Open Shortest Path First)**
- **読み方**: オーエスピーエフ
- **意味**: リンクステート型の内部ルーティングプロトコル
- **関連用語**: RIP、EIGRP、BGP

**QoS (Quality of Service)**
- **読み方**: キューオーエス
- **意味**: ネットワークサービスの品質保証技術
- **関連用語**: 優先制御、帯域制御

**SDN (Software Defined Networking)**
- **読み方**: エスディーエヌ
- **意味**: ソフトウェアによりネットワークを集中制御する技術
- **関連用語**: OpenFlow、NFV

**SNMP (Simple Network Management Protocol)**
- **読み方**: エスエヌエムピー
- **意味**: ネットワーク機器を管理するためのプロトコル
- **関連用語**: MIB、トラップ、ポーリング

**STP (Spanning Tree Protocol)**
- **読み方**: エスティーピー
- **意味**: ループを防止するプロトコル。IEEE 802.1D
- **関連用語**: RSTP、MSTP、BPDU

**VLAN (Virtual LAN)**
- **読み方**: ブイラン
- **意味**: 物理的な接続に依存しない論理的なLAN
- **関連用語**: トランクポート、タグVLAN

**VRRP (Virtual Router Redundancy Protocol)**
- **読み方**: ブイアールアールピー
- **意味**: 標準的なルータ冗長化プロトコル
- **関連用語**: HSRP、仮想IP

**VXLAN (Virtual Extensible LAN)**
- **読み方**: ブイエックスラン
- **意味**: L3ネットワーク上にL2ネットワークを構築する技術
- **関連用語**: オーバーレイネットワーク、NVGRE

### あ行

**アクセススイッチ**
- **読み方**: あくせすすいっち
- **意味**: エンドユーザーの端末を直接接続するスイッチ
- **関連用語**: ディストリビューションスイッチ、コアスイッチ

**オーバーサブスクリプション**
- **読み方**: おーばーさぶすくりぷしょん
- **意味**: 上位回線の帯域を下位ポートの合計帯域より小さく設計すること
- **関連用語**: ノンブロッキング、帯域設計

### か行

**カスケード接続**
- **読み方**: かすけーどせつぞく
- **意味**: 複数の機器を数珠つなぎに接続する方法
- **関連用語**: スタック接続、アップリンク

**コアスイッチ**
- **読み方**: こあすいっち
- **意味**: ネットワークの中核となる高性能スイッチ
- **関連用語**: バックボーン、アグリゲーション

**コリジョンドメイン**
- **読み方**: こりじょんどめいん
- **意味**: 衝突が発生する可能性のあるネットワーク範囲
- **関連用語**: ブロードキャストドメイン、CSMA/CD

### さ行

**スパインリーフ構成**
- **読み方**: すぱいんりーふこうせい
- **意味**: データセンター向けの2階層ネットワーク構成
- **関連用語**: 3階層モデル、Closネットワーク

**ステートフルインスペクション**
- **読み方**: すてーとふるいんすぺくしょん
- **意味**: 通信の状態を記録して制御するファイアウォール技術
- **関連用語**: パケットフィルタリング、DPI

### た行

**帯域幅**
- **読み方**: たいいきはば
- **意味**: データ転送可能な容量。bps（ビット毎秒）で表現
- **関連用語**: スループット、回線速度

**トランクポート**
- **読み方**: とらんくぽーと
- **意味**: 複数のVLANを通すポート
- **関連用語**: アクセスポート、タグVLAN

### な行

**ノンブロッキング**
- **読み方**: のんぶろっきんぐ
- **意味**: 全ポートが同時に最大速度で通信可能な状態
- **関連用語**: ワイヤスピード、バックプレーン容量

### は行

**バックプレーン**
- **読み方**: ばっくぷれーん
- **意味**: スイッチ内部でデータを転送する基板・バス
- **関連用語**: スイッチングファブリック、内部帯域

**ブロードキャストドメイン**
- **読み方**: ぶろーどきゃすとどめいん
- **意味**: ブロードキャストが到達する範囲
- **関連用語**: マルチキャスト、ユニキャスト

**ポートミラーリング**
- **読み方**: ぽーとみらーりんぐ
- **意味**: 特定ポートの通信を別ポートにコピーする機能
- **関連用語**: SPAN、パケットキャプチャ

### ま行

**マルチキャスト**
- **読み方**: まるちきゃすと
- **意味**: 特定のグループに対する同報通信
- **関連用語**: ユニキャスト、ブロードキャスト

### ら行

**リンクアグリゲーション**
- **読み方**: りんくあぐりげーしょん
- **意味**: 複数の物理リンクを束ねて論理的な1本のリンクとする技術
- **関連用語**: LACP、ポートチャネル、LAG

**ループ**
- **読み方**: るーぷ
- **意味**: ネットワーク上で経路が環状になっている状態
- **関連用語**: ブロードキャストストーム、STP

**ルーティングテーブル**
- **読み方**: るーてぃんぐてーぶる
- **意味**: パケットの転送先を決定するための経路情報
- **関連用語**: FIB、RIB、ネクストホップ

### わ行

**ワイヤスピード**
- **読み方**: わいやすぴーど
- **意味**: 回線の物理速度で遅延なく転送できる性能
- **関連用語**: ノンブロッキング、線速
