# イーサネットの種類について

## 概要
イーサネット（Ethernet）は、コンピュータネットワークの規格の1つで、世界中で最も広く使用されているLAN（Local Area Network）技術です。1973年にゼロックス社のロバート・メトカーフによって開発され、現在ではIEEE 802.3として標準化されています。本資料では、代表的なイーサネットの種類とその特徴について詳しく解説します。

## 1. イーサネットの基本概念・仕組み

### イーサネットの基本原理
- **定義**: 有線LANの技術規格で、CSMA/CD（Carrier Sense Multiple Access with Collision Detection）方式を基本としたネットワーク技術
- **動作原理**: フレーム単位でのデータ伝送、MACアドレスによる機器識別、衝突検出と再送制御
- **特徴**: 高い互換性、スケーラビリティ、コスト効率の良さ

### 従来技術との関係
- **トークンリングとの違い**: 非決定的アクセス方式、シンプルな実装、低コスト
- **改善点**: 高速化、全二重通信の実現、スイッチング技術の導入
- **限界**: 物理的な距離制限、電気的特性による速度制限

## 2. イーサネットの種類・分類

### 速度による分類
イーサネットは主に伝送速度によって分類されます。

### 10Mbpsイーサネット（標準イーサネット）
**特徴:**
- 最初に標準化されたイーサネット規格
- CSMA/CD方式を使用
- 現在はほとんど使用されていない

**主な規格:**
```
10BASE5（Thick Ethernet）
- 同軸ケーブル（太）使用
- 最大セグメント長: 500m
- 最大ノード数: 100

10BASE2（Thin Ethernet）
- 同軸ケーブル（細）使用
- 最大セグメント長: 185m
- 最大ノード数: 30

10BASE-T
- ツイストペアケーブル（UTP）使用
- 最大セグメント長: 100m
- スター型トポロジー
```

**📊 具体的な計算例**
**例: 10BASE-Tネットワークの最大遅延時間計算**
- ケーブル長: 100m
- 信号伝播速度: 約0.77c（光速の77%）

**ステップ1: 信号伝播時間の計算**
```
伝播時間 = 距離 ÷ 速度
= 100m ÷ (0.77 × 3×10^8 m/s)
= 100m ÷ 2.31×10^8 m/s
≈ 0.43μs
```

**ステップ2: 往復遅延時間（RTT）**
```
RTT = 伝播時間 × 2
= 0.43μs × 2
= 0.86μs
```

**結果: 最大往復遅延時間は約0.86マイクロ秒**

💡 **実際の現場では**: 実際にはスイッチやリピータの処理遅延も加わるため、総遅延時間は1-2μs程度になります。

### 100Mbpsイーサネット（ファストイーサネット）
**特徴:**
- 10Mbpsの10倍の速度
- IEEE 802.3uとして標準化
- 広く普及した規格

**主な規格:**
```
100BASE-TX
- カテゴリ5以上のUTPケーブル使用
- 最大セグメント長: 100m
- 2対（4線）使用

100BASE-FX
- マルチモード光ファイバー使用
- 最大セグメント長: 2km（全二重時）
- 電磁干渉を受けない
```

**📊 具体的な計算例**
**例: 100BASE-TXの実効転送速度計算**
- 理論速度: 100Mbps
- イーサネットフレームオーバーヘッド考慮

**ステップ1: フレーム構造の確認**
```
プリアンブル: 7バイト
SFD: 1バイト
宛先MAC: 6バイト
送信元MAC: 6バイト
タイプ/長さ: 2バイト
データ: 46-1500バイト
FCS: 4バイト
IFG（フレーム間隔）: 12バイト相当
```

**ステップ2: 最大サイズフレームの効率計算**
```
総フレームサイズ = 7 + 1 + 6 + 6 + 2 + 1500 + 4 + 12 = 1538バイト
データ部分 = 1500バイト
効率 = 1500 ÷ 1538 × 100% ≈ 97.5%
```

**ステップ3: 実効転送速度**
```
実効速度 = 100Mbps × 0.975 = 97.5Mbps
```

**結果: 最大約97.5Mbpsの実効転送速度**

💡 **実際の現場では**: TCP/IPのオーバーヘッドも考慮すると、実際のアプリケーション層での転送速度は90-95Mbps程度になります。

### 1Gbpsイーサネット（ギガビットイーサネット）
**特徴:**
- 100Mbpsの10倍の速度
- IEEE 802.3zおよび802.3abとして標準化
- 現在の主流規格

**主な規格:**
```
1000BASE-T
- カテゴリ5e以上のUTPケーブル使用
- 最大セグメント長: 100m
- 4対（8線）すべて使用
- 双方向同時通信

1000BASE-SX
- マルチモード光ファイバー使用（短波長）
- 最大セグメント長: 220-550m
- データセンター内接続用

1000BASE-LX
- シングルモード/マルチモード光ファイバー使用（長波長）
- 最大セグメント長: 5km（シングルモード）
- 建物間接続用
```

### 10Gbpsイーサネット以上
**特徴:**
- データセンターやバックボーンネットワーク用
- IEEE 802.3aeとして標準化
- さらなる高速化が進行中

**主な規格:**
```
10GBASE-T
- カテゴリ6A以上のUTPケーブル使用
- 最大セグメント長: 100m
- 高い消費電力

10GBASE-SR
- マルチモード光ファイバー使用
- 最大セグメント長: 300m
- データセンター内接続

40GBASE/100GBASE
- 主にデータセンターのバックボーン
- 光ファイバー使用
- 複数レーンの並列伝送
```

## 3. 詳細仕様・パラメータ

### ケーブルカテゴリの詳細
#### カテゴリ5e（Cat5e）
- **意味**: Enhanced Category 5
- **周波数帯域**: 100MHz
- **対応速度**: 最大1Gbps
- **推奨用途**: 1000BASE-T

#### カテゴリ6（Cat6）
- **意味**: Category 6
- **周波数帯域**: 250MHz
- **対応速度**: 最大1Gbps（100m）、10Gbps（55m）
- **推奨用途**: 1000BASE-T、短距離10GBASE-T

#### カテゴリ6A（Cat6A）
- **意味**: Augmented Category 6
- **周波数帯域**: 500MHz
- **対応速度**: 最大10Gbps（100m）
- **推奨用途**: 10GBASE-T

## 4. 実装例・適用事例

### 基本的なネットワーク構成例
```
[端末]---(Cat5e/100m)---[スイッチ]---(光ファイバー/1km)---[コアスイッチ]
  |                          |                                    |
100BASE-TX              1000BASE-T                          10GBASE-SR
```

### 実際の適用事例
#### 事例1: 中規模オフィスネットワーク
- **課題**: 100台の端末を接続し、ファイルサーバーへの高速アクセスが必要
- **適用方法**: 
  - 端末接続: 100BASE-TX
  - サーバー接続: 1000BASE-T
  - スイッチ間: 1000BASE-SX（光ファイバー）
- **結果**: 必要十分な性能を低コストで実現
- **効果**: 初期投資を抑えつつ、将来の拡張性も確保

#### 事例2: データセンター内ネットワーク
- **課題**: 高密度サーバー環境での大容量データ転送
- **適用方法**:
  - サーバー接続: 10GBASE-T
  - ラック間: 40GBASE-SR4
  - コアスイッチ: 100GBASE-SR10
- **結果**: ボトルネックのない高速ネットワーク構築
- **効果**: 仮想化環境でのライブマイグレーション時間を大幅短縮

## 5. メリット・デメリット

### メリット
**1. 高い互換性**
- **理由**: 標準規格に準拠した製品間での相互接続が保証
- **効果**: マルチベンダー環境の構築が容易
- **具体例**: 異なるメーカーのスイッチとNICを問題なく接続可能

**2. スケーラビリティ**
- **理由**: 10Mbpsから100Gbpsまで幅広い速度オプション
- **効果**: 段階的なアップグレードが可能
- **具体例**: 100BASE-TXから1000BASE-Tへの移行が容易

**3. コスト効率**
- **理由**: 大量生産による低価格化
- **効果**: 初期投資と運用コストの削減
- **具体例**: ギガビットイーサネットポートの価格は10年で1/10以下に

### デメリット
**1. 距離制限**
- **理由**: 電気信号の減衰と規格上の制限
- **影響**: UTPケーブルでは最大100m
- **対策**: 光ファイバーの使用、リピーターの設置

**2. 電磁干渉の影響（UTPケーブル）**
- **理由**: シールドされていない銅線使用
- **影響**: 工場環境などでは通信エラーが発生
- **対策**: STPケーブルや光ファイバーの使用

| 消費電力 | ◎ | ○ | △ | ○ |

### 適用判断フローチャート
1. **必要な帯域は？**
   - 100Mbps未満 → 100BASE-TX
   - 100Mbps-1Gbps → 次の判断へ
   - 1Gbps以上 → 次の判断へ

2. **距離は100m以内？**
   - Yes → 1000BASE-Tまたは10GBASE-T
   - No → 光ファイバー（1000BASE-LX等）

3. **電磁干渉の懸念は？**
   - Yes → 光ファイバー推奨
   - No → UTPケーブルで可

## 7. 最新動向・今後の展望
- **現在の課題**: 10GBASE-Tの消費電力削減、さらなる高速化のコスト
- **研究動向**: 400ギガビット、テラビットイーサネットの開発
- **将来予測**: 2030年までに一般オフィスでも10Gbpsが標準化
- **関連技術**: Power over Ethernet（PoE）、Time-Sensitive Networking（TSN）

### 問題1
イーサネットの基本的なアクセス制御方式として正しいものはどれか？

- A) CSMA/CD
- B) トークンパッシング
- C) ポーリング
- D) TDMA

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
イーサネットの基本的なアクセス制御方式はCSMA/CD（Carrier Sense Multiple Access with Collision Detection）です。これは、送信前にキャリアを検知し、衝突が発生した場合は検出して再送する方式です。<br>
<br>
Bのトークンパッシングはトークンリングで使用される方式です。<br>
Cのポーリングは集中制御型の方式です。<br>
DのTDMAは時分割多重アクセス方式で、無線通信で使用されます。
</details>

### 問題2
100BASE-TXで使用するUTPケーブルのカテゴリとして最低限必要なものはどれか？

- A) カテゴリ3
- B) カテゴリ4
- C) カテゴリ5
- D) カテゴリ6

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
100BASE-TXではカテゴリ5以上のUTPケーブルが必要です。カテゴリ5は100MHzの周波数帯域に対応しており、100Mbpsの通信に必要な性能を満たしています。<br>
<br>
Aのカテゴリ3は10BASE-T用で、16MHzまでの対応です。<br>
Bのカテゴリ4は20MHzまでの対応で、現在はほとんど使用されていません。<br>
Dのカテゴリ6も使用可能ですが、最低限必要なものではありません。
</details>

### 問題3
1000BASE-Tで使用するUTPケーブルの線数（ペア数）はいくつか？

- C) 3対（6線）
- D) 4対（8線）

<details>
<summary>解答</summary>
<strong>正解: D</strong><br>
1000BASE-Tでは4対（8線）すべてを使用します。各ペアで250Mbpsずつ、双方向同時通信を行うことで、合計1Gbpsの通信速度を実現しています。<br>
<br>
Bの2対（4線）は100BASE-TXで使用される構成です。<br>
AとCの構成は標準的なイーサネットでは使用されません。
</details>

</details>

</details>

### 問題14
イーサネットにおいて、全二重通信が可能になった主な理由は何か？

- A) 通信速度の向上
- B) スイッチングハブの普及
- C) ケーブル品質の向上
- D) プロトコルの変更

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
スイッチングハブの普及により、各ポートが独立したコリジョンドメインとなり、CSMA/CDが不要になったため、全二重通信が可能になりました。<br>
<br>
Aの通信速度の向上は結果であって原因ではありません。<br>
Cのケーブル品質は関係ありますが、主な理由ではありません。<br>
Dのプロトコル自体は基本的に変更されていません。
</details>

### 問題15
ある企業で100台のPCを1000BASE-Tで接続し、ファイルサーバーへは10GBASE-Tで接続する場合、スイッチに必要な最小構成は？

- A) 100ポートの1000BASE-Tスイッチのみ
- B) 100ポートの1000BASE-Tスイッチ + 1ポートの10GBASE-T
- C) 48ポートの1000BASE-Tスイッチ × 3台
- D) 24ポートの1000BASE-Tスイッチ × 5台 + 10GBASE-Tアップリンク

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
100台のPCには1000BASE-Tポートが100個必要で、ファイルサーバー用に10GBASE-Tポートが最低1個必要です。これを満たす最小構成はBです。<br>
<br>
Aは10GBASE-Tポートが含まれていません。<br>
Cは144ポートで過剰であり、10GBASE-Tも明記されていません。<br>
Dは120ポートで過剰です。
</details>

### 問題16
工場などの電磁ノイズが多い環境でイーサネットを使用する場合の最適な選択は？

- A) カテゴリ5e UTPケーブル
- B) カテゴリ6 UTPケーブル
- C) 光ファイバーケーブル
- D) 無線LAN

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
光ファイバーケーブルは電磁干渉を受けないため、電磁ノイズが多い環境では最適な選択です。<br>
<br>
AとBのUTPケーブルは電磁干渉を受けやすいです。<br>
Dの無線LANも電波干渉の影響を受ける可能性があります。
</details>

### 問題17
MTU（Maximum Transmission Unit）サイズ1500バイトのネットワークで、9000バイトのデータを送信する場合、最小何個のフレームに分割されるか？

- A) 5個
- B) 6個
- C) 7個
- D) 9個

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
9000バイト ÷ 1500バイト/フレーム = 6フレーム<br>
各フレームに1500バイトずつ格納すると、6個のフレームが必要です。<br>
<br>
実際の分割：1500 + 1500 + 1500 + 1500 + 1500 + 1500 = 9000バイト
</details>

### 問題18
次世代のイーサネット技術として期待されているTSN（Time-Sensitive Networking）の主な用途は？

- A) 一般的なWeb閲覧
- B) ファイル転送の高速化
- C) 産業用制御や車載ネットワーク

<summary>解答</summary>

TSN（Time-Sensitive Networking）は、決定的な低遅延通信を実現する技術で、産業用制御システムや自動車の車載ネットワークなど、リアルタイム性が要求される用途で期待されています。<br>
<br>
Aの一般的なWeb閲覧では必要ありません。<br>
Bのファイル転送では遅延の厳密な制御は不要です。<br>

### 問題19
40GBASE-SR4の「4」が意味するものは何か？

- A) 4番目のバージョン
- B) 4本の光ファイバーを使用
- C) 4kmの伝送距離
- D) 4レーンの並列伝送

<details>
<summary>解答</summary>
<strong>正解: D</strong><br>
40GBASE-SR4の「4」は4レーンの並列伝送を意味します。各レーン10Gbps × 4 = 40Gbpsを実現しています。<br>
<br>
Bの4本の光ファイバーは結果的に正しいですが、正確には4レーンの並列伝送を意味します。<br>

</details>

### 問題20
エンタープライズネットワークで、将来の拡張性を考慮してケーブル配線を行う場合、最も適切な選択は？

- A) カテゴリ5eで統一し、コストを削減
- B) カテゴリ6Aで統一し、10Gbpsまで対応可能にする
- C) 必要な箇所のみカテゴリ6、他はカテゴリ5e
- D) すべて光ファイバーで配線

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
将来の拡張性を考慮すると、カテゴリ6Aで統一することで10Gbpsまでの通信に対応でき、再配線のコストを避けることができます。初期投資は高くなりますが、長期的には最も合理的な選択です。<br>
<br>
Aのカテゴリ5eでは将来10Gbpsが必要になった際に再配線が必要です。<br>
Cの混在環境は管理が複雑になります。<br>
Dの光ファイバーは端末接続には過剰でコストも高額です。
</details>

## 9. 専門用語集

このスライドで使用された技術用語について、アルファベット順・50音順で解説します。

### アルファベット

**CSMA/CD (Carrier Sense Multiple Access with Collision Detection)**
- **読み方**: シーエスエムエー・シーディー
- **意味**: イーサネットで使用される媒体アクセス制御方式。送信前にキャリアを検知し、衝突を検出した場合は再送信を行う
- **関連用語**: コリジョン、キャリアセンス

**FCS (Frame Check Sequence)**
- **読み方**: エフシーエス
- **意味**: フレームの誤り検出用の4バイトの値。CRC32アルゴリズムで計算される
- **関連用語**: CRC、エラー検出

**IEEE (Institute of Electrical and Electronics Engineers)**
- **読み方**: アイトリプルイー
- **意味**: 電気・電子技術の学会。イーサネットなどの通信規格を策定
- **関連用語**: IEEE 802.3、標準化団体

**IFG (Inter-Frame Gap)**
- **読み方**: アイエフジー
- **意味**: イーサネットフレーム間の最小間隔。96ビット時間（12バイト相当）
- **関連用語**: フレーム間隔、タイミング

**LAN (Local Area Network)**
- **読み方**: ラン
- **意味**: 限定された範囲内のコンピュータネットワーク
- **関連用語**: WAN、MAN

**MAC (Media Access Control)**
- **読み方**: マック
- **意味**: データリンク層の下位副層。MACアドレスによる機器識別を行う
- **関連用語**: MACアドレス、データリンク層

**MDI/MDI-X (Medium Dependent Interface)**
- **読み方**: エムディーアイ・エムディーアイクロス
- **意味**: イーサネットの物理的な配線方式。MDI-Xは送受信が逆になっている
- **関連用語**: ストレートケーブル、クロスケーブル

**MTU (Maximum Transmission Unit)**
- **読み方**: エムティーユー
- **意味**: 一度に送信できる最大データサイズ。イーサネットでは通常1500バイト
- **関連用語**: フラグメンテーション、ジャンボフレーム

**NIC (Network Interface Card)**
- **読み方**: ニック
- **意味**: ネットワークインターフェースカード。コンピュータをネットワークに接続するためのハードウェア
- **関連用語**: LANカード、ネットワークアダプタ

**PoE (Power over Ethernet)**
- **読み方**: ピーオーイー
- **意味**: イーサネットケーブルを通じて電力を供給する技術
- **関連用語**: IEEE 802.3af/at/bt、PSE、PD

**QoS (Quality of Service)**
- **読み方**: キューオーエス
- **意味**: ネットワークサービスの品質保証。優先制御などを行う
- **関連用語**: 優先度制御、帯域制御

**RJ-45**
- **読み方**: アールジェーよんじゅうご
- **意味**: 8ピンのモジュラーコネクタ。イーサネットで標準的に使用
- **関連用語**: 8P8C、モジュラージャック

**SFD (Start Frame Delimiter)**
- **読み方**: エスエフディー
- **意味**: フレームの開始を示す1バイトのパターン（10101011）
- **関連用語**: プリアンブル、フレーム同期

**SFP (Small Form-factor Pluggable)**
- **読み方**: エスエフピー
- **意味**: 光トランシーバーの規格。ホットスワップ可能
- **関連用語**: SFP+、GBIC、光モジュール

**STP/UTP (Shielded/Unshielded Twisted Pair)**
- **読み方**: エスティーピー・ユーティーピー
- **意味**: シールド付き/シールドなしツイストペアケーブル
- **関連用語**: ノイズ対策、電磁干渉

**TSN (Time-Sensitive Networking)**
- **読み方**: ティーエスエヌ
- **意味**: 時間に敏感なネットワーキング。決定的な低遅延通信を実現
- **関連用語**: リアルタイム通信、産業用イーサネット

**VLAN (Virtual LAN)**
- **読み方**: ブイラン
- **意味**: 仮想的にLANを分割する技術
- **関連用語**: IEEE 802.1Q、タグVLAN

### あ行

**オートネゴシエーション**
- **読み方**: おーとねごしえーしょん
- **意味**: 接続機器間で自動的に最適な通信速度とモードを決定する機能
- **関連用語**: 速度自動認識、デュプレックス

### か行

**カテゴリ（ケーブル）**
- **読み方**: かてごり
- **意味**: ツイストペアケーブルの性能分類。数字が大きいほど高性能
- **関連用語**: Cat5e、Cat6、Cat6A

**キャリアセンス**
- **読み方**: きゃりあせんす
- **意味**: 通信路が使用中かどうかを検知すること
- **関連用語**: CSMA/CD、衝突回避

**ギガビットイーサネット**
- **読み方**: ぎがびっといーさねっと
- **意味**: 1Gbpsの通信速度を持つイーサネット規格
- **関連用語**: 1000BASE-T、IEEE 802.3z/ab

**クロスケーブル**
- **読み方**: くろすけーぶる
- **意味**: 送信と受信の配線が交差したケーブル。同種機器間の接続に使用
- **関連用語**: ストレートケーブル、MDI/MDI-X

**コリジョン**
- **読み方**: こりじょん
- **意味**: 複数の機器が同時に送信することによるデータの衝突
- **関連用語**: CSMA/CD、コリジョンドメイン

### さ行

**シングルモード光ファイバー**
- **読み方**: しんぐるもーどひかりふぁいばー
- **意味**: コア径が小さく、単一のモードで光が伝搬する光ファイバー。長距離伝送用
- **関連用語**: マルチモード光ファイバー、コア径

**スイッチングハブ**
- **読み方**: すいっちんぐはぶ
- **意味**: MACアドレスを学習し、必要なポートにのみデータを転送する機器
- **関連用語**: レイヤ2スイッチ、ブリッジ

**ストレートケーブル**
- **読み方**: すとれーとけーぶる
- **意味**: 配線がストレートに接続されたケーブル。PC-スイッチ間などで使用
- **関連用語**: クロスケーブル、T568A/B

**全二重通信**
- **読み方**: ぜんにじゅうつうしん
- **意味**: 送信と受信を同時に行える通信方式
- **関連用語**: 半二重通信、フルデュプレックス

### た行

**ツイストペアケーブル**
- **読み方**: ついすとぺあけーぶる
- **意味**: 2本の導線をより合わせたケーブル。ノイズ低減効果がある
- **関連用語**: UTP、STP、より対線

**デュプレックス**
- **読み方**: でゅぷれっくす
- **意味**: 通信の双方向性を表す用語。全二重または半二重がある
- **関連用語**: フルデュプレックス、ハーフデュプレックス

### は行

**光ファイバー**
- **読み方**: ひかりふぁいばー
- **意味**: 光信号で通信を行うケーブル。電磁干渉を受けない
- **関連用語**: シングルモード、マルチモード、光トランシーバー

**ファストイーサネット**
- **読み方**: ふぁすといーさねっと
- **意味**: 100Mbpsの通信速度を持つイーサネット規格
- **関連用語**: 100BASE-TX、IEEE 802.3u

**フレーム**
- **読み方**: ふれーむ
- **意味**: イーサネットにおけるデータ伝送の単位
- **関連用語**: パケット、MTU

**プリアンブル**
- **読み方**: ぷりあんぶる
- **意味**: フレームの先頭に付加される同期用の7バイトのパターン
- **関連用語**: SFD、同期

### ま行

**マルチモード光ファイバー**
- **読み方**: まるちもーどひかりふぁいばー
- **意味**: コア径が大きく、複数のモードで光が伝搬する光ファイバー。短距離用
- **関連用語**: シングルモード光ファイバー、モード分散

### ら行

**リピーターハブ**
- **読み方**: りぴーたーはぶ
- **意味**: 受信した信号を増幅して全ポートに送信する機器
- **関連用語**: 物理層、信号増幅、コリジョンドメイン
