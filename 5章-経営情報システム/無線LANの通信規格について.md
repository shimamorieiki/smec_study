# 無線LANの通信規格について

## 概要
無線LAN（Wireless Local Area Network）は、電波を使用してデータ通信を行うネットワーク技術です。1997年にIEEE 802.11規格が策定されて以来、通信速度の向上、セキュリティの強化、省電力化など、継続的な進化を遂げています。現代のモバイルデバイスやIoT機器の普及により、無線LANは私たちの生活やビジネスに不可欠なインフラストラクチャとなっています。

## 1. 基本概念・仕組み

### 無線LANの基本原理
- **定義**: 電波を媒体として使用し、有線ケーブルを使わずにネットワーク接続を実現する技術
- **動作原理**: 
  - データを電波信号に変調して送信
  - 受信側で電波信号を復調してデータに戻す
  - CSMA/CA（Carrier Sense Multiple Access with Collision Avoidance）によるアクセス制御
- **特徴**: 
  - 物理的な配線が不要で設置の自由度が高い
  - 複数の機器が同時に接続可能
  - 電波の到達範囲内で移動しながら通信可能

### 有線LANとの比較
- **従来技術との違い**: 
  - 物理的なケーブル接続が不要
  - 設置・移設が容易
  - 同時接続数に制限がある
- **改善点**: 
  - モビリティの実現
  - 配線コストの削減
  - 設置の柔軟性
- **限界**: 
  - 通信速度は有線に劣る場合が多い
  - 電波干渉の影響を受けやすい
  - セキュリティリスクが高い

## 2. 無線LAN規格の種類・分類

### IEEE 802.11規格の体系
無線LAN規格は、IEEE（米国電気電子学会）によって標準化されており、802.11の後にアルファベットを付けて各規格を区別します。

### IEEE 802.11b
**特徴:**
- 2.4GHz帯を使用
- 最大通信速度：11Mbps
- 1999年に策定された初期の実用的な規格

**技術仕様:**
```
周波数帯域: 2.4GHz（2.400～2.484GHz）
チャンネル数: 14ch（日本）、11ch（米国）
変調方式: CCK（Complementary Code Keying）
```

**📊 実効速度の計算例**
**例: オフィス環境での実効速度**
- 理論最大速度: 11Mbps
- オーバーヘッド: 約40%

**ステップ1: 実効速度の算出**
```
実効速度 = 理論速度 × (1 - オーバーヘッド率)
実効速度 = 11Mbps × 0.6 = 約6.6Mbps
```

**ステップ2: 実際のファイル転送時間**
```
100MBファイルの転送時間
= (100MB × 8bit) ÷ 6.6Mbps
= 800Mbit ÷ 6.6Mbps = 約121秒（約2分）
```

**結果: 実際の使用環境では理論値の約60%程度の速度**

💡 **実際の現場では**: 電子レンジなど2.4GHz帯を使用する機器との干渉に注意が必要

### IEEE 802.11a
**特徴:**
- 5GHz帯を使用
- 最大通信速度：54Mbps
- 電波干渉が少ない

**技術仕様:**
```
周波数帯域: 5GHz（5.15～5.35GHz、5.47～5.725GHz）
チャンネル数: 19ch（日本）
変調方式: OFDM（Orthogonal Frequency Division Multiplexing）
```

**📊 チャンネル設計の計算例**
**例: オフィスビルでのチャンネル配置**
- 利用可能チャンネル: W52（36,40,44,48ch）、W53（52,56,60,64ch）
- 各チャンネル幅: 20MHz

**ステップ1: 干渉しないチャンネル選択**
```
チャンネル間隔 = 20MHz
干渉回避には4チャンネル以上の間隔が必要
推奨配置: 36ch, 52ch, 64ch
```

**結果: 3つのアクセスポイントを干渉なく配置可能**

### IEEE 802.11g
**特徴:**
- 2.4GHz帯を使用
- 最大通信速度：54Mbps
- 802.11bとの下位互換性あり

**技術仕様:**
```
周波数帯域: 2.4GHz
変調方式: OFDM（高速時）、CCK（低速時）
互換性: 802.11b機器と混在可能
```

### IEEE 802.11n（Wi-Fi 4）
**特徴:**
- 2.4GHz/5GHz両対応
- 最大通信速度：600Mbps（理論値）
- MIMO技術の採用

**技術仕様:**
```
周波数帯域: 2.4GHz/5GHz（デュアルバンド）
チャンネル幅: 20MHz/40MHz
MIMO: 最大4×4
変調方式: OFDM
```

**📊 MIMO効果の計算例**
**例: MIMOストリーム数による速度向上**
- 基本速度（1ストリーム）: 150Mbps
- MIMO構成: 2×2、3×3、4×4

**計算:**
```
2×2 MIMO: 150Mbps × 2 = 300Mbps
3×3 MIMO: 150Mbps × 3 = 450Mbps
4×4 MIMO: 150Mbps × 4 = 600Mbps
```

### IEEE 802.11ac（Wi-Fi 5）
**特徴:**
- 5GHz帯専用
- 最大通信速度：6.9Gbps（理論値）
- MU-MIMO対応

**技術仕様:**
```
周波数帯域: 5GHz
チャンネル幅: 20/40/80/160MHz
MIMO: 最大8×8
変調方式: 256QAM
```

### IEEE 802.11ax（Wi-Fi 6/6E）
**特徴:**
- 2.4GHz/5GHz/6GHz対応（6Eは6GHz追加）
- 最大通信速度：9.6Gbps（理論値）
- OFDMA技術による効率化

**技術仕様:**
```
周波数帯域: 2.4GHz/5GHz/6GHz（6E）
チャンネル幅: 20/40/80/160MHz
MIMO: 最大8×8
変調方式: 1024QAM
新技術: OFDMA、Target Wake Time（TWT）
```

## 3. 主要技術とパラメータ

### 変調方式の詳細
#### QAM（Quadrature Amplitude Modulation）
- **意味**: 直交振幅変調、位相と振幅を組み合わせてデータを表現
- **設定範囲**: 16QAM、64QAM、256QAM、1024QAM
- **影響**: QAM値が大きいほど高速だが、ノイズに弱くなる
- **推奨値**: 
  - 近距離・安定環境：256QAM以上
  - 中距離・一般環境：64QAM
  - 遠距離・劣悪環境：16QAM

#### チャンネル幅
- **意味**: 通信に使用する周波数の幅
- **設定範囲**: 20MHz、40MHz、80MHz、160MHz
- **影響**: 幅が広いほど高速だが、干渉リスクが増加
- **推奨値**: 
  - 高密度環境：20MHz
  - 一般オフィス：40MHz
  - 低密度環境：80MHz以上

### セキュリティ規格
#### WEP（Wired Equivalent Privacy）
- **暗号化方式**: RC4
- **鍵長**: 64bit/128bit
- **脆弱性**: 既に破られており使用非推奨

#### WPA（Wi-Fi Protected Access）
- **暗号化方式**: TKIP
- **認証方式**: PSK/802.1X
- **改善点**: WEPの脆弱性を修正

#### WPA2
- **暗号化方式**: AES
- **認証方式**: PSK/802.1X
- **特徴**: 現在の標準的なセキュリティ規格

#### WPA3
- **暗号化方式**: AES-256
- **認証方式**: SAE（Simultaneous Authentication of Equals）
- **特徴**: 最新規格、より強固なセキュリティ

## 4. 実装例・適用事例

### 基本的なアクセスポイント設定
```bash
# Linux環境でのhostapd設定例
interface=wlan0
driver=nl80211
ssid=CompanyWiFi
hw_mode=g
channel=6
ieee80211n=1
wmm_enabled=1
ht_capab=[HT40+][SHORT-GI-40][DSSS_CCK-40]

# セキュリティ設定
auth_algs=1
wpa=2
wpa_key_mgmt=WPA-PSK
wpa_pairwise=CCMP
rsn_pairwise=CCMP
wpa_passphrase=SecurePassword123!
```

### エンタープライズ環境での実装
```bash
# RADIUS認証を使用した802.1X設定
ieee8021x=1
eap_server=0
auth_server_addr=192.168.1.10
auth_server_port=1812
auth_server_shared_secret=radius_secret

# VLANタギング
dynamic_vlan=1
vlan_file=/etc/hostapd/hostapd.vlan
```

### 実際の適用事例
#### 事例1: 大手製造業A社のスマート工場
- **課題**: 有線LANでは生産ラインの変更に対応困難
- **適用方法**: 802.11ax（Wi-Fi 6）を全面採用、産業用APを配置
- **結果**: 
  - 生産ライン変更時間を80%短縮
  - IoTセンサー1,000台以上を安定接続
  - リアルタイムデータ収集により品質向上
- **効果**: 年間5,000万円のコスト削減

#### 事例2: 教育機関B大学のキャンパスWi-Fi
- **課題**: 学生・教職員20,000人の同時接続対応
- **適用方法**: 
  - 802.11acを基幹として整備
  - eduroamによる相互接続対応
  - 高密度エリアにはWi-Fi 6を追加導入
- **結果**: 
  - 同時接続数15,000台を実現
  - 平均速度100Mbps以上を維持
  - オンライン授業の全面実施が可能に
- **効果**: 学習環境の大幅な改善、他大学との連携強化

## 5. メリット・デメリット

### メリット
**1. 配線の自由度**
- **理由**: 物理的なケーブルが不要
- **効果**: レイアウト変更が容易、初期コスト削減
- **具体例**: オフィスのフリーアドレス化により、座席利用率30%向上

**2. モビリティの実現**
- **理由**: 移動しながらの通信が可能
- **効果**: 業務効率の向上、新しい働き方の実現
- **具体例**: 倉庫内でタブレットを使用した在庫管理により、作業時間50%短縮

**3. 拡張性の高さ**
- **理由**: アクセスポイントの追加で容易に拡張可能
- **効果**: 段階的な投資が可能、需要に応じた柔軟な対応
- **具体例**: イベント時の一時的な増設により、来場者満足度向上

### デメリット
**1. セキュリティリスク**
- **理由**: 電波は物理的に遮断できない
- **影響**: 不正アクセスや盗聴のリスク
- **対策**: WPA3の使用、VPNとの併用、定期的なセキュリティ監査

**2. 通信の不安定性**
- **理由**: 電波干渉や障害物の影響を受ける
- **影響**: 通信速度の低下、接続の切断
- **対策**: サイトサーベイの実施、適切なチャンネル設計、冗長構成

**3. 有線LANに比べて速度が劣る**
- **理由**: 電波の物理的制約、共有媒体のため
- **影響**: 大容量データ転送には不向き
- **対策**: 重要なサーバーは有線接続、Wi-Fi 6/6Eの導入

## 8. 理解度確認クイズ（4択問題20問）

### 問題1
無線LANで使用されるアクセス制御方式として正しいものはどれか？

- A) CSMA/CD
- B) CSMA/CA
- C) Token Ring
- D) FDDI

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
正解はBのCSMA/CA（Carrier Sense Multiple Access with Collision Avoidance）です。無線LANでは電波の特性上、衝突を検出することが困難なため、事前に衝突を回避する方式を採用しています。<br>
<br>
Aが間違いの理由：CSMA/CDは有線LANで使用される衝突検出方式<br>
Cが間違いの理由：Token Ringは古い有線LAN規格<br>
Dが間違いの理由：FDDIは光ファイバーを使用した有線LAN規格<br>
<br>
【補足】実務では、このアクセス制御の違いにより、無線LANは有線LANに比べて実効速度が低下することを理解しておく必要があります。
</details>

### 問題2
IEEE 802.11nの特徴として誤っているものはどれか？

- A) 2.4GHz帯と5GHz帯の両方に対応
- B) MIMO技術を採用
- C) 最大通信速度は54Mbps
- D) Wi-Fi 4とも呼ばれる

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
正解はCです。IEEE 802.11nの最大通信速度は600Mbps（理論値）であり、54Mbpsは802.11a/gの最大速度です。<br>
<br>
Aが正しい理由：802.11nはデュアルバンド対応<br>
Bが正しい理由：MIMO技術により複数アンテナで高速化を実現<br>
Dが正しい理由：Wi-Fi Allianceにより802.11nはWi-Fi 4と命名<br>
<br>
【補足】実際の環境では、使用するMIMO数やチャンネル幅により速度が変動します。
</details>

### 問題3
5GHz帯を使用する無線LAN規格の組み合わせとして正しいものはどれか？

- A) 802.11b、802.11g
- B) 802.11a、802.11ac
- C) 802.11b、802.11n
- D) 802.11g、802.11ax

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
正解はBです。802.11aは5GHz帯専用、802.11acも5GHz帯専用の規格です。<br>
<br>
Aが間違いの理由：両方とも2.4GHz帯のみ使用<br>
Cが間違いの理由：802.11bは2.4GHz帯のみ（802.11nは両対応）<br>
Dが間違いの理由：802.11gは2.4GHz帯のみ（802.11axは両対応）<br>
<br>
【補足】5GHz帯は電波干渉が少ない反面、障害物に弱く到達距離が短いという特性があります。
</details>

### 問題4
WPA2で使用される暗号化方式はどれか？

- A) WEP
- B) TKIP
- C) AES
- D) DES

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
正解はCのAES（Advanced Encryption Standard）です。WPA2ではCCMP（Counter Mode with CBC-MAC Protocol）としてAESを使用します。<br>
<br>
Aが間違いの理由：WEPは初期の脆弱な暗号化方式<br>
Bが間違いの理由：TKIPはWPAで使用される暗号化方式<br>
Dが間違いの理由：DESは古い暗号化方式で無線LANでは使用しない<br>
<br>
【補足】現在はWPA3が最新規格ですが、多くの環境ではWPA2が標準として使用されています。
</details>

### 問題5
チャンネル幅を20MHzから40MHzに変更した場合の影響として適切なものはどれか？

- A) 通信速度が向上するが、使用可能なチャンネル数が減少する
- B) 通信速度は変わらないが、到達距離が延びる
- C) 消費電力が減少する
- D) セキュリティが向上する

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
正解はAです。チャンネル幅を広げると理論上の通信速度は2倍になりますが、使用する周波数帯域が広がるため、干渉を避けて配置できるチャンネル数が減少します。<br>
<br>
Bが間違いの理由：通信速度は向上し、到達距離はむしろ短くなる傾向<br>
Cが間違いの理由：より多くのデータを処理するため消費電力は増加<br>
Dが間違いの理由：チャンネル幅とセキュリティは直接関係しない<br>
<br>
【補足】高密度環境では20MHz幅を使用し、干渉を最小限に抑えることが推奨されます。
</details>

### 問題6
MIMOの「2×2」という表記が示すものは何か？

- A) 周波数帯域の幅
- B) 送信アンテナ数×受信アンテナ数
- C) 最大接続台数
- D) チャンネル数

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
正解はBです。MIMO（Multiple Input Multiple Output）の表記は「送信アンテナ数×受信アンテナ数」を表します。2×2は送信2本、受信2本のアンテナ構成を意味します。<br>
<br>
Aが間違いの理由：周波数帯域幅はMHzで表記<br>
Cが間違いの理由：最大接続台数とは無関係<br>
Dが間違いの理由：チャンネル数とは無関係<br>
<br>
【補足】MIMOのストリーム数が多いほど理論上の通信速度は向上しますが、実装コストも増加します。
</details>

### 問題7
802.11axで新たに採用された技術はどれか？

- A) MIMO
- B) OFDM
- C) OFDMA
- D) QAM

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
正解はCのOFDMA（Orthogonal Frequency Division Multiple Access）です。802.11ax（Wi-Fi 6）で初めて採用され、複数端末への同時通信効率を大幅に向上させました。<br>
<br>
Aが間違いの理由：MIMOは802.11nから採用<br>
Bが間違いの理由：OFDMは802.11aから採用<br>
Dが間違いの理由：QAM自体は以前から使用（1024QAMは802.11axで採用）<br>
<br>
【補足】OFDMAにより、高密度環境での通信効率が従来の4倍程度まで向上します。
</details>

### 問題8
電子レンジが無線LANに干渉する理由として正しいものはどれか？

- A) 電子レンジが5GHz帯を使用するため
- B) 電子レンジが2.4GHz帯を使用するため
- C) 電子レンジが強い磁場を発生させるため
- D) 電子レンジが有線LANに接続されているため

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
正解はBです。電子レンジは食品を加熱するために2.45GHzのマイクロ波を使用しており、これが2.4GHz帯の無線LANと干渉します。<br>
<br>
Aが間違いの理由：電子レンジは5GHz帯を使用しない<br>
Cが間違いの理由：磁場ではなく電磁波（マイクロ波）による干渉<br>
Dが間違いの理由：電子レンジの有線LAN接続は無関係<br>
<br>
【補足】この問題を回避するため、重要な通信には5GHz帯の使用が推奨されます。
</details>

### 問題9
エンタープライズ環境でよく使用される認証方式はどれか？

- A) WEP
- B) PSK（Pre-Shared Key）
- C) 802.1X
- D) WPS

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
正解はCの802.1Xです。RADIUSサーバーと連携し、ユーザーごとの認証が可能なため、企業環境で広く採用されています。<br>
<br>
Aが間違いの理由：WEPは脆弱で企業使用は非推奨<br>
Bが間違いの理由：PSKは家庭や小規模向けで、共通パスワードのため管理が困難<br>
Dが間違いの理由：WPSは簡易接続用で、セキュリティリスクがある<br>
<br>

## 9. 専門用語集

このスライドで使用された技術用語について、アルファベット順・50音順で解説します。

### アルファベット

**AES (Advanced Encryption Standard)**
- **読み方**: エーイーエス
- **意味**: 米国政府標準の暗号化方式。128/192/256ビットの鍵長に対応し、WPA2/WPA3で採用されている強固な暗号化アルゴリズム
- **関連用語**: WPA2、CCMP、暗号化

**AP (Access Point)**
- **読み方**: アクセスポイント
- **意味**: 無線LAN端末を有線ネットワークに接続するための基地局装置。無線ルーターと異なり、純粋にブリッジ機能のみを持つ
- **関連用語**: 無線ルーター、SSID、ビーコン

**CSMA/CA (Carrier Sense Multiple Access with Collision Avoidance)**
- **読み方**: シーエスエムエー・シーエー
- **意味**: 無線LANで使用される衝突回避方式。送信前に電波の使用状況を確認し、衝突を事前に回避する
- **関連用語**: CSMA/CD、衝突回避、バックオフ

**DFS (Dynamic Frequency Selection)**
- **読み方**: ディーエフエス
- **意味**: 5GHz帯で気象レーダーなどとの干渉を避けるため、使用チャンネルを自動的に切り替える機能
- **関連用語**: W53、W56、レーダー検出

**IEEE (Institute of Electrical and Electronics Engineers)**
- **読み方**: アイトリプルイー
- **意味**: 電気・電子技術に関する国際的な標準化団体。無線LAN規格802.11シリーズを策定
- **関連用語**: 802.11、標準化、Wi-Fi Alliance

**MIMO (Multiple Input Multiple Output)**
- **読み方**: マイモ
- **意味**: 複数のアンテナを使用して送受信を行い、通信速度を向上させる技術
- **関連用語**: 空間多重、ストリーム、MU-MIMO

**OFDM (Orthogonal Frequency Division Multiplexing)**
- **読み方**: オーエフディーエム
- **意味**: 直交周波数分割多重方式。複数の搬送波を使用して高速通信を実現する変調方式
- **関連用語**: 変調方式、サブキャリア、OFDMA

**OFDMA (Orthogonal Frequency Division Multiple Access)**
- **読み方**: オーエフディーエムエー
- **意味**: Wi-Fi 6で採用された技術。OFDMを拡張し、複数端末への同時通信を効率化
- **関連用語**: Wi-Fi 6、802.11ax、マルチユーザー

**PSK (Pre-Shared Key)**
- **読み方**: ピーエスケー
- **意味**: 事前共有鍵。WPA/WPA2で使用される、パスワードを事前に共有する認証方式
- **関連用語**: WPA、パスフレーズ、認証

**QAM (Quadrature Amplitude Modulation)**
- **読み方**: キューエーエム
- **意味**: 直交振幅変調。位相と振幅を組み合わせてデータを表現する変調方式
- **関連用語**: 変調方式、256QAM、1024QAM

**RADIUS (Remote Authentication Dial-In User Service)**
- **読み方**: ラディウス
- **意味**: ネットワーク認証プロトコル。802.1X認証で使用される認証サーバー
- **関連用語**: 802.1X、EAP、認証サーバー

**SSID (Service Set Identifier)**
- **読み方**: エスエスアイディー
- **意味**: 無線LANネットワークを識別するための名前。最大32文字の英数字で設定可能
- **関連用語**: ネットワーク名、ビーコン、ESSID

**TKIP (Temporal Key Integrity Protocol)**
- **読み方**: ティーキップ
- **意味**: WPAで使用される暗号化プロトコル。WEPの脆弱性を修正するため開発された
- **関連用語**: WPA、暗号化、RC4

**TWT (Target Wake Time)**
- **読み方**: ティーダブリューティー
- **意味**: Wi-Fi 6で導入された省電力機能。端末の通信タイミングをスケジューリングする
- **関連用語**: Wi-Fi 6、省電力、スリープ

**VLAN (Virtual Local Area Network)**
- **読み方**: ブイラン
- **意味**: 物理的な接続に依存せず、論理的にネットワークを分割する技術
- **関連用語**: ネットワーク分離、タギング、セグメント

**WEP (Wired Equivalent Privacy)**
- **読み方**: ウェップ
- **意味**: 初期の無線LAN暗号化方式。現在は脆弱性が発見され使用非推奨
- **関連用語**: RC4、暗号化、脆弱性

**Wi-Fi (Wireless Fidelity)**
- **読み方**: ワイファイ
- **意味**: Wi-Fi Allianceが認定する無線LAN規格の総称。IEEE 802.11規格に準拠
- **関連用語**: 無線LAN、802.11、Wi-Fi Alliance

**WPA (Wi-Fi Protected Access)**
- **読み方**: ダブリューピーエー
- **意味**: WEPの脆弱性を改善した暗号化規格。TKIP暗号化を使用
- **関連用語**: TKIP、セキュリティ、暗号化

**WPS (Wi-Fi Protected Setup)**
- **読み方**: ダブリューピーエス
- **意味**: ボタンやPINコードで簡単に無線LAN接続を設定する機能
- **関連用語**: 簡単設定、PINコード、プッシュボタン

### あ行

**アクセス制御**
- **読み方**: あくせすせいぎょ
- **意味**: ネットワークへの接続を管理・制限する仕組み。MACアドレスフィルタリングなどが該当
- **関連用語**: MACアドレス、認証、フィルタリング

**暗号化**
- **読み方**: あんごうか
- **意味**: データを第三者が読めない形式に変換すること。無線LANでは通信内容の保護に使用
- **関連用語**: WEP、WPA、AES

**インフラストラクチャモード**
- **読み方**: いんふらすとらくちゃもーど
- **意味**: アクセスポイントを介して通信を行う一般的な無線LAN接続方式
- **関連用語**: アドホックモード、AP、基地局

**エンタープライズ認証**
- **読み方**: えんたーぷらいずにんしょう
- **意味**: 802.1X/EAPを使用した企業向け認証方式。個別のユーザー認証が可能
- **関連用語**: 802.1X、RADIUS、EAP

### か行

**干渉**
- **読み方**: かんしょう
- **意味**: 同じ周波数帯を使用する機器同士が互いに影響を与え合い、通信品質が低下する現象
- **関連用語**: 電子レンジ、チャンネル、ノイズ

**キャプティブポータル**
- **読み方**: きゃぷてぃぶぽーたる
- **意味**: 公衆無線LANなどで、インターネット接続前に表示される認証・同意画面
- **関連用語**: 認証、公衆無線LAN、利用規約

**空間多重**
- **読み方**: くうかんたじゅう
- **意味**: MIMO技術で複数のアンテナを使い、同じ周波数で複数のデータストリームを送信する技術
- **関連用語**: MIMO、ストリーム、多重化

### さ行

**サイトサーベイ**
- **読み方**: さいとさーべい
- **意味**: 無線LAN構築前に電波環境を調査し、最適なAP配置を決定する作業
- **関連用語**: 電波調査、チャンネル設計、カバレッジ

**周波数帯**
- **読み方**: しゅうはすうたい
- **意味**: 無線通信で使用する電波の周波数範囲。無線LANでは主に2.4GHz、5GHz、6GHz帯を使用
- **関連用語**: 2.4GHz、5GHz、チャンネル

**ステルスSSID**
- **読み方**: すてるすえすえすあいでぃー
- **意味**: SSIDをビーコンで通知しない設定。セキュリティ効果は限定的
- **関連用語**: SSID、ビーコン、隠蔽

**セキュリティプロトコル**
- **読み方**: せきゅりてぃぷろとこる
- **意味**: 無線LAN通信を保護するための規約。WEP、WPA、WPA2、WPA3などが該当
- **関連用語**: 暗号化、認証、プロトコル

### た行

**帯域幅**
- **読み方**: たいいきはば
- **意味**: 通信に使用する周波数の幅。20MHz、40MHz、80MHz、160MHzなどがある
- **関連用語**: チャンネル幅、周波数、スペクトラム

**チャンネル**
- **読み方**: ちゃんねる
- **意味**: 無線LANで使用する周波数を分割した単位。2.4GHz帯は1-14ch、5GHz帯は36ch以降
- **関連用語**: 周波数、チャンネル幅、非重複チャンネル

**チャンネルボンディング**
- **読み方**: ちゃんねるぼんでぃんぐ
- **意味**: 複数のチャンネルを束ねて使用し、通信速度を向上させる技術
- **関連用語**: チャンネル幅、40MHz、80MHz

**デュアルバンド**
- **読み方**: でゅあるばんど
- **意味**: 2.4GHz帯と5GHz帯の両方に対応すること。柔軟な運用が可能
- **関連用語**: トライバンド、周波数帯、マルチバンド

### な行

**認証**
- **読み方**: にんしょう
- **意味**: ネットワークに接続する端末や利用者の正当性を確認すること
- **関連用語**: WPA、802.1X、パスワード

**ノイズフロア**
- **読み方**: のいずふろあ
- **意味**: 環境に存在する背景雑音のレベル。これより弱い信号は検出できない
- **関連用語**: SNR、信号強度、干渉

### は行

**パスフレーズ**
- **読み方**: ぱすふれーず
- **意味**: WPA/WPA2で使用する8～63文字のパスワード。PSK認証で使用
- **関連用語**: PSK、パスワード、認証

**ビーコン**
- **読み方**: びーこん
- **意味**: アクセスポイントが定期的に送信する、ネットワークの存在を通知する信号
- **関連用語**: SSID、ビーコン間隔、管理フレーム

**ビームフォーミング**
- **読み方**: びーむふぉーみんぐ
- **意味**: 特定の端末に向けて電波を集中させ、通信品質を向上させる技術
- **関連用語**: 指向性、アンテナ、802.11ac

**ブリッジモード**
- **読み方**: ぶりっじもーど
- **意味**: 無線と有線のネットワークを単純に接続するモード。ルーティング機能は持たない
- **関連用語**: ルーターモード、AP、透過モード

**プローブ要求**
- **読み方**: ぷろーぶようきゅう
- **意味**: 端末がアクセスポイントを探すために送信する信号
- **関連用語**: プローブ応答、アクティブスキャン、SSID

**変調方式**
- **読み方**: へんちょうほうしき
- **意味**: デジタルデータを電波信号に変換する方法。OFDM、QAMなどがある
- **関連用語**: OFDM、QAM、変調

### ま行

**マルチSSID**
- **読み方**: まるちえすえすあいでぃー
- **意味**: 1台のアクセスポイントで複数のSSIDを同時に運用する機能
- **関連用語**: SSID、VLAN、ゲストネットワーク

**無線LANコントローラー**
- **読み方**: むせんらんこんとろーらー
- **意味**: 複数のアクセスポイントを集中管理する装置。大規模環境で使用
- **関連用語**: 集中管理、WLC、エンタープライズ

**メッシュネットワーク**
- **読み方**: めっしゅねっとわーく
- **意味**: 複数のノードが相互に接続し、自動的に最適な経路を選択するネットワーク
- **関連用語**: メッシュWi-Fi、バックホール、自己修復

### ら行

**ローミング**
- **読み方**: ろーみんぐ
- **意味**: 移動中に接続するアクセスポイントを自動的に切り替える機能
- **関連用語**: ハンドオーバー、シームレス、802.11r

**レガシーレート**
- **読み方**: れがしーれーと
- **意味**: 古い規格との互換性のために残されている低速な通信速度
- **関連用語**: 下位互換、802.11b、管理フレーム

### わ行

**ワイヤレスブリッジ**
- **読み方**: わいやれすぶりっじ
- **意味**: 離れた場所の有線ネットワーク同士を無線で接続する機能
- **関連用語**: WDS、ブリッジ、ポイントツーポイント
