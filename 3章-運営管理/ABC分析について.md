# ABC分析について

## 概要
ABC分析は、在庫管理や品質管理において、管理対象を重要度に応じて分類し、効率的な管理を実現するための手法です。パレートの法則（80:20の法則）に基づき、「少数の重要な項目が全体の大部分を占める」という考え方を応用しています。在庫管理においては、売上高や在庫金額の累積比率に基づいて品目を3つのグループに分類し、それぞれに適した管理方法を適用することで、限られた経営資源を効果的に配分できます。

## 1. 基本概念・仕組み

### ABC分析の定義
- **定義**: 管理対象を重要度に応じてA群（重要）、B群（普通）、C群（軽微）の3つのグループに分類し、それぞれに適した管理方法を適用する手法
- **動作原理**: 売上高、在庫金額、利益貢献度などの指標を基に累積比率を計算し、その比率に応じて分類を行う
- **特徴**: パレートの法則に基づき、少数の品目が全体の価値の大部分を占めることを前提とした分析手法

### パレートの法則との関係
- **従来技術との違い**: 全品目を一律に管理するのではなく、重要度に応じた差別化管理を行う
- **改善点**: 管理コストの削減と管理精度の向上を同時に実現
- **限界**: 定量的指標のみでの分類のため、定性的要因（顧客の重要性、戦略的価値など）を考慮しない場合がある

## 2. 分類基準と各グループの特徴

### 分類基準
ABC分析では、以下の基準に基づいて品目を分類します：
- 累積売上高比率
- 累積在庫金額比率
- 累積利益貢献度比率
- 累積取引回数比率

### A群: 重要管理品目
**特徴:**
- 品目数は全体の10-20%程度
- 売上高・在庫金額は全体の70-80%を占める
- 高い管理精度が要求される

**算出方法:**
```
A群の基準：累積比率70-80%まで
```

**📊 具体的な計算例**
**例: 電子部品メーカーの在庫管理**
- 全品目数: 1,000品目
- 年間総売上高: 10億円

**ステップ1: 各品目の売上高を降順に並べ替え**
```
品目1: 1.5億円
品目2: 1.2億円
品目3: 0.8億円
...
```

**ステップ2: 累積売上高と累積比率を計算**
```
品目1: 1.5億円 (累積: 1.5億円、累積比率: 15%)
品目2: 1.2億円 (累積: 2.7億円、累積比率: 27%)
品目3: 0.8億円 (累積: 3.5億円、累積比率: 35%)
...
品目150: 累積比率75%に到達
```

**結果: 上位150品目（全体の15%）がA群に分類**

💡 **実際の現場では**: A群品目は日次での在庫確認、定期的な需要予測の見直し、安全在庫の精緻な設定などの重点管理を行います。

### B群: 中間管理品目
**特徴:**
- 品目数は全体の20-30%程度
- 売上高・在庫金額は全体の15-20%を占める
- 標準的な管理レベルで対応

**算出方法:**
```
B群の基準：累積比率80-95%の範囲
```

**📊 具体的な計算例**
**例: 同じ電子部品メーカーの続き**

**ステップ3: A群の次の品目から累積計算を継続**
```
品目151: 累積比率75.2%
品目152: 累積比率75.4%
...
品目400: 累積比率95%に到達
```

**結果: 品目151-400（全体の25%）がB群に分類**

💡 **実際の現場では**: B群品目は週次での在庫確認、月次での発注点の見直しなど、A群より管理頻度を下げた運用を行います。

### C群: 軽微管理品目
**特徴:**
- 品目数は全体の50-70%程度
- 売上高・在庫金額は全体の5-10%を占める
- 簡易的な管理で十分

**算出方法:**
```
C群の基準：累積比率95%以降
```

**📊 具体的な計算例**
**例: 同じ電子部品メーカーの続き**

**ステップ4: 残りの品目をC群に分類**
```
品目401-1000: 累積比率95-100%
```

**結果: 品目401-1000（全体の60%）がC群に分類**

💡 **実際の現場では**: C群品目は月次での在庫確認、大量購入による単価削減、定量発注方式の採用など、管理コストを最小化する運用を行います。

## 3. 実装手順と詳細計算

### 基本的な実装手順
1. **データ収集**
   - 各品目の売上高データ
   - 在庫金額データ
   - 必要に応じて利益データ

2. **データの並べ替え**
   - 分析指標（売上高など）の降順でソート

3. **累積値の計算**
   - 各品目の累積売上高を計算
   - 累積比率を算出

4. **グループ分類**
   - 累積比率に基づいてA・B・C群に分類

5. **管理方針の設定**
   - 各グループに適した管理方法を決定

### 詳細な計算例
```python
# Python実装例
import pandas as pd
import numpy as np

def abc_analysis(data, value_column, item_column):
    # データを値の降順でソート
    sorted_data = data.sort_values(by=value_column, ascending=False)
    
    # 累積値と累積比率を計算
    sorted_data['累積値'] = sorted_data[value_column].cumsum()
    sorted_data['累積比率'] = sorted_data['累積値'] / sorted_data[value_column].sum() * 100
    
    # ABC分類
    conditions = [
        sorted_data['累積比率'] <= 80,
        sorted_data['累積比率'] <= 95,
        sorted_data['累積比率'] > 95
    ]
    choices = ['A', 'B', 'C']
    sorted_data['分類'] = np.select(conditions, choices)
    
    return sorted_data
```

### 実際の適用事例
#### 事例1: 自動車部品製造業
- **課題**: 20,000点以上の部品在庫の管理効率化
- **適用方法**: 年間使用金額を基準にABC分析を実施
- **結果**: A群2,000品目（10%）が総在庫金額の75%を占めることが判明
- **効果**: A群品目の在庫回転率を2倍に改善、在庫保有コスト20%削減

#### 事例2: 小売チェーン店
- **課題**: 商品別の発注業務の効率化
- **適用方法**: 売上高と利益率を組み合わせた2軸ABC分析を実施
- **結果**: 高売上・高利益率商品の重点管理体制を構築
- **効果**: 欠品率50%削減、利益率3ポイント向上

## 4. 管理方法の詳細

### A群の管理方法
1. **在庫管理**
   - 日次での在庫確認
   - 定期発注方式の採用
   - 精緻な需要予測

2. **発注管理**
   - EOQ（経済的発注量）の算出
   - リードタイムの短縮交渉
   - 複数サプライヤーの確保

3. **品質管理**
   - 受入検査の全数実施
   - トレーサビリティの確保

### B群の管理方法
1. **在庫管理**
   - 週次での在庫確認
   - 定量発注方式の検討
   - 標準的な安全在庫の設定

2. **発注管理**
   - 月次での発注点見直し
   - 標準的なリードタイム設定

### C群の管理方法
1. **在庫管理**
   - 月次での在庫確認
   - ダブルビン方式の採用
   - 大量購入による単価削減

2. **発注管理**
   - 年間契約による一括購入
   - 自動発注システムの活用

## 5. メリット・デメリット

### メリット
**1. 管理効率の向上**
- **理由**: 重要品目に管理資源を集中できる
- **効果**: 限られた人員で効果的な在庫管理が可能
- **具体例**: A群品目の在庫精度99%以上を少人数で実現

**2. コスト削減**
- **理由**: 品目の重要度に応じた差別化管理
- **効果**: 在庫保有コスト、管理コストの削減
- **具体例**: C群品目の管理簡素化により管理工数30%削減

**3. 在庫最適化**
- **理由**: 重要品目の適正在庫維持
- **効果**: 欠品リスクの低減と過剰在庫の削減
- **具体例**: A群品目の欠品率1%未満を維持しながら在庫回転率向上

### デメリット
**1. 定性的要因の軽視**
- **理由**: 数値データのみに基づく分類
- **影響**: 戦略的重要性を持つ低売上品目の軽視
- **対策**: 定性的評価を加味した修正ABC分析の実施

**2. 分類の固定化**
- **理由**: 一度分類すると見直しが疎かになりがち
- **影響**: 市場変化への対応遅れ
- **対策**: 定期的（四半期ごと）な分類見直しの実施

## 6. 選択・導入の指針

### ABC分析の適用判断基準
| 観点 | 適している | 適していない | 
|------|-----------|--------------|
| 品目数 | 多品種（100品目以上） | 少品種（50品目未満） |
| 売上分布 | 偏りが大きい | 均等に分散 |
| 管理資源 | 限定的 | 十分にある |
| 業種 | 製造業、小売業 | 受注生産業 |

### 適用判断フローチャート
1. **品目数は100以上か？** 
   - Yes → 次の判断へ
   - No → 他の管理手法を検討

2. **売上の偏りは大きいか？**
   - Yes → ABC分析を推奨  
   - No → 品目特性別管理を検討

3. **管理資源は限定的か？**
   - Yes → ABC分析を強く推奨
   - No → より精緻な個別管理も選択肢

Bが間違いの理由：品目数の削減とは関係ない<br>
Dが間違いの理由：在庫ゼロは現実的ではない<br>
<br>
【補足】例えば、売上は少ないが生産に必須の部品（C群だがVital）を適切に管理できます。
</details>

- B) 年1回まとめて発注

<summary>解答</summary>

<br>
【補足】実際のEOQ=√(2×1,200×2,000÷(100×0.2))≒490個ですが、C群には簡易管理を適用します。
</details>

## 9. 専門用語集

### アルファベット

**ABC分析 (ABC Analysis)**
- **読み方**: エービーシーぶんせき
- **意味**: 在庫品目を重要度に応じてA・B・Cの3つのグループに分類し、それぞれに適した管理方法を適用する手法
- **関連用語**: パレート分析、重点管理

**EOQ (Economic Order Quantity)**
- **読み方**: イーオーキュー、経済的発注量
- **意味**: 発注費用と在庫維持費用の合計を最小化する最適な発注量を算出する手法
- **関連用語**: 定量発注方式、在庫管理

**FSN分析 (Fast/Slow/Non-moving Analysis)**
- **読み方**: エフエスエヌぶんせき
- **意味**: 在庫の動きの速さによってFast（高回転）、Slow（低回転）、Non-moving（不動）に分類する手法
- **関連用語**: 在庫回転率、ABC分析

**JIT (Just In Time)**
- **読み方**: ジャストインタイム
- **意味**: 必要なものを、必要な時に、必要な量だけ生産・調達する方式
- **関連用語**: トヨタ生産方式、在庫削減

**VED分析 (Vital/Essential/Desirable Analysis)**
- **読み方**: ブイイーディーぶんせき
- **意味**: 品目の重要性をVital（必須）、Essential（重要）、Desirable（望ましい）に分類する手法
- **関連用語**: ABC分析、重要度分析

**VMI (Vendor Managed Inventory)**
- **読み方**: ベンダー管理在庫
- **意味**: 納入業者が顧客の在庫を管理し、適切なタイミングで補充を行う方式
- **関連用語**: サプライチェーン管理、在庫管理

**XYZ分析 (XYZ Analysis)**
- **読み方**: エックスワイゼットぶんせき
- **意味**: 需要の変動性によってX（安定）、Y（変動）、Z（不規則）に分類する手法
- **関連用語**: 需要予測、ABC分析

### あ行

**安全在庫（あんぜんざいこ）**
- **読み方**: あんぜんざいこ
- **意味**: 需要変動や納期遅延などの不確実性に対応するために保有する在庫
- **関連用語**: 在庫管理、サービスレベル

### か行

**欠品（けっぴん）**
- **読み方**: けっぴん
- **意味**: 顧客の需要に対して在庫が不足し、供給できない状態
- **関連用語**: 在庫切れ、機会損失

**経済的発注量（けいざいてきはっちゅうりょう）**
- **読み方**: けいざいてきはっちゅうりょう
- **意味**: EOQの日本語訳。発注費用と在庫維持費用の合計を最小化する発注量
- **関連用語**: EOQ、最適発注量

### さ行

**在庫回転率（ざいこかいてんりつ）**
- **読み方**: ざいこかいてんりつ
- **意味**: 一定期間に在庫が何回転したかを示す指標。売上高÷平均在庫高で算出
- **関連用語**: 在庫効率、資金効率

**在庫維持費（ざいこいじひ）**
- **読み方**: ざいこいじひ
- **意味**: 在庫を保有することで発生する費用。保管費、資本費、劣化損失費など
- **関連用語**: 在庫コスト、保管コスト

### た行

**ダブルビン方式（だぶるびんほうしき）**
- **読み方**: だぶるびんほうしき
- **意味**: 2つの容器を使い、1つが空になったら発注する簡易的な在庫管理方式
- **関連用語**: 定量発注方式、ビジュアル管理

**定期発注方式（ていきはっちゅうほうしき）**
- **読み方**: ていきはっちゅうほうしき
- **意味**: 一定期間ごとに在庫を確認し、目標在庫量までの差分を発注する方式
- **関連用語**: 発注方式、在庫管理

**定量発注方式（ていりょうはっちゅうほうしき）**
- **読み方**: ていりょうはっちゅうほうしき
- **意味**: 在庫が一定量（発注点）まで減少したら、あらかじめ決めた一定量を発注する方式
- **関連用語**: 発注点、発注方式

### は行

**パレートの法則（ぱれーとのほうそく）**
- **読み方**: ぱれーとのほうそく
- **意味**: 全体の80%の結果は20%の要因によって生み出されるという経験則。80:20の法則とも呼ばれる
- **関連用語**: ABC分析、重点管理

**発注点（はっちゅうてん）**
- **読み方**: はっちゅうてん
- **意味**: 定量発注方式において、この在庫量に達したら発注を行うという基準となる在庫量
- **関連用語**: 定量発注方式、安全在庫

### ま行

**見込み生産（みこみせいさん）**
- **読み方**: みこみせいさん
- **意味**: 需要予測に基づいて事前に生産し、在庫として保有する生産方式
- **関連用語**: 受注生産、在庫管理

### ら行

**リードタイム（りーどたいむ）**
- **読み方**: りーどたいむ
- **意味**: 発注から納品までに要する時間
- **関連用語**: 納期、調達期間

**累積比率（るいせきひりつ）**
- **読み方**: るいせきひりつ
- **意味**: ABC分析において、上位から順に加算した値の全体に対する割合
- **関連用語**: ABC分析、パレート図
