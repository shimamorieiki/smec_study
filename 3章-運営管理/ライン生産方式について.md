# ライン生産方式について

## 概要

ライン生産方式は、製品を連続的に生産するための生産システムで、工程順に設備や作業者を配置し、製品が一定の流れに沿って加工される生産方式です。自動車産業をはじめ、家電製品、食品加工など多くの産業で採用されており、大量生産を効率的に行うための基本的な生産システムです。ヘンリー・フォードが自動車生産に導入したことで有名になり、現代では様々な改良が加えられています。

## 1. ライン生産方式の基本概念

### ライン生産方式の定義
- **定義**: 製品の加工順序に従って、設備や作業者を配置し、一定のペースで製品を流す生産方式
- **特徴**: 連続性、同期性、専門化、標準化された作業
- **重要性**: 大量生産の効率化、品質の安定化、コスト削減の実現

### ライン生産の基本要素
- **工程（ワークステーション）**: 特定の作業を行う作業場所
- **作業時間**: 各工程で必要な作業時間
- **製品の流れ**: 工程間を移動する製品の動線
- **タクトタイム**: 製品1個を生産するのに与えられた時間

## 2. ラインバランシング

### ラインバランシングとは
ラインバランシングは、各工程の作業時間をできるだけ均等に配分し、ライン全体の効率を最大化する手法です。

### ラインバランシングの目的
- **作業負荷の平準化**: 各工程の作業時間を均等化
- **遊休時間の最小化**: 作業者や設備の無駄な待ち時間を削減
- **生産性の向上**: ライン全体の効率を最大化
- **作業者数の最適化**: 必要最小限の人員配置

### ラインバランシングの手順

#### ステップ1: 作業要素の分析
```
例：製品Aの組立作業
作業要素1: 部品準備（20秒）
作業要素2: 部品A取付（35秒）
作業要素3: 部品B取付（40秒）
作業要素4: ネジ締め（30秒）
作業要素5: 検査（25秒）
作業要素6: 梱包（30秒）
総作業時間: 180秒
```

#### ステップ2: タクトタイムの算出
```
タクトタイム = 稼働時間 ÷ 必要生産数

例：
1日の稼働時間: 8時間 = 480分 = 28,800秒
1日の必要生産数: 480個
タクトタイム = 28,800秒 ÷ 480個 = 60秒/個
```

#### ステップ3: 理論最小工程数の算出
```
理論最小工程数 = 総作業時間 ÷ タクトタイム

例：
理論最小工程数 = 180秒 ÷ 60秒 = 3工程
```

#### ステップ4: 作業の工程への割り当て
```
工程1: 作業要素1 + 作業要素2 = 20秒 + 35秒 = 55秒
工程2: 作業要素3 + 部品要素4の一部 = 40秒 + 20秒 = 60秒
工程3: 作業要素4の残り + 作業要素5 + 作業要素6 = 10秒 + 25秒 + 30秒 = 65秒

※工程3が65秒となりタクトタイムを超過するため、再調整が必要
```

### 📊 具体的な計算例

**例: 電子機器組立ラインのバランシング**

**前提条件:**
- 1日の稼働時間: 8時間（休憩含まず）
- 1日の生産目標: 400個
- 作業要素と作業時間:
  - A: 基板準備（25秒）
  - B: IC取付（45秒）
  - C: はんだ付け（50秒）
  - D: 配線接続（35秒）
  - E: 動作確認（40秒）
  - F: ケース組立（30秒）
  - G: 最終検査（35秒）
  - H: 梱包（20秒）

**ステップ1: タクトタイム計算**
```
タクトタイム = (8時間 × 3600秒) ÷ 400個
            = 28,800秒 ÷ 400個
            = 72秒/個
```

**ステップ2: 総作業時間と理論最小工程数**
```
総作業時間 = 25 + 45 + 50 + 35 + 40 + 30 + 35 + 20 = 280秒
理論最小工程数 = 280秒 ÷ 72秒 = 3.89 ≈ 4工程
```

**ステップ3: 作業割り当て**
```
工程1: A + B = 25 + 45 = 70秒（タクトタイム内）
工程2: C + H = 50 + 20 = 70秒（タクトタイム内）
工程3: D + F = 35 + 30 = 65秒（タクトタイム内）
工程4: E + G = 40 + 35 = 75秒（タクトタイムを3秒超過）
```

💡 **実際の現場では**: 工程4のように若干の超過がある場合、作業改善や一時的な支援体制で対応することが多いです。

## 3. ピッチダイアグラム

### ピッチダイアグラムとは
ピッチダイアグラムは、各工程での作業時間の累積を視覚的に表現したグラフで、ラインバランスの状態を一目で把握できるツールです。

### ピッチダイアグラムの構成要素
- **横軸**: 工程番号または工程名
- **縦軸**: 累積作業時間
- **実線**: 実際の累積作業時間
- **理想線**: タクトタイムに基づく理想的な累積時間

### ピッチダイアグラムの作成手順

#### 例：先ほどの電子機器組立ラインの場合

```
工程別作業時間:
工程1: 70秒
工程2: 70秒  
工程3: 65秒
工程4: 75秒

累積作業時間:
工程1まで: 70秒
工程2まで: 140秒
工程3まで: 205秒
工程4まで: 280秒

理想累積時間（タクトタイム72秒）:
工程1まで: 72秒
工程2まで: 144秒
工程3まで: 216秒
工程4まで: 288秒
```

### ピッチダイアグラムの活用方法
- **ボトルネック工程の特定**: 理想線を大きく上回る工程
- **余裕のある工程の特定**: 理想線を下回る工程
- **改善優先順位の決定**: 乖離が大きい工程から改善
- **改善効果の可視化**: 改善前後の比較

💡 **実際の現場では**: ピッチダイアグラムは定期的に更新し、継続的な改善活動の指標として活用されます。

## 4. サイクルタイムの計算

### サイクルタイムとは
サイクルタイムは、ライン上で実際に製品1個が完成するまでの時間間隔です。

### サイクルタイムの種類

#### 理論サイクルタイム
```
理論サイクルタイム = 最大工程作業時間

例：工程1（70秒）、工程2（70秒）、工程3（65秒）、工程4（75秒）
理論サイクルタイム = 75秒
```

#### 実際サイクルタイム
```
実際サイクルタイム = 理論サイクルタイム + ライン停止時間 + その他のロス時間

例：
理論サイクルタイム: 75秒
平均ライン停止時間: 5秒/個
その他のロス: 3秒/個
実際サイクルタイム = 75 + 5 + 3 = 83秒
```

### 📊 サイクルタイム計算の実例

**例: 自動車部品組立ライン**

**条件:**
- 各工程の作業時間:
  - 工程A: 120秒
  - 工程B: 110秒
  - 工程C: 125秒
  - 工程D: 115秒
- ライン効率: 95%
- 1日の稼働時間: 450分

**計算:**
```
理論サイクルタイム = MAX(120, 110, 125, 115) = 125秒

実際サイクルタイム = 125秒 ÷ 0.95 = 131.6秒

1日の生産可能数 = (450分 × 60秒) ÷ 131.6秒
                = 27,000秒 ÷ 131.6秒
                = 205個
```

## 5. 編成効率

### 編成効率の定義
編成効率は、ラインバランシングの良さを示す指標で、各工程の作業時間がどれだけ均等に配分されているかを表します。

### 編成効率の計算式
```
編成効率 = (総作業時間) ÷ (工程数 × サイクルタイム) × 100%
```

### 📊 編成効率の計算例

**例1: 家電製品組立ライン**

**条件:**
- 総作業時間: 360秒
- 工程数: 6工程
- 各工程の作業時間: 58秒、62秒、60秒、65秒、55秒、60秒
- サイクルタイム: 65秒（最大工程時間）

**計算:**
```
編成効率 = 360秒 ÷ (6工程 × 65秒) × 100%
        = 360秒 ÷ 390秒 × 100%
        = 92.3%
```

**例2: 編成効率改善の事例**

**改善前:**
- 工程1: 80秒
- 工程2: 45秒
- 工程3: 75秒
- 工程4: 50秒
- 総作業時間: 250秒
- サイクルタイム: 80秒
- 編成効率 = 250 ÷ (4 × 80) × 100% = 78.1%

**改善後（作業再配分）:**
- 工程1: 65秒
- 工程2: 60秒
- 工程3: 63秒
- 工程4: 62秒
- 総作業時間: 250秒（変わらず）
- サイクルタイム: 65秒
- 編成効率 = 250 ÷ (4 × 65) × 100% = 96.2%

💡 **実際の現場では**: 編成効率90%以上が優良、85%以上が良好とされることが多いです。

## 6. ラインの形態

### 単一品種ライン

#### 定義と特徴
**定義**: 1つの製品のみを連続的に生産するライン
**特徴**:
- 専用設備・治具の使用が可能
- 作業の標準化が容易
- 高い生産効率を実現
- 設備投資が大きい
- 需要変動への対応が困難

#### 適用条件
- 大量生産が見込める製品
- 製品寿命が長い
- 需要が安定している
- 設備投資の回収が可能

#### 具体例
```
自動車エンジン専用ライン:
- 生産品目: 特定型式のエンジンのみ
- 月産能力: 50,000台
- ライン長: 200m
- 工程数: 80工程
- タクトタイム: 30秒
- 編成効率: 95%以上
```

### 多品種ライン

#### 定義と特徴
**定義**: 複数の製品を切り替えながら生産するライン
**特徴**:
- 汎用設備の使用
- 段取り替えが必要
- 柔軟な生産対応が可能
- 在庫削減が可能
- 生産効率は単一品種より低い

#### 多品種ラインの種類

**1. ロット切替型**
- 一定数量ごとに品種を切り替え
- 段取り時間のロスが発生
- 在庫が発生しやすい

**2. 混流生産型**
- 複数品種を混在させて生産
- 段取り替えを最小化
- 平準化生産が可能

### 形態別比較表

| 項目 | 単一品種ライン | 多品種ライン（ロット切替） | 多品種ライン（混流） |
|------|--------------|------------------------|-------------------|
| 設備投資 | 高い | 中程度 | 中～高 |
| 生産効率 | 非常に高い | 中程度 | 高い |
| 柔軟性 | 低い | 中程度 | 高い |
| 段取り時間 | なし | 多い | 少ない |
| 在庫水準 | 低い | 高い | 低い |
| 作業習熟 | 容易 | 中程度 | 困難 |

## 7. 混合品種ラインの編成効率

### 混合品種ラインの特殊性
混合品種ラインでは、品種によって作業時間が異なるため、編成効率の計算が複雑になります。

### 編成効率の計算方法

#### 方法1: 加重平均による計算
```
混合品種編成効率 = Σ(品種別編成効率 × 生産比率)

例：
品種A: 編成効率90%、生産比率60%
品種B: 編成効率85%、生産比率30%
品種C: 編成効率88%、生産比率10%

混合品種編成効率 = 0.90×0.60 + 0.85×0.30 + 0.88×0.10
                = 0.54 + 0.255 + 0.088
                = 88.3%
```

#### 方法2: 総作業時間による計算
```
混合品種編成効率 = 総作業時間 ÷ (工程数 × 加重平均サイクルタイム × 総生産数) × 100%
```

### 📊 混合品種ラインの詳細計算例

**例: 電子部品組立ライン（3品種混流）**

**前提条件:**
```
品種別データ:
品種X: 作業時間240秒、生産比率50%、日産200個
品種Y: 作業時間180秒、生産比率30%、日産120個
品種Z: 作業時間300秒、生産比率20%、日産80個

ライン構成: 4工程
```

**ステップ1: 品種別工程配分**
```
品種X（作業時間240秒）:
工程1: 60秒、工程2: 65秒、工程3: 55秒、工程4: 60秒
サイクルタイム: 65秒
編成効率 = 240 ÷ (4 × 65) = 92.3%

品種Y（作業時間180秒）:
工程1: 45秒、工程2: 48秒、工程3: 42秒、工程4: 45秒
サイクルタイム: 48秒
編成効率 = 180 ÷ (4 × 48) = 93.8%

品種Z（作業時間300秒）:
工程1: 75秒、工程2: 78秒、工程3: 72秒、工程4: 75秒
サイクルタイム: 78秒
編成効率 = 300 ÷ (4 × 78) = 96.2%
```

**ステップ2: 混合品種編成効率**
```
加重平均編成効率 = 92.3% × 0.5 + 93.8% × 0.3 + 96.2% × 0.2
                = 46.15% + 28.14% + 19.24%
                = 93.53%
```

**ステップ3: 生産能力分析**
```
加重平均サイクルタイム = 65 × 0.5 + 48 × 0.3 + 78 × 0.2
                     = 32.5 + 14.4 + 15.6
                     = 62.5秒

1日の稼働時間を8時間とすると:
理論生産能力 = 28,800秒 ÷ 62.5秒 = 460.8個/日
実際の生産数 = 200 + 120 + 80 = 400個/日
ライン稼働率 = 400 ÷ 460.8 = 86.8%
```

💡 **実際の現場では**: 混合品種ラインでは、品種切替の順序も編成効率に影響するため、生産順序の最適化も重要です。

### 混合品種ライン運用のポイント

#### 1. 品種グループ化
```
類似作業でグループ化:
グループ1: 品種A、B、C（基板実装系）
グループ2: 品種D、E（機械組立系）
グループ3: 品種F、G、H（検査重視系）

効果: 段取り時間20%削減、編成効率5%向上
```

#### 2. ピッチタイムの設定
```
共通ピッチタイム方式:
全品種で最大作業時間の工程に合わせる
→ シンプルだが効率低下

可変ピッチタイム方式:
品種ごとに最適なピッチタイムを設定
→ 効率的だが管理が複雑
```

#### 3. バッファの活用
```
工程間バッファ設置:
- 品種切替時の影響を吸収
- 標準バッファ量: 30分～1時間分
- 効果: ライン停止50%削減
```

## 8. ライン生産方式の評価と改善

### 総合評価指標

#### OEE（Overall Equipment Effectiveness）
```
OEE = 稼働率 × 性能率 × 品質率

例：
稼働率 = 85%（実稼働時間/計画稼働時間）
性能率 = 92%（実際サイクルタイム/理論サイクルタイム）
品質率 = 98%（良品数/総生産数）
OEE = 0.85 × 0.92 × 0.98 = 76.6%
```

### 改善手法

#### 1. ECRS（Eliminate, Combine, Rearrange, Simplify）
- **Eliminate（排除）**: 不要な作業の削除
- **Combine（結合）**: 複数作業の統合
- **Rearrange（再配置）**: 作業順序の最適化
- **Simplify（簡素化）**: 作業方法の簡略化

#### 2. 動作経済の原則
- 両手同時使用
- 動作の対称性
- 自然な動作リズム
- 動作範囲の最小化

## 10. 理解度確認クイズ（4択問題20問）

### 問題1
ラインバランシングの主な目的として最も適切なものはどれか？

- A) 設備投資を最大化する
- B) 各工程の作業時間を均等化し、効率を最大化する
- C) 作業者数を増やす
- D) 製品の種類を減らす

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
ラインバランシングは各工程の作業時間をできるだけ均等に配分し、遊休時間を最小化してライン全体の効率を最大化することが目的です。Aの設備投資最大化は目的ではなく、むしろ効率的な設備活用を目指します。Cの作業者数は最適化（通常は最小化）が目的で、増やすことではありません。Dの製品種類削減はラインバランシングとは直接関係ありません。
</details>

### 問題2
タクトタイムが60秒、総作業時間が350秒の場合、理論最小工程数はいくつか？

- A) 5工程
- B) 6工程
- C) 7工程
- D) 8工程

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
理論最小工程数 = 総作業時間 ÷ タクトタイム = 350秒 ÷ 60秒 = 5.83... ≈ 6工程（切り上げ）。小数点以下が出た場合は必ず切り上げる必要があります。5工程では350秒の作業を収めることができず（5×60=300秒）、6工程が必要となります。
</details>

### 問題3
ピッチダイアグラムで理想線を大きく上回っている工程は何を示しているか？

- A) 余裕のある工程
- B) ボトルネック工程
- C) 不要な工程
- D) 自動化された工程

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
ピッチダイアグラムで実際の累積作業時間が理想線（タクトタイムに基づく線）を大きく上回る工程は、作業時間が長くラインの流れを妨げているボトルネック工程を示しています。Aの余裕のある工程は逆に理想線を下回ります。Cの不要な工程やDの自動化はピッチダイアグラムからは判断できません。
</details>

### 問題4
編成効率が85%のラインで、総作業時間が400秒、工程数が5の場合、サイクルタイムは何秒か？

- A) 80秒
- B) 85秒
- C) 94秒
- D) 100秒

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
編成効率の式を変形すると：サイクルタイム = 総作業時間 ÷ (工程数 × 編成効率) = 400秒 ÷ (5 × 0.85) = 400 ÷ 4.25 = 94.1秒 ≈ 94秒。編成効率85%は0.85として計算する必要があります。
</details>

### 問題5
単一品種ラインの特徴として適切でないものはどれか？

- A) 専用設備の使用が可能
- B) 需要変動への対応が容易
- C) 作業の標準化が容易
- D) 高い生産効率を実現

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
単一品種ラインは1つの製品のみを生産するため、需要変動への対応が困難です。需要が減少しても設備を他製品に転用できないためです。A、C、Dは単一品種ラインの典型的な特徴で、専用化により高効率を実現できます。
</details>

### 問題6
混流生産型の多品種ラインの特徴として正しいものはどれか？

- A) 段取り替えが頻繁に必要
- B) 在庫水準が高い
- C) 平準化生産が可能
- D) 作業習熟が容易

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
混流生産では複数品種を混在させて生産するため、需要に応じた平準化生産が可能です。Aは誤りで、混流生産は段取り替えを最小化します。Bも誤りで、必要な分だけ生産するため在庫水準は低くなります。Dは誤りで、複数品種の作業を覚える必要があるため習熟は困難です。
</details>

### 問題7
作業要素A（30秒）、B（45秒）、C（25秒）、D（40秒）があり、タクトタイムが50秒の場合、最適な工程配分はどれか？

- A) 工程1:A+B、工程2:C+D
- B) 工程1:A+C、工程2:B、工程3:D
- C) 工程1:B、工程2:A+C、工程3:D
- D) 工程1:A、工程2:B、工程3:C、工程4:D

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
各選択肢を検証すると：A)工程1が75秒となりタクトタイムを大幅超過。B)工程1:55秒→超過、工程2:45秒→OK、工程3:40秒→OK。ただし工程1が5秒超過するものの、他の選択肢より最適。C)各工程は50秒以内だが3工程で済むところを3工程使用。D)4工程も使い非効率。実際には工程1の5秒超過を作業改善で対応します。
</details>

### 問題8
サイクルタイムとタクトタイムの関係について正しい説明はどれか？

- A) サイクルタイムは必ずタクトタイムと等しい
- B) サイクルタイムはタクトタイムより短くなければならない
- C) サイクルタイムがタクトタイムを超えると生産遅れが発生する
- D) サイクルタイムとタクトタイムは無関係である

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
サイクルタイム（実際の生産間隔）がタクトタイム（要求される生産間隔）を超えると、必要な生産数を達成できず生産遅れが発生します。Aは誤りで、理想的には等しいことが望ましいが実際は異なることが多いです。Bは逆で、サイクルタイムはタクトタイム以下である必要があります。Dは誤りで、両者は密接に関連しています。
</details>

### 問題9
編成効率を向上させる方法として適切でないものはどれか？

- A) 作業の再配分による平準化
- B) ボトルネック工程の改善
- C) 工程数の増加
- D) 作業方法の簡素化

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
編成効率 = 総作業時間 ÷ (工程数 × サイクルタイム) なので、工程数を増やすと分母が大きくなり編成効率は低下します。A、B、Dはいずれも編成効率向上に寄与する適切な方法です。
</details>

### 問題10
混合品種ラインで品種A（編成効率95%、生産比率40%）、品種B（編成効率80%、生産比率60%）の加重平均編成効率は？

- B) 86.0%

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
加重平均編成効率 = 95% × 0.4 + 80% × 0.6 = 38% + 48% = 86.0%。各品種の編成効率に生産比率を掛けて合計します。
</details>

### 問題11
1日8時間稼働で480個生産する場合のタクトタイムは？

- B) 45秒
- C) 60秒
- D) 90秒

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
タクトタイム = 稼働時間 ÷ 必要生産数 = (8時間 × 3600秒) ÷ 480個 = 28,800秒 ÷ 480個 = 60秒/個
</details>

### 問題12

### 問題15

### 問題16

### 問題17
ライン停止時間を含む実際のサイクルタイムを求める際に考慮すべき要素として適切でないものは？

- A) 理論サイクルタイム
- B) 設備故障時間
- C) 段取り替え時間
- D) 製品の販売価格

<details>
<summary>解答</summary>

### 問題18
OEE（総合設備効率）の構成要素でないものはどれか？

- A) 稼働率
- B) 性能率
- C) 品質率
- D) 利益率

<details>
<summary>解答</summary>
<strong>正解: D</strong><br>
OEE = 稼働率 × 性能率 × 品質率 で計算されます。稼働率は計画に対する実稼働、性能率は理論に対する実際の生産速度、品質率は良品率を表します。利益率は経営指標であり、OEEの構成要素ではありません。
</details>

### 問題19
ラインバランシングを行う際の作業要素分析で最初に行うべきことは？

- A) タクトタイムの計算
- B) 作業要素の分解と時間測定
- C) 工程への割り当て
- D) 編成効率の計算

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
ラインバランシングの第一歩は、製品製造に必要な全作業を要素作業に分解し、それぞれの時間を正確に測定することです。これがないとタクトタイムを計算しても適切な工程配分ができません。A→C→Dの順序は、Bの後に行います。
</details>

### 問題20
混合品種ラインの運用で「品種グループ化」を行う主な目的は？

- A) 作業者を減らすため
- B) 段取り時間を削減するため
- C) 設備投資を増やすため
- D) 品質検査を省略するため

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
類似した作業内容や使用設備が共通する品種をグループ化することで、品種切替時の段取り替え時間を大幅に削減できます。これにより生産効率が向上します。作業者削減や設備投資増は目的ではなく、品質検査の省略は品質保証上行ってはいけません。
</details>

## 11. 専門用語集

### アルファベット

**ECRS**
- **読み方**: イーシーアールエス
- **意味**: Eliminate（排除）、Combine（結合）、Rearrange（再配置）、Simplify（簡素化）の頭文字を取った改善手法。作業改善の基本的な考え方を示す。
- **関連用語**: 作業改善、IE（Industrial Engineering）

**OEE (Overall Equipment Effectiveness)**
- **読み方**: オーイーイー
- **意味**: 総合設備効率。稼働率×性能率×品質率で計算される設備の総合的な効率指標。
- **関連用語**: 稼働率、性能率、品質率、TPM

### あ行

**編成効率（へんせいこうりつ）**
- **読み方**: へんせいこうりつ
- **意味**: ラインバランシングの良さを示す指標。総作業時間を（工程数×サイクルタイム）で割った値。理想的には100%に近いほど良い。
- **関連用語**: ラインバランシング、サイクルタイム

### か行

**混流生産（こんりゅうせいさん）**
- **読み方**: こんりゅうせいさん
- **意味**: 複数の品種を同一ライン上で混在させながら生産する方式。段取り替えを最小化し、需要に応じた柔軟な生産が可能。
- **関連用語**: 多品種ライン、平準化生産

**工程（こうてい）**
- **読み方**: こうてい
- **意味**: 製品製造における作業の単位。ライン生産では、特定の作業を行う作業場所（ワークステーション）を指す。
- **関連用語**: ワークステーション、作業要素

### さ行

**サイクルタイム**
- **読み方**: さいくるたいむ
- **意味**: ライン上で実際に製品1個が完成するまでの時間間隔。理論サイクルタイムは最大工程作業時間で決まる。
- **関連用語**: タクトタイム、理論サイクルタイム

**作業要素（さぎょうようそ）**
- **読み方**: さぎょうようそ
- **意味**: 製品を製造するために必要な個々の作業単位。これ以上分割できない基本的な作業動作。
- **関連用語**: 要素作業、作業分析

### た行

**タクトタイム**
- **読み方**: たくとたいむ
- **意味**: 顧客の需要を満たすために、製品1個を生産するのに与えられた時間。稼働時間を必要生産数で割って求める。
- **関連用語**: サイクルタイム、ピッチタイム

**段取り替え（だんどりがえ）**
- **読み方**: だんどりがえ
- **意味**: 生産する品種を切り替える際に必要な準備作業。治具交換、設備調整、材料準備などを含む。
- **関連用語**: 段取り時間、SMED

**単一品種ライン（たんいつひんしゅらいん）**
- **読み方**: たんいつひんしゅらいん
- **意味**: 1つの製品のみを連続的に生産する専用ライン。高効率だが柔軟性に欠ける。
- **関連用語**: 専用ライン、大量生産

**多品種ライン（たひんしゅらいん）**
- **読み方**: たひんしゅらいん
- **意味**: 複数の製品を切り替えながら生産するライン。ロット切替型と混流生産型がある。
- **関連用語**: 混流生産、フレキシブルライン

### は行

**ピッチタイム**
- **読み方**: ぴっちたいむ
- **意味**: 作業者や設備が一定のリズムで作業を行う時間間隔。タクトタイムと同義で使われることも多い。
- **関連用語**: タクトタイム、作業ペース

**ピッチダイアグラム**
- **読み方**: ぴっちだいあぐらむ
- **意味**: 各工程での作業時間の累積を視覚的に表現したグラフ。横軸に工程、縦軸に累積作業時間をとる。
- **関連用語**: 累積作業時間、ラインバランス

**平準化生産（へいじゅんかせいさん）**
- **読み方**: へいじゅんかせいさん
- **意味**: 生産量と生産品種を平均化し、日々の生産を安定させる生産方式。在庫削減と生産効率向上を実現。
- **関連用語**: 混流生産、ジャストインタイム

**ボトルネック工程（ぼとるねっくこうてい）**
- **読み方**: ぼとるねっくこうてい
- **意味**: ライン内で最も作業時間が長く、全体の生産能力を制約している工程。改善の重点対象となる。
- **関連用語**: 制約工程、律速工程

### ま行

**混合品種ライン（こんごうひんしゅらいん）**
- **読み方**: こんごうひんしゅらいん
- **意味**: 複数の品種を同一ライン上で生産するライン。品種により作業時間が異なるため、編成効率の計算が複雑になる。
- **関連用語**: 混流生産、多品種ライン

### や行

**遊休時間（ゆうきゅうじかん）**
- **読み方**: ゆうきゅうじかん
- **意味**: 作業者や設備が作業をしていない待ち時間。ラインバランシングにより最小化を図る。
- **関連用語**: 手待ち時間、アイドルタイム

### ら行

**ライン生産方式（らいんせいさんほうしき）**
- **読み方**: らいんせいさんほうしき
- **意味**: 製品の加工順序に従って設備や作業者を配置し、一定のペースで製品を流す生産方式。大量生産に適している。
- **関連用語**: フローショップ、流れ生産

**ラインバランシング**
- **読み方**: らいんばらんしんぐ
- **意味**: 各工程の作業時間をできるだけ均等に配分し、ライン全体の効率を最大化する手法。
- **関連用語**: 工程編成、作業配分

**ロット切替型（ろっときりかえがた）**
- **読み方**: ろっときりかえがた
- **意味**: 一定数量（ロット）ごとに生産品種を切り替える多品種生産方式。段取り時間が発生する。
- **関連用語**: バッチ生産、ロットサイズ

### わ行

**ワークステーション**
- **読み方**: わーくすてーしょん
- **意味**: ライン上で特定の作業を行う作業場所。工程と同義で使われることが多い。
- **関連用語**: 工程、作業場所
