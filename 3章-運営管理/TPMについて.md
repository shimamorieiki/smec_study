# TPM（Total Productive Maintenance）について

## 概要

TPM（Total Productive Maintenance：全員参加の生産保全）は、生産設備の効率を最大化し、故障ゼロ・不良ゼロを目指す総合的な設備管理手法です。1971年に日本で生まれ、現在では世界中の製造業で採用されている重要な生産管理システムです。

TPMは単なる保全活動ではなく、オペレーターから経営層まで全員が参加し、小集団活動を通じて設備の体質改善を図る全社的な取り組みです。設備総合効率（OEE：Overall Equipment Effectiveness）の向上を主要な指標として、生産性向上とコスト削減を実現します。

## 1. TPMの基本概念・定義

### TPMの定義
- **定義**: 生産システムの効率を極限まで高めることを目標とし、設備のライフサイクル全体を対象として、災害ゼロ・不良ゼロ・故障ゼロなどあらゆるロスを未然防止する仕組みを構築する活動
- **特徴**: トップから第一線従業員まで全員参加で、生産部門をはじめ開発・営業・管理などあらゆる部門にわたって実施
- **重要性**: 設備効率の向上だけでなく、人材育成や職場活性化にも大きく貢献

### TPMの5つの基本理念
1. **設備効率の最大化**: 設備の持つ能力を100%発揮させる
2. **予防保全の徹底**: 故障を未然に防ぐ体制の確立
3. **全員参加**: オペレーターから経営層まで全員が保全活動に参加
4. **小集団活動**: 現場の知恵を活かした改善活動
5. **継続的改善**: PDCAサイクルによる絶え間ない向上

## 2. 自主保全（Autonomous Maintenance）

### 自主保全の定義と目的
自主保全は、オペレーター自身が「自分の設備は自分で守る」という考えのもと、日常的な保全活動を行うTPMの中核となる活動です。

**目的:**
- オペレーターの設備に対する意識向上
- 異常の早期発見・早期対応
- 設備故障の未然防止
- 保全部門との連携強化

### 自主保全の7ステップ

#### ステップ1: 初期清掃
- **活動内容**: 設備の徹底的な清掃と点検
- **狙い**: 清掃を通じて設備の異常を発見し、清掃の重要性を認識
- **実施項目**: 
  - 設備本体の清掃
  - 給油・増締めの実施
  - 不具合箇所の発見とタグ付け

#### ステップ2: 発生源・困難箇所対策
- **活動内容**: 汚れの発生源対策と清掃困難箇所の改善
- **狙い**: 清掃時間の短縮と清掃しやすい設備づくり
- **実施項目**:
  - 汚れ発生源の特定と対策
  - カバーや防護板の設置
  - 清掃道具の工夫

#### ステップ3: 清掃・給油基準の作成
- **活動内容**: 日常的な清掃・給油・点検の基準書作成
- **狙い**: 誰でも同じレベルの保全ができる仕組みづくり
- **実施項目**:
  - 清掃箇所と方法の明確化
  - 給油箇所と周期の設定
  - チェックシートの作成

#### ステップ4: 総点検
- **活動内容**: 設備の構造・機能に関する教育と点検スキルの習得
- **狙い**: オペレーターの設備知識向上と点検能力の向上
- **実施項目**:
  - 設備構造の理解
  - 点検方法の習得
  - 異常判定基準の理解

#### ステップ5: 自主点検
- **活動内容**: オペレーター自身による定期点検の実施
- **狙い**: 異常の早期発見と対応能力の向上
- **実施項目**:
  - 点検基準書の作成
  - 定期点検の実施
  - 異常時の対応手順確立

#### ステップ6: 標準化
- **活動内容**: これまでの活動の標準化と維持管理体制の確立
- **狙い**: 活動の定着と継続的な改善
- **実施項目**:
  - 作業標準書の整備
  - 管理基準の設定
  - 改善活動の継続

#### ステップ7: 自主管理
- **活動内容**: 設備管理の完全な自主化と継続的改善
- **狙い**: 最高レベルの設備管理と生産性向上
- **実施項目**:
  - 目標管理の実施
  - 改善活動の推進
  - 技能向上の継続

### 自主保全の具体的実施例

**事例: 射出成形機の自主保全**

**初期状態:**
- 油漏れによる床の汚れ
- 金型交換に30分
- 月2回の突発故障

**実施内容:**
1. **清掃活動**: 毎日10分の清掃時間設定
2. **発生源対策**: 油漏れ箇所の特定と補修
3. **給油管理**: 給油箇所の見える化と定期給油
4. **点検強化**: 振動・温度の日常チェック

**成果:**
- 突発故障ゼロ達成（6ヶ月間）
- 金型交換時間20分に短縮
- 不良率50%削減

## 3. 計画保全（Planned Maintenance）

### 計画保全の定義と目的
計画保全は、設備の故障や性能劣化を未然に防ぐため、計画的に行う保全活動です。保全部門が中心となり、科学的なデータに基づいて最適な保全計画を立案・実行します。

**目的:**
- 設備故障の未然防止
- 設備寿命の延長
- 保全コストの最適化
- 生産計画の安定化

### 計画保全の体系

#### 1. 予防保全（Preventive Maintenance）
**時間基準保全（TBM：Time Based Maintenance）**
- **定義**: 一定の時間間隔で行う保全
- **実施項目**:
  - 定期点検（日常・月次・年次）
  - 定期部品交換
  - オーバーホール
- **適用例**: ベアリング交換（運転時間8,000時間ごと）

**状態基準保全（CBM：Condition Based Maintenance）**
- **定義**: 設備の状態を監視し、異常兆候を検知して行う保全
- **監視項目**:
  - 振動測定
  - 温度測定
  - 油分析
  - 電流値監視
- **適用例**: 振動値が基準値を超えたらベアリング交換

#### 2. 改良保全（Corrective Maintenance）
- **定義**: 設備の弱点を改善し、信頼性を向上させる活動
- **実施内容**:
  - 設計改善
  - 材質変更
  - 部品強化
  - 保全性向上
- **適用例**: 頻繁に故障する部品の材質を耐摩耗性の高いものに変更

#### 3. 保全予防（Maintenance Prevention）
- **定義**: 新設備導入時に保全しやすい設備を設計する活動
- **実施内容**:
  - 保全性を考慮した設計
  - 標準化・モジュール化
  - 診断機能の組み込み
- **適用例**: 点検窓の設置、交換しやすい部品配置

### 計画保全の実施手順

#### ステップ1: 設備評価と重要度設定
```
設備重要度マトリックス
┌─────────────┬────────────┐
│     故障影響度     │   保全優先度   │
├─────────────┼────────────┤
│ A（生産停止）      │ 最優先対応     │
│ B（生産低下）      │ 優先対応       │
│ C（品質影響）      │ 計画対応       │
│ D（影響軽微）      │ 通常対応       │
└─────────────┴────────────┘
```

#### ステップ2: 保全方式の選定
- **高重要度設備**: CBM＋TBMの組み合わせ
- **中重要度設備**: TBM中心
- **低重要度設備**: 事後保全も許容

#### ステップ3: 保全計画の立案
**年間保全カレンダーの作成**
- 生産計画との調整
- 保全要員の配置計画
- 予備品・資材の手配計画
- 外注計画

#### ステップ4: 保全の実施と記録
- 計画に基づく保全実施
- 作業内容の詳細記録
- 異常発見時の対応
- データベースへの登録

### 計画保全の実施例

**事例: コンプレッサーの計画保全**

**設備仕様:**
- スクリューコンプレッサー 75kW
- 運転時間: 24時間/日、330日/年
- 重要度: A（生産停止設備）

**保全計画:**
```
┌────────┬──────────┬──────────┐
│ 保全項目   │ 周期         │ 実施内容     │
├────────┼──────────┼──────────┤
│ 日常点検   │ 毎日         │ 圧力・温度確認│
│ 月次点検   │ 月1回        │ 振動・電流測定│
│ 3ヶ月点検  │ 3ヶ月ごと    │ フィルター交換│
│ 年次点検   │ 年1回        │ 分解整備      │
│ CBM        │ 常時         │ 振動監視      │
└────────┴──────────┴──────────┘
```

**成果:**
- MTBF（平均故障間隔）: 2,000時間→8,000時間
- 保全コスト: 30%削減
- 突発停止: ゼロ化達成

## 4. TPMの8本柱

### 1. 自主保全
前述の通り、オペレーターによる自主的な保全活動

### 2. 計画保全
前述の通り、保全部門による計画的な保全活動

### 3. 個別改善
- **目的**: 設備効率を阻害するロスの徹底排除
- **対象16大ロス**:
  - 故障ロス
  - 段取り・調整ロス
  - 刃具交換ロス
  - 立ち上がりロス
  - チョコ停・空転ロス
  - 速度低下ロス
  - 不良・手直しロス
  - シャットダウンロス

### 4. 初期管理
- **目的**: 新設備の垂直立ち上げと初期故障の防止
- **活動内容**:
  - 設備仕様へのMP（保全予防）情報反映
  - 初期流動管理
  - フィードバック体制確立

### 5. 品質保全
- **目的**: 「不良ゼロ」の達成
- **活動内容**:
  - 品質不良要因の解析
  - 設備起因不良の撲滅
  - 品質保証体制の確立

### 6. 教育訓練
- **目的**: TPM活動を支える人材育成
- **教育体系**:
  - 階層別教育
  - 機能別教育
  - 技能認定制度

### 7. 管理間接部門のTPM
- **目的**: 事務効率の向上と生産支援強化
- **活動内容**:
  - 業務プロセス改善
  - 情報システムの効率化
  - 部門間連携強化

### 8. 安全・衛生・環境
- **目的**: 災害ゼロ・環境負荷低減
- **活動内容**:
  - リスクアセスメント
  - ヒヤリハット活動
  - 環境保全活動

## 5. 設備総合効率（OEE）の計算

### OEEの定義
```
OEE = 時間稼働率 × 性能稼働率 × 良品率
```

### 計算例

**設備データ:**
- 負荷時間: 480分
- 停止時間: 80分
- 理論サイクルタイム: 1分/個
- 生産数: 360個
- 不良数: 18個

**計算過程:**
1. **時間稼働率** = (480-80) ÷ 480 = 83.3%
2. **性能稼働率** = (1×360) ÷ (480-80) = 90.0%
3. **良品率** = (360-18) ÷ 360 = 95.0%
4. **OEE** = 0.833 × 0.900 × 0.950 = 71.2%

**世界クラスの目標値:**
- OEE: 85%以上
- 時間稼働率: 90%以上
- 性能稼働率: 95%以上
- 良品率: 99%以上

## 7. 実務上の注意点

### 成功のポイント
- **トップの強いリーダーシップ**: 経営層の継続的なコミットメント
- **全員参加の徹底**: 一人も例外を作らない
- **小集団活動の活性化**: 現場の知恵を最大限活用
- **見える化の推進**: 活動成果の可視化
- **教育の充実**: 継続的なスキルアップ

### よくある失敗パターン
- **形式的な活動**: 書類作成が目的化
- **一部門だけの活動**: 製造部門のみで完結
- **継続性の欠如**: 初期の熱意が続かない
- **成果の未測定**: 効果が実感できない

## 8. 理解度確認クイズ（4択問題20問）

### 問題1
TPMの基本理念として誤っているものはどれか？

- A) 設備効率の最大化を目指す
- B) 保全部門だけで実施する専門的活動である
- C) 小集団活動を通じて改善を進める
- D) 予防保全を重視する

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
TPMは「全員参加」が基本理念の一つであり、保全部門だけでなく、オペレーターから経営層まで全員が参加する活動です。<br>
<br>
Aは正しい：設備効率の最大化はTPMの主要目標です<br>
Cは正しい：小集団活動はTPMの重要な実施形態です<br>
Dは正しい：故障の未然防止（予防保全）はTPMの中心的な考え方です
</details>

### 問題2
自主保全の7ステップの正しい順序はどれか？

- A) 初期清掃→総点検→発生源対策→清掃給油基準作成→自主点検→標準化→自主管理
- B) 初期清掃→発生源対策→清掃給油基準作成→総点検→自主点検→標準化→自主管理
- C) 総点検→初期清掃→発生源対策→清掃給油基準作成→自主点検→標準化→自主管理
- D) 初期清掃→発生源対策→総点検→清掃給油基準作成→標準化→自主点検→自主管理

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
自主保全の7ステップは以下の順序で進めます：<br>
1. 初期清掃（設備の異常発見）<br>
2. 発生源・困難箇所対策（清掃しやすい設備づくり）<br>
3. 清掃・給油基準作成（日常管理の仕組みづくり）<br>
4. 総点検（設備知識の習得）<br>
5. 自主点検（点検スキルの実践）<br>
6. 標準化（活動の定着）<br>
7. 自主管理（完全な自主化）<br>
<br>
この順序により、段階的にオペレーターの能力と意識を高めていきます。
</details>

### 問題3
時間基準保全（TBM）と状態基準保全（CBM）の違いとして正しいものはどれか？

- A) TBMは故障後に行い、CBMは故障前に行う
- B) TBMは一定周期で行い、CBMは設備状態を監視して行う
- C) TBMは保全部門が行い、CBMはオペレーターが行う
- D) TBMは高額設備のみ、CBMは全設備が対象

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
TBM（Time Based Maintenance）は運転時間や暦日数など、あらかじめ決められた時間間隔で保全を行う方式です。一方、CBM（Condition Based Maintenance）は振動や温度などの設備状態を常時または定期的に監視し、異常の兆候を検知したら保全を行う方式です。<br>
<br>
Aは誤り：両方とも予防保全であり、故障前に行います<br>
Cは誤り：実施部門による区別ではありません<br>
Dは誤り：設備の重要度や特性により使い分けます
</details>

### 問題4
OEE（設備総合効率）85%を達成するために、時間稼働率90%、良品率99%の場合、必要な性能稼働率は約何％か？

- A) 90%
- B) 93%
- C) 95%
- D) 97%

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
OEE = 時間稼働率 × 性能稼働率 × 良品率 なので、<br>
0.85 = 0.90 × 性能稼働率 × 0.99<br>
性能稼働率 = 0.85 ÷ (0.90 × 0.99) = 0.85 ÷ 0.891 = 0.954<br>
したがって、約95%の性能稼働率が必要です。<br>
<br>
【補足】世界クラスのOEE目標85%を達成するには、各要素で高いレベルが求められます。
</details>

### 問題7
計画保全における改良保全の説明として最も適切なものはどれか？

- A) 定期的に部品を交換する活動
- B) 故障してから修理する活動

### 問題8
以下の条件でOEEを計算した場合、正しい値はどれか？
- 負荷時間：500分
- 停止時間：50分
- 理論サイクルタイム：2分/個
- 生産数：200個
- 不良数：10個

- A) 約76%
- B) 約82%
- C) 約88%
- D) 約94%

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
計算過程：<br>
1. 時間稼働率 = (500-50)÷500 = 450÷500 = 0.90 (90%)<br>
2. 性能稼働率 = (2×200)÷(500-50) = 400÷450 = 0.889 (88.9%)<br>
3. 良品率 = (200-10)÷200 = 190÷200 = 0.95 (95%)<br>
4. OEE = 0.90 × 0.889 × 0.95 = 0.760 (76.0%)<br>
<br>
したがって、OEEは約76%です。
</details>

## 9. 専門用語集

### アルファベット

**CBM (Condition Based Maintenance)**
- **読み方**: シービーエム
- **意味**: 状態基準保全。設備の状態（振動、温度、音など）を監視し、異常の兆候を検知したときに保全を行う方式
- **関連用語**: TBM、予防保全

**MP (Maintenance Prevention)**
- **読み方**: エムピー
- **意味**: 保全予防。新設備の設計・導入段階で、保全しやすく故障しにくい設備にするための活動
- **関連用語**: 初期管理、LCC（ライフサイクルコスト）

**MTBF (Mean Time Between Failures)**
- **読み方**: エムティービーエフ
- **意味**: 平均故障間隔。ある故障から次の故障までの平均時間で、設備の信頼性を表す指標
- **関連用語**: MTTR、稼働率

**MTTR (Mean Time To Repair)**
- **読み方**: エムティーティーアール
- **意味**: 平均修復時間。故障が発生してから修理が完了し、運転再開するまでの平均時間
- **関連用語**: MTBF、保全性

**OEE (Overall Equipment Effectiveness)**
- **読み方**: オーイーイー
- **意味**: 設備総合効率。時間稼働率×性能稼働率×良品率で計算される、設備の総合的な効率指標
- **関連用語**: 稼働率、設備効率

**PM (Productive Maintenance)**
- **読み方**: ピーエム
- **意味**: 生産保全。アメリカで生まれた予防保全を中心とした設備管理の考え方で、TPMの前身
- **関連用語**: TPM、予防保全

**TBM (Time Based Maintenance)**
- **読み方**: ティービーエム
- **意味**: 時間基準保全。運転時間や暦日など、一定の時間間隔で行う計画的な保全方式
- **関連用語**: CBM、定期保全

**TPM (Total Productive Maintenance)**
- **読み方**: ティーピーエム
- **意味**: 全員参加の生産保全。製造業において設備効率を最大化するための総合的な管理手法
- **関連用語**: 生産保全、PM

### あ行

**アベイラビリティ（Availability）**
- **読み方**: あべいらびりてぃ
- **意味**: 設備が要求されたときに運転可能な状態にある確率。可用性とも呼ばれる
- **関連用語**: 信頼性、保全性

**オーバーホール（Overhaul）**
- **読み方**: おーばーほーる
- **意味**: 設備を分解し、部品の交換や調整を行って、新品同様の状態に戻す大規模な整備
- **関連用語**: 定期整備、予防保全

### か行

**改良保全（Corrective Maintenance）**
- **読み方**: かいりょうほぜん
- **意味**: 設備の弱点部分を改善し、故障しにくくする保全活動
- **関連用語**: 予防保全、事後保全

**可動率（Operating Rate）**
- **読み方**: かどうりつ
- **意味**: 負荷時間に対して実際に設備が稼働した時間の割合
- **関連用語**: 時間稼働率、OEE

**計画保全（Planned Maintenance）**
- **読み方**: けいかくほぜん
- **意味**: 設備の故障を未然に防ぐため、計画的に行う保全活動の総称
- **関連用語**: 予防保全、予知保全

**故障解析（Failure Analysis）**
- **読み方**: こしょうかいせき
- **意味**: 故障の原因を科学的に分析し、再発防止策を立案する活動
- **関連用語**: RCA（根本原因分析）、FMEA

**個別改善（Focused Improvement）**
- **読み方**: こべつかいぜん
- **意味**: 特定の設備やロスに焦点を当てて行う集中的な改善活動
- **関連用語**: ロス分析、TPM8本柱

### さ行

**自主保全（Autonomous Maintenance）**
- **読み方**: じしゅほぜん
- **意味**: オペレーター自身が行う日常的な保全活動。TPMの中核となる活動
- **関連用語**: TPM、計画保全

**初期管理（Early Equipment Management）**
- **読み方**: しょきかんり
- **意味**: 新設備導入時の垂直立ち上げと初期故障の防止を目的とした管理活動
- **関連用語**: MP、垂直立ち上げ

**垂直立ち上げ（Vertical Start-up）**
- **読み方**: すいちょくたちあげ
- **意味**: 新設備導入時に短期間で計画能力を達成すること
- **関連用語**: 初期管理、初期流動管理

### た行

**チョコ停（Minor Stoppage）**
- **読み方**: ちょこてい
- **意味**: 数分程度の短時間の設備停止。頻発すると大きなロスとなる
- **関連用語**: 空転ロス、速度低下ロス

**定期保全（Periodic Maintenance）**
- **読み方**: ていきほぜん
- **意味**: あらかじめ定められた周期で行う保全活動
- **関連用語**: TBM、予防保全

### な行

**日常保全（Daily Maintenance）**
- **読み方**: にちじょうほぜん
- **意味**: 清掃、給油、増締めなど、毎日行う基本的な保全活動
- **関連用語**: 自主保全、定期保全

### は行

**品質保全（Quality Maintenance）**
- **読み方**: ひんしつほぜん
- **意味**: 設備起因の品質不良をゼロにすることを目的とした保全活動
- **関連用語**: TPM8本柱、不良ゼロ

**負荷時間（Loading Time）**
- **読み方**: ふかじかん
- **意味**: 稼働可能時間から計画停止時間を除いた、設備が稼働すべき時間
- **関連用語**: 稼働時間、OEE計算

**保全予防（Maintenance Prevention）**
- **読み方**: ほぜんよぼう
- **意味**: 新設備の設計段階から保全性を考慮し、保全しやすい設備を実現する活動
- **関連用語**: MP、初期管理

### ま行

**見える化（Visualization）**
- **読み方**: みえるか
- **意味**: 設備の状態、活動成果、異常などを誰でも一目で分かるように表示すること
- **関連用語**: 目で見る管理、5S

### や行

**予知保全（Predictive Maintenance）**
- **読み方**: よちほぜん
- **意味**: 設備の劣化傾向を把握し、故障時期を予測して行う保全
- **関連用語**: CBM、診断技術

**予防保全（Preventive Maintenance）**
- **読み方**: よぼうほぜん
- **意味**: 故障が発生する前に計画的に行う保全活動の総称
- **関連用語**: TBM、CBM

### ら行

**ライフサイクルコスト（Life Cycle Cost）**
- **読み方**: らいふさいくるこすと
- **意味**: 設備の取得から廃棄までの全期間にかかる総費用
- **関連用語**: LCC、初期管理

**劣化（Deterioration）**
- **読み方**: れっか
- **意味**: 時間経過や使用により設備の性能や機能が低下すること
- **関連用語**: 強制劣化、自然劣化

**ロス（Loss）**
- **読み方**: ろす
- **意味**: 設備が本来持つ能力を発揮できない要因。TPMでは16大ロスを定義
- **関連用語**: 設備効率、OEE
