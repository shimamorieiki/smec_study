# 照明について

## 概要
照明は、人工光源や自然光源を用いて空間を明るくし、視作業の効率性や快適性を向上させる技術です。適切な照明設計は、省エネルギー、視覚的快適性、作業効率の向上など、多方面に影響を与える重要な要素となっています。照明技術は、光の物理的特性の理解から、人間の視覚特性への配慮、そして環境への影響まで、幅広い知識を統合した総合的な分野です。

## 1. 照明の基本概念・仕組み

### 照明の役割
- **定義**: 光源から発せられる光を利用して、空間や物体を見やすくすること
- **動作原理**: 光源から発せられた光が、直接または反射・拡散を経て、対象物や空間に到達し、人間の視覚に認識される
- **特徴**: 視認性の向上、空間の演出、安全性の確保、生体リズムへの影響など多岐にわたる機能を持つ

### 照明設計の基本要素
- **従来の照明との違い**: LED技術の発展により、従来の白熱灯や蛍光灯から、より効率的で制御可能な照明システムへ移行
- **改善点**: エネルギー効率の大幅な向上、調光・調色機能の充実、長寿命化
- **限界**: 初期コストの高さ、グレア（まぶしさ）の問題、色再現性の課題

## 2. 光の物理量と単位

### 光の測定指標
照明設計において使用される主要な光の物理量には、光束、光度、照度、輝度があります。これらは相互に関連しながら、照明の質を定量的に評価するための基準となります。

### 光束（Luminous Flux）
**特徴:**
- 光源から放射される光の総量を表す
- 単位：ルーメン（lm）
- 光源の明るさの総合的な指標

**算出方法:**
```
光束 [lm] = 光度 [cd] × 立体角 [sr]
全光束 = ∫∫ I(θ,φ) × sinθ dθ dφ
```

**📊 具体的な計算例**
**例: 60W白熱電球の光束計算**
- 発光効率: 約15 lm/W
- 消費電力: 60W

**ステップ1: 全光束の算出**
```
全光束 = 発光効率 × 消費電力
全光束 = 15 lm/W × 60W = 900 lm
```

**結果: 60W白熱電球は約900ルーメンの光束を発する**

💡 **実際の現場では**: LED電球の場合、同じ明るさ（900lm）を約10Wで実現でき、大幅な省エネルギーが可能

### 光度（Luminous Intensity）
**特徴:**
- ある方向への光の強さを表す
- 単位：カンデラ（cd）
- 指向性のある光源の評価に使用

**算出方法:**
```
光度 [cd] = 光束 [lm] / 立体角 [sr]
点光源の場合: I = Φ / 4π
```

**📊 具体的な計算例**
**例: スポットライトの光度計算**
- 全光束: 1000 lm
- ビーム角: 30°（立体角: 0.214 sr）

**ステップ1: 平均光度の算出**
```
平均光度 = 光束 / 立体角
平均光度 = 1000 lm / 0.214 sr ≈ 4673 cd
```

**結果: ビーム内の平均光度は約4673カンデラ**

💡 **実際の現場では**: スポットライトの配光特性により、中心部の光度はさらに高くなることが多い

### 照度（Illuminance）
**特徴:**
- 面に入射する光の量を表す
- 単位：ルクス（lx）= lm/m²
- 作業面の明るさ評価に使用

**算出方法:**
```
照度 [lx] = 光束 [lm] / 面積 [m²]
点光源からの照度: E = I × cosθ / r²
```

**📊 具体的な計算例**
**例: オフィスデスクの照度計算**
- 天井高さ: 2.7m
- デスク高さ: 0.7m
- 光源からの距離: 2.0m
- 光度: 1000 cd
- 入射角: 0°（直下）

**ステップ1: 照度の算出**
```
照度 = 光度 × cos(入射角) / 距離²
照度 = 1000 cd × cos(0°) / (2.0m)²
照度 = 1000 × 1 / 4 = 250 lx
```

**結果: デスク面の照度は250ルクス**

💡 **実際の現場では**: JIS規格では事務作業に750lx以上が推奨されるため、複数の照明器具の組み合わせが必要

### 輝度（Luminance）
**特徴:**
- 光源や反射面の明るさの見え方を表す
- 単位：カンデラ毎平方メートル（cd/m²）
- まぶしさの評価に使用

**算出方法:**
```
輝度 [cd/m²] = 光度 [cd] / 見かけの面積 [m²]
拡散反射面: L = ρ × E / π
```

**📊 具体的な計算例**
**例: 白い壁面の輝度計算**
- 照度: 500 lx
- 反射率: 0.8（80%）

**ステップ1: 輝度の算出**
```
輝度 = 反射率 × 照度 / π
輝度 = 0.8 × 500 lx / 3.14
輝度 ≈ 127 cd/m²
```

**結果: 白い壁面の輝度は約127 cd/m²**

💡 **実際の現場では**: VDT作業環境では、画面と周囲の輝度比を1:3〜1:10程度に抑えることが推奨される

## 3. 光源の種類と特性

### 自然光源
#### 太陽光
- **特徴**: 連続スペクトル、時間により色温度が変化（2000K〜10000K）
- **利点**: 優れた演色性（Ra=100）、エネルギーコスト不要
- **課題**: 制御困難、季節・天候による変動

#### 昼光利用
- **直射日光**: 高照度だが制御が必要
- **天空光**: 安定した拡散光
- **反射光**: 建物や地面からの間接光

### 人工光源
#### LED（Light Emitting Diode）
- **発光原理**: 半導体のPN接合における電子の再結合
- **効率**: 100〜200 lm/W
- **寿命**: 40,000〜50,000時間
- **特徴**: 調光・調色可能、即時点灯、小型化可能

#### 蛍光灯
- **発光原理**: 水銀蒸気の紫外線放射を蛍光体で可視光に変換
- **効率**: 60〜100 lm/W
- **寿命**: 6,000〜15,000時間
- **特徴**: 比較的高効率、広範囲照明に適する

#### 白熱電球
- **発光原理**: フィラメントの熱放射
- **効率**: 10〜20 lm/W
- **寿命**: 1,000〜2,000時間
- **特徴**: 優れた演色性、調光容易、低効率

#### HIDランプ（高輝度放電灯）
- **種類**: メタルハライドランプ、高圧ナトリウムランプ、水銀灯
- **効率**: 50〜150 lm/W
- **寿命**: 6,000〜24,000時間
- **特徴**: 高効率、高出力、始動時間が必要

## 4. 光の質的特性

### 演色性（Color Rendering）
演色性は、光源が物体の色をどれだけ自然に再現できるかを示す指標です。

#### 演色評価数（Ra）
- **定義**: 基準光源と比較した色の見え方の忠実度（0〜100）
- **測定方法**: 8〜15種類の試験色の色差から算出
- **評価基準**:
  - Ra 90以上: 優秀（美術館、商業施設）
  - Ra 80以上: 良好（オフィス、住宅）
  - Ra 60以上: 普通（工場、倉庫）

**📊 具体的な比較例**
| 光源種類 | 演色評価数（Ra） | 適用場所 |
|---------|----------------|---------|
| 太陽光 | 100 | 基準 |
| LED（高演色） | 90〜95 | 美術館、店舗 |
| LED（一般） | 80〜85 | オフィス、住宅 |
| 蛍光灯（三波長） | 80〜85 | 一般照明 |
| 高圧ナトリウム灯 | 25〜30 | 道路照明 |

### 色温度（Color Temperature）
色温度は、光源の光色を絶対温度（K：ケルビン）で表した指標です。

#### 色温度による分類
- **電球色（2700〜3000K）**: 温かみのある光、リラックス空間向け
- **温白色（3500K）**: 自然な白色光、住宅全般
- **白色（4000K）**: 中性的な白色光、オフィス
- **昼白色（5000K）**: 太陽光に近い白色光、作業空間
- **昼光色（6500K）**: 青みがかった白色光、精密作業

**📊 時間帯別推奨色温度**
| 時間帯 | 推奨色温度 | 理由 |
|--------|-----------|------|
| 朝（6-9時） | 4000-5000K | 覚醒効果 |
| 昼（9-17時） | 5000-6500K | 作業効率向上 |
| 夕（17-20時） | 3500-4000K | 移行期 |
| 夜（20時以降） | 2700-3000K | リラックス効果 |

## 5. メリット・デメリット

### 適切な照明設計のメリット
**1. エネルギー効率の向上**
- **理由**: LED技術の採用により消費電力を大幅削減
- **効果**: 電気代を最大80%削減可能
- **具体例**: 40W蛍光灯→10W LEDで同等照度を実現

**2. 作業効率・生産性の向上**
- **理由**: 適切な照度と演色性により視認性が向上
- **効果**: 作業ミスの減少、疲労軽減
- **具体例**: 750lx以上の照度で細かい作業の効率が20%向上

**3. 健康・ウェルビーイングの改善**
- **理由**: サーカディアンリズムに配慮した照明制御
- **効果**: 睡眠の質向上、気分の改善
- **具体例**: 色温度の日内変動により体内時計を調整

### 不適切な照明のデメリット
**1. 眼精疲労・健康被害**
- **理由**: 不適切な照度、グレア、フリッカー
- **影響**: 頭痛、目の疲れ、集中力低下
- **対策**: 適切な配光設計、間接照明の活用

**2. エネルギーの無駄遣い**
- **理由**: 過剰照明、非効率な光源の使用
- **影響**: 電気代増加、CO2排出量増加
- **対策**: 人感センサー、調光システムの導入

## 6. 照明設計の指針

### 用途別照度基準
| 用途 | 推奨照度 [lx] | 演色性 Ra | 色温度 [K] |
|------|--------------|----------|-----------|
| 精密作業 | 1500〜3000 | 90以上 | 5000〜6500 |
| 事務作業 | 750〜1000 | 80以上 | 4000〜5000 |
| 会議室 | 500〜750 | 80以上 | 4000〜5000 |
| 廊下・通路 | 100〜200 | 60以上 | 3500〜4000 |

### 照明設計の判断フローチャート
1. **用途の確認** 
   - 作業照明が必要 → 高照度・高演色性を選択
   - 雰囲気照明が必要 → 次の判断へ

2. **省エネルギーの重要度**
   - 高い → LED照明を選択
   - 中程度 → 用途に応じて選択

3. **初期投資の制約**
   - 制約あり → 段階的LED化を検討
   - 制約なし → 全面LED化を推奨

### 問題4
点光源から2m離れた位置での照度が250 lxのとき、4m離れた位置での照度は？

- B) 100 lx
- C) 62.5 lx
- D) 31.25 lx

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>

<br>
Aが間違いの理由：距離に比例すると誤解した計算<br>
Bが間違いの理由：計算が不正確<br>
Dが間違いの理由：距離の3乗に反比例すると誤解した計算<br>
<br>
【補足】逆2乗の法則は照明設計の基本原理で、器具配置の決定に重要です。
</details>

## 9. 専門用語集

このスライドで使用された照明関連用語について、アルファベット順・50音順で解説します。

### アルファベット

**HID (High Intensity Discharge)**
- **読み方**: エイチアイディー
- **意味**: 高輝度放電灯の総称。アーク放電により高い光束を得る光源
- **関連用語**: メタルハライドランプ、高圧ナトリウムランプ

**IoT (Internet of Things)**
- **読み方**: アイオーティー
- **意味**: インターネットに接続された機器が相互に通信し、自動制御や遠隔操作を可能にする技術
- **関連用語**: スマート照明、無線制御

**LED (Light Emitting Diode)**
- **読み方**: エルイーディー
- **意味**: 発光ダイオード。半導体に電流を流すことで発光する固体光源
- **関連用語**: 有機EL、半導体

**Ra (Color Rendering Index)**
- **読み方**: アールエー
- **意味**: 演色評価数。光源の演色性を0〜100の数値で表した指標
- **関連用語**: 演色性、色再現性

**VDT (Visual Display Terminal)**
- **読み方**: ブイディーティー
- **意味**: コンピュータのディスプレイなど、視覚表示端末の総称
- **関連用語**: VDT作業、ディスプレイ

### あ行

**色温度（いろおんど）**
- **読み方**: いろおんど
- **意味**: 光源の光色を絶対温度（K：ケルビン）で表した数値。低いほど赤みがかり、高いほど青みがかる
- **関連用語**: 電球色、昼白色、昼光色

**演色性（えんしょくせい）**
- **読み方**: えんしょくせい
- **意味**: 光源が物体の色を自然に再現する性能
- **関連用語**: 演色評価数（Ra）、色再現性

### か行

**カンデラ（cd）**
- **読み方**: かんでら
- **意味**: 光度の単位。特定方向への光の強さを表す
- **関連用語**: 光度、ルーメン

**輝度（きど）**
- **読み方**: きど
- **意味**: 光源や反射面の明るさの見え方を表す物理量。単位はcd/m²
- **関連用語**: 照度、光度

**グレア**
- **読み方**: ぐれあ
- **意味**: まぶしさ。視野内の高輝度部分により生じる不快感や視認性低下
- **関連用語**: 遮光角、間接照明

**蛍光灯（けいこうとう）**
- **読み方**: けいこうとう
- **意味**: 水銀蒸気の放電による紫外線を蛍光体で可視光に変換する光源
- **関連用語**: 三波長形、インバーター

**光度（こうど）**
- **読み方**: こうど
- **意味**: 光源から特定方向へ放射される光の強さ。単位はカンデラ（cd）
- **関連用語**: 光束、配光

**光束（こうそく）**
- **読み方**: こうそく
- **意味**: 光源から放射される光の総量。単位はルーメン（lm）
- **関連用語**: 全光束、光度

### さ行

**サーカディアンリズム**
- **読み方**: さーかでぃあんりずむ
- **意味**: 約24時間周期の生体リズム。光により調整される
- **関連用語**: 体内時計、メラトニン

**照度（しょうど）**
- **読み方**: しょうど
- **意味**: 面に入射する光の量。単位はルクス（lx）
- **関連用語**: 作業面照度、平均照度

**人工光源（じんこうこうげん）**
- **読み方**: じんこうこうげん
- **意味**: 人工的に作られた光源。LED、蛍光灯、白熱電球など
- **関連用語**: 自然光源、照明器具

**全光束（ぜんこうそく）**
- **読み方**: ぜんこうそく
- **意味**: 光源から全方向に放射される光束の総和
- **関連用語**: 光束、ルーメン

### た行

**昼光色（ちゅうこうしょく）**
- **読み方**: ちゅうこうしょく
- **意味**: 色温度6500K程度の青みがかった白色光
- **関連用語**: 色温度、昼白色

**昼白色（ちゅうはくしょく）**
- **読み方**: ちゅうはくしょく
- **意味**: 色温度5000K程度の自然な白色光
- **関連用語**: 色温度、白色

**電球色（でんきゅうしょく）**
- **読み方**: でんきゅうしょく
- **意味**: 色温度2700〜3000K程度の温かみのある光色
- **関連用語**: 色温度、白熱電球

### は行

**配光（はいこう）**
- **読み方**: はいこう
- **意味**: 光源や照明器具から放射される光の方向別強度分布
- **関連用語**: 配光曲線、指向性

**白熱電球（はくねつでんきゅう）**
- **読み方**: はくねつでんきゅう
- **意味**: フィラメントの熱放射により発光する電球
- **関連用語**: タングステン、ハロゲン電球

**フリッカー**
- **読み方**: ふりっかー
- **意味**: 照明のちらつき現象。疲労や不快感の原因となる
- **関連用語**: 高周波点灯、インバーター

### ま行

**メタルハライドランプ**
- **読み方**: めたるはらいどらんぷ
- **意味**: 金属ハロゲン化物を封入した高輝度放電灯
- **関連用語**: HIDランプ、始動器

### ら行

**ルーメン（lm）**
- **読み方**: るーめん
- **意味**: 光束の単位。光源から放射される光の総量を表す
- **関連用語**: 光束、全光束

**ルクス（lx）**
- **読み方**: るくす
- **意味**: 照度の単位。1平方メートルあたり1ルーメンの光束
- **関連用語**: 照度、照度計

**立体角（りったいかく）**
- **読み方**: りったいかく
- **意味**: 三次元空間における角度。単位はステラジアン（sr）
- **関連用語**: 光度、配光
