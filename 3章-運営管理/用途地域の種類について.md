# 用途地域の種類について

## 概要

用途地域とは、都市計画法に基づいて定められる地域地区の一つで、建築物の用途の混在を防ぐことで、それぞれの地域にふさわしい環境を保ち、効率的な都市活動の確保を図ることを目的とした制度です。日本では13種類の用途地域が定められており、それぞれの地域で建築可能な建物の種類や規模が制限されています。

用途地域は、住居の環境を保護する「住居系」、商業の利便を増進する「商業系」、工業の利便を増進する「工業系」の3つに大別され、建築基準法により建築物の用途制限、建蔽率、容積率、高さ制限などが定められています。これらの制限により、良好な市街地環境の形成と維持が図られています。

## 1. 用途地域の基本概念・定義

### 用途地域制度の目的
- **定義**: 都市計画法第8条に基づき、市街地の大枠としての土地利用を定める地域地区の一つ
- **特徴**: 建築物の用途、容積率、建蔽率、高さ等を制限することで、土地利用の純化を図る
- **重要性**: 住環境の保護、商業・工業の利便性向上、都市機能の適正配置を実現

### 用途地域の法的位置づけ
- **定義**: 都市計画法に基づく地域地区として、市町村が都市計画として決定
- **特徴**: 建築基準法により具体的な建築制限が規定される
- **重要性**: 私権の制限を伴うため、都市計画決定手続きを経て定められる

## 2. 用途地域の分類・種類

### 用途地域の3分類
用途地域は、その目的により以下の3つに大別されます。

### 住居系用途地域（8種類）
| 項目 | 内容 |
|------|------|
| 特徴 | 住居の環境を保護することを目的とした地域 |
| 適用範囲 | 低層住宅から中高層住宅まで、住環境の保護レベルに応じて細分化 |
| 注意点 | 種類により建築可能な用途が段階的に緩和される |

### 商業系用途地域（2種類）
| 項目 | 内容 |
|------|------|
| 特徴 | 商業その他の業務の利便を増進することを目的とした地域 |
| 適用範囲 | 近隣の住民への日用品供給から、広域的な商業施設まで対応 |
| 注意点 | 住宅の建築も可能だが、日影規制等の適用が緩い |

### 工業系用途地域（3種類）
| 項目 | 内容 |
|------|------|
| 特徴 | 工業の利便を増進することを目的とした地域 |
| 適用範囲 | 住宅との共存を図る地域から、工業専用地域まで段階的に設定 |
| 注意点 | 工業専用地域では住宅の建築が禁止される |

## 3. 各用途地域の詳細

### 1. 第一種低層住居専用地域
- **目的**: 低層住宅に係る良好な住居の環境を保護する
- **建蔽率**: 30%、40%、50%、60%のうち都市計画で定める
- **容積率**: 50%、60%、80%、100%、150%、200%のうち都市計画で定める
- **高さ制限**: 10mまたは12m
- **建築可能**: 住宅、共同住宅、小中高校、図書館、診療所、寺社等
- **建築不可**: 店舗（兼用住宅で50㎡以下は可）、事務所、ホテル、遊戯施設等

### 2. 第二種低層住居専用地域
- **目的**: 主として低層住宅に係る良好な住居の環境を保護する
- **建蔽率**: 30%、40%、50%、60%のうち都市計画で定める
- **容積率**: 50%、60%、80%、100%、150%、200%のうち都市計画で定める
- **高さ制限**: 10mまたは12m
- **建築可能**: 第一種に加え、150㎡以下の店舗・飲食店等
- **建築不可**: 事務所、ホテル、遊戯施設、工場等

### 3. 第一種中高層住居専用地域
- **目的**: 中高層住宅に係る良好な住居の環境を保護する
- **建蔽率**: 30%、40%、50%、60%のうち都市計画で定める
- **容積率**: 100%、150%、200%、300%、400%、500%のうち都市計画で定める
- **高さ制限**: なし（日影規制あり）
- **建築可能**: 住宅、500㎡以下の店舗・飲食店、大学、病院等
- **建築不可**: 事務所、ホテル、遊戯施設、工場等

### 4. 第二種中高層住居専用地域
- **目的**: 主として中高層住宅に係る良好な住居の環境を保護する
- **建蔽率**: 30%、40%、50%、60%のうち都市計画で定める
- **容積率**: 100%、150%、200%、300%、400%、500%のうち都市計画で定める
- **高さ制限**: なし（日影規制あり）
- **建築可能**: 第一種に加え、1,500㎡以下の店舗・事務所等
- **建築不可**: ホテル、遊戯施設、工場等

### 5. 第一種住居地域
- **目的**: 住居の環境を保護する
- **建蔽率**: 50%、60%、80%のうち都市計画で定める
- **容積率**: 100%、150%、200%、300%、400%、500%のうち都市計画で定める
- **高さ制限**: なし（日影規制あり）
- **建築可能**: 住宅、3,000㎡以下の店舗・事務所、ホテル等
- **建築不可**: 大規模な遊戯施設、工場等

### 6. 第二種住居地域
- **目的**: 主として住居の環境を保護する
- **建蔽率**: 50%、60%、80%のうち都市計画で定める
- **容積率**: 100%、150%、200%、300%、400%、500%のうち都市計画で定める
- **高さ制限**: なし（日影規制あり）
- **建築可能**: 第一種に加え、10,000㎡以下の店舗・事務所、カラオケボックス等
- **建築不可**: 大規模な遊戯施設、工場等

### 7. 準住居地域
- **目的**: 道路の沿道としての地域の特性にふさわしい業務の利便の増進を図りつつ、これと調和した住居の環境を保護する
- **建蔽率**: 50%、60%、80%のうち都市計画で定める
- **容積率**: 100%、150%、200%、300%、400%、500%のうち都市計画で定める
- **高さ制限**: なし
- **建築可能**: 住宅、店舗、事務所、自動車修理工場（300㎡以下）等
- **建築不可**: 大規模な工場、危険物貯蔵施設等

### 8. 田園住居地域
- **目的**: 農業の利便の増進を図りつつ、これと調和した低層住宅に係る良好な住居の環境を保護する
- **建蔽率**: 30%、40%、50%、60%のうち都市計画で定める
- **容積率**: 50%、60%、80%、100%、150%、200%のうち都市計画で定める
- **高さ制限**: 10mまたは12m
- **建築可能**: 住宅、農産物直売所、農家レストラン（500㎡以下）等
- **建築不可**: 一般の店舗、事務所、ホテル等

### 9. 近隣商業地域
- **目的**: 近隣の住宅地の住民に対する日用品の供給を行うことを主たる内容とする商業その他の業務の利便を増進する
- **建蔽率**: 60%、80%のうち都市計画で定める
- **容積率**: 100%～500%のうち都市計画で定める
- **高さ制限**: なし
- **建築可能**: ほとんどの用途（キャバレー、個室付浴場等を除く）
- **建築不可**: 危険性や環境悪化の恐れが大きい工場等

### 10. 商業地域
- **目的**: 主として商業その他の業務の利便を増進する
- **建蔽率**: 80%（防火地域内の耐火建築物は100%）
- **容積率**: 200%～1300%のうち都市計画で定める
- **高さ制限**: なし
- **建築可能**: ほとんどすべての用途
- **建築不可**: 危険性や環境悪化の恐れが大きい工場等

### 11. 準工業地域
- **目的**: 主として環境の悪化をもたらすおそれのない工業の利便を増進する
- **建蔽率**: 50%、60%、80%のうち都市計画で定める
- **容積率**: 100%～500%のうち都市計画で定める
- **高さ制限**: なし
- **建築可能**: ほとんどすべての用途
- **建築不可**: 個室付浴場等、危険性が大きい工場等

### 12. 工業地域
- **目的**: 主として工業の利便を増進する
- **建蔽率**: 50%、60%のうち都市計画で定める
- **容積率**: 100%～400%のうち都市計画で定める
- **高さ制限**: なし
- **建築可能**: 工場、住宅、店舗等（学校、病院、ホテル等は不可）
- **建築不可**: 学校、病院、ホテル、劇場等

### 13. 工業専用地域
- **目的**: 工業の利便を増進する
- **建蔽率**: 30%～60%のうち都市計画で定める
- **容積率**: 100%～400%のうち都市計画で定める
- **高さ制限**: なし
- **建築可能**: 工場、事務所、店舗（物品販売・飲食店を除く）等
- **建築不可**: 住宅、共同住宅、学校、病院、ホテル、物販店舗等

## 4. 具体的計算例・事例

### ケース1: 建蔽率・容積率の計算

#### パターンA: 第一種低層住居専用地域での住宅建築
- **前提条件**: 
  - 敷地面積: 200㎡
  - 建蔽率: 40%
  - 容積率: 80%
  - 高さ制限: 10m
- **計算過程**: 
  - 建築面積の上限 = 200㎡ × 40% = 80㎡
  - 延床面積の上限 = 200㎡ × 80% = 160㎡
- **結果**: 建築面積80㎡以下、延床面積160㎡以下、高さ10m以下の住宅が建築可能

#### パターンB: 商業地域での店舗併用住宅
- **前提条件**: 
  - 敷地面積: 150㎡
  - 建蔽率: 80%（防火地域内の耐火建築物で100%）
  - 容積率: 600%
- **計算過程**: 
  - 建築面積の上限 = 150㎡ × 100% = 150㎡
  - 延床面積の上限 = 150㎡ × 600% = 900㎡
- **結果**: 建築面積150㎡、延床面積900㎡までの建物が建築可能（6階建て相当）

### ケース2: 用途制限による建築可否の判断

#### 店舗建築の可否判断
- **第一種低層住居専用地域**: 兼用住宅で店舗部分50㎡以下なら可能
- **第二種低層住居専用地域**: 独立店舗も150㎡以下なら可能
- **第一種中高層住居専用地域**: 500㎡以下なら可能
- **第二種中高層住居専用地域**: 1,500㎡以下なら可能
- **第一種住居地域**: 3,000㎡以下なら可能
- **第二種住居地域**: 10,000㎡以下なら可能

## 5. 実務上の注意点

### 用途地域確認の重要ポイント
- **ポイント1**: 市町村の都市計画図で用途地域を必ず確認する
- **ポイント2**: 複数の用途地域にまたがる敷地の場合は、過半の属する地域の制限を適用
- **ポイント3**: 用途地域の変更は都市計画決定手続きが必要で、個人では変更不可

### よくある誤解・トラブル
- **誤解1**: 「住居専用地域なら事務所は一切建てられない」→ 兼用住宅なら一定規模まで可能
- **誤解2**: 「既存不適格建築物は違法建築」→ 法改正前に適法に建てられたものは適法

## 6. よくある質問（Q&A）

### Q1. 第一種低層住居専用地域で小さなパン屋を開業できますか？

**A1.** 条件付きで可能です。住宅と兼用で、店舗部分の床面積が50㎡以下、かつ建物の延床面積の2分の1未満であれば開業できます。

#### 具体的な例
例えば、延床面積100㎡の住宅の場合、40㎡までの店舗部分なら設置可能です。ただし、独立した店舗建築は不可能で、必ず住宅と一体でなければなりません。

### Q2. 用途地域の境界線上に建物を建てる場合、どちらの制限が適用されますか？

**A2.** 敷地の過半が属する用途地域の制限が適用されます。

#### 詳細な取り扱い
敷地面積の計算において、各用途地域に属する部分の面積を測定し、より大きい面積を占める用途地域の建築制限が敷地全体に適用されます。ただし、建蔽率・容積率については加重平均による場合もあります。

## 7. まとめ・今後の展望

用途地域制度は、日本の都市計画の根幹をなす制度として、良好な市街地環境の形成に重要な役割を果たしています。13種類の用途地域はそれぞれ異なる目的と制限を持ち、地域の特性に応じた土地利用を実現しています。

今後は、少子高齢化やライフスタイルの多様化に対応し、より柔軟な土地利用を可能にする制度改正が検討されています。特に、2018年に創設された田園住居地域は、都市農地の保全と住環境の調和を図る新しい試みとして注目されています。
