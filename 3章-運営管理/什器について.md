# 什器について

## 概要
什器（じゅうき）とは、小売店舗において商品の陳列・展示・保管に使用される設備・備品の総称です。効果的な什器の選択と配置は、顧客の購買行動に大きな影響を与え、売上向上の重要な要素となります。本資料では、代表的な什器であるゴンドラ、ステージ、そして各種ショーケースについて詳しく解説します。

## 1. 什器の基本概念と役割

### 什器の定義
- **定義**: 商品を陳列・展示・保管するための店舗設備
- **目的**: 商品の魅力的な展示、効率的な在庫管理、顧客の購買促進
- **重要性**: 店舗の売上や顧客満足度に直接的な影響を与える

### 什器選択の基本原則
- **商品特性との適合性**: 商品のサイズ、重量、保管条件に適した什器の選択
- **顧客動線の考慮**: 店舗内の人の流れを考慮した配置
- **視認性の確保**: 商品が見やすく、手に取りやすい設計

## 2. 主要な什器の種類と特徴

### ゴンドラ（Gondola）

#### 定義と基本構造
ゴンドラは、小売店舗で最も一般的に使用される両面陳列可能な什器です。通路の中央に設置され、両側から商品を見ることができる構造となっています。

#### 詳細仕様
| 項目 | 標準仕様 |
|------|---------|
| 高さ | 120cm～180cm（最も一般的：150cm） |
| 幅 | 60cm～120cm（最も一般的：90cm） |
| 奥行 | 30cm～60cm（両面合計） |
| 段数 | 4～6段（可動式） |
| 耐荷重 | 1段あたり30kg～50kg |

#### 特徴と利点
- **両面陳列**: 売場効率を最大化
- **可動棚**: 商品サイズに応じて調整可能
- **エンド活用**: ゴンドラの端部（エンド）は特売品の展示に最適
- **組み合わせ自由**: 複数のゴンドラを連結して売場を構成

#### 具体的な活用例
**スーパーマーケットでの活用**
- 中央通路：加工食品、調味料、菓子類の陳列
- 棚割り：上段（軽量商品）、中段（売れ筋商品）、下段（重量商品）
- エンド展開：季節商品や特売品の大量陳列

**ドラッグストアでの活用**
- 医薬品：カテゴリー別に整理された陳列
- 化粧品：ブランド別の展開
- 日用品：使用頻度の高い商品を手に取りやすい高さに配置

### ステージ（Stage）

#### 定義と用途
ステージは、フロアから一段高い位置に設置される展示台で、特別な商品や推奨商品を目立たせるための什器です。

#### 詳細仕様
| 項目 | 標準仕様 |
|------|---------|
| 高さ | 10cm～30cm（台の高さ） |
| サイズ | 60cm×60cm～180cm×180cm |
| 形状 | 正方形、長方形、円形など |
| 材質 | 木製、金属製、アクリル製 |
| 耐荷重 | 50kg～200kg |

#### 活用方法
**季節商品の展開**
- 春：新生活用品、花見関連商品
- 夏：冷感グッズ、アウトドア用品
- 秋：行楽用品、防寒準備品
- 冬：暖房器具、クリスマス商品

**イベント展開**
- 新商品発表会
- ブランドフェア
- 地域物産展
- 特別セール

### ショーケース（Showcase）

ショーケースは商品を保護しながら展示する什器で、用途や構造により4つの主要なタイプに分類されます。

#### クローズドケース（Closed Case）

**定義と特徴**
完全に密閉された展示ケースで、高額商品や繊細な商品の展示に使用されます。

**詳細仕様**
| 項目 | 仕様 |
|------|------|
| 構造 | 全面ガラス張り、施錠可能 |
| サイズ | 幅60cm～180cm、高さ90cm～200cm |
| 照明 | LED照明内蔵 |
| 温湿度管理 | 一部モデルで可能 |
| セキュリティ | 防犯センサー対応可 |

**使用例**
- 宝飾品店：高級時計、ジュエリー
- 電器店：高額カメラ、レンズ
- 眼鏡店：ブランドフレーム
- 博物館：貴重な展示品

#### オープンケース（Open Case）

**定義と特徴**
上部や前面が開放されており、顧客が直接商品に触れることができる展示ケースです。

**詳細仕様**
| 項目 | 仕様 |
|------|------|
| 構造 | 前面または上面開放型 |
| サイズ | 幅90cm～150cm、高さ70cm～120cm |
| 棚板 | ガラス製または金属製、可動式 |
| 背面 | ミラー仕上げまたはパネル |

**使用例**
- パン屋：焼きたてパンの陳列
- 雑貨店：アクセサリー、小物類
- 書店：文具、ステーショナリー
- 土産物店：地域特産品

#### リーチインケース（Reach-in Case）

**定義と特徴**
冷蔵・冷凍機能を持ち、扉を開けて商品を取り出すタイプのショーケースです。

**詳細仕様**
| 項目 | 仕様 |
|------|------|
| 温度帯 | 冷蔵：2℃～10℃、冷凍：-18℃～-25℃ |
| 扉 | ガラス扉（透明または曇りガラス） |
| 容量 | 300L～2000L |
| 省エネ性能 | インバーター制御、LED照明 |
| 扉の枚数 | 1～6枚 |

**使用例と温度管理**
- **コンビニエンスストア**
  - 飲料（3℃～5℃）：ペットボトル、缶飲料
  - デザート（2℃～4℃）：プリン、ゼリー
  - 冷凍食品（-18℃以下）：アイスクリーム、冷凍弁当

- **スーパーマーケット**
  - 乳製品（2℃～5℃）：牛乳、ヨーグルト
  - 精肉（0℃～2℃）：パック詰め肉類
  - 冷凍食品（-20℃以下）：冷凍野菜、冷凍魚介類

#### ウォークインケース（Walk-in Case）

**定義と特徴**
人が中に入って商品を選べる大型の冷蔵・冷凍室です。

**詳細仕様**
| 項目 | 仕様 |
|------|------|
| サイズ | 10㎡～100㎡以上 |
| 高さ | 2.5m～3.5m |
| 温度帯 | 冷蔵：0℃～10℃、冷凍：-25℃～-15℃ |
| 扉 | 自動ドアまたは手動スイングドア |
| 床材 | 滑り止め加工済み |

**使用例**
- **業務用スーパー**
  - 冷蔵室：野菜、果物の大量陳列
  - 冷凍室：冷凍食品の箱売り
  
- **酒類販売店**
  - ビール専用室（5℃～7℃）
  - ワインセラー（12℃～15℃、湿度60～70%）

## 3. 什器選択の実践的ガイド

### 業態別の什器構成例

#### コンビニエンスストア（売場面積：150㎡）
| 什器種類 | 台数 | 用途 |
|----------|------|------|
| ゴンドラ | 8～10台 | 一般商品陳列 |
| リーチインケース | 15～20台 | 飲料・冷蔵食品 |
| オープンケース | 2～3台 | おにぎり・サンドイッチ |
| ステージ | 1～2台 | 季節商品・キャンペーン |

#### 食品スーパー（売場面積：1000㎡）
| 什器種類 | 台数 | 用途 |
|----------|------|------|
| ゴンドラ | 40～50台 | 加工食品・日用品 |
| リーチインケース | 30～40台 | 冷蔵・冷凍食品 |
| オープンケース | 10～15台 | 青果・精肉・鮮魚 |
| ステージ | 5～8台 | 特売品・催事 |

### 什器配置の基本原則

#### ゴールデンゾーンの活用
- **高さ60cm～150cm**：最も見やすく手に取りやすい高さ
- **売れ筋商品**：ゴールデンゾーンに配置
- **高利益商品**：目線の高さに配置

#### 動線設計
1. **主通路**：幅1.8m～2.4m、ゴンドラを直角に配置
2. **副通路**：幅1.2m～1.5m、商品カテゴリー間の移動
3. **レジ前**：インパルス購買を促す小型什器の配置

## 4. 什器のメンテナンスと管理

### 日常メンテナンス
| 什器種類 | 清掃頻度 | 重点チェック項目 |
|----------|----------|----------------|
| ゴンドラ | 毎日 | 棚板の汚れ、プライスカードの状態 |
| ショーケース | 毎日 | ガラスの汚れ、照明の点灯確認 |
| 冷蔵・冷凍ケース | 毎日 | 温度確認、霜取り状態、ドアパッキン |

### 定期メンテナンス
- **月次点検**：什器の安定性、ネジの緩み、キャスターの動作
- **年次点検**：塗装の剥がれ、錆の発生、電気系統の点検

## 5. 最新トレンドと今後の展望

### デジタル技術の導入
- **電子棚札**：価格の自動更新、在庫連動
- **デジタルサイネージ**：動画による商品訴求
- **IoTセンサー**：在庫管理、温度管理の自動化

### サステナビリティへの対応
- **省エネ型冷蔵ケース**：自然冷媒の使用、高断熱材の採用
- **リサイクル可能素材**：什器の製造における環境配慮
- **モジュール設計**：部品交換による長寿命化

## 7. 理解度確認クイズ（4択問題20問）

### 問題1
ゴンドラの最も一般的な高さはどれか？

- A) 100cm
- B) 150cm
- C) 200cm
- D) 250cm

<details>
<summary>解答</summary>
<strong>正解: B) 150cm</strong><br>
ゴンドラの高さは120cm～180cmの範囲が一般的ですが、最も多く使用されるのは150cmです。この高さは平均的な成人の目線に近く、上段まで商品が見やすく、手も届きやすいため、売場効率が最も高くなります。<br>
<br>
Aの100cmは低すぎて陳列効率が悪く、Cの200cmやDの250cmは高すぎて上段の商品が取りにくくなるため、一般的ではありません。
</details>

### 問題2
ステージ什器の主な用途として最も適切なものはどれか？

- A) 在庫商品の保管
- B) レジ周りの小物陳列
- C) 季節商品や推奨商品の特別展示
- D) 従業員の作業台

<details>
<summary>解答</summary>
<strong>正解: C) 季節商品や推奨商品の特別展示</strong><br>
ステージは床面から一段高い位置に設置される展示台で、特別な商品を目立たせるための什器です。季節商品、新商品、キャンペーン商品など、特に注目してもらいたい商品の展示に使用されます。<br>
<br>
Aの在庫保管は倉庫やバックヤードの役割、Bのレジ周りにはレジ横什器、Dの作業台は作業用什器が適しており、ステージの用途ではありません。
</details>

### 問題3
クローズドケースの特徴として正しくないものはどれか？

- A) 全面がガラスで覆われている
- B) 顧客が自由に商品を手に取れる
- C) 施錠が可能である
- D) 高額商品の展示に適している

<details>
<summary>解答</summary>
<strong>正解: B) 顧客が自由に商品を手に取れる</strong><br>
クローズドケースは完全に密閉された展示ケースであり、顧客が直接商品に触れることはできません。商品を見せる際は、スタッフが鍵を開けて取り出す必要があります。<br>
<br>
A、C、Dはすべてクローズドケースの特徴として正しく、特に高額商品や繊細な商品を安全に展示するために使用されます。
</details>

### 問題4
リーチインケースの冷蔵温度帯として適切なものはどれか？

- A) -25℃～-18℃
- B) -10℃～-5℃
- C) 2℃～10℃
- D) 15℃～20℃

<details>
<summary>解答</summary>
<strong>正解: C) 2℃～10℃</strong><br>
リーチインケースの冷蔵温度帯は2℃～10℃が標準です。この温度帯は、飲料、乳製品、デザートなどの冷蔵商品を適切に保存するのに最適です。<br>
<br>
Aの-25℃～-18℃は冷凍温度帯、Bの-10℃～-5℃は冷蔵としては低すぎ、Dの15℃～20℃は常温に近く冷蔵の意味がありません。
</details>

### 問題5
ウォークインケースの最大の特徴は何か？

- A) 省エネ性能が高い
- B) 人が中に入って商品を選べる
- C) 設置面積が小さい
- D) 温度管理が不要

<details>
<summary>解答</summary>
<strong>正解: B) 人が中に入って商品を選べる</strong><br>
ウォークインケースの最大の特徴は、その名の通り「Walk-in（歩いて入る）」ことができる点です。顧客や従業員が冷蔵・冷凍室の中に入って、直接商品を選ぶことができます。<br>
<br>
Aの省エネ性能は一般的に大型のため劣り、Cの設置面積は逆に大きく、Dの温度管理は他の冷蔵ケース同様に必要です。
</details>

### 問題6
ゴンドラのエンド部分の活用方法として最も効果的なものはどれか？

- A) 在庫商品の一時保管
- B) 特売品や季節商品の大量陳列
- C) 清掃用具の設置
- D) 従業員の休憩スペース

<details>
<summary>解答</summary>
<strong>正解: B) 特売品や季節商品の大量陳列</strong><br>
ゴンドラのエンド（端部）は、通路に面して視認性が高いため、特売品や季節商品などのプロモーション商品を大量に陳列するのに最適です。エンド展開は売上向上の重要な手法の一つです。<br>
<br>
A、C、Dはいずれも売場の有効活用という観点から不適切で、特にエンドという目立つ場所を売上に貢献しない用途に使うのは機会損失となります。
</details>

### 問題7
オープンケースが最も適している商品はどれか？

- A) 高級腕時計
- B) 冷凍食品
- C) 焼きたてパン
- D) 医薬品

<details>
<summary>解答</summary>
<strong>正解: C) 焼きたてパン</strong><br>
オープンケースは上部や前面が開放されており、顧客が直接商品を手に取れる構造です。焼きたてパンのように、香りや見た目で訴求し、顧客が自分で選んで取る商品に最適です。<br>
<br>
Aの高級腕時計はセキュリティ上クローズドケース、Bの冷凍食品は温度管理が必要なリーチインケース、Dの医薬品は管理上の理由から通常は什器の後ろで管理されます。
</details>

### 問題8
食品スーパー（売場面積1000㎡）で最も設置台数が多い什器はどれか？

- A) ステージ
- B) ゴンドラ

- D) ウォークインケース

<details>
<summary>解答</summary>
<strong>正解: B) ゴンドラ</strong><br>
食品スーパーでは、加工食品や日用品などの常温商品を陳列するゴンドラが40～50台と最も多く設置されます。売場の基本となる什器であり、売場面積の大部分を占めます。<br>
<br>
Aのステージは5～8台程度、Cのクローズドケースは食品スーパーではほとんど使用されず、Dのウォークインケースは設置されても1～2室程度です。
</details>

### 問題9
什器のゴールデンゾーンの高さとして正しいものはどれか？

- A) 0cm～50cm
- B) 60cm～150cm
- C) 160cm～200cm
- D) 200cm以上

<details>
<summary>解答</summary>
<strong>正解: B) 60cm～150cm</strong><br>
ゴールデンゾーンは、顧客が最も見やすく手に取りやすい高さのことで、一般的に床から60cm～150cmの範囲を指します。この高さに売れ筋商品や高利益商品を配置することで、売上向上が期待できます。<br>
<br>
Aは低すぎて見にくく、CやDは高すぎて手が届きにくいため、ゴールデンゾーンとは呼ばれません。

### 問題10
リーチインケースとウォークインケースの最大の違いは何か？

- A) 温度管理の有無
- B) 商品の取り出し方法
- C) 設置場所
- D) 価格帯

リーチインケースは外から扉を開けて手を伸ばして（Reach-in）商品を取り出すのに対し、ウォークインケースは人が中に入って（Walk-in）商品を選ぶという取り出し方法の違いが最大の特徴です。<br>
<br>
Aの温度管理は両方とも必要、Cの設置場所は店舗レイアウト次第、Dの価格はサイズにより様々で、決定的な違いではありません。
</details>

### 問題11
コンビニエンスストアの飲料用リーチインケースの適正温度は？

- A) -5℃～0℃
- B) 0℃～2℃
- C) 3℃～5℃
- D) 10℃～15℃

<details>
<summary>解答</summary>

コンビニエンスストアの飲料は、3℃～5℃で管理されるのが一般的です。この温度帯は、飲料を美味しく感じる温度であり、かつ品質を保持できる温度です。<br>
<br>
AやBは冷たすぎて凍結の恐れがあり、Dは冷たさを感じにくく、夏場の需要に応えられません。
</details>

什器への初期投資額が最も高いものはどれか？

- A) ゴンドラ
- B) ステージ
- C) オープンケース
- D) リーチインケース

<details>
<summary>解答</summary>
<strong>正解: D) リーチインケース</strong><br>
リーチインケースは冷蔵・冷凍機能を持つため、初期投資額が30～100万円/台と最も高額です。冷却装置、断熱構造、温度制御システムなどが必要なためです。<br>
<br>
Aのゴンドラは5～15万円/台、Bのステージは構造が単純で比較的安価、Cのオープンケースも冷却機能がなければ10～30万円程度です。
</details>

### 問題13
ワインの保管に適したウォークインケースの温度と湿度は？

- A) 5℃～7℃、湿度40～50%
- B) 8℃～10℃、湿度50～60%
- C) 12℃～15℃、湿度60～70%
- D) 18℃～20℃、湿度70～80%

<details>
<summary>解答</summary>
<strong>正解: C) 12℃～15℃、湿度60～70%</strong><br>
ワインの保管には12℃～15℃の温度と60～70%の湿度が最適とされています。この環境により、ワインの熟成が適切に進み、コルクの乾燥も防げます。<br>
<br>
Aは温度が低すぎ、Bもやや低め、Dは温度が高すぎてワインの劣化を早める可能性があります。
</details>

### 問題14
什器の日常メンテナンスで最も重要な項目はどれか？

- A) 月1回の大掃除
- B) 年1回の塗装
- C) 毎日の清掃と点検
- D) 5年ごとの買い替え

<details>
<summary>解答</summary>
<strong>正解: C) 毎日の清掃と点検</strong><br>
什器の維持管理では、毎日の清掃と点検が最も重要です。特に食品を扱う什器では、衛生管理と温度管理の観点から日常的なメンテナンスが欠かせません。<br>
<br>
Aの月1回では頻度が少なく、Bの塗装は数年に1回程度、Dの買い替えは最終手段であり、日常メンテナンスとは言えません。
</details>

電子棚札の最大のメリットは、価格変更を本部から一括で行えることによる作業効率化です。従来の紙の値札交換作業が不要になり、人件費削減と価格の正確性向上が実現できます。<br>
<br>
Aの什器は依然必要、Cの自動補充は別のシステム、Dの万引き防止は電子棚札の主目的ではありません。
</details>

### 問題16

- D) 3.0m以上

### 問題17
省エネ型冷蔵ケースで採用されている技術として適切でないものは？

- A) 自然冷媒の使用
- B) LED照明
- C) 高断熱材
- D) 常時開放型扉

<details>
<summary>解答</summary>
<strong>正解: D) 常時開放型扉</strong><br>
省エネ型冷蔵ケースでは、冷気の漏れを防ぐために扉は密閉型が基本です。常時開放型では冷気が逃げてエネルギー効率が著しく低下します。<br>
<br>
A、B、Cはすべて省エネに貢献する技術で、特に自然冷媒は環境負荷も低減します。
</details>

### 問題18
什器投資の一般的な回収期間として最も現実的なものは？

- A) 3ヶ月～6ヶ月
- B) 1年～3年
- C) 5年～7年
- D) 10年以上

<details>
<summary>解答</summary>
<strong>正解: B) 1年～3年</strong><br>
什器投資の回収期間は、什器の種類や売上向上効果により異なりますが、一般的に1年～3年が目安とされています。これ以上長いと投資効率が悪いと判断されることが多いです。<br>
<br>
Aは短すぎて非現実的、Cは投資効率が悪く、Dは什器の耐用年数を考慮すると長すぎます。
</details>

### 問題19
冷凍食品の保管に適したリーチインケースの温度は？

- A) 0℃～2℃
- B) -5℃～-10℃
- C) -18℃～-25℃
- D) -30℃以下

<details>
<summary>解答</summary>
<strong>正解: C) -18℃～-25℃</strong><br>
冷凍食品の品質を保持するためには、-18℃以下での保管が必要です。一般的なリーチインケースでは-18℃～-25℃で管理されており、この温度帯が最も適しています。<br>
<br>
Aは冷蔵温度、Bは不十分な冷凍温度、Dは過度に低温でエネルギー効率が悪くなります。
</details>

### 問題20
什器レイアウトで「回遊性」を高めるための工夫として不適切なものは？

- A) 通路を一方通行にする
- B) 主通路と副通路を組み合わせる
- C) コーナーに魅力的な商品を配置
- D) 見通しの良い什器配置

<details>
<summary>解答</summary>
<strong>正解: A) 通路を一方通行にする</strong><br>
回遊性を高めるには、顧客が自由に動き回れる環境が重要です。一方通行にすると動線が制限され、顧客の自由な買い物を妨げ、回遊性が低下します。<br>
<br>
B、C、Dはいずれも回遊性を高める効果的な方法で、顧客が店内を楽しく巡回できる環境を作ります。
</details>

## 8. 専門用語集

### あ行

**ウォークインケース**
- **読み方**: うぉーくいんけーす
- **意味**: 人が中に入って商品を選べる大型の冷蔵・冷凍室。主に業務用スーパーや酒類販売店で使用される
- **関連用語**: リーチインケース、冷蔵室、冷凍室

**エンド（エンド展開）**
- **読み方**: えんど（えんどてんかい）
- **意味**: ゴンドラの端部分を利用した商品陳列。視認性が高く、特売品や季節商品の展示に効果的
- **関連用語**: ゴンドラ、プロモーション、エンドキャップ

**オープンケース**
- **読み方**: おーぷんけーす
- **意味**: 上部や前面が開放されており、顧客が直接商品に触れることができる展示ケース
- **関連用語**: ショーケース、クローズドケース

### か行

**回遊性**
- **読み方**: かいゆうせい
- **意味**: 顧客が店内を自由に動き回りやすい状態。売上向上に重要な要素
- **関連用語**: 動線、レイアウト

**クローズドケース**
- **読み方**: くろーずどけーす
- **意味**: 完全に密閉された展示ケース。高額商品や繊細な商品の展示に使用
- **関連用語**: ショーケース、オープンケース、セキュリティ

**ゴールデンゾーン**
- **読み方**: ごーるでんぞーん
- **意味**: 床から60cm～150cmの高さで、最も見やすく手に取りやすいゾーン。売れ筋商品の配置に最適
- **関連用語**: 棚割り、商品陳列

**ゴンドラ**
- **読み方**: ごんどら
- **意味**: 小売店舗で最も一般的な両面陳列可能な什器。可動棚により様々な商品に対応可能
- **関連用語**: 什器、陳列棚、エンド

### さ行

**什器**
- **読み方**: じゅうき
- **意味**: 商品の陳列・展示・保管に使用される店舗設備・備品の総称
- **関連用語**: 陳列器具、店舗設備

**ショーケース**
- **読み方**: しょーけーす
- **意味**: 商品を展示するためのケース型什器の総称。保護と展示の両機能を持つ
- **関連用語**: クローズドケース、オープンケース、リーチインケース、ウォークインケース

**ステージ**
- **読み方**: すてーじ
- **意味**: フロアから一段高い位置に設置される展示台。特別な商品の訴求に使用
- **関連用語**: 展示台、プロモーション什器

### た行

**棚割り**
- **読み方**: たなわり
- **意味**: 商品を什器のどの位置に配置するかを決める計画。売上に大きく影響
- **関連用語**: ゴールデンゾーン、フェイシング

**動線**
- **読み方**: どうせん
- **意味**: 店内での顧客や従業員の移動経路。効率的な動線設計が重要
- **関連用語**: 主通路、副通路、回遊性

### は行

**フェイシング**
- **読み方**: ふぇいしんぐ
- **意味**: 商品の陳列面数。売れ筋商品は多くのフェイスを取る
- **関連用語**: 棚割り、商品陳列

**プロモーション**
- **読み方**: ぷろもーしょん
- **意味**: 販売促進活動。什器を活用した商品訴求も重要な手法
- **関連用語**: エンド展開、ステージ、販促

### ら行

**リーチインケース**
- **読み方**: りーちいんけーす
- **意味**: 扉を開けて商品を取り出すタイプの冷蔵・冷凍ショーケース
- **関連用語**: 冷蔵ケース、冷凍ケース、ウォークインケース

**冷蔵ケース**
- **読み方**: れいぞうけーす
- **意味**: 2℃～10℃程度で商品を保管する什器。飲料や乳製品などに使用
- **関連用語**: リーチインケース、冷凍ケース、温度管理

**レイアウト**
- **読み方**: れいあうと
- **意味**: 店舗内の什器配置計画。売上や作業効率に大きく影響
- **関連用語**: 動線、什器配置、売場設計
