# MRP（Material Requirements Planning）について

## 概要
MRP（Material Requirements Planning：資材所要量計画）は、製造業において必要な資材を必要な時期に必要な量だけ調達・生産するための生産管理手法です。1960年代にアメリカで開発され、独立需要品目（完成品）の需要から従属需要品目（部品・原材料）の需要を計算し、在庫削減と納期遵守を実現する重要な生産計画システムとして発展してきました。

## 1. 基本概念・仕組み

### MRPの核となる概念
- **定義**: 最終製品の生産計画（マスタープロダクションスケジュール）に基づいて、必要な部品や原材料の所要量と調達時期を逆算して計画する手法
- **動作原理**: 部品展開（BOM展開）により最終製品から構成部品を展開し、リードタイムを考慮して必要時期を計算
- **特徴**: プッシュ型の生産管理システムで、計画主導型の資材調達を実現

### 従来の発注方式との関係
- **従来技術との違い**: 定期発注方式や定量発注方式と異なり、実際の需要に基づいた計画的な発注が可能
- **改善点**: 過剰在庫や欠品のリスクを大幅に削減し、資金効率を向上
- **限界**: 需要予測の精度に依存し、計画変更への柔軟性に課題がある

## 2. MRPシステムの構成要素

### 入力情報の分類
MRPシステムを正しく機能させるために必要な3つの基本入力情報があります。

### MPS（Master Production Schedule：基準生産計画）
**特徴:**
- 最終製品の生産スケジュールを週単位または日単位で計画
- 需要予測と受注情報に基づいて作成
- 計画期間は通常3～6ヶ月程度

**作成方法:**
```
MPS = 需要予測 + 確定受注 - 在庫量
```

**📊 具体的な計算例**
**例: 自転車製造会社のMPS作成**
- 需要予測: 100台/週
- 確定受注: 80台
- 現在庫: 20台

**ステップ1: 総需要の算出**
```
総需要 = max(需要予測, 確定受注) = max(100, 80) = 100台
```

**ステップ2: 生産必要量の計算**
```
生産必要量 = 総需要 - 現在庫 = 100 - 20 = 80台
```

**結果: 今週は80台の生産が必要**

💡 **実際の現場では**: 安全在庫を考慮し、変動に備えて10～20%程度の余裕を持たせることが一般的です。

### BOM（Bill of Materials：部品表）
**特徴:**
- 製品を構成する全ての部品・材料のリスト
- 階層構造で親子関係を明確化
- 各部品の必要数量を記載

**構造例:**
```
製品A
├── 部品B (2個)
│   ├── 部材C (3個)
│   └── 部材D (1個)
└── 部品E (1個)
    └── 部材F (4個)
```

### 在庫記録ファイル
**特徴:**
- 各品目の在庫量、発注残、リードタイムを管理
- リアルタイムまたは定期的に更新
- 安全在庫レベルの設定

## 3. MRP計算の詳細

### 基本計算式
#### 総所要量の計算
```
総所要量 = 独立需要 + 従属需要
```

#### 正味所要量の計算
```
正味所要量 = 総所要量 - 有効在庫
有効在庫 = 現在庫 + 発注残 - 引当済在庫
```

#### 手配量の決定
```
手配量 = 正味所要量（ロットまとめを考慮）
```

### MRP計算の実例

**📊 自転車製造の詳細計算例**

**前提条件:**
- 自転車100台の生産計画（第5週）
- BOM構成:
  - フレーム: 1個/台
  - タイヤ: 2個/台
  - ハンドル: 1個/台

**現在の在庫状況（第1週）:**
| 品目 | 現在庫 | 発注残 | リードタイム |
|------|--------|--------|--------------|
| フレーム | 20 | 30 | 2週間 |
| タイヤ | 50 | 100 | 3週間 |
| ハンドル | 10 | 0 | 1週間 |

**ステップ1: 総所要量の計算**
```
フレーム総所要量 = 100台 × 1個 = 100個
タイヤ総所要量 = 100台 × 2個 = 200個
ハンドル総所要量 = 100台 × 1個 = 100個
```

**ステップ2: 正味所要量の計算**
```
フレーム正味所要量 = 100 - (20 + 30) = 50個
タイヤ正味所要量 = 200 - (50 + 100) = 50個
ハンドル正味所要量 = 100 - (10 + 0) = 90個
```

**ステップ3: 発注時期の決定**
```
フレーム発注時期 = 第5週 - 2週間 = 第3週
タイヤ発注時期 = 第5週 - 3週間 = 第2週
ハンドル発注時期 = 第5週 - 1週間 = 第4週
```

**結果: 発注スケジュール**
- 第2週: タイヤ50個発注
- 第3週: フレーム50個発注
- 第4週: ハンドル90個発注

💡 **実際の現場では**: ロットサイズの制約（最小発注単位）や価格割引を考慮して発注量を調整します。

## 4. MRPの種類と発展

### クローズドループMRP
**特徴:**
- フィードバック機能を持つMRPシステム
- 実績と計画の差異を分析し、計画を修正
- 能力計画（CRP）との連携

**処理フロー:**
```
計画作成 → 実行 → 実績収集 → 差異分析 → 計画修正
```

### MRP II（Manufacturing Resource Planning）
**特徴:**
- MRPを拡張し、経営資源全体を計画対象に
- 財務計画、人員計画との統合
- シミュレーション機能の充実

**統合範囲:**
- 生産計画
- 在庫管理
- 購買管理
- 原価管理
- 財務管理

### ERP（Enterprise Resource Planning）への発展
**特徴:**
- 企業全体の経営資源を統合管理
- リアルタイムでの情報共有
- グローバル対応

### 基本実装（スプレッドシート）
```
週次MRP計算表の例：

| 週 | 総需要 | 在庫開始 | 生産量 | 在庫終了 | 発注量 |
|----|--------|----------|--------|----------|--------|
| 1  | 100    | 50       | 100    | 50       | 150    |
| 2  | 120    | 50       | 120    | 50       | 170    |
| 3  | 80     | 50       | 80     | 50       | 130    |
```

### システム実装の要件
```
MRPシステムの主要機能:
1. BOM管理機能
   - 多階層BOMの登録・編集
   - 版数管理
   - 代替部品管理

2. 在庫管理機能
   - リアルタイム在庫更新
   - ロケーション管理
   - 棚卸機能

3. 計画計算エンジン
   - 高速MRP計算
   - What-if分析
   - 例外レポート生成
```

### 実際の適用事例

#### 事例1: 自動車部品メーカーA社
- **課題**: 多品種少量生産による在庫過多と欠品の頻発
- **適用方法**: 週次MRP計算の導入と日次での微調整
- **結果**: 在庫回転率が年4回から年12回に改善
- **効果**: 在庫金額を70%削減、納期遵守率99%達成

#### 事例2: 電子機器メーカーB社
- **課題**: グローバルサプライチェーンの複雑化
- **適用方法**: クラウドベースのMRPシステム導入
- **結果**: リードタイムを30%短縮
- **効果**: 緊急発注コストを年間5000万円削減

## 6. メリット・デメリット

### メリット

**1. 在庫削減効果**
- **理由**: 必要な時に必要な分だけ調達
- **効果**: 在庫保有コストを30～50%削減可能
- **具体例**: 部品在庫の月数を3ヶ月から1ヶ月に短縮

**2. 納期遵守率の向上**
- **理由**: 計画的な資材調達により欠品を防止
- **効果**: 納期遵守率を95%以上に向上
- **具体例**: 緊急発注の削減により安定供給を実現

**3. 業務の標準化**
- **理由**: システマティックな計画立案
- **効果**: 属人化の解消と業務効率化
- **具体例**: 計画作成時間を週40時間から10時間に短縮

### デメリット

**1. 初期投資の大きさ**
- **理由**: システム導入とデータ整備が必要
- **影響**: 中小企業には導入障壁が高い
- **対策**: 段階的導入やクラウドサービスの活用

**2. データ精度への依存**
- **理由**: 不正確なデータは計画全体に影響
- **影響**: 在庫過不足の原因となる
- **対策**: 定期的なデータメンテナンスと棚卸

**3. 計画変更への対応の難しさ**
- **理由**: 大量のデータ再計算が必要
- **影響**: 急な需要変動に弱い
- **対策**: 短サイクルでの計画見直しとバッファ管理

## 7. 選択・導入の指針

### MRP導入適性の判断基準
| 観点 | 適している | 適していない |
|------|------------|--------------|
| 製品構成 | 多階層BOM | 単純な構成 |
| 需要特性 | 予測可能 | 変動が激しい |
| 生産形態 | 計画生産 | 受注生産 |
| 企業規模 | 中規模以上 | 小規模 |

### 導入判断フローチャート
1. **部品点数は100点以上か？**
   - Yes → 次の判断へ
   - No → 簡易的な在庫管理で対応

2. **BOMは3階層以上か？**
   - Yes → MRP導入を推奨
   - No → スプレッドシートでの管理を検討

3. **月間の計画変更は10%以内か？**
   - Yes → 標準的なMRP導入
   - No → 高頻度更新対応のMRPまたはカンバン方式を検討

## 8. 最新動向・今後の展望

- **現在の課題**: IoT/AIとの統合、リアルタイム化への対応
- **研究動向**: 機械学習による需要予測精度の向上、自動計画修正機能
- **将来予測**: 2030年までに完全自動化されたMRPシステムが主流に
- **関連技術**: APS（Advanced Planning and Scheduling）、S&OP（Sales and Operations Planning）

- D) 製品の品質を向上させること

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
MRPの主目的は、必要な資材を必要な時期に必要な量だけ調達することです。これにより在庫削減と納期遵守を実現します。<br>

<summary>解答</summary>

</details>

## 10. 専門用語集

このドキュメントで使用された専門用語について、アルファベット順・50音順で解説します。

### アルファベット

**APS (Advanced Planning and Scheduling)**
- **読み方**: エーピーエス
- **意味**: 生産スケジューリングの高度な最適化を行うシステム。MRPの結果を受けて、設備能力や作業員の制約を考慮した詳細スケジュールを作成
- **関連用語**: MRP、生産スケジューリング

**BOM (Bill of Materials)**
- **読み方**: ボム、ビーオーエム
- **意味**: 製品を構成する部品や原材料の一覧表。親子関係と必要数量を階層構造で表現
- **関連用語**: 部品表、製品構成表、部品展開

**CRP (Capacity Requirements Planning)**
- **読み方**: シーアールピー
- **意味**: 能力所要量計画。MRPの結果から必要な生産能力を計算し、能力不足を事前に把握
- **関連用語**: MRP、能力計画

**ERP (Enterprise Resource Planning)**
- **読み方**: イーアールピー
- **意味**: 企業資源計画。企業の経営資源（ヒト・モノ・カネ・情報）を統合的に管理するシステム
- **関連用語**: MRP II、統合業務パッケージ

**JIT (Just In Time)**
- **読み方**: ジット、ジャストインタイム
- **意味**: 必要なものを必要な時に必要な量だけ生産・調達する生産方式
- **関連用語**: カンバン方式、トヨタ生産方式

**MPS (Master Production Schedule)**
- **読み方**: エムピーエス
- **意味**: 基準生産計画。最終製品の生産スケジュールを示す計画
- **関連用語**: 生産計画、大日程計画

**MRP (Material Requirements Planning)**
- **読み方**: エムアールピー
- **意味**: 資材所要量計画。製品の生産計画から必要な部品・原材料の量と時期を計算するシステム
- **関連用語**: MRP II、資材計画

**MRP II (Manufacturing Resource Planning)**
- **読み方**: エムアールピーツー
- **意味**: 製造資源計画。MRPを拡張し、財務・人員などの経営資源全体を統合的に計画するシステム
- **関連用語**: MRP、ERP

**S&OP (Sales and Operations Planning)**
- **読み方**: エスアンドオーピー
- **意味**: 販売・生産統合計画。営業計画と生産計画を統合し、需給バランスを最適化する経営手法
- **関連用語**: 需給調整、統合計画

**What-if分析**
- **読み方**: ワットイフぶんせき
- **意味**: 「もし～だったら」という仮定のもとでシミュレーションを行い、結果を予測する分析手法
- **関連用語**: シミュレーション、感度分析

### あ行

**安全在庫（あんぜんざいこ）**
- **意味**: 需要変動や納期遅延などの不確実性に備えて保有する余裕在庫
- **関連用語**: バッファ在庫、保険在庫

### か行

**カンバン方式（かんばんほうしき）**
- **意味**: トヨタが開発した生産管理方式。後工程が前工程に生産を指示するプル型システム
- **関連用語**: JIT、プル型生産

**基準生産計画（きじゅんせいさんけいかく）**
- **意味**: MPSの日本語訳。最終製品の生産スケジュールを定めた計画
- **関連用語**: MPS、大日程計画

**クローズドループMRP（くろーずどるーぷえむあーるぴー）**
- **意味**: 実績データをフィードバックして計画を修正する機能を持つMRPシステム
- **関連用語**: フィードバック、計画修正

### さ行

**在庫回転率（ざいこかいてんりつ）**
- **意味**: 一定期間に在庫が何回転したかを示す指標。売上原価÷平均在庫で計算
- **関連用語**: 在庫効率、在庫保有期間

**在庫記録ファイル（ざいこきろくふぁいる）**
- **意味**: 各品目の現在庫量、発注残、リードタイムなどを記録したデータベース
- **関連用語**: 在庫マスタ、在庫台帳

**資材所要量計画（しざいしょようりょうけいかく）**
- **意味**: MRPの日本語訳。生産に必要な資材の量と時期を計画すること
- **関連用語**: MRP、資材計画

**従属需要（じゅうぞくじゅよう）**
- **意味**: 最終製品の需要から派生する部品・原材料の需要
- **関連用語**: 独立需要、派生需要

**正味所要量（しょうみしょようりょう）**
- **意味**: 総所要量から有効在庫を差し引いた、実際に手配が必要な量
- **関連用語**: 総所要量、有効在庫

**総所要量（そうしょようりょう）**
- **意味**: ある期間に必要な品目の総量。在庫を考慮しない必要量
- **関連用語**: 正味所要量、グロス所要量

### た行

**独立需要（どくりつじゅよう）**
- **意味**: 他の品目の需要に依存しない、最終製品などの需要
- **関連用語**: 従属需要、最終需要

### は行

**部品展開（ぶひんてんかい）**
- **意味**: BOMに基づいて製品から構成部品を展開し、必要量を計算すること
- **関連用語**: BOM展開、爆発計算

**部品表（ぶひんひょう）**
- **意味**: BOMの日本語訳。製品の構成部品とその数量を示す表
- **関連用語**: BOM、製品構成表

**プッシュ型生産（ぷっしゅがたせいさん）**
- **意味**: 計画に基づいて前工程から後工程へ押し出す生産方式
- **関連用語**: プル型生産、計画主導型

### ま行

**マスタープロダクションスケジュール**
- **意味**: MPSのカタカナ表記。基準生産計画のこと
- **関連用語**: MPS、基準生産計画

### や行

**有効在庫（ゆうこうざいこ）**
- **意味**: 現在庫に発注残を加え、引当済在庫を引いた、使用可能な在庫量
- **関連用語**: 利用可能在庫、正味在庫

### ら行

**リードタイム（りーどたいむ）**
- **意味**: 発注から納入までに要する時間。調達リードタイムと製造リードタイムがある
- **関連用語**: 調達期間、製造期間

**ロットサイズ（ろっとさいず）**
- **意味**: 一度に生産または発注する数量の単位
- **関連用語**: バッチサイズ、発注単位
