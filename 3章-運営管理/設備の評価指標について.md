# 設備の評価指標について

## 概要
設備の評価指標は、製造業やサービス業において設備の性能、信頼性、効率性を定量的に測定・管理するための重要な尺度です。これらの指標を適切に活用することで、設備投資の意思決定、保全計画の策定、生産性向上などが可能となります。本資料では、主要な設備評価指標である平均故障間動作時間（MTBF）、平均修復時間（MTTR）、アベイラビリティ（可用性）、および設備更新について詳しく解説します。

## 1. 基本概念・仕組み

### 設備評価指標の体系
- **定義**: 設備の性能や状態を定量的に表現し、管理・改善に活用する数値指標
- **動作原理**: 設備の稼働データ、故障データ、修理データなどを収集・分析して算出
- **特徴**: 
  - 設備の現状を客観的に把握可能
  - 時系列での比較により改善効果を検証可能
  - 設備間の性能比較が可能

### 従来の管理手法との関係
- **従来手法との違い**: 経験や勘に頼る管理から、データに基づく科学的管理への移行
- **改善点**: 予防保全、予知保全の実現による計画外停止の削減
- **限界**: データ収集・分析のための初期投資とシステム構築が必要

## 2. 主要指標の詳細

### 平均故障間動作時間（MTBF: Mean Time Between Failures）
**特徴:**
- 設備の信頼性を表す最も基本的な指標
- 故障と故障の間の平均稼働時間
- 値が大きいほど信頼性が高い

**算出方法:**
```
MTBF = 総稼働時間 ÷ 故障回数
```

**📊 具体的な計算例**
**例: 製造ラインAの信頼性評価**
- 測定期間: 1年間（365日）
- 計画稼働時間: 8,760時間（24時間×365日）
- 実際の稼働時間: 8,200時間
- 故障回数: 20回

**ステップ1: 総稼働時間の確認**
```
総稼働時間 = 8,200時間
```

**ステップ2: MTBFの計算**
```
MTBF = 8,200時間 ÷ 20回 = 410時間
```

**結果: 平均して410時間に1回故障が発生**

💡 **実際の現場では**: MTBFが高い設備は予防保全の間隔を長く設定でき、保全コストの削減が可能です。一般的に、重要設備では1,000時間以上のMTBFが求められます。

### 平均修復時間（MTTR: Mean Time To Repair）
**特徴:**
- 設備の保全性（メンテナビリティ）を表す指標
- 故障発生から修理完了までの平均時間
- 値が小さいほど保全性が高い

**算出方法:**
```
MTTR = 総修理時間 ÷ 修理回数
```

**📊 具体的な計算例**
**例: 包装機械の保全性評価**
- 測定期間: 6ヶ月
- 修理回数: 15回
- 各修理時間: 2, 3, 1.5, 4, 2.5, 3.5, 2, 5, 1, 3, 2.5, 4.5, 3, 2, 3時間

**ステップ1: 総修理時間の計算**
```
総修理時間 = 2 + 3 + 1.5 + 4 + 2.5 + 3.5 + 2 + 5 + 1 + 3 + 2.5 + 4.5 + 3 + 2 + 3 = 42.5時間
```

**ステップ2: MTTRの計算**
```
MTTR = 42.5時間 ÷ 15回 = 2.83時間
```

**結果: 平均修理時間は約2.83時間**

💡 **実際の現場では**: MTTRを短縮するため、予備品の在庫管理、作業手順の標準化、保全員のスキル向上などが重要です。

### アベイラビリティ（可用性）
**特徴:**
- 設備が要求されたときに稼働可能な確率
- MTBFとMTTRを組み合わせた総合指標
- パーセンテージで表現され、高いほど良い

**算出方法:**
```
アベイラビリティ = MTBF ÷ (MTBF + MTTR) × 100%
```

**📊 具体的な計算例**
**例: プレス機械の可用性評価**
- MTBF: 500時間
- MTTR: 5時間

**ステップ1: 分母の計算**
```
MTBF + MTTR = 500 + 5 = 505時間
```

**ステップ2: アベイラビリティの計算**
```
アベイラビリティ = 500 ÷ 505 × 100% = 99.01%
```

**結果: 設備の可用性は99.01%**

💡 **実際の現場では**: 重要設備では99%以上のアベイラビリティが求められることが多く、99.5%以上を目標とする場合もあります。

### 設備更新
**特徴:**
- 既存設備を新しい設備に置き換える戦略的意思決定
- 技術的・経済的観点から総合的に判断
- タイミングが重要な経営判断

**評価方法:**
```
設備更新の判断基準 = 技術的要因 + 経済的要因 + 戦略的要因
```

**📊 具体的な評価例**
**例: 加工機械の更新検討**
- 現設備の使用年数: 15年
- 年間保全費用: 500万円（増加傾向）
- 新設備投資額: 3,000万円
- 新設備による年間コスト削減: 400万円

**ステップ1: 投資回収期間の計算**
```
投資回収期間 = 3,000万円 ÷ 400万円 = 7.5年
```

**ステップ2: 総合評価**
- 技術的要因: 故障頻度増加、部品調達困難
- 経済的要因: 保全費用増加、生産性低下
- 戦略的要因: 新製品対応不可、競争力低下

**結果: 設備更新を推奨**

## 3. 詳細仕様・パラメータ

### MTBFの詳細パラメータ
#### 稼働時間の定義
- **意味**: 設備が正常に動作している時間
- **設定範囲**: 24時間連続稼働から断続運転まで様々
- **影響**: 稼働パターンによりMTBF値が変動
- **推奨値**: 業界標準に基づく目標値設定

#### 故障の定義
- **意味**: 設備が要求機能を果たせない状態
- **設定範囲**: 完全停止から性能低下まで
- **影響**: 定義により故障回数が変動
- **推奨値**: 明確な基準の文書化

### MTTRの詳細パラメータ
#### 修理時間の範囲
- **意味**: 故障認知から修理完了までの時間
- **設定範囲**: 診断時間、部品調達時間、実作業時間を含む
- **影響**: 含める範囲により値が大きく変動
- **推奨値**: 全工程を含めた測定

#### 修理体制
- **意味**: 保全員の配置と対応体制
- **設定範囲**: 常駐から外注まで
- **影響**: 体制により応答時間が変動
- **推奨値**: 設備重要度に応じた体制構築

## 4. 実装例・適用事例

### 基本実装
```python
# 設備評価指標計算システムの基本実装
class EquipmentMetrics:
    def __init__(self):
        self.operation_hours = []
        self.failure_times = []
        self.repair_times = []
    
    def calculate_mtbf(self):
        total_operation = sum(self.operation_hours)
        failure_count = len(self.failure_times)
        if failure_count == 0:
            return float('inf')
        return total_operation / failure_count
    
    def calculate_mttr(self):
        if not self.repair_times:
            return 0
        return sum(self.repair_times) / len(self.repair_times)
    
    def calculate_availability(self):
        mtbf = self.calculate_mtbf()
        mttr = self.calculate_mttr()
        if mtbf == float('inf'):
            return 1.0
        return mtbf / (mtbf + mttr)
```

### 応用実装
```python
# より高度な設備評価システム
import numpy as np
from datetime import datetime, timedelta

class AdvancedEquipmentMetrics:
    def __init__(self):
        self.events = []  # (timestamp, event_type, duration)
        
    def add_event(self, timestamp, event_type, duration=0):
        self.events.append({
            'timestamp': timestamp,
            'type': event_type,  # 'failure', 'repair_start', 'repair_end'
            'duration': duration
        })
    
    def calculate_weibull_mtbf(self):
        """ワイブル分布を用いたMTBF予測"""
        failure_intervals = self._get_failure_intervals()
        if len(failure_intervals) < 2:
            return None
            
        # ワイブル分布パラメータの推定
        shape, scale = self._estimate_weibull_params(failure_intervals)
        
        # 期待値（MTBF）の計算
        from scipy.special import gamma
        mtbf = scale * gamma(1 + 1/shape)
        return mtbf
    
    def predict_next_failure(self):
        """次回故障時期の予測"""
        mtbf = self.calculate_weibull_mtbf()
        if not mtbf:
            return None
            
        last_repair = self._get_last_repair_time()
        predicted_failure = last_repair + timedelta(hours=mtbf)
        return predicted_failure
    
    def optimize_maintenance_schedule(self, cost_pm, cost_cm):
        """予防保全スケジュールの最適化"""
        # cost_pm: 予防保全コスト
        # cost_cm: 事後保全コスト
        
        mtbf = self.calculate_mtbf()
        optimal_interval = mtbf * np.sqrt(cost_pm / cost_cm)
        return optimal_interval
```

## 5. メリット・デメリット

### メリット
**1. 客観的な設備管理**
- **理由**: 数値化により感覚的判断を排除
- **効果**: 適切な投資判断と資源配分
- **具体例**: A工場では指標導入により保全費用20%削減

**2. 予防保全の実現**
- **理由**: 傾向分析による故障予測が可能
- **効果**: 計画外停止の大幅削減
- **具体例**: B社では計画外停止を年間50回から10回に削減

**3. 継続的改善の推進**
- **理由**: 定量的な目標設定と効果測定が可能
- **効果**: PDCAサイクルの確立
- **具体例**: C工場では3年間でMTBF倍増を達成

### デメリット
**1. 初期投資の必要性**
- **理由**: データ収集システムの構築コスト
- **影響**: 中小企業では導入障壁となる場合あり
- **対策**: 段階的導入や簡易システムから開始

**2. データ収集の負担**
- **理由**: 正確なデータ入力には工数が必要
- **影響**: 現場の負担増加による抵抗
- **対策**: IoT活用による自動化推進

**3. 指標の誤用リスク**
- **理由**: 数値のみに注目し本質を見失う危険
- **影響**: 不適切な意思決定の可能性
- **対策**: 複数指標の総合評価と定性的要因の考慮

## 6. 選択・導入の指針

### 設備評価指標の選択基準
| 観点 | MTBF重視 | MTTR重視 | アベイラビリティ重視 |
|------|-----------|-----------|-------------------|
| 適用設備 | 高信頼性要求設備 | 修理容易性重視設備 | バランス重視設備 |
| 業界例 | 半導体製造 | 食品製造 | 自動車製造 |
| 改善方針 | 予防保全強化 | 保全体制強化 | 総合的改善 |
| 投資優先度 | 設備品質向上 | 保全ツール・訓練 | 両方均等 |

### 適用判断フローチャート
1. **設備の重要度評価**
   - クリティカル設備 → 全指標を詳細管理
   - 一般設備 → 基本指標のみ管理

2. **現状の問題点分析**
   - 故障頻度が高い → MTBF改善を優先
   - 修理時間が長い → MTTR改善を優先

3. **投資余力の確認**
   - 十分な予算 → 総合的システム導入
   - 限定的予算 → 重点指標から段階導入

設備の信頼性を表す指標として最も適切なものはどれか？

- A) MTTR（平均修復時間）
- B) MTBF（平均故障間動作時間）
- C) アベイラビリティ
- D) 稼働率

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
MTBFは故障と故障の間の平均稼働時間を表し、設備の信頼性を直接的に示す指標です。<br>
<br>
Aが間違いの理由：MTTRは保全性（修理のしやすさ）を表す指標<br>
Cが間違いの理由：アベイラビリティは信頼性と保全性の総合指標<br>
Dが間違いの理由：稼働率は計画に対する実績の割合で、故障以外の要因も含む
</details>

- D) 876時間

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>

### 問題4
MTBF=400時間、MTTR=4時間の設備のアベイラビリティは？

- A) 99.0%
- B) 98.0%
- C) 99.5%
- D) 97.5%

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
アベイラビリティ = MTBF ÷ (MTBF + MTTR) × 100% = 400 ÷ (400 + 4) × 100% = 400 ÷ 404 × 100% = 99.0%<br>
<br>
Bが間違いの理由：計算式を誤って適用（396/400などの誤計算）<br>
Cが間違いの理由：より高い値だが、実際の計算結果と異なる<br>
Dが間違いの理由：より低い値で、計算結果と大きく異なる
</details>

## 9. 専門用語集

このスライドで使用された技術用語について、アルファベット順・50音順で解説します。

### アルファベット

**ABC分析（ABC Analysis）**
- **読み方**: エービーシーぶんせき
- **意味**: 重要度により対象を3段階（A:最重要、B:重要、C:一般）に分類する手法。設備管理では故障影響度により設備を分類
- **関連用語**: パレート分析、重要度分類

**IoT（Internet of Things）**
- **読み方**: アイオーティー
- **意味**: モノのインターネット。設備にセンサーを取り付け、ネットワーク経由でデータを収集・分析する技術
- **関連用語**: インダストリー4.0、スマートファクトリー

**LCC（Life Cycle Cost）**
- **読み方**: エルシーシー、ライフサイクルコスト
- **意味**: 設備の取得から廃棄までの全期間にかかる総費用。初期投資、運用費、保全費、廃棄費の合計
- **関連用語**: TCO（Total Cost of Ownership）

**MTBF（Mean Time Between Failures）**
- **読み方**: エムティービーエフ
- **意味**: 平均故障間動作時間。故障から次の故障までの平均稼働時間で、設備の信頼性を表す指標
- **関連用語**: 信頼性、故障率

**MTTR（Mean Time To Repair）**
- **読み方**: エムティーティーアール
- **意味**: 平均修復時間。故障発生から修理完了までの平均時間で、設備の保全性を表す指標
- **関連用語**: 保全性、修理時間

**PM（Preventive Maintenance）**
- **読み方**: ピーエム
- **意味**: 予防保全。故障が発生する前に計画的に実施する保全活動
- **関連用語**: 定期保全、計画保全

**TPM（Total Productive Maintenance）**
- **読み方**: ティーピーエム
- **意味**: 全員参加の生産保全。オペレーターも含めた全員で設備の効率化を図る活動
- **関連用語**: 自主保全、5S活動

### あ行

**アベイラビリティ（Availability）**
- **読み方**: あべいらびりてぃ
- **意味**: 可用性。設備が要求されたときに稼働可能な確率。MTBFとMTTRから算出される総合指標
- **関連用語**: 稼働率、信頼性

**慣らし運転（Break-in Operation）**
- **読み方**: ならしうんてん
- **意味**: 新設備導入時に、初期不良を洗い出すために実施する試運転期間
- **関連用語**: 初期故障、バスタブ曲線

### か行

**可用性（Availability）**
- **読み方**: かようせい
- **意味**: アベイラビリティの日本語訳。設備がいつでも使用可能な状態にある度合い
- **関連用語**: アベイラビリティ、稼働率

**機会損失（Opportunity Loss）**
- **読み方**: きかいそんしつ
- **意味**: 設備故障により生産できなかったことによる利益の損失
- **関連用語**: ダウンタイムコスト、生産損失

**故障率（Failure Rate）**
- **読み方**: こしょうりつ
- **意味**: 単位時間あたりの故障発生確率。MTBFの逆数として表される
- **関連用語**: MTBF、信頼性

### さ行

**自主保全（Autonomous Maintenance）**
- **読み方**: じしゅほぜん
- **意味**: オペレーター自身が行う日常的な保全活動。清掃、給油、増締めなど
- **関連用語**: TPM、5S活動

**状態監視保全（Condition Based Maintenance）**
- **読み方**: じょうたいかんしほぜん
- **意味**: 設備の状態を常時監視し、異常の兆候を検知して実施する保全
- **関連用語**: 予知保全、振動診断

**信頼性（Reliability）**
- **読み方**: しんらいせい
- **意味**: 設備が故障せずに要求機能を果たし続ける能力。MTBFで定量化
- **関連用語**: MTBF、故障率

### た行

**ダウンタイム（Downtime）**
- **読み方**: だうんたいむ
- **意味**: 設備が停止している時間。計画停止と計画外停止に分類される
- **関連用語**: 稼働時間、アップタイム

**デジタルツイン（Digital Twin）**
- **読み方**: でじたるついん
- **意味**: 現実の設備と同じ挙動をする仮想モデル。シミュレーションによる最適化が可能
- **関連用語**: シミュレーション、Industry 4.0

### は行

**バスタブ曲線（Bathtub Curve）**
- **読み方**: ばすたぶきょくせん
- **意味**: 設備の故障率が時間経過とともに変化する様子を表した曲線。初期故障期、偶発故障期、摩耗故障期の3期
- **関連用語**: 故障率、ライフサイクル

**保全性（Maintainability）**
- **読み方**: ほぜんせい
- **意味**: 設備の修理・保全のしやすさ。MTTRで定量化される
- **関連用語**: MTTR、修理時間

### や行

**予知保全（Predictive Maintenance）**
- **読み方**: よちほぜん
- **意味**: 設備の状態データから故障を予測し、故障前に保全を実施する手法
- **関連用語**: 状態監視、振動診断

**予防保全（Preventive Maintenance）**
- **読み方**: よぼうほぜん
- **意味**: 故障が発生する前に、時間や使用量を基準に計画的に実施する保全
- **関連用語**: 定期保全、TBM（Time Based Maintenance）

### ら行

**ライフサイクル（Life Cycle）**
- **読み方**: らいふさいくる
- **意味**: 設備の導入から廃棄までの全期間。設計、製造、使用、保全、廃棄の各段階
- **関連用語**: LCC、設備更新

**劣化（Deterioration）**
- **読み方**: れっか
- **意味**: 時間経過や使用により設備の性能が低下すること
- **関連用語**: 摩耗、老朽化

### わ行

**ワイブル分布（Weibull Distribution）**
- **読み方**: わいぶるぶんぷ
- **意味**: 故障データの解析に用いられる確率分布。故障の発生パターンを数学的にモデル化
- **関連用語**: 故障解析、信頼性工学
