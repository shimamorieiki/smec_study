# エコアクション21について

## 概要

エコアクション21は、環境省が策定した日本独自の環境マネジメントシステム（EMS）認証・登録制度です。中小事業者等の環境への取り組みを促進するとともに、その取り組みを効果的・効率的に実施するため、国際標準化機構のISO14001規格をベースとしつつ、中小事業者にとって取り組みやすい環境経営システムのあり方を規定しています。2004年に制度が開始され、環境への取組と経営の両立を図る「環境経営」のツールとして、多くの中小企業に活用されています。

エコアクション21の特徴は、環境マネジメントシステム、環境パフォーマンス評価及び環境報告を一つに統合したものであり、それぞれの要素において以下を要求しています：①PDCAサイクルに基づく環境マネジメントシステムの構築・運用・維持、②CO2削減・廃棄物削減・水使用量削減等の環境パフォーマンスの向上、③環境活動レポートの作成・公表による環境コミュニケーションの促進。

本制度は、特に中小企業における環境経営の普及を目的としており、ISO14001と比較して、取り組みやすく、費用負担も少ないという特徴があります。また、環境省のガイドラインに基づいた第三者認証制度であるため、社会的信頼性も確保されています。

## 1. エコアクション21の基本概念・定義

### エコアクション21の定義
- **定義**: 環境省が策定した、中小事業者等の幅広い事業者に対して、自主的に「環境への関わりに気づき、目標を持ち、行動することができる」ことを支援する日本独自の環境マネジメントシステム
- **特徴**: ①ガイドラインに基づく環境経営システムの構築・運用・維持、②環境への取組に関する目標を持ち、行動し、結果を取りまとめ、評価し、公表する仕組み、③第三者による認証・登録制度
- **重要性**: 中小企業の環境経営を促進し、持続可能な経済社会の構築に貢献

### 環境マネジメントシステム（EMS）
- **定義**: 組織が環境方針を定め、その実現のために計画（Plan）、実施（Do）、点検（Check）、改善（Act）のPDCAサイクルを回しながら継続的改善を行う仕組み
- **特徴**: ①体系的・組織的な環境管理、②継続的改善の仕組み、③トップマネジメントのコミットメント
- **重要性**: 環境負荷の低減と経営の効率化を同時に実現

### 環境活動レポート
- **定義**: エコアクション21に取り組む事業者が、環境方針、環境目標、環境活動計画とその実績、環境関連法規制の遵守状況、その他の環境への取組等を取りまとめた報告書
- **特徴**: ①年1回以上の作成・公表義務、②規定された項目の記載要求、③ステークホルダーとのコミュニケーションツール
- **重要性**: 環境情報の透明性確保と社会的信頼性の向上

## 2. エコアクション21の認証・登録の仕組み

### 認証・登録制度の概要
エコアクション21の認証・登録は、環境省が定めたガイドラインに基づき、一般財団法人持続性推進機構（IPSuS）が中央事務局として運営しています。

### 認証・登録の区分

#### 通常の認証・登録
| 項目 | 内容 |
|------|------|
| 特徴 | 単独の事業者が個別に認証・登録を受ける |
| 適用範囲 | 全組織・全活動を対象とすることが原則 |
| 注意点 | 段階的認証も可能だが、4年以内に全組織・全活動に拡大する必要がある |

#### 業種別ガイドラインによる認証・登録
| 項目 | 内容 |
|------|------|
| 特徴 | 特定業種向けに策定されたガイドラインに基づく認証 |
| 適用範囲 | 建設業、食品関連事業者、産業廃棄物処理業等 |
| 注意点 | 業種特有の環境負荷や法規制に対応した要求事項が追加される |

#### サプライチェーン型認証・登録
| 項目 | 内容 |
|------|------|
| 特徴 | 大手企業（中核企業）が関係企業と一体となって認証を受ける |
| 適用範囲 | サプライチェーン全体での環境負荷低減を目指す |
| 注意点 | 中核企業のリーダーシップとサポートが重要 |

## 3. 具体的な取組事例・計算例

### ケース1: 製造業A社（従業員50名）の環境負荷削減

#### パターンA: CO2排出量の削減
- **前提条件**: 
  - 年間電力使用量：300,000kWh
  - 電力のCO2排出係数：0.470kg-CO2/kWh
  - 削減目標：前年度比5%削減
- **計算過程**: 
  - 現状のCO2排出量：300,000kWh × 0.470kg-CO2/kWh = 141,000kg-CO2
  - 削減目標量：141,000kg-CO2 × 5% = 7,050kg-CO2
  - 目標排出量：141,000kg-CO2 - 7,050kg-CO2 = 133,950kg-CO2
- **結果**: 年間7,050kg-CO2の削減が必要

#### パターンB: 廃棄物排出量の削減
- **前提条件**: 
  - 年間廃棄物排出量：120トン
  - リサイクル率：60%
  - 削減目標：廃棄物排出量10%削減、リサイクル率70%達成
- **計算過程**: 
  - 現状の最終処分量：120トン × (100% - 60%) = 48トン
  - 削減後の廃棄物排出量：120トン × 90% = 108トン
  - 目標リサイクル率達成時の最終処分量：108トン × (100% - 70%) = 32.4トン
- **結果**: 最終処分量を48トンから32.4トンへ15.6トン削減

### ケース2: サービス業B社（従業員20名）の環境活動

#### 水使用量の削減
- **前提条件**: 
  - 年間水使用量：1,200m³
  - 水道料金単価：300円/m³
  - 削減目標：前年度比3%削減
- **計算過程**: 
  - 現状の水道料金：1,200m³ × 300円/m³ = 360,000円
  - 削減目標量：1,200m³ × 3% = 36m³
  - 削減後の水使用量：1,200m³ - 36m³ = 1,164m³
  - 削減後の水道料金：1,164m³ × 300円/m³ = 349,200円
- **結果**: 年間10,800円のコスト削減効果

## 4. エコアクション21導入の手続き・プロセス

### 導入から認証取得までの流れ

1. **ステップ1: 導入の準備・体制づくり**
   - 詳細説明：経営者のコミットメント表明、環境経営責任者の任命、実施体制の構築
   - 必要書類：組織図、役割分担表
   - 注意点：全従業員の参加意識を高めることが重要

2. **ステップ2: 環境負荷と環境への取組状況の把握**
   - 詳細説明：エネルギー使用量、廃棄物排出量、水使用量等のデータ収集・分析
   - 必要書類：環境負荷チェックシート、取組チェックシート
   - 注意点：過去1年間のデータを正確に把握する

3. **ステップ3: 環境方針の策定**
   - 詳細説明：組織の環境への取組の基本的方向を示す方針を策定
   - 必要書類：環境方針文書
   - 注意点：経営者による署名が必要

4. **ステップ4: 環境目標と環境活動計画の策定**
   - 詳細説明：3年程度の中期目標と単年度目標を設定、具体的な活動計画を作成
   - 必要書類：環境目標設定表、環境活動計画書
   - 注意点：実現可能で検証可能な目標設定が重要

5. **ステップ5: 計画の実施と運用**
   - 詳細説明：環境活動計画に基づく取組の実施、教育訓練の実施、文書・記録の管理
   - 必要書類：実施記録、教育訓練記録、各種管理記録
   - 注意点：PDCAサイクルを意識した運用

6. **ステップ6: 取組状況の点検と問題の是正**
   - 詳細説明：定期的な監視測定、内部監査の実施、不適合の是正処置
   - 必要書類：監視測定記録、内部監査報告書、是正処置記録
   - 注意点：客観的な評価と改善が重要

7. **ステップ7: 環境活動レポートの作成と公表**
   - 詳細説明：1年間の取組結果をまとめたレポートを作成し、外部に公表
   - 必要書類：環境活動レポート
   - 注意点：規定項目を網羅し、分かりやすい内容にする

8. **ステップ8: 審査申込と現地審査**
   - 詳細説明：審査機関への申込、書類審査と現地審査の受審
   - 必要書類：審査申込書、各種環境経営システム文書一式
   - 注意点：審査費用は事業規模により異なる

### 関連する制度・規則
- **根拠法令**: 環境基本法、環境配慮促進法
- **所管官庁**: 環境省
- **関連制度**: ISO14001、エコステージ、KES（京都環境マネジメントシステムスタンダード）

## 5. 実務上の注意点

### エコアクション21導入時の重要ポイント
- **ポイント1**: 経営者の強いリーダーシップと全従業員の参加が不可欠
- **ポイント2**: 身の丈に合った目標設定と段階的な取組の拡大
- **ポイント3**: 環境負荷データの正確な把握と継続的な記録管理

### よくある誤解・トラブル
- **誤解1**: 「認証取得が目的」→ 正しくは「環境経営の継続的改善が目的」
- **誤解2**: 「大企業向けの制度」→ 正しくは「中小企業向けに設計された制度」
- **誤解3**: 「費用対効果が見込めない」→ 正しくは「省エネ・省資源によるコスト削減効果が期待できる」

## 6. よくある質問（Q&A）

### Q1. エコアクション21とISO14001の違いは何ですか？

**A1.** エコアクション21はISO14001と比較して、以下の点で中小企業に適した制度となっています。

#### 主な違いの詳細説明
1. **要求事項の簡素化**: エコアクション21は必要最小限の要求事項に絞り込まれており、中小企業でも取り組みやすい
2. **費用負担**: 審査・認証費用がISO14001の約1/5～1/10程度と安価
3. **環境活動レポート**: エコアクション21では作成・公表が必須だが、ISO14001では任意
4. **具体的な環境パフォーマンス項目**: CO2、廃棄物、水使用量の把握が必須要求事項として明記

### Q2. エコアクション21の認証取得にかかる期間と費用はどの程度ですか？

**A2.** 事業規模により異なりますが、一般的な目安は以下の通りです。

#### 期間と費用の詳細説明
**取得期間**: 
- 準備開始から認証取得まで：6ヶ月～1年程度
- 既に環境活動を行っている場合：3～6ヶ月程度

**費用の目安**（従業員数による）:
- 30人以下：審査費用10～15万円、2年間の認証・登録料5万円
- 31～60人：審査費用15～20万円、2年間の認証・登録料10万円
- 61～100人：審査費用20～25万円、2年間の認証・登録料15万円

### Q3. 部分的な認証取得は可能ですか？

**A3.** 段階的認証という仕組みがあり、部分的な認証取得が可能です。

#### 段階的認証の詳細説明
段階的認証は、以下の条件を満たす必要があります：
1. **初回認証時**: 本社を含む主要な事業所を対象範囲に含める
2. **拡大計画**: 4年以内に全組織・全活動に拡大する計画を策定
3. **毎年の拡大**: 中間審査または更新審査時に対象範囲を拡大
4. **最終目標**: 4年以内に全組織・全活動での認証取得を完了

## 7. まとめ・今後の展望

エコアクション21は、中小企業の環境経営を促進する有効なツールとして、着実に普及が進んでいます。2023年時点で約7,500社が認証を取得しており、環境負荷の低減だけでなく、経営効率の向上、企業イメージの向上、従業員の意識改革等、多面的な効果をもたらしています。

今後の展望として、以下の動向が注目されます：
1. **カーボンニュートラルへの対応強化**: 2050年カーボンニュートラル実現に向けた取組の強化
2. **デジタル化の推進**: 環境データ管理のデジタル化、オンライン審査の拡充
3. **サプライチェーン全体での取組**: 大企業を中心としたサプライチェーン型認証の拡大
4. **SDGsとの連携**: SDGs達成に向けた取組との統合的な運用

エコアクション21は、中小企業が無理なく環境経営に取り組めるよう、今後も制度の改善と普及促進が図られていくことが期待されます。

- C) 環境省が策定した日本独自の環境マネジメントシステムである
- D) 環境活動レポートの作成は任意である

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
エコアクション21は環境省が策定した日本独自の環境マネジメントシステムです。ISO14001をベースとしていますが、中小企業向けに要求事項を簡素化しており（Aは誤り）、大企業専用ではなく中小企業向けの制度です（Bは誤り）。また、環境活動レポートの作成・公表は必須要求事項です（Dは誤り）。

<summary>解答</summary>

<details>
<summary>解答</summary>

</details>

### 問題11
年間電力使用量が250,000kWh、電力のCO2排出係数が0.500kg-CO2/kWhの事業所が、電力使用量を10%削減した場合のCO2削減量はどれか。

- A) 10,000kg-CO2
- B) 12,500kg-CO2
- C) 25,000kg-CO2
- D) 125,000kg-CO2

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
計算過程：<br>
1. 現状のCO2排出量 = 250,000kWh × 0.500kg-CO2/kWh = 125,000kg-CO2<br>
2. 電力削減量 = 250,000kWh × 10% = 25,000kWh<br>
3. CO2削減量 = 25,000kWh × 0.500kg-CO2/kWh = 12,500kg-CO2<br>
したがって、正解は12,500kg-CO2となります。
</details>

最終処分量の計算：<br>
最終処分量 = 廃棄物排出量 × (100% - リサイクル率)<br>

</details>
