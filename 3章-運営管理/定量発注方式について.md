# 定量発注方式について

## 概要
定量発注方式（Fixed Quantity Ordering System）は、在庫管理の基本的な手法の一つで、在庫が一定の水準（発注点）に達したときに、あらかじめ決められた一定量（経済的発注量）を発注する方式です。製造業、流通業、小売業など幅広い業界で採用されており、適切な在庫レベルを維持しながら、在庫保有コストと発注コストのバランスを最適化することを目的としています。この方式は、需要が比較的安定している商品や、単価が高い商品、保管スペースに制約がある場合に特に有効です。

## 1. 基本概念・仕組み

### 定量発注方式の基本原理
- **定義**: 在庫量が事前に設定した発注点を下回ったときに、常に一定の量（経済的発注量）を発注する在庫管理方式
- **動作原理**: 継続的な在庫監視により、在庫量が発注点に達した瞬間に自動的に発注プロセスが開始される
- **特徴**: 
  - 発注量は常に一定（経済的発注量）
  - 発注タイミングは在庫量に依存（不定期）
  - 需要変動に対して柔軟に対応可能
  - システム化・自動化が比較的容易

### 従来の発注方式との関係
- **定期発注方式との違い**: 
  - 定量発注：発注量固定、発注時期変動
  - 定期発注：発注時期固定、発注量変動
- **改善点**: 
  - 過剰在庫・欠品リスクの低減
  - 発注作業の効率化
  - 在庫保有コストの最適化
- **限界**: 
  - 需要の大幅な変動への対応が困難
  - 継続的な在庫監視が必要
  - 初期パラメータ設定に専門知識が必要

## 2. 主要構成要素

### 構成要素の分類
定量発注方式は、以下の3つの主要な構成要素から成り立っています。

### 安全在庫（Safety Stock）
**特徴:**
- 需要変動や納期遅延に対するバッファー
- 欠品リスクを回避するための最小限の在庫
- サービスレベルに応じて設定される

**算出方法:**
```
安全在庫 = 安全係数 × √リードタイム × 需要の標準偏差
```

**📊 具体的な計算例**
**例: 電子部品メーカーの安全在庫計算**
- 平均日需要: 100個
- 需要の標準偏差: 20個
- リードタイム: 5日
- 目標サービスレベル: 95%（安全係数: 1.65）

**ステップ1: リードタイム中の需要変動を計算**
```
リードタイム中の標準偏差 = √5 × 20 = 2.236 × 20 = 44.72個
```

**ステップ2: 安全在庫を計算**
```
安全在庫 = 1.65 × 44.72 = 73.8個 ≈ 74個
```

**結果: 74個の安全在庫を保持することで、95%の確率で欠品を回避できる**

💡 **実際の現場では**: 季節変動や特別なイベント（キャンペーンなど）を考慮して、安全係数を調整することが一般的です。

### 発注点（Reorder Point）
**特徴:**
- 発注を行うトリガーとなる在庫水準
- リードタイム中の需要と安全在庫の合計
- 自動発注システムの重要なパラメータ

**算出方法:**
```
発注点 = (平均日需要 × リードタイム) + 安全在庫
```

**📊 具体的な計算例**
**例: 小売店の発注点設定**
- 平均日需要: 50個
- リードタイム: 7日
- 安全在庫: 100個（上記とは別の商品）

**ステップ1: リードタイム中の需要を計算**
```
リードタイム中の需要 = 50個/日 × 7日 = 350個
```

**ステップ2: 発注点を計算**
```
発注点 = 350個 + 100個 = 450個
```

**結果: 在庫が450個を下回ったら自動的に発注を行う**

💡 **実際の現場では**: 発注点は定期的に見直し、需要パターンの変化に応じて調整します。

### 経済的発注量（Economic Order Quantity: EOQ）
**特徴:**
- 総在庫コストを最小化する最適な発注量
- 発注コストと在庫保有コストのトレードオフを考慮
- 数理モデルに基づく科学的な算出方法

**算出方法:**
```
EOQ = √(2 × 年間需要量 × 1回あたり発注コスト / 在庫保有コスト率 × 単価)
```

**📊 具体的な計算例**
**例: 製造業の原材料発注**
- 年間需要量: 10,000個
- 1回あたり発注コスト: 5,000円
- 単価: 1,000円
- 在庫保有コスト率: 20%（0.2）

**ステップ1: 公式に値を代入**
```
EOQ = √(2 × 10,000 × 5,000 / 0.2 × 1,000)
    = √(100,000,000 / 200)
    = √500,000
    = 707個
```

**ステップ2: 年間発注回数を確認**
```
年間発注回数 = 10,000個 ÷ 707個 = 14.1回 ≈ 14回
```

**結果: 707個ずつ年14回発注することで、総コストが最小となる**

💡 **実際の現場では**: 発注単位（ロットサイズ）の制約や、保管スペースの制限なども考慮して最終的な発注量を決定します。

## 3. 実装手順

### 定量発注方式の導入プロセス
#### パラメータ設定の詳細
- **意味**: 安全在庫、発注点、経済的発注量の初期値設定
- **設定範囲**: 過去の需要データ（最低1年分）を基に統計的に算出
- **影響**: 在庫回転率、欠品率、総在庫コストに直接影響
- **推奨値**: 業界や商品特性により異なるが、サービスレベル95%程度から開始

#### モニタリング体制の構築
- **意味**: 在庫量の継続的な監視と発注実行の仕組み
- **設定範囲**: リアルタイム〜日次での在庫チェック
- **影響**: 発注の適時性と在庫精度に影響
- **推奨値**: 高回転商品はリアルタイム、低回転商品は日次監視

```python
    current_stock = get_current_stock(item_code)
    reorder_point = get_reorder_point(item_code)

        send_notification("発注実行: " + item_code)
    
    return current_stock
```

## 5. メリット・デメリット

### メリット
**1. 在庫管理の効率化**
- **理由**: 発注判断が明確で自動化可能
- **効果**: 管理工数の大幅削減（約60%削減）
- **具体例**: 1日2時間の発注業務が30分に短縮

**2. 在庫コストの最適化**
- **理由**: 数理モデルに基づく科学的な在庫量設定
- **効果**: 総在庫コスト15-30%削減
- **具体例**: 年間1億円の在庫が7,000万円に削減

**3. 欠品リスクの低減**
- **理由**: 安全在庫による需要変動への対応
- **効果**: サービスレベル95%以上の維持
- **具体例**: 月間欠品件数が50件から5件に減少

### デメリット
**1. 初期設定の複雑性**
- **理由**: 統計的な分析と専門知識が必要
- **影響**: 導入期間の長期化（3-6ヶ月）
- **対策**: 専門コンサルタントの活用、段階的導入

**2. 需要変動への対応限界**
- **理由**: パラメータが固定的で急激な変化に弱い
- **影響**: 季節商品や新商品での精度低下
- **対策**: 定期的なパラメータ見直し、AI予測の活用

**3. システム投資の必要性**
- **理由**: 継続的な在庫監視にはITシステムが不可欠
- **影響**: 初期投資100万円〜1,000万円
- **対策**: クラウドサービスの活用、段階的なシステム化

### 適用判断フローチャート
1. **商品の需要は安定しているか？** 
   - Yes → 定量発注方式を検討
   - No → 次の判断へ

2. **在庫管理システムは導入済みか？**
   - Yes → 定量発注方式が最適  
   - No → 定期発注方式またはシステム導入を検討

3. **商品単価は高いか？**
   - Yes → 定量発注方式を強く推奨
   - No → コスト効果を詳細に検証

## 9. 専門用語集

このドキュメントで使用された専門用語について、アルファベット順・50音順で解説します。

### アルファベット
**ABC分析 (ABC Analysis)**
- **読み方**: エービーシーぶんせき
- **意味**: 在庫品目を売上高や出荷量の大きさによってA・B・Cの3つのグループに分類し、重要度に応じた管理方法を適用する手法
- **関連用語**: パレート分析、重点管理

**EDI (Electronic Data Interchange)**
- **読み方**: イーディーアイ
- **意味**: 企業間で商取引に関する情報を標準的な形式に統一して、電子的に交換する仕組み
- **関連用語**: VMI、サプライチェーン管理

**EOQ (Economic Order Quantity)**
- **読み方**: イーオーキュー
- **意味**: 経済的発注量。発注コストと在庫保有コストの合計を最小化する最適な発注量
- **関連用語**: 定量発注方式、総在庫コスト

**IoT (Internet of Things)**
- **読み方**: アイオーティー
- **意味**: モノのインターネット。様々な物体にセンサーを付けてインターネットに接続し、相互に情報交換する仕組み
- **関連用語**: RFID、スマートシェルフ

**POS (Point of Sale)**
- **読み方**: ポス
- **意味**: 販売時点情報管理システム。商品が販売された時点で即座に情報を記録・集計するシステム
- **関連用語**: 需要予測、在庫管理システム

**RFID (Radio Frequency Identification)**
- **読み方**: アールエフアイディー
- **意味**: 電波を使って非接触でICタグの情報を読み書きする技術
- **関連用語**: IoT、自動認識技術

**VMI (Vendor Managed Inventory)**
- **読み方**: ブイエムアイ
- **意味**: ベンダー管理在庫。供給者が需要者の在庫を管理し、適切なタイミングで補充を行う仕組み
- **関連用語**: サプライチェーン管理、在庫管理

### あ行
**安全在庫（あんぜんざいこ）**
- **読み方**: あんぜんざいこ
- **意味**: 需要変動や納期遅延などの不確実性に対応するために保有する余裕在庫。バッファー在庫とも呼ばれる
- **関連用語**: サービスレベル、欠品率

**安全係数（あんぜんけいすう）**
- **読み方**: あんぜんけいすう
- **意味**: 目標とするサービスレベルを達成するために、安全在庫の計算で使用する統計的な係数
- **関連用語**: 正規分布、標準偏差

### か行
**欠品（けっぴん）**
- **読み方**: けっぴん
- **意味**: 在庫切れにより顧客の注文に応じられない状態。品切れとも呼ばれる
- **関連用語**: サービスレベル、機会損失

**経済的発注量（けいざいてきはっちゅうりょう）**
- **読み方**: けいざいてきはっちゅうりょう
- **意味**: 発注コストと在庫保有コストの合計を最小化する最適な発注数量。EOQとも呼ばれる
- **関連用語**: 総在庫コスト、最適化

### さ行
**在庫回転率（ざいこかいてんりつ）**
- **読み方**: ざいこかいてんりつ
- **意味**: 一定期間に在庫が何回転したかを示す指標。年間売上高を平均在庫額で割って算出
- **関連用語**: 在庫効率、キャッシュフロー

**在庫保有コスト（ざいこほゆうこすと）**
- **読み方**: ざいこほゆうこすと
- **意味**: 在庫を保管することで発生する費用。保管費、資本費、陳腐化費用などを含む
- **関連用語**: 総在庫コスト、在庫管理費用

**サービスレベル（さーびすれべる）**
- **読み方**: さーびすれべる
- **意味**: 顧客の注文に対して在庫切れを起こさずに対応できる確率。充足率とも呼ばれる
- **関連用語**: 欠品率、顧客満足度

### た行
**定期発注方式（ていきはっちゅうほうしき）**
- **読み方**: ていきはっちゅうほうしき
- **意味**: あらかじめ決められた一定の周期で発注を行い、発注量は在庫状況に応じて変動させる方式
- **関連用語**: 定量発注方式、発注方式

**定量発注方式（ていりょうはっちゅうほうしき）**
- **読み方**: ていりょうはっちゅうほうしき
- **意味**: 在庫が発注点を下回ったときに、常に一定量（経済的発注量）を発注する在庫管理方式
- **関連用語**: 発注点、経済的発注量

### は行
**発注コスト（はっちゅうこすと）**
- **読み方**: はっちゅうこすと
- **意味**: 1回の発注にかかる固定的な費用。発注書作成、検品、事務処理などの費用を含む
- **関連用語**: 総在庫コスト、固定費

**発注点（はっちゅうてん）**
- **読み方**: はっちゅうてん
- **意味**: 発注を行うトリガーとなる在庫水準。リードタイム中の需要と安全在庫の合計で設定
- **関連用語**: リードタイム、定量発注方式

**標準偏差（ひょうじゅんへんさ）**
- **読み方**: ひょうじゅんへんさ
- **意味**: データのばらつきを表す統計量。需要変動の大きさを測る際に使用
- **関連用語**: 分散、正規分布

### ら行
**リードタイム（りーどたいむ）**
- **読み方**: りーどたいむ
- **意味**: 発注してから商品が納入されるまでの所要時間。調達期間とも呼ばれる
- **関連用語**: 発注点、納期
