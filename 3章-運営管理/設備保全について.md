# 設備保全について

## 概要
設備保全は、製造業において生産設備の性能を維持・向上させ、故障による生産停止を防ぎ、製品品質を確保するための重要な活動です。適切な保全活動により、設備の寿命延長、生産性向上、総合的なコスト削減を実現できます。現代の製造業では、IoTやAI技術を活用した高度な保全管理が進展しており、予知保全や改良保全といった先進的な手法が注目されています。

## 1. 基本概念・仕組み

### 設備保全の定義
- **定義**: 生産設備が持つ機能・性能を維持し、故障を未然に防ぎ、また故障した場合には速やかに復旧させる一連の活動
- **動作原理**: PDCA（Plan-Do-Check-Act）サイクルに基づいた継続的改善プロセス
- **特徴**: 技術的側面（点検・修理）と管理的側面（計画・評価）の両面を含む総合的活動

### 故障の分類
- **故障（Failure）**: 設備が要求される機能を果たせなくなった状態
- **チョコ停（Minor Stoppage）**: 短時間（通常10分以内）で復旧可能な軽微な停止
- **ドカ停（Major Stoppage）**: 長時間（通常30分以上）にわたる重大な停止

## 2. 保全方式の分類

### 時間軸による分類
保全活動は、故障発生のタイミングとの関係で大きく分類されます。

### 事後保全（Breakdown Maintenance）
**特徴:**
- 故障が発生してから修理を行う方式
- 計画的ではなく、突発的な対応が中心
- 緊急対応能力が重要

**算出方法:**
```
事後保全コスト = 修理費用 + 生産損失 + 品質損失 + 緊急対応費
```

**📊 具体的な計算例**
**例: 食品製造ラインの充填機故障**
- 修理費用: 50万円（部品代30万円 + 作業費20万円）
- 生産損失: 200万円（停止時間4時間 × 時間当たり生産高50万円）
- 品質損失: 30万円（不良品廃棄）
- 緊急対応費: 20万円（休日出勤手当等）

**結果: 総コスト300万円**

💡 **実際の現場では**: 重要度の低い設備や、故障しても影響が小さい設備に適用されることが多い

### 予防保全（Preventive Maintenance）
**特徴:**
- 故障が発生する前に計画的に保全を実施
- 時間基準保全（TBM: Time Based Maintenance）が中心
- 定期的な点検・部品交換を実施

**算出方法:**
```
予防保全間隔 = MTBF（平均故障間隔） × 安全係数（0.7～0.9）
```

**📊 具体的な計算例**
**例: コンプレッサーの予防保全計画**
- MTBF: 5,000時間
- 安全係数: 0.8
- 1日の稼働時間: 16時間

**ステップ1: 予防保全間隔の計算**
```
予防保全間隔 = 5,000時間 × 0.8 = 4,000時間
```

**ステップ2: 保全実施日数の計算**
```
保全実施日数 = 4,000時間 ÷ 16時間/日 = 250日
```

**結果: 約8ヶ月ごとに予防保全を実施**

### 定期保全（Periodic Maintenance）
**特徴:**
- 予防保全の一種で、一定期間ごとに実施
- カレンダー基準での管理が中心
- 法定点検も含まれる

**実施内容:**
- 日常点検（毎日）
- 週次点検（毎週）
- 月次点検（毎月）
- 年次点検（毎年）

### 予知保全（Predictive Maintenance）
**特徴:**
- 設備の状態を監視し、異常の兆候を検知して保全を実施
- 状態基準保全（CBM: Condition Based Maintenance）とも呼ばれる
- センサーやIoT技術を活用

**監視項目:**
- 振動測定
- 温度測定
- 潤滑油分析
- 電流値監視

**📊 具体的な計算例**
**例: 回転機械の振動監視による予知保全**
- 正常時振動値: 2.0mm/s
- 注意値: 4.5mm/s
- 危険値: 7.0mm/s
- 現在の振動値: 3.8mm/s

**劣化速度の計算:**
```
劣化速度 = (3.8 - 2.0) ÷ 運転時間1,000h = 0.0018mm/s/h
```

**保全実施時期の予測:**
```
残存時間 = (4.5 - 3.8) ÷ 0.0018 = 約389時間
```

**結果: 約390時間後（約24日後）に保全実施を計画**

### 改良保全（Improvement Maintenance）
**特徴:**
- 設備の弱点を改善し、信頼性を向上させる活動
- 故障の根本原因を解決
- 設計変更や材質変更を含む

**実施内容:**
- 故障解析（なぜなぜ分析）
- 設計改善
- 部品の材質変更
- 構造の補強

### 保全予防（Maintenance Prevention）
**特徴:**
- 設備の設計・製作段階から保全を考慮
- 保全が不要または容易な設備を目指す
- ライフサイクルコストの最適化

**重要な違い：予防保全との比較**
| 項目 | 予防保全 | 保全予防 |
|------|----------|----------|
| 実施時期 | 設備稼働後 | 設備設計段階 |
| 目的 | 故障の未然防止 | 保全作業の削減・簡易化 |
| アプローチ | 定期的な保全実施 | 保全しやすい設計 |
| 対象 | 既存設備 | 新規設備 |
| 効果 | 故障率低減 | 保全コスト削減 |

## 3. 保全体制の分類

### 集中保全（Centralized Maintenance）
**特徴:**
- 専門の保全部門が全設備の保全を担当
- 高度な技術力を持つ専門家が対応
- 設備管理の一元化

**メリット:**
- 専門技術の集約
- 保全品質の均一化
- 効率的な人員配置

**デメリット:**
- 現場との距離
- 対応の遅れ
- コミュニケーション不足

### 部門保全（Departmental Maintenance）
**特徴:**
- 各製造部門が自部門の設備保全を担当
- 現場に密着した保全活動
- オペレーターによる日常保全も含む

**メリット:**
- 迅速な対応
- 設備特性の深い理解
- 現場ニーズの反映

**デメリット:**
- 技術力のばらつき
- 専門性の不足
- 部門間の連携不足

## 4. 実装例・適用事例

### TPM（Total Productive Maintenance）の実施例
```
【8本柱の活動】
1. 個別改善
2. 自主保全
3. 計画保全
4. 初期管理
5. 品質保全
6. 教育訓練
7. 管理間接
8. 安全・環境
```

### 実際の適用事例
#### 事例1: 自動車部品製造工場
- **課題**: プレス機のチョコ停が頻発（1日平均20回）
- **適用方法**: 
  - 振動センサーによる予知保全導入
  - オペレーターによる日常点検強化
  - 金型の改良保全実施
- **結果**: チョコ停回数が1日平均3回に減少
- **効果**: 稼働率15%向上、年間3,000万円のコスト削減

#### 事例2: 化学プラント
- **課題**: 反応釜の突発故障によるドカ停（年3回発生）
- **適用方法**:
  - IoTセンサーによる24時間監視
  - AI分析による異常予測
  - 予知保全システムの構築
- **結果**: 突発故障ゼロを2年間継続
- **効果**: 生産損失5,000万円/年の削減

## 5. メリット・デメリット

### 各保全方式のメリット・デメリット比較

**事後保全**
- メリット: 初期投資不要、設備を限界まで使用
- デメリット: 突発故障リスク、高い修理コスト

**予防保全**
- メリット: 故障の未然防止、計画的な生産
- デメリット: 過剰保全の可能性、部品の無駄

**予知保全**
- メリット: 最適なタイミングでの保全、コスト最適化
- デメリット: 高い初期投資、専門技術が必要

## 6. 選択・導入の指針

### 保全方式選択の基準
| 観点 | 事後保全 | 予防保全 | 予知保全 |
|------|----------|----------|----------|
| 初期コスト | ◎ | ○ | △ |
| 運用コスト | △ | ○ | ◎ |
| 信頼性 | △ | ○ | ◎ |
| 技術レベル | ◎ | ○ | △ |

### 適用判断フローチャート
1. **設備の重要度は高いか？** 
   - Yes → 予防保全または予知保全へ
   - No → 事後保全を検討

2. **故障の予測は可能か？**
   - Yes → 予知保全を推奨
   - No → 予防保全を推奨

3. **投資対効果は見込めるか？**
   - Yes → 選択した保全方式を実施
   - No → より簡易な方式を再検討

## 7. 最新動向・今後の展望
- **現在の課題**: 熟練保全技術者の不足、設備の高度化・複雑化
- **研究動向**: AI・機械学習による故障予測精度の向上、デジタルツイン技術の活用
- **将来予測**: 完全自動化された予知保全システム、自己修復機能を持つ設備
- **関連技術**: IoT、ビッグデータ、5G通信、エッジコンピューティング

- B) 設備の機能・性能を維持し、故障を防ぐこと
- C) 設備をできるだけ長く使い続けること
- D) 設備の外観をきれいに保つこと

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
設備保全の基本的な目的は、設備の機能・性能を維持し、故障を未然に防ぐことです。<br>
<br>

Dが間違いの理由：外観ではなく機能・性能が重要<br>

【補足】実務では、設備の重要度に応じて保全レベルを設定し、コストと効果のバランスを考慮します。

### 問題4
MTBF（平均故障間隔）が4,000時間、安全係数0.8の場合、予防保全間隔として適切なものはどれか？

- A) 2,000時間
- B) 3,200時間
- C) 4,000時間
- D) 5,000時間

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
予防保全間隔 = MTBF × 安全係数 = 4,000時間 × 0.8 = 3,200時間<br>
<br>
Aが間違いの理由：計算が誤っている（安全係数0.5相当）<br>
Cが間違いの理由：安全係数を考慮していない<br>
Dが間違いの理由：安全係数を誤って乗算ではなく加算している<br>
<br>
【補足】安全係数は通常0.7～0.9の範囲で設定され、設備の重要度により調整します。
</details>

### 問題12

- B) 92.5%
- C) 95.2%
- D) 98.0%

<summary>解答</summary>

計算過程：200 ÷ 210 × 100 = 95.238...% ≈ 95.2%<br>
<br>
【補足】可用性は設備が要求されたときに稼働可能な確率を示す重要な指標です。
</details>

### 問題15
年間保全費用500万円、年間故障損失300万円、改良保全投資200万円で故障損失を100万円に削減できる場合、投資回収期間は？

- A) 0.5年
- B) 1年
- C) 1.5年
- D) 2年

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
投資回収期間 = 投資額 ÷ 年間削減額 = 200万円 ÷ (300万円 - 100万円) = 1年<br>
<br>
計算の詳細：削減額 = 300万円 - 100万円 = 200万円/年<br>
投資回収期間 = 200万円 ÷ 200万円/年 = 1年<br>
<br>
【補足】実際の投資判断では、金利や他の投資機会も考慮する必要があります。
</details>

## 9. 専門用語集

このスライドで使用された専門用語について、アルファベット順・50音順で解説します。

### アルファベット

**CBM (Condition Based Maintenance)**
- **読み方**: シービーエム
- **意味**: 状態基準保全。設備の状態を監視し、必要な時に保全を行う方式
- **関連用語**: 予知保全、状態監視

**IoT (Internet of Things)**
- **読み方**: アイオーティー
- **意味**: モノのインターネット。設備にセンサーを取り付け、ネットワーク経由でデータ収集する技術
- **関連用語**: スマートファクトリー、インダストリー4.0

**MTBF (Mean Time Between Failures)**
- **読み方**: エムティービーエフ
- **意味**: 平均故障間隔。故障から次の故障までの平均時間
- **関連用語**: 信頼性、稼働率

**MTTR (Mean Time To Repair)**
- **読み方**: エムティーティーアール
- **意味**: 平均修復時間。故障発生から修理完了までの平均時間
- **関連用語**: 保全性、可用性

**OEE (Overall Equipment Effectiveness)**
- **読み方**: オーイーイー
- **意味**: 設備総合効率。稼働率×性能率×品質率で算出される総合指標
- **関連用語**: TPM、生産性

**PDCA (Plan-Do-Check-Act)**
- **読み方**: ピーディーシーエー
- **意味**: 計画・実行・評価・改善のマネジメントサイクル
- **関連用語**: 継続的改善、品質管理

**TBM (Time Based Maintenance)**
- **読み方**: ティービーエム
- **意味**: 時間基準保全。一定時間ごとに保全を実施する方式
- **関連用語**: 予防保全、定期保全

**TPM (Total Productive Maintenance)**
- **読み方**: ティーピーエム
- **意味**: 全員参加の生産保全。製造部門と保全部門が協力して行う保全活動
- **関連用語**: 自主保全、8本柱

### あ行

**改良保全（かいりょうほぜん）**
- **意味**: 設備の弱点を改善し、信頼性や保全性を向上させる活動
- **関連用語**: 信頼性向上、設計改善

**可用性（かようせい）**
- **意味**: 設備が要求されたときに稼働可能である確率
- **関連用語**: 信頼性、保全性、MTBF、MTTR

### か行

**故障（こしょう）**
- **意味**: 設備が要求される機能を果たせなくなった状態
- **関連用語**: 不具合、異常、停止

### さ行

**事後保全（じごほぜん）**
- **意味**: 故障が発生してから修理を行う保全方式
- **関連用語**: 故障修理、緊急保全

**自主保全（じしゅほぜん）**
- **意味**: オペレーターが自分の設備を自分で保全する活動
- **関連用語**: TPM、日常点検

**集中保全（しゅうちゅうほぜん）**
- **意味**: 専門の保全部門が全設備の保全を一元的に担当する体制
- **関連用語**: 保全体制、専門保全

**状態監視（じょうたいかんし）**
- **意味**: センサー等により設備の状態を継続的に監視すること
- **関連用語**: 予知保全、CBM

### た行

**チョコ停（ちょこてい）**
- **意味**: 10分以内で復旧可能な軽微な設備停止
- **関連用語**: 小停止、瞬停

**定期保全（ていきほぜん）**
- **意味**: カレンダー基準で定期的に実施する保全
- **関連用語**: 予防保全、TBM

**ドカ停（どかてい）**
- **意味**: 30分以上にわたる重大な設備停止
- **関連用語**: 大停止、長時間停止

### は行

**部門保全（ぶもんほぜん）**
- **意味**: 各製造部門が自部門の設備保全を担当する体制
- **関連用語**: 分散保全、現場保全

**保全性（ほぜんせい）**
- **意味**: 設備が保全しやすい度合い、修理のしやすさ
- **関連用語**: 信頼性、設計品質

**保全予防（ほぜんよぼう）**
- **意味**: 設備の設計・製作段階から保全を考慮し、保全が不要または容易な設備を目指す活動
- **関連用語**: MP設計、メンテナンスフリー

### や行

**予知保全（よちほぜん）**
- **意味**: 設備の状態を監視し、異常の兆候を検知して保全を実施する方式
- **関連用語**: 状態基準保全、CBM

**予防保全（よぼうほぜん）**
- **意味**: 故障が発生する前に計画的に保全を実施する方式
- **関連用語**: 計画保全、TBM

### ら行

**劣化（れっか）**
- **意味**: 時間経過や使用により設備の性能が低下すること
- **関連用語**: 摩耗、腐食、疲労

- **英語併記**: 国際的に使われる用語は英語も併記
