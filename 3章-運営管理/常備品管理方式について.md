# 常備品管理方式について

## 概要
常備品管理方式は、企業が原材料、部品、完成品などの在庫を適切に管理するための体系的な手法です。適切な在庫管理により、顧客サービスレベルの維持と在庫コストの最小化という相反する目標のバランスを取ることができます。在庫管理は、企業の運転資本管理、キャッシュフロー、顧客満足度に直接的な影響を与える重要な経営課題です。

## 1. 基本概念・仕組み

### 常備品管理の核となる概念
- **定義**: 常備品管理とは、需要に対応するために適切な量の在庫を適切なタイミングで保有し、補充する管理手法
- **動作原理**: 需要予測、発注点の設定、発注量の決定、リードタイムの管理を組み合わせて最適な在庫水準を維持
- **特徴**: 
  - 在庫切れリスクの最小化
  - 在庫保有コストの最適化
  - 資金効率の向上
  - 顧客サービスレベルの維持

### 在庫管理の基本要素
- **安全在庫**: 需要や供給の不確実性に対するバッファーとして保有する在庫
- **リードタイム**: 発注から納品までの所要時間
- **発注点**: 補充発注を行うタイミングを示す在庫水準
- **経済的発注量（EOQ）**: 発注コストと在庫保有コストの合計を最小化する発注量

## 2. 種類・分類

### 在庫管理方式の分類軸
在庫管理方式は、在庫の監視方法と発注タイミングによって大きく分類されます。

### 定量発注方式（継続的在庫管理方式）
**特徴:**
- 在庫量が発注点に達したら、常に一定量を発注
- 在庫を継続的に監視
- 発注量は毎回同じ（経済的発注量）

**算出方法:**
```
発注点 = 平均需要量 × リードタイム + 安全在庫
経済的発注量（EOQ）= √(2 × 年間需要量 × 発注費用 / 保管費用率)
```

**📊 具体的な計算例**
**例: 電子部品の在庫管理**
- 年間需要量: 12,000個
- 1回あたり発注費用: 3,000円
- 単価: 500円
- 年間保管費用率: 20%
- リードタイム: 5日
- 1日あたり平均需要: 40個
- 安全在庫: 100個

**ステップ1: 経済的発注量の計算**
```
EOQ = √(2 × 12,000 × 3,000 / (500 × 0.2))
    = √(72,000,000 / 100)
    = √720,000
    = 849個
```

**ステップ2: 発注点の計算**
```
発注点 = 40個/日 × 5日 + 100個
      = 200個 + 100個
      = 300個
```

**結果: 在庫が300個になったら849個を発注する**

💡 **実際の現場では**: バーコードやRFIDを使用して在庫をリアルタイムで監視し、自動発注システムと連携させることが一般的です。

### 定期発注方式（定期的在庫管理方式）
**特徴:**
- 一定期間ごとに在庫を確認し、目標在庫量まで補充
- 発注間隔は一定だが、発注量は変動
- 管理が簡便で、複数品目の同時発注が可能

**算出方法:**
```
発注量 = 目標在庫量 - 現在庫量 - 発注残
目標在庫量 = (発注間隔 + リードタイム) × 平均需要量 + 安全在庫
```

**📊 具体的な計算例**
**例: 事務用品の在庫管理**
- 発注間隔: 30日
- リードタイム: 5日
- 1日あたり平均需要: 10個
- 安全在庫: 50個
- 現在庫: 80個
- 発注残: 0個

**ステップ1: 目標在庫量の計算**
```
目標在庫量 = (30日 + 5日) × 10個/日 + 50個
          = 35日 × 10個/日 + 50個
          = 350個 + 50個
          = 400個
```

**ステップ2: 発注量の計算**
```
発注量 = 400個 - 80個 - 0個
      = 320個
```

**結果: 320個を発注する**

### ツービン方式（ダブルビン方式）
**特徴:**
- 2つの容器（ビン）を使用した視覚的な在庫管理
- 一方のビンが空になったら、もう一方を使用開始し、空のビンを補充
- 小物部品や低価値品の管理に適している

**運用方法:**
1. 各ビンに発注点相当の在庫を保管
2. 片方のビンから使用開始
3. 空になったら発注カードで補充依頼
4. もう一方のビンを使用している間に補充完了

### 発注点補充方式（Min-Max方式）
**特徴:**
- 最小在庫量（Min）と最大在庫量（Max）を設定
- 在庫がMin以下になったら、Maxまで補充
- 需要変動が大きい品目に適している

**算出方法:**
```
Min = リードタイム中の需要量 + 安全在庫
Max = Min + 経済的発注量
発注量 = Max - 現在庫量
```

## 3. 詳細仕様・パラメータ

### 重要なパラメータ群

#### 安全在庫の詳細
- **意味**: 需要や供給の不確実性に対応するための緩衝在庫
- **設定範囲**: 通常、リードタイム中の需要量の10-50%
- **影響**: 高すぎると在庫コスト増加、低すぎると欠品リスク増加
- **推奨値**: サービスレベル95%の場合、標準偏差の1.65倍

#### サービスレベルの詳細
- **意味**: 在庫切れを起こさない確率
- **設定範囲**: 90-99.9%（品目の重要度により設定）
- **影響**: 高いほど安全在庫が増加
- **推奨値**: 
  - Aランク品: 95-99%
  - Bランク品: 90-95%
  - Cランク品: 85-90%

#### リードタイムの詳細
- **意味**: 発注から納品までの所要時間
- **設定範囲**: 数時間から数ヶ月（品目・供給元により異なる）
- **影響**: 長いほど発注点が高くなり、在庫量が増加
- **推奨値**: 可能な限り短縮し、安定化を図る

## 4. 実装例・適用事例

### 基本実装（定量発注方式の例）
```python
class InventoryManagement:
    def __init__(self, annual_demand, ordering_cost, unit_cost, holding_rate, lead_time, safety_stock):
        self.annual_demand = annual_demand
        self.ordering_cost = ordering_cost
        self.unit_cost = unit_cost
        self.holding_rate = holding_rate
        self.lead_time = lead_time
        self.safety_stock = safety_stock
        
    def calculate_eoq(self):
        """経済的発注量の計算"""
        eoq = math.sqrt(
            (2 * self.annual_demand * self.ordering_cost) / 
            (self.unit_cost * self.holding_rate)
        )
        return round(eoq)
    
    def calculate_reorder_point(self):
        """発注点の計算"""
        daily_demand = self.annual_demand / 365
        reorder_point = (daily_demand * self.lead_time) + self.safety_stock
        return round(reorder_point)
    
    def check_inventory(self, current_stock):
        """在庫チェックと発注判定"""
        reorder_point = self.calculate_reorder_point()
        if current_stock <= reorder_point:
            return self.calculate_eoq()
        return 0
```

### 応用実装（ABC分析を組み合わせた管理）
```python
class ABCInventoryManagement:
    def __init__(self, items_data):
        self.items_data = items_data
        self.classify_items()
        
    def classify_items(self):
        """品目をABC分類"""
        # 年間使用金額で降順ソート
        sorted_items = sorted(
            self.items_data, 
            key=lambda x: x['annual_usage'] * x['unit_cost'], 
            reverse=True
        )
        
        total_value = sum(item['annual_usage'] * item['unit_cost'] 
                         for item in sorted_items)
        cumulative_value = 0
        
        for item in sorted_items:
            item_value = item['annual_usage'] * item['unit_cost']
            cumulative_value += item_value
            cumulative_percentage = cumulative_value / total_value * 100
            
            if cumulative_percentage <= 70:
                item['class'] = 'A'
            elif cumulative_percentage <= 90:
                item['class'] = 'B'
            else:
                item['class'] = 'C'
    
    def set_management_policy(self):
        """分類に応じた管理方針の設定"""
        policies = {
            'A': {'review_cycle': 'continuous', 'service_level': 0.98},
            'B': {'review_cycle': 'weekly', 'service_level': 0.95},
            'C': {'review_cycle': 'monthly', 'service_level': 0.90}
        }
        
        for item in self.items_data:
            item['policy'] = policies[item['class']]
```

### 実際の適用事例

#### 事例1: トヨタ自動車のかんばん方式
- **課題**: 過剰在庫の削減と生産効率の向上
- **適用方法**: プル型生産システムとして、後工程が必要な分だけ前工程から引き取る方式を採用
- **結果**: 在庫を最小限に抑えながら、欠品を防止
- **効果**: 在庫回転率が大幅に向上し、キャッシュフローが改善

#### 事例2: アマゾンの予測型在庫管理
- **課題**: 膨大な商品数と即日配送への対応
- **適用方法**: AIと機械学習を活用した需要予測と、地域別の分散在庫管理
- **結果**: 商品別・地域別の最適在庫配置を実現
- **効果**: 在庫切れ率を最小化しながら、配送時間を短縮

#### 事例3: セブンイレブンの単品管理
- **課題**: 限られた店舗スペースでの品揃えと鮮度管理
- **適用方法**: POSデータを活用した時間帯別・曜日別の需要予測と多頻度小口配送
- **結果**: 1日3回以上の配送により、常に新鮮な商品を提供
- **効果**: 廃棄ロスを削減しながら、機会損失を最小化

## 5. メリット・デメリット

### メリット

**1. 在庫コストの最適化**
- **理由**: 適切な発注量と発注タイミングにより、過剰在庫を防止
- **効果**: 保管コスト、資本コスト、陳腐化リスクの削減
- **具体例**: EOQの採用により、総在庫コストを20-30%削減可能

**2. 顧客サービスレベルの向上**
- **理由**: 安全在庫の適切な設定により、欠品を防止
- **効果**: 顧客満足度の向上、機会損失の削減
- **具体例**: サービスレベル95%の達成により、売上機会の確保

**3. キャッシュフローの改善**
- **理由**: 在庫回転率の向上により、運転資本を削減
- **効果**: 資金効率の向上、投資余力の創出
- **具体例**: 在庫回転率を年6回から12回に改善し、運転資本を50%削減

**4. 業務効率の向上**
- **理由**: システマティックな管理により、属人性を排除
- **効果**: 発注業務の標準化、ミスの削減
- **具体例**: 自動発注システムにより、発注業務時間を80%削減

### デメリット

**1. 初期投資コスト**
- **理由**: システム導入、教育、プロセス変更に費用が必要
- **影響**: 中小企業には負担が大きい
- **対策**: 段階的導入、クラウドサービスの活用

**2. 需要予測の困難性**
- **理由**: 市場環境の変化、季節変動、トレンドの影響
- **影響**: 予測精度が低いと、過剰在庫や欠品が発生
- **対策**: AIや機械学習の活用、予測精度の継続的改善

**3. 管理の複雑性**
- **理由**: 品目数が多い場合、パラメータ設定が煩雑
- **影響**: 管理工数の増加、ミスの可能性
- **対策**: ABC分析による重点管理、システム化の推進

**4. 柔軟性の欠如**
- **理由**: ルールベースの管理のため、例外対応が困難
- **影響**: 特殊な需要や緊急対応への遅れ
- **対策**: 例外処理ルールの設定、人的判断の併用

## 6. 選択・導入の指針

### 在庫管理方式の選択基準
| 観点 | 定量発注方式 | 定期発注方式 | ツービン方式 | Min-Max方式 |
|------|--------------|--------------|--------------|-------------|
| 管理精度 | ◎ | ○ | △ | ○ |
| 導入コスト | △ | ○ | ◎ | ○ |
| 運用の簡便性 | △ | ○ | ◎ | ○ |
| 適用品目数 | 少～中 | 中～多 | 少 | 中 |
| システム化必要性 | ◎ | ○ | × | △ |

### 適用判断フローチャート
1. **品目価値は高いか？** 
   - Yes → 定量発注方式を推奨
   - No → 次の判断へ

2. **需要は安定しているか？**
   - Yes → 定期発注方式を推奨
   - No → Min-Max方式を推奨

3. **品目数は少ないか？**
   - Yes → ツービン方式も検討可能
   - No → システム化を前提とした方式を選択

### 導入ステップ
1. **現状分析**: 在庫回転率、欠品率、在庫金額の把握
2. **ABC分析**: 重点管理品目の特定
3. **方式選定**: 品目特性に応じた管理方式の選択
4. **パラメータ設定**: EOQ、安全在庫、発注点の計算
5. **システム構築**: 在庫管理システムの導入・カスタマイズ
6. **運用開始**: 段階的導入と効果測定
7. **継続的改善**: KPIモニタリングとパラメータ調整

経済的発注量（EOQ）を計算する公式として正しいものはどれか？

- A) √(2 × 年間需要量 × 発注費用 / 保管費用)
- B) √(年間需要量 × 発注費用 × 保管費用)
- C) 2 × 年間需要量 × 発注費用 / 保管費用
- D) √(年間需要量 / (発注費用 × 保管費用))

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
EOQの公式は√(2 × 年間需要量 × 発注費用 / 保管費用)です。この公式により、発注コストと在庫保有コストの合計を最小化する発注量が求められます。<br>

Dが間違いの理由：分子と分母の関係が正しくありません
</details>

### 問題7
Min-Max方式において、発注を行うタイミングはいつか？

- A) 在庫が最大在庫量（Max）に達したとき

- D) 在庫がゼロになったとき

## 9. 専門用語集

このスライドで使用された専門用語について、アルファベット順・50音順で解説します。

### アルファベット

**ABC分析（ABC Analysis）**
- **読み方**: エービーシーぶんせき
- **意味**: 在庫品目を年間使用金額の大きさで分類し、重要度に応じて管理方法を変える手法。パレートの法則に基づく
- **関連用語**: パレート分析、重点管理

**EOQ（Economic Order Quantity）**
- **読み方**: イーオーキュー
- **意味**: 経済的発注量。発注コストと在庫保有コストの合計を最小化する最適な発注量
- **関連用語**: 最適発注量、ウィルソンの公式

**JIT（Just In Time）**
- **読み方**: ジャストインタイム
- **意味**: 必要なものを、必要な時に、必要な量だけ生産・調達する生産方式
- **関連用語**: トヨタ生産方式、リーン生産

**Min-Max方式（Min-Max System）**
- **読み方**: ミンマックスほうしき
- **意味**: 最小在庫量と最大在庫量を設定し、最小量以下になったら最大量まで補充する方式
- **関連用語**: 発注点補充方式

**RFID（Radio Frequency Identification）**
- **読み方**: アールエフアイディー
- **意味**: 電波を使って非接触でデータの読み書きを行う自動認識技術
- **関連用語**: ICタグ、電子タグ

**VMI（Vendor Managed Inventory）**
- **読み方**: ブイエムアイ
- **意味**: 供給業者が顧客の在庫を管理し、適切なタイミングで補充を行う方式
- **関連用語**: ベンダー管理在庫

### あ行

**安全在庫（あんぜんざいこ）**
- **意味**: 需要や供給の不確実性に対応するためのバッファーとして保有する在庫
- **関連用語**: バッファー在庫、予備在庫

### か行

**かんばん方式（かんばんほうしき）**
- **意味**: トヨタ生産方式の一部で、生産指示や部品の引き取りを「かんばん」と呼ばれるカードで管理する方式
- **関連用語**: プル型生産、後工程引き取り

**クロスドッキング（くろすどっきんぐ）**
- **意味**: 入荷した商品を保管せずに、仕分けして即座に出荷する物流手法
- **関連用語**: 通過型物流センター

**経済的発注量（けいざいてきはっちゅうりょう）**
- **意味**: 発注コストと在庫保有コストの合計を最小化する最適な発注量。EOQとも呼ばれる
- **関連用語**: EOQ、最適発注量

### さ行

**在庫回転率（ざいこかいてんりつ）**
- **意味**: 一定期間に在庫が何回転したかを示す指標。年間売上原価÷平均在庫で計算
- **関連用語**: 在庫回転日数、在庫効率

**サービスレベル（さーびすれべる）**
- **意味**: 在庫切れを起こさない確率。顧客の需要に対応できる割合
- **関連用語**: 充足率、欠品率

### た行

**定期発注方式（ていきはっちゅうほうしき）**
- **意味**: 一定期間ごとに在庫を確認し、目標在庫量まで補充する発注方式
- **関連用語**: 定期補充方式、サイクル補充

**定量発注方式（ていりょうはっちゅうほうしき）**
- **意味**: 在庫が発注点に達したら、一定量（通常EOQ）を発注する方式
- **関連用語**: 発注点方式、s-Q方式

**ツービン方式（つーびんほうしき）**
- **意味**: 2つの容器を使用し、片方が空になったらもう一方を使用しながら補充する視覚的な在庫管理方式
- **関連用語**: ダブルビン方式、2ビン方式

### は行

**発注点（はっちゅうてん）**
- **意味**: 補充発注を行うべき在庫水準。リードタイム中の需要量に安全在庫を加えた量
- **関連用語**: 発注水準、再発注点

**ブルウィップ効果（ぶるうぃっぷこうか）**
- **意味**: サプライチェーンの川上に行くほど需要変動が増幅される現象
- **関連用語**: 需要増幅、情報の歪み

### ま行

**見込み生産（みこみせいさん）**
- **意味**: 需要予測に基づいて事前に生産し、在庫として保有する生産方式
- **関連用語**: MTS（Make to Stock）

### ら行

**リードタイム（りーどたいむ）**
- **意味**: 発注から納品までの所要時間。調達リードタイムとも呼ばれる
- **関連用語**: 調達期間、納期
