# 物流機能について

## 概要

物流機能とは、生産地から消費地へ商品を移動させる過程で必要となる一連の活動を指します。単に商品を運ぶだけでなく、保管、包装、流通加工、情報処理など多岐にわたる機能を含みます。現代のビジネスにおいて、物流は「第三の利益源」と呼ばれ、企業の競争力を左右する重要な要素となっています。

## 1. 輸配送（Transportation and Delivery）

### 輸送と配送の違い

#### 輸送
- **定義**: 工場や物流センター間など、拠点間の長距離・大量の物品移動
- **特徴**: 
  - 大型トラックや鉄道、船舶、航空機を使用
  - パレット単位やコンテナ単位での移動
  - 定期的な運行スケジュール

#### 配送
- **定義**: 物流センターから最終顧客への短距離・小口の物品移動
- **特徴**: 
  - 小型トラックやバンを使用
  - ケース単位や個別単位での移動
  - 顧客の要望に応じた柔軟な対応

### 輸配送の手段と特徴

| 輸送手段 | 特徴 | 適用場面 | コスト |
|---------|------|---------|--------|
| トラック輸送 | 柔軟性が高い、Door to Door可能 | 国内輸送全般 | 中 |
| 鉄道輸送 | 大量輸送、定時性高い、環境負荷低い | 長距離・大量輸送 | 低 |
| 海上輸送 | 超大量輸送、国際輸送の主力 | 国際貿易、原材料輸送 | 最低 |
| 航空輸送 | 高速、確実性高い | 高付加価値品、緊急品 | 最高 |

### 輸配送の最適化手法

#### 1. 積載率の向上
**具体例: ある運送会社の改善事例**
- **改善前**: トラック積載率60%、月間輸送コスト500万円
- **改善策**: 
  - 配送ルートの見直し
  - 混載の推進
  - 積み付け方法の改善
- **改善後**: トラック積載率85%、月間輸送コスト350万円（30%削減）

#### 2. モーダルシフト
環境負荷の低い輸送手段への転換を指します。

**計算例: CO2排出量の比較**
東京→大阪間（500km）で10トンの貨物を輸送する場合：
- トラック輸送: 500km × 0.17kg-CO2/トンキロ × 10トン = 850kg-CO2
- 鉄道輸送: 500km × 0.025kg-CO2/トンキロ × 10トン = 125kg-CO2
- **削減効果**: 725kg-CO2（85.3%削減）

## 2. 保管（Storage）

### 保管の目的と機能

#### 主要な目的
1. **需給調整機能**: 生産と消費の時間的ギャップを調整
2. **品質保持機能**: 商品の品質を維持・管理
3. **在庫バッファ機能**: 需要変動への対応

### 保管施設の種類

#### 営業倉庫の分類
| 倉庫種別 | 保管対象 | 設備特徴 | 具体例 |
|---------|---------|---------|--------|
| 普通倉庫 | 一般貨物 | 標準的な設備 | 家電、衣料品 |
| 冷蔵倉庫 | 冷蔵・冷凍品 | 温度管理設備 | 食品、医薬品 |
| 危険品倉庫 | 危険物 | 防火・防爆設備 | 化学品、燃料 |
| サイロ | バラ貨物 | 縦型円筒構造 | 穀物、セメント |

### 保管コストの計算

**例: 月間保管コストの算出**
```
基本情報：
- 倉庫面積: 1,000㎡
- 保管料単価: 3,000円/㎡・月
- 平均在庫量: 800パレット
- 入出庫頻度: 月200回

月間保管コスト = 固定費 + 変動費
固定費 = 1,000㎡ × 3,000円 = 300万円
変動費（入出庫料）= 200回 × 1,500円/回 = 30万円
合計 = 330万円/月
```

### 在庫管理手法

#### ABC分析による重点管理
**具体例: ある小売店の在庫管理**
- **A品目（売上の70%）**: 全品目の20% → 毎日在庫確認
- **B品目（売上の20%）**: 全品目の30% → 週1回在庫確認
- **C品目（売上の10%）**: 全品目の50% → 月1回在庫確認

## 3. 荷役（Cargo Handling）

### 荷役作業の種類

#### 基本的な荷役作業

2. **運搬**: 倉庫内での貨物の移動
3. **仕分け**: 配送先別、品目別の分類作業
4. **ピッキング**: オーダーに応じた商品の取り出し

| 自動倉庫 | 大量・高頻度の入出庫 | 最高 | 最高 |
| コンベア | 連続的な貨物移動 | 高 | 高 |

### 荷役作業の効率化

## 5. 流通加工（Distribution Processing）

### 流通加工の定義と目的

流通加工とは、物流過程において商品に付加価値を与える加工作業を指します。生産における加工とは異なり、顧客ニーズに応じた最終調整を行います。

### 主な流通加工の種類

#### 1. 物理的加工
- **切断・分割**: ロール紙の裁断、鋼材の切断
- **組立・セット**: ギフトセット、アソート商品
- **小分け・詰替え**: 業務用から家庭用への再包装

#### 2. 表示・情報付加
- **ラベル貼付**: 価格ラベル、バーコード
- **検品・検査**: 品質チェック、数量確認
- **情報登録**: 製品情報のデータベース登録

### 流通加工の効果測定

**具体例: アパレル物流センターでの値札付け作業**
```
店舗での作業の場合：
- 作業時間: 1枚当たり30秒
- 人件費: 1,200円/時間
- 1日処理量: 960枚（8時間）
- コスト: 1枚当たり10円

物流センターでの集約作業：
- 作業時間: 1枚当たり10秒（専用機器使用）
- 人件費: 1,000円/時間
- 1日処理量: 2,880枚（8時間）
- コスト: 1枚当たり2.8円

削減効果: 72%のコスト削減
```

## 6. 在庫管理（Inventory Management）

### 在庫管理の目的と重要性

在庫管理は、必要な商品を、必要な時に、必要な量だけ供給できるよう、在庫水準を適切にコントロールする活動です。

### 在庫管理手法

#### 1. 定量発注方式
**計算例**
```
基本データ：
- 年間需要量(D): 12,000個
- 1回当たり発注費用(S): 3,000円
- 在庫維持費率(h): 20%/年
- 単価(C): 500円

経済的発注量(EOQ) = √(2DS/hC)
EOQ = √(2 × 12,000 × 3,000 / (0.2 × 500))
    = √(72,000,000 / 100)
    = √720,000
    = 849個

発注回数 = 12,000 / 849 = 14.1回/年
```

#### 2. 定期発注方式
**適用例: コンビニエンスストアの発注**
- 発注間隔: 毎日（パン、弁当）、週2回（飲料）、週1回（雑貨）
- 発注量: (発注間隔+リードタイム)中の予想需要量 - 現在庫量

### 在庫回転率の改善

**改善事例**
```
改善前：
- 平均在庫: 5,000万円
- 年間売上原価: 6億円
- 在庫回転率: 12回/年

改善施策：
1. 需要予測精度の向上
2. リードタイムの短縮
3. 小ロット多頻度配送

改善後：
- 平均在庫: 3,000万円（40%削減）
- 年間売上原価: 6億円（変わらず）
- 在庫回転率: 20回/年
- 在庫削減効果: 2,000万円の資金効率改善
```

#### 3. 物流拠点数 vs 配送効率
**拠点集約のシミュレーション**
```
現状: 全国10拠点
- 拠点費用: 10拠点 × 2,000万円 = 2億円
```

- 目的関数: 総物流コストの最小化

## 9. よくある質問（Q&A）

### Q1. 3PL（サードパーティ・ロジスティクス）と自社物流のどちらを選ぶべきですか？

**A1.** 企業の規模、物流の複雑性、コア・コンピタンスによって判断すべきです。

#### 3PLが適している場合
- 物流量の変動が大きい
- 物流がコア事業でない
- 初期投資を抑えたい
- 専門的なノウハウが必要

#### 自社物流が適している場合
- 特殊な商品特性がある
- 高度な品質管理が必要
- 物流が競争優位の源泉
- 十分な物流量がある

**コスト比較例**
```
年間物流量: 10万個
3PL利用: 500円/個 × 10万個 = 5,000万円/年
自社物流: 初期投資2億円 + 運営費3,000万円/年
損益分岐点: 2億円 ÷ (5,000万円 - 3,000万円) = 10年
```

### Q2. 在庫を削減しすぎると欠品リスクが高まりますが、どうバランスを取るべきですか？

**A2.** 商品特性に応じた在庫戦略の使い分けが重要です。

#### ABC-XYZ分析による在庫戦略
```
AX品目（売上高・需要安定）: 
- 在庫回転率重視
- 安全在庫最小化
- 例: 定番商品

CZ品目（売上低・需要不安定）:
- 在庫リスク回避
- 受注生産検討
- 例: 特注品

適正在庫 = 基準在庫 + 安全在庫
安全在庫 = 安全係数 × √リードタイム × 需要の標準偏差
```

## 12. 専門用語集

### アルファベット

**3PL (Third Party Logistics)**
- **読み方**: サードパーティー・ロジスティクス
- **意味**: 荷主企業に代わって、物流業務を包括的に受託し、効率的な物流システムを構築・運営する事業者。単なる運送・保管の受託を超えて、物流戦略の立案から実行までを担う。
- **関連用語**: 4PL、物流アウトソーシング

**ABC分析**
- **読み方**: エービーシーぶんせき
- **意味**: 在庫品目を売上高や出荷頻度などの重要度によってA、B、Cの3つのグループに分類し、重点管理を行う手法。パレートの法則に基づく。
- **関連用語**: パレート分析、重点管理

**EDI (Electronic Data Interchange)**
- **読み方**: イーディーアイ
- **意味**: 企業間で受発注や請求などの取引データを、標準化された形式で電子的に交換するシステム。手作業によるミスを削減し、処理速度を向上させる。
- **関連用語**: 電子商取引、B2B

**EOQ (Economic Order Quantity)**
- **読み方**: イーオーキュー、経済的発注量
- **意味**: 発注費用と在庫維持費用の合計を最小化する最適な発注量。ウィルソンの公式により算出される。
- **関連用語**: 最適発注量、在庫管理

**OMS (Order Management System)**
- **読み方**: オーエムエス、受注管理システム
- **意味**: 受注から出荷までの一連のプロセスを管理するシステム。在庫引当、出荷指示、請求処理などを統合的に管理する。
- **関連用語**: 受発注システム、販売管理

**TMS (Transportation Management System)**
- **読み方**: ティーエムエス、輸配送管理システム
- **意味**: 輸配送業務を効率化するためのシステム。配車計画、ルート最適化、運賃計算、車両追跡などの機能を持つ。
- **関連用語**: 配送管理、運行管理

**WMS (Warehouse Management System)**
- **読み方**: ダブリューエムエス、倉庫管理システム
- **意味**: 倉庫内の在庫管理、入出庫管理、ロケーション管理、作業指示などを行うシステム。作業の効率化と在庫精度の向上を実現する。
- **関連用語**: 在庫管理システム、倉庫管理

### あ行

**安全在庫（あんぜんざいこ）**
- **意味**: 需要変動や納期遅延などの不確実性に対応するために保有する在庫。サービスレベルを維持するためのバッファとして機能する。
- **関連用語**: バッファ在庫、サービスレベル

### か行

**荷役（かやく）**
- **意味**: 貨物の積み込み、積み卸し、運搬、仕分けなど、物流拠点内で行われる貨物の取り扱い作業全般。物流コストの大きな部分を占める。
- **関連用語**: マテハン、貨物取扱い

**共同配送（きょうどうはいそう）**
- **意味**: 複数の荷主の貨物を集約して配送する方式。積載率の向上とコスト削減を実現する。
- **関連用語**: 混載、共同物流

### さ行

**在庫回転率（ざいこかいてんりつ）**
- **意味**: 一定期間に在庫が何回転したかを示す指標。年間売上原価を平均在庫金額で除して算出。資金効率を測る重要な指標。
- **関連用語**: 在庫回転日数、棚卸資産回転率

**サプライチェーン**
- **意味**: 原材料の調達から最終消費者への商品提供まで、供給に関わる一連の流れ。複数の企業が連携して価値を創造する。
- **関連用語**: SCM、バリューチェーン

### た行

**定期発注方式（ていきはっちゅうほうしき）**
- **意味**: あらかじめ決められた一定の間隔で発注を行う在庫管理方式。発注量は在庫状況により変動する。
- **関連用語**: 定量発注方式、発注点方式

**定量発注方式（ていりょうはっちゅうほうしき）**
- **意味**: 在庫が一定量（発注点）まで減少したときに、あらかじめ決められた一定量を発注する方式。
- **関連用語**: 発注点、定期発注方式

**トレーサビリティ**
- **意味**: 商品の生産から消費までの流通経路を追跡可能にする仕組み。食品安全や品質保証のために重要。
- **関連用語**: 追跡可能性、履歴管理

### な行

**荷主（にぬし）**
- **意味**: 物流サービスを利用する側の企業。貨物の所有者として、物流業者に輸送や保管を委託する。
- **関連用語**: 発荷主、着荷主

### は行

**配送センター（はいそうセンター）**
- **意味**: 商品を一時保管し、顧客への配送を行う物流拠点。在庫機能と仕分け機能を持つ。
- **関連用語**: DC、物流センター

**パレット**
- **意味**: 貨物を載せて、フォークリフトなどで荷役作業を行うための台。標準化により物流効率が向上する。
- **関連用語**: パレタイズ、ユニットロード

**物流コスト（ぶつりゅうコスト）**
- **意味**: 輸送費、保管費、荷役費、包装費、情報処理費など、物流活動に関わるすべての費用。売上高の5-15%を占めることが多い。
- **関連用語**: ロジスティクスコスト、物流費

### ま行

**マテリアルハンドリング**
- **意味**: 倉庫や工場内での原材料、仕掛品、製品の移動・取り扱い。略してマテハンとも呼ばれる。
- **関連用語**: 荷役、構内物流

**ミルクラン**
- **意味**: 一台のトラックが複数の仕入先を巡回して集荷する方式。牛乳配達のルートに由来する。
- **関連用語**: 巡回集荷、共同集荷

**モーダルシフト**
- **意味**: トラック輸送から鉄道や船舶など、より環境負荷の低い輸送手段への転換。CO2削減の重要な施策。
- **関連用語**: 複合一貫輸送、インターモーダル

### や行

**輸送密度（ゆそうみつど）**
- **意味**: 輸送手段の積載能力に対する実際の積載量の割合。積載率とも呼ばれ、輸送効率の指標となる。
- **関連用語**: 積載率、実車率

### ら行

**リードタイム**
- **意味**: 発注から納品までの所要時間。短縮により在庫削減と顧客満足度向上が可能。
- **関連用語**: 納期、調達期間

**流通加工（りゅうつうかこう）**
- **意味**: 物流過程において商品に付加価値を与える加工作業。値札付け、セット組み、小分けなどが含まれる。
- **関連用語**: 物流加工、付加価値サービス

**ロジスティクス**
- **意味**: 物流を戦略的に管理し、原材料調達から最終消費まで効率的な物の流れを実現する活動。単なる物流を超えた概念。
- **関連用語**: 物流管理、SCM
