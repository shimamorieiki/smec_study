# 生産管理の指標について

## 概要
生産管理の指標は、製造業やサービス業において生産活動の効率性、品質、安全性を定量的に評価するための重要なツールです。これらの指標を適切に活用することで、生産プロセスの改善点を特定し、継続的な改善活動（カイゼン）を推進することができます。本資料では、生産性、歩留まり、直行率、労働災害に関する指標（度数率、年千人率、強度率）、そしてPQCDSMEという包括的な管理指標について詳しく解説します。

## 1. 生産管理指標の基本概念・仕組み

### 生産管理指標の役割
- **定義**: 生産活動の効率性、品質、安全性を数値化して評価・管理するための指標体系
- **動作原理**: 実績データを収集し、計算式に基づいて指標値を算出、目標値と比較して改善活動につなげる
- **特徴**: 客観的な評価、時系列での比較可能性、部門間・企業間のベンチマーク可能性

### 指標管理の重要性
- **従来の経験・勘による管理との違い**: 数値に基づく客観的な判断が可能
- **改善点**: 問題の早期発見、改善効果の定量的把握、目標設定の明確化
- **限界**: 数値化できない要素の見落とし、過度な数値管理による弊害

## 2. 各指標の詳細

### 生産性
**特徴:**
- 投入資源に対する産出量の比率を表す指標
- 労働生産性、設備生産性、資本生産性などの種類がある
- 企業の競争力を示す最も基本的な指標

**算出方法:**
```
生産性 = アウトプット ÷ インプット

労働生産性 = 生産量（または付加価値額）÷ 労働投入量（人数または労働時間）
設備生産性 = 生産量 ÷ 設備稼働時間
資本生産性 = 付加価値額 ÷ 投下資本
```

**📊 具体的な計算例**
**例: A工場の労働生産性計算**
- 月間生産量: 10,000個
- 従業員数: 50人
- 月間労働時間: 8,000時間（50人×160時間/人）

**ステップ1: 人数ベースの労働生産性**
```
労働生産性（人数ベース）= 10,000個 ÷ 50人 = 200個/人
```

**ステップ2: 時間ベースの労働生産性**
```
労働生産性（時間ベース）= 10,000個 ÷ 8,000時間 = 1.25個/時間
```

**結果: 1人あたり月200個、1時間あたり1.25個の生産性**

💡 **実際の現場では**: 付加価値額ベースの生産性も重要。単純な生産個数だけでなく、製品の価値も考慮する必要がある。

### 歩留まり（歩留まり率）
**特徴:**
- 投入原材料に対する良品産出量の比率
- 材料の無駄を評価する重要指標
- プロセスの安定性を示す指標でもある

**算出方法:**
```
歩留まり率（%）= （良品数量 ÷ 投入数量）× 100
```

**📊 具体的な計算例**
**例: 半導体製造工程の歩留まり計算**
- 投入ウェハー数: 1,000枚
- 良品チップ数: 850枚

**計算:**
```
歩留まり率 = （850枚 ÷ 1,000枚）× 100 = 85%
```

**多工程の歩留まり計算例:**
- 工程A歩留まり: 95%
- 工程B歩留まり: 90%
- 工程C歩留まり: 98%

**総合歩留まり:**
```
総合歩留まり = 0.95 × 0.90 × 0.98 = 0.838 = 83.8%
```

💡 **実際の現場では**: 工程別の歩留まりを管理し、ボトルネック工程を特定することが重要。

### 直行率（First Pass Yield: FPY）
**特徴:**
- 手直しや再作業なしに一発で合格する製品の割合
- 工程の品質レベルを示す重要指標
- 隠れたコストを可視化する指標

**算出方法:**
```
直行率（%）= （一発合格数 ÷ 投入数）× 100
```

**📊 具体的な計算例**
**例: 組立工程の直行率計算**
- 投入数: 500個
- 一発合格数: 450個
- 手直し後合格数: 40個
- 不良品: 10個

**計算:**
```
直行率 = （450個 ÷ 500個）× 100 = 90%
歩留まり率 = （490個 ÷ 500個）× 100 = 98%
```

**結果: 直行率90%、歩留まり98%**

💡 **実際の現場では**: 歩留まりは高くても直行率が低い場合、手直しコストが発生している。直行率の改善が重要。

### 度数率
**特徴:**
- 労働災害の発生頻度を示す指標
- 100万延実労働時間あたりの労働災害死傷者数
- 安全管理の基本指標

**算出方法:**
```
度数率 = （労働災害による死傷者数 ÷ 延実労働時間数）× 1,000,000
```

**📊 具体的な計算例**
**例: B工場の年間度数率計算**
- 年間労働災害死傷者数: 3人
- 従業員数: 200人
- 年間労働日数: 250日
- 1日の労働時間: 8時間

**ステップ1: 延実労働時間数の計算**
```
延実労働時間数 = 200人 × 250日 × 8時間 = 400,000時間
```

**ステップ2: 独率の計算**
```
度数率 = （3人 ÷ 400,000時間）× 1,000,000 = 7.5
```

**結果: 度数率7.5（100万時間あたり7.5人の災害発生）**

💡 **実際の現場では**: 業種別の平均値と比較し、自社の安全レベルを評価する。

### 年千人率
**特徴:**
- 労働者1,000人あたりの年間労働災害死傷者数
- 度数率とは異なる観点から災害発生状況を評価
- 企業規模に関係なく比較可能

**算出方法:**
```
年千人率 = （年間労働災害死傷者数 ÷ 平均労働者数）× 1,000
```

**📊 具体的な計算例**
**例: C工場の年千人率計算**
- 年間労働災害死傷者数: 4人
- 平均労働者数: 300人

**計算:**
```
年千人率 = （4人 ÷ 300人）× 1,000 = 13.3
```

**結果: 年千人率13.3（1,000人あたり年間13.3人の災害発生）**

💡 **実際の現場では**: 労働時間の長短に関係なく災害発生状況を把握できるため、パートタイム労働者が多い職場でも有効。

### 強度率
**特徴:**
- 労働災害の重篤度を示す指標
- 1,000延実労働時間あたりの労働損失日数
- 災害の深刻さを定量的に評価

**算出方法:**
```
強度率 = （延労働損失日数 ÷ 延実労働時間数）× 1,000
```

**労働損失日数の基準:**
- 死亡: 7,500日
- 永久全労働不能: 7,500日
- 永久一部労働不能: 身体障害等級に応じた日数
- 一時労働不能: 実休業日数

**📊 具体的な計算例**
**例: D工場の強度率計算**
- 休業4日の災害: 2件（損失日数8日）
- 休業30日の災害: 1件（損失日数30日）
- 延実労働時間数: 400,000時間

**ステップ1: 延労働損失日数の計算**
```
延労働損失日数 = 8日 + 30日 = 38日
```

**ステップ2: 強度率の計算**
```
強度率 = （38日 ÷ 400,000時間）× 1,000 = 0.095
```

**結果: 強度率0.095**

💡 **実際の現場では**: 度数率が低くても強度率が高い場合は、重大災害が発生している可能性がある。

### PQCDSME
**特徴:**
- 生産管理の総合的な評価指標群
- 各要素をバランスよく管理することが重要
- 企業の競争力を多面的に評価

**各要素の詳細:**
- **P (Productivity)**: 生産性 - 効率的な資源活用
- **Q (Quality)**: 品質 - 顧客要求を満たす製品・サービス
- **C (Cost)**: コスト - 競争力のある価格設定
- **D (Delivery)**: 納期 - 約束した期日での納品
- **S (Safety)**: 安全 - 労働災害の防止
- **M (Morale)**: 士気 - 従業員のやる気・満足度
- **E (Environment)**: 環境 - 環境負荷の低減

**📊 PQCDSME評価の実例**
**例: E工場の月次PQCDSME評価**

| 項目 | 目標値 | 実績値 | 達成率 | 評価 |
|------|--------|--------|--------|------|
| P: 労働生産性 | 100個/人 | 95個/人 | 95% | △ |
| Q: 不良率 | 1%以下 | 0.8% | 120% | ◎ |
| C: 原価率 | 70%以下 | 72% | 97% | ○ |
| D: 納期遵守率 | 98%以上 | 99% | 101% | ◎ |
| S: 度数率 | 5.0以下 | 3.2 | 156% | ◎ |
| M: 従業員満足度 | 80点以上 | 75点 | 94% | △ |
| E: CO2排出量 | 100t以下 | 95t | 105% | ○ |

💡 **実際の現場では**: レーダーチャートで可視化し、弱点を特定して改善活動を展開する。

## 3. 指標の活用方法

### 指標管理のPDCAサイクル
1. **Plan（計画）**
   - 目標値の設定
   - データ収集方法の決定
   - 評価頻度の設定

2. **Do（実行）**
   - データの収集
   - 指標の算出
   - 現場へのフィードバック

3. **Check（評価）**
   - 目標値との比較
   - トレンド分析
   - 異常値の検出

4. **Act（改善）**
   - 改善策の立案
   - 改善活動の実施
   - 効果の検証

### ベンチマーキング
- **社内ベンチマーク**: 部門間、工場間での比較
- **業界ベンチマーク**: 同業他社との比較
- **ベストプラクティス**: 優良企業の事例研究

## 4. メリット・デメリット

### メリット
**1. 客観的な評価が可能**
- **理由**: 数値化により主観を排除
- **効果**: 公平な評価、説得力のある改善提案
- **具体例**: 生産性向上の効果を数値で証明

**2. 改善効果の可視化**
- **理由**: 時系列でのデータ比較が可能
- **効果**: モチベーション向上、改善活動の継続
- **具体例**: 歩留まり改善による原価低減効果の把握

**3. 問題の早期発見**
- **理由**: 異常値の迅速な検出
- **効果**: 大きな損失の回避、迅速な対応
- **具体例**: 直行率低下による品質問題の早期発見

### デメリット
**1. 数値化できない要素の軽視**
- **理由**: 測定困難な要素が評価から漏れる
- **影響**: 組織文化、ノウハウの軽視
- **対策**: 定性的評価との併用

**2. 過度な数値管理による弊害**
- **理由**: 数値目標の達成が目的化
- **影響**: 創造性の低下、短期的視点の蔓延
- **対策**: バランスの取れた目標設定

**3. データ収集・管理コスト**
- **理由**: システム構築、人員配置が必要
- **影響**: 中小企業での導入障壁
- **対策**: 重要指標に絞った段階的導入

## 7. 理解度確認クイズ（4択問題20問）

### 問題1
労働生産性を計算する際の正しい式はどれか？

- A) 生産量 × 労働投入量
- B) 生産量 ÷ 労働投入量
- C) 労働投入量 ÷ 生産量
- D) 生産量 + 労働投入量

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
労働生産性は「アウトプット÷インプット」の考え方に基づき、生産量を労働投入量で割ることで算出します。<br>
<br>
Aが間違いの理由：掛け算では生産性を表現できません<br>
Cが間違いの理由：分子と分母が逆で、これは労働投入原単位を表します<br>
Dが間違いの理由：足し算では比率を表現できません
</details>

### 問題2
歩留まり率が90%、直行率が80%の工程がある。この状況の解釈として正しいものはどれか？

- A) 不良品が20%発生している
- B) 手直しにより10%の製品が良品になっている
- C) 最終的に10%が廃棄されている
- D) 80%の製品は問題なく生産されている

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
歩留まり率90%は最終的に90%が良品、直行率80%は80%が一発合格を意味します。差の10%は手直しにより良品になった製品です。<br>
<br>
Aが間違いの理由：不良品は10%（100%-90%）です<br>
Cが間違いの理由：廃棄率は10%ですが、問題文の主旨とは異なります<br>
Dが間違いの理由：一発合格は80%ですが、最終良品率は90%です
</details>

### 問題3
ある工場で年間労働災害死傷者数が5人、平均労働者数が500人の場合、年千人率はいくらか？

- A) 1.0
- B) 5.0
- C) 10.0
- D) 100.0

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
年千人率 = (年間労働災害死傷者数 ÷ 平均労働者数) × 1,000<br>
= (5 ÷ 500) × 1,000 = 10.0<br>
<br>
Aが間違いの理由：計算を間違えています（0.01×1,000=10）<br>
Bが間違いの理由：1,000を掛け忘れています<br>
Dが間違いの理由：計算を間違えています（10倍多い）
</details>

### 問題7
工程Aの歩留まりが95%、工程Bの歩留まりが90%の場合、2工程を通しての総合歩留まりはいくらか？

- A) 92.5%
- B) 85.5%
- C) 90.0%
- D) 95.0%

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
総合歩留まり = 0.95 × 0.90 = 0.855 = 85.5%<br>
複数工程の歩留まりは、各工程の歩留まりを掛け合わせて算出します。<br>
<br>
Aが間違いの理由：平均値（(95+90)/2）ではありません<br>
Cが間違いの理由：工程Bの歩留まりのみを採用した誤りです<br>
Dが間違いの理由：工程Aの歩留まりのみを採用した誤りです
</details>

### 問題8
生産性向上の方法として適切でないものはどれか？

- A) 自動化設備の導入
- B) 作業の標準化
- C) 在庫の増加
- D) 多能工化の推進

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
在庫の増加は資本効率を悪化させ、生産性向上には寄与しません。むしろ在庫削減が生産性向上につながります。<br>
<br>
Aが間違いの理由：自動化は労働生産性向上の有効な手段です<br>
Bが間違いの理由：標準化により作業効率が向上します<br>
Dが間違いの理由：多能工化により柔軟な人員配置が可能になります
</details>

### 問題9
度数率が10.0の意味として正しいものはどれか？

- A) 10人に1人が労働災害に遭っている
- B) 100万時間あたり10人が労働災害に遭っている
- C) 1,000時間あたり10人が労働災害に遭っている
- D) 年間10人が労働災害に遭っている

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
度数率は100万延実労働時間あたりの労働災害死傷者数を表す指標です。<br>
<br>

## 8. 専門用語集

このスライドで使用された専門用語について、50音順で解説します。

### あ行
**異常値（いじょうち）**
- **読み方**: いじょうち
- **意味**: 通常の範囲から大きく外れた測定値や指標値。統計的に設定した管理限界を超えた値
- **関連用語**: 管理限界、管理図、外れ値

**一発合格（いっぱつごうかく）**
- **読み方**: いっぱつごうかく
- **意味**: 製品が手直しや再作業なしに、最初の検査で合格すること
- **関連用語**: 直行率、手直し、再作業

**延実労働時間（えんじつろうどうじかん）**
- **読み方**: えんじつろうどうじかん
- **意味**: 全従業員が実際に労働した時間の合計。残業時間を含むが休憩時間は除く
- **関連用語**: 度数率、強度率、労働時間

### か行
**改善活動（かいぜんかつどう）**
- **読み方**: かいぜんかつどう
- **意味**: 生産性、品質、安全性などを向上させるための継続的な取り組み
- **関連用語**: カイゼン、PDCA、QCサークル

**管理指標（かんりしひょう）**
- **読み方**: かんりしひょう
- **意味**: 経営や生産活動を数値化して管理するための指標
- **関連用語**: KPI、生産管理指標、評価指標

**強度率（きょうどりつ）**
- **読み方**: きょうどりつ
- **意味**: 1,000延実労働時間あたりの労働損失日数。労働災害の重篤度を示す指標
- **関連用語**: 度数率、労働損失日数、労働災害

### さ行
**歳出生産性（さいしゅつせいさんせい）**
- **読み方**: さいしゅつせいさんせい
- **意味**: 誤記。正しくは「産出生産性」または単に「生産性」
- **関連用語**: 生産性、労働生産性

**士気（しき）**
- **読み方**: しき
- **意味**: 従業員のやる気、モチベーション、職場の雰囲気
- **関連用語**: モラール、従業員満足度、PQCDSME

**手直し（てなおし）**
- **読み方**: てなおし
- **意味**: 不良品や不合格品を修正して良品にする作業
- **関連用語**: 再作業、リワーク、直行率

**生産性（せいさんせい）**
- **読み方**: せいさんせい
- **意味**: 投入した資源（インプット）に対する産出（アウトプット）の比率
- **関連用語**: 労働生産性、設備生産性、資本生産性

### た行
**直行率（ちょっこうりつ）**
- **読み方**: ちょっこうりつ
- **意味**: 手直しや再作業なしに一発で合格する製品の割合。First Pass Yield (FPY)
- **関連用語**: 一発合格、歩留まり、品質

**度数率（どすうりつ）**
- **読み方**: どすうりつ
- **意味**: 100万延実労働時間あたりの労働災害による死傷者数
- **関連用語**: 労働災害、強度率、年千人率

### な行
**年千人率（ねんせんにんりつ）**
- **読み方**: ねんせんにんりつ
- **意味**: 労働者1,000人あたりの年間労働災害死傷者数
- **関連用語**: 度数率、労働災害、安全管理

### は行
**歩留まり（ぶどまり）**
- **読み方**: ぶどまり
- **意味**: 投入した原材料や部品に対する良品の割合。歩留まり率とも言う
- **関連用語**: 良品率、不良率、歩留まり率

**付加価値（ふかかち）**
- **読み方**: ふかかち
- **意味**: 企業が生産活動によって新たに生み出した価値。売上高から原材料費などを差し引いた額
- **関連用語**: 付加価値額、労働生産性、粗利益

### ま行
**モラール（もらーる）**
- **読み方**: もらーる
- **意味**: 英語のMoraleから。従業員の士気、意欲、職場の雰囲気
- **関連用語**: 士気、従業員満足度、PQCDSME

### ら行
**労働災害（ろうどうさいがい）**
- **読み方**: ろうどうさいがい
- **意味**: 労働者が業務に起因して負傷、疾病、死亡すること
- **関連用語**: 労災、度数率、強度率、年千人率

**労働生産性（ろうどうせいさんせい）**
- **読み方**: ろうどうせいさんせい
- **意味**: 労働投入量に対する生産量または付加価値額の比率
- **関連用語**: 生産性、人時生産性、付加価値生産性

**労働損失日数（ろうどうそんしつにっすう）**
- **読み方**: ろうどうそんしつにっすう
- **意味**: 労働災害により失われた労働日数。死亡は7,500日として計算
- **関連用語**: 強度率、労働災害、休業日数

### アルファベット
**FPY (First Pass Yield)**
- **読み方**: エフピーワイ、ファーストパスイールド
- **意味**: 直行率。最初の工程や検査で合格する製品の割合
- **関連用語**: 直行率、一発合格率

**KPI (Key Performance Indicator)**
- **読み方**: ケーピーアイ
- **意味**: 重要業績評価指標。目標達成度を測る重要な指標
- **関連用語**: 管理指標、評価指標

**PDCA**
- **読み方**: ピーディーシーエー
- **意味**: Plan-Do-Check-Actの略。計画・実行・評価・改善のサイクル
- **関連用語**: 改善活動、管理サイクル

**PQCDSME**
- **読み方**: ピーキューシーディーエスエムイー
- **意味**: Productivity, Quality, Cost, Delivery, Safety, Morale, Environmentの頭文字。生産管理の総合指標
- **関連用語**: 生産管理指標、総合評価

**QC (Quality Control)**
- **読み方**: キューシー
- **意味**: 品質管理。製品やサービスの品質を維持・向上させる活動
- **関連用語**: 品質、QCサークル、品質管理

**SDGs (Sustainable Development Goals)**
- **読み方**: エスディージーズ
- **意味**: 持続可能な開発目標。国連が定めた17の国際目標
- **関連用語**: 環境、サステナビリティ、CSR
