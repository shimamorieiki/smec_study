# 工程図記号について

## 概要
工程図記号は、製造業や生産管理において作業工程を視覚的に表現するための標準化された記号体系です。これらの記号を使用することで、複雑な製造プロセスを分かりやすく図示し、作業者間での共通理解を促進できます。特に複合記号を含む工程図記号は、生産効率の向上、品質管理の改善、作業標準化の推進において重要な役割を果たします。

## 1. 基本概念・仕組み

### 工程図記号の定義
- **定義**: 生産工程における各種作業、検査、運搬、停滞などを表す標準化された図形記号
- **動作原理**: 時系列に沿って記号を配置し、材料や製品の流れと各工程での処理内容を視覚化
- **特徴**: 国際規格（ISO）や日本工業規格（JIS）により標準化され、業界を問わず共通理解が可能

### 工程分析との関係
- **従来技術との違い**: 文字による工程説明と比較して、視覚的理解が容易で標準化されている
- **改善点**: 複雑な工程も簡潔に表現でき、改善点の発見が容易
- **限界**: 詳細な作業内容や条件は別途文書化が必要

## 2. 記号の種類・分類

### 基本記号の分類
工程図記号は、その機能により以下の5つの基本カテゴリーに分類されます。

### 加工記号: ○（円）
**特徴:**
- 材料の形状、性質、品質を変化させる作業を表す
- 付加価値を生む主要な工程
- 機械加工、組立、調整などが該当

**記号の詳細:**
```
○ = 加工・作業
```

**📊 具体的な使用例**
**例: 部品の切削加工工程**
- 前提条件1: 原材料の鋼材を投入
- 前提条件2: NC旋盤で外径加工を実施

**ステップ1: 記号の配置**
```
→ ○ → 
  切削
```

**ステップ2: 詳細情報の付記**
```
→ ○ → 
  切削
  (5分)
```

**結果: 加工時間5分の切削工程として表現**

💡 **実際の現場では**: 作業時間や使用機械名を併記することで、より詳細な工程分析が可能になります

### 運搬記号: →（矢印）
**特徴:**
- 材料や製品の移動を表す
- 付加価値を生まない工程
- 改善対象として重要視される

**記号の詳細:**
```
→ = 運搬・移動
```

### 検査記号: □（四角）
**特徴:**
- 品質や数量の確認作業を表す
- 品質保証の重要工程
- 全数検査と抜取検査を区別して表記

**記号の詳細:**
```
□ = 検査
```

### 停滞記号: △（三角）
**特徴:**
- 計画的な一時保管を表す
- 在庫や仕掛品の管理ポイント
- 停滞時間の短縮が改善課題

**記号の詳細:**
```
△ = 停滞・保管
```

### 滞留記号: ▽（逆三角）
**特徴:**
- 計画外の待機や遅延を表す
- ムダの発生源として改善対象
- ボトルネック工程の特定に有効

**記号の詳細:**
```
▽ = 滞留・遅延
```

## 3. 複合記号の詳細

### 複合記号の概念
複合記号は、2つ以上の基本記号を組み合わせて、複数の機能を同時に持つ工程を表現する記号です。

#### 加工検査記号: ⊕（円の中に十字）
- **意味**: 加工しながら同時に検査を行う工程
- **設定範囲**: インライン検査、自動検査装置を使用する工程
- **影響**: 工程数の削減、品質の即時フィードバック
- **推奨値**: 高精度が要求される工程で使用

#### 運搬加工記号: ⊗（円の中に×印）
- **意味**: 運搬しながら同時に加工を行う工程
- **設定範囲**: コンベア上での組立、移動中の処理
- **影響**: リードタイムの短縮、スペース効率の向上
- **推奨値**: 連続生産ラインで推奨

#### 保管検査記号: ⊡（四角の中に四角）
- **意味**: 保管中に検査を行う工程
- **設定範囲**: エージング検査、経時変化の確認
- **影響**: 保管スペースの有効活用
- **推奨値**: 時間経過が品質に影響する製品で使用

### 複合記号の使用例

**📊 複合記号の実践的活用**
**例: 自動車部品の製造ライン**

**ケース1: インライン検査を含む加工工程**
```
→ ⊕ → □ → ○ →
  加工検査  最終検査  組立
  (10分)    (2分)    (5分)
```

**ケース2: 移動組立ラインの表現**
```
→ ⊗ → ⊗ → ⊗ → □
  組立1  組立2  組立3  検査
  (3分)  (3分)  (3分)  (2分)
```

## 4. 実装例・適用事例

### 基本的な工程図の作成
```
[原材料] → △ → ○ → □ → ○ → → → △ → [完成品]
         受入  切削  検査  組立  運搬  出荷待ち
         (30分)(5分) (2分) (10分)(3分) (60分)
```

### 複合記号を活用した改善例
```
改善前:
→ ○ → → → □ → → → ○ →
  加工1  運搬  検査  運搬  加工2
  (5分) (2分) (3分) (2分) (5分)
合計: 17分

改善後:
→ ⊕ → ⊗ →
  加工検査1  運搬加工2
  (6分)     (6分)
合計: 12分（29%短縮）
```

### 実際の適用事例
#### 事例1: 電子部品製造工場
- **課題**: 検査工程での滞留によるリードタイム増大
- **適用方法**: インライン検査（⊕）の導入
- **結果**: リードタイム30%短縮
- **効果**: 仕掛在庫50%削減、不良品の早期発見

#### 事例2: 食品加工工場
- **課題**: 運搬時間によるロスと品質劣化
- **適用方法**: 運搬加工記号（⊗）を使用した工程設計
- **結果**: 工程間の移動時間70%削減
- **効果**: 鮮度保持、作業効率20%向上

## 5. メリット・デメリット

### メリット
**1. 視覚的理解の促進**
- **理由**: 標準化された記号により言語の壁を越えた理解が可能
- **効果**: 作業者の教育時間短縮、ミスの削減
- **具体例**: 多国籍の作業者が働く工場での共通言語として機能

**2. 改善点の発見容易性**
- **理由**: ムダな工程が記号により一目で判別可能
- **効果**: 継続的改善活動の促進
- **具体例**: 運搬記号（→）の連続は改善対象として即座に認識

**3. 標準化による比較可能性**
- **理由**: 異なる工場や工程でも同じ記号体系で比較可能
- **効果**: ベストプラクティスの展開が容易
- **具体例**: グループ企業間での工程改善事例の共有

### デメリット
**1. 詳細情報の表現限界**
- **理由**: 記号だけでは作業の詳細内容や条件を表現できない
- **影響**: 別途作業手順書等の文書が必要
- **対策**: 記号と詳細文書を組み合わせた管理体系の構築

**2. 初期教育の必要性**
- **理由**: 記号の意味を理解するための教育が必要
- **影響**: 導入初期の教育コスト発生
- **対策**: 社内教育プログラムの整備、掲示物による周知

## 6. 選択・導入の指針

### 記号選択の基準
| 観点 | 基本記号のみ | 複合記号併用 | 独自記号追加 |
|------|-----------|-----------|-----------|
| 理解容易性 | ◎ | ○ | △ |
| 表現力 | △ | ◎ | ◎ |
| 標準性 | ◎ | ◎ | × |
| 導入コスト | ◎ | ○ | △ |

### 適用判断フローチャート
1. **工程の複雑さ** 
   - 単純 → 基本記号のみ使用
   - 複雑 → 次の判断へ

2. **同時作業の有無**
   - あり → 複合記号を積極活用
   - なし → 基本記号で表現

3. **業界特有の工程**
   - あり → 独自記号の追加検討
   - なし → 標準記号で対応

- A) 運搬

- C) 検査
- D) 停滞

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>

<br>

## 9. 専門用語集

このスライドで使用された専門用語について、アルファベット順・50音順で解説します。

### アルファベット

**IoT (Internet of Things)**
- **読み方**: アイオーティー
- **意味**: モノのインターネット。センサーや通信機能を持った機器が相互に接続され、データを交換する仕組み
- **関連用語**: Industry 4.0、スマートファクトリー

**ISO (International Organization for Standardization)**
- **読み方**: アイエスオー
- **意味**: 国際標準化機構。工業規格の国際的な標準化を推進する組織
- **関連用語**: JIS、標準化

**JIS (Japanese Industrial Standards)**
- **読み方**: ジス
- **意味**: 日本工業規格。日本の国家規格として制定される工業標準
- **関連用語**: ISO、標準化

**TOC (Theory of Constraints)**
- **読み方**: ティーオーシー
- **意味**: 制約理論。システム全体の制約（ボトルネック）に着目して改善を行う手法
- **関連用語**: ボトルネック、スループット

**VSM (Value Stream Mapping)**
- **読み方**: ブイエスエム
- **意味**: 価値流れ図。製品やサービスの価値の流れを可視化する手法
- **関連用語**: リーン生産、ムダ削減

### あ行

**エージング**
- **読み方**: えーじんぐ
- **意味**: 製品を一定期間保管し、品質の安定化や熟成を図る工程
- **関連用語**: 保管検査、経時変化

**インライン検査**
- **読み方**: いんらいんけんさ
- **意味**: 生産ラインの中で、製品を止めることなく行う検査方式
- **関連用語**: 加工検査記号（⊕）、品質管理

**運搬記号**
- **読み方**: うんぱんきごう
- **意味**: 工程図で材料や製品の移動を表す→（矢印）記号
- **関連用語**: ムダ、付加価値

### か行

**加工記号**
- **読み方**: かこうきごう
- **意味**: 工程図で材料の形状・性質・品質を変化させる作業を表す○（円）記号
- **関連用語**: 付加価値、主要工程

**加工検査記号**
- **読み方**: かこうけんさきごう
- **意味**: 加工しながら同時に検査を行う工程を表す⊕（円の中に十字）記号
- **関連用語**: 複合記号、インライン検査

**検査記号**
- **読み方**: けんさきごう
- **意味**: 工程図で品質や数量の確認作業を表す□（四角）記号
- **関連用語**: 品質管理、品質保証

**経時変化**
- **読み方**: けいじへんか
- **意味**: 時間の経過とともに製品の特性が変化すること
- **関連用語**: エージング、保管検査

**工程図**
- **読み方**: こうていず
- **意味**: 生産工程を標準化された記号で表現した図表
- **関連用語**: 工程分析、生産管理

**工程分析**
- **読み方**: こうていぶんせき
- **意味**: 生産工程を詳細に調査・分析し、改善点を見出す手法
- **関連用語**: IE（Industrial Engineering）、改善活動

### さ行

**仕掛在庫**
- **読み方**: しかかりざいこ
- **意味**: 生産工程の途中にある未完成品の在庫
- **関連用語**: リードタイム、在庫管理

**スループット**
- **読み方**: するーぷっと
- **意味**: 一定時間内にシステムが処理できる量
- **関連用語**: ボトルネック、TOC

### た行

**滞留記号**
- **読み方**: たいりゅうきごう
- **意味**: 工程図で計画外の待機や遅延を表す▽（逆三角）記号
- **関連用語**: ムダ、ボトルネック

**デジタルツイン**
- **読み方**: でじたるついん
- **意味**: 物理的な製品や工程をデジタル空間に再現する技術
- **関連用語**: IoT、シミュレーション

**停滞記号**
- **読み方**: ていたいきごう
- **意味**: 工程図で計画的な一時保管を表す△（三角）記号
- **関連用語**: 在庫管理、保管

### は行

**複合記号**
- **読み方**: ふくごうきごう
- **意味**: 2つ以上の基本記号を組み合わせて複数の機能を表現する記号
- **関連用語**: ⊕、⊗、⊡

**付加価値**
- **読み方**: ふかかち
- **意味**: 生産活動により製品に付け加えられる価値
- **関連用語**: 加工、ムダ削減

**ボトルネック**
- **読み方**: ぼとるねっく
- **意味**: 生産工程全体の能力を制限している工程
- **関連用語**: TOC、滞留

**保管検査記号**
- **読み方**: ほかんけんさきごう
- **意味**: 保管中に検査を行う工程を表す⊡（四角の中に四角）記号
- **関連用語**: 複合記号、エージング

### ま行

**ムダ**
- **読み方**: むだ
- **意味**: 付加価値を生まない活動や資源
- **関連用語**: リーン生産、改善

### や行

**運搬加工記号**
- **読み方**: うんぱんかこうきごう
- **意味**: 運搬しながら同時に加工を行う工程を表す⊗（円の中に×印）記号
- **関連用語**: 複合記号、連続生産

### ら行

**リードタイム**
- **読み方**: りーどたいむ
- **意味**: 受注から納品までの総所要時間
- **関連用語**: 工程時間、スループット

**リーン生産**
- **読み方**: りーんせいさん
- **意味**: ムダを徹底的に排除し、効率的な生産を目指す生産方式
- **関連用語**: トヨタ生産方式、ムダ削減

**連続生産ライン**
- **読み方**: れんぞくせいさんらいん
- **意味**: 製品が停止することなく連続的に流れる生産方式
- **関連用語**: 運搬加工、コンベア
