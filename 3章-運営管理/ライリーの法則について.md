# ライリーの法則について

## 概要

ライリーの法則（Reilly's Law of Retail Gravitation）は、1931年にアメリカの経済学者ウィリアム・J・ライリー（William J. Reilly）によって提唱された小売引力の法則です。この法則は、都市間の小売商圏を分析し、消費者がどちらの都市で買い物をするかを予測するための理論的フレームワークを提供します。

物理学のニュートンの万有引力の法則を応用し、都市の小売引力は人口に比例し、距離の2乗に反比例するという考え方に基づいています。これにより、複数の商業地域が存在する場合の商圏境界を数学的に算出することが可能となります。

## 1. 基本概念・定義

### ライリーの法則の定義
- **定義**: 2つの都市間の商圏境界は、それぞれの都市の人口と距離によって決定されるという法則
- **特徴**: 物理学の引力法則を小売業に応用した理論
- **重要性**: 店舗立地戦略、商圏分析、市場調査の基礎理論として活用

### 基本公式
ライリーの法則の基本公式は以下の通りです：

```
Da = Dab / (1 + √(Pb/Pa))
```

ここで：
- Da：A市から商圏境界までの距離
- Dab：A市とB市の間の距離
- Pa：A市の人口
- Pb：B市の人口

### 理論的背景
- **ニュートンの万有引力の法則との類似性**: F = G × (m1 × m2) / r²
- **消費者行動の仮定**: 消費者は大きな都市により魅力を感じる
- **距離減衰効果**: 距離が増えるほど購買意欲は急激に減少

## 2. 商圏分析への応用

### 商圏境界の算出方法
商圏境界とは、2つの商業施設や都市の引力が等しくなる地点を指します。

### 修正ライリーの法則
実務では、人口以外の要素も考慮した修正版が使用されます：

```
Da = Dab / (1 + √(Sb/Sa × α))
```

ここで：
- Sa、Sb：それぞれの都市の魅力度（売場面積、商品数など）
- α：修正係数（交通利便性、駐車場などを反映）

### 商圏の種類
| 商圏区分 | 定義 | 顧客シェア |
|---------|------|-----------|
| 第1次商圏 | 最も影響力の強い地域 | 60-70% |
| 第2次商圏 | 中程度の影響力を持つ地域 | 20-25% |
| 第3次商圏 | 影響力の弱い地域 | 5-15% |

## 3. 具体的計算例・事例

### ケース1: 基本的な2都市間の商圏境界計算

#### 設定
- A市：人口10万人
- B市：人口40万人
- A市とB市の距離：60km

#### 計算過程
```
Step 1: 人口比の平方根を計算
√(Pb/Pa) = √(40万/10万) = √4 = 2

Step 2: 分母を計算
1 + √(Pb/Pa) = 1 + 2 = 3

Step 3: A市から商圏境界までの距離を計算
Da = 60km ÷ 3 = 20km

Step 4: B市から商圏境界までの距離を計算
Db = 60km - 20km = 40km
```

#### 結果
A市から20km、B市から40kmの地点が商圏境界となります。

### ケース2: 3都市間の商圏分析

#### 設定
- A市：人口20万人、大型ショッピングモール有
- B市：人口30万人、中規模商業施設
- C市：人口15万人、地域密着型商店街
- A-B間：50km、B-C間：40km、A-C間：70km

#### A市とB市の商圏境界
```
Da-b = 50km ÷ (1 + √(30万/20万))
     = 50km ÷ (1 + √1.5)
     = 50km ÷ (1 + 1.225)
     = 50km ÷ 2.225
     = 22.5km（A市から）
```

#### B市とC市の商圏境界
```
Db-c = 40km ÷ (1 + √(15万/30万))
     = 40km ÷ (1 + √0.5)
     = 40km ÷ (1 + 0.707)
     = 40km ÷ 1.707
     = 23.4km（B市から）
```

#### A市とC市の商圏境界
```
Da-c = 70km ÷ (1 + √(15万/20万))
     = 70km ÷ (1 + √0.75)
     = 70km ÷ (1 + 0.866)
     = 70km ÷ 1.866
     = 37.5km（A市から）
```

### ケース3: 売場面積を考慮した修正ライリーの法則

#### 設定
- 店舗X：売場面積3,000㎡、駅前立地（アクセス係数1.2）
- 店舗Y：売場面積5,000㎡、郊外立地（アクセス係数0.8）
- 店舗間距離：15km

#### 計算過程
```
Step 1: 修正魅力度の計算
Sx（修正後） = 3,000㎡ × 1.2 = 3,600
Sy（修正後） = 5,000㎡ × 0.8 = 4,000

Step 2: 商圏境界の計算
Dx = 15km ÷ (1 + √(4,000/3,600))
   = 15km ÷ (1 + √1.111)
   = 15km ÷ (1 + 1.054)
   = 15km ÷ 2.054
   = 7.3km（店舗Xから）
```

#### 結果
アクセス係数を考慮すると、店舗Xから7.3km、店舗Yから7.7kmの地点が商圏境界となります。

## 5. 限界と注意点

### ライリーの法則の限界

#### 1. 単純化された仮定
- **前提**: すべての消費者が同質であると仮定
- **現実**: 所得、年齢、ライフスタイルによる差異
- **対策**: セグメント別の分析が必要

#### 2. 地理的要因の無視
- **前提**: 直線距離での計算
- **現実**: 河川、山脈、交通網の影響
- **対策**: 時間距離や心理的距離の導入

#### 3. 商品特性の考慮不足
- **前提**: すべての商品カテゴリーで同一
- **現実**: 最寄品と買回品で商圏が異なる
- **対策**: 商品別の係数設定

### 現代的な修正アプローチ

#### ハフモデルとの併用
```
Pij = (Sj^α / Tij^β) / Σ(Sk^α / Tik^β)
```
- Pij：地点iの消費者が店舗jを選択する確率
- Sj：店舗jの魅力度
- Tij：地点iから店舗jまでの時間距離
- α、β：パラメータ

#### GISを活用した詳細分析
- 実際の道路網を考慮した到達圏分析
- 人口メッシュデータとの統合
- リアルタイムデータの活用

## 6. よくある質問（Q&A）

### Q1. ライリーの法則は現代でも有効ですか？

**A1.** 基本的な考え方は現在でも有効ですが、そのまま使用するのではなく、現代的な要素を加味した修正版を使用することが重要です。

#### 現代的な活用方法
- **Eコマースの影響**: オンライン購買率を考慮した商圏設定
- **交通手段の多様化**: 公共交通機関の利便性を係数化
- **ライフスタイルの変化**: 時間価値の上昇を反映した時間距離の重視
- **データ分析との融合**: ビッグデータやAIを活用した精緻化

### Q2. 人口以外にどのような要素を考慮すべきですか？

**A2.** 現代の商圏分析では、以下の要素を総合的に考慮する必要があります。

#### 考慮すべき主要要素
1. **経済的要素**
   - 所得水準（購買力指数）
   - 消費支出額
   - 競合店舗の存在

2. **施設的要素**
   - 売場面積
   - 駐車場収容台数
   - 営業時間

3. **アクセス要素**
   - 公共交通機関の有無
   - 道路整備状況
   - 交通渋滞の影響

4. **心理的要素**
   - ブランドイメージ
   - 顧客満足度
   - 口コミ評価

### Q3. 小規模店舗でもライリーの法則は適用できますか？

**A3.** 小規模店舗の場合、そのまま適用するよりも、業態特性に応じた修正が必要です。

#### 小規模店舗への適用方法
- **近隣型商圏の設定**: 第1次商圏を500m-1km程度に限定
- **専門性の考慮**: 特殊な商品・サービスの場合は広域商圏
- **地域密着度の反映**: 常連客比率を重視した分析
- **補完的指標の活用**: 徒歩・自転車での来店を考慮

### 問題14

総時間距離 = 15分 + 25分 = 40分（仮想的な総距離）<br>

ただし、これはA-B間の中点を示す。実際の配置を考慮すると、<br>

</details>

オムニチャネル時代では、実店舗とECの連携（クリック&コレクト、店舗受取など）が重要です。これにより物理的な距離の制約が緩和され、商圏が拡大する可能性があるため、修正係数として考慮する必要があります。
</details>

### 問題17
GISを活用した商圏分析で、ライリーの法則と比べた利点は？

- A) 計算が簡単
- B) 実際の道路網を考慮できる
- C) 人口データが不要
- D) 結果が単純明快

<details>
<summary>解答</summary>
<strong>正解: B) 実際の道路網を考慮できる</strong><br>
GIS（地理情報システム）では、実際の道路網、河川、鉄道などの地理的障害を考慮した到達圏分析が可能です。ライリーの法則の直線距離による計算と異なり、より現実的な商圏設定ができます。
</details>

### 問題18
商圏分析で「時間価値の上昇」を考慮する場合、どのような修正が必要か？

- A) 人口の重みを増やす
- B) 距離の影響を強める
- C) 商品価格を上げる
- D) 営業時間を延長する

<details>
<summary>解答</summary>
<strong>正解: B) 距離の影響を強める</strong><br>
時間価値が上昇すると、消費者は移動時間をより重視するようになります。そのため、距離（時間距離）の影響を強める修正（例：距離の累乗を2乗から2.5乗にする）が必要になります。
</details>

### 問題19
人口減少地域でライリーの法則を適用する際の課題は？

- A) 計算が複雑になる
- B) 商圏が過大に推定される
- C) 競合が増える
- D) 公式が使えない

<details>
<summary>解答</summary>
<strong>正解: B) 商圏が過大に推定される</strong><br>
人口減少地域では、絶対的な需要が減少しているにも関わらず、ライリーの法則では相対的な人口比で商圏を決定するため、実際の購買力以上に商圏が広く推定される可能性があります。購買力指数などで補正が必要です。
</details>

### 問題20
AIを活用した商圏分析が、従来のライリーの法則と最も異なる点は？

- A) 計算速度が速い
- B) 多変量を同時に扱える
- C) 結果が正確
- D) コストが安い

<details>
<summary>解答</summary>
<strong>正解: B) 多変量を同時に扱える</strong><br>
AIや機械学習を活用した商圏分析では、人口や距離だけでなく、天候、イベント、SNSの評判、個人の購買履歴など、多数の変数を同時に考慮した予測が可能です。これにより、より複雑で動的な消費者行動を捉えることができます。
</details>

## 9. 専門用語集

このスライドで使用された専門用語について、50音順で解説します。

### あ行
**商圏（しょうけん）**
- **読み方**: しょうけん
- **意味**: 店舗や商業施設が顧客を吸引できる地理的範囲。顧客が来店する地域の広がりを示す。
- **関連用語**: 第1次商圏、第2次商圏、第3次商圏

**商圏境界（しょうけんきょうかい）**
- **読み方**: しょうけんきょうかい
- **意味**: 2つ以上の店舗や都市の商圏が接する境界線。この地点では複数の商業施設の引力が均衡する。
- **関連用語**: 分岐点、商圏分析

**アクセス係数（あくせすけいすう）**
- **読み方**: あくせすけいすう
- **意味**: 店舗への到達しやすさを数値化した指標。交通利便性、駐車場の有無などを考慮して設定。
- **関連用語**: 修正係数、立地条件

**オムニチャネル**
- **読み方**: おむにちゃねる
- **意味**: 実店舗、ECサイト、モバイルなど複数の販売チャネルを統合し、顧客に一貫した購買体験を提供する戦略。
- **関連用語**: マルチチャネル、O2O

### か行
**買回品（かいまわりひん）**
- **読み方**: かいまわりひん
- **意味**: 消費者が複数の店舗を比較検討してから購入する商品。衣料品、家電製品など。
- **関連用語**: 最寄品、専門品

**クリック&コレクト**
- **読み方**: くりっくあんどこれくと
- **意味**: オンラインで注文し、実店舗で商品を受け取るサービス。Click and Collectの日本語表記。
- **関連用語**: オムニチャネル、店舗受取

### さ行
**最寄品（もよりひん）**
- **読み方**: もよりひん
- **意味**: 日常的に購入する頻度が高く、最寄りの店舗で購入される商品。食料品、日用品など。
- **関連用語**: 買回品、利便品

**修正係数（しゅうせいけいすう）**
- **読み方**: しゅうせいけいすう
- **意味**: ライリーの法則の基本公式を現実に即して調整するための係数。業態特性や立地条件を反映。
- **関連用語**: アクセス係数、魅力度

**GIS（ジーアイエス）**
- **読み方**: じーあいえす
- **意味**: Geographic Information Systemの略。地理情報システム。地図データと各種情報を統合して分析するシステム。
- **関連用語**: 商圏分析、到達圏

### た行
**第1次商圏（だいいちじしょうけん）**
- **読み方**: だいいちじしょうけん
- **意味**: 店舗の顧客の60-70%が居住する最も重要な商圏。店舗から最も近い範囲。
- **関連用語**: 第2次商圏、第3次商圏

**到達圏（とうたつけん）**
- **読み方**: とうたつけん
- **意味**: ある地点から一定時間内に到達できる範囲。時間距離で表される商圏。
- **関連用語**: 時間距離、アクセシビリティ

### な行
**ニュートンの万有引力の法則（にゅーとんのばんゆういんりょくのほうそく）**
- **読み方**: にゅーとんのばんゆういんりょくのほうそく
- **意味**: 2つの物体間に働く引力は質量の積に比例し、距離の2乗に反比例するという物理法則。
- **関連用語**: ライリーの法則、引力モデル

### は行
**ハフモデル**
- **読み方**: はふもでる
- **意味**: David Huffが提唱した確率的商圏モデル。消費者が各店舗を選択する確率を算出。
- **関連用語**: 確率モデル、選択確率

**引力モデル（いんりょくもでる）**
- **読み方**: いんりょくもでる
- **意味**: 物理学の引力法則を応用し、都市間や店舗間の相互作用を分析するモデルの総称。
- **関連用語**: ライリーの法則、重力モデル

### ま行
**魅力度（みりょくど）**
- **読み方**: みりょくど
- **意味**: 店舗や都市が消費者を引きつける力を数値化した指標。売場面積、品揃え、サービスなどで構成。
- **関連用語**: 店舗魅力度、集客力

### や行
**要因分析（よういんぶんせき）**
- **読み方**: よういんぶんせき
- **意味**: 商圏形成に影響を与える各種要因を分析し、その影響度を評価する手法。
- **関連用語**: 多変量解析、回帰分析

### ら行
**ライリーの法則（らいりーのほうそく）**
- **読み方**: らいりーのほうそく
- **意味**: William J. Reillyが1931年に提唱した小売引力の法則。都市の商圏は人口に比例し距離の2乗に反比例する。
- **関連用語**: 小売引力の法則、Reilly's Law

**立地条件（りっちじょうけん）**
- **読み方**: りっちじょうけん
- **意味**: 店舗の立地に関する諸条件。交通アクセス、視認性、周辺環境などを含む。
- **関連用語**: 立地評価、出店戦略

### わ行
**分岐点（ぶんきてん）**
- **読み方**: ぶんきてん
- **意味**: 消費者がどちらの店舗・都市で買い物をするかの分かれ目となる地点。商圏境界と同義。
- **関連用語**: 商圏境界、均衡点
