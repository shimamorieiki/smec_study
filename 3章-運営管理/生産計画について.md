# 生産計画について

## 概要

生産計画とは、企業が製品を生産するために必要な資源（人員、設備、材料、時間）を効率的に配分し、顧客の需要に応えるための計画を立てる活動です。適切な生産計画により、納期遵守率の向上、在庫コストの削減、設備稼働率の最適化が実現できます。本資料では、生産計画の中核となるスケジューリング手法について、フォワードスケジューリング、バックワードスケジューリング、フローショップスケジューリング（ジョンソン法）、ジョブショップスケジューリング（ディスパッチングルール）を詳しく解説します。

## 1. 基本概念・仕組み

### スケジューリングの基本要素
- **定義**: 限られた資源の中で、複数のジョブ（作業）を最適な順序で処理するための計画を立てること
- **動作原理**: 各ジョブの処理時間、納期、優先度を考慮し、全体最適を目指す
- **特徴**: 組合せ最適化問題として扱われ、ジョブ数が増えると計算量が指数関数的に増加

### スケジューリングの評価指標
- **納期遵守率**: 顧客への約束を守る指標
- **平均フロータイム**: ジョブが工場に滞留する時間
- **設備稼働率**: 設備の有効活用度
- **仕掛在庫量**: 生産途中の製品在庫

## 2. スケジューリング手法の分類

### 時間軸による分類

スケジューリングは計画の立て方により大きく2つに分類されます。

### フォワードスケジューリング（前進スケジューリング）
**特徴:**
- 現在時点から前向きに計画を立てる
- 最早開始時刻を基準に作業を配置
- 設備の稼働率を重視する場合に有効

**算出方法:**
```
最早開始時刻 = max(前工程の完了時刻, 資材到着時刻)
最早完了時刻 = 最早開始時刻 + 処理時間
```

**📊 具体的な計算例**
**例: 3工程の製品Aの生産計画**
- 前提条件1: 各工程の処理時間は工程1: 2時間、工程2: 3時間、工程3: 1時間
- 前提条件2: 開始可能時刻は9:00、資材到着は8:30

**ステップ1: 工程1の計算**
```
最早開始時刻 = max(-, 8:30) = 9:00（開始可能時刻を採用）
最早完了時刻 = 9:00 + 2:00 = 11:00
```

**ステップ2: 工程2の計算**
```
最早開始時刻 = 11:00
最早完了時刻 = 11:00 + 3:00 = 14:00
```

**ステップ3: 工程3の計算**
```
最早開始時刻 = 14:00
最早完了時刻 = 14:00 + 1:00 = 15:00
```

**結果: 15:00に生産完了（最早完了時刻）**

💡 **実際の現場では**: 見込み生産型の工場で、在庫を持ちながら効率的に生産する場合に採用されます。

### バックワードスケジューリング（後進スケジューリング）
**特徴:**
- 納期から逆算して計画を立てる
- 最遅開始時刻を基準に作業を配置
- 在庫削減を重視する場合に有効

**算出方法:**
```
最遅完了時刻 = min(後工程の開始時刻, 納期)
最遅開始時刻 = 最遅完了時刻 - 処理時間
```

**📊 具体的な計算例**
**例: 3工程の製品Bの生産計画**
- 前提条件1: 各工程の処理時間は工程1: 2時間、工程2: 3時間、工程3: 1時間
- 前提条件2: 納期は17:00

**ステップ1: 工程3の計算（最終工程から開始）**
```
最遅完了時刻 = 17:00（納期）
最遅開始時刻 = 17:00 - 1:00 = 16:00
```

**ステップ2: 工程2の計算**
```
最遅完了時刻 = 16:00
最遅開始時刻 = 16:00 - 3:00 = 13:00
```

**ステップ3: 工程1の計算**
```
最遅完了時刻 = 13:00
最遅開始時刻 = 13:00 - 2:00 = 11:00
```

**結果: 11:00に生産開始必要（最遅開始時刻）**

💡 **実際の現場では**: 受注生産型の工場で、在庫を最小限に抑えながら納期を守る場合に採用されます。

## 3. フローショップスケジューリング

### フローショップの特徴
- **定義**: すべてのジョブが同じ順序で機械を通過する生産形態
- **特徴**: 流れ作業的な生産に適している
- **例**: 自動車の組立ライン、食品製造ライン

### ジョンソン法（Johnson's Method）
**特徴:**
- 2機械フローショップ問題の最適解を求める手法
- 総処理時間（メイクスパン）を最小化
- 計算が簡単で現場でも使いやすい

**アルゴリズム:**
1. すべてのジョブの処理時間リストを作成
2. 最小処理時間を持つジョブを選択
3. 機械1での処理時間が最小なら前から配置
4. 機械2での処理時間が最小なら後ろから配置
5. 配置済みジョブを除外し、2に戻る

**📊 具体的な計算例**
**例: 5つのジョブを2台の機械で処理**

| ジョブ | 機械1 | 機械2 |
|--------|-------|-------|
| A      | 5     | 2     |
| B      | 3     | 8     |
| C      | 7     | 4     |
| D      | 1     | 6     |
| E      | 4     | 3     |

**ステップ1: 最小値の探索**
```
最小値 = 1（ジョブD、機械1）
→ Dを先頭に配置: [D, -, -, -, -]
```

**ステップ2: 残りから最小値探索**
```
最小値 = 2（ジョブA、機械2）
→ Aを最後に配置: [D, -, -, -, A]
```

**ステップ3: 継続**
```
最小値 = 3（ジョブB、機械1）
→ Bを前から配置: [D, B, -, -, A]
```

**ステップ4: 継続**
```
最小値 = 3（ジョブE、機械2）
→ Eを後ろから配置: [D, B, -, E, A]
```

**ステップ5: 最後のジョブ**
```
Cを配置: [D, B, C, E, A]
```

**結果: 最適順序はD→B→C→E→A**

💡 **実際の現場では**: 印刷工場での印刷→製本、金属加工での切削→研磨などの2工程生産で活用されます。

### ジョンソン法の拡張
- **3機械問題への適用条件**: 
  - 機械2の最大処理時間 ≤ 機械1の最小処理時間、または
  - 機械2の最大処理時間 ≤ 機械3の最小処理時間
- **適用方法**: 条件を満たす場合、仮想的に2機械問題に変換して解く

## 4. ジョブショップスケジューリング

### ジョブショップの特徴
- **定義**: 各ジョブが異なる順序で機械を通過する生産形態
- **特徴**: 多品種少量生産に適している
- **例**: 金型製作、試作品製造、修理工場

### ディスパッチングルール（Dispatching Rules）
**定義**: 機械が空いたときに、待ちジョブの中から次に処理するジョブを選ぶ規則

#### 主要なディスパッチングルール

**1. FCFS（First Come First Served）**
- **意味**: 先着順
- **特徴**: 公平性が高い
- **欠点**: 納期や処理時間を考慮しない

**2. SPT（Shortest Processing Time）**
- **意味**: 処理時間最短優先
- **特徴**: 平均フロータイム最小化
- **欠点**: 長時間ジョブが後回しになる

**📊 SPTルールの計算例**
**例: 4つのジョブの優先順位決定**

| ジョブ | 処理時間 | 到着時刻 |
|--------|---------|----------|
| J1     | 8       | 0        |
| J2     | 3       | 2        |
| J3     | 5       | 1        |
| J4     | 2       | 3        |

**時刻0での判断**: J1のみ → J1を処理
**時刻8での判断**: J2(3), J3(5), J4(2) → J4を選択（最短）
**時刻10での判断**: J2(3), J3(5) → J2を選択
**時刻13での判断**: J3のみ → J3を処理

**結果: J1→J4→J2→J3の順で処理**

**3. EDD（Earliest Due Date）**
- **意味**: 納期最早優先
- **特徴**: 最大納期遅れ最小化
- **適用**: 納期遵守が重要な場合

**4. SLACK（Slack Time）**
- **意味**: 余裕時間最小優先
- **計算**: 余裕時間 = 納期 - 現在時刻 - 残処理時間
- **特徴**: 動的に優先度が変化

**5. CR（Critical Ratio）**
- **意味**: クリティカル比最小優先
- **計算**: CR = (納期 - 現在時刻) / 残処理時間
- **特徴**: 納期と処理時間の両方を考慮

### ディスパッチングルールの比較

| ルール | 平均フロータイム | 納期遵守率 | 公平性 | 計算の複雑さ |
|--------|-----------------|------------|--------|--------------|
| FCFS   | △              | △          | ◎      | ◎            |
| SPT    | ◎              | ○          | △      | ◎            |
| EDD    | ○              | ◎          | ○      | ◎            |
| SLACK  | ○              | ◎          | ○      | ○            |
| CR     | ○              | ◎          | ○      | △            |

## 5. 実装例・適用事例

### 実際の適用事例

#### 事例1: 自動車部品メーカーA社
- **課題**: 多品種少量生産での納期遅延が頻発
- **適用方法**: EDDルールとSLACKルールを組み合わせたハイブリッド方式を導入
- **結果**: 納期遵守率が75%から92%に向上
- **効果**: 顧客満足度の向上、緊急対応コストの削減

#### 事例2: 食品加工工場B社
- **課題**: 2工程（調理→包装）での待ち時間が長い
- **適用方法**: ジョンソン法を適用し、日次生産順序を最適化
- **結果**: 総処理時間が平均15%短縮
- **効果**: 残業時間の削減、製品鮮度の向上

#### 事例3: 金型製作所C社
- **課題**: 複雑な工程を持つジョブショップでの管理困難
- **適用方法**: CRルールを基本とし、緊急案件にはプリエンプティブ処理を適用
- **結果**: 平均納期遅れ日数が5日から2日に短縮
- **効果**: 受注増加、リピート率向上

## 6. 選択・導入の指針

### スケジューリング手法の選択基準

#### 生産形態による選択
1. **見込み生産中心の場合**
   - フォワードスケジューリングを採用
   - SPTルールで効率重視

2. **受注生産中心の場合**
   - バックワードスケジューリングを採用
   - EDDまたはCRルールで納期重視

3. **混合生産の場合**
   - ハイブリッド方式を検討
   - 製品特性により使い分け

#### 工場レイアウトによる選択
| レイアウト | 推奨手法 | 理由 |
|-----------|---------|------|
| フローショップ | ジョンソン法 | 最適解が保証される |
| ジョブショップ | ディスパッチングルール | 柔軟な対応が可能 |
| セル生産 | グループテクノロジー | 類似品のまとめ生産 |

### 導入ステップ
1. **現状分析**
   - 生産データの収集（処理時間、納期、稼働率）
   - ボトルネック工程の特定
   - 現行ルールの評価

2. **手法選定**
   - 評価指標の優先順位決定
   - シミュレーションによる効果予測
   - 段階的導入計画の策定

3. **実装と改善**
   - パイロット運用
   - KPIモニタリング
   - 継続的改善（PDCA）

- C) 在庫を最小限に抑えることを重視する
- D) 最遅開始時刻を基準にする

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
フォワードスケジューリングは現在時点から前向きに計画を立てる手法です。最早開始時刻を基準に作業を配置し、設備の稼働率を重視する場合に有効です。<br>
<br>

Dが間違いの理由：最遅開始時刻はバックワードスケジューリングで使用<br>
<br>
【補足】実務では、見込み生産型の工場でフォワードスケジューリングが多く採用されます。

### 問題8
CRルール（クリティカル比）の計算式として正しいものはどれか？

- A) CR = 処理時間 / 納期
- B) CR = (納期 - 現在時刻) / 残処理時間
- C) CR = 残処理時間 / (納期 - 現在時刻)
