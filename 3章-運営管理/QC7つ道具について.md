# QC7つ道具について

## 概要
QC7つ道具（Quality Control 7 Tools）は、品質管理において最も基本的かつ重要な統計的手法の集合体です。これらは1960年代に日本で体系化され、製造業を中心に品質改善活動の基礎として世界中で活用されています。データの収集・整理・分析を通じて問題の発見と解決を支援し、継続的な品質向上を実現するための実践的なツール群です。

## 1. 基本概念・仕組み

### QC7つ道具の核となる概念
- **定義**: 品質管理における問題解決のための7つの基本的な統計的手法
- **動作原理**: データの可視化と統計的分析により、問題の本質を明らかにし、改善につなげる
- **特徴**: 
  - 誰でも理解しやすく実践可能
  - 少ない投資で大きな効果が期待できる
  - 現場での問題解決に直結

### 従来の管理手法との関係
- **従来技術との違い**: 経験や勘に頼った管理から、データに基づく科学的管理への転換
- **改善点**: 客観的なデータ分析により、問題の真因を特定できる
- **限界**: 複雑な統計解析や多変量解析には対応していない（新QC7つ道具で補完）

## 2. 7つの道具の詳細

### QC7つ道具の分類
品質管理の目的に応じて、データ収集・整理・分析・管理の各段階で使い分けられます。

### 1. チェックシート（Check Sheet）
**特徴:**
- データ収集を効率化する記録用紙
- 現場で簡単にデータを記録できる
- データの傾向を一目で把握可能

**作成方法:**
```
1. 収集する項目を明確にする
2. 記録しやすい形式を設計する
3. 期間・担当者を明記する
4. 集計欄を設ける
```

**📊 具体的な活用例**
**例: 製品不良のチェックシート**
- 期間: 2024年1月1日～1月31日
- 対象: 製品A（生産数1000個/日）

```
不良項目    | 正の字カウント | 合計
-----------|--------------|-----
傷        | 正正正III      | 18
汚れ      | 正正I         | 11  
寸法不良   | 正III        | 8
変形      | II           | 2
その他     | I            | 1
```

💡 **実際の現場では**: チェックシートは毎日の始業時に配布し、作業者が不良を発見した都度記録。週次で集計してパレート図作成に活用します。

### 2. パレート図（Pareto Chart）
**特徴:**
- 問題の重要度を視覚的に表現
- 80-20の法則を活用した優先順位付け
- 改善効果の大きい項目を特定

**作成方法:**
```
1. データを降順に並べ替える
2. 棒グラフで各項目の件数を表示
3. 累積比率の折れ線グラフを追加
4. 80%ラインを引いて重点項目を特定
```

**📊 具体的な計算例**
**例: 不良原因のパレート分析**
- 総不良数: 100件
- 分析期間: 1ヶ月

**ステップ1: データの整理**
```
不良原因 | 件数 | 累積件数 | 累積比率
--------|-----|---------|--------
傷      | 45  | 45      | 45%
汚れ    | 25  | 70      | 70%
寸法不良 | 15  | 85      | 85%
変形    | 10  | 95      | 95%
その他   | 5   | 100     | 100%
```

**結果: 「傷」と「汚れ」で全体の70%を占めるため、この2項目を重点改善対象とする**

### 3. 特性要因図（Cause and Effect Diagram / Fishbone Diagram）
**特徴:**
- 問題の要因を体系的に整理
- ブレーンストーミングに最適
- 4M（Man, Machine, Material, Method）の観点で分析

**作成方法:**
```
1. 解決したい問題（特性）を右端に記入
2. 背骨となる主線を引く
3. 大骨（主要因）を4M等で分類
4. 中骨・小骨で詳細要因を展開
```

**📊 具体的な活用例**
**例: 製品の傷不良の要因分析**
```
        人（Man）           機械（Machine）
         ├─作業者の熟練度    ├─設備の老朽化
         ├─教育不足         ├─メンテナンス不足
         └─疲労            └─治具の摩耗
                    ＼    ／
                     ＼  ／
                      ＼／ ──→ 製品の傷
                      ／＼
                     ／  ＼
                    ／    ＼
        材料（Material）    方法（Method）
         ├─原材料の品質     ├─作業手順書の不備
         ├─保管状態        ├─検査基準の曖昧さ
         └─供給業者の変更    └─運搬方法
```

### 4. ヒストグラム（Histogram）
**特徴:**
- データの分布状態を視覚化
- 工程能力の把握に有効
- 規格との比較が容易

**作成方法:**
```
1. データの最大値・最小値を確認
2. 適切な区間数を決定（√n または スタージェスの公式）
3. 度数分布表を作成
4. 棒グラフで表示
```

**📊 具体的な計算例**
**例: 製品寸法のヒストグラム作成**
- サンプル数: 100個
- 規格: 50.0±0.5mm

**ステップ1: 区間数の決定**
```
区間数 = 1 + 3.322 × log₁₀(100) = 約7区間
区間幅 = (最大値-最小値) / 区間数 = (50.8-49.2) / 7 = 0.23mm
```

**ステップ2: 度数分布表**
```
区間(mm)      | 度数 | 相対度数
-------------|-----|--------
49.2～49.43  | 2   | 2%
49.43～49.66 | 8   | 8%
49.66～49.89 | 15  | 15%
49.89～50.12 | 40  | 40%
50.12～50.35 | 25  | 25%
50.35～50.58 | 8   | 8%
50.58～50.81 | 2   | 2%
```

💡 **実際の現場では**: 正規分布に従っているが、平均が規格中心からややずれている。工程の調整が必要。

### 5. 散布図（Scatter Diagram）
**特徴:**
- 2つの変数間の関係を視覚化
- 相関関係の有無を判断
- 原因と結果の関係を探る

**作成方法:**
```
1. 対になるデータを収集
2. X軸とY軸を設定
3. データを点でプロット
4. 相関の傾向を分析
```

**📊 具体的な計算例**
**例: 温度と不良率の相関分析**
- データ数: 20日分
- X軸: 作業場温度（℃）
- Y軸: 不良率（%）

**相関係数の計算**
```
r = Σ(xi - x̄)(yi - ȳ) / √[Σ(xi - x̄)² × Σ(yi - ȳ)²]
r = 0.85 （強い正の相関）
```

**結果: 温度が上がると不良率も上昇する傾向。空調管理の強化が必要。**

### 6. 管理図（Control Chart）
**特徴:**
- 工程の安定性を監視
- 異常の早期発見
- 統計的管理状態の判定

**作成方法:**
```
1. 管理する特性値を決定
2. データを時系列で収集
3. 中心線（CL）と管理限界線（UCL/LCL）を計算
4. データをプロットして傾向を監視
```

**📊 具体的な計算例**
**例: X̄-R管理図の作成**
- サンプルサイズ: n=5
- サブグループ数: 25

**ステップ1: 管理限界の計算**
```
X̄管理図:
CL = X̄̄ = 50.0mm
UCL = X̄̄ + A₂R̄ = 50.0 + 0.577 × 0.4 = 50.23mm
LCL = X̄̄ - A₂R̄ = 50.0 - 0.577 × 0.4 = 49.77mm

R管理図:
CL = R̄ = 0.4mm
UCL = D₄R̄ = 2.114 × 0.4 = 0.85mm
LCL = D₃R̄ = 0 × 0.4 = 0mm
```

### 7. 層別（Stratification）
**特徴:**
- データを特性で分類
- 隠れた要因の発見
- 他の手法と組み合わせて使用

**実施方法:**
```
1. 層別の観点を決定（4M、時間、場所等）
2. データを分類
3. 各層で他のQC手法を適用
4. 層間の差異を分析
```

**📊 具体的な活用例**
**例: 作業シフト別の不良率分析**
```
シフト | 生産数 | 不良数 | 不良率
------|-------|-------|-------
昼勤   | 5000  | 50    | 1.0%
夜勤   | 4500  | 90    | 2.0%
```

**結果: 夜勤の不良率が2倍。照明・疲労・人員配置等の要因を調査。**

## 3. 活用の手順とポイント

### PDCAサイクルでの活用
#### Plan（計画）段階
- **チェックシート**: データ収集計画の立案
- **特性要因図**: 問題の要因分析
- **パレート図**: 重点課題の特定

#### Do（実行）段階
- **チェックシート**: データの収集
- **層別**: データの分類・整理

#### Check（評価）段階
- **ヒストグラム**: 分布状態の確認
- **散布図**: 要因間の関係分析
- **管理図**: 工程の安定性評価

#### Act（改善）段階
- **パレート図**: 改善効果の確認
- **管理図**: 継続的な監視

## 4. 実装例・適用事例

### 基本的な品質改善プロジェクト
```
プロジェクト: 製品Aの不良率低減
期間: 3ヶ月
目標: 不良率2%→0.5%

1週目: チェックシートでデータ収集
2週目: パレート図で重点不良を特定
3週目: 特性要因図で要因分析
4週目: 層別で詳細分析
5-8週目: 改善実施
9-12週目: 管理図で効果確認
```

### 実際の適用事例
#### 事例1: 自動車部品メーカーA社
- **課題**: 組立工程での不良率3%
- **適用方法**: 
  - パレート図で「寸法不良」が60%と判明
  - 特性要因図で「治具の摩耗」が主因と特定
  - 管理図で治具交換周期を最適化
- **結果**: 不良率0.8%に低減
- **効果**: 年間2000万円のコスト削減

#### 事例2: 電子機器メーカーB社
- **課題**: 基板実装工程の品質ばらつき
- **適用方法**:
  - ヒストグラムで工程能力不足を確認
  - 散布図で温度と不良の相関を発見
  - 層別で設備間の差を分析
- **結果**: Cpk値0.8→1.5に改善
- **効果**: 顧客クレーム80%削減

## 5. メリット・デメリット

### メリット
**1. 簡単で実用的**
- **理由**: 高度な統計知識が不要
- **効果**: 現場作業者が自主的に活用可能
- **具体例**: 製造現場での日常的な品質管理に即座に適用できる

**2. 低コストで導入可能**
- **理由**: 特別なソフトウェアや設備が不要
- **効果**: 紙とペン、基本的な表計算ソフトで実施可能
- **具体例**: 中小企業でも容易に導入でき、大きな改善効果を得られる

**3. 視覚的で理解しやすい**
- **理由**: グラフや図表で問題を可視化
- **効果**: 関係者間での情報共有が容易
- **具体例**: 経営層への報告でも一目で状況が伝わる

### デメリット
**1. 単純な分析に限定**
- **理由**: 複雑な要因間の相互作用は分析困難
- **影響**: 多変量解析が必要な問題には不適
- **対策**: 必要に応じて新QC7つ道具や高度な統計手法を併用

**2. 定性的データの扱いが限定的**
- **理由**: 数値データ中心の手法
- **影響**: 顧客の声など定性情報の分析が困難
- **対策**: 新QC7つ道具（親和図、連関図等）で補完

## 6. 選択・導入の指針

### 問題タイプ別の手法選択
| 問題のタイプ | 推奨手法 | 補助手法 | 適用例 |
|------------|---------|---------|--------|
| 不良の特定 | パレート図 | チェックシート | 重点不良の特定 |
| 原因分析 | 特性要因図 | 散布図・層別 | 不良要因の究明 |
| 工程管理 | 管理図 | ヒストグラム | 工程の安定化 |
| データ収集 | チェックシート | - | 現場データの記録 |

### 適用判断フローチャート
1. **問題は数値化可能か？** 
   - Yes → QC7つ道具を適用
   - No → 新QC7つ道具を検討

2. **データは既にあるか？**
   - Yes → パレート図・ヒストグラム等で分析
   - No → チェックシートでデータ収集から開始

3. **継続的な管理が必要か？**
   - Yes → 管理図を導入
   - No → 単発の分析手法を選択

## 8. 理解度確認クイズ（4択問題20問）

### 問題1
QC7つ道具の主な目的として最も適切なものはどれか？

- A) 高度な統計解析を行うため
- B) 品質管理における問題解決を支援するため
- C) 経営戦略を立案するため
- D) 人事評価を行うため

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
QC7つ道具は品質管理における問題解決を支援するための基本的な統計的手法です。<br>
<br>
Aが間違いの理由：QC7つ道具は基本的で簡単な手法であり、高度な統計解析は目的ではない<br>
Cが間違いの理由：経営戦略立案は新QC7つ道具の領域<br>
Dが間違いの理由：人事評価は品質管理とは異なる領域<br>
<br>
【補足】実務では、現場の作業者が日常的に使える簡便性が重要視されます。
</details>

### 問題2
パレート図で重点管理すべき項目を判断する目安として一般的なものはどれか？

- A) 上位50%までの項目
- B) 上位80%までの項目
- C) 上位90%までの項目
- D) 全項目

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
パレート図では「80-20の法則」に基づき、累積比率80%までの項目を重点管理対象とします。<br>
<br>
Aが間違いの理由：50%では重要な項目を見逃す可能性がある<br>
Cが間違いの理由：90%では焦点が絞れず、効率的な改善ができない<br>
Dが間違いの理由：全項目を対象にすると優先順位付けの意味がない<br>
<br>
【補足】実際には70-80%程度で区切ることが多く、状況に応じて調整します。
</details>

### 問題3
特性要因図の「4M」に含まれないものはどれか？

- A) Man（人）
- B) Machine（機械）
- C) Money（金）
- D) Method（方法）

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
特性要因図の基本的な4Mは、Man（人）、Machine（機械）、Material（材料）、Method（方法）です。<br>
<br>
Money（金）は4Mには含まれません。ただし、5M、6Mと拡張する場合には、Measurement（測定）やMother Nature（環境）が追加されることがあります。<br>
<br>
【補足】製造業では4Mが基本ですが、サービス業では異なる分類を使うこともあります。
</details>

### 問題4
ヒストグラムの区間数を決定する方法として適切でないものはどれか？

- A) スタージェスの公式（k = 1 + 3.322 × log₁₀n）
- B) 平方根法（k = √n）
- C) データ数の10%
- D) 5～20の範囲で調整

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
データ数の10%という基準は、ヒストグラムの区間数決定には使用されません。<br>
<br>
Aは正しい：スタージェスの公式は最も一般的な方法<br>
Bは正しい：平方根法も簡便な方法として使用される<br>
Dは正しい：実用的には5～20の範囲で見やすく調整する<br>
<br>
【補足】区間数が多すぎると分布の傾向が見えにくく、少なすぎると詳細が失われます。
</details>

### 問題6
散布図で相関係数が0.9の場合、どのような関係を示すか？

- A) 強い負の相関
- B) 強い正の相関
- C) 相関なし
- D) 完全な負の相関

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
相関係数0.9は強い正の相関を示します（0.7以上で強い相関）。<br>
<br>
Aが間違いの理由：負の相関は相関係数がマイナスの場合<br>
Cが間違いの理由：相関なしは0に近い場合（-0.2～0.2程度）<br>
Dが間違いの理由：完全な負の相関は-1の場合<br>
<br>
【補足】相関関係は因果関係を示すものではないことに注意が必要です。
</details>

### 問題7
管理図でプロットが管理限界線を超えた場合の対応として適切なものはどれか？

- A) 無視して作業を継続
- B) 異常原因を調査し除去
- C) 管理限界線を変更
- D) データを削除

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
管理限界線を超えた場合は異常原因を調査し、除去する必要があります。<br>
<br>
Aが間違いの理由：異常を放置すると品質問題が拡大する<br>
Cが間違いの理由：管理限界線は統計的に決まるもので恣意的に変更しない<br>
Dが間違いの理由：データの削除は問題の隠蔽になる<br>
<br>
【補足】異常原因には特殊原因と共通原因があり、対応方法が異なります。
</details>

### 問題8
層別を行う際の分類基準として不適切なものはどれか？

- A) 作業者
- B) 設備
- C) 不良数の大小
- D) 原材料ロット

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
不良数の大小は結果であり、層別の分類基準としては不適切です。<br>
<br>
A、B、Dは正しい：これらは要因系の分類基準として適切<br>

### 問題11
ある工程で100個のサンプルを測定し、平均50mm、標準偏差2mmだった。規格が50±6mmの場合、工程能力指数Cpはいくつか？

- A) 0.5
- B) 1.0
- C) 1.5
- D) 2.0

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
Cp = (規格上限 - 規格下限) / (6 × 標準偏差) = (56-44) / (6×2) = 12/12 = 1.0<br>
<br>
計算過程：<br>
規格上限 = 50 + 6 = 56mm<br>
規格下限 = 50 - 6 = 44mm<br>
規格幅 = 56 - 44 = 12mm<br>
6σ = 6 × 2 = 12mm<br>
<br>
【補足】Cp=1.0は工程能力が規格幅と同じで、改善の余地があります。
</details>

## 9. 専門用語集

### アルファベット

**4M**
- **読み方**: よんエム
- **意味**: 特性要因図で使用する要因分類の基本。Man（人）、Machine（機械）、Material（材料）、Method（方法）の頭文字
- **関連用語**: 5M、6M、特性要因図

**Cp（Process Capability Index）**
- **読み方**: シーピー
- **意味**: 工程能力指数。規格幅に対する工程のばらつきの比率を示す指標
- **関連用語**: Cpk、工程能力、標準偏差

**Cpk（Process Capability Index considering process centering）**
- **読み方**: シーピーケー
- **意味**: 偏りを考慮した工程能力指数。工程の中心が規格中心からずれている場合の能力を示す
- **関連用語**: Cp、工程能力

**PDCA**
- **読み方**: ピーディーシーエー
- **意味**: Plan（計画）、Do（実行）、Check（評価）、Act（改善）の管理サイクル
- **関連用語**: PDCA サイクル、継続的改善

**QC（Quality Control）**
- **読み方**: キューシー
- **意味**: 品質管理。製品やサービスの品質を維持・向上させるための活動
- **関連用語**: QC7つ道具、品質保証

**UCL/LCL（Upper/Lower Control Limit）**
- **読み方**: ユーシーエル/エルシーエル
- **意味**: 管理図における上方/下方管理限界線。工程の統計的管理状態を判定する基準線
- **関連用語**: 管理図、中心線（CL）

### あ行

**異常原因（いじょうげんいん）**
- **意味**: 工程に通常とは異なる変動をもたらす特殊な要因。管理図で検出される
- **関連用語**: 共通原因、管理図

### か行

**管理限界（かんりげんかい）**
- **意味**: 管理図において、工程が統計的管理状態にあるかを判定する境界線
- **関連用語**: UCL、LCL、管理図

**管理図（かんりず）**
- **意味**: 工程の安定性を時系列で監視するためのグラフ。QC7つ道具の一つ
- **関連用語**: X̄-R管理図、管理限界

**工程能力（こうていのうりょく）**
- **意味**: 工程が規格を満足する製品を作る能力の程度
- **関連用語**: Cp、Cpk、工程能力指数

### さ行

**散布図（さんぷず）**
- **意味**: 2つの変数間の関係を点のプロットで表したグラフ。相関関係の分析に使用
- **関連用語**: 相関係数、回帰分析

**層別（そうべつ）**
- **意味**: データを特定の観点で分類し、グループ別に分析する手法
- **関連用語**: 4M、要因分析

### た行

**チェックシート（ちぇっくしーと）**
- **意味**: データを効率的に収集・記録するための様式化された記録用紙
- **関連用語**: データ収集、記録

**特性要因図（とくせいよういんず）**
- **意味**: 問題（特性）とその要因の関係を魚の骨のような形で表した図。石川ダイアグラムとも呼ばれる
- **関連用語**: 4M、要因分析、フィッシュボーン図

### は行

**パレート図（ぱれーとず）**
- **意味**: 項目別の数値を大きい順に並べた棒グラフと累積比率の折れ線グラフを組み合わせた図
- **関連用語**: 80-20の法則、重点管理

**ヒストグラム（ひすとぐらむ）**
- **意味**: データの分布状態を柱状グラフで表したもの。度数分布図とも呼ばれる
- **関連用語**: 正規分布、工程能力

**標準偏差（ひょうじゅんへんさ）**
- **意味**: データのばらつきの程度を表す統計量。記号σ（シグマ）で表される
- **関連用語**: 分散、正規分布

### ま行

**見える化（みえるか）**
- **意味**: 問題や状況を誰でも理解できるよう視覚的に表現すること
- **関連用語**: 可視化、QC7つ道具

### ら行

**連（れん）**
- **意味**: 管理図において、点が中心線の片側に連続して現れる現象。異常の兆候
- **関連用語**: 管理図、異常判定ルール

---

**専門用語集作成時の注意点:**
- QC7つ道具で使用される統計用語は正確に定義
- 現場で使われる実務的な意味も含めて説明
- JIS規格での定義がある場合は準拠
- 関連する手法や概念との関係を明記
