# 補充点方式について

## 概要
補充点方式は、在庫管理における重要な手法の一つで、在庫量がある一定の水準（補充点）に達したときに発注を行う方式です。この方式は、適切な在庫水準を維持しながら、在庫切れや過剰在庫を防ぐことを目的としています。本資料では、発注点補充点方式、定期補充点方式、定期発注点補充点方式の3つの主要な方式について詳しく解説します。

## 1. 基本概念・定義

補充点方式とは、在庫管理において在庫量が一定の水準（補充点）に達したときに、あらかじめ決められた量を発注する在庫管理手法です。

### 補充点の設定要素
- **定義**: 発注を行うべき在庫水準
- **特徴**: 需要量、リードタイム、安全在庫を考慮して設定
- **重要性**: 適切な設定により在庫切れリスクと在庫コストのバランスを取る

### 発注量の決定要素
- **定義**: 発注時に手配する商品の数量
- **特徴**: 経済的発注量（EOQ）などを考慮して設定
- **重要性**: 発注コストと在庫保管コストの最適化

## 2. 補充点方式の分類

### 分類基準
補充点方式は、発注タイミングの決め方と発注量の決め方によって分類されます。

### 発注点補充点方式（定量発注方式）
| 項目 | 内容 |
|------|------|
| 特徴 | 在庫量が発注点に達したら、一定量を発注する |
| 適用範囲 | 需要が比較的安定している商品、高価値商品 |
| 注意点 | 常時在庫監視が必要、発注頻度が不規則になる |

### 定期補充点方式（定期発注方式）
| 項目 | 内容 |
|------|------|
| 特徴 | 一定期間ごとに在庫を確認し、補充点まで発注する |
| 適用範囲 | 複数商品の同時発注、需要変動がある商品 |
| 注意点 | 発注サイクル間の需要変動への対応が必要 |

### 定期発注点補充点方式（ハイブリッド方式）
| 項目 | 内容 |
|------|------|
| 特徴 | 定期的な発注と緊急時の発注を組み合わせる |
| 適用範囲 | 重要度の高い商品、需要変動が大きい商品 |
| 注意点 | 管理が複雑になる、両方式の利点を活かす設計が必要 |

## 3. 具体的計算例・事例

### ケース1: 発注点補充点方式の計算

#### パターンA: 標準的な商品の場合
- **前提条件**: 
  - 1日平均需要量：100個
  - リードタイム：5日
  - 安全在庫：200個
  - 経済的発注量：1,000個

- **計算過程**: 
  - 発注点 = （平均需要量 × リードタイム）+ 安全在庫
  - 発注点 = （100個 × 5日）+ 200個 = 700個

- **結果**: 在庫が700個になったら1,000個発注する

#### パターンB: 需要変動が大きい商品の場合
- **前提条件**: 
  - 1日平均需要量：100個（標準偏差30個）
  - リードタイム：5日
  - サービス率：95%（安全係数1.65）
  - 経済的発注量：1,500個

- **計算過程**: 
  - リードタイム中の需要の標準偏差 = 30個 × √5 = 67.08個
  - 安全在庫 = 1.65 × 67.08個 = 110.68個 ≈ 111個
  - 発注点 = （100個 × 5日）+ 111個 = 611個

- **結果**: 在庫が611個になったら1,500個発注する

### ケース2: 定期補充点方式の計算

#### パターンA: 週次発注の場合
- **前提条件**: 
  - 1日平均需要量：50個
  - 発注サイクル：7日
  - リードタイム：3日
  - 安全在庫：150個

- **計算過程**: 
  - 補充点 = （発注サイクル + リードタイム）× 平均需要量 + 安全在庫
  - 補充点 = （7日 + 3日）× 50個 + 150個 = 650個
  - 発注量 = 補充点 - 現在在庫量

- **結果**: 
  - 現在在庫が200個の場合：650個 - 200個 = 450個発注
  - 現在在庫が400個の場合：650個 - 400個 = 250個発注

#### パターンB: 月次発注の場合
- **前提条件**: 
  - 1日平均需要量：20個
  - 発注サイクル：30日
  - リードタイム：7日
  - 安全在庫：100個

- **計算過程**: 
  - 補充点 = （30日 + 7日）× 20個 + 100個 = 840個
  - 発注量 = 補充点 - 現在在庫量

- **結果**: 月末在庫が300個の場合、540個発注する

### ケース3: 定期発注点補充点方式の計算

- **前提条件**: 
  - 1日平均需要量：80個
  - 定期発注サイクル：14日
  - 緊急発注点：300個
  - リードタイム：4日
  - 安全在庫：200個

- **計算過程**: 
  - 定期発注時の補充点 = （14日 + 4日）× 80個 + 200個 = 1,640個
  - 緊急発注点 = （80個 × 4日）+ 200個 = 520個

- **結果**: 
  - 定期発注日：在庫を1,640個まで補充
  - 定期発注日以外：在庫が520個を下回ったら緊急発注

## 4. 手続き・プロセス

### 発注点補充点方式の運用手順
1. **ステップ1**: 発注点の設定
   - 需要予測データの収集
   - リードタイムの確認
   - 安全在庫の計算

2. **ステップ2**: 在庫監視
   - 在庫管理システムでの常時監視
   - 発注点到達のアラート設定
   - 日次在庫確認の実施

3. **ステップ3**: 発注実行
   - 発注点到達時の自動発注
   - 発注書の作成と承認
   - サプライヤーへの発注送信

### 定期補充点方式の運用手順
1. **ステップ1**: 発注サイクルの決定
   - 商品特性の分析
   - 物流効率の検討
   - コスト最適化の計算

2. **ステップ2**: 定期在庫確認
   - 発注日の在庫棚卸し
   - システムでの在庫データ確認
   - 補充必要量の計算

3. **ステップ3**: 発注量決定と実行
   - 補充点までの必要量算出
   - 複数商品の同時発注調整
   - 発注の実行と確認

## 5. 実務上の注意点

### 方式選択の重要ポイント
- **ポイント1**: 商品特性（価値、需要変動、保管コスト）を考慮した方式選択
- **ポイント2**: システム化レベルに応じた運用方法の決定
- **ポイント3**: サプライヤーとの協力体制構築

### よくある誤解・トラブル
- **誤解1**: 発注点に余裕を持たせすぎて過剰在庫になる
  - 正しい理解：適切な安全在庫の計算が重要
- **誤解2**: 定期発注は管理が楽だが在庫切れリスクが高い
  - 正しい理解：適切な補充点設定により在庫切れは防げる

## 6. よくある質問（Q&A）

### Q1. 発注点補充点方式と定期補充点方式のどちらを選ぶべきか？

**A1.** 商品特性と管理体制によって選択します。

#### 選択基準の詳細
- **発注点補充点方式が適している場合**：
  - 高価値商品で在庫コストが高い
  - 需要が比較的安定している
  - 在庫管理システムが整備されている

- **定期補充点方式が適している場合**：
  - 複数商品をまとめて発注したい
  - 物流コストを削減したい
  - 在庫管理の作業負荷を平準化したい

### Q2. 安全在庫はどのように設定すればよいか？

**A2.** 需要の変動性とサービスレベルから統計的に算出します。

#### 安全在庫の計算方法
- **基本式**：安全在庫 = 安全係数 × √リードタイム × 需要の標準偏差
- **サービスレベル別安全係数**：
  - 90%：1.28
  - 95%：1.65
  - 99%：2.33

### Q3. 定期発注点補充点方式はどのような場合に有効か？

**A3.** 重要商品で在庫切れを絶対に避けたい場合に有効です。

#### 適用例
- 医療機関での重要医薬品
- 製造業での基幹部品
- 小売業での売れ筋商品

## 7. まとめ・今後の展望

補充点方式は、在庫管理の基本的かつ重要な手法として、多くの企業で活用されています。今後は、AIやIoT技術の発展により、より精度の高い需要予測と自動発注システムの導入が進むと予想されます。また、サプライチェーン全体での在庫最適化を目指すVMI（Vendor Managed Inventory）との連携も重要になってきています。

- B) 在庫が一定水準に達したら一定量を発注する
- C) 毎日同じ量を発注する
- D) 月末に一括して発注する

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
発注点補充点方式は、在庫量が発注点に達したときに、あらかじめ決められた一定量（経済的発注量など）を発注する方式です。<br>
<br>

<br>
【補足】実務では、在庫管理システムにより自動的に発注点到達を検知し、発注処理を行います。

<summary>解答</summary>
<strong>正解: B</strong><br>

<br>
Aが間違いの理由：発注サイクルが考慮されていません<br>
Cが間違いの理由：経済的発注量は発注量の決定に使用され、補充点の計算には使いません<br>
Dが間違いの理由：これは発注量の計算式の一部であり、補充点の定義ではありません<br>
<br>
【補足】この計算により、次回発注時までの在庫切れリスクを最小化できます。
</details>

- B) 月間需要量、輸送費用、人件費

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
EOQは、発注費用と在庫保管費用の合計を最小化する発注量で、年間需要量、1回あたり発注費用、単位あたり在庫保管費用から計算されます。<br>

Dが間違いの理由：これらは在庫水準の指標であり、EOQの計算要素ではありません<br>
<br>

週次の定期補充点方式で、平均日需要50個、発注サイクル7日、リードタイム3日、安全在庫100個の場合、補充点はいくらか？

- B) 450個
- C) 500個
- D) 600個

<details>
<summary>解答</summary>
<strong>正解: D</strong><br>
補充点 = （発注サイクル + リードタイム）× 平均日需要 + 安全在庫<br>
補充点 = （7日 + 3日）× 50個 + 100個 = 10日 × 50個 + 100個 = 500個 + 100個 = 600個<br>

- 補充点 = 500個 + 100個（安全在庫）= 600個<br>

## 9. 専門用語集

### あ行
**安全在庫（あんぜんざいこ）**
- **読み方**: あんぜんざいこ
- **意味**: 需要変動やリードタイムの不確実性に対応するために保有する余分な在庫。欠品を防ぐためのバッファー在庫。
- **関連用語**: サービスレベル、安全係数

**安全係数（あんぜんけいすう）**
- **読み方**: あんぜんけいすう
- **意味**: 安全在庫を計算する際に使用する統計的な係数。要求されるサービスレベルに応じて決まる。
- **関連用語**: 安全在庫、サービスレベル、標準偏差

### か行
**経済的発注量（けいざいてきはっちゅうりょう）**
- **読み方**: けいざいてきはっちゅうりょう
- **意味**: EOQ（Economic Order Quantity）とも呼ばれ、発注費用と在庫保管費用の合計を最小化する最適な発注量。
- **関連用語**: 発注費用、在庫保管費用、発注点

### さ行
**在庫回転率（ざいこかいてんりつ）**
- **読み方**: ざいこかいてんりつ
- **意味**: 一定期間に在庫が何回転したかを示す指標。年間売上原価÷平均在庫金額で計算される。
- **関連用語**: 在庫回転日数、平均在庫

**サービスレベル（さーびすれべる）**
- **読み方**: さーびすれべる
- **意味**: 在庫切れを起こさない確率。通常90%、95%、99%などの水準で設定される。
- **関連用語**: 安全在庫、安全係数

### た行
**定期発注点補充点方式（ていきはっちゅうてんほじゅうてんほうしき）**
- **読み方**: ていきはっちゅうてんほじゅうてんほうしき
- **意味**: 定期的な発注と緊急時の発注を組み合わせたハイブリッド型の在庫管理方式。
- **関連用語**: 発注点補充点方式、定期補充点方式

**定期補充点方式（ていきほじゅうてんほうしき）**
- **読み方**: ていきほじゅうてんほうしき
- **意味**: 一定期間ごとに在庫を確認し、設定した補充点まで発注する方式。定期発注方式とも呼ばれる。
- **関連用語**: 発注サイクル、補充点

**定量発注方式（ていりょうはっちゅうほうしき）**
- **読み方**: ていりょうはっちゅうほうしき
- **意味**: 発注点補充点方式の別名。在庫が発注点に達したら一定量を発注する方式。
- **関連用語**: 発注点補充点方式、経済的発注量

### は行
**発注サイクル（はっちゅうさいくる）**
- **読み方**: はっちゅうさいくる
- **意味**: 定期補充点方式において、発注を行う間隔（週次、月次など）。
- **関連用語**: 定期補充点方式、リードタイム

**発注点（はっちゅうてん）**
- **読み方**: はっちゅうてん
- **意味**: 発注を行うべき在庫水準。この水準に達したら発注を開始する。
- **関連用語**: 補充点、安全在庫、リードタイム

**発注点補充点方式（はっちゅうてんほじゅうてんほうしき）**
- **読み方**: はっちゅうてんほじゅうてんほうしき
- **意味**: 在庫量が発注点に達したら一定量を発注する在庫管理方式。定量発注方式とも呼ばれる。
- **関連用語**: 発注点、経済的発注量、定量発注方式

**発注費用（はっちゅうひよう）**
- **読み方**: はっちゅうひよう
- **意味**: 1回の発注にかかる固定的な費用。発注処理、検品、運送手配などの費用を含む。
- **関連用語**: 経済的発注量、在庫保管費用

**標準偏差（ひょうじゅんへんさ）**
- **読み方**: ひょうじゅんへんさ
- **意味**: データのばらつきを表す統計的指標。需要変動の大きさを測定する際に使用。
- **関連用語**: 安全在庫、変動係数

**補充点（ほじゅうてん）**
- **読み方**: ほじゅうてん
- **意味**: 在庫を補充すべき目標水準。定期補充点方式では、この水準まで在庫を補充する。
- **関連用語**: 発注点、安全在庫、最大在庫量

### ま行
**見込み生産（みこみせいさん）**
- **読み方**: みこみせいさん
- **意味**: 需要予測に基づいて事前に生産し在庫として保有する生産方式。
- **関連用語**: 受注生産、在庫管理

### ら行
**リードタイム（りーどたいむ）**
- **読み方**: りーどたいむ
- **意味**: 発注してから商品が納入されるまでの期間。調達期間とも呼ばれる。
- **関連用語**: 発注点、安全在庫

### アルファベット
**ABC分析（えーびーしーぶんせき）**
- **読み方**: えーびーしーぶんせき
- **意味**: 商品を売上高や利益貢献度により重要度別にA、B、Cに分類する手法。
- **関連用語**: パレート分析、在庫管理

**EOQ（Economic Order Quantity）**
- **読み方**: いーおーきゅー
- **意味**: 経済的発注量。発注費用と在庫保管費用の合計を最小化する最適な発注量。
- **関連用語**: 発注費用、在庫保管費用、ウィルソンの公式

**JIT（Just In Time）**
- **読み方**: じゃすといんたいむ
- **意味**: 必要なものを、必要な時に、必要な量だけ生産・調達する方式。
- **関連用語**: かんばん方式、リーン生産

**VMI（Vendor Managed Inventory）**
- **読み方**: ぶいえむあい
- **意味**: サプライヤーが顧客の在庫を管理し、補充の責任を持つ在庫管理方式。
- **関連用語**: サプライチェーン管理、補充点方式
