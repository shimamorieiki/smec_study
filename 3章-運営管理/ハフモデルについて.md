# ハフモデルについて

## 概要
ハフモデル（Huff Model）は、1963年にデビッド・L・ハフ（David L. Huff）によって提案された、小売店舗の商圏分析と顧客吸引力を予測するための確率的重力モデルです。消費者が複数の店舗から特定の店舗を選択する確率を、店舗の魅力度（売場面積など）と店舗までの距離を基に算出します。このモデルは、新規出店計画、既存店舗の売上予測、競合店の影響分析など、小売業の立地戦略において広く活用されています。

## 1. 基本概念・仕組み

### ハフモデルの核となる概念
- **定義**: 消費者が特定の店舗を選択する確率を、店舗の魅力度と距離の関数として表現する空間相互作用モデル
- **動作原理**: 店舗の魅力度に比例し、距離に反比例する形で顧客吸引力を計算
- **特徴**: 確率的アプローチにより、消費者行動の不確実性を考慮した現実的な予測が可能

### 基本公式
ハフモデルの基本公式は以下の通りです：

```
Pij = (Sj^α / Tij^β) / Σ(Sk^α / Tik^β)
```

ここで：
- **Pij**: 地点iの消費者が店舗jを選択する確率
- **Sj**: 店舗jの魅力度（通常は売場面積）
- **Tij**: 地点iから店舗jまでの距離（または時間）
- **α**: 魅力度パラメータ（通常1.0）
- **β**: 距離抵抗パラメータ（業態により異なる、通常1.5～3.0）
- **k**: 競合店舗を含むすべての店舗

### 関連モデルとの関係
- **従来の商圏分析との違い**: ライリーの法則やコンバースの分岐点公式が決定論的であるのに対し、ハフモデルは確率論的アプローチを採用
- **改善点**: 複数店舗の同時評価が可能で、部分的な顧客流出入を表現できる
- **限界**: パラメータの設定が経験的であり、地域特性や業態により調整が必要

## 2. パラメータの種類と特性

### 魅力度パラメータ（α）
**特徴:**
- 店舗の魅力度が顧客吸引力に与える影響の強さを表す
- 通常は1.0に設定されるが、業態により0.5～2.0の範囲で調整
- 値が大きいほど、魅力度の差が顧客選択に強く影響

**業態別の典型的な値:**
```
総合スーパー: α = 1.0～1.2
専門店: α = 0.8～1.0
コンビニエンスストア: α = 0.5～0.7
```

### 距離抵抗パラメータ（β）
**特徴:**
- 距離が顧客の店舗選択に与える負の影響の強さを表す
- 業態により大きく異なり、1.5～3.0の範囲が一般的
- 値が大きいほど、近距離の店舗が選択されやすい

**業態別の典型的な値:**
```
コンビニエンスストア: β = 2.5～3.0
食品スーパー: β = 2.0～2.5
総合スーパー: β = 1.5～2.0
専門店（高級品）: β = 1.0～1.5
```

## 3. 具体的計算例・事例

### ケース1: 新規スーパーマーケットの出店計画

#### 設定条件
ある住宅地（地点A）から、既存店舗2店と新規出店候補店舗1店への顧客流出率を計算します。

**既存店舗データ:**
- 店舗1: 売場面積 2,000㎡、距離 2.0km
- 店舗2: 売場面積 1,500㎡、距離 3.0km
- 新規店舗（計画）: 売場面積 2,500㎡、距離 1.5km

**パラメータ設定:**
- α = 1.0（標準的な魅力度パラメータ）
- β = 2.0（食品スーパーの標準的な距離抵抗）

#### 計算過程

**ステップ1: 各店舗の吸引力を計算**
```
店舗1の吸引力 = 2000^1.0 / 2.0^2.0 = 2000 / 4.0 = 500
店舗2の吸引力 = 1500^1.0 / 3.0^2.0 = 1500 / 9.0 = 166.67
新規店舗の吸引力 = 2500^1.0 / 1.5^2.0 = 2500 / 2.25 = 1111.11
```

**ステップ2: 吸引力の合計を計算**
```
吸引力合計 = 500 + 166.67 + 1111.11 = 1777.78
```

**ステップ3: 各店舗の選択確率を計算**
```
店舗1の選択確率 = 500 / 1777.78 = 0.281 (28.1%)
店舗2の選択確率 = 166.67 / 1777.78 = 0.094 (9.4%)
新規店舗の選択確率 = 1111.11 / 1777.78 = 0.625 (62.5%)
```

**結果: 地点Aの顧客の62.5%が新規店舗を選択すると予測される**

💡 **実際の現場では**: この結果を基に、商圏内の複数地点で同様の計算を行い、全体の来店客数や売上高を予測します。

### ケース2: 競合店出店の影響分析

#### 設定条件
既存店舗の商圏内に競合店が出店した場合の顧客流出を分析します。

**出店前の状況:**
- 自店舗: 売場面積 3,000㎡、各地点からの平均距離 2.5km
- 既存競合店: 売場面積 2,000㎡、各地点からの平均距離 4.0km

**出店後の状況:**
- 新規競合店: 売場面積 2,500㎡、各地点からの平均距離 2.0km

**パラメータ設定:**
- α = 1.0、β = 2.0

#### 計算過程

**出店前の自店舗シェア:**
```
自店舗の吸引力 = 3000 / 2.5^2 = 480
既存競合店の吸引力 = 2000 / 4.0^2 = 125
合計吸引力 = 480 + 125 = 605
自店舗シェア = 480 / 605 = 0.793 (79.3%)
```

**出店後の自店舗シェア:**
```
自店舗の吸引力 = 3000 / 2.5^2 = 480
既存競合店の吸引力 = 2000 / 4.0^2 = 125
新規競合店の吸引力 = 2500 / 2.0^2 = 625
合計吸引力 = 480 + 125 + 625 = 1230
自店舗シェア = 480 / 1230 = 0.390 (39.0%)
```

**結果: 競合店出店により、自店舗のシェアは79.3%から39.0%へ、40.3ポイント低下すると予測される**

## 4. 実装例・適用事例

### 基本的な実装（Python）
```python
import numpy as np

def huff_model(stores, customer_location, alpha=1.0, beta=2.0):
    """
    ハフモデルによる店舗選択確率の計算
    
    Parameters:
    stores: 店舗データのリスト [(面積, x座標, y座標), ...]
    customer_location: 顧客の位置 (x, y)
    alpha: 魅力度パラメータ
    beta: 距離抵抗パラメータ
    
    Returns:
    probabilities: 各店舗の選択確率のリスト
    """
    attractions = []
    
    for store in stores:
        area, store_x, store_y = store
        # 距離の計算（ユークリッド距離）
        distance = np.sqrt((customer_location[0] - store_x)**2 + 
                          (customer_location[1] - store_y)**2)
        # 吸引力の計算
        if distance > 0:
            attraction = (area ** alpha) / (distance ** beta)
        else:
            attraction = float('inf')  # 距離0の場合は無限大
        attractions.append(attraction)
    
    # 確率の計算
    total_attraction = sum(attractions)
    probabilities = [att / total_attraction for att in attractions]
    
    return probabilities

# 使用例
stores = [
    (2000, 1, 2),   # 店舗1: 面積2000㎡、位置(1,2)
    (1500, 3, 1),   # 店舗2: 面積1500㎡、位置(3,1)
    (2500, 2, 3)    # 店舗3: 面積2500㎡、位置(2,3)
]
customer = (0, 0)   # 顧客の位置

probabilities = huff_model(stores, customer)
for i, prob in enumerate(probabilities):
    print(f"店舗{i+1}の選択確率: {prob:.3f} ({prob*100:.1f}%)")
```

### 実際の適用事例

#### 事例1: イオンリテール株式会社
- **課題**: 新規ショッピングセンター開発における最適立地の選定
- **適用方法**: ハフモデルを用いて候補地の商圏人口と競合影響を分析
- **結果**: 3候補地から最適地を選定し、計画通りの集客を達成
- **効果**: 出店後1年で予測値の95%の来店客数を記録

#### 事例2: セブン-イレブン・ジャパン
- **課題**: 高密度出店戦略における自店競合の最小化
- **適用方法**: 修正ハフモデルを用いて既存店への影響を評価
- **結果**: 自店競合を最小限に抑えながら商圏カバー率を向上
- **効果**: ドミナント戦略により地域シェア40%を達成

## 5. メリット・デメリット

### メリット

**1. 確率的予測による現実的な分析**
- **理由**: 消費者行動の不確実性を考慮
- **効果**: 0か100かではない、部分的な顧客流動を表現可能
- **具体例**: 実際の消費者は複数店舗を使い分けており、その行動パターンを反映できる

**2. 複数店舗の同時評価**
- **理由**: すべての競合店を含めた総合的な分析が可能
- **効果**: 新規出店や競合出店の影響を定量的に把握
- **具体例**: 5店舗が競合する地域での各店舗のシェア変化を一度に計算可能

**3. パラメータ調整による柔軟な対応**
- **理由**: 業態や地域特性に応じてパラメータを調整可能
- **効果**: 様々な小売業態に適用できる汎用性
- **具体例**: コンビニはβ=3.0、大型SCはβ=1.5など業態別に設定

### デメリット

**1. パラメータ設定の経験依存性**
- **理由**: 最適なα、βの値は試行錯誤で決定する必要がある
- **影響**: 不適切なパラメータ設定により予測精度が低下
- **対策**: 過去データによる検証とパラメータの継続的な調整

**2. 魅力度指標の単純化**
- **理由**: 通常は売場面積のみを魅力度として使用
- **影響**: 価格、品揃え、サービス等の要因を考慮できない
- **対策**: 複合的な魅力度指標の開発や、修正ハフモデルの適用

**3. 交通手段の考慮不足**
- **理由**: 単純な直線距離や道路距離のみを使用
- **影響**: 公共交通機関の有無や道路事情を反映できない
- **対策**: アクセシビリティ指標の導入や時間距離の採用

### 問題6
ある地点から店舗Aまで2km、店舗Bまで4kmの距離がある。両店舗の売場面積が同じ場合、β=2.0のとき店舗Aの選択確率は？

- A) 50%
- B) 60%
- C) 70%
- D) 80%

<details>
<summary>解答</summary>
<strong>正解: D</strong><br>
計算過程：<br>
店舗Aの吸引力 = S / 2^2 = S / 4<br>
店舗Bの吸引力 = S / 4^2 = S / 16<br>
合計吸引力 = S/4 + S/16 = 4S/16 + S/16 = 5S/16<br>
店舗Aの選択確率 = (S/4) / (5S/16) = (S/4) × (16/5S) = 16/20 = 0.8 (80%)<br>
<br>
【補足】距離が2倍になると、β=2.0の場合、吸引力は1/4になります。
</details>

**ドミナント戦略**
- **読み方**: どみなんとせんりゃく
- **意味**: 特定地域に集中的に店舗を出店し、高いシェアを獲得する戦略。コンビニエンスストアでよく採用される
- **関連用語**: 高密度出店、市場シェア

### は行

**ハフモデル**
- **読み方**: はふもでる
- **意味**: David L. Huffが1963年に提案した、消費者の店舗選択確率を予測する空間相互作用モデル
- **関連用語**: 空間相互作用モデル、商圏分析

**パラメータ**
- **読み方**: ぱらめーた
- **意味**: モデルの動作を制御する変数。ハフモデルではα（魅力度パラメータ）とβ（距離抵抗パラメータ）が主要なパラメータ
- **関連用語**: 魅力度パラメータ、距離抵抗パラメータ

### ま行

**魅力度**
- **読み方**: みりょくど
- **意味**: 店舗が顧客を引きつける力の大きさ。ハフモデルでは主に売場面積で表現されるが、品揃えや価格なども含む場合がある
- **関連用語**: 売場面積、魅力度パラメータ

**魅力度パラメータ（α）**
- **読み方**: みりょくどぱらめーた
- **意味**: ハフモデルにおいて、店舗の魅力度が顧客吸引力に与える影響の強さを表す指数
- **関連用語**: 魅力度、パラメータ

### ら行

**ライリーの法則**
- **読み方**: らいりーのほうそく
- **意味**: William J. Reillyが1931年に提案した、2都市間の商圏境界を決定する法則。小売引力の法則とも呼ばれる
- **関連用語**: コンバースの分岐点公式、決定論的モデル

**立地分析**
- **読み方**: りっちぶんせき
- **意味**: 店舗の出店場所を評価・選定するための分析。商圏分析、競合分析、売上予測などを含む総合的な評価
- **関連用語**: 商圏分析、出店計画
