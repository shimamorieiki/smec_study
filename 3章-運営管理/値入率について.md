# 値入率について

## 概要

値入率（ねいれりつ）は、小売業や流通業において商品の販売価格と仕入価格の関係を表す重要な経営指標です。商品に対してどれだけの利益を上乗せして販売するかを示し、企業の収益性を左右する重要な要素となります。値入率を適切に設定・管理することで、企業は競争力を維持しながら適正な利益を確保することができます。

本資料では、値入の基本概念から売価値入率、原価値入率の詳細な計算方法まで、実務で必要となる知識を体系的にまとめています。

## 1. 値入（ねいれ）の基本概念

### 値入とは

値入（ねいれ）とは、商品の仕入原価に対して販売価格を設定する際に上乗せする金額のことです。つまり、販売価格と仕入原価の差額を指します。

- **値入額** = 販売価格 - 仕入原価
- **目的**: 企業の利益確保、諸経費のカバー、適正な価格設定

### 値入の重要性

1. **利益の源泉**: 値入は企業の粗利益となり、経営の基盤となる
2. **価格競争力**: 適切な値入により市場での競争力を維持
3. **経費カバー**: 人件費、家賃、光熱費などの諸経費を賄う
4. **在庫リスク対応**: 売れ残りや値下げリスクに対応する余裕を確保

### 値入に影響する要因

- **市場環境**: 競合他社の価格、需要と供給のバランス
- **商品特性**: 商品の付加価値、ブランド力、季節性
- **コスト構造**: 仕入原価、物流費、人件費などの諸経費
- **経営戦略**: 薄利多売か高付加価値戦略か

## 2. 売価値入率（ばいかねいれりつ）

### 売価値入率の定義

売価値入率とは、販売価格に対する値入額の割合を示す指標です。販売価格を基準（100%）として、そのうち何パーセントが値入（粗利益）となるかを表します。

### 売価値入率の計算式

```
売価値入率（%） = (値入額 ÷ 販売価格) × 100
            = ((販売価格 - 仕入原価) ÷ 販売価格) × 100
```

### 売価値入率の特徴

1. **販売価格基準**: 販売価格を100%として計算
2. **粗利益率と同義**: 売価値入率は粗利益率と同じ概念
3. **経営分析での活用**: 収益性分析で頻繁に使用される
4. **業界比較**: 同業他社との収益性比較に適している

### 売価値入率の計算例

#### 例1: 基本的な計算

- **仕入原価**: 6,000円
- **販売価格**: 10,000円
- **値入額**: 10,000円 - 6,000円 = 4,000円

```
売価値入率 = (4,000円 ÷ 10,000円) × 100 = 40%
```

#### 例2: 実務での応用

ある衣料品店で、仕入原価3,500円のシャツを5,800円で販売する場合：

- **値入額**: 5,800円 - 3,500円 = 2,300円
- **売価値入率**: (2,300円 ÷ 5,800円) × 100 = 39.66%

この場合、販売価格の約40%が粗利益となることを意味します。

#### 例3: 複数商品の平均売価値入率

| 商品 | 仕入原価 | 販売価格 | 値入額 | 売価値入率 |
|------|---------|---------|--------|-----------|
| 商品A | 2,000円 | 3,000円 | 1,000円 | 33.33% |
| 商品B | 5,000円 | 8,000円 | 3,000円 | 37.50% |
| 商品C | 8,000円 | 15,000円 | 7,000円 | 46.67% |

### 売価値入率の活用方法

1. **価格設定**: 目標売価値入率から販売価格を逆算
2. **収益管理**: 商品カテゴリー別の収益性分析
3. **値下げ判断**: 値下げしても最低限確保すべき売価値入率の設定
4. **業績評価**: 期間比較や店舗間比較での活用

## 3. 原価値入率（げんかねいれりつ）

### 原価値入率の定義

原価値入率とは、仕入原価に対する値入額の割合を示す指標です。仕入原価を基準（100%）として、それに対して何パーセントの値入（マークアップ）を行うかを表します。

### 原価値入率の計算式

```
原価値入率（%） = (値入額 ÷ 仕入原価) × 100
             = ((販売価格 - 仕入原価) ÷ 仕入原価) × 100
```

### 原価値入率の特徴

1. **仕入原価基準**: 仕入原価を100%として計算
2. **マークアップ率**: 原価に対する上乗せ率を表す
3. **仕入担当者視点**: 仕入れ時の価格設定で使用
4. **売価値入率より高い数値**: 同じ値入でも原価値入率の方が高くなる

### 原価値入率の計算例

#### 例1: 基本的な計算

- **仕入原価**: 6,000円
- **販売価格**: 10,000円
- **値入額**: 10,000円 - 6,000円 = 4,000円

```
原価値入率 = (4,000円 ÷ 6,000円) × 100 = 66.67%
```

#### 例2: 実務での応用

食品スーパーで、仕入原価800円の商品を1,200円で販売する場合：

- **値入額**: 1,200円 - 800円 = 400円
- **原価値入率**: (400円 ÷ 800円) × 100 = 50%

この場合、仕入原価に対して50%の値入を行っていることを意味します。

#### 例3: 原価値入率から販売価格を決定

目標原価値入率80%で、仕入原価2,500円の商品の販売価格を決定する場合：

- **値入額**: 2,500円 × 80% = 2,000円
- **販売価格**: 2,500円 + 2,000円 = 4,500円

### 原価値入率と売価値入率の関係

同じ商品でも、原価値入率と売価値入率は異なる数値になります。

#### 相互変換の公式

```
売価値入率 = 原価値入率 ÷ (100 + 原価値入率) × 100

原価値入率 = 売価値入率 ÷ (100 - 売価値入率) × 100
```

#### 変換例

原価値入率50%の場合の売価値入率：
```
売価値入率 = 50 ÷ (100 + 50) × 100 = 50 ÷ 150 × 100 = 33.33%
```

売価値入率40%の場合の原価値入率：
```
原価値入率 = 40 ÷ (100 - 40) × 100 = 40 ÷ 60 × 100 = 66.67%
```

## 4. 値入率の実務応用

### 業種別の標準的な値入率

| 業種 | 売価値入率の目安 | 原価値入率の目安 |
|------|----------------|----------------|
| 食品スーパー | 20-25% | 25-33% |
| コンビニエンスストア | 25-30% | 33-43% |
| アパレル | 50-60% | 100-150% |
| 家電量販店 | 15-20% | 18-25% |
| 百貨店 | 35-45% | 54-82% |
| 飲食店 | 60-70% | 150-233% |

### 値入率設定の考え方

#### 1. コスト積み上げ方式

```
必要売価値入率 = (諸経費率 + 目標営業利益率) ÷ (1 - ロス率)
```

例：諸経費率30%、目標営業利益率5%、ロス率3%の場合
```
必要売価値入率 = (30% + 5%) ÷ (1 - 0.03) = 35% ÷ 0.97 = 36.08%
```

#### 2. 市場価格基準方式

競合他社の価格を基準に、自社の付加価値を考慮して値入率を調整

#### 3. 商品特性別設定

- **定番商品**: 安定的な値入率設定
- **季節商品**: 需要期は高め、終盤は低めに設定
- **新商品**: 導入期は高め、普及期は調整

### 値下げと値入率の関係

#### 値下げ後の売価値入率計算

元の販売価格10,000円（仕入原価6,000円）を20%値下げした場合：

- **値下げ後の販売価格**: 10,000円 × 0.8 = 8,000円
- **値入額**: 8,000円 - 6,000円 = 2,000円
- **値下げ後の売価値入率**: (2,000円 ÷ 8,000円) × 100 = 25%

元の売価値入率40%から25%に低下

### 複数回転と値入率

商品回転率を考慮した年間粗利益の計算：

```
年間粗利益 = 平均在庫 × 原価値入率 × 年間回転数
```

例：平均在庫1,000万円、原価値入率50%、年間回転数6回
```
年間粗利益 = 1,000万円 × 0.5 × 6 = 3,000万円
```

### 値入率分析の手法

#### 1. ABC分析による管理

売上高構成比でA・B・Cランクに分類し、ランク別に目標値入率を設定

| ランク | 売上構成比 | 管理方針 | 目標売価値入率 |
|--------|-----------|---------|---------------|
| A | 70% | 重点管理 | 35-40% |
| B | 20% | 通常管理 | 40-45% |
| C | 10% | 簡易管理 | 45-50% |

#### 2. 期間比較分析

月次・四半期・年次での値入率推移を分析し、異常値を発見

#### 3. 商品カテゴリー別分析

カテゴリー別の値入率を分析し、収益構造を把握

### 値入率改善の施策

1. **仕入原価の削減**
   - 大量仕入による単価引下げ
   - 仕入先の見直し・交渉
   - PB商品の開発

2. **販売価格の適正化**
   - 価格弾力性を考慮した価格設定
   - 付加価値の向上による価格引上げ
   - 競合分析による価格ポジショニング

3. **商品構成の最適化**
   - 高値入率商品の販売強化
   - 低値入率商品の見直し
   - クロスマーチャンダイジング

4. **ロス率の削減**
   - 廃棄ロスの削減
   - 値下げロスの削減
   - 機会ロスの削減

### システムを活用した値入率管理

#### POSシステムでの管理

- リアルタイムでの値入率把握
- 商品別・時間帯別の分析
- 自動発注との連携

#### 在庫管理システムとの連携

- 適正在庫の維持
- 回転率と値入率の最適化
- 死に筋商品の早期発見

## 6. 計算問題演習

### 問題1: 売価値入率の計算

ある書店で、仕入原価1,200円の本を1,800円で販売している。この時の売価値入率を求めなさい。

**解答**
- 値入額 = 1,800円 - 1,200円 = 600円
- 売価値入率 = (600円 ÷ 1,800円) × 100 = 33.33%

### 問題2: 原価値入率の計算

仕入原価4,000円の商品に対して、原価値入率60%で価格設定する場合、販売価格はいくらになるか。

**解答**
- 値入額 = 4,000円 × 60% = 2,400円
- 販売価格 = 4,000円 + 2,400円 = 6,400円

### 問題3: 値入率の相互変換

売価値入率が25%の時、原価値入率は何%になるか。

**解答**
- 原価値入率 = 25 ÷ (100 - 25) × 100 = 25 ÷ 75 × 100 = 33.33%

### 問題4: 値下げ後の値入率

仕入原価5,000円、当初販売価格8,000円の商品を30%値下げした。値下げ後の売価値入率を求めなさい。

**解答**
- 値下げ後の販売価格 = 8,000円 × 0.7 = 5,600円
- 値入額 = 5,600円 - 5,000円 = 600円
- 売価値入率 = (600円 ÷ 5,600円) × 100 = 10.71%

### 問題5: 目標粗利益からの価格設定

月間売上目標1,000万円、目標粗利益額350万円の場合、必要な平均売価値入率は何%か。

**解答**
- 必要売価値入率 = (350万円 ÷ 1,000万円) × 100 = 35%

### 問題6: 複数商品の加重平均値入率

以下の3商品の売上高加重平均売価値入率を求めなさい。

| 商品 | 売上高 | 売価値入率 |
|------|--------|-----------|
| A | 500万円 | 30% |
| B | 300万円 | 40% |
| C | 200万円 | 25% |

**解答**
- 合計売上高 = 500 + 300 + 200 = 1,000万円
- 加重平均 = (500×30% + 300×40% + 200×25%) ÷ 1,000
- = (150 + 120 + 50) ÷ 1,000 = 320 ÷ 1,000 = 32%

### 問題7: 必要販売数量の計算

仕入原価2,000円の商品を売価値入率40%で販売し、月間100万円の粗利益を確保したい。必要な販売数量を求めなさい。

**解答**
- 販売価格 = 2,000円 ÷ (1 - 0.4) = 2,000円 ÷ 0.6 = 3,333円
- 1個あたり粗利益 = 3,333円 × 0.4 = 1,333円
- 必要販売数量 = 1,000,000円 ÷ 1,333円 = 750個

### 問題8: ロス率を考慮した値入率

ロス率5%を見込んで、最終的に売価値入率30%を確保したい。初期設定すべき売価値入率は何%か。

**解答**
- 必要売価値入率 = 30% ÷ (1 - 0.05) = 30% ÷ 0.95 = 31.58%

## 7. よくある質問（Q&A）

### Q1. 売価値入率と原価値入率、どちらを使うべきですか？

**A1.** 用途によって使い分けることが重要です。

**売価値入率を使う場面：**
- 経営分析や収益性評価を行う時
- 他社との比較を行う時
- 財務諸表との整合性を取る時
- 顧客への価格説明を行う時

**原価値入率を使う場面：**
- 仕入担当者が価格設定を行う時
- 仕入先との交渉を行う時
- 商品の値付け作業を行う時
- マークアップ方式で価格計算する時

実務では両方を理解し、状況に応じて使い分けることが大切です。

### Q2. 値入率が高ければ高いほど良いのでしょうか？

**A2.** 必ずしもそうではありません。

値入率を高く設定することには以下のようなメリット・デメリットがあります：

**メリット：**
- 利益額の増加
- 値下げ余地の確保
- 経営の安定性向上

**デメリット：**
- 価格競争力の低下
- 販売数量の減少リスク
- 在庫回転率の悪化
- 顧客離れのリスク

適正な値入率は、業界特性、商品特性、競合状況、自社の経営戦略などを総合的に考慮して決定する必要があります。

### Q3. 値下げセールを行う際の値入率管理のポイントは？

**A3.** 値下げセールでは以下の点に注意が必要です：

1. **最低値入率の設定**
   - 諸経費をカバーできる最低ラインを明確にする
   - 赤字にならない限界値を把握する

2. **値下げ率と販売数量の関係**
   - 値下げによる販売数量増加を予測
   - 数量増による総利益額を試算

3. **段階的な値下げ**
   - 10% → 20% → 30%と段階的に実施
   - 各段階での売れ行きを確認

4. **値下げ商品の選定**
   - 在庫過多商品を優先
   - 季節商品は早めに値下げ

### Q4. 新商品の値入率はどのように設定すればよいですか？

**A4.** 新商品の値入率設定には戦略的な考慮が必要です：

**導入期の価格戦略：**

1. **スキミング戦略（高値入率）**
   - 革新的な商品
   - ブランド力のある商品
   - 初期は50-60%の高値入率

2. **ペネトレーション戦略（低値入率）**
   - 市場シェア獲得重視
   - 競合商品が多い場合
   - 初期は20-30%の低値入率

3. **段階的調整**
   - 市場の反応を見ながら調整
   - 競合の動向を注視
   - 3-6ヶ月で見直し

### Q5. 値入率と在庫回転率の関係について教えてください。

**A5.** 値入率と在庫回転率は密接な関係があります：

**基本的な関係性：**
- 値入率が高い → 販売価格が高い → 売れ行きが鈍い → 在庫回転率が低下
- 値入率が低い → 販売価格が低い → 売れ行きが良い → 在庫回転率が向上

**最適化の考え方：**
```
年間粗利益額 = 平均在庫高 × 売価値入率 × 在庫回転率
```

例：
- ケース1：値入率40%、回転率6回 → 240%の投資収益率
- ケース2：値入率30%、回転率10回 → 300%の投資収益率

値入率を下げても回転率が大幅に向上すれば、トータルの収益性は向上する可能性があります。

## 9. 専門用語集

### あ行

**値入（ねいれ）**
- **読み方**: ねいれ
- **意味**: 商品の販売価格と仕入原価の差額。企業の粗利益となる部分で、諸経費や純利益の源泉となる。
- **関連用語**: 粗利益、マークアップ、値入率

**値入額（ねいれがく）**
- **読み方**: ねいれがく
- **意味**: 販売価格から仕入原価を差し引いた金額。値入を金額で表したもの。
- **関連用語**: 粗利益額、マージン

**値入率（ねいれりつ）**
- **読み方**: ねいれりつ
- **意味**: 値入額を基準値（販売価格または仕入原価）で割った割合。売価値入率と原価値入率の2種類がある。
- **関連用語**: 売価値入率、原価値入率、粗利益率

**売れ筋商品（うれすじしょうひん）**
- **読み方**: うれすじしょうひん
- **意味**: 売上高や販売数量が多く、在庫回転率の高い商品。一般的に安定した値入率を確保できる。
- **関連用語**: 死に筋商品、定番商品

### か行

**回転率（かいてんりつ）**
- **読み方**: かいてんりつ
- **意味**: 一定期間に在庫が何回入れ替わったかを示す指標。年間売上高を平均在庫高で割って算出する。
- **関連用語**: 在庫回転率、商品回転率

**価格弾力性（かかくだんりょくせい）**
- **読み方**: かかくだんりょくせい
- **意味**: 価格の変化に対する需要量の変化の度合い。価格を下げた時にどの程度売上が増加するかを示す。
- **関連用語**: 需要の価格弾力性

**仕入原価（しいれげんか）**
- **読み方**: しいれげんか
- **意味**: 商品を仕入れる際の取得価格。運送費など付随費用を含む場合もある。
- **関連用語**: 取得原価、仕入値

**粗利益（そりえき）**
- **読み方**: そりえき
- **意味**: 売上高から売上原価を差し引いた利益。値入額の累計に相当する。
- **関連用語**: 売上総利益、グロスマージン

**粗利益率（そりえきりつ）**
- **読み方**: そりえきりつ
- **意味**: 売上高に対する粗利益の割合。売価値入率と同じ概念。
- **関連用語**: 売上総利益率、売価値入率

### さ行

**死に筋商品（しにすじしょうひん）**
- **読み方**: しにすじしょうひん
- **意味**: 売れ行きが悪く、在庫回転率の低い商品。値下げ対象となることが多い。
- **関連用語**: 売れ筋商品、滞留在庫

**スキミング戦略（すきみんぐせんりゃく）**
- **読み方**: すきみんぐせんりゃく
- **意味**: 新商品導入時に高価格（高値入率）を設定し、初期の利益を最大化する価格戦略。
- **関連用語**: ペネトレーション戦略、価格戦略

### た行

**定番商品（ていばんしょうひん）**
- **読み方**: ていばんしょうひん
- **意味**: 年間を通じて安定的に売れる基本的な商品。安定した値入率を設定しやすい。
- **関連用語**: 季節商品、売れ筋商品

### な行

**値下げ（ねさげ）**
- **読み方**: ねさげ
- **意味**: 当初の販売価格から価格を引き下げること。値入率の低下を伴う。
- **関連用語**: マークダウン、見切り

**値下げロス（ねさげろす）**
- **読み方**: ねさげろす
- **意味**: 値下げにより失われる利益。当初の値入額と値下げ後の値入額の差。
- **関連用語**: 廃棄ロス、機会ロス

### は行

**売価値入率（ばいかねいれりつ）**
- **読み方**: ばいかねいれりつ
- **意味**: 販売価格に対する値入額の割合。(値入額÷販売価格)×100で計算する。
- **関連用語**: 原価値入率、粗利益率

**販売価格（はんばいかかく）**
- **読み方**: はんばいかかく
- **意味**: 顧客に対して提示する商品の価格。売価とも呼ばれる。
- **関連用語**: 売価、定価、実売価格

**ペネトレーション戦略（ぺねとれーしょんせんりゃく）**
- **読み方**: ぺねとれーしょんせんりゃく
- **意味**: 新商品導入時に低価格（低値入率）を設定し、市場シェア獲得を優先する価格戦略。
- **関連用語**: スキミング戦略、市場浸透戦略

### ま行

**マークアップ（まーくあっぷ）**
- **読み方**: まーくあっぷ
- **意味**: 仕入原価に対する値入の上乗せ。原価値入率と同じ概念で使われることが多い。
- **関連用語**: 値入、原価値入率

**マークダウン（まーくだうん）**
- **読み方**: まーくだうん
- **意味**: 販売価格の引き下げ。値下げと同義。
- **関連用語**: 値下げ、プライスダウン

**見切り（みきり）**
- **読み方**: みきり
- **意味**: 売れ残り商品を大幅に値下げして在庫処分すること。
- **関連用語**: 値下げ、在庫処分

### ら行

**ロス率（ろすりつ）**
- **読み方**: ろすりつ
- **意味**: 廃棄や値下げなどにより失われる利益の割合。値入率設定時に考慮する必要がある。
- **関連用語**: 廃棄ロス、値下げロス、機会ロス

### アルファベット

**ABC分析（えーびーしーぶんせき）**
- **読み方**: えーびーしーぶんせき
- **意味**: 商品を売上高や利益貢献度でランク分けし、重要度に応じて管理方法を変える分析手法。
- **関連用語**: パレート分析、重点管理

**PB商品（ぴーびーしょうひん）**
- **読み方**: ぴーびーしょうひん
- **意味**: プライベートブランド商品。小売業者が独自に企画・開発した商品で、一般的に高い値入率を確保できる。
- **関連用語**: NB商品（ナショナルブランド）

**POSシステム（ぽすしすてむ）**
- **読み方**: ぽすしすてむ
- **意味**: 販売時点情報管理システム。商品別の売上や値入率をリアルタイムで把握できる。
- **関連用語**: 販売管理システム、在庫管理システム
