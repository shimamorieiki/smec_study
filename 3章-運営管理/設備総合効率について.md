# 設備総合効率について

## 概要
設備総合効率（OEE: Overall Equipment Effectiveness）は、製造業において設備の生産性を総合的に評価する指標です。TPM（Total Productive Maintenance：全員参加の生産保全）の中核的な概念として、設備が持つ潜在能力をどの程度発揮できているかを数値化し、改善の方向性を明確にします。OEEは、設備の稼働状況を3つの観点（時間稼働率、性能稼働率、良品率）から分析し、それぞれの要因による損失（停止ロス、性能ロス、不良ロス）を明らかにすることで、効率的な改善活動を可能にします。

## 1. 基本概念・仕組み

### 設備総合効率（OEE）の定義
- **定義**: 設備の理論的な最大生産能力に対する実際の生産実績の比率
- **動作原理**: 時間稼働率 × 性能稼働率 × 良品率 の3要素の掛け算で算出
- **特徴**: 単一の指標で設備の総合的な効率を評価でき、改善ポイントが明確になる

### 3大ロスとの関係
- **従来の設備管理との違い**: 単純な稼働時間だけでなく、質的な要素も含めて評価
- **改善点**: 隠れた損失を可視化し、体系的な改善活動が可能
- **限界**: 設備以外の要因（人的要因、材料要因など）は直接反映されない

## 2. 3大ロスの詳細

### 停止ロス
**定義:**
設備が計画された稼働時間内に停止することによる生産機会の損失

**種類:**
- **故障停止**: 設備の突発的な故障による停止
- **段取り・調整停止**: 品種切替やセットアップによる停止
- **計画外保全**: 予定外のメンテナンスによる停止

**📊 具体的な計算例**
**例: 自動車部品製造ラインの停止ロス計算**
- 負荷時間: 480分（8時間）
- 故障停止: 30分
- 段取り時間: 60分
- 計画外保全: 10分

**ステップ1: 停止時間の合計**
```
停止時間合計 = 故障停止 + 段取り時間 + 計画外保全
停止時間合計 = 30分 + 60分 + 10分 = 100分
```

**ステップ2: 実稼働時間の算出**
```
実稼働時間 = 負荷時間 - 停止時間合計
実稼働時間 = 480分 - 100分 = 380分
```

**結果: 停止ロスは100分（20.8%）**

💡 **実際の現場では**: 段取り時間の短縮（SMED：シングル段取り）や予防保全の強化により改善

### 性能ロス
**定義:**
設備が稼働しているが、理想的な速度で生産できていないことによる損失

**種類:**
- **速度低下**: 設備の老朽化や調整不良による速度低下
- **空転・小停止**: センサー誤作動や材料詰まりによる短時間停止
- **立ち上がりロス**: 運転開始時の速度が安定するまでの損失

**📊 具体的な計算例**
**例: 包装機械の性能ロス計算**
- 実稼働時間: 380分
- 理論サイクルタイム: 2秒/個
- 実際の生産数: 10,000個

**ステップ1: 理論生産時間の算出**
```
理論生産時間 = 理論サイクルタイム × 実際の生産数
理論生産時間 = 2秒/個 × 10,000個 = 20,000秒 = 333.3分
```

**ステップ2: 性能ロスの算出**
```
性能ロス = 実稼働時間 - 理論生産時間
性能ロス = 380分 - 333.3分 = 46.7分
```

**結果: 性能ロスは46.7分（12.3%）**

💡 **実際の現場では**: 小停止の原因分析と対策、設備の定期的な調整により改善

### 不良ロス
**定義:**
生産した製品のうち、品質基準を満たさない不良品による損失

**種類:**
- **工程不良**: 製造工程で発生する不良品
- **立ち上がり不良**: 運転開始時の条件不安定による不良
- **手直し・再加工**: 修正可能な不良品の再処理時間

**📊 具体的な計算例**
**例: 電子部品製造の不良ロス計算**
- 生産数量: 10,000個
- 不良品数: 200個
- 手直し品数: 50個（1個あたり30秒の追加工数）

**ステップ1: 良品数の算出**
```
良品数 = 生産数量 - 不良品数
良品数 = 10,000個 - 200個 = 9,800個
```

**ステップ2: 手直し時間の算出**
```
手直し時間 = 手直し品数 × 追加工数
手直し時間 = 50個 × 30秒/個 = 1,500秒 = 25分
```

**結果: 不良ロスは200個（2%）+ 手直し時間25分**

💡 **実際の現場では**: 工程能力の向上、作業標準の徹底、品質管理の強化により改善

## 3. OEEの構成要素と計算方法

### 時間稼働率
**意味**: 
計画された稼働時間に対して、実際に設備が稼働した時間の割合

**算出方法:**
```
時間稼働率 = 実稼働時間 ÷ 負荷時間 × 100
```

**📊 具体的な計算例**
**例: プレス機の時間稼働率**
- 負荷時間: 480分
- 停止時間: 100分（故障30分、段取り60分、その他10分）

```
実稼働時間 = 480分 - 100分 = 380分
時間稼働率 = 380分 ÷ 480分 × 100 = 79.2%
```

### 性能稼働率
**意味**: 
実際の生産速度と理論的な最高速度の比率

**算出方法:**
```
性能稼働率 = (理論サイクルタイム × 生産数量) ÷ 実稼働時間 × 100
```

**📊 具体的な計算例**
**例: 射出成形機の性能稼働率**
- 実稼働時間: 380分
- 理論サイクルタイム: 30秒/個
- 実際の生産数: 600個

```
理論生産時間 = 30秒/個 × 600個 = 18,000秒 = 300分
性能稼働率 = 300分 ÷ 380分 × 100 = 78.9%
```

### 良品率
**意味**: 
生産した製品のうち、品質基準を満たした良品の割合

**算出方法:**
```
良品率 = 良品数 ÷ 生産数量 × 100
```

**📊 具体的な計算例**
**例: 組立ラインの良品率**
- 生産数量: 600個
- 不良品数: 12個

```
良品数 = 600個 - 12個 = 588個
良品率 = 588個 ÷ 600個 × 100 = 98.0%
```

## 4. 設備総合効率（OEE）の総合計算

### OEEの算出式
```
OEE = 時間稼働率 × 性能稼働率 × 良品率
```

### 総合的な計算例
**📊 包括的なOEE計算例**
**例: 食品製造ラインの1日のOEE算出**

**基礎データ:**
- 稼働予定時間: 24時間（1,440分）
- 計画停止: 240分（休憩、清掃、点検）
- 負荷時間: 1,200分

**実績データ:**
- 故障による停止: 45分
- 段取り替え: 120分
- 小停止・空転: 実稼働時間内で85分相当の損失
- 理論サイクルタイム: 3秒/個
- 生産数量: 18,000個
- 不良品数: 360個

**ステップ1: 時間稼働率の算出**
```
停止時間合計 = 45分 + 120分 = 165分
実稼働時間 = 1,200分 - 165分 = 1,035分
時間稼働率 = 1,035分 ÷ 1,200分 × 100 = 86.3%
```

**ステップ2: 性能稼働率の算出**
```
理論生産時間 = 3秒/個 × 18,000個 = 54,000秒 = 900分
性能稼働率 = 900分 ÷ 1,035分 × 100 = 87.0%
```

**ステップ3: 良品率の算出**
```
良品数 = 18,000個 - 360個 = 17,640個
良品率 = 17,640個 ÷ 18,000個 × 100 = 98.0%
```

**ステップ4: OEEの算出**
```
OEE = 86.3% × 87.0% × 98.0% = 73.6%
```

💡 **実際の現場では**: 世界クラスのOEEは85%以上とされ、多くの工場では60-70%程度

## 5. メリット・デメリット

### メリット
**1. 総合的な効率評価**
- **理由**: 3つの観点から多角的に評価
- **効果**: 隠れた損失の発見と改善機会の特定
- **具体例**: 稼働率は高いが性能ロスが大きい設備の発見

**2. 改善の優先順位付け**
- **理由**: 各要素の貢献度が明確
- **効果**: 限られたリソースの効果的な配分
- **具体例**: 時間稼働率60%の設備を優先的に改善

**3. 継続的改善の指標**
- **理由**: 定量的な目標設定が可能
- **効果**: PDCAサイクルの効果的な運用
- **具体例**: 月次OEE目標の設定と達成度管理

### デメリット
**1. 過度の効率追求リスク**
- **理由**: 数値改善が目的化する可能性
- **影響**: 品質や安全性の軽視
- **対策**: バランスの取れたKPI設定

**2. 計測の手間とコスト**
- **理由**: 詳細なデータ収集が必要
- **影響**: 現場の負担増加
- **対策**: IoTセンサーによる自動収集

## 6. 選択・導入の指針

### OEE導入の判断基準
| 観点 | 適している | 適していない | 備考 |
|------|-----------|--------------|------|
| 業種 | 量産型製造業 | 受注生産 | 繰り返し生産が前提 |
| 設備規模 | 中～大規模 | 小規模 | データ収集体制が必要 |
| 改善意識 | 高い | 低い | 全員参加が重要 |
| IT化レベル | 中～高 | 低 | データ管理システムが有効 |

### 導入ステップ
1. **現状把握とベースライン設定** 
   - 主要設備の選定
   - 初期OEE測定
   - 目標値の設定

2. **データ収集体制の構築**
   - 記録方法の標準化
   - 責任者の任命
   - システム化の検討

3. **改善活動の実施**
   - ロス分析
   - 改善案の立案
   - 効果の検証

- C) 90.0%
- D) 69.4%

<summary>解答</summary>

<br>
Bが間違いの理由：計算式を誤って適用した結果<br>
Cが間違いの理由：理論生産時間の計算を誤った結果<br>
Dが間違いの理由：時間稼働率と混同した結果<br>
<br>
【補足】性能稼働率は実稼働時間に対する理論生産時間の割合で、速度ロスを表します。
</details>

### 問題11
負荷時間600分、故障60分、段取り90分、生産数5,000個、不良品100個、理論サイクルタイム5秒/個の場合、OEEは？

- A) 65.3%
- B) 71.8%
- C) 58.7%
- D) 75.0%

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
計算過程：<br>
時間稼働率 = (600-150)÷600 = 75.0%<br>

## 9. 専門用語集

このスライドで使用された専門用語について、アルファベット順・50音順で解説します。

### アルファベット

**IoT (Internet of Things)**
- **読み方**: アイオーティー
- **意味**: 様々な機器がインターネットに接続され、相互に情報交換する仕組み。OEEではセンサーデータの自動収集に活用
- **関連用語**: スマートファクトリー、インダストリー4.0

**KPI (Key Performance Indicator)**
- **読み方**: ケーピーアイ
- **意味**: 重要業績評価指標。OEEは製造現場の主要なKPIの一つ
- **関連用語**: OEE、生産性指標

**OEE (Overall Equipment Effectiveness)**
- **読み方**: オーイーイー
- **意味**: 設備総合効率。時間稼働率×性能稼働率×良品率で算出される総合的な設備効率指標
- **関連用語**: TPM、設備効率

**PDCA (Plan-Do-Check-Act)**
- **読み方**: ピーディーシーエー
- **意味**: 計画・実行・評価・改善のサイクル。OEE改善活動の基本的なフレームワーク
- **関連用語**: 継続的改善、改善活動

**SMED (Single Minute Exchange of Die)**
- **読み方**: スメッド
- **意味**: シングル段取り。段取り時間を10分未満に短縮する手法
- **関連用語**: 段取り替え、停止ロス

**TPM (Total Productive Maintenance)**
- **読み方**: ティーピーエム
- **意味**: 全員参加の生産保全。設備効率を最大化する総合的な管理手法
- **関連用語**: OEE、予防保全

### あ行

**空転（くうてん）**
- **読み方**: くうてん
- **意味**: 設備は動いているが、実際には生産していない状態。ワーク待ちなどが原因
- **関連用語**: 小停止、性能ロス

**小停止（しょうていし）**
- **読み方**: しょうていし
- **意味**: 10分未満の短時間の設備停止。センサー誤作動や材料詰まりなどが原因
- **関連用語**: 性能ロス、空転

### か行

**稼働率（かどうりつ）**
- **読み方**: かどうりつ
- **意味**: 設備が実際に稼働している時間の割合。OEEでは時間稼働率として評価
- **関連用語**: 時間稼働率、負荷時間

**カレンダー時間（かれんだーじかん）**
- **読み方**: かれんだーじかん
- **意味**: 暦上の総時間。24時間×日数で計算される
- **関連用語**: 負荷時間、計画停止

**計画停止（けいかくていし）**
- **読み方**: けいかくていし
- **意味**: 休憩、定期保全、会議など、あらかじめ計画された設備の停止
- **関連用語**: 負荷時間、カレンダー時間

**工程能力（こうていのうりょく）**
- **読み方**: こうていのうりょく
- **意味**: 工程が規格内の製品を安定して生産する能力。Cp、Cpkで表される
- **関連用語**: 良品率、品質管理

### さ行

**サイクルタイム（さいくるたいむ）**
- **読み方**: さいくるたいむ
- **意味**: 1個の製品を生産するのに要する時間
- **関連用語**: 理論サイクルタイム、タクトタイム

**時間稼働率（じかんかどうりつ）**
- **読み方**: じかんかどうりつ
- **意味**: 負荷時間に対する実稼働時間の割合。OEEの構成要素の一つ
- **関連用語**: OEE、停止ロス

**実稼働時間（じつかどうじかん）**
- **読み方**: じつかどうじかん
- **意味**: 負荷時間から停止時間を除いた、実際に設備が稼働した時間
- **関連用語**: 負荷時間、停止時間

**性能稼働率（せいのうかどうりつ）**
- **読み方**: せいのうかどうりつ
- **意味**: 実稼働時間に対する理論生産時間の割合。速度効率を表す
- **関連用語**: OEE、性能ロス

**性能ロス（せいのうろす）**
- **読み方**: せいのうろす
- **意味**: 設備が理論速度で稼働できないことによる損失
- **関連用語**: 速度低下、小停止

**設備総合効率（せつびそうごうこうりつ）**
- **読み方**: せつびそうごうこうりつ
- **意味**: OEEの日本語表記。設備の総合的な効率を表す指標
- **関連用語**: OEE、TPM

### た行

**段取り替え（だんどりがえ）**
- **読み方**: だんどりがえ
- **意味**: 生産品目を切り替える際の準備作業。金型交換、治具交換など
- **関連用語**: SMED、停止ロス

**停止ロス（ていしろす）**
- **読み方**: ていしろす
- **意味**: 設備が停止することによる生産機会の損失
- **関連用語**: 故障停止、段取り停止

### な行

**負荷時間（ふかじかん）**
- **読み方**: ふかじかん
- **意味**: カレンダー時間から計画停止時間を除いた時間
- **関連用語**: カレンダー時間、実稼働時間

**不良ロス（ふりょうろす）**
- **読み方**: ふりょうろす
- **意味**: 品質不良による損失。不良品の廃棄、手直しによる時間損失を含む
