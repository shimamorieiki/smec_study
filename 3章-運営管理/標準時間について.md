# 標準時間について

## 概要
標準時間は、工業管理における重要な概念であり、特定の作業を標準的な作業条件の下で、標準的な作業者が標準的なペースで作業を行った場合に必要とする時間を指します。標準時間は生産計画、原価管理、作業改善、賃金決定など、製造業の様々な側面で活用される基本的な指標です。

## 1. 基本概念・仕組み

### 標準時間の構成要素
- **定義**: 標準時間 = 正味時間 + 余裕時間
- **動作原理**: 実際の作業時間を観測し、作業ペースを評価（レイティング）して標準的な時間を算出
- **特徴**: 客観的で公正な時間基準を提供し、様々な管理活動の基礎となる

### 従来の管理手法との関係
- **従来技術との違い**: 経験や勘に頼った時間見積もりから、科学的・客観的な時間測定への移行
- **改善点**: 作業者間の能力差を考慮した公平な評価が可能
- **限界**: 創造的作業や非定型作業には適用が困難

## 2. 標準時間の構成要素

### 正味時間（Net Time）
**特徴:**
- 作業に直接必要な時間
- 余裕を含まない純粋な作業時間
- 観測時間にレイティング係数を掛けて算出

**算出方法:**
```
正味時間 = 観測時間 × レイティング係数
```

**📊 具体的な計算例**
**例: 部品組立作業の正味時間算出**
- 観測時間: 120秒
- レイティング係数: 1.10（観測対象者のペースが標準より10%遅い）

**ステップ1: レイティング評価**
```
観測対象者のペース = 標準の90%
レイティング係数 = 100% ÷ 90% = 1.11
```

**ステップ2: 正味時間算出**
```
正味時間 = 120秒 × 1.11 = 133.2秒
```

**結果: 正味時間は133.2秒**

💡 **実際の現場では**: レイティングは熟練した観測者が、作業者の動作速度、努力度、熟練度、作業条件を総合的に評価して決定します。

### 余裕時間（Allowance Time）
**特徴:**
- 作業遂行上不可避的に必要となる時間
- 疲労余裕、個人的余裕、管理余裕などで構成
- 正味時間に対する比率（余裕率）で表現

**余裕の種類:**
1. **疲労余裕**: 作業による疲労回復のための時間
2. **個人的余裕**: 生理的欲求（トイレ、水分補給など）のための時間
3. **管理余裕**: 作業準備、片付け、打ち合わせなどの時間
4. **職場余裕**: 機械の調整、材料待ちなどの時間

## 3. 標準時間の設定方法

### ストップウォッチ法（Time Study）
**基本手順:**
1. **作業の分析と要素作業への分解**
   - 作業全体を観測可能な要素作業に分解
   - 各要素作業の始点と終点を明確に定義

2. **観測回数の決定**
   - 統計的信頼性を確保するため、通常10～30回観測
   - 作業のばらつきが大きい場合は観測回数を増やす

3. **時間観測の実施**
   - 連続観測法: ストップウォッチを止めずに連続的に観測
   - 反復観測法: 各要素作業ごとにストップウォッチをリセット

4. **異常値の除去**
   - 統計的手法により異常値を特定し除外
   - 3σ法などを使用

5. **レイティングの実施**
   - 観測対象者の作業ペースを評価
   - 標準的な作業者の標準的なペースを100%として評価

6. **正味時間の算出**
   ```
   正味時間 = 観測時間の平均値 × レイティング係数
   ```

7. **余裕率の設定と標準時間の決定**
   - 内掛け法または外掛け法により標準時間を算出

### レイティング（Rating）
**定義**: 観測対象者の作業ペースを標準的な作業者の標準的なペースと比較して評価すること

**レイティングの要素:**
1. **速度（Speed）**: 動作の速さ
2. **努力度（Effort）**: 作業への取り組み姿勢
3. **熟練度（Skill）**: 作業の習熟度
4. **作業条件（Conditions）**: 環境条件の影響

**レイティング手法:**
- **レベリング法**: 速度、努力度、熟練度、作業条件を個別に評価
- **合成レイティング法**: 速度と努力度を総合的に評価
- **客観レイティング法**: 標準動作時間と比較して評価

### 余裕率（Allowance Rate）
**一般的な余裕率の目安:**
| 作業条件 | 疲労余裕 | 個人的余裕 | 管理余裕 | 合計 |
|---------|----------|------------|----------|------|
| 軽作業（座り作業） | 4-7% | 5% | 3-5% | 12-17% |
| 中作業（立ち作業） | 7-12% | 5% | 3-5% | 15-22% |
| 重作業（重量物取扱） | 12-20% | 5% | 3-5% | 20-30% |
| 精密作業 | 8-15% | 5% | 3-5% | 16-25% |

### 内掛け法と外掛け法

#### 内掛け法（内掛率）
**特徴:**
- 標準時間を100%として、その中に余裕時間が含まれると考える方法
- 余裕率は標準時間に対する比率で表現

**計算式:**
```
標準時間 = 正味時間 ÷ (1 - 余裕率)
```

**📊 具体的な計算例**
**例: 内掛け法による標準時間算出**
- 正味時間: 100秒
- 余裕率: 20%（0.20）

**計算:**
```
標準時間 = 100秒 ÷ (1 - 0.20)
        = 100秒 ÷ 0.80
        = 125秒
```

**検証:**
```
正味時間 = 125秒 × 0.80 = 100秒 ✓
余裕時間 = 125秒 × 0.20 = 25秒
```

#### 外掛け法（外掛率）
**特徴:**
- 正味時間を100%として、それに余裕時間を加える方法
- 余裕率は正味時間に対する比率で表現

**計算式:**
```
標準時間 = 正味時間 × (1 + 余裕率)
```

**📊 具体的な計算例**
**例: 外掛け法による標準時間算出**
- 正味時間: 100秒
- 余裕率: 25%（0.25）

**計算:**
```
標準時間 = 100秒 × (1 + 0.25)
        = 100秒 × 1.25
        = 125秒
```

**検証:**
```
余裕時間 = 100秒 × 0.25 = 25秒
標準時間 = 100秒 + 25秒 = 125秒 ✓
```

### 内掛け法と外掛け法の関係
**変換公式:**
```
内掛率 = 外掛率 ÷ (1 + 外掛率)
外掛率 = 内掛率 ÷ (1 - 内掛率)
```

**比較表:**
| 項目 | 内掛け法 | 外掛け法 |
|------|----------|----------|
| 基準 | 標準時間 = 100% | 正味時間 = 100% |
| 計算の直感性 | やや複雑 | 直感的 |
| 使用場面 | 日本で一般的 | 欧米で一般的 |
| 余裕率20%の場合の標準時間 | 正味時間 ÷ 0.8 | 正味時間 × 1.2 |

## 4. その他の標準時間設定方法

### 実績資料法（Historical Data Method）
**特徴:**
- 過去の作業実績データを統計的に分析して標準時間を設定
- 大量の実績データが必要
- 類似作業への適用が容易

**実施手順:**
1. 過去の作業実績データの収集
2. 異常値の除去とデータクリーニング
3. 統計分析（回帰分析、相関分析など）
4. 標準時間の推定式の作成
5. 新規作業への適用と検証

**メリット:**
- 観測の手間が省ける
- 客観的なデータに基づく設定
- 長期的な改善傾向の把握が可能

**デメリット:**
- 過去のムダも含んでしまう可能性
- 作業方法の変更に対応しにくい
- 初期データの蓄積が必要

### 経験見積法（Experience Estimation Method）
**特徴:**
- 熟練者の経験と知識に基づいて標準時間を見積もる
- 迅速な設定が可能
- 非定型作業に適用可能

**実施方法:**
1. **単独見積法**: 1人の熟練者が見積もる
2. **複数見積法**: 複数の熟練者が独立に見積もり、平均値を採用
3. **デルファイ法**: 専門家の意見を段階的に収束させる

**適用場面:**
- 新規作業で実績データがない場合
- 少量生産や単品生産
- 創造的作業や知的作業

### 標準時間資料法（Standard Data Method）
**特徴:**
- 基本動作や要素作業の標準時間をデータベース化
- 作業の組み合わせで全体の標準時間を算出
- 迅速かつ一貫性のある設定が可能

**データベースの構成例:**
| 要素作業 | 条件 | 標準時間 |
|----------|------|----------|
| 部品を取る | 距離10cm | 0.5秒 |
| 部品を取る | 距離30cm | 1.2秒 |
| ネジを締める | M3×10mm | 3.5秒 |
| ネジを締める | M5×15mm | 5.2秒 |

**適用手順:**
1. 作業を要素作業に分解
2. データベースから該当する標準時間を検索
3. 各要素作業の標準時間を合計
4. 必要に応じて調整係数を適用

### PTS法（Predetermined Time Standards）
**特徴:**
- 人間の基本動作を詳細に分析し、あらかじめ時間値を設定
- 作業設計段階で標準時間の設定が可能
- 国際的に標準化された手法

**主要なPTS法:**
1. **MTM（Methods Time Measurement）**
   - 最も広く使用されているPTS法
   - 基本動作を「つかむ」「動かす」「回す」などに分類
   - 各動作に詳細な時間値を設定

2. **WF（Work Factor）**
   - 動作の困難度を考慮したシステム
   - 身体部位、移動距離、重量、注意度などを要因として考慮

3. **MOST（Maynard Operation Sequence Technique）**
   - MTMを簡略化したシステム
   - 一般移動、制御移動、道具使用の3つのモデル

**MTMの基本動作と時間値の例（1TMU = 0.036秒）:**
| 動作記号 | 動作内容 | 距離/条件 | 時間値(TMU) |
|----------|----------|-----------|-------------|
| R10A | 手を伸ばす | 10cm、容易 | 6.5 |
| G1A | つかむ | 小物、容易 | 2.0 |
| M10B | 動かす | 10cm、正確 | 10.3 |
| RL1 | 離す | 通常 | 2.0 |

## 5. メリット・デメリット

### メリット
**1. 客観的な評価基準の確立**
- **理由**: 科学的な測定方法に基づく時間設定
- **効果**: 作業者間の公平な評価が可能
- **具体例**: 賃金決定において納得性の高い基準を提供

**2. 生産性向上の基礎データ**
- **理由**: 現状の作業時間を正確に把握
- **効果**: 改善余地の発見と効果測定が可能
- **具体例**: 作業改善により30%の時間短縮を実現

**3. 原価管理の精度向上**
- **理由**: 正確な作業時間に基づく原価計算
- **効果**: 見積もり精度の向上と利益管理の改善
- **具体例**: 見積もり誤差を±20%から±5%に改善

### デメリット
**1. 設定に時間とコストがかかる**
- **理由**: 詳細な作業観測と分析が必要
- **影響**: 初期投資が大きい
- **対策**: 重要作業から段階的に導入

**2. 作業者の心理的抵抗**
- **理由**: 監視されているという感覚
- **影響**: 労使関係の悪化の可能性
- **対策**: 目的の明確な説明と作業者の参画

**3. 創造的作業への適用困難**
- **理由**: 作業内容が標準化できない
- **影響**: 知的労働や開発業務には不適
- **対策**: 別の評価方法との併用

### 適用判断フローチャート
1. **作業の反復性は高いか？**
   - Yes → 次の判断へ
   - No → 経験見積法

2. **実績データは十分にあるか？**
   - Yes → 実績資料法
   - No → 次の判断へ

3. **作業設計段階での設定が必要か？**
   - Yes → PTS法
   - No → ストップウォッチ法

## 8. 理解度確認クイズ（4択問題20問）

### 問題1
標準時間の構成要素として正しいものはどれか？

- A) 標準時間 = 観測時間 + 余裕時間
- B) 標準時間 = 正味時間 + 余裕時間
- C) 標準時間 = 実働時間 + 休憩時間
- D) 標準時間 = 作業時間 + 準備時間

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
標準時間は正味時間と余裕時間の合計で構成されます。正味時間は観測時間にレイティング係数を掛けて算出される、作業に直接必要な時間です。<br>
<br>
Aが間違いの理由：観測時間は実際に測定した時間であり、レイティングによる調整が必要<br>
Cが間違いの理由：実働時間や休憩時間という概念は標準時間の構成要素ではない<br>
Dが間違いの理由：準備時間は余裕時間の一部として含まれる可能性はあるが、基本構成ではない
</details>

### 問題2
レイティング係数が1.20の場合、どのような状況を表しているか？

- A) 観測対象者の作業ペースが標準より20%速い
- B) 観測対象者の作業ペースが標準より20%遅い
- C) 標準時間が観測時間より20%長い
- D) 余裕率が20%である

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
レイティング係数1.20は、観測対象者の作業ペースが標準の83.3%（100÷120）であることを意味し、標準より約20%遅いことを示します。<br>
<br>
Aが間違いの理由：作業ペースが速い場合、レイティング係数は1.0未満になる<br>
Cが間違いの理由：レイティング係数は作業ペースの評価であり、時間の長短を直接表すものではない<br>
Dが間違いの理由：レイティング係数と余裕率は別の概念
</details>

- B) 80秒
- C) 85秒
- D) 90秒

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
内掛け法の計算式：標準時間 = 正味時間 ÷ (1 - 余裕率)<br>
標準時間 = 60秒 ÷ (1 - 0.25) = 60秒 ÷ 0.75 = 80秒<br>
<br>
Aが間違いの理由：外掛け法で余裕率25%とした場合の計算結果（60×1.25=75）と混同<br>
Cが間違いの理由：計算式の適用誤り<br>
Dが間違いの理由：計算式の適用誤り
</details>

### 問題4
外掛け法で余裕率20%の場合、正味時間100秒の標準時間はいくらか？

- A) 80秒
- B) 100秒
- C) 120秒
- D) 125秒

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
外掛け法の計算式：標準時間 = 正味時間 × (1 + 余裕率)<br>
標準時間 = 100秒 × (1 + 0.20) = 100秒 × 1.20 = 120秒<br>
<br>
Aが間違いの理由：余裕率を減算してしまっている<br>
Bが間違いの理由：余裕時間を加算していない<br>

</details>

### 問題5
疲労余裕に該当しないものはどれか？

- A) 重量物運搬による体力消耗の回復時間
- B) 精密作業による眼精疲労の回復時間
- C) トイレに行くための時間
- D) 高温環境での作業による疲労回復時間

<details>
<summary>解答</summary>

トイレに行くための時間は個人的余裕に分類されます。疲労余裕は作業による肉体的・精神的疲労の回復に必要な時間です。<br>
<br>
A、B、Dはすべて作業に起因する疲労の回復時間であり、疲労余裕に該当します。
</details>

### 問題8
ストップウォッチ法における観測回数の決定で考慮すべき要因はどれか？

- A) 作業者の賃金水準
- B) 作業のばらつきの大きさ
- C) 工場の操業時間
- D) 製品の販売価格

<details>

### あ行

**余裕時間（よゆうじかん）**
- **読み方**: よゆうじかん
- **意味**: 作業遂行上不可避的に必要となる時間で、疲労回復、生理的欲求、作業準備などのための時間
- **関連用語**: 余裕率、疲労余裕、個人的余裕

**余裕率（よゆうりつ）**
- **読み方**: よゆうりつ
- **意味**: 正味時間または標準時間に対する余裕時間の比率
- **関連用語**: 内掛け法、外掛け法

### か行

**外掛け法（そとがけほう）**
- **読み方**: そとがけほう
- **意味**: 正味時間を100%として、それに余裕時間を加える標準時間の算出方法
- **関連用語**: 内掛け法、余裕率

**観測時間（かんそくじかん）**
- **読み方**: かんそくじかん
- **意味**: ストップウォッチなどで実際に測定した作業時間
- **関連用語**: 正味時間、レイティング

**経験見積法（けいけんみつもりほう）**
- **読み方**: けいけんみつもりほう
- **意味**: 熟練者の経験と知識に基づいて標準時間を見積もる方法
- **関連用語**: デルファイ法

### さ行

**正味時間（しょうみじかん）**
- **読み方**: しょうみじかん
- **意味**: 作業に直接必要な時間で、観測時間にレイティング係数を掛けて算出される
- **関連用語**: 観測時間、レイティング

**ストップウォッチ法（すとっぷうぉっちほう）**
- **読み方**: すとっぷうぉっちほう
- **意味**: ストップウォッチを用いて実際の作業時間を測定し、標準時間を設定する方法
- **関連用語**: 時間研究、連続観測法、反復観測法

### た行

- **読み方**: ひょうじゅんじかん
- **意味**: 標準的な作業条件の下で、標準的な作業者が標準的なペースで作業を行った場合に必要とする時間

- **関連用語**: 要素作業、データベース

**疲労余裕（ひろうよゆう）**

- **意味**: 作業による肉体的・精神的疲労の回復に必要な余裕時間

### ま行

- **関連用語**: PTS法、MTM

**MTM（えむてぃーえむ）**
