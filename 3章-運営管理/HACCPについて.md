# HACCPについて

## 概要
HACCP（Hazard Analysis and Critical Control Point）は、食品の製造・加工工程において、食品の安全性を確保するための衛生管理手法です。1960年代に米国でアポロ計画の宇宙食の安全性確保のために開発され、現在では世界的に採用されている食品安全管理システムです。従来の最終製品検査に頼る管理手法と異なり、原材料の受入から最終製品までの各工程において、微生物汚染、金属混入等の危害要因を分析し、特に重要な工程を継続的に監視・記録することで、製品の安全性を確保します。

## 1. 基本概念・仕組み

### HACCPの核となる概念
- **定義**: 食品の製造工程において、科学的根拠に基づいて危害要因を分析し、その危害を防止するための重要管理点を特定して、継続的に監視・記録することで食品の安全性を確保する手法
- **動作原理**: 予防的アプローチにより、危害の発生を未然に防ぐシステム
- **特徴**: 
  - 科学的根拠に基づく管理
  - 予防的管理手法
  - 継続的な監視と記録
  - 体系的・組織的アプローチ

### 従来の品質管理との違い
- **従来手法**: 最終製品の抜き取り検査による事後的管理
- **HACCP**: 工程管理による予防的管理
- **改善点**: 
  - 全製品の安全性確保が可能
  - 問題発生時の迅速な対応
  - トレーサビリティの確保
- **限界**: 
  - 導入初期の設備投資が必要
  - 従業員教育の徹底が必要
  - 継続的な記録管理の負担

## 2. HACCPの7原則12手順

### 準備段階（手順1～5）
1. **HACCPチームの編成**
   - 多部門の専門家で構成
   - 責任者の明確化
   - 外部専門家の活用

2. **製品説明書の作成**
   - 製品の特性
   - 原材料・成分
   - 保存方法・期限

3. **意図する用途及び対象消費者の確認**
   - 一般消費者向けか特定層向けか
   - 調理方法の想定
   - 喫食方法

4. **製造工程一覧図の作成**
   - 原材料受入から出荷まで
   - 各工程の詳細記載
   - 温度・時間等の条件明記

5. **製造工程一覧図の現場確認**
   - 実際の作業との照合
   - 修正・更新

### HACCP7原則（手順6～12）

#### 原則1（手順6）: 危害要因分析（HA）の実施
**詳細説明:**
危害要因分析は、原材料及び製造工程において、食品の安全性に影響を与える可能性のある生物的、化学的、物理的危害要因を科学的に分析することです。

**危害要因の分類:**
- **生物的危害**: 病原微生物（サルモネラ、腸管出血性大腸菌O157等）
- **化学的危害**: 農薬、動物用医薬品、アレルゲン、自然毒等
- **物理的危害**: 金属片、ガラス片、硬質プラスチック片等

**📊 具体的な危害要因分析例**
**例: 鶏肉加工品の製造工程**

**ステップ1: 原材料受入工程の分析**
```
危害要因: サルモネラ汚染（生物的危害）
発生要因: 鶏肉の初発菌数が高い
管理手段: 受入時の温度確認、信頼できる供給業者の選定
```

**ステップ2: 加熱工程の分析**
```
危害要因: 病原微生物の残存（生物的危害）
発生要因: 加熱不足
管理手段: 中心温度75℃1分以上の加熱
```

💡 **実際の現場では**: 危害要因分析は全工程について実施し、各危害の発生頻度と重篤度を評価して管理の必要性を判断します。

#### 原則2（手順7）: 重要管理点（CCP）の決定
**詳細説明:**
CCPは、特定の危害要因を管理しなければ、その後の工程で危害を取り除くことができない重要な工程です。

**CCP決定の判断基準（デシジョンツリー）:**
1. この工程で危害を予防・除去・低減できるか？
2. この工程を管理しないと危害が許容レベルを超えるか？
3. 以降の工程で危害を除去・低減できるか？

**📊 CCP決定の具体例**
**例: 牛乳製造工程でのCCP判定**

```
工程: 殺菌工程
Q1: この工程で病原微生物を除去できるか？ → Yes
Q2: この工程以外で病原微生物を除去できるか？ → No
結論: CCPに決定
```

💡 **実際の現場では**: CCPは必要最小限に設定し、確実に管理できる体制を整えることが重要です。

#### 原則3（手順8）: 管理基準（CL）の設定
**詳細説明:**
管理基準は、CCPにおいて危害要因を管理するための限界値です。科学的根拠に基づいて設定する必要があります。

**管理基準の種類:**
- **温度**: 加熱温度、冷却温度、保管温度
- **時間**: 加熱時間、冷却時間
- **pH**: 酸性度
- **水分活性**: 微生物の増殖に必要な水分
- **その他**: 塩素濃度、金属探知機の感度等

**📊 管理基準設定の具体例**
**例: ハンバーグ製造における加熱工程の管理基準**

```
危害要因: 腸管出血性大腸菌O157
管理基準: 中心温度75℃以上、1分間以上
科学的根拠: 厚生労働省の加熱基準
測定方法: 中心温度計による連続測定
```

**例: 金属探知工程の管理基準**
```
危害要因: 金属異物
管理基準: Fe 1.0mm、SUS 2.0mm以上を検出
測定方法: テストピースによる動作確認（1時間ごと）
```

💡 **実際の現場では**: 管理基準は法的基準や業界基準を参考に、自社の製造条件に応じて設定します。

#### 原則4（手順9）: モニタリング方法の設定
- **連続的モニタリング**: 温度の自動記録等
- **非連続的モニタリング**: 定期的なサンプリング検査
- **記録方法**: チェックシート、自動記録装置

#### 原則5（手順10）: 改善措置の設定
- **逸脱時の製品の取扱い**: 隔離、廃棄、再加工
- **工程の是正**: 温度調整、時間延長
- **原因究明と再発防止**

#### 原則6（手順11）: 検証方法の設定
- **日常的検証**: モニタリング記録の確認
- **定期的検証**: 微生物検査、システム全体の見直し
- **妥当性確認**: 管理基準の科学的根拠の再確認

#### 原則7（手順12）: 記録と保存方法の設定
- **記録すべき内容**: モニタリング記録、逸脱記録、改善措置記録
- **保存期間**: 製品の賞味期限＋1年以上
- **記録の管理**: 改ざん防止、トレーサビリティ確保

## 3. 実装例・適用事例

### 基本実装例：小規模製パン業でのHACCP
```
製品: 食パン
主要CCP: 焼成工程

危害要因分析:
- 生地中の病原微生物 → 焼成工程で管理
- 金属異物 → 金属探知機で管理

CCP1: 焼成工程
- 管理基準: オーブン内温度 200℃、20分間
- モニタリング: 温度計による連続監視、タイマー管理
- 改善措置: 基準未達製品の再焼成または廃棄

CCP2: 金属探知工程  
- 管理基準: Fe 1.2mm、SUS 2.5mm
- モニタリング: 1時間ごとのテストピース確認
- 改善措置: 検出品の除去、原因調査
```

### 応用実装例：大規模食肉加工施設
```
製品: 冷凍ハンバーグ
複数CCP管理:

CCP1: 原料肉受入
- 管理基準: 品温5℃以下
- モニタリング: 全ロット温度測定

CCP2: 成型後加熱
- 管理基準: 中心温度75℃、1分以上
- モニタリング: 連続式温度記録計

CCP3: 急速冷凍
- 管理基準: 30分以内に中心温度-18℃
- モニタリング: 自動温度記録

CCP4: 金属探知
- 管理基準: Fe 1.0mm、SUS 2.0mm
- モニタリング: 30分ごとの感度確認
```

### 実際の適用事例

#### 事例1: 大手乳業メーカーA社
- **課題**: 食中毒事故の発生による信頼回復
- **適用方法**: 全工場でHACCP導入、第三者認証取得
- **結果**: 5年間食品事故ゼロ

#### 事例2: 中小食品製造業B社

- **効果**: 売上高50%増、従業員の意識向上

## 4. メリット・デメリット

### メリット
**1. 食品安全性の向上**
- **理由**: 科学的根拠に基づく予防的管理
- **効果**: 食中毒事故リスクの大幅削減
- **具体例**: 導入企業の食品事故発生率90%以上減少

**2. 品質の均一化**
- **理由**: 標準化された製造管理
- **効果**: 製品品質のばらつき減少
- **具体例**: クレーム率50%削減事例多数

**3. 従業員の意識向上**
- **理由**: 役割と責任の明確化
- **効果**: 自主的な改善活動の活性化
- **具体例**: 改善提案数3倍増加

**4. 取引機会の拡大**
- **理由**: 取引先からの要求対応
- **効果**: 新規顧客獲得、輸出可能
- **具体例**: HACCP導入後の新規取引30%増

### デメリット
**1. 初期投資の負担**
- **理由**: 設備改修、システム構築費用
- **影響**: 中小企業には大きな負担
- **対策**: 補助金活用、段階的導入

**2. 文書管理の増加**
- **理由**: 記録・保存義務
- **影響**: 事務作業量の増加
- **対策**: IT化による効率化

**3. 継続的な教育訓練の必要性**
- **理由**: 全従業員の理解が必要
- **影響**: 教育コストと時間
- **対策**: 外部研修の活用、OJTの充実

|------|-------------------|--------------|----------------|
| 対象事業者 | 小規模事業者 | 中規模以上 | 輸出・大手取引 |
| 管理の厳格さ | ○ | ◎ | ◎◎ |
| 導入コスト | ◎ | ○ | △ |
| 文書化要求 | ○ | ◎ | ◎◎ |
| 市場評価 | ○ | ◎ | ◎◎ |

### 導入判断フローチャート
1. **従業員数50名以上？** 
   - Yes → 基準B以上推奨
   - No → 次の判断へ

2. **輸出または大手との取引？**
   - Yes → 第三者認証HACCP推奨
   - No → 基準AまたはBを選択

3. **複雑な製造工程？**
   - Yes → 基準B推奨
   - No → 基準Aから開始

## 7. 理解度確認クイズ（4択問題20問）

### 問題1
HACCPの正式名称として正しいものはどれか？

- A) Hazard Analysis and Critical Control Point
- B) Health Analysis and Crisis Control Program
- C) Hazard Assessment and Critical Checkpoint
- D) Health Assurance and Control Criteria Program

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
HACCPはHazard Analysis and Critical Control Pointの略称です。日本語では「危害要因分析重要管理点」と訳されます。<br>
<br>
Bが間違いの理由：HealthやCrisisという用語は使われていません<br>
Cが間違いの理由：AssessmentやCheckpointは正式名称に含まれません<br>
Dが間違いの理由：完全に異なる用語の組み合わせです<br>
<br>
【補足】HACCPは1960年代にNASAとピルスベリー社が共同開発した食品安全管理手法です。
</details>

### 問題2
HACCPにおける危害要因の分類として正しい組み合わせはどれか？

- A) 生物的・化学的・物理的
- B) 細菌的・毒物的・異物的
- C) 微生物的・有害的・機械的
- D) 病原的・汚染的・混入的

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
HACCPでは危害要因を「生物的危害」「化学的危害」「物理的危害」の3つに分類します。<br>
<br>
Bが間違いの理由：正式な分類用語ではありません<br>
Cが間違いの理由：微生物的は生物的の一部であり、分類として不適切です<br>
Dが間違いの理由：これらは危害の性質を表す言葉で、分類名ではありません<br>
<br>
【補足】生物的危害には病原微生物、化学的危害には農薬やアレルゲン、物理的危害には金属片やガラス片などが含まれます。
</details>

### 問題3
次のうち、HACCP7原則に含まれないものはどれか？

- A) 危害要因分析の実施
- B) 従業員の健康管理
- C) 重要管理点の決定
- D) 管理基準の設定

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
従業員の健康管理は一般衛生管理（前提条件プログラム）に含まれる事項で、HACCP7原則には含まれません。<br>
<br>
Aは原則1、Cは原則2、Dは原則3に該当します。<br>
<br>
【補足】HACCP7原則は、1.危害要因分析、2.CCP決定、3.管理基準設定、4.モニタリング設定、5.改善措置設定、6.検証方法設定、7.記録方法設定です。
</details>

### 問題4
CCPを決定する際の判断基準として適切でないものはどれか？

- A) その工程で危害を予防・除去・低減できるか
- B) その工程のコストが最も低いか
- C) 以降の工程で危害を除去できないか
- D) 管理しないと危害が許容レベルを超えるか

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
CCP決定はコストではなく、食品安全上の必要性に基づいて行います。<br>
<br>
A、C、Dはすべてデシジョンツリーで使用される適切な判断基準です。<br>
<br>
【補足】CCPは必要最小限に設定し、確実に管理できることが重要です。コストは考慮事項ですが、決定基準ではありません。
</details>

### 問題5
管理基準（CL）として設定する項目として不適切なものはどれか？

- A) 温度
- B) 時間
- C) 従業員の経験年数
- D) pH値

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
管理基準は科学的に測定可能で、リアルタイムに確認できる物理的・化学的パラメータである必要があります。従業員の経験年数は管理基準として不適切です。<br>
<br>
A（温度）、B（時間）、D（pH値）はすべて測定可能で、科学的根拠に基づいて設定できる適切な管理基準です。<br>
<br>
【補足】その他の管理基準としては、水分活性、塩素濃度、金属探知機の感度などがあります。
</details>

### 問題6
食肉製品の加熱工程における一般的な管理基準として正しいものはどれか？

- A) 中心温度63℃で30分間
- B) 中心温度75℃で1分間
- C) 表面温度80℃で5分間
- D) 中心温度60℃で10分間

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
厚生労働省の基準では、食肉製品の加熱は中心温度75℃で1分間以上が基準とされています。<br>
<br>
Aは低温殺菌の基準（別の条件）、Cは表面温度なので不適切、Dは温度が不十分です。<br>
<br>
【補足】または中心温度70℃で3分間、65℃で15分間など、同等の殺菌効果が得られる条件も認められています。
</details>

### 問題7
HACCPにおけるモニタリングの方法として、最も望ましいものはどれか？

- A) 月1回の抜き取り検査
- B) 連続的な自動測定記録
- C) 作業終了後の一括確認
- D) 管理者による不定期チェック

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
CCPのモニタリングは可能な限り連続的に行い、逸脱を速やかに発見できることが理想です。<br>
<br>
Aは頻度が少なすぎ、Cは事後確認で予防にならず、Dは計画的でないため不適切です。<br>
<br>
【補足】連続測定が困難な場合は、科学的根拠に基づいた頻度で非連続的モニタリングを行います。
</details>

### 問題8
改善措置として最初に行うべきことは何か？

- A) 責任者の処分
- B) 影響を受けた製品の処置
- C) 報告書の作成
- D) 設備の全面更新

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
管理基準を逸脱した場合、まず影響を受けた製品を適切に処置（隔離、廃棄、再加工等）することが最優先です。<br>
<br>
その後、工程の是正、原因究明、再発防止策の実施という順序で対応します。<br>
<br>
【補足】改善措置は事前に手順を定め、迅速に実行できるよう準備しておくことが重要です。
</details>

### 問題9
次の工程のうち、一般的にCCPになりにくいものはどれか？

- A) 加熱殺菌工程
- B) 金属探知工程
- C) 包装工程
- D) 冷却工程

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
包装工程は一般的に危害要因の除去や低減を行う工程ではないため、CCPになりにくいです。<br>
<br>

## 8. 専門用語集

このドキュメントで使用された専門用語について、アルファベット順・50音順で解説します。

### アルファベット

**CCP (Critical Control Point)**
- **読み方**: シーシーピー
- **意味**: 重要管理点。食品の安全性を確保するために、危害要因を予防、除去、または許容レベルまで低減するために管理が必須な工程
- **関連用語**: OPRP、管理点

**CL (Critical Limit)**
- **読み方**: シーエル
- **意味**: 管理基準。CCPにおいて、食品の安全性を確保するために遵守しなければならない限界値
- **関連用語**: 許容限界、オペレーション限界

**FSSC22000**
- **読み方**: エフエスエスシーにまんにせん
- **意味**: 食品安全システム認証。ISO22000にISO/TS22002-1等を加えた食品安全マネジメントシステムの認証スキーム
- **関連用語**: ISO22000、GFSI

**GFSI (Global Food Safety Initiative)**
- **読み方**: ジーエフエスアイ
- **意味**: 世界食品安全イニシアティブ。食品安全認証プログラムの承認等を行う民間団体
- **関連用語**: 第三者認証

**HA (Hazard Analysis)**
- **読み方**: エイチエー
- **意味**: 危害要因分析。原材料及び製造工程において発生する可能性のある危害要因を分析すること
- **関連用語**: リスク評価、危害評価

**HACCP (Hazard Analysis and Critical Control Point)**
- **読み方**: ハサップ
- **意味**: 危害要因分析重要管理点。食品の製造工程で発生する可能性のある危害を分析し、重要な工程を継続的に監視・記録する衛生管理手法
- **関連用語**: 食品安全、予防的管理

**ISO22000**
- **読み方**: アイエスオーにまんにせん
- **意味**: 食品安全マネジメントシステムの国際規格。HACCPの原則を含む包括的な管理システム
- **関連用語**: マネジメントシステム、国際標準

**JFS規格**
- **読み方**: ジェイエフエスきかく
- **意味**: 日本発の食品安全マネジメント規格。日本の食文化に適合した食品安全規格
- **関連用語**: 一般財団法人食品安全マネジメント協会

**OPRP (Operational Prerequisite Program)**
- **読み方**: オーピーアールピー
- **意味**: オペレーション前提条件プログラム。CCPではないが重要な管理を行う工程
- **関連用語**: PRP、CCP

**PRP (Prerequisite Program)**
- **読み方**: ピーアールピー
- **意味**: 前提条件プログラム。HACCPシステムの土台となる一般的衛生管理プログラム
- **関連用語**: 一般衛生管理、SSOP

**SSOP (Sanitation Standard Operating Procedures)**
- **読み方**: エスエスオーピー
- **意味**: 衛生標準作業手順書。施設設備の衛生管理に関する具体的な手順を定めた文書
- **関連用語**: SOP、衛生管理

### あ行

**一般衛生管理**
- **読み方**: いっぱんえいせいかんり
- **意味**: HACCPの前提となる基本的な衛生管理。施設設備の衛生管理、従業員の健康管理、衛生教育など
- **関連用語**: 前提条件プログラム、PRP

**逸脱（いつだつ）**
- **読み方**: いつだつ
- **意味**: 管理基準を満たさない状態。CCPにおいて設定した管理基準から外れること
- **関連用語**: 管理基準逸脱、是正措置

**オペレーション限界**
- **読み方**: おぺれーしょんげんかい
- **意味**: 管理基準より厳しく設定する操作上の限界値。逸脱を防ぐための予防的な基準
- **関連用語**: 管理基準、アクションレベル

### か行

**改善措置**
- **読み方**: かいぜんそち
- **意味**: 管理基準の逸脱が発生した際に取る是正行動。影響を受けた製品の処置と工程の修正を含む
- **関連用語**: 是正措置、予防措置

**科学的根拠**
- **読み方**: かがくてきこんきょ
- **意味**: 実験データ、文献情報、専門家の知見など、客観的に証明できる根拠
- **関連用語**: エビデンス、妥当性確認

**管理基準**
- **読み方**: かんりきじゅん
- **意味**: CCPにおいて危害要因を管理するための限界値。温度、時間、pH等の測定可能な値
- **関連用語**: CL、許容限界

**危害要因**
- **読み方**: きがいよういん
- **意味**: 食品の安全性に悪影響を及ぼす可能性のある生物的、化学的、物理的要因
- **関連用語**: ハザード、リスク

**危害要因分析**
- **読み方**: きがいよういんぶんせき
- **意味**: 各工程で発生する可能性のある危害要因を特定し、その重要性を評価すること
- **関連用語**: HA、リスク評価

**記録**
- **読み方**: きろく
- **意味**: HACCPシステムの実施状況を証明する文書。モニタリング結果、逸脱、改善措置等を記載
- **関連用語**: 文書化、トレーサビリティ

**検証**
- **読み方**: けんしょう
- **意味**: HACCPシステムが適切に機能していることを確認する活動
- **関連用語**: バリデーション、妥当性確認

### さ行

**重要管理点**
- **読み方**: じゅうようかんりてん
- **意味**: 食品の安全性確保のために管理が必須な工程。CCPの日本語訳
- **関連用語**: CCP、必須管理点

**前提条件プログラム**
- **読み方**: ぜんていじょうけんぷろぐらむ
- **意味**: HACCPシステムを効果的に機能させるための基礎となる衛生管理プログラム
- **関連用語**: PRP、一般衛生管理

### た行

**妥当性確認**
- **読み方**: だとうせいかくにん
- **意味**: 管理手段や管理基準が科学的に適切であることを確認すること
- **関連用語**: バリデーション、検証

**デシジョンツリー**
- **読み方**: でしじょんつりー
- **意味**: CCPを決定するための判断基準を系統的に示した判定図
- **関連用語**: CCP決定、判定樹

**トレーサビリティ**
- **読み方**: とれーさびりてぃ
- **意味**: 製品の履歴、所在、適用履歴を追跡できる能力
- **関連用語**: 追跡可能性、履歴管理

### は行

**バリデーション**
- **読み方**: ばりでーしょん
- **意味**: HACCPプランが効果的であることを証明する行為
- **関連用語**: 妥当性確認、検証

**フローダイアグラム**
- **読み方**: ふろーだいあぐらむ
- **意味**: 製造工程の流れを図式化したもの。製造工程一覧図
- **関連用語**: 工程図、プロセスフロー

### ま行

**モニタリング**
- **読み方**: もにたりんぐ
- **意味**: CCPが管理下にあることを確認するための計画的な観察・測定
- **関連用語**: 監視、連続測定

### ら行

**リスク評価**
- **読み方**: りすくひょうか
- **意味**: 危害要因の発生可能性と重篤性を評価すること
- **関連用語**: 危害評価、リスクアセスメント
