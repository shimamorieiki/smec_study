# ワークサンプリングについて

## 概要
ワークサンプリング（Work Sampling）は、作業者や機械の活動状態を統計的手法を用いて分析する作業測定技術です。ランダムな時刻に瞬間的な観測を繰り返し行い、その観測結果から作業の構成比率や稼働率を推定します。連続観測に比べて効率的で、複数の対象を同時に調査できる特徴があります。

## 1. 基本概念・仕組み

### ワークサンプリングの定義
- **定義**: 作業者や機械の活動状態を、ランダムな時刻に瞬間的に観測し、その観測結果から全体の状態構成比率を統計的に推定する方法
- **動作原理**: 確率論と統計学の原理に基づき、無作為抽出によって母集団の特性を推定
- **特徴**: 非連続的観測、複数対象の同時観測可能、観測者への負担が少ない

### 統計学的基礎
- **二項分布の適用**: 各観測は「該当する」「該当しない」の二値で記録
- **大数の法則**: 観測回数を増やすことで推定精度が向上
- **正規分布近似**: 観測回数が多い場合、二項分布は正規分布で近似可能

## 2. 種類・分類

### 観測対象による分類
ワークサンプリングは観測対象によって以下のように分類されます。

### 作業者ワークサンプリング
**特徴:**
- 作業者の活動状態を観測
- 主作業、準備作業、余裕時間などの構成比を把握
- 作業改善の基礎データとして活用

**算出方法:**
```
構成比率(%) = (該当状態の観測回数 / 総観測回数) × 100
```

**📊 具体的な計算例**
**例: 製造現場の作業者観測**
- 総観測回数: 1,000回
- 主作業観測回数: 650回

**ステップ1: 構成比率の計算**
```
主作業率 = (650 / 1,000) × 100 = 65%
```

**ステップ2: 信頼区間の計算（95%信頼度）**
```
標準誤差 = √(0.65 × 0.35 / 1,000) = 0.0151
信頼区間 = 65% ± 1.96 × 1.51% = 65% ± 3.0%
```

**結果: 主作業率は62.0%～68.0%の範囲と推定**

💡 **実際の現場では**: 観測結果を基に、非付加価値作業の削減や作業配分の最適化を検討します。

### 機械ワークサンプリング
**特徴:**
- 機械設備の稼働状態を観測
- 稼働、段取り、故障、待機などの状態を把握
- 設備総合効率（OEE）算出の基礎データ

**算出方法:**
```
稼働率(%) = (稼働観測回数 / 総観測回数) × 100
```

**📊 具体的な計算例**
**例: 工作機械の稼働率調査**
- 総観測回数: 800回
- 稼働観測回数: 560回
- 段取り観測回数: 120回
- 故障観測回数: 40回
- 待機観測回数: 80回

**ステップ1: 各状態の構成比率計算**
```
稼働率 = (560 / 800) × 100 = 70.0%
段取り率 = (120 / 800) × 100 = 15.0%
故障率 = (40 / 800) × 100 = 5.0%
待機率 = (80 / 800) × 100 = 10.0%
```

**ステップ2: 改善ポイントの特定**
```
非稼働時間 = 段取り率 + 故障率 + 待機率 = 30.0%
```

**結果: 稼働率70%、改善余地30%**

💡 **実際の現場では**: 段取り時間短縮（SMED）、予防保全、生産計画改善などの対策を立案します。

## 3. 詳細仕様・パラメータ

### 重要なパラメータ群

#### 必要観測回数の詳細
- **意味**: 要求される精度と信頼度を満たすために必要な観測回数
- **設定範囲**: 通常100回～10,000回程度
- **影響**: 観測回数が多いほど精度が向上するが、コストも増加
- **推奨値**: 初期調査では400～1,000回、詳細調査では2,000回以上

**計算式:**
```
n = (Z² × p × (1-p)) / E²

ここで、
n: 必要観測回数
Z: 信頼度に対応する標準正規分布の値（95%信頼度で1.96）
p: 推定される構成比率（事前情報がない場合は0.5）
E: 許容誤差（例：±3%なら0.03）
```

#### 観測間隔の詳細
- **意味**: 各観測を行う時刻の間隔
- **設定範囲**: 作業サイクルの10倍以上を推奨
- **影響**: 間隔が短すぎると独立性が損なわれる
- **推奨値**: ランダム時刻表を使用し、最小間隔を設定

## 4. 実装例・適用事例

### 基本実装
```python
# ワークサンプリング実施プログラムの例
import random
import datetime

class WorkSampling:
    def __init__(self, start_time, end_time, num_observations):
        self.start_time = start_time
        self.end_time = end_time
        self.num_observations = num_observations
        self.observations = []
    
    def generate_random_times(self):
        """ランダムな観測時刻を生成"""
        time_range = (self.end_time - self.start_time).total_seconds()
        random_seconds = sorted([random.random() * time_range 
                               for _ in range(self.num_observations)])
        
        return [self.start_time + datetime.timedelta(seconds=s) 
                for s in random_seconds]
    
    def calculate_confidence_interval(self, p, confidence=0.95):
        """信頼区間を計算"""
        z = 1.96 if confidence == 0.95 else 2.58  # 95%または99%信頼度
        n = len(self.observations)
        se = (p * (1 - p) / n) ** 0.5
        return (p - z * se, p + z * se)
```

### 応用実装
```python
# 複数対象の同時観測システム
class MultiTargetSampling:
    def __init__(self, targets, categories):
        self.targets = targets  # 観測対象のリスト
        self.categories = categories  # 状態カテゴリのリスト
        self.observation_matrix = {}
        
    def record_observation(self, time, observations):
        """複数対象の同時観測を記録"""
        self.observation_matrix[time] = observations
    
    def analyze_results(self):
        """全対象の結果を分析"""
        results = {}
        for target in self.targets:
            target_obs = [obs[target] for obs in self.observation_matrix.values()]
            results[target] = self.calculate_distribution(target_obs)
        return results
    
    def calculate_distribution(self, observations):
        """カテゴリ別の分布を計算"""
        total = len(observations)
        distribution = {}
        for category in self.categories:
            count = observations.count(category)
            distribution[category] = {
                'count': count,
                'percentage': (count / total) * 100,
                'confidence_interval': self.calculate_confidence_interval(count/total)
            }
        return distribution
```

## 5. メリット・デメリット

### メリット
**1. 効率的な調査が可能**
- **理由**: 連続観測と比較して観測時間が大幅に短縮
- **効果**: 調査コストの削減、観測者の負担軽減
- **具体例**: 8時間の連続観測を100回の瞬間観測（実質10分程度）で代替

**2. 複数対象の同時観測**
- **理由**: 瞬間観測のため、複数の対象を巡回して観測可能
- **効果**: 全体像の把握、相互関係の分析が可能
- **具体例**: 10台の機械を1人の観測者が巡回観測

**3. 観測対象への影響が少ない**
- **理由**: 瞬間的な観測のため、作業者が意識しにくい
- **効果**: より自然な状態のデータ収集が可能
- **具体例**: 作業者が観測を意識せず通常通り作業

### デメリット
**1. 短時間作業の把握困難**
- **理由**: 瞬間観測のため、短時間で終わる作業を見逃す可能性
- **影響**: 重要だが短時間の作業が過小評価される
- **対策**: 観測回数を増やす、連続観測と併用

**2. 詳細な作業内容の把握不可**
- **理由**: 状態のみを記録し、作業の詳細内容は不明
- **影響**: 作業方法の改善には別途詳細分析が必要
- **対策**: 代表的な時間帯で連続観測を実施

**3. 統計的誤差の存在**
- **理由**: サンプリングによる推定のため、誤差が必ず存在
- **影響**: 100%正確な値は得られない
- **対策**: 必要精度に応じた観測回数の設定

## 6. 選択・導入の指針

### 手法選択の基準
| 観点 | ワークサンプリング | 連続観測法 | 実績記録法 |
|------|-------------------|-----------|-----------|
| 精度 | ○（統計的精度） | ◎（完全把握） | △（記録精度依存） |
| 速度 | ◎（短時間） | △（長時間） | ○（自動記録） |
| コスト | ◎（低コスト） | △（高コスト） | ○（システム次第） |
| 習得難易度 | ○（統計知識要） | ◎（単純） | △（システム理解要） |

### 適用判断フローチャート
1. **観測対象は複数か？** 
   - Yes → ワークサンプリング推奨
   - No → 次の判断へ

2. **詳細な作業分析が必要か？**
   - Yes → 連続観測法推奨
   - No → ワークサンプリング検討

3. **統計的精度で十分か？**
   - Yes → ワークサンプリング推奨
   - No → 連続観測法または実績記録法

標準誤差 = √(0.7×0.3/100) = √(0.21/100) = 0.0458 ≈ 4.6%<br>
<br>
Aが間違いの理由：計算値の約半分<br>
Cが間違いの理由：稼働率と標準誤差を混同<br>
Dが間違いの理由：計算値の2倍以上で過大
</details>

## 9. 専門用語集

このスライドで使用された専門用語について、50音順で解説します。

### あ行
**稼働率（かどうりつ）**
- **読み方**: かどうりつ
- **意味**: 設備や作業者が実際に付加価値を生む作業を行っている時間の割合。総時間に対する実稼働時間の比率
- **関連用語**: 時間稼働率、性能稼働率、設備総合効率（OEE）

**観測間隔（かんそくかんかく）**
- **読み方**: かんそくかんかく
- **意味**: ワークサンプリングにおいて、各観測を行う時刻の間の時間間隔。観測の独立性を保つため適切に設定する必要がある
- **関連用語**: ランダム時刻表、最小間隔

**観測回数（かんそくかいすう）**
- **読み方**: かんそくかいすう
- **意味**: ワークサンプリングで実施する観測の総数。要求される精度と信頼度により決定される
- **関連用語**: 必要観測回数、サンプルサイズ

### か行
**許容誤差（きょようごさ）**
- **読み方**: きょようごさ
- **意味**: ワークサンプリングの結果として許容される推定値の誤差範囲。通常±3%や±5%などで設定
- **関連用語**: 精度、信頼区間

**構成比率（こうせいひりつ）**
- **読み方**: こうせいひりつ
- **意味**: 全体に対する特定の状態や作業の占める割合。パーセンテージで表現される
- **関連用語**: 作業構成、時間構成

### さ行
**作業測定（さぎょうそくてい）**
- **読み方**: さぎょうそくてい
- **意味**: 作業に要する時間を科学的に測定・分析する手法の総称。ワークサンプリング、時間研究などが含まれる
- **関連用語**: IE（Industrial Engineering）、作業研究

**瞬間観測（しゅんかんかんそく）**
- **読み方**: しゅんかんかんそく
- **意味**: ある時点での状態を一瞬で記録する観測方法。ワークサンプリングの基本的な観測方式
- **関連用語**: スナップ観測、点観測

**信頼区間（しんらいくかん）**
- **読み方**: しんらいくかん
- **意味**: 推定値が一定の確率（信頼度）で含まれると期待される範囲。95%信頼区間が一般的
- **関連用語**: 信頼度、区間推定

**信頼度（しんらいど）**
- **読み方**: しんらいど
- **意味**: 推定値が信頼区間内に含まれる確率。通常95%または99%が使用される
- **関連用語**: 有意水準、信頼水準

**層別（そうべつ）**
- **読み方**: そうべつ
- **意味**: データを特定の基準（時間帯、製品種類など）で分類して分析する手法
- **関連用語**: 層別分析、層別サンプリング

### た行
**段取り（だんどり）**
- **読み方**: だんどり
- **意味**: 作業や生産を開始する前の準備作業。工具交換、材料準備、設備調整などが含まれる
- **関連用語**: 段取り替え、SMED（シングル段取り）

### な行
**二項分布（にこうぶんぷ）**
- **読み方**: にこうぶんぷ
- **意味**: 成功か失敗かの2つの結果しかない試行を繰り返したときの成功回数の確率分布
- **関連用語**: ベルヌーイ試行、確率分布

### は行
**標準誤差（ひょうじゅんごさ）**
- **読み方**: ひょうじゅんごさ
- **意味**: 推定値のばらつきを表す指標。標本比率の標準偏差
- **関連用語**: 標準偏差、誤差

**付加価値作業（ふかかちさぎょう）**
- **読み方**: ふかかちさぎょう
- **意味**: 製品やサービスの価値を高める作業。顧客が対価を支払う価値のある作業
- **関連用語**: 主作業、価値作業

### ま行
**無作為抽出（むさくいちゅうしゅつ）**
- **読み方**: むさくいちゅうしゅつ
- **意味**: すべての要素が等しい確率で選ばれるような抽出方法。ランダムサンプリング
- **関連用語**: ランダム化、確率抽出

### や行
**余裕時間（よゆうじかん）**
- **読み方**: よゆうじかん
- **意味**: 作業者が作業を継続するために必要な休憩や生理的欲求のための時間
- **関連用語**: 余裕率、用達余裕、疲労余裕

**余裕率（よゆうりつ）**
- **読み方**: よゆうりつ
- **意味**: 正味作業時間に対する余裕時間の割合。標準時間設定に使用される
- **関連用語**: 余裕時間、標準時間

### ら行
**ランダム時刻表（らんだむじこくひょう）**
- **読み方**: らんだむじこくひょう
- **意味**: ワークサンプリングで使用する、無作為に決定された観測時刻の一覧表
- **関連用語**: 乱数表、観測スケジュール

**連続観測法（れんぞくかんそくほう）**
- **読み方**: れんぞくかんそくほう
- **意味**: 作業の開始から終了まで連続的に観測・記録する作業測定手法
- **関連用語**: 時間研究、ストップウォッチ法

### わ行
**ワークサンプリング（わーくさんぷりんぐ）**
- **読み方**: わーくさんぷりんぐ
- **意味**: 作業者や機械の活動状態を統計的手法により分析する作業測定技術。Work Samplingの日本語表記
- **関連用語**: 作業抽出法、稼働分析

### アルファベット
**OEE (Overall Equipment Effectiveness)**
- **読み方**: オーイーイー
- **意味**: 設備総合効率。時間稼働率×性能稼働率×良品率で算出される設備の総合的な効率指標
- **関連用語**: TPM、設備効率

**SMED (Single Minute Exchange of Die)**
- **読み方**: スメッド
- **意味**: シングル段取り。段取り時間を10分未満に短縮することを目指す改善手法
- **関連用語**: 段取り改善、内段取り、外段取り

**95%信頼度（きゅうじゅうごパーセントしんらいど）**
- **読み方**: きゅうじゅうごパーセントしんらいど
- **意味**: 推定値が信頼区間に含まれる確率が95%であること。最も一般的に使用される信頼度
- **関連用語**: 信頼区間、有意水準5%

---

**専門用語集作成時の注意点:**
- **正確性**: 定義は作業測定・IE分野の標準に準拠
- **実用性**: 実際の現場で使われる文脈を含めて説明
- **関連性**: 関連する用語や概念との関係を明記
- **理解しやすさ**: 専門知識がない読者でも理解できる説明
