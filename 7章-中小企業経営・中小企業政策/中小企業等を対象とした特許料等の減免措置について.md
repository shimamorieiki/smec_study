# 中小企業等を対象とした特許料等の減免措置について

## 概要

日本の特許制度では、イノベーションの促進と中小企業の知的財産活動の支援を目的として、中小企業等を対象とした特許料等の減免措置が設けられています。この制度は、資金力に限りがある中小企業や個人発明家、大学等が特許権を取得・維持しやすくすることで、日本全体の技術開発力の向上を図るものです。

特許料等の減免措置は、2019年4月1日に施行された改正特許法により大幅に拡充され、より多くの中小企業等が利用しやすい制度となりました。減免対象となる料金は、審査請求料、特許料（1～10年分）、国際出願に係る手数料など多岐にわたります。

## 1. 基本概念・定義

### 特許料等の減免措置とは
- **定義**: 一定の要件を満たす中小企業、個人、大学等に対して、特許関係料金を軽減または免除する制度
- **特徴**: 事前の審査や証明書の提出を不要とし、申請書と簡単な添付書類のみで適用可能
- **重要性**: 中小企業等の知的財産活動を経済的に支援し、イノベーションを促進する

### 減免対象となる料金
- **定義**: 特許出願から権利維持までに必要な各種手数料のうち、減免措置の対象となるもの
- **特徴**: 審査請求料と特許料（年金）が主な対象
- **重要性**: 特許取得・維持にかかる費用負担を大幅に軽減

## 2. 減免措置の種類と要件

### 減免率による分類
減免措置は、対象者の属性や規模により、異なる減免率が適用されます。

### 中小企業（会社）
| 項目 | 内容 |
|------|------|
| 特徴 | 中小企業基本法で定義される中小企業 |
| 適用範囲 | 審査請求料：1/2軽減、特許料（1～10年）：1/2軽減 |
| 注意点 | 大企業の子会社等は対象外 |

### 小規模企業・個人事業主
| 項目 | 内容 |
|------|------|
| 特徴 | 従業員20人以下（商業・サービス業は5人以下）の企業 |
| 適用範囲 | 審査請求料：1/3に軽減、特許料（1～10年）：1/3に軽減 |
| 注意点 | 業種により従業員数の基準が異なる |

### 中小ベンチャー企業・小規模ベンチャー企業
| 項目 | 内容 |
|------|------|
| 特徴 | 設立10年未満で一定の要件を満たす企業 |
| 適用範囲 | 審査請求料：1/3に軽減、特許料（1～10年）：1/3に軽減 |
| 注意点 | 試験研究費等の売上高比率が3%超であることが必要 |

### 大学等・大学等研究者
| 項目 | 内容 |
|------|------|
| 特徴 | 大学、高等専門学校、大学共同利用機関等 |
| 適用範囲 | 審査請求料：1/2軽減、特許料（1～10年）：1/2軽減 |
| 注意点 | 承認TLOに対する譲渡も対象 |

### 個人
| 項目 | 内容 |
|------|------|
| 特徴 | 市町村民税非課税者等の個人 |
| 適用範囲 | 審査請求料：免除または1/3に軽減、特許料（1～10年）：免除または1/3に軽減 |
| 注意点 | 所得に応じて減免率が異なる |

## 3. 具体的計算例・事例

### ケース1: 中小企業による特許出願

#### パターンA: 通常料金の場合
- **前提条件**: 請求項数10の特許出願
- **計算過程**: 
  - 審査請求料：138,000円＋（請求項数10－1）×4,000円 = 174,000円
  - 特許料（1～3年）：年額4,300円×3年 = 12,900円
  - 合計：186,900円
- **結果**: 初期費用として186,900円が必要

#### パターンB: 減免措置適用（1/2軽減）の場合
- **前提条件**: 同上の条件で中小企業として減免申請
- **計算過程**: 
  - 審査請求料：174,000円×1/2 = 87,000円
  - 特許料（1～3年）：12,900円×1/2 = 6,450円
  - 合計：93,450円
- **結果**: 93,450円の負担で済み、93,450円の軽減効果

### ケース2: 小規模企業による複数特許の維持

#### パターンA: 通常料金での10年間維持
- **前提条件**: 5件の特許を10年間維持
- **計算過程**: 
  - 1件あたり10年間の特許料：約33万円
  - 5件の合計：約165万円
- **結果**: 10年間で165万円の維持費が必要

#### パターンB: 減免措置適用（1/3に軽減）の場合
- **前提条件**: 同上の条件で小規模企業として減免申請
- **計算過程**: 
  - 1件あたり10年間の特許料：約33万円×1/3 = 約11万円
  - 5件の合計：約55万円
- **結果**: 10年間で55万円の負担で済み、110万円の軽減効果

### ケース3: 大学発ベンチャーによる国際出願

#### 国際出願関連手数料の減免
- **前提条件**: PCT国際出願を行う大学発ベンチャー（設立5年目）
- **計算過程**: 
  - 国際出願手数料（送付手数料＋調査手数料）：約20万円
  - 減免適用（2/3軽減）：約20万円×1/3 = 約6.7万円
- **結果**: 国際出願の初期費用を大幅に削減可能

## 4. 手続き・プロセス

### 減免申請の流れ
1. **ステップ1: 要件の確認**
   - 詳細説明：自社が減免対象の要件を満たしているか確認
   - 必要書類：定款、登記事項証明書、決算書類等
   - 注意点：大企業の子会社でないことの確認が必要

2. **ステップ2: 申請書の作成**
   - 詳細説明：減免申請書に必要事項を記入
   - 必要書類：減免申請書、証明書類（必要に応じて）
   - 注意点：2019年4月以降は証明書類の提出が原則不要

3. **ステップ3: 料金納付**
   - 詳細説明：減免後の料金を計算して納付
   - 必要書類：納付書（減免後の金額を記載）
   - 注意点：減免申請と同時に料金納付が必要

4. **ステップ4: 適用確認**
   - 詳細説明：特許庁からの通知により減免適用を確認
   - 必要書類：特になし
   - 注意点：要件を満たさない場合は差額納付が必要

### 関連する制度・規則
- **根拠法令**: 特許法第195条の2、特許法施行令第10条
- **所管官庁**: 特許庁
- **関連制度**: 中小企業等特許関係料金減免制度、産業競争力強化法に基づく特許料軽減制度

## 5. 実務上の注意点

### 減免申請時の重要ポイント
- **ポイント1**: 出願人全員が減免対象者である必要がある（共同出願の場合）
- **ポイント2**: 権利の譲渡や実施許諾により減免要件を満たさなくなる場合がある
- **ポイント3**: 虚偽の申請は刑事罰の対象となる可能性がある

### よくある誤解・トラブル
- **誤解1**: 「一度減免を受ければ永続的に適用される」→ 正しくは毎年の特許料納付時に要件確認が必要
- **誤解2**: 「赤字企業は自動的に減免対象」→ 正しくは規模要件等を満たす必要がある
- **誤解3**: 「減免申請は複雑で時間がかかる」→ 正しくは2019年改正により大幅に簡素化

## 6. よくある質問（Q&A）

### Q1. 共同出願の場合、一部の出願人のみが減免対象者でも減免は受けられますか？

**A1.** いいえ、共同出願の場合は出願人全員が減免対象者である必要があります。

#### 詳細説明
共同出願において減免措置を受けるためには、すべての出願人が減免要件を満たしている必要があります。例えば、中小企業と大企業が共同出願する場合、大企業が含まれているため減免措置は適用されません。ただし、持分に応じた減免という制度もあるため、詳細は特許庁に確認することをお勧めします。

### Q2. 特許権を譲渡した後も減免は継続されますか？

**A2.** 譲受人が減免要件を満たしている場合のみ継続されます。

#### 詳細説明
特許権の譲渡後は、譲受人の属性により減免の継続可否が決まります。譲受人が大企業等の減免対象外である場合、次回の特許料納付から通常料金となります。譲渡の際は、減免措置への影響も考慮して検討することが重要です。

### Q3. 減免申請のタイミングはいつですか？

**A3.** 各種料金の納付時に同時に申請します。

#### 詳細説明
審査請求料は審査請求時、特許料は特許料納付時（登録時または年金納付時）に減免申請を行います。事前申請や一括申請はできないため、各納付のタイミングで都度申請が必要です。電子出願ソフトを利用すれば、納付と同時に簡単に申請できます。

### Q4. 外国企業の日本法人は減免対象になりますか？

**A4.** 日本法人として中小企業の要件を満たせば対象となります。

#### 詳細説明
外国企業の100%子会社であっても、その親会社が外国の中小企業であり、日本法人自体が中小企業の要件を満たしていれば減免対象となります。ただし、親会社が外国の大企業の場合は、日本法人も大企業の子会社として扱われ、減免対象外となります。

## 7. まとめ・今後の展望

中小企業等を対象とした特許料等の減免措置は、日本のイノベーション促進において重要な役割を果たしています。2019年の法改正により申請手続きが大幅に簡素化され、より多くの中小企業等が利用しやすい制度となりました。

今後は、スタートアップ企業への更なる支援拡充や、国際出願関連費用の減免範囲拡大などが検討されています。また、デジタル化の進展により、オンラインでの申請・管理がより簡便になることが期待されます。中小企業等においては、この減免制度を積極的に活用し、知的財産戦略を推進することが競争力強化につながるでしょう。

### あ行

- **読み方**: いのべーしょん
- **意味**: 新しい技術や手法、アイデアなどを導入し、経済的・社会的価値を創造すること。技術革新。
- **関連用語**: 研究開発、知的財産

### か行

**共同出願（きょうどうしゅつがん）**
- **読み方**: きょうどうしゅつがん
- **意味**: 複数の者が共同で特許出願を行うこと。出願人全員の同意が必要。
- **関連用語**: 出願人、共有特許

**減免措置（げんめんそち）**
- **読み方**: げんめんそち
- **意味**: 一定の要件を満たす者に対して、料金を軽減または免除する制度。
- **関連用語**: 軽減、免除

**研究開発費比率（けんきゅうかいはつひひりつ）**
- **読み方**: けんきゅうかいはつひひりつ
- **意味**: 売上高に対する研究開発費の割合。中小ベンチャー企業の認定基準の一つ。
- **関連用語**: 試験研究費、開発費

### さ行

**審査請求（しんさせいきゅう）**
- **読み方**: しんさせいきゅう
- **意味**: 特許出願について実体審査を求める手続き。出願から3年以内に行う必要がある。
- **関連用語**: 審査請求料、実体審査

**承認TLO（しょうにんてぃーえるおー）**
- **読み方**: しょうにんてぃーえるおー
- **意味**: 大学等の研究成果を民間企業へ技術移転する機関で、文部科学省・経済産業省の承認を受けたもの。
- **関連用語**: 技術移転、産学連携

**小規模企業（しょうきぼきぎょう）**
- **読み方**: しょうきぼきぎょう
- **意味**: 製造業等は従業員20人以下、商業・サービス業は5人以下の企業。
- **関連用語**: 中小企業、零細企業

### た行

**中小企業（ちゅうしょうきぎょう）**
- **読み方**: ちゅうしょうきぎょう
- **意味**: 中小企業基本法で定める一定規模以下の企業。業種により資本金・従業員数の基準が異なる。
- **関連用語**: 小規模企業、中小企業基本法

**中小ベンチャー企業（ちゅうしょうべんちゃーきぎょう）**
- **読み方**: ちゅうしょうべんちゃーきぎょう
- **意味**: 設立10年未満で、試験研究費等比率が売上高の3%超の中小企業。
- **関連用語**: スタートアップ、研究開発型企業

**特許料（とっきょりょう）**
- **読み方**: とっきょりょう
- **意味**: 特許権を維持するために毎年納付する料金。年金とも呼ばれる。
- **関連用語**: 年金、維持費

- **意味**: 経済産業省の外局で、産業財産権の審査・登録等を行う行政機関。
