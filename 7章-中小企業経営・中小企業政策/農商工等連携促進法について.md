# 農商工等連携促進法について

## 概要
農商工等連携促進法（正式名称：中小企業者と農林漁業者との連携による事業活動の促進に関する法律）は、中小企業者と農林漁業者が有機的に連携し、それぞれの経営資源を有効に活用して行う事業活動を促進することにより、中小企業の経営の向上及び農林漁業経営の改善を図ることを目的として、平成20年（2008年）に制定された法律です。

この法律は、農林漁業と商工業の垣根を越えた連携を促進し、地域経済の活性化と新たな価値創造を目指すものです。従来の産業別の縦割り行政から脱却し、異業種間の連携による相乗効果を生み出すことで、両者の経営改善と地域経済の発展を実現することを狙いとしています。

## 1. 基本概念・定義

### 農商工等連携の定義
- **定義**: 中小企業者と農林漁業者が通常の商取引関係を超えて協力し、お互いの強みを活かした新商品の開発、生産若しくは需要の開拓又は新サービスの開発、提供若しくは需要の開拓を行うこと
- **特徴**: 単なる原材料の売買関係ではなく、共同での商品開発や販路開拓など、より深い協業関係を構築すること
- **重要性**: 農林漁業の6次産業化を促進し、付加価値の高い商品・サービスを創出することで、両者の収益性向上を実現する

### 中小企業者の定義
- **定義**: 中小企業基本法に定める中小企業者（業種により資本金・従業員数の基準が異なる）
- **特徴**: 製造業、卸売業、小売業、サービス業など幅広い業種が対象
- **重要性**: 農林漁業者との連携により、新たな事業機会の創出と経営の向上を図る主体

### 農林漁業者の定義
- **定義**: 農業、林業又は漁業を営む者（個人・法人を問わない）
- **特徴**: 第一次産業に従事する生産者全般が対象
- **重要性**: 商工業者との連携により、生産物の高付加価値化と販路拡大を実現する主体

## 2. 支援措置の種類

### 支援措置の分類基準
農商工等連携促進法に基づく支援措置は、連携事業の段階や内容に応じて、以下のように分類されます。

### 農商工等連携事業計画の認定制度
| 項目 | 内容 |
|------|------|
| 特徴 | 中小企業者と農林漁業者が共同で作成した事業計画を国が認定 |
| 適用範囲 | 新商品・新サービスの開発、生産・提供、需要開拓に関する事業 |
| 注意点 | 両者が対等な立場で連携し、それぞれの経営改善が見込まれることが必要 |

### 農商工等連携支援事業計画の認定制度
| 項目 | 内容 |
|------|------|
| 特徴 | 農商工連携を支援する事業を行う者（支援機関等）の計画を国が認定 |
| 適用範囲 | 連携体のマッチング、事業計画作成支援、販路開拓支援等 |
| 注意点 | 公益法人、NPO法人、商工会議所、商工会等が主な対象 |

## 3. 支援の金額・割合の詳細

### 補助金・助成金の支援内容

#### 基本的な補助率
- **補助率**: 対象経費の**2/3以内**
- **自己負担**: 残り1/3は事業者負担
- **注意点**: 補助金は原則として後払い（立替払いが必要）

#### 用途別の補助上限額
| 支援内容 | 補助上限額 | 主な対象経費 |
|----------|------------|--------------|
| 試作品開発・実証実験 | 500万円 | 原材料費、外注加工費、技術指導料等 |
| 市場調査・展示会出展 | 200万円 | 調査委託費、出展料、装飾費等 |
| 設備導入（生産・加工用） | 1,000万円 | 機械装置購入費、改良費等 |
| システム開発（IT活用） | 3,000万円 | ソフトウェア開発費、システム構築費等 |
| 販路開拓・ブランディング | 300万円 | 広告宣伝費、パッケージデザイン費等 |
| 専門家派遣 | 1回あたり3万円 | コンサルタント謝金、旅費等 |

### 融資制度の優遇内容

#### 日本政策金融公庫による低利融資
| 項目 | 内容 |
|------|------|
| 金利優遇 | **基準金利マイナス0.9%** |
| 融資限度額 | 設備資金：7億2,000万円以内<br>運転資金：2億5,000万円以内 |
| 返済期間 | 設備資金：20年以内（据置3年以内）<br>運転資金：7年以内（据置2年以内） |
| 担保・保証人 | 要相談（事業内容により柔軟に対応） |

#### 信用保証の特例措置
| 項目 | 内容 |
|------|------|
| 普通保証 | 2億円 → **4億円**に拡大 |
| 無担保保証 | 8,000万円 → **1億6,000万円**に拡大 |
| 特別小口保証 | 1,250万円 → **2,500万円**に拡大 |
| 保証料率 | 通常より**0.1～0.2%**程度優遇 |

### 税制優遇措置の詳細

#### 中小企業投資促進税制
| 対象設備 | 優遇内容 | 適用要件 |
|----------|----------|----------|
| 機械装置 | **特別償却30%**<br>または<br>**税額控除7%** | 1台160万円以上 |
| 器具備品 | **特別償却30%**<br>または<br>**税額控除7%** | 1台120万円以上 |
| ソフトウェア | **特別償却30%**<br>または<br>**税額控除7%** | 一つ70万円以上 |

**※注意**: 資本金3,000万円以下の法人・個人事業主のみ税額控除の選択が可能

### その他の支援措置

#### 各種支援制度の活用
| 支援項目 | 内容 | 備考 |
|----------|------|------|
| 特許料等の減免 | 審査請求料・特許料を**1/2に軽減** | 認定計画に基づく開発成果が対象 |
| 中小機構の専門家継続派遣 | **年間10回まで無料** | 通常は1企業5回まで |
| JETRO輸出支援 | 海外展示会出展支援の**優先採択** | 認定商品の輸出が対象 |
| 地域団体商標の登録料減免 | 登録料・更新料を**1/2に軽減** | 連携体での出願が対象 |

### 支援措置利用時の注意点

#### 重要な留意事項
1. **併用制限**: 他の国の補助金との併用は原則不可（重複排除）
2. **事前着手の禁止**: 認定前に開始した事業は補助対象外
3. **経理の区分**: 補助事業の経理を明確に区分管理する必要
4. **成果報告**: 事業終了後5年間は成果報告書の提出義務
5. **収益納付**: 補助事業により相当の収益が生じた場合は、補助金の一部返還の可能性

## 4. 具体的な事例

### ケース1: 地域特産品を活用した新商品開発

#### パターンA: 農業者と食品製造業者の連携
- **前提条件**: 
  - 農業者：高品質なトマトを生産するが、規格外品の廃棄が課題
  - 食品製造業者：新商品開発のための差別化された原材料を探索
- **連携内容**: 
  - 規格外トマトを活用した高付加価値トマトソースの共同開発
  - 農業者の栽培ノウハウと製造業者の加工技術を融合
- **支援内容**: 
  - 試作品開発費用の補助（上限500万円）
  - 新商品の販路開拓支援
  - 専門家によるマーケティング指導
- **結果**: 年間売上2,000万円の新商品として事業化に成功

#### パターンB: 漁業者と飲食業者の連携
- **前提条件**: 
  - 漁業者：未利用魚の有効活用が課題
  - 飲食業者：地域色のあるメニュー開発を模索
- **連携内容**: 
  - 未利用魚を活用した新メニューの共同開発
  - 漁業者による鮮度管理技術の提供
- **支援内容**: 
  - 設備導入費用の補助（上限1,000万円）
  - HACCP導入支援
  - ブランディング支援
- **結果**: 地域の名物料理として定着し、観光客増加に貢献

### ケース2: 農業の6次産業化支援

#### パターンA: 農業者とIT企業の連携
- **前提条件**: 
  - 農業者：生産管理の効率化と直販体制構築が課題
  - IT企業：農業分野での新サービス開発を計画
- **連携内容**: 
  - 生産管理システムとECサイトの共同開発
  - IoTセンサーによる栽培データの収集・分析
- **支援内容**: 
  - システム開発費の補助（上限3,000万円）
  - 中小企業基盤整備機構による経営指導
  - 日本政策金融公庫による低利融資
- **結果**: 生産性30%向上、直販比率50%達成

#### パターンB: 林業者と建築業者の連携
- **前提条件**: 
  - 林業者：地域材の需要拡大が課題
  - 建築業者：環境配慮型住宅の差別化を検討
- **連携内容**: 
  - 地域材を活用したエコ住宅の共同開発
  - トレーサビリティシステムの構築
- **支援内容**: 
  - 商品開発費の補助（上限1,000万円）
  - 展示会出展支援
  - 認証取得支援
- **結果**: 年間20棟の受注を達成、地域材利用率80%実現

## 5. 認定手続きとプロセス

### 農商工等連携事業計画の認定手続き
1. **事前相談**: 
   - 詳細説明：各地域の経済産業局・地方農政局で事前相談を実施
   - 必要書類：事業概要書、連携体制図
   - 注意点：両者の役割分担と経営改善効果を明確化

2. **計画書作成**: 
   - 詳細説明：所定の様式に従い、5年以内の事業計画を作成
   - 必要書類：事業計画書、収支計画書、連携契約書案
   - 注意点：定量的な目標設定（売上高、付加価値額等）が必要

3. **申請書提出**: 
   - 詳細説明：経済産業局・地方農政局に共同で申請
   - 必要書類：申請書一式、添付書類（定款、決算書等）
   - 注意点：申請時期は年4回程度（要確認）

4. **審査・認定**: 
   - 詳細説明：書面審査及び必要に応じてヒアリング実施
   - 必要書類：追加資料の提出を求められる場合あり
   - 注意点：審査期間は概ね2～3ヶ月

### 関連する制度・規則
- **根拠法令**: 中小企業者と農林漁業者との連携による事業活動の促進に関する法律（平成20年法律第38号）
- **所管官庁**: 経済産業省（中小企業庁）、農林水産省
- **関連制度**: 6次産業化法、地域資源活用促進法、中小企業地域資源活用プログラム

- **ポイント1**: 対等なパートナーシップの構築 - お互いの経営資源と専門性を尊重し、Win-Winの関係を築く
- **ポイント2**: 明確な役割分担と責任の所在 - 契約書等で各者の役割、費用負担、利益配分を明確化
- **ポイント3**: 継続的なコミュニケーション - 定期的な会議体の設置と情報共有の仕組み構築

### よくある誤解・トラブル
- **誤解1**: 単なる原材料供給契約でも認定される → 正しい理解：共同での新商品開発等、より深い連携が必要
- **誤解2**: 認定を受ければ自動的に補助金がもらえる → 正しい理解：認定後、別途補助金申請が必要で、採択は競争的

## 7. よくある質問（Q&A）

### Q1. 農商工等連携事業計画の認定を受けるメリットは何ですか？

**A1.** 認定を受けることで、以下のような様々な支援措置を受けることができます。

#### 支援措置の詳細
1. **補助金・助成金**：試作品開発、展示会出展、専門家派遣等に対する費用補助（補助率2/3以内）
2. **低利融資**：日本政策金融公庫による設備資金・運転資金の低利融資（基準金利-0.9%）
3. **信用保証**：中小企業信用保険法の特例による保証限度額の拡大
4. **税制優遇**：機械装置等の特別償却または税額控除（中小企業投資促進税制）
5. **専門家支援**：中小企業基盤整備機構等による継続的な経営支援

### Q2. 認定申請にあたって、中小企業者と農林漁業者の出資比率に制限はありますか？

**A2.** 出資比率に関する明確な制限はありませんが、実質的に対等な連携であることが重要です。

#### 判断基準の詳細
- **形式的要件**：共同申請であること、連携契約が締結されていること
- **実質的要件**：
  - 両者がそれぞれの経営資源を有効活用していること
  - 事業リスクを適切に分担していること
  - 利益配分が貢献度に応じて公平に設定されていること
- **審査のポイント**：一方が他方の下請け的立場にならないよう、対等性が確保されているかを重視

## 8. まとめ・今後の展望

農商工等連携促進法は、農林漁業と商工業の連携による新たな価値創造を支援する重要な制度です。地域資源を活用した6次産業化の推進、農林漁業者の所得向上、中小企業の新事業展開など、多様な効果が期待されています。

今後は、デジタル技術の活用による連携の高度化、輸出を視野に入れたグローバル展開、SDGsに対応した持続可能な連携モデルの構築などが重要なテーマとなるでしょう。また、コロナ禍を経て、地産地消やサプライチェーンの強靭化の観点からも、農商工連携の重要性はさらに高まっています。

国も令和3年度から「農商工等連携促進法」の運用を見直し、オンラインでの申請手続きの簡素化や、スタートアップ企業との連携促進など、時代のニーズに応じた制度改善を進めています。

**マッチング（まっちんぐ）**
- **読み方**: まっちんぐ
- **意味**: 連携を希望する事業者同士を引き合わせること
- **関連用語**: コーディネート、ビジネスマッチング

**未利用資源（みりようしげん）**
- **読み方**: みりようしげん
- **意味**: 規格外品、未利用魚など、従来活用されていなかった資源
- **関連用語**: 資源の有効活用、循環型社会

### や行

**有機的連携（ゆうきてきれんけい）**
- **読み方**: ゆうきてきれんけい
- **意味**: 各主体が密接に結びつき、相互作用しながら一体的に機能する連携
- **関連用語**: 協業、シナジー効果

### ら行

**連携契約（れんけいけいやく）**
- **読み方**: れんけいけいやく
- **意味**: 農商工等連携事業における役割分担、費用負担、利益配分等を定めた契約
- **関連用語**: 契約書、協定書

**ローカルブランド（ろーかるぶらんど）**
- **読み方**: ろーかるぶらんど
- **意味**: 地域の特産品や地域名を冠したブランド
- **関連用語**: 地域ブランド、地理的表示（GI）
