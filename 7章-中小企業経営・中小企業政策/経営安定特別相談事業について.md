# 経営安定特別相談事業について

## 概要

経営安定特別相談事業は、中小企業・小規模事業者が経営の安定に支障を生じるような問題に直面した際に、商工会議所や商工会等が設置する「経営安定特別相談室」において、経営の専門家が相談に応じる公的支援制度です。特に、連鎖倒産防止、経営危機の回避、円滑な事業承継など、中小企業の経営安定化を図ることを目的として、昭和48年の第一次オイルショック時に創設されました。

本事業は、単なる相談対応にとどまらず、弁護士、公認会計士、税理士、中小企業診断士などの専門家と連携し、経営改善計画の策定から金融機関との調整、法的整理の支援まで、包括的なサポートを提供する重要な中小企業支援施策です。

## 1. 基本概念・定義

### 経営安定特別相談事業の定義
- **定義**: 経営の安定に支障を生じている中小企業・小規模事業者に対し、商工会議所等に設置された経営安定特別相談室が、倒産回避や経営再建のための相談・支援を行う公的制度
- **特徴**: 無料相談、専門家連携、秘密厳守、全国的なネットワーク
- **重要性**: 地域経済の安定、雇用の維持、連鎖倒産の防止に寄与

### 経営安定特別相談室
- **定義**: 商工会議所・商工会・都道府県商工会連合会に設置され、経営危機に直面した中小企業の相談に応じる専門組織
- **特徴**: 全国約250か所に設置、統一的な支援体制、地域密着型の支援
- **重要性**: 中小企業にとって身近で利用しやすい相談窓口として機能

### 商工調停士
- **定義**: 経営安定特別相談室において、倒産回避や経営再建のための相談・指導を行う専門家
- **特徴**: 豊富な経営経験、調停能力、守秘義務の遵守
- **重要性**: 中立的立場から企業と債権者の調整を行う重要な役割

## 2. 相談対象・支援内容の分類

### 相談対象企業の要件
経営安定特別相談事業の対象となる企業は、以下のような状況にある中小企業・小規模事業者です。

### 経営危機の類型
| 項目 | 内容 |
|------|------|
| 資金繰り悪化型 | 売上減少、回収遅延、過剰在庫等による運転資金不足 |
| 連鎖倒産危機型 | 取引先の倒産による売掛金回収不能、受注急減 |
| 過剰債務型 | 借入金返済負担が収益を圧迫、債務超過状態 |
| 事業承継困難型 | 後継者不在、承継時の資金不足、株式買取資金不足 |

### 支援内容の詳細
| 支援メニュー | 内容 | 対応する専門家 |
|-------------|------|---------------|
| 経営診断・分析 | 財務状況の把握、問題点の抽出、改善可能性の判断 | 中小企業診断士、公認会計士 |
| 再建計画策定 | 経営改善計画、資金繰り計画、事業再構築計画の作成 | 中小企業診断士、税理士 |
| 金融調整 | 金融機関との交渉、リスケジュール、新規融資の斡旋 | 商工調停士、金融機関OB |
| 法的整理支援 | 民事再生、破産手続き、特定調停の支援 | 弁護士、司法書士 |
| 事業承継支援 | 承継計画策定、M&A仲介、株式評価 | 税理士、中小企業診断士 |

## 3. 具体的な支援プロセス・事例

### ケース1: 売上急減による資金繰り悪化企業の支援

#### パターンA: リスケジュールによる再建
- **前提条件**: 
  - 年商3億円の製造業
  - 主要取引先の発注減により売上が前年比40%減少
  - 借入金残高8,000万円、月次返済額300万円
  - 従業員20名

- **支援過程**: 
  1. 経営安定特別相談室への相談（相談から3日以内に初回面談）
  2. 財務状況の詳細分析（1週間以内に完了）
  3. 金融機関への返済猶予要請（元金返済を1年間停止）
  4. 経営改善計画の策定（3年間で黒字化を目指す）
  5. 新規受注先の開拓支援（商工会議所のネットワーク活用）

- **結果**: 
  - 月次返済額を300万円から50万円（利息のみ）に軽減
  - 資金繰りが改善し、倒産を回避
  - 1年後に新規取引先3社を獲得、売上が回復基調に

#### パターンB: 事業再編による再生
- **前提条件**: 
  - 年商5億円の小売業（3店舗運営）
  - 競合店進出により全店舗が赤字化
  - 債務超過額3,000万円
  - 従業員35名

- **支援過程**: 
  1. 全店舗の収益性分析
  2. 不採算店舗2店舗の閉鎖決定
  3. 従業員の配置転換と希望退職の実施
  4. 残存店舗の競争力強化（品揃え・サービス改革）
  5. 金融機関との債務減免交渉

- **結果**: 
  - 月次収支が300万円の赤字から50万円の黒字に転換
  - 債務の一部（1,500万円）について減免を受ける
  - 雇用の7割（25名）を維持

### ケース2: 連鎖倒産危機への対応

#### パターンA: 緊急資金調達による危機回避
- **前提条件**: 
  - 年商2億円の卸売業
  - 主要販売先（売上の60%）が突然倒産
  - 売掛金4,000万円が回収不能に
  - 運転資金が1か月分しかない

- **支援過程**: 
  1. 緊急相談対応（当日中に商工調停士が対応）
  2. セーフティネット保証の申請支援（2日以内）
  3. 日本政策金融公庫への緊急融資申込み
  4. 既存取引先への販売強化、新規開拓
  5. 売掛金回収の一部可能性調査（破産管財人との交渉）

- **結果**: 
  - 緊急融資2,000万円を2週間で調達
  - 資金ショートを回避し、事業継続
  - 6か月後に新規取引先を5社開拓、売上の分散化に成功

## 4. 手続き・利用方法

### 相談申込みから支援開始までの流れ

1. **相談申込み**: 
   - 最寄りの商工会議所・商工会に電話または訪問
   - 必要書類：決算書3期分、試算表、資金繰り表
   - 注意点：早期相談が重要、手遅れになる前に

2. **初回面談（相談受付から3営業日以内）**: 
   - 商工調停士による状況ヒアリング
   - 必要書類：会社概要、取引先一覧、借入金一覧
   - 注意点：正確な情報開示が支援の前提

3. **経営診断・分析（1週間程度）**: 
   - 財務分析、SWOT分析、資金繰り分析
   - 必要書類：詳細な財務資料、事業計画書
   - 注意点：追加資料の提出を求められる場合あり

4. **支援方針の決定**: 
   - 再建可能性の判断
   - 支援メニューの選定
   - 専門家チームの編成

5. **具体的支援の実施**: 
   - 各種計画の策定
   - 関係者との調整
   - 進捗管理とフォローアップ

### 関連する制度・支援機関
- **根拠**: 中小企業支援法、商工会議所法、商工会法
- **所管官庁**: 経済産業省中小企業庁
- **連携機関**: 
  - 日本商工会議所
  - 全国商工会連合会
  - 中小企業基盤整備機構
  - 信用保証協会
  - 日本政策金融公庫

## 5. 実務上の注意点

### 相談時の重要ポイント
- **ポイント1**: 早期相談が成功の鍵 - 資金繰りに余裕があるうちに相談することで選択肢が広がる
- **ポイント2**: 正確な情報開示 - 隠し事があると適切な支援が受けられない
- **ポイント3**: 経営者の改善意欲 - 他責にせず、自ら改善に取り組む姿勢が不可欠
- **ポイント4**: 家族の理解と協力 - 個人保証の整理等で家族の協力が必要な場合が多い

### よくある誤解・トラブル
- **誤解1**: 「相談すると倒産が公になる」→ 実際は厳格な守秘義務があり、情報は漏れない
- **誤解2**: 「費用が高額」→ 相談は原則無料、専門家派遣も初回は無料のケースが多い
- **誤解3**: 「金融機関との関係が悪化する」→ むしろ計画的な対応により信頼関係が改善
- **誤解4**: 「法的整理を強要される」→ あくまで私的整理による再建を優先的に検討

## 6. よくある質問（Q&A）

### Q1. 個人事業主でも相談できますか？

**A1.** はい、相談可能です。経営安定特別相談事業は、法人だけでなく個人事業主も対象としています。

#### 詳細説明
個人事業主の場合、以下の点に注意が必要です：
- 事業用資金と個人資金の区分を明確にする
- 青色申告決算書等の財務資料を準備する
- 個人の債務（住宅ローン等）も含めた総合的な検討が必要
- 小規模事業者持続化補助金等、個人事業主向けの支援策も併せて検討

### Q2. どの程度の債務超過でも支援を受けられますか？

**A2.** 債務超過の程度だけで支援の可否は決まりません。事業の将来性、改善可能性を総合的に判断します。

#### 詳細説明
支援可能性の判断基準：
- **事業性評価**: コア事業の収益力、技術力、顧客基盤
- **経営者の資質**: 改善意欲、実行力、誠実性
- **外部環境**: 市場動向、競合状況、地域経済
- **支援効果**: 雇用維持、地域経済への影響、連鎖倒産防止効果

実際には、債務超過額が年商を超えていても、事業に将来性があれば支援を受けられるケースもあります。

### Q3. 相談内容が取引先や金融機関に漏れることはありませんか？

**A3.** 相談内容は厳格な守秘義務により保護されており、相談者の同意なく第三者に漏れることはありません。

#### 詳細説明
守秘義務の仕組み：
- 商工調停士、相談員は法的な守秘義務を負う
- 相談記録は施錠管理、アクセス制限
- 金融機関等への情報提供は相談者の書面による同意が必要
- 違反した場合は資格剥奪等の処分対象

ただし、支援を進める上で、相談者の同意を得て金融機関等と情報共有することは、むしろ問題解決に有効な場合が多いです。

## 7. まとめ・今後の展望

経営安定特別相談事業は、中小企業の経営危機に対する最後の砦として、これまで多くの企業の倒産を回避し、雇用と地域経済を守ってきました。コロナ禍においても、多くの企業がこの制度を活用して危機を乗り越えています。

今後は、デジタル化による相談体制の強化、AIを活用した経営診断の高度化、事業承継や事業再編支援の充実など、時代のニーズに応じた進化が期待されています。また、予防的な経営相談の強化により、危機に陥る前の早期対応を促進する方向での制度改善も検討されています。

中小企業経営者には、経営に不安を感じた段階で早期に相談することを強く推奨します。「転ばぬ先の杖」として、この制度を積極的に活用することが、持続可能な経営の実現につながります。

## 9. 専門用語集

このスライドで使用された専門用語について、50音順で解説します。

### あ行

**オイルショック**
- **読み方**: おいるしょっく
- **意味**: 1973年と1979年に起きた原油価格の急騰による世界的な経済混乱。第一次オイルショック時に中小企業の経営危機が深刻化し、経営安定特別相談事業創設のきっかけとなった
- **関連用語**: 石油危機、スタグフレーション

### か行

**過剰債務（かじょうさいむ）**
- **読み方**: かじょうさいむ
- **意味**: 企業の返済能力を超えた借入金を抱えている状態。収益力に比して借入金が多すぎ、利払いや元本返済が経営を圧迫する状況
- **関連用語**: 債務超過、資金繰り悪化

**経営改善計画（けいえいかいぜんけいかく）**
- **読み方**: けいえいかいぜんけいかく
- **意味**: 経営危機に陥った企業が、収益力回復と財務健全化を図るために策定する中期的な行動計画。通常3〜5年の計画期間で作成
- **関連用語**: 事業再生計画、リストラクチャリング

**経営安定特別相談室（けいえいあんていとくべつそうだんしつ）**
- **読み方**: けいえいあんていとくべつそうだんしつ
- **意味**: 商工会議所等に設置され、経営危機に直面した中小企業の相談に応じる専門組織。全国約250か所に設置
- **関連用語**: 商工調停士、経営指導員

### さ行

**債務超過（さいむちょうか）**
- **読み方**: さいむちょうか
- **意味**: 企業の負債総額が資産総額を上回っている状態。貸借対照表上、純資産がマイナスとなっている財務状況
- **関連用語**: 資産超過、自己資本

**資金繰り（しきんぐり）**
- **読み方**: しきんぐり
- **意味**: 企業が日々の支払いに必要な現金を確保し、管理すること。売上があっても現金化のタイミングによっては資金不足に陥る場合がある
- **関連用語**: キャッシュフロー、運転資金

**私的整理（してきせいり）**
- **読み方**: してきせいり
- **意味**: 裁判所を介さず、債務者と債権者が任意の話し合いにより債務整理を行う手続き。法的整理に比べて柔軟な対応が可能
- **関連用語**: 法的整理、任意整理

**商工調停士（しょうこうちょうていし）**
- **読み方**: しょうこうちょうていし
- **意味**: 経営安定特別相談室において、企業と債権者の間に立って調整を行う専門家。豊富な経営経験と調停能力を持つ
- **関連用語**: 経営指導員、相談員

**信用保証協会（しんようほしょうきょうかい）**
- **読み方**: しんようほしょうきょうかい
- **意味**: 中小企業が金融機関から融資を受ける際に、その債務を保証する公的機関。各都道府県に設置されている
- **関連用語**: 保証付融資、セーフティネット保証

**セーフティネット保証（せーふてぃねっとほしょう）**
- **読み方**: せーふてぃねっとほしょう
- **意味**: 経営の安定に支障を生じている中小企業を支援するための信用保証制度。通常の保証限度額とは別枠で利用可能
- **関連用語**: 危機関連保証、特別保証

### た行

**中小企業診断士（ちゅうしょうきぎょうしんだんし）**
- **読み方**: ちゅうしょうきぎょうしんだんし
- **意味**: 中小企業の経営診断・助言を行う国家資格を持つ専門家。経営改善計画の策定等で重要な役割を果たす
- **関連用語**: 経営コンサルタント、専門家派遣

- **読み方**: みんじさいせい
- **意味**: 民事再生法に基づく法的整理の一種。経営者が経営を継続しながら、裁判所の監督下で事業の再建を図る手続き

- **関連用語**: 条件変更、返済猶予

**連鎖倒産（れんさとうさん）**
- **読み方**: れんさとうさん
- **意味**: 取引先企業の倒産により売掛金が回収不能となり、それが原因で自社も倒産に至ること。経営安定特別相談事業の重要な防止対象
- **関連用語**: 黒字倒産、取引先リスク
