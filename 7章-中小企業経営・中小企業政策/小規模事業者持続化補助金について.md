# 小規模事業者持続化補助金について

## 概要

小規模事業者持続化補助金は、小規模事業者が自らの経営を見直し、自ら持続的な経営に向けた計画を作成した上で行う販路開拓や生産性向上の取組を支援する制度です。

この補助金は、日本国内の小規模事業者の持続的発展を支援するため、商工会・商工会議所の支援を受けながら経営計画を策定し、その計画に基づいて実施する販路開拓等の取り組みに対して補助金を交付する国の支援制度として2013年度補正予算から開始されました。

新型コロナウイルス感染症の影響により事業環境が大きく変化する中、小規模事業者が事業を継続し、新たな販路を開拓することの重要性が高まっており、本補助金制度の役割はますます重要になっています。

## 1. 基本概念・定義

### 小規模事業者の定義
- **定義**: 中小企業基本法に定める小規模企業者
- **特徴**: 従業員数が一定以下の事業者が対象
- **重要性**: 日本の企業数の約9割を占める経済の基盤

#### 業種別の小規模事業者の定義
| 業種 | 従業員数 |
|------|----------|
| 商業・サービス業（宿泊業・娯楽業を除く） | 常時使用する従業員数5人以下 |
| 宿泊業・娯楽業 | 常時使用する従業員数20人以下 |
| 製造業その他 | 常時使用する従業員数20人以下 |

### 補助対象事業
- **定義**: 策定した経営計画に基づいて実施する、地道な販路開拓等のための取組、あるいは販路開拓等と併せて行う業務効率化のための取組
- **特徴**: 商工会・商工会議所の支援を受けて経営計画を作成し、その計画に沿って実施する事業
- **重要性**: 単なる設備投資ではなく、持続的な経営に向けた取組であることが必要

## 2. 補助金の種類・類型

### 類型の分類基準
補助金は申請者の状況や取組内容に応じて、通常枠と特別枠に分類されます。

### 通常枠
| 項目 | 内容 |
|------|------|
| 特徴 | 一般的な販路開拓等の取組を支援 |
| 補助率 | 2/3 |
| 補助上限額 | 50万円 |
| 対象経費 | 機械装置等費、広報費、ウェブサイト関連費、展示会等出展費、旅費、開発費、資料購入費、雑役務費、借料、設備処分費、委託・外注費 |

### 特別枠の種類

#### 賃金引上げ枠
| 項目 | 内容 |
|------|------|
| 特徴 | 事業場内最低賃金を地域別最低賃金より+30円以上とする小規模事業者 |
| 補助上限額 | 200万円 |
| 補助率 | 2/3（赤字事業者は3/4） |
| 要件 | 補助事業実施期間に事業場内最低賃金を地域別最低賃金より+30円以上とすること |

#### 卒業枠
| 項目 | 内容 |
|------|------|
| 特徴 | 常時使用する従業員を増やし、小規模事業者の従業員数を超えて規模を拡大する事業者 |
| 補助上限額 | 200万円 |
| 補助率 | 2/3 |
| 要件 | 補助事業実施期間中に小規模事業者として定義する従業員数を超えること |

#### 後継者支援枠
| 項目 | 内容 |
|------|------|
| 特徴 | 将来的に事業承継を行う予定があり、新たな取組を行う後継者候補が実施する事業 |
| 補助上限額 | 200万円 |
| 補助率 | 2/3 |
| 要件 | 申請時に「アトツギ甲子園」のファイナリストになった事業者であること |

#### 創業枠
| 項目 | 内容 |
|------|------|
| 特徴 | 過去3年以内に「特定創業支援等事業」による支援を受け創業した事業者 |
| 補助上限額 | 200万円 |
| 補助率 | 2/3 |
| 要件 | 産業競争力強化法に基づく認定市区町村や認定連携創業支援等事業者が実施した「特定創業支援等事業」による支援を過去3年の間に受けたこと |

## 3. 具体的計算例・事例

### ケース1: 飲食店が新規顧客開拓のためのホームページ作成とチラシ配布を行う場合

#### パターンA: 通常枠での申請（補助対象経費80万円の場合）
- **前提条件**: 
  - 従業員3名の飲食店
  - ホームページ作成費用：50万円
  - チラシ印刷・配布費用：30万円
  - 合計：80万円
- **計算過程**: 
  - 補助対象経費：80万円
  - 補助率：2/3
  - 補助金額：80万円 × 2/3 = 53.3万円
  - 上限額50万円を超えるため、補助金額は50万円
- **結果**: 補助金額50万円、自己負担30万円

#### パターンB: 賃金引上げ枠での申請（補助対象経費250万円の場合）
- **前提条件**: 
  - 従業員5名の飲食店（現在の事業場内最低賃金1,000円）
  - 地域別最低賃金：1,000円
  - 事業場内最低賃金を1,030円に引き上げ予定
  - 新型厨房機器導入：150万円
  - 新メニュー開発費：50万円
  - 広告宣伝費：50万円
  - 合計：250万円
- **計算過程**: 
  - 補助対象経費：250万円
  - 補助率：2/3
  - 補助金額：250万円 × 2/3 = 166.7万円
  - 上限額200万円内のため、補助金額は166.7万円
- **結果**: 補助金額166.7万円、自己負担83.3万円

### ケース2: 製造業が展示会出展と新商品開発を行う場合

#### パターンA: 通常枠での申請
- **前提条件**: 
  - 従業員15名の製造業
  - 展示会出展費用：30万円
  - 新商品開発費：40万円
  - 合計：70万円
- **計算過程**: 
  - 補助対象経費：70万円
  - 補助率：2/3
  - 補助金額：70万円 × 2/3 = 46.7万円
  - 上限額50万円内のため、補助金額は46.7万円
- **結果**: 補助金額46.7万円、自己負担23.3万円

#### パターンB: 卒業枠での申請（従業員増加計画あり）
- **前提条件**: 
  - 現在従業員19名の製造業
  - 補助事業期間中に従業員を21名に増加予定
  - 新規設備導入：180万円
  - 人材育成費：40万円
  - 販路開拓費：80万円
  - 合計：300万円
- **計算過程**: 
  - 補助対象経費：300万円
  - 補助率：2/3
  - 補助金額：300万円 × 2/3 = 200万円
  - 上限額200万円のため、補助金額は200万円
- **結果**: 補助金額200万円、自己負担100万円

## 4. 申請手続き・プロセス

### 申請から交付までの流れ

1. **ステップ1: 経営計画書の作成**
   - 詳細説明：商工会・商工会議所の支援を受けながら、自社の強み・弱み、市場環境等を分析し、今後の経営方針を明確にした経営計画書を作成
   - 必要書類：経営計画書（様式2）、補助事業計画書（様式3）
   - 注意点：計画の実現可能性、具体性が審査の重要ポイント

2. **ステップ2: 商工会・商工会議所での事業支援計画書の作成依頼**
   - 詳細説明：作成した経営計画書等を商工会・商工会議所に提出し、事業支援計画書（様式4）の作成を依頼
   - 必要書類：経営計画書、補助事業計画書
   - 注意点：締切日まで余裕を持って依頼すること（通常1週間程度必要）

3. **ステップ3: 申請書類の提出**
   - 詳細説明：必要書類一式を日本商工会議所または全国商工会連合会へ提出
   - 必要書類：
     - 小規模事業者持続化補助金申請書（様式1）
     - 経営計画書（様式2）
     - 補助事業計画書（様式3）
     - 事業支援計画書（様式4）
     - 補助金交付申請書（様式5）
     - 電子媒体（CD-R等）
   - 注意点：電子申請（Jグランツ）での申請を推奨

4. **ステップ4: 審査**
   - 詳細説明：外部有識者による審査委員会において、提出された申請書類をもとに審査
   - 審査基準：
     - 基礎審査（必要な提出書類がすべて提出されているか等）
     - 加点審査（経営計画の適切性、補助事業計画の有効性等）
   - 注意点：審査には通常2～3か月程度かかる

5. **ステップ5: 採択・交付決定**
   - 詳細説明：審査結果に基づき採択事業者を決定し、補助金の交付決定通知書を送付
   - 注意点：交付決定前に発注・支払等を行った経費は補助対象外

6. **ステップ6: 補助事業の実施**
   - 詳細説明：交付決定通知書に記載の補助事業実施期間内に、計画に基づいて事業を実施
   - 注意点：計画変更が必要な場合は事前に変更申請が必要

7. **ステップ7: 実績報告**
   - 詳細説明：補助事業完了後30日以内に実績報告書を提出
   - 必要書類：
     - 実績報告書
     - 経費支出の証拠書類（領収書、請求書等）
     - 成果物の写真等
   - 注意点：証拠書類の不備により補助金が支払われないケースがあるため注意

8. **ステップ8: 補助金の受領**
   - 詳細説明：実績報告書の確認後、補助金額の確定通知書が送付され、請求書提出後に補助金が振り込まれる
   - 注意点：補助金は後払い（精算払い）

### 関連する制度・規則
- **根拠法令**: 補助金等に係る予算の執行の適正化に関する法律
- **所管官庁**: 中小企業庁
- **関連制度**: ものづくり補助金、IT導入補助金、事業再構築補助金

## 5. 実務上の注意点

### 申請時の重要ポイント
- **ポイント1**: 経営計画書は自社の現状分析から始め、具体的かつ実現可能な計画を記載すること
- **ポイント2**: 補助対象経費は証拠書類（見積書、領収書等）が必要なため、適切に保管すること
- **ポイント3**: 商工会・商工会議所の会員でなくても申請可能だが、事業支援計画書の作成依頼は必須

### よくある誤解・トラブル
- **誤解1**: 「補助金は前払いでもらえる」→ 正しくは「補助事業完了後の後払い（精算払い）」
- **誤解2**: 「採択されれば自動的に補助金がもらえる」→ 正しくは「計画通りに事業を実施し、適切な実績報告を行った場合のみ」
- **誤解3**: 「人件費も補助対象」→ 正しくは「販路開拓や業務効率化に直接寄与する経費のみが対象で、通常の人件費は対象外」

## 6. よくある質問（Q&A）

### Q1. 個人事業主でも申請できますか？

**A1.** はい、申請できます。法人だけでなく個人事業主も対象となります。

#### 申請要件の詳細
個人事業主の場合も、業種に応じた従業員数の要件を満たしていれば申請可能です。ただし、以下の点に注意が必要です：
- 開業届を提出していること
- 確定申告を行っていること（創業枠を除く）
- 事業を営んでいることが客観的に確認できること

### Q2. 補助対象経費として認められないものは何ですか？

**A2.** 以下のような経費は補助対象外となります。

#### 補助対象外経費の具体例
- 事務所等に係る家賃、保証金、敷金、仲介手数料、光熱水費
- 電話代、インターネット利用料金等の通信費
- 商品券等の金券
- 文房具などの事務用品等の消耗品代、雑誌購読料、新聞代、団体等の会費
- 茶菓、飲食、奢侈品、娯楽、接待等の費用
- 不動産の購入費、自動車等車両の購入費・修理費・車検費用
- 税務申告、決算書作成等のために税理士、公認会計士等に支払う費用
- 各種保険料
- 振込手数料、代引手数料
- 借入金などの支払利息及び遅延損害金
- 公租公課（消費税及び地方消費税等）
- 補助金事業計画書･申請書･報告書等の作成・送付・手続きに係る費用

### Q3. 複数回申請することは可能ですか？

**A3.** 過去に採択を受けた事業者も一定の条件下で申請可能です。

#### 再申請の条件
- 過去3年間に2回以上、小規模事業者持続化補助金の採択を受けた事業者は申請できません
- 過去の補助事業と明確に異なる事業であることが必要
- 過去の補助事業の実績報告が適切に完了していること

### Q4. 申請から補助金受領までどのくらいの期間がかかりますか？

**A4.** 通常、申請から補助金受領まで6～8か月程度かかります。

#### 標準的なスケジュール例
1. 申請書提出：4月
2. 採択発表：6月下旬
3. 交付決定：7月上旬
4. 補助事業実施期間：7月～12月
5. 実績報告書提出：翌年1月
6. 補助金受領：翌年2月

※実際のスケジュールは公募回により異なります

## 7. まとめ・今後の展望

小規模事業者持続化補助金は、日本の経済を支える小規模事業者の持続的発展を支援する重要な制度です。単なる設備投資への補助ではなく、経営計画に基づいた販路開拓等の取組を支援することで、事業者の経営力向上を図ることを目的としています。

今後は、デジタル化の進展や環境への配慮など、時代の変化に対応した小規模事業者の取組への支援がさらに重要になると考えられます。また、事業承継や創業支援など、事業者のライフサイクルに応じた支援メニューの充実も期待されます。

申請を検討する事業者は、まず自社の経営課題を明確にし、商工会・商工会議所等の支援機関と連携しながら、実効性のある経営計画を策定することが成功への第一歩となります。

## 8. 理解度確認クイズ（4択問題20問）

### 問題1
小規模事業者持続化補助金における商業・サービス業（宿泊業・娯楽業を除く）の小規模事業者の定義として正しいものはどれか？

- A) 常時使用する従業員数3人以下
- B) 常時使用する従業員数5人以下
- C) 常時使用する従業員数10人以下
- D) 常時使用する従業員数20人以下

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
商業・サービス業（宿泊業・娯楽業を除く）の小規模事業者は、常時使用する従業員数5人以下と定義されています。<br>
<br>
Aが間違いの理由：3人以下は定義より少なすぎます<br>
Cが間違いの理由：10人以下は定義より多すぎます<br>
Dが間違いの理由：20人以下は製造業その他の定義です<br>
<br>
【補足】業種により小規模事業者の定義が異なることを理解しておくことが重要です。
</details>

### 問題2
小規模事業者持続化補助金の通常枠における補助率と補助上限額の組み合わせとして正しいものはどれか？

- A) 補助率1/2、補助上限額50万円
- B) 補助率2/3、補助上限額50万円
- C) 補助率2/3、補助上限額100万円
- D) 補助率3/4、補助上限額50万円

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
通常枠の補助率は2/3、補助上限額は50万円です。<br>
<br>
Aが間違いの理由：補助率は1/2ではなく2/3です<br>
Cが間違いの理由：通常枠の上限額は100万円ではなく50万円です<br>
Dが間違いの理由：通常枠の補助率は3/4ではなく2/3です（3/4は赤字事業者の賃金引上げ枠の場合）<br>
<br>
【補足】特別枠では補助上限額が200万円になる場合があります。
</details>

### 問題3
賃金引上げ枠の要件として正しいものはどれか？

- A) 事業場内最低賃金を地域別最低賃金より+20円以上とすること
- B) 事業場内最低賃金を地域別最低賃金より+30円以上とすること
- C) 事業場内最低賃金を地域別最低賃金より+50円以上とすること
- D) 事業場内最低賃金を地域別最低賃金より+100円以上とすること

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
賃金引上げ枠の要件は、事業場内最低賃金を地域別最低賃金より+30円以上とすることです。<br>
<br>
Aが間違いの理由：+20円では要件を満たしません<br>
Cが間違いの理由：+50円は要件より高く設定されています<br>
Dが間違いの理由：+100円は要件より大幅に高く設定されています<br>
<br>
【補足】賃金引上げ枠では、赤字事業者の場合は補助率が3/4に引き上げられます。
</details>

### 問題4
補助対象経費として認められるものはどれか？

- A) 事務所の家賃
- B) 展示会等出展費
- C) 電話代・インターネット利用料金
- D) 税理士への決算書作成費用

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
展示会等出展費は販路開拓のための経費として補助対象となります。<br>
<br>
Aが間違いの理由：事務所等に係る家賃は補助対象外です<br>
Cが間違いの理由：通信費は補助対象外です<br>
Dが間違いの理由：税務申告、決算書作成等のための費用は補助対象外です<br>
<br>
【補足】補助対象経費は販路開拓や業務効率化に直接寄与するものに限定されています。
</details>

### 問題5

## 9. 専門用語集

### あ行

**アトツギ甲子園（あとつぎこうしえん）**
- **読み方**: あとつぎこうしえん
- **意味**: 中小企業庁が後援する、後継者（アトツギ）向けの新規事業アイデアを競うビジネスプランコンテスト。全国各地で地方大会が開催され、各地の代表者が全国大会でプレゼンテーションを行う
- **関連用語**: 後継者支援枠、事業承継

### か行

**確定申告（かくていしんこく）**
- **読み方**: かくていしんこく
- **意味**: 1年間の所得と納税額を税務署に申告する手続き。個人事業主は毎年2月16日から3月15日までに前年分を申告する。小規模事業者持続化補助金の申請時には、営業実態の確認資料として提出が求められる
- **関連用語**: 個人事業主、青色申告

**経営計画書（けいえいけいかくしょ）**
- **読み方**: けいえいけいかくしょ
- **意味**: 企業の現状分析、経営方針、具体的な行動計画などを記載した書類。小規模事業者持続化補助金では様式2として、自社の強み・弱み、市場環境、今後の経営方針等を記載する
- **関連用語**: 補助事業計画書、事業支援計画書

**広報費（こうほうひ）**
- **読み方**: こうほうひ
- **意味**: パンフレット・ポスター・チラシ等の作成および広報媒体等を活用するために支払われる経費。小規模事業者持続化補助金の補助対象経費の一つ
- **関連用語**: 補助対象経費、販路開拓

**交付決定（こうふけってい）**
- **読み方**: こうふけってい
- **意味**: 補助金の採択後、正式に補助金の交付を決定すること。交付決定通知書が発行され、これ以降に発注・契約・支出した経費が補助対象となる
- **関連用語**: 採択、交付決定通知書

### さ行

**採択（さいたく）**
- **読み方**: さいたく
- **意味**: 補助金の審査を通過し、補助対象事業者として選定されること。採択されても、その後の交付申請・交付決定を経て初めて補助事業を開始できる
- **関連用語**: 審査、交付決定

**事業支援計画書（じぎょうしえんけいかくしょ）**
- **読み方**: じぎょうしえんけいかくしょ
- **意味**: 商工会・商工会議所が発行する、申請者の事業計画の実効性や実現可能性を確認した書類。小規模事業者持続化補助金では様式4として必須書類
- **関連用語**: 商工会、商工会議所

**事業場内最低賃金（じぎょうじょうないさいていちんぎん）**
- **読み方**: じぎょうじょうないさいていちんぎん
- **意味**: 事業場（事業所）で働くすべての労働者に支払う賃金の最低額。賃金引上げ枠では、これを地域別最低賃金より+30円以上にすることが要件
- **関連用語**: 地域別最低賃金、賃金引上げ枠

**実績報告書（じっせきほうこくしょ）**
- **読み方**: じっせきほうこくしょ
- **意味**: 補助事業完了後に提出する、事業の実施内容と経費支出を報告する書類。領収書等の証拠書類を添付し、計画通りに事業が実施されたことを証明する
- **関連用語**: 補助事業実施期間、証拠書類

**証拠書類（しょうこしょるい）**
- **読み方**: しょうこしょるい
- **意味**: 経費の支出を証明する書類。見積書、発注書、納品書、請求書、領収書、振込明細書等。補助金の実績報告時に提出が必要
- **関連用語**: 実績報告書、補助対象経費

**商工会（しょうこうかい）**
- **読み方**: しょうこうかい
- **意味**: 主に町村部に設立された、地域の商工業者の経営支援を行う団体。全国商工会連合会を頂点とする組織。小規模事業者持続化補助金の申請支援を行う
- **関連用語**: 商工会議所、事業支援計画書

**商工会議所（しょうこうかいぎしょ）**
- **読み方**: しょうこうかいぎしょ
- **意味**: 主に市部に設立された、地域の商工業者の経営支援を行う団体。日本商工会議所を頂点とする組織。小規模事業者持続化補助金の申請支援を行う
- **関連用語**: 商工会、事業支援計画書

**小規模事業者（しょうきぼじぎょうしゃ）**
- **読み方**: しょうきぼじぎょうしゃ
- **意味**: 中小企業基本法に定める、常時使用する従業員数が一定以下の事業者。業種により基準が異なり、商業・サービス業は5人以下、製造業その他は20人以下など
- **関連用語**: 中小企業基本法、常時使用する従業員

### た行

**地域別最低賃金（ちいきべつさいていちんぎん）**
- **読み方**: ちいきべつさいていちんぎん
- **意味**: 都道府県ごとに定められた最低賃金。すべての労働者に適用され、これを下回る賃金での雇用は違法となる
- **関連用語**: 事業場内最低賃金、賃金引上げ枠

**中小企業基本法（ちゅうしょうきぎょうきほんほう）**
- **読み方**: ちゅうしょうきぎょうきほんほう
- **意味**: 中小企業に関する施策の基本理念や基本方針を定めた法律。中小企業者および小規模企業者の定義を規定している
- **関連用語**: 小規模事業者、中小企業者

**賃金引上げ枠（ちんぎんひきあげわく）**
- **読み方**: ちんぎんひきあげわく
- **意味**: 小規模事業者持続化補助金の特別枠の一つ。事業場内最低賃金を地域別最低賃金より+30円以上とする事業者が対象で、補助上限額が200万円に引き上げられる
- **関連用語**: 事業場内最低賃金、特別枠

**通常枠（つうじょうわく）**
- **読み方**: つうじょうわく
- **意味**: 小規模事業者持続化補助金の基本的な申請枠。補助率2/3、補助上限額50万円で、一般的な販路開拓等の取組を支援する
- **関連用語**: 特別枠、補助率

**展示会等出展費（てんじかいとうしゅってんひ）**
- **読み方**: てんじかいとうしゅってんひ
- **意味**: 新商品等を展示会等に出展または商談会に参加するために要する経費。出展料、運搬費、通訳料、翻訳料等が含まれる。補助対象経費の一つ
- **関連用語**: 補助対象経費、販路開拓

**特定創業支援等事業（とくていそうぎょうしえんとうじぎょう）**
- **読み方**: とくていそうぎょうしえんとうじぎょう
- **意味**: 産業競争力強化法に基づき、認定を受けた市区町村や創業支援等事業者が実施する、創業希望者への継続的な支援事業。創業セミナーや個別相談等が該当
- **関連用語**: 創業枠、産業競争力強化法

**特別枠（とくべつわく）**
- **読み方**: とくべつわく
- **意味**: 小規模事業者持続化補助金において、特定の要件を満たす事業者向けに設定された申請枠。賃金引上げ枠、卒業枠、後継者支援枠、創業枠があり、補助上限額が200万円
- **関連用語**: 通常枠、補助上限額

### は行

**販路開拓（はんろかいたく）**
- **読み方**: はんろかいたく
- **意味**: 新たな顧客や市場を開拓し、商品・サービスの販売経路を拡大すること。小規模事業者持続化補助金の主要な支援対象
- **関連用語**: 補助対象事業、経営計画

**補助金交付申請書（ほじょきんこうふしんせいしょ）**
- **読み方**: ほじょきんこうふしんせいしょ
- **意味**: 補助金の交付を正式に申請する書類。小規模事業者持続化補助金では様式5として、採択後に提出する
- **関連用語**: 交付決定、採択

**補助事業計画書（ほじょじぎょうけいかくしょ）**
- **読み方**: ほじょじぎょうけいかくしょ
- **意味**: 補助金を活用して実施する具体的な事業内容を記載した書類。小規模事業者持続化補助金では様式3として、販路開拓等の取組内容を詳細に記載する
- **関連用語**: 経営計画書、補助対象事業

**補助事業実施期間（ほじょじぎょうじっしきかん）**
- **読み方**: ほじょじぎょうじっしきかん
- **意味**: 補助金の交付決定日から定められた期限までの期間。この期間内に補助事業を完了し、経費の支払いを終える必要がある
- **関連用語**: 交付決定、実績報告書

**補助対象経費（ほじょたいしょうけいひ）**
- **読み方**: ほじょたいしょうけいひ
- **意味**: 補助金の対象となる経費。機械装置等費、広報費、ウェブサイト関連費、展示会等出展費、旅費、開発費、資料購入費、雑役務費、借料、設備処分費、委託・外注費など
- **関連用語**: 補助対象外経費、補助率

**補助対象事業（ほじょたいしょうじぎょう）**
- **読み方**: ほじょたいしょうじぎょう
- **意味**: 策定した経営計画に基づいて実施する、地道な販路開拓等のための取組、あるいは販路開拓等と併せて行う業務効率化のための取組
- **関連用語**: 経営計画、販路開拓

**補助率（ほじょりつ）**
- **読み方**: ほじょりつ
- **意味**: 補助対象経費に対する補助金額の割合。通常枠では2/3、賃金引上げ枠の赤字事業者は3/4など、枠や条件により異なる
- **関連用語**: 補助上限額、補助対象経費

**補助上限額（ほじょじょうげんがく）**
- **読み方**: ほじょじょうげんがく
- **意味**: 補助金として交付される金額の上限。通常枠は50万円、特別枠（賃金引上げ枠、卒業枠、後継者支援枠、創業枠）は200万円
- **関連用語**: 補助率、特別枠

- **関連用語**: GビズID、電子申請
