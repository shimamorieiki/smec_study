# CAPM（資本資産価格モデル）について

## 概要
CAPM（Capital Asset Pricing Model：資本資産価格モデル）は、1960年代にウィリアム・シャープ、ジョン・リントナー、ヤン・モッシンによって独立に開発された、証券の期待収益率を推定するための理論モデルです。このモデルは、リスクとリターンの関係を定量的に表現し、投資判断や企業価値評価の基礎となる重要な理論です。

## 1. CAPMの基本概念と前提条件

### CAPMの基本式
CAPMの基本式は以下のように表されます：

```
E(Ri) = Rf + βi × [E(Rm) - Rf]
```

- **E(Ri)**: 証券iの期待収益率
- **Rf**: リスクフリーレート（無リスク利子率）
- **βi**: 証券iのベータ係数
- **E(Rm)**: 市場ポートフォリオの期待収益率
- **[E(Rm) - Rf]**: リスクプレミアム（市場リスクプレミアム）

### CAPMの前提条件
1. **完全市場**: 取引コストや税金が存在しない
2. **情報の対称性**: すべての投資家が同じ情報を持つ
3. **同質的期待**: すべての投資家が同じ期待を持つ
4. **単一期間モデル**: 投資期間は1期間のみ
5. **リスク回避的投資家**: 投資家はリスク回避的である
6. **無制限の借入・貸出**: リスクフリーレートで無制限に借入・貸出が可能
7. **分割可能性**: すべての証券は無限に分割可能

## 2. 安全資産を含む効率的フロンティア

### 効率的フロンティアの概念
効率的フロンティアとは、与えられたリスク水準において最大の期待収益率を提供するポートフォリオの集合、または与えられた期待収益率において最小のリスクを持つポートフォリオの集合です。

### 安全資産がない場合の効率的フロンティア
- **形状**: 双曲線状の曲線
- **特徴**: リスクとリターンのトレードオフを表現
- **最小分散ポートフォリオ**: フロンティア上で最もリスクが小さいポートフォリオ

### 安全資産を含む場合の効率的フロンティア（資本市場線：CML）
安全資産（リスクフリー資産）を導入すると、効率的フロンティアは以下のように変化します：

#### 資本市場線（Capital Market Line: CML）の方程式
```
E(Rp) = Rf + [(E(Rm) - Rf) / σm] × σp
```

- **E(Rp)**: ポートフォリオの期待収益率
- **σp**: ポートフォリオの標準偏差
- **σm**: 市場ポートフォリオの標準偏差

#### 特徴
1. **直線性**: 安全資産と市場ポートフォリオを結ぶ直線
2. **接点ポートフォリオ**: 元の効率的フロンティアとの接点が市場ポートフォリオ
3. **分離定理**: すべての投資家は市場ポートフォリオと安全資産の組み合わせを保有

### 具体的計算例：資本市場線の活用

**例：ポートフォリオの期待収益率計算**
- リスクフリーレート（Rf）: 2%
- 市場ポートフォリオの期待収益率（E(Rm)）: 10%
- 市場ポートフォリオの標準偏差（σm）: 20%
- 投資家のポートフォリオの標準偏差（σp）: 15%

**計算過程：**
```
E(Rp) = 2% + [(10% - 2%) / 20%] × 15%
      = 2% + [8% / 20%] × 15%
      = 2% + 0.4 × 15%
      = 2% + 6%
      = 8%
```

**結果：** このポートフォリオの期待収益率は8%となります。

## 3. 相関係数とポートフォリオ理論

### 相関係数の定義
相関係数（ρ）は、2つの証券の収益率の線形関係の強さと方向を示す指標です。

```
ρij = Cov(Ri, Rj) / (σi × σj)
```

- **ρij**: 証券iとjの相関係数（-1 ≤ ρ ≤ 1）
- **Cov(Ri, Rj)**: 証券iとjの共分散
- **σi, σj**: 証券i、jの標準偏差

### 相関係数の解釈
- **ρ = 1**: 完全正相関（同じ方向に動く）
- **ρ = 0**: 無相関（関係なし）
- **ρ = -1**: 完全負相関（逆方向に動く）

### 2資産ポートフォリオのリスク計算

#### ポートフォリオの分散
```
σp² = w1²σ1² + w2²σ2² + 2w1w2ρ12σ1σ2
```

- **w1, w2**: 各資産の投資比率（w1 + w2 = 1）
- **σ1, σ2**: 各資産の標準偏差
- **ρ12**: 資産1と2の相関係数

### 分散効果の具体例

**例：相関係数による分散効果の比較**
- 資産A: 期待収益率 8%、標準偏差 15%
- 資産B: 期待収益率 12%、標準偏差 20%
- 投資比率: 各50%（w1 = w2 = 0.5）

**ケース1：相関係数 ρ = 1（完全正相関）**
```
σp² = 0.5² × 15² + 0.5² × 20² + 2 × 0.5 × 0.5 × 1 × 15 × 20
    = 0.25 × 225 + 0.25 × 400 + 0.5 × 300
    = 56.25 + 100 + 150
    = 306.25
σp = 17.5%
```

**ケース2：相関係数 ρ = 0（無相関）**
```
σp² = 0.5² × 15² + 0.5² × 20² + 2 × 0.5 × 0.5 × 0 × 15 × 20
    = 56.25 + 100 + 0
    = 156.25
σp = 12.5%
```

**ケース3：相関係数 ρ = -0.5（負相関）**
```
σp² = 0.5² × 15² + 0.5² × 20² + 2 × 0.5 × 0.5 × (-0.5) × 15 × 20
    = 56.25 + 100 - 75
    = 81.25
σp = 9.01%
```

💡 **実務での活用**: 相関係数が低い資産を組み合わせることで、ポートフォリオ全体のリスクを大幅に削減できます。

## 4. 個別リスクと市場リスク

### リスクの分解
証券の総リスクは、以下の2つの要素に分解されます：

```
総リスク = 市場リスク（システマティック・リスク） + 個別リスク（非システマティック・リスク）
σi² = βi²σm² + σε²
```

### 市場リスク（システマティック・リスク）
- **定義**: 市場全体の変動に起因するリスク
- **特徴**: 分散投資では除去できない
- **要因**: 
  - 経済状況の変化
  - 金利変動
  - インフレーション
  - 政治的要因
- **測定**: ベータ係数（β）で測定

### 個別リスク（非システマティック・リスク）
- **定義**: 個別企業や産業に固有のリスク
- **特徴**: 分散投資により除去可能
- **要因**:
  - 経営者の能力
  - 新製品の成否
  - 労働争議
  - 財務状況
- **測定**: 残差分散（σε²）で測定

### 分散投資の効果

**例：ポートフォリオの個別リスク削減**
n銘柄の等金額ポートフォリオの場合：

```
ポートフォリオの個別リスク = (1/n) × 平均個別リスク
```

| 銘柄数 | 個別リスクの削減率 |
|--------|-------------------|
| 1銘柄 | 0% |
| 10銘柄 | 90% |
| 30銘柄 | 97% |
| 100銘柄 | 99% |

💡 **実務的示唆**: 約20-30銘柄で個別リスクの大部分を除去可能

## 5. β係数（ベータ係数）

### β係数の定義
β係数は、個別証券の収益率が市場ポートフォリオの収益率に対してどの程度感応的かを示す指標です。

```
βi = Cov(Ri, Rm) / σm²
```

- **Cov(Ri, Rm)**: 証券iと市場ポートフォリオの共分散
- **σm²**: 市場ポートフォリオの分散

### β係数の解釈
- **β = 1**: 市場と同じ動き
- **β > 1**: 市場より大きく変動（アグレッシブ）
- **β < 1**: 市場より小さく変動（ディフェンシブ）
- **β = 0**: 市場と無相関
- **β < 0**: 市場と逆相関（稀）

### β係数の推定方法

#### 回帰分析による推定
```
Ri - Rf = αi + βi(Rm - Rf) + εi
```

過去の収益率データを用いて回帰分析を行い、傾きβiを推定します。

### β係数の具体的計算例

**例：A社のβ係数計算**
過去5年間のデータ：

| 年 | A社収益率 | 市場収益率 |
|----|-----------|-----------|
| 1 | 15% | 10% |
| 2 | -5% | -2% |
| 3 | 20% | 15% |
| 4 | 8% | 5% |
| 5 | 12% | 8% |

**計算手順：**
1. 各年の超過収益率を計算（Rf = 2%と仮定）
2. 共分散を計算
3. 市場の分散を計算
4. β = 共分散 / 市場分散

**結果：** β ≈ 1.3（市場より30%感応的）

### ポートフォリオのβ係数
```
βp = Σ(wi × βi)
```

ポートフォリオのβは、構成証券のβの加重平均となります。

### β係数の実務的応用

#### 1. 期待収益率の推定
```
E(Ri) = 2% + 1.3 × (10% - 2%) = 12.4%
```

#### 2. リスク調整後収益率の評価
- **ジェンセンのアルファ**: α = 実際の収益率 - CAPM期待収益率
- **シャープレシオ**: (Ri - Rf) / σi
- **トレイナーレシオ**: (Ri - Rf) / βi

## 6. CAPMの実務応用

### 1. 株式評価
```
株式の理論価格 = 期待配当 / (CAPM期待収益率 - 成長率)
```

### 2. 資本コストの推定
企業の株主資本コストとしてCAPM期待収益率を使用

### 3. プロジェクト評価
NPV計算の割引率として使用

### 4. パフォーマンス評価
ファンドマネージャーの運用成績評価

## 7. CAPMの限界と拡張

### 限界
1. **単一期間モデル**: 現実は多期間
2. **正規分布仮定**: 収益率分布は必ずしも正規分布でない
3. **市場ポートフォリオの特定困難**: 真の市場ポートフォリオは観察不可能
4. **取引コストの無視**: 現実には取引コストが存在
5. **借入制約**: リスクフリーレートでの無制限借入は非現実的

### 主な拡張モデル
1. **APT（裁定価格理論）**: 複数のリスクファクター
2. **Fama-Frenchの3ファクターモデル**: 市場、規模、簿価時価比率
3. **Carhart4ファクターモデル**: モメンタムファクター追加
4. **消費CAPM**: 消費の限界効用を考慮

</details>

- B) リスクフリーレートと市場ポートフォリオを結ぶ直線となる
- C) リスクが増加すると期待収益率は逓減する
- D) すべての個別証券がこの線上に位置する

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
資本市場線（CML）は、リスクフリー資産と市場ポートフォリオを結ぶ直線です。これは、投資家がリスクフリー資産と市場ポートフォリオを任意の比率で組み合わせることができるためです。<br>
<br>
Aが間違いの理由：安全資産がない場合の効率的フロンティアは双曲線状だが、安全資産を含むと直線になる<br>
Cが間違いの理由：CML上ではリスクと期待収益率は比例関係にある<br>
Dが間違いの理由：CML上にあるのは効率的なポートフォリオのみで、個別証券は証券市場線（SML）上に位置する
</details>

- B) 分散投資効果により、ポートフォリオのリスクを削減できる
- C) ポートフォリオの期待収益率は個別証券の期待収益率より低くなる

<summary>解答</summary>
<strong>正解: B</strong><br>

<br>
Aが間違いの理由：負の相関により、ポートフォリオのリスクは個別証券より小さくなる可能性が高い<br>
Cが間違いの理由：期待収益率は投資比率の加重平均となり、相関係数の影響を受けない<br>
Dが間違いの理由：負の相関は分散投資効果を高めるため、むしろ望ましい
</details>

</details>

<strong>正解: B</strong><br>

E(Ri) = 3% + 0.8 × (11% - 3%)<br>
      = 3% + 0.8 × 8%<br>
      = 3% + 6.4%<br>
      = 9.4%<br>
<br>
Aが間違いの理由：計算誤り<br>
Cが間違いの理由：市場収益率より高くなっている（β<1なのに）<br>
Dが間違いの理由：リスクプレミアムのみを計算
</details>

### 問題11

<br>
Bが間違いの理由：リスクの分解に関する概念とは異なる<br>

</details>

### 問題12

- B) 12%
- C) 8%
- D) 15%

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>

E(R) = 12%<br>
<br>

Cが間違いの理由：計算誤り<br>

</details>

### 問題19

## 9. 専門用語集

### アルファベット

**APT (Arbitrage Pricing Theory)**
- **読み方**: エーピーティー、裁定価格理論
- **意味**: Stephen Rossが開発した、複数のリスクファクターを考慮する資産価格モデル。CAPMの一般化として位置づけられる
- **関連用語**: CAPM、マルチファクターモデル

**CAPM (Capital Asset Pricing Model)**
- **読み方**: キャップエム、資本資産価格モデル
- **意味**: リスクとリターンの関係を表す均衡モデル。証券の期待収益率をシステマティック・リスクの関数として表現
- **関連用語**: 証券市場線（SML）、資本市場線（CML）

**CML (Capital Market Line)**
- **読み方**: シーエムエル、資本市場線
- **意味**: リスクフリー資産と市場ポートフォリオを結ぶ直線。効率的ポートフォリオのリスクとリターンの関係を示す
- **関連用語**: 効率的フロンティア、分離定理

**SML (Security Market Line)**
- **読み方**: エスエムエル、証券市場線
- **意味**: 個別証券やポートフォリオのベータ係数と期待収益率の関係を示す直線
- **関連用語**: CAPM、ベータ係数

### あ行

**アルファ（α）**
- **読み方**: あるふぁ
- **意味**: 実際の収益率とCAPMが予測する期待収益率の差。正の値は超過収益を示す
- **関連用語**: ジェンセンのアルファ、超過収益

**安全資産（リスクフリー資産）**
- **読み方**: あんぜんしさん
- **意味**: 収益率の不確実性がない（リスクがゼロの）資産。通常は短期国債を指す
- **関連用語**: リスクフリーレート、国債

### か行

**加重平均資本コスト（WACC）**
- **読み方**: かじゅうへいきんしほんこすと
- **意味**: 企業の資金調達コストの加重平均。株主資本コストの計算にCAPMが使用される
- **関連用語**: 資本コスト、CAPM

**完全市場**
- **読み方**: かんぜんしじょう
- **意味**: 取引コスト、税金、情報の非対称性などの市場の摩擦が存在しない理想的な市場
- **関連用語**: 市場の効率性、CAPM前提条件

**期待収益率**
- **読み方**: きたいしゅうえきりつ
- **意味**: 将来得られると予想される収益率の期待値
- **関連用語**: リスクプレミアム、CAPM

**共分散**
- **読み方**: きょうぶんさん
- **意味**: 2つの変数の連動性を表す統計量。ポートフォリオ理論で重要な概念
- **関連用語**: 相関係数、分散

### さ行

**残差分散**
- **読み方**: ざんさぶんさん
- **意味**: 回帰分析において説明できない部分の分散。個別リスクの尺度
- **関連用語**: 個別リスク、R²

**市場ポートフォリオ**
- **読み方**: しじょうぽーとふぉりお
- **意味**: すべてのリスク資産を時価総額比率で保有した理論上のポートフォリオ
- **関連用語**: CAPM、効率的ポートフォリオ

**市場リスク（システマティック・リスク）**
- **読み方**: しじょうりすく
- **意味**: 市場全体の変動に起因し、分散投資では除去できないリスク
- **関連用語**: ベータ係数、個別リスク

**資本市場線（CML）**
- **読み方**: しほんしじょうせん
- **意味**: リスクフリー資産と市場ポートフォリオを結ぶ直線
- **関連用語**: 効率的フロンティア、CAPM

**証券市場線（SML）**
- **読み方**: しょうけんしじょうせん
- **意味**: ベータ係数と期待収益率の関係を示す直線
- **関連用語**: CAPM、ベータ係数

**シャープレシオ**
- **読み方**: しゃーぷれしお
- **意味**: リスク1単位あたりの超過収益を示す指標
- **関連用語**: リスク調整後収益率、トレイナーレシオ

**相関係数**
- **読み方**: そうかんけいすう
- **意味**: 2つの変数の線形関係の強さと方向を-1から1の値で表す指標
- **関連用語**: 共分散、ポートフォリオ理論

### た行

**トレイナーレシオ**
- **読み方**: とれいなーれしお
- **意味**: システマティック・リスク（ベータ）1単位あたりの超過収益
- **関連用語**: シャープレシオ、パフォーマンス評価

### は行

**標準偏差**
- **読み方**: ひょうじゅんへんさ
- **意味**: データのばらつきを表す指標。投資理論ではリスクの尺度として使用
- **関連用語**: 分散、ボラティリティ

**非システマティック・リスク（個別リスク）**
- **読み方**: ひしすてまてぃっくりすく
- **意味**: 個別企業や産業に固有のリスクで、分散投資により除去可能
- **関連用語**: 市場リスク、分散投資

**分散**
- **読み方**: ぶんさん
- **意味**: データのばらつきを表す統計量。標準偏差の2乗
- **関連用語**: 標準偏差、リスク

**分散投資**
- **読み方**: ぶんさんとうし
- **意味**: 複数の資産に投資することでリスクを削減する投資手法
- **関連用語**: ポートフォリオ、個別リスク

**分離定理**
- **読み方**: ぶんりていり
- **意味**: 最適なリスク資産の組み合わせは投資家のリスク選好と独立に決まるという定理
- **関連用語**: 市場ポートフォリオ、CAPM

**ベータ係数（β）**
- **読み方**: べーたけいすう
- **意味**: 個別証券の収益率が市場収益率に対してどの程度感応的かを示す指標
- **関連用語**: システマティック・リスク、CAPM

**ポートフォリオ**
- **読み方**: ぽーとふぉりお
- **意味**: 複数の資産の組み合わせ。投資理論の中心概念
- **関連用語**: 分散投資、効率的フロンティア

### ま行

**無リスク利子率（リスクフリーレート）**
- **読み方**: むりすくりしりつ
- **意味**: リスクがゼロの資産から得られる収益率。通常は短期国債利回り
- **関連用語**: 安全資産、CAPM

### ら行

**リスクプレミアム**
- **読み方**: りすくぷれみあむ
- **意味**: リスクを取ることに対する追加的な期待収益率
- **関連用語**: 市場リスクプレミアム、期待収益率

**リスクフリーレート**
- **読み方**: りすくふりーれーと
- **意味**: 無リスク資産の収益率。CAPMの重要な構成要素
- **関連用語**: 国債利回り、CAPM
