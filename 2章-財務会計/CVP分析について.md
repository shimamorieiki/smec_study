# CVP分析について

## 概要

CVP分析（Cost-Volume-Profit Analysis：原価・販売量・利益分析）は、企業の原価、販売量、利益の関係を分析し、経営意思決定に活用する管理会計手法です。損益分岐点分析とも呼ばれ、企業が利益を出すために必要な販売量や売上高を明らかにし、価格設定、生産計画、投資判断などの経営上の重要な意思決定を支援します。

## 1. 基本概念・定義

CVP分析は、以下の基本的な前提条件のもとで行われます。

### 基本前提
- **線形性の仮定**: 売上高と変動費は販売量に比例して変化する
- **単一製品または製品構成一定**: 分析対象は単一製品、または複数製品の場合は販売構成比が一定
- **分析期間内での価格・費用の安定性**: 販売価格と単位変動費は一定
- **生産量＝販売量**: 在庫の増減はない
- **費用の分解可能性**: すべての費用は変動費と固定費に明確に分類できる

### 主要な構成要素

#### 売上高（Sales Revenue）
- **定義**: 製品・サービスの販売によって得られる収入
- **計算式**: 売上高 = 販売価格 × 販売量
- **特徴**: 販売量に比例して増加（線形関係）

#### 変動費（Variable Cost）
- **定義**: 生産量や販売量の変化に比例して変動する費用
- **例**: 原材料費、直接労務費、販売手数料、運送費
- **計算式**: 総変動費 = 単位変動費 × 販売量

#### 固定費（Fixed Cost）
- **定義**: 生産量や販売量の変化に関係なく一定期間内で一定額発生する費用
- **例**: 賃借料、減価償却費、管理職給与、保険料
- **特徴**: 短期的には変化しないが、長期的には変動する可能性がある

#### 貢献利益（Contribution Margin）
- **定義**: 売上高から変動費を差し引いた利益
- **計算式**: 貢献利益 = 売上高 - 変動費
- **意味**: 固定費の回収と利益の創出に貢献する利益

## 2. CVP分析の主要指標

### 損益分岐点（Break-Even Point: BEP）

損益分岐点は、総収益と総費用が等しくなり、利益がゼロとなる販売量または売上高を示します。

#### 販売量基準の損益分岐点
```
損益分岐点販売量 = 固定費 ÷ 単位貢献利益
               = 固定費 ÷ (販売価格 - 単位変動費)
```

#### 売上高基準の損益分岐点
```
損益分岐点売上高 = 固定費 ÷ 貢献利益率
               = 固定費 ÷ ((売上高 - 変動費) ÷ 売上高)
```

### 貢献利益率（Contribution Margin Ratio）
```
貢献利益率 = 貢献利益 ÷ 売上高 × 100%
         = (売上高 - 変動費) ÷ 売上高 × 100%
         = 1 - 変動費率
```

### 安全余裕率（Margin of Safety）
```
安全余裕率 = (実際売上高 - 損益分岐点売上高) ÷ 実際売上高 × 100%
```

### 目標利益達成販売量
```
目標利益達成販売量 = (固定費 + 目標利益) ÷ 単位貢献利益
```

## 3. 具体的計算例・事例

### ケース1: 単一製品のCVP分析

#### 基本データ
- 製品A販売価格: 10,000円/個
- 単位変動費: 6,000円/個
- 月間固定費: 2,000,000円
- 現在の月間販売量: 600個

#### 分析計算

**ステップ1: 単位貢献利益の計算**
```
単位貢献利益 = 販売価格 - 単位変動費
            = 10,000円 - 6,000円
            = 4,000円/個
```

**ステップ2: 貢献利益率の計算**
```
貢献利益率 = 単位貢献利益 ÷ 販売価格 × 100%
         = 4,000円 ÷ 10,000円 × 100%
         = 40%
```

**ステップ3: 損益分岐点の計算**
```
損益分岐点販売量 = 固定費 ÷ 単位貢献利益
               = 2,000,000円 ÷ 4,000円
               = 500個

損益分岐点売上高 = 損益分岐点販売量 × 販売価格
               = 500個 × 10,000円
               = 5,000,000円
```

**ステップ4: 現在の利益計算**
```
現在の売上高 = 600個 × 10,000円 = 6,000,000円
現在の変動費 = 600個 × 6,000円 = 3,600,000円
現在の貢献利益 = 6,000,000円 - 3,600,000円 = 2,400,000円
現在の営業利益 = 2,400,000円 - 2,000,000円 = 400,000円
```

**ステップ5: 安全余裕率の計算**
```
安全余裕率 = (6,000,000円 - 5,000,000円) ÷ 6,000,000円 × 100%
         = 16.67%
```

### ケース2: 複数製品のCVP分析（販売構成比一定）

#### 基本データ
| 製品 | 販売価格 | 単位変動費 | 販売構成比 |
|------|----------|------------|------------|
| 製品X | 8,000円 | 5,000円 | 60% |
| 製品Y | 12,000円 | 7,000円 | 40% |

- 月間固定費: 3,000,000円

#### 分析計算

**ステップ1: 加重平均単位貢献利益の計算**
```
製品Xの単位貢献利益 = 8,000円 - 5,000円 = 3,000円
製品Yの単位貢献利益 = 12,000円 - 7,000円 = 5,000円

加重平均単位貢献利益 = (3,000円 × 0.6) + (5,000円 × 0.4)
                    = 1,800円 + 2,000円
                    = 3,800円
```

**ステップ2: 加重平均販売価格の計算**
```
加重平均販売価格 = (8,000円 × 0.6) + (12,000円 × 0.4)
               = 4,800円 + 4,800円
               = 9,600円
```

**ステップ3: 加重平均貢献利益率の計算**
```
加重平均貢献利益率 = 3,800円 ÷ 9,600円 × 100%
                 = 39.58%
```

**ステップ4: 損益分岐点の計算**
```
損益分岐点総販売量 = 3,000,000円 ÷ 3,800円
                 = 789.47個（約790個）

製品Xの損益分岐点販売量 = 790個 × 0.6 = 474個
製品Yの損益分岐点販売量 = 790個 × 0.4 = 316個

損益分岐点売上高 = 790個 × 9,600円 = 7,584,000円
```

### ケース3: 価格変更による影響分析

#### シナリオ設定
現在の状況（ケース1のデータを使用）から、以下の変更を検討：
- 販売価格を10%引き下げて9,000円にする
- この価格変更により販売量が30%増加すると予測

#### 影響分析

**変更後の状況**
```
新販売価格 = 10,000円 × 0.9 = 9,000円
新販売量 = 600個 × 1.3 = 780個
単位変動費 = 6,000円（変更なし）
固定費 = 2,000,000円（変更なし）

新単位貢献利益 = 9,000円 - 6,000円 = 3,000円
新貢献利益率 = 3,000円 ÷ 9,000円 × 100% = 33.33%

新損益分岐点販売量 = 2,000,000円 ÷ 3,000円 = 666.67個（約667個）
```

**利益の比較**
```
変更前の利益 = 400,000円（前述の計算より）

変更後の売上高 = 780個 × 9,000円 = 7,020,000円
変更後の変動費 = 780個 × 6,000円 = 4,680,000円
変更後の貢献利益 = 7,020,000円 - 4,680,000円 = 2,340,000円
変更後の営業利益 = 2,340,000円 - 2,000,000円 = 340,000円

利益の変化 = 340,000円 - 400,000円 = -60,000円（減少）
```

💡 **実際の現場では**: 価格引き下げによる販売量増加が期待通りに実現するかは不確実であり、競合他社の反応、市場の価格弾力性、ブランド価値への影響なども考慮する必要があります。

## 4. CVP分析の応用

### 営業レバレッジ（Operating Leverage）

営業レバレッジは、売上高の変化に対する営業利益の変化の程度を示す指標です。

```
営業レバレッジ度 = 貢献利益 ÷ 営業利益
```

#### 計算例（ケース1のデータ使用）
```
営業レバレッジ度 = 2,400,000円 ÷ 400,000円 = 6倍
```

これは、売上高が1%増加すると営業利益が6%増加することを意味します。

### 感度分析（Sensitivity Analysis）

CVP分析の各要素が変化した場合の利益への影響を分析します。

#### 要素別の影響度分析例
| 変化要素 | 変化率 | 利益への影響 |
|----------|--------|--------------|
| 販売価格 | +1% | +15% |
| 販売量 | +1% | +6% |
| 単位変動費 | +1% | -9% |
| 固定費 | +1% | -5% |

### 制約条件下での最適化

複数製品を扱う場合、生産能力や資源の制約を考慮した最適な製品構成を決定します。

#### 例: 機械時間制約下での最適化
| 製品 | 単位貢献利益 | 必要機械時間 | 時間当たり貢献利益 |
|------|--------------|--------------|-------------------|
| 製品A | 4,000円 | 2時間 | 2,000円/時間 |
| 製品B | 3,000円 | 1時間 | 3,000円/時間 |

制約条件下では、時間当たり貢献利益の高い製品Bを優先的に生産します。

## 5. 実務上の注意点

### CVP分析の限界と留意点

1. **前提条件の現実性**
   - 完全な線形関係は現実には稀
   - 規模の経済や不経済が存在
   - 価格と販売量の関係は複雑

2. **費用分解の困難性**
   - 準変動費、準固定費の存在
   - 段階的固定費（ステップコスト）の考慮
   - 間接費の配賦問題

3. **分析期間の設定**
   - 短期的分析に適している
   - 長期的には固定費も変動する
   - 技術革新や市場環境の変化

### 実務での活用ポイント

1. **意思決定への活用**
   - 新製品導入の判断
   - 製品ラインの削減・追加
   - アウトソーシングの検討
   - 価格戦略の立案

2. **リスク管理**
   - 損益分岐点の把握による経営リスクの評価
   - 安全余裕率によるバッファーの確保
   - シナリオ分析による不確実性への対応

3. **業績管理**
   - 部門別・製品別の収益性評価
   - 目標設定と進捗管理
   - インセンティブ設計への活用

## 6. よくある質問（Q&A）

### Q1. 変動費と固定費の分類が難しい費用はどう扱えばよいですか？

**A1.** 準変動費や準固定費として扱い、以下の方法で対応します。

#### 対応方法
1. **高低点法**: 過去のデータから最高点と最低点を使って費用を分解
2. **最小二乗法**: 統計的手法により変動費率と固定費を推定
3. **スキャッタープロット法**: 散布図を作成して視覚的に判断
4. **エンジニアリング法**: 技術的な分析により費用の性質を判定

実務では、重要性の原則に基づき、影響の大きい費用項目について詳細な分析を行い、影響の小さい項目は簡便的な方法で処理することが一般的です。

### Q2. 複数製品を扱う場合、どのように損益分岐点を計算すればよいですか？

**A2.** 以下の3つのアプローチがあります。

#### アプローチ別の詳細説明

1. **販売構成比一定法**
   - 最も一般的な方法
   - 加重平均により単一製品として扱う
   - 前述のケース2で示した方法

2. **製品別個別計算法**
   - 各製品の損益分岐点を個別に計算
   - 共通固定費の配賦が必要
   - 製品別の意思決定に有用

3. **貢献利益総額法**
   - 全製品の貢献利益総額で固定費を回収
   - 製品構成の変化に柔軟に対応可能
   - 全社的な損益管理に適している

### Q3. インフレーションがある場合、CVP分析はどのように修正すべきですか？

**A3.** インフレーションを考慮したCVP分析では、以下の調整が必要です。

#### 調整方法
1. **実質価値での分析**
   - すべての金額をベース年の価値に換算
   - インフレ率を除去した実質ベースで計算

2. **名目価値での予測**
   - 将来の価格・費用にインフレ率を反映
   - 年度別に異なるインフレ率を適用可能

3. **感度分析の実施**
   - インフレ率の変化による影響を分析
   - 複数のシナリオでの損益分岐点を計算

## 7. まとめ・今後の展望

### 問題5
営業レバレッジ度が5倍の企業で、売上高が10%増加した場合、営業利益は何%増加するか？

- A) 10%
- B) 20%
- C) 50%
- D) 100%

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
営業レバレッジ度は、売上高の変化率に対する営業利益の変化率の倍数を示します。<br>
営業利益の変化率 = 売上高の変化率 × 営業レバレッジ度<br>
= 10% × 5倍<br>
= 50%<br>
<br>
固定費の存在により、売上高の変化が営業利益に増幅されて影響します。
</details>

### 問題8

= 600個<br>
<br>
目標利益を達成するには、固定費に加えて目標利益分の貢献利益も必要です。
</details>

### 問題9
価格を10%引き上げ、販売量が5%減少した場合、貢献利益への影響として最も適切なものは？（変動費は一定）

- A) 必ず増加する
- B) 必ず減少する
- C) 変化しない
- D) 変動費率により増減が決まる

<details>
<summary>解答</summary>
<strong>正解: D</strong><br>
貢献利益の変化は変動費率により異なります。<br>
例：販売価格100円、変動費60円（変動費率60%）の場合<br>
変更前：100円 × 100個 - 60円 × 100個 = 4,000円<br>
変更後：110円 × 95個 - 60円 × 95個 = 10,450円 - 5,700円 = 4,750円（増加）<br>
<br>
しかし、変動費率が高い場合は減少する可能性もあります。一般的に、変動費率が50%未満であれば、このケースでは貢献利益は増加します。
</details>

### 問題10
段階的固定費（ステップコスト）がある場合のCVP分析の特徴は？

- A) 損益分岐点が複数存在する可能性がある
- B) 変動費率が変化する
- C) 貢献利益率が一定でなくなる
- D) 分析が不可能になる

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
段階的固定費は、一定の活動量を超えると段階的に増加する固定費です（例：工場の増設、管理者の追加雇用）。この場合、固定費の水準が変わるポイントで新たな損益分岐点が発生する可能性があります。<br>
<br>
変動費率や貢献利益率は変化せず、分析は可能ですが、複数の範囲に分けて行う必要があります。
</details>

### 問題11
ある企業の売上高10,000,000円、変動費6,000,000円、固定費3,000,000円の場合、営業レバレッジ度は？

- A) 2倍
- B) 3倍
- C) 4倍
- D) 5倍

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
貢献利益 = 売上高 - 変動費 = 10,000,000円 - 6,000,000円 = 4,000,000円<br>
営業利益 = 貢献利益 - 固定費 = 4,000,000円 - 3,000,000円 = 1,000,000円<br>
営業レバレッジ度 = 貢献利益 ÷ 営業利益 = 4,000,000円 ÷ 1,000,000円 = 4倍<br>
<br>
営業レバレッジ度が高いほど、売上高の変化が営業利益に大きく影響します。
</details>

- C) 製造業では変動費がない

製造業では生産量と販売量が異なる場合があり、在庫の増減がCVP分析に影響を与えます。標準的なCVP分析では生産量＝販売量を前提としていますが、製造業では全部原価計算と直接原価計算の違いなども考慮する必要があります。<br>
<br>

- B) 限界利益と貢献利益は同じ概念である

### 問題14
機会費用を考慮したCVP分析で、生産能力に制約がある場合の意思決定基準は？

- B) 貢献利益率の高い製品を優先
- C) 制約資源当たり貢献利益の高い製品を優先

<summary>解答</summary>
<strong>正解: C</strong><br>
生産能力に制約がある場合（機械時間、労働時間、原材料等）、制約資源の単位当たり貢献利益が最も高い製品を優先的に生産することで、全体の利益を最大化できます。<br>
<br>
例：機械時間が制約の場合、「単位貢献利益÷必要機械時間」が最も高い製品から生産します。

### 問題15
不確実性下でのCVP分析の手法として適切でないものは？

- A) 感度分析
- B) シナリオ分析
- C) モンテカルロ・シミュレーション
- D) 移動平均法

<details>
<summary>解答</summary>
<strong>正解: D</strong><br>
移動平均法は時系列データの平滑化手法であり、CVP分析における不確実性の分析手法ではありません。<br>
<br>
感度分析：各変数の変化が結果に与える影響を分析<br>
シナリオ分析：複数の状況を想定した分析<br>
モンテカルロ・シミュレーション：確率分布を用いた多数回の試行による分析<br>
これらはすべて不確実性下でのCVP分析に有効な手法です。
</details>

### 問題16
アウトソーシングの意思決定にCVP分析を適用する場合、最も重要な検討事項は？

- B) 自社生産時の変動費と外注費の比較
- C) 品質管理コストのみ
- D) 人件費のみ

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
アウトソーシングの意思決定では、自社生産を続ける場合の変動費（回避可能原価）と外注費を比較することが基本です。ただし、実務では以下も考慮する必要があります：<br>
- 回避可能な固定費<br>
- 品質管理コスト<br>
- 機会費用<br>
- 戦略的要因（コア・コンピタンス、柔軟性等）<br>

### 問題17
CVP分析を用いた価格戦略で、需要の価格弾力性が-2の場合、価格を10%引き下げると販売量は？

- A) 5%増加
- B) 10%増加
- C) 20%増加
- D) 20%減少

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
需要の価格弾力性 = 需要量の変化率 ÷ 価格の変化率<br>
-2 = 需要量の変化率 ÷ (-10%)<br>
需要量の変化率 = -2 × (-10%) = 20%<br>
<br>
価格弾力性が-2ということは、価格が1%下がると需要量が2%増加することを意味します。したがって、価格を10%引き下げると販売量は20%増加します。
</details>

## 9. 専門用語集

このスライドで使用された専門用語について、50音順で解説します。

### あ行

**安全余裕率（あんぜんよゆうりつ）**
- **読み方**: あんぜんよゆうりつ
- **意味**: 現在の売上高が損益分岐点売上高をどれだけ上回っているかを示す指標。売上高がどの程度減少しても赤字にならないかの余裕度を表す
- **計算式**: (実際売上高 - 損益分岐点売上高) ÷ 実際売上高 × 100%
- **関連用語**: 損益分岐点、経営安全率

**営業レバレッジ（えいぎょうればれっじ）**
- **読み方**: えいぎょうればれっじ
- **意味**: 売上高の変化に対する営業利益の変化の程度を示す指標。固定費の存在により生じる利益の拡大効果
- **計算式**: 貢献利益 ÷ 営業利益
- **関連用語**: 財務レバレッジ、総合レバレッジ

### か行

**加重平均（かじゅうへいきん）**
- **読み方**: かじゅうへいきん
- **意味**: 複数の数値に重要度（ウェイト）を掛けて平均を求める方法。CVP分析では複数製品の販売構成比を考慮した平均値の算出に使用
- **関連用語**: 単純平均、販売構成比

**感度分析（かんどぶんせき）**
- **読み方**: かんどぶんせき
- **意味**: 入力変数の変化が結果に与える影響を分析する手法。CVP分析では価格、数量、費用の変化が利益に与える影響を測定
- **関連用語**: シナリオ分析、What-if分析

**貢献利益（こうけんりえき）**
- **読み方**: こうけんりえき
- **意味**: 売上高から変動費を差し引いた利益。固定費の回収と利益の創出に貢献する利益額
- **計算式**: 売上高 - 変動費
- **関連用語**: 限界利益、粗利益

**貢献利益率（こうけんりえきりつ）**
- **読み方**: こうけんりえきりつ
- **意味**: 売上高に占める貢献利益の割合。売上高1円当たりの貢献利益を示す
- **計算式**: 貢献利益 ÷ 売上高 × 100%
- **関連用語**: 変動費率、限界利益率

**固定費（こていひ）**
- **読み方**: こていひ
- **意味**: 生産量や販売量の変化に関係なく一定期間内で一定額発生する費用
- **例**: 賃借料、減価償却費、管理職給与
- **関連用語**: 変動費、準固定費

### さ行

**CVP分析（しーぶいぴーぶんせき）**
- **読み方**: しーぶいぴーぶんせき
- **意味**: Cost-Volume-Profit Analysisの略。原価・販売量・利益の関係を分析する管理会計手法
- **関連用語**: 損益分岐点分析、利益計画

**準固定費（じゅんこていひ）**
- **読み方**: じゅんこていひ
- **意味**: 一定の範囲内では固定的だが、活動量が大きく変化すると段階的に変化する費用
- **例**: 監督者給与、設備のリース料
- **関連用語**: 段階的固定費、ステップコスト

**準変動費（じゅんへんどうひ）**
- **読み方**: じゅんへんどうひ
- **意味**: 固定費的要素と変動費的要素の両方を持つ費用
- **例**: 電気料金（基本料金＋従量料金）
- **関連用語**: 混合費

**損益分岐点（そんえきぶんきてん）**
- **読み方**: そんえきぶんきてん
- **意味**: 総収益と総費用が等しくなり、利益がゼロとなる販売量または売上高
- **英語**: Break-Even Point (BEP)
- **関連用語**: 損益分岐点分析、採算点

### た行

**段階的固定費（だんかいてきこていひ）**
- **読み方**: だんかいてきこていひ
- **意味**: 活動量が一定水準を超えると段階的に増加する固定費
- **英語**: Step Cost
- **関連用語**: 準固定費、キャパシティコスト

**単位貢献利益（たんいこうけんりえき）**
- **読み方**: たんいこうけんりえき
- **意味**: 製品1単位当たりの貢献利益。販売価格から単位変動費を差し引いた額
- **計算式**: 販売価格 - 単位変動費
- **関連用語**: 単位限界利益

**直接原価計算（ちょくせつげんかけいさん）**
- **読み方**: ちょくせつげんかけいさん
- **意味**: 変動製造原価のみを製品原価とし、固定製造原価を期間費用として処理する原価計算方法
- **関連用語**: 全部原価計算、変動原価計算

### は行

**販売構成比（はんばいこうせいひ）**
- **読み方**: はんばいこうせいひ
- **意味**: 複数製品の販売量または売上高の全体に占める各製品の割合
- **関連用語**: プロダクトミックス、売上構成比

**変動費（へんどうひ）**
- **読み方**: へんどうひ
- **意味**: 生産量や販売量の変化に比例して変動する費用
- **例**: 原材料費、直接労務費、販売手数料
- **関連用語**: 固定費、比例費

**変動費率（へんどうひりつ）**
- **読み方**: へんどうひりつ
- **意味**: 売上高に占める変動費の割合
- **計算式**: 変動費 ÷ 売上高 × 100%
- **関連用語**: 貢献利益率

### ま行

**目標利益（もくひょうりえき）**
- **読み方**: もくひょうりえき
- **意味**: 企業が達成を目指す利益額。CVP分析では目標利益達成に必要な販売量や売上高を計算
- **関連用語**: 利益計画、予算

### ら行

**利益計画（りえきけいかく）**
- **読み方**: りえきけいかく
- **意味**: 目標利益を達成するための販売計画、生産計画、費用計画などを総合的に立案すること
- **関連用語**: 予算管理、経営計画

**臨界点（りんかいてん）**
- **読み方**: りんかいてん
- **意味**: 損益分岐点の別称。利益と損失の境界点
- **関連用語**: 損益分岐点、採算点

- **理解促進**: 初学者にも分かりやすい説明を心がける
