# 設備投資案の評価について

## 概要

設備投資案の評価は、企業が限られた資金を効率的に配分し、企業価値を最大化するための重要な意思決定プロセスです。投資案の採否を判断するために、複数の評価手法が開発されており、それぞれに特徴と限界があります。本資料では、代表的な4つの評価手法について詳しく解説します。

## 1. 正味現在価値法（NPV法）

### 定義と概要

正味現在価値法（Net Present Value Method）は、投資案から生じる将来キャッシュフローを現在価値に割り引いて合計し、初期投資額を差し引いた値（NPV）を計算する手法です。

### 計算式

```
NPV = Σ(CFt / (1 + r)^t) - I0

ここで:
- CFt: t期のキャッシュフロー
- r: 割引率（資本コスト）
- t: 期間
- I0: 初期投資額
```

### 判断基準
- **NPV > 0**: 投資案を採択
- **NPV = 0**: 採択・棄却は無差別
- **NPV < 0**: 投資案を棄却

### 具体的計算例

**例1: 基本的なNPV計算**
- 初期投資額: 1,000万円
- 年間キャッシュフロー: 300万円（5年間）
- 割引率: 10%

```
NPV = 300/(1.1)¹ + 300/(1.1)² + 300/(1.1)³ + 300/(1.1)⁴ + 300/(1.1)⁵ - 1,000
    = 272.7 + 247.9 + 225.4 + 204.9 + 186.3 - 1,000
    = 1,137.2 - 1,000
    = 137.2万円
```

**結果**: NPV > 0のため、投資案を採択すべき

### メリット
- 貨幣の時間価値を考慮
- 金額表示で直感的に理解しやすい
- 複数案の比較が容易

### デメリット
- 割引率の設定が困難
- 投資規模の異なる案の比較に注意が必要

## 2. 内部収益率法（IRR法）

### 定義と概要

内部収益率法（Internal Rate of Return Method）は、NPVをゼロにする割引率（IRR）を求め、それを資本コストと比較して投資判断を行う手法です。

### 計算式

```
0 = Σ(CFt / (1 + IRR)^t) - I0
```

### 判断基準
- **IRR > 資本コスト**: 投資案を採択
- **IRR = 資本コスト**: 採択・棄却は無差別
- **IRR < 資本コスト**: 投資案を棄却

### 具体的計算例

**例2: IRRの計算**
- 初期投資額: 500万円
- キャッシュフロー: 1年目200万円、2年目300万円、3年目250万円

試行錯誤法またはExcelのIRR関数を使用：
```
0 = 200/(1+IRR)¹ + 300/(1+IRR)² + 250/(1+IRR)³ - 500
```

計算結果: IRR ≈ 22.7%

資本コストが15%の場合、IRR > 資本コストのため採択

### メリット
- 収益率で表示されるため理解しやすい
- 投資規模に依存しない相対的評価

### デメリット
- 複数のIRRが存在する場合がある
- 相互排他的な投資案の比較に問題がある

## 3. 収益性指数法（PI法）

### 定義と概要

収益性指数法（Profitability Index Method）は、将来キャッシュフローの現在価値合計を初期投資額で割った値を計算する手法です。

### 計算式

```
PI = Σ(CFt / (1 + r)^t) / I0
```

### 判断基準
- **PI > 1.0**: 投資案を採択
- **PI = 1.0**: 採択・棄却は無差別
- **PI < 1.0**: 投資案を棄却

### 具体的計算例

**例3: PIの計算**
- 初期投資額: 800万円
- 年間キャッシュフロー: 250万円（4年間）
- 割引率: 8%

```
キャッシュフローの現在価値合計 = 250/(1.08)¹ + 250/(1.08)² + 250/(1.08)³ + 250/(1.08)⁴
                              = 231.5 + 214.3 + 198.5 + 183.8
                              = 828.1万円

PI = 828.1 / 800 = 1.035
```

**結果**: PI > 1.0のため、投資案を採択すべき

### メリット
- 投資効率を示す指標として有用
- 資本制約下での投資案選択に適している

### デメリット
- 投資規模の違いを反映しない
- 相互排他的な投資案の比較に注意が必要

## 4. 回収期間法

### 定義と概要

回収期間法（Payback Period Method）は、初期投資額を回収するまでの期間を計算し、その期間の長短で投資判断を行う手法です。

### 計算方法

累積キャッシュフローが初期投資額に達するまでの期間を計算

### 判断基準
- **回収期間 < 基準期間**: 投資案を採択
- **回収期間 ≥ 基準期間**: 投資案を棄却

### 具体的計算例

**例4: 回収期間の計算**
- 初期投資額: 600万円
- キャッシュフロー: 1年目150万円、2年目200万円、3年目250万円、4年目300万円

```
累積キャッシュフロー:
1年目: 150万円
2年目: 350万円（150 + 200）
3年目: 600万円（350 + 250）
```

**結果**: 回収期間は3年

### メリット
- 計算が簡単で理解しやすい
- 流動性リスクの評価に有用

### デメリット
- 貨幣の時間価値を考慮しない
- 回収期間後のキャッシュフローを無視

## 5. 各手法の比較

| 評価手法 | 時間価値考慮 | 全期間CF考慮 | 計算の容易さ | 相互排他案の比較 |
|---------|------------|------------|------------|----------------|
| NPV法 | ○ | ○ | △ | ◎ |
| IRR法 | ○ | ○ | △ | △ |
| PI法 | ○ | ○ | ○ | △ |
| 回収期間法 | × | × | ◎ | ○ |

## 6. 実務上の注意点

### 複数手法の併用
- 単一の手法に頼らず、複数の手法を組み合わせて総合的に判断
- 各手法の長所・短所を理解した上で使用

### 感度分析の実施
- キャッシュフロー予測の不確実性を考慮
- 主要変数の変化が結果に与える影響を分析

### 定性的要因の考慮
- 戦略的適合性
- 技術革新への対応
- 環境・社会への影響

### 問題1
初期投資額1,200万円、年間キャッシュフロー400万円（4年間）、割引率12%の投資案のNPVを計算せよ。

<details>
<summary>解答</summary>
<strong>NPV = 14.9万円</strong><br>
計算過程：<br>
NPV = 400/(1.12)¹ + 400/(1.12)² + 400/(1.12)³ + 400/(1.12)⁴ - 1,200<br>
    = 357.1 + 318.9 + 284.7 + 254.2 - 1,200<br>
    = 1,214.9 - 1,200<br>
    = 14.9万円<br>
NPV > 0のため採択すべき
</details>

試行錯誤法により、IRR ≈ 19.4%

### 問題6

</details>

### 問題18
投資案AのIRR=18%、投資案BのIRR=15%である。資本コストが12%の場合、必ずA案を選択すべきか。理由も述べよ。

<summary>解答</summary>

</details>

## 8. 専門用語集

### アルファベット

**DCF (Discounted Cash Flow)**
- **読み方**: ディーシーエフ
- **意味**: 割引キャッシュフロー。将来のキャッシュフローを現在価値に割り引く手法
- **関連用語**: NPV、現在価値、割引率

**IRR (Internal Rate of Return)**
- **読み方**: アイアールアール
- **意味**: 内部収益率。NPVをゼロにする割引率
- **関連用語**: NPV、割引率、収益率

**MIRR (Modified Internal Rate of Return)**
- **読み方**: エムアイアールアール
- **意味**: 修正内部収益率。再投資率を考慮したIRR
- **関連用語**: IRR、再投資率

**NPV (Net Present Value)**
- **読み方**: エヌピーブイ
- **意味**: 正味現在価値。投資の現在価値から初期投資を引いた値
- **関連用語**: 現在価値、DCF、投資評価

**PI (Profitability Index)**
- **読み方**: ピーアイ
- **意味**: 収益性指数。現在価値を初期投資で割った値
- **関連用語**: NPV、投資効率

### あ行

**永続価値（えいぞくかち）**
- **意味**: 無限に続くキャッシュフローの現在価値
- **関連用語**: 終価、残存価値

### か行

**回収期間（かいしゅうきかん）**
- **意味**: 初期投資額を回収するまでの期間
- **関連用語**: 投資回収、流動性
