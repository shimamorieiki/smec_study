# 連結財務諸表について

## 概要

連結財務諸表とは、支配従属関係にある企業集団（親会社と子会社）を単一の組織体とみなして作成される財務諸表です。企業集団全体の財政状態、経営成績、キャッシュ・フローの状況を適正に表示することで、投資家等の利害関係者に対して有用な情報を提供することを目的としています。

## 1. 連結財務諸表の基本概念

### 連結の範囲
- **親会社**: 他の企業を支配している企業
- **子会社**: 親会社によって支配されている企業
- **支配**: 議決権の50%超を保有、または実質的に経営を支配している状態

### 連結財務諸表の構成
| 財務諸表 | 内容 |
|---------|------|
| 連結貸借対照表 | 企業集団全体の財政状態を表示 |
| 連結損益計算書 | 企業集団全体の経営成績を表示 |
| 連結包括利益計算書 | 包括利益の内訳を表示 |
| 連結株主資本等変動計算書 | 純資産の部の変動を表示 |
| 連結キャッシュ・フロー計算書 | 企業集団全体の資金収支を表示 |

## 2. 投資と資本の相殺消去

### 基本的な考え方
投資と資本の相殺消去は、親会社の子会社株式（投資勘定）と子会社の資本勘定を相殺し、連結財務諸表から内部取引を消去する手続きです。

### 相殺消去の仕訳パターン

#### パターン1: 100%子会社の場合
**前提条件**: 
- 親会社が子会社の株式を100%取得
- 取得価額: 1,000万円
- 子会社の純資産: 800万円（資本金500万円、利益剰余金300万円）

**相殺消去仕訳**:
```
資本金       500万円 | 子会社株式  1,000万円
利益剰余金   300万円 |
のれん       200万円 |
```

#### パターン2: 部分所有（80%）の場合
**前提条件**:
- 親会社が子会社の株式を80%取得
- 取得価額: 800万円
- 子会社の純資産: 900万円（資本金600万円、利益剰余金300万円）

**相殺消去仕訳**:
```
資本金       600万円 | 子会社株式     800万円
利益剰余金   300万円 | 非支配株主持分 180万円
のれん        80万円 |
```

### 段階取得の場合の処理

#### ケース: 段階的に支配を獲得
**第1段階**: 30%取得（持分法適用）
- 取得価額: 300万円
- 子会社純資産: 1,000万円

**第2段階**: 追加で40%取得（合計70%で支配獲得）
- 追加取得価額: 450万円
- 支配獲得時の子会社純資産: 1,200万円

**処理手順**:
1. 既保有分（30%）を時価評価
2. 段階取得に係る差額を純資産の部に計上
3. のれんは支配獲得時の時価で一括計算

## 3. のれん

### のれんの定義と性質
- **定義**: 被取得企業の取得原価が、取得時における被取得企業の識別可能資産および負債の純額を超過する額
- **性質**: 超過収益力を表す資産
- **会計処理**: 20年以内の効果の及ぶ期間で規則的に償却

### のれんの計算例

#### 例1: 正ののれんが発生するケース
**前提条件**:
- 買収価額: 5,000万円
- 識別可能純資産の時価: 3,500万円
- 持分比率: 100%

**計算**:
```
のれん = 5,000万円 - 3,500万円 = 1,500万円
```

**年間償却額**（10年償却の場合）:
```
年間償却額 = 1,500万円 ÷ 10年 = 150万円
```

#### 例2: 負ののれんが発生するケース
**前提条件**:
- 買収価額: 2,000万円
- 識別可能純資産の時価: 2,500万円
- 持分比率: 100%

**計算**:
```
負ののれん = 2,000万円 - 2,500万円 = △500万円
```

**会計処理**: 負ののれんは一括で特別利益に計上

### のれんの減損

#### 減損の兆候
- 営業活動から生じる損益が継続してマイナス
- 経営環境の著しい悪化
- 市場価値の著しい下落

#### 減損テストの実施例
**前提条件**:
- のれん残高: 1,000万円
- 割引前将来キャッシュ・フロー: 800万円
- 回収可能価額: 600万円

**判定と処理**:
1. 減損の認識: 1,000万円 > 800万円 → 減損を認識
2. 減損損失: 1,000万円 - 600万円 = 400万円

## 4. 非支配株主持分

### 非支配株主持分の概念
- **定義**: 子会社の純資産のうち、親会社に帰属しない部分
- **表示場所**: 連結貸借対照表の純資産の部
- **計算基準**: 子会社の純資産×非支配株主の持分比率

### 非支配株主持分の計算例

#### 基本的な計算
**前提条件**:
- 子会社の純資産: 2,000万円
- 親会社の持分比率: 70%
- 非支配株主の持分比率: 30%

**計算**:
```
非支配株主持分 = 2,000万円 × 30% = 600万円
```

#### 期中の変動を含む計算
**前提条件**:
- 期首の子会社純資産: 2,000万円
- 当期純利益: 500万円
- 配当金: 100万円
- 親会社の持分比率: 70%

**非支配株主持分の変動**:
```
期首残高: 2,000万円 × 30% = 600万円
当期純利益の配分: 500万円 × 30% = 150万円
配当金の配分: △100万円 × 30% = △30万円
期末残高: 600万円 + 150万円 - 30万円 = 720万円
```

### 非支配株主との取引

#### ケース1: 追加取得（親会社が非支配株主から株式を追加取得）
**前提条件**:
- 既存持分: 70%
- 追加取得: 10%（取得価額300万円）
- 追加取得時の非支配株主持分（10%分）: 250万円

**処理**:
```
非支配株主持分 250万円 | 現金預金 300万円
資本剰余金      50万円 |
```

#### ケース2: 一部売却（親会社が保有株式の一部を売却）
**前提条件**:
- 既存持分: 80%
- 売却持分: 10%（売却価額400万円）
- 売却による非支配株主持分の増加額: 350万円

**処理**:
```
現金預金        400万円 | 非支配株主持分 350万円
                        | 資本剰余金      50万円
```

## 5. 連結修正仕訳の実務

### 内部取引の消去

#### 商品売買取引の消去
**前提条件**:
- 親会社から子会社への商品売上: 1,000万円
- 原価: 700万円
- 期末在庫（子会社）: 200万円

**消去仕訳**:
```
売上高      1,000万円 | 売上原価    1,000万円
売上原価       60万円 | 商品          60万円
                      | (未実現利益の消去)
```

#### 債権債務の消去
**前提条件**:
- 親会社の売掛金: 500万円
- 子会社の買掛金: 500万円

**消去仕訳**:
```
買掛金       500万円 | 売掛金       500万円
```

## 6. 実務上の注意点

### 連結決算実務のポイント
- **決算日の統一**: 原則として親会社と子会社の決算日を統一
- **会計処理の統一**: グループ内で会計方針を統一
- **重要性の原則**: 金額的・質的に重要性の乏しい子会社は連結範囲から除外可能

### よくある誤解とトラブル
- **誤解1**: 持分法適用会社も連結範囲に含まれる
  - 正解: 持分法適用会社は連結範囲外（関連会社として別途処理）
- **誤解2**: のれんは一括で費用処理する
  - 正解: 20年以内の効果の及ぶ期間で規則的に償却

## 7. よくある質問（Q&A）

### Q1. 親会社と子会社の決算日が異なる場合の処理は？

**A1.** 原則として決算日を統一しますが、実務上困難な場合は以下の処理を行います。

#### 決算日の差異が3か月を超えない場合
- 子会社の決算日現在の財務諸表を使用
- 重要な取引は調整仕訳で反映

#### 決算日の差異が3か月を超える場合
- 仮決算を実施して連結

### Q2. のれんの償却年数はどのように決定するのですか？

**A2.** 投資の効果が及ぶ期間を合理的に見積もって決定します。

#### 償却年数決定の考慮事項
- 被取得企業の事業内容
- 企業結合の目的
- シナジー効果の発現期間
- 業界慣行

**実務では5年～10年が多く採用されています。**

### Q3. 非支配株主持分はなぜ純資産の部に表示するのですか？

**A3.** 国際的な会計基準との整合性を図るためです。

#### 表示の変遷
- **旧基準**: 負債の部と純資産の部の中間（少数株主持分）
- **現行基準**: 純資産の部の株主資本以外の項目

これにより、連結財務諸表が企業集団全体の観点から作成されていることが明確になりました。

## 8. 理解度確認クイズ（4択問題20問）

### 問題1
連結財務諸表の作成目的として最も適切なものはどれか。

- A) 親会社単独の財政状態を詳細に開示するため
- B) 企業集団を単一の組織体とみなして財務情報を提供するため
- C) 子会社の個別業績を強調するため
- D) 税務申告のための基礎資料を作成するため

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
連結財務諸表は、支配従属関係にある企業集団を単一の組織体とみなして、その財政状態、経営成績、キャッシュ・フローの状況を表示することを目的としています。<br>
Aは誤り：親会社単独ではなく企業集団全体を表示します。<br>
Cは誤り：個別業績ではなく集団全体の業績を表示します。<br>
Dは誤り：税務申告は個別財務諸表で行います。
</details>

### 問題2
親会社が子会社株式を80%取得した場合の投資と資本の相殺消去で、正しい処理はどれか。
（子会社の純資産1,000万円、取得価額900万円）

- A) のれん100万円、非支配株主持分200万円を計上
- B) のれん260万円、非支配株主持分200万円を計上  
- C) 負ののれん100万円、非支配株主持分200万円を計上
- D) のれん100万円、非支配株主持分100万円を計上

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
計算過程：<br>
・取得持分に対応する純資産 = 1,000万円 × 80% = 800万円<br>
・のれん = 900万円 - 800万円 = 100万円...ではなく<br>
・のれん = 取得価額900万円 - (純資産1,000万円 × 80%) = 900万円 - 800万円 = 100万円<br>
・非支配株主持分 = 1,000万円 × 20% = 200万円<br>
※問題の選択肢に誤りがありました。正しくは「のれん100万円、非支配株主持分200万円」となります。
</details>

### 問題3
のれんの会計処理について正しいものはどれか。

- A) 一括で特別損失に計上する
- B) 20年以内の効果の及ぶ期間で規則的に償却する
- C) 永久に資産として計上し続ける
- D) 5年間で均等償却することが義務付けられている

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
日本基準では、のれんは20年以内の効果の及ぶ期間にわたり、規則的に償却することが求められています。<br>
Aは誤り：負ののれんの場合は一括で特別利益に計上しますが、正ののれんは償却します。<br>
Cは誤り：IFRS等では非償却ですが、日本基準では償却が必要です。<br>
Dは誤り：5年固定ではなく、効果の及ぶ期間を合理的に見積もります。
</details>

### 問題4
非支配株主持分の表示場所として正しいものはどれか。

- A) 連結貸借対照表の流動負債の部
- B) 連結貸借対照表の固定負債の部
- C) 連結貸借対照表の純資産の部
- D) 連結損益計算書の特別損益の部

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
現行の会計基準では、非支配株主持分は連結貸借対照表の純資産の部に、株主資本以外の項目として表示されます。これは国際的な会計基準との整合性を図った結果です。<br>
A、Bは誤り：負債ではなく純資産の構成要素です。<br>
Dは誤り：貸借対照表項目であり、損益計算書項目ではありません。
</details>

### 問題5
段階取得により支配を獲得した場合の会計処理として正しいものはどれか。

- A) 既保有分は簿価のまま処理する
- B) 既保有分を支配獲得時の時価で再評価する
- C) 既保有分に係るのれんは償却しない
- D) 段階取得の処理は認められていない

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
段階取得により支配を獲得した場合、既に保有していた持分（既保有分）は支配獲得時の時価で再評価し、評価差額は段階取得に係る損益として処理します。<br>
Aは誤り：時価評価が必要です。<br>
Cは誤り：のれんは一括計算し、通常通り償却します。<br>
Dは誤り：段階取得は実務でよく発生し、会計基準で処理方法が定められています。
</details>

### 問題6
親会社から子会社への商品売上1,000万円（原価700万円）があり、期末に200万円が子会社在庫として残っている場合の未実現利益はいくらか。

- A) 60万円
- B) 140万円
- C) 200万円
- D) 300万円

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
計算過程：<br>
・利益率 = (1,000万円 - 700万円) ÷ 1,000万円 = 30%<br>
・未実現利益 = 200万円 × 30% = 60万円<br>
期末在庫に含まれる内部利益を消去する必要があります。
</details>

### 問題7
連結決算において、親会社と子会社の決算日が異なる場合の原則的な処理はどれか。

- A) 親会社の決算日に統一する
- B) 子会社の決算日に統一する
- C) それぞれの決算日の財務諸表をそのまま使用する
- D) 中間の日付で仮決算を行う

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
連結決算においては、原則として親会社の決算日に統一します。ただし、決算日の差異が3か月を超えない場合は、子会社の決算日現在の財務諸表を使用することも認められています（重要な取引については必要な調整を行う）。
</details>

### 問題8
のれんの減損の兆候として該当しないものはどれか。

- A) 営業活動から生じる損益の継続的なマイナス
- B) 経営環境の著しい悪化
- C) 一時的な売上の増加
- D) 市場価値の著しい下落

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
一時的な売上の増加はむしろ好材料であり、減損の兆候ではありません。<br>
A、B、Dはいずれも減損会計基準で示されている減損の兆候に該当します。継続的な赤字、経営環境の悪化、市場価値の下落は、資産の収益性が低下している可能性を示唆します。
</details>

### 問題9
親会社が保有する子会社株式（持分70%）の一部（10%）を売却した場合の会計処理として正しいものはどれか。

- A) 売却損益を特別損益に計上する
- B) 売却差額を資本剰余金に計上する
- C) 売却差額を利益剰余金に計上する
- D) 売却差額をその他の包括利益に計上する

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
支配が継続している状況での子会社株式の一部売却は、資本取引として処理されます。したがって、売却価額と減少する持分との差額は資本剰余金に直接計上され、損益は認識されません。
</details>

### 問題10
連結財務諸表に含まれない財務諸表はどれか。

- A) 連結貸借対照表
- B) 連結損益計算書
- C) 連結製造原価報告書
- D) 連結キャッシュ・フロー計算書

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
連結製造原価報告書は作成されません。連結財務諸表は、連結貸借対照表、連結損益計算書、連結包括利益計算書、連結株主資本等変動計算書、連結キャッシュ・フロー計算書から構成されます。製造原価は連結損益計算書の売上原価に含めて表示されます。
</details>

### 問題11
負ののれんが発生した場合の会計処理として正しいものはどれか。

- A) 20年以内で規則的に償却する
- B) 一括で特別利益に計上する
- C) 一括で特別損失に計上する
- D) 資本剰余金に計上する

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
負ののれん（取得原価が識別可能純資産を下回る場合）は、その発生年度において一括で特別利益に計上します。これは、バーゲンパーチェス（割安購入）による利益と考えられるためです。
</details>

### 問題12
子会社の当期純利益500万円のうち、親会社持分が70%の場合、非支配株主に帰属する当期純利益はいくらか。

- A) 150万円
- B) 350万円
- C) 500万円
- D) 700万円

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
計算過程：<br>
非支配株主に帰属する当期純利益 = 500万円 × (100% - 70%) = 500万円 × 30% = 150万円<br>
子会社の利益は持分比率に応じて親会社と非支配株主に配分されます。
</details>

### 問題13
連結精算表の作成順序として最も適切なものはどれか。

- A) 個別財務諸表 → 連結修正仕訳 → 連結財務諸表
- B) 連結修正仕訳 → 個別財務諸表 → 連結財務諸表
- C) 連結財務諸表 → 個別財務諸表 → 連結修正仕訳
- D) 個別財務諸表 → 連結財務諸表 → 連結修正仕訳

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
連結財務諸表の作成は、まず親会社と子会社の個別財務諸表を合算し、次に連結修正仕訳（投資と資本の相殺消去、内部取引の消去等）を行い、最後に連結財務諸表を作成するという順序で行われます。
</details>

### 問題14
内部取引の消去が必要な理由として最も適切なものはどれか。

- A) 税務上の要請があるため
- B) 企業集団を単一の組織体として表示するため
- C) 個別企業の業績を明確にするため
- D) 監査の便宜を図るため

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
連結財務諸表は企業集団を単一の組織体とみなして作成するため、グループ内の内部取引は存在しないものとして消去する必要があります。これにより、企業集団と外部との取引のみが財務諸表に表示されることになります。
</details>

### 問題15
親会社がのれんの減損テストを実施した結果、のれん残高1,000万円に対して回収可能価額が600万円と算定された場合の減損損失はいくらか。

- A) 0円（減損なし）
- B) 400万円
- C) 600万円
- D) 1,000万円

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
減損損失 = のれん帳簿価額 - 回収可能価額 = 1,000万円 - 600万円 = 400万円<br>
のれんの帳簿価額が回収可能価額を上回る場合、その差額を減損損失として認識します。
</details>

### 問題16
非支配株主持分の変動要因に該当しないものはどれか。

- A) 子会社の当期純利益
- B) 子会社からの配当
- C) 親会社の増資
- D) 親会社による子会社株式の追加取得

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
親会社の増資は親会社の資本の変動であり、非支配株主持分には影響しません。<br>
Aは正：子会社利益の非支配株主持分相当額が加算されます。<br>
Bは正：配当の非支配株主持分相当額が減算されます。<br>
Dは正：追加取得により非支配株主持分が減少します。
</details>

### 問題17
連結会計において持分法が適用される会社はどれか。

- A) 議決権の60%を保有する会社
- B) 議決権の25%を保有し重要な影響力を有する会社
- C) 議決権の10%を保有する会社
- D) 議決権の51%を保有する会社

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
持分法は、議決権の20%以上50%以下を保有し、重要な影響力を有する関連会社に適用されます。<br>
A、Dは誤り：50%超は子会社として連結対象となります。<br>
Cは誤り：通常20%未満では重要な影響力がないと推定されます。
</details>

### 問題18
連結範囲の決定において「支配」の判定基準とならないものはどれか。

- A) 議決権の過半数を所有
- B) 取締役会の構成員の過半数を占める
- C) 重要な財務及び営業の方針決定を支配する契約の存在
- D) 売上高の過半数を占める取引関係

<details>
<summary>解答</summary>
<strong>正解: D</strong><br>
売上高の大小は支配の判定基準ではありません。支配は議決権比率、役員の派遣状況、契約関係等により判定されます。取引関係の大小は影響力の一要素となることはありますが、それだけで支配は判定されません。
</details>

### 問題19
のれんの償却年数を決定する際の考慮事項として不適切なものはどれか。

- A) 被取得企業の事業内容
- B) 投資の効果が及ぶ期間
- C) 税法上の損金算入期間
- D) 企業結合によるシナジー効果

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
のれんの償却年数は会計上の判断により決定され、税法上の取扱いとは独立しています。<br>
A、B、Dは正：これらは全て償却年数決定の重要な考慮事項です。投資効果の発現期間を合理的に見積もることが重要です。
</details>

### 問題20
連結キャッシュ・フロー計算書の作成方法として正しいものはどれか。

- A) 親会社のキャッシュ・フロー計算書に子会社分を単純合算する
- B) 連結貸借対照表と連結損益計算書から作成する
- C) 個別キャッシュ・フロー計算書を合算し、内部取引を消去する
- D) 子会社のキャッシュ・フロー計算書のみから作成する

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
連結キャッシュ・フロー計算書は、原則として連結貸借対照表と連結損益計算書を基に作成されます（原則法）。これにより、連結修正仕訳の影響が適切に反映されます。<br>
Cの方法（簡便法）も認められていますが、原則法が基本です。
</details>

## 9. 専門用語集

### あ行

**相殺消去（そうさいしょうきょ）**
- **読み方**: そうさいしょうきょ
- **意味**: 連結会社間の債権債務、取引高、未実現損益等を連結財務諸表から除去する手続き
- **関連用語**: 投資と資本の相殺消去、内部取引消去

### か行

**企業結合（きぎょうけつごう）**
- **読み方**: きぎょうけつごう
- **意味**: ある企業又は企業を構成する事業と他の企業又は企業を構成する事業とが一つの報告単位に統合されること
- **関連用語**: 買収、合併、のれん

**共通支配下の取引（きょうつうしはいかのとりひき）**
- **読み方**: きょうつうしはいかのとりひき
- **意味**: すべての結合当事企業又は事業が、企業結合の前後で同一の企業により最終的に支配され、かつ、その支配が一時的でない場合の企業結合
- **関連用語**: グループ内再編、組織再編

### さ行

**支配（しはい）**
- **読み方**: しはい
- **意味**: ある企業の財務及び営業又は事業の方針を決定する機関を支配している状態
- **関連用語**: 親会社、子会社、議決権

**持分法（じぶんほう）**
- **読み方**: じぶんほう
- **意味**: 投資会社が被投資会社の純資産及び損益のうち投資会社に帰属する部分の変動に応じて、その投資の額を連結決算日ごとに修正する方法
- **関連用語**: 関連会社、重要な影響力

### た行

**段階取得（だんかいしゅとく）**
- **読み方**: だんかいしゅとく
- **意味**: 複数回の取引により他の企業の支配を獲得すること
- **関連用語**: 追加取得、支配獲得

### な行

**内部取引（ないぶとりひき）**
- **読み方**: ないぶとりひき
- **意味**: 連結グループ内の会社間で行われる取引
- **関連用語**: 内部売上高、内部仕入高、未実現利益

**のれん**
- **読み方**: のれん
- **意味**: 被取得企業の取得原価が、取得時における被取得企業の識別可能資産及び負債の純額を超過する額で、超過収益力を表す
- **関連用語**: 正ののれん、負ののれん、のれん償却

### は行

**非支配株主持分（ひしはいかぶぬしもちぶん）**
- **読み方**: ひしはいかぶぬしもちぶん
- **意味**: 子会社の純資産のうち、親会社に帰属しない部分
- **関連用語**: 少数株主持分（旧称）、非支配株主損益

**負ののれん（ふののれん）**
- **読み方**: ふののれん
- **意味**: 被取得企業の取得原価が、取得時における識別可能資産及び負債の純額を下回る場合の差額
- **関連用語**: バーゲンパーチェス、特別利益

### ま行

**未実現利益（みじつげんりえき）**
- **読み方**: みじつげんりえき
- **意味**: 連結グループ内取引により生じた利益で、連結グループ外部に対して実現していない利益
- **関連用語**: 内部利益、棚卸資産未実現利益

### ら行

**連結子会社（れんけつこがいしゃ）**
- **読み方**: れんけつこがいしゃ
- **意味**: 連結財務諸表作成にあたり連結の範囲に含められる子会社
- **関連用語**: 連結範囲、非連結子会社

**連結修正仕訳（れんけつしゅうせいしわけ）**
- **読み方**: れんけつしゅうせいしわけ
- **意味**: 個別財務諸表を合算したものから連結財務諸表を作成するために必要な修正仕訳
- **関連用語**: 連結精算表、開始仕訳

**連結精算表（れんけつせいさんひょう）**
- **読み方**: れんけつせいさんひょう
- **意味**: 個別財務諸表を合算し、連結修正仕訳を加えて連結財務諸表を作成するための作業表
- **関連用語**: ワークシート、連結修正仕訳

**連結範囲（れんけつはんい）**
- **読み方**: れんけつはんい
- **意味**: 連結財務諸表に含める親会社及び子会社の範囲
- **関連用語**: 連結子会社、非連結子会社、重要性の原則

---

**用語集作成時の注意点:**
- **正確性**: 会計基準に準拠した正確な定義を記載
- **実務性**: 実務で使われる文脈や注意点も含める
- **関連性**: 関連する用語との関係を明確にする
- **理解しやすさ**: 専門用語を使わずに平易な言葉で説明する
