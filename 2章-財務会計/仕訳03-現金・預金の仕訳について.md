# 現金・預金の仕訳について

## 現金・預金取引の概要

現金および預金は企業活動における最も基本的な決済手段であり、すべての取引の起点または終点となります。簿記上の「現金」は、通貨（紙幣・硬貨）だけでなく、通貨代用証券も含む広い概念です。また、預金は普通預金、当座預金、定期預金など多様な形態があり、それぞれ異なる特徴と会計処理を持ちます。正確な現金・預金管理は、企業の資金繰りと内部統制の観点から極めて重要です。

## 1. 現金の範囲と種類

### 通貨
- **定義**: 日本銀行券（紙幣）および補助貨幣（硬貨）
- **特徴**: 最も流動性が高く、即座に支払いに使用可能
- **重要性**: 日常的な小口取引の決済手段

### 通貨代用証券
- **定義**: 現金と同様に扱われる証券類
- **種類**: 
  - 他人振出小切手（送金小切手、預金小切手を含む）
  - 郵便為替証書
  - 配当金領収証
  - 期限到来済の公社債利札
- **特徴**: 金融機関で即座に現金化可能

### 現金勘定に含まれないもの
- 自社振出小切手（当座預金の減少）
- 期限未到来の公社債利札
- 収入印紙・切手（貯蔵品または通信費）
- 商品券（前受金または受取商品券）

## 2. 預金の種類と特徴

### 当座預金
| 項目 | 内容 |
|------|------|
| 特徴 | 小切手・手形の決済用、無利息 |
| 用途 | 企業間取引の主要決済手段 |
| 当座借越 | 残高を超えて引き出し可能（契約により） |
| 関連帳簿 | 当座預金出納帳、銀行勘定調整表 |

### 普通預金
| 項目 | 内容 |
|------|------|
| 特徴 | 自由に預入・払出可能、利息付き |
| 用途 | 一般的な資金の保管・決済 |
| 制限 | 特になし |
| 関連帳簿 | 普通預金出納帳 |

### 定期預金
| 項目 | 内容 |
|------|------|
| 特徴 | 一定期間の預入、高金利 |
| 用途 | 余剰資金の運用 |
| 制限 | 満期前の解約は原則不可 |
| 会計処理 | 満期1年超は投資その他の資産 |

### その他の預金
- **定期積金**: 毎月一定額を積み立て、満期に元利合計を受取
- **通知預金**: 引出時に事前通知が必要、普通預金より高金利
- **別段預金**: 特定目的（配当金支払等）のための一時的な預金

## 3. 具体的計算例・事例

### ケース1: 現金取引の基本

#### パターンA: 商品500,000円を現金で販売し、他人振出小切手300,000円と現金200,000円を受け取った
- **前提条件**: 他人振出小切手は現金として処理
- **仕訳**:
  ```
  (借) 現金 500,000 / (貸) 売上 500,000
  ```
- **結果**: 小切手も現金に含めて処理

#### パターンB: 給料600,000円を支払い、従業員の要望により小切手400,000円と現金200,000円で支払った
- **前提条件**: 自社振出小切手は当座預金の減少
- **仕訳**:
  ```
  (借) 給料 600,000 / (貸) 当座預金 400,000
                     / (貸) 現金 200,000
  ```
- **結果**: 自社振出小切手は当座預金から支払い

### ケース2: 小口現金の処理

#### パターンA: 小口現金として50,000円を補給した（定額資金前渡制度）
- **前提条件**: 小口現金係に現金を前渡し
- **仕訳**:
  ```
  (借) 小口現金 50,000 / (貸) 現金 50,000
  ```
- **結果**: 小口現金勘定を設定

#### パターンB: 小口現金から交通費8,000円、事務用品費5,000円、雑費2,000円を支払い、月末に補給した
- **前提条件**: 定額資金前渡制度での精算
- **仕訳**:
  ```
  (借) 交通費 8,000 / (貸) 小口現金 15,000
  (借) 事務用品費 5,000
  (借) 雑費 2,000
  
  (借) 小口現金 15,000 / (貸) 現金 15,000
  ```
- **結果**: 使用分を補給して定額を維持

### ケース3: 当座預金取引

#### パターンA: 売掛金1,000,000円を回収し、得意先振出の小切手を当座預金に預け入れた
- **前提条件**: 他人振出小切手の当座預金預入
- **仕訳**:
  ```
  (借) 当座預金 1,000,000 / (貸) 売掛金 1,000,000
  ```
- **結果**: 直接当座預金の増加として処理

#### パターンB: 買掛金800,000円を小切手を振り出して支払った
- **前提条件**: 自社振出小切手での支払い
- **仕訳**:
  ```
  (借) 買掛金 800,000 / (貸) 当座預金 800,000
  ```
- **結果**: 当座預金の減少として処理

### ケース4: 当座借越

#### パターンA: 当座預金残高300,000円で、500,000円の小切手を振り出した（借越限度額500,000円）
- **前提条件**: 当座借越契約あり
- **仕訳**:
  ```
  (借) 仕入 500,000 / (貸) 当座預金 300,000
                     / (貸) 当座借越 200,000
  ```
- **結果**: 不足分は当座借越（負債）として処理

#### パターンB: 売上代金600,000円を当座預金に預け入れた（当座借越残高200,000円）
- **前提条件**: 当座借越の返済
- **仕訳**:
  ```
  (借) 当座借越 200,000 / (貸) 売上 600,000
  (借) 当座預金 400,000
  ```
- **結果**: まず借越を返済し、残額を当座預金に

### ケース5: 預金間の振替

#### パターンA: 普通預金から当座預金へ1,000,000円を振り替えた
- **前提条件**: 同一銀行内での振替
- **仕訳**:
  ```
  (借) 当座預金 1,000,000 / (貸) 普通預金 1,000,000
  ```
- **結果**: 預金種類の変更のみ

#### パターンB: 定期預金3,000,000円が満期となり、利息30,000円（源泉所得税20.315%）とともに普通預金に入金された
- **前提条件**: 利息の源泉徴収あり
- **仕訳**:
  ```
  (借) 普通預金 3,023,905 / (貸) 定期預金 3,000,000
                          / (貸) 受取利息 23,905
  (借) 租税公課 6,095
  ```
- **結果**: 税引後利息23,905円（30,000円×79.685%）

### ケース6: 現金過不足

#### パターンA: 現金実査の結果、帳簿残高1,000,000円に対し、実際残高は995,000円だった
- **前提条件**: 原因不明の現金不足
- **仕訳**:
  ```
  (借) 現金過不足 5,000 / (貸) 現金 5,000
  ```
- **結果**: 一時的に現金過不足勘定で処理

#### パターンB: 上記の現金不足のうち、3,000円は通信費の記帳漏れ、残額は原因不明のまま決算を迎えた
- **前提条件**: 一部原因判明、一部原因不明
- **仕訳**:
  ```
  (借) 通信費 3,000 / (貸) 現金過不足 3,000
  (借) 雑損失 2,000 / (貸) 現金過不足 2,000
  ```
- **結果**: 原因不明分は雑損失として処理

### ケース7: 銀行勘定調整

#### パターンA: 当座預金の帳簿残高2,000,000円、銀行残高2,150,000円、未取付小切手200,000円、未取立小切手50,000円
- **前提条件**: 銀行勘定調整表の作成
- **計算**:
  ```
  銀行残高 2,150,000円
  加算：未取付小切手 200,000円
  減算：未取立小切手 50,000円
  調整後残高 2,300,000円
  
  帳簿残高 2,000,000円
  差額 300,000円（要調査）
  ```

#### パターンB: 上記の差額は、受取利息250,000円の記帳漏れと、振込手数料50,000円の記帳漏れだった
- **仕訳**:
  ```
  (借) 当座預金 250,000 / (貸) 受取利息 250,000
  (借) 支払手数料 50,000 / (貸) 当座預金 50,000
  ```
- **結果**: 帳簿残高を修正して一致

## 4. 外貨預金の処理

### 外貨預金の開設
1. **預入時**: 預入時の為替レートで円換算
   ```
   (借) 外貨預金 xxx / (貸) 現金 xxx
   ```

2. **決算時**: 決算日レートで評価替え
   ```
   (借) 外貨預金 xxx / (貸) 為替差益 xxx
   または
   (借) 為替差損 xxx / (貸) 外貨預金 xxx
   ```

3. **引出時**: 引出時の為替レートで円換算
   ```
   (借) 現金 xxx / (貸) 外貨預金 xxx
   (借) 為替差損益 xxx
   ```

### 電子記録債権・債務との連携
- **電子記録債権の発生**:
  ```
  (借) 電子記録債権 xxx / (貸) 売上 xxx
  ```
- **電子記録債権の決済**:
  ```
  (借) 普通預金 xxx / (貸) 電子記録債権 xxx
  ```

## 5. 実務上の注意点

### 現金・預金管理の重要ポイント
- **ポイント1**: 現金は日次で実査を行い、帳簿残高と照合する
- **ポイント2**: 小切手は振出日から6か月で時効となるため注意
- **ポイント3**: 当座借越は実質的に短期借入金として開示
- **ポイント4**: 通貨代用証券は速やかに預金化する
- **ポイント5**: 銀行勘定調整表は月次で作成し、差異を調査する

### よくある誤解・トラブル
- **誤解1**: 収入印紙や切手を現金として処理してしまう
  - 正しい理解: 収入印紙は租税公課または貯蔵品、切手は通信費または貯蔵品
- **誤解2**: 自社振出小切手を現金で処理してしまう
  - 正しい理解: 自社振出小切手は当座預金の減少
- **誤解3**: 当座借越を当座預金のマイナス残高として処理してしまう
  - 正しい理解: 当座借越は負債勘定として処理

## 6. よくある質問（Q&A）

### Q1. 他人振出小切手と自社振出小切手の処理の違いは？

**A1.** 他人振出小切手は現金、自社振出小切手は当座預金で処理します。

#### 詳細説明
- **他人振出小切手**: 受け取った時点で現金勘定に計上。銀行で換金可能な通貨代用証券として扱います。
- **自社振出小切手**: 振出時に当座預金を減少させます。相手方に渡った時点で当座預金から引き落とされる可能性があるためです。

例：売掛金100,000円を他人振出小切手で回収
```
(借) 現金 100,000 / (貸) 売掛金 100,000
```

例：買掛金100,000円を自社振出小切手で支払い
```
(借) 買掛金 100,000 / (貸) 当座預金 100,000
```

### Q2. 当座借越契約がある場合の処理方法は？

**A2.** 当座預金残高を超える支払いは当座借越勘定で処理します。

#### 詳細説明
当座借越契約により、当座預金残高を超えて支払いができます。超過分は当座借越（負債）として処理します。

例：残高500,000円で800,000円の小切手振出
```
(借) 仕入 800,000 / (貸) 当座預金 500,000
                   / (貸) 当座借越 300,000
```

入金時は、まず当座借越を返済してから当座預金を増加させます。

### Q3. 銀行勘定調整表の作成目的と方法は？

**A3.** 帳簿残高と銀行残高の差異原因を明らかにし、正しい残高を把握するために作成します。

#### 詳細説明
主な調整項目：
1. **時間的ずれ**
   - 未取付小切手：振出済みだが銀行未決済
   - 未取立小切手：預入済みだが銀行未入金

2. **記帳漏れ**
   - 銀行の自動引落・振込
   - 利息の入金
   - 手数料の引落

調整後、両者の残高が一致することを確認し、記帳漏れがあれば修正仕訳を行います。

## 7. まとめ・今後の展望

現金・預金の管理は企業の資金管理の基礎であり、内部統制の重要な要素です。今後は、キャッシュレス決済の普及、電子記録債権・債務の活用、AIを活用した資金管理の自動化など、デジタル化がさらに進展することが予想されます。しかし、基本的な仕訳の理解と正確な処理の重要性は変わりません。

## 8. 理解度確認クイズ（4択問題20問）

### 問題1
商品300,000円を販売し、代金として他人振出小切手200,000円と収入印紙100,000円分を受け取った場合の仕訳はどれか？

- A) (借) 現金 300,000 / (貸) 売上 300,000
- B) (借) 現金 200,000、租税公課 100,000 / (貸) 売上 300,000
- C) (借) 現金 200,000、貯蔵品 100,000 / (貸) 売上 300,000
- D) (借) 現金 200,000、受取商品券 100,000 / (貸) 売上 300,000

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
他人振出小切手は現金として処理しますが、収入印紙は現金ではなく、使用目的により租税公課または貯蔵品として処理します。商品代金として受け取った場合は租税公課として処理するのが一般的です。<br>
<br>
Aが間違いの理由：収入印紙を現金として処理している<br>
Cが間違いの理由：収入印紙を貯蔵品で処理（在庫として保有する場合）<br>
Dが間違いの理由：収入印紙を受取商品券で処理している
</details>

### 問題2
買掛金500,000円を支払うため小切手を振り出し、ただちに仕入先に郵送した場合の仕訳はどれか？

- A) (借) 買掛金 500,000 / (貸) 現金 500,000
- B) (借) 買掛金 500,000 / (貸) 当座預金 500,000
- C) (借) 買掛金 500,000 / (貸) 未払金 500,000
- D) (借) 買掛金 500,000 / (貸) 支払手形 500,000

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
自社振出小切手は当座預金の減少として処理します。小切手を振り出した時点で当座預金から引き落とされる可能性があるため、振出時に当座預金を減少させます。<br>
<br>
Aが間違いの理由：自社振出小切手を現金で処理している<br>
Cが間違いの理由：未払金は小切手振出では使用しない<br>
Dが間違いの理由：小切手は支払手形ではない
</details>

### 問題3
当座預金残高800,000円、当座借越限度額500,000円の状況で、1,200,000円の仕入代金を小切手で支払った場合の仕訳はどれか？

- A) (借) 仕入 1,200,000 / (貸) 当座預金 1,200,000
- B) (借) 仕入 1,200,000 / (貸) 当座預金 800,000、当座借越 400,000
- C) (借) 仕入 1,200,000 / (貸) 当座預金 800,000、短期借入金 400,000
- D) (借) 仕入 1,200,000 / (貸) 当座借越 1,200,000

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
当座預金残高800,000円を超える部分400,000円は当座借越として処理します。当座借越限度額500,000円以内なので取引可能です。<br>
<br>
Aが間違いの理由：当座預金残高を超えているのに当座借越を使用していない<br>
Cが間違いの理由：当座借越を短期借入金で処理している<br>
Dが間違いの理由：当座預金残高を無視している
</details>

### 問題4
小口現金の定額資金前渡制度で、月初に30,000円を補給し、月中に交通費12,000円、消耗品費8,000円、雑費3,000円を支払った。月末の補給仕訳はどれか？

- A) (借) 交通費 12,000、消耗品費 8,000、雑費 3,000 / (貸) 小口現金 23,000
- B) (借) 小口現金 23,000 / (貸) 現金 23,000
- C) (借) 交通費 12,000、消耗品費 8,000、雑費 3,000 / (貸) 現金 23,000
- D) (借) 交通費 12,000、消耗品費 8,000、雑費 3,000 / (貸) 小口現金 23,000、(借) 小口現金 23,000 / (貸) 現金 23,000

<details>
<summary>解答</summary>
<strong>正解: D</strong><br>
定額資金前渡制度では、月末に使用分を費用計上し、同時に使用分を補給します。2つの仕訳が必要です。<br>
<br>
Aが間違いの理由：補給の仕訳が漏れている<br>
Bが間違いの理由：費用計上の仕訳が漏れている<br>
Cが間違いの理由：小口現金勘定を経由していない
</details>

### 問題5
現金の帳簿残高1,500,000円に対し、実査の結果1,508,000円あった。原因を調査したところ、受取利息10,000円の記帳漏れが判明し、残額は原因不明だった場合の仕訳はどれか？

- A) (借) 現金 8,000 / (貸) 現金過不足 8,000、(借) 現金過不足 10,000 / (貸) 受取利息 10,000、(借) 雑収入 2,000 / (貸) 現金過不足 2,000
- B) (借) 現金 8,000 / (貸) 現金過不足 8,000、(借) 現金過不足 8,000 / (貸) 受取利息 10,000、(借) 現金 2,000
- C) (借) 現金 8,000 / (貸) 受取利息 8,000
- D) (借) 現金 10,000 / (貸) 受取利息 10,000、(借) 雑損失 2,000 / (貸) 現金 2,000

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
まず現金過不足8,000円を計上し、その後原因が判明した10,000円を受取利息に振り替え、原因不明の差額2,000円（貸方）を雑収入として処理します。<br>
<br>
Bが間違いの理由：差額の計算と処理が誤り<br>
Cが間違いの理由：現金過不足勘定を使用していない<br>
Dが間違いの理由：差額を雑損失（借方）で処理している
</details>

### 問題6
売掛金700,000円を回収し、得意先から郵便為替証書500,000円と配当金領収証200,000円を受け取った場合の仕訳はどれか？

## 9. 専門用語集

### あ行
**預り金（あずかりきん）**
- **読み方**: あずかりきん
- **意味**: 一時的に預かった金銭で、後日返還または特定目的で支払う債務
- **関連用語**: 源泉所得税、社会保険料

### か行
**外貨預金（がいかよきん）**
- **読み方**: がいかよきん
- **意味**: 外国通貨建てで保有する預金
- **関連用語**: 為替差損益、為替レート

**為替差益（かわせさえき）**
- **読み方**: かわせさえき
- **意味**: 為替相場の変動により生じる利益
- **関連用語**: 為替差損、外貨預金

**為替差損（かわせさそん）**
- **読み方**: かわせさそん
- **意味**: 為替相場の変動により生じる損失
- **関連用語**: 為替差益、外貨預金

**現金（げんきん）**
- **読み方**: げんきん
- **意味**: 通貨および通貨代用証券の総称
- **関連用語**: 通貨代用証券、小口現金

**現金過不足（げんきんかふそく）**
- **読み方**: げんきんかふそく
- **意味**: 現金の実際残高と帳簿残高の差額を一時的に処理する勘定
- **関連用語**: 現金実査、雑損失、雑収入

**源泉所得税（げんせんしょとくぜい）**
- **読み方**: げんせんしょとくぜい
- **意味**: 給与や利息等の支払時に天引きされる所得税
- **関連用語**: 預り金、租税公課

**小切手（こぎって）**
- **読み方**: こぎって
- **意味**: 銀行に対する支払委託証券
- **関連用語**: 当座預金、他人振出小切手

**小口現金（こぐちげんきん）**
- **読み方**: こぐちげんきん
- **意味**: 日常的な少額支払い用に用意する現金
- **関連用語**: 定額資金前渡制度、インプレスト・システム

### さ行
**雑収入（ざつしゅうにゅう）**
- **読み方**: ざつしゅうにゅう
- **意味**: 主たる営業活動以外から生じる少額の収入
- **関連用語**: 雑損失、現金過不足

**雑損失（ざつそんしつ）**
- **読み方**: ざつそんしつ
- **意味**: 主たる営業活動以外から生じる少額の損失
- **関連用語**: 雑収入、現金過不足

### た行
**他人振出小切手（たにんふりだしこぎって）**
- **読み方**: たにんふりだしこぎって
- **意味**: 他社が振り出した小切手で、受取側では現金として扱う
- **関連用語**: 現金、通貨代用証券

**定額資金前渡制度（ていがくしきんまえわたしせいど）**
- **読み方**: ていがくしきんまえわたしせいど
- **意味**: 小口現金を一定額に保つ管理方法
- **関連用語**: 小口現金、インプレスト・システム

**定期積金（ていきつみきん）**
