# 減損処理の意義について

## 概要

減損処理とは、固定資産の収益性が低下して投資額の回収が見込めなくなった際に、その資産の帳簿価額を回収可能価額まで減額する会計処理のことです。これは、財務諸表利用者に対して企業の実態を適正に表示し、投資判断に有用な情報を提供するという財務会計の基本的な目的を達成するために不可欠な処理です。

2000年代初頭に日本でも「固定資産の減損に係る会計基準」が導入され、上場企業等には減損処理の適用が義務付けられました。これにより、企業は保有する固定資産の価値を定期的に見直し、必要に応じて減損損失を計上することが求められています。

## 1. 減損処理の基本概念・定義

### 減損処理の定義
- **定義**: 資産の収益性の低下により投資額の回収が見込めなくなった状態において、一定の条件の下で回収可能性を反映させるように帳簿価額を減額する会計処理
- **特徴**: 一度計上した減損損失は、原則として戻し入れることができない（日本基準）
- **重要性**: 財務諸表の信頼性向上、投資家保護、経営者の投資責任の明確化

### 回収可能価額
- **定義**: 正味売却価額と使用価値のいずれか高い金額
- **特徴**: 資産または資産グループから得られる将来キャッシュ・フローを基礎として算定
- **重要性**: 減損損失の測定における基準値として機能

### 減損の兆候
- **定義**: 資産または資産グループに減損が生じている可能性を示す事象
- **特徴**: 営業損益の継続的なマイナス、市場価格の著しい下落、経営環境の著しい悪化など
- **重要性**: 減損処理のプロセスを開始するトリガーとなる

## 2. 減損処理の分類・種類

### 対象資産による分類

固定資産の減損処理は、対象となる資産の種類によって以下のように分類されます。

### 有形固定資産の減損
| 項目 | 内容 |
|------|------|
| 特徴 | 土地、建物、機械装置、車両運搬具などの物理的実体を持つ資産が対象 |
| 適用範囲 | 事業用資産、遊休資産、処分予定資産など |
| 注意点 | 土地については時価の回復可能性が低いため、特に慎重な判断が必要 |

### 無形固定資産の減損
| 項目 | 内容 |
|------|------|
| 特徴 | のれん、特許権、商標権、ソフトウェアなどの物理的実体を持たない資産が対象 |
| 適用範囲 | 自社利用ソフトウェア、市場販売目的ソフトウェア、のれんなど |
| 注意点 | のれんについては毎期減損の兆候の有無にかかわらず減損テストが必要（IFRS） |

### 投資その他の資産の減損
| 項目 | 内容 |
|------|------|
| 特徴 | 投資不動産、長期前払費用などが対象 |
| 適用範囲 | 賃貸等不動産、ゴルフ会員権など |
| 注意点 | 投資不動産については賃貸収入の推移に注意が必要 |

## 3. 具体的計算例・事例

### ケース1: 製造設備の減損処理

#### パターンA: 減損損失を認識する場合
- **前提条件**: 
  - 製造設備の帳簿価額：1,000万円
  - 割引前将来キャッシュ・フロー：800万円
  - 正味売却価額：300万円
  - 使用価値：600万円
- **計算過程**: 
  1. 減損の認識判定：帳簿価額1,000万円 > 割引前CF800万円 → 減損を認識
  2. 回収可能価額の算定：max(正味売却価額300万円, 使用価値600万円) = 600万円
  3. 減損損失の計算：1,000万円 - 600万円 = 400万円
- **結果**: 減損損失400万円を特別損失に計上

#### パターンB: 減損損失を認識しない場合
- **前提条件**: 
  - 製造設備の帳簿価額：1,000万円
  - 割引前将来キャッシュ・フロー：1,200万円
  - 正味売却価額：700万円
  - 使用価値：900万円
- **計算過程**: 
  1. 減損の認識判定：帳簿価額1,000万円 < 割引前CF1,200万円 → 減損を認識しない
- **結果**: 減損損失の計上なし

### ケース2: のれんの減損処理

#### IFRS基準での処理
- **前提条件**: 
  - のれんを含む資金生成単位の帳簿価額：5,000万円（うち、のれん2,000万円）
  - 資金生成単位の回収可能価額：4,000万円
- **計算過程**: 
  1. 減損損失の算定：5,000万円 - 4,000万円 = 1,000万円
  2. のれんへの配分：まず、のれんから減損（上限2,000万円）
- **結果**: のれんの減損損失1,000万円を計上

#### 日本基準での処理
- **前提条件**: 
  - のれんの帳簿価額：2,000万円
  - のれんの未償却残高に対応する営業利益：年間300万円
  - 残存償却年数：8年
- **計算過程**: 
  1. 減損の兆候判定：営業利益がプラスで推移 → 減損の兆候なし
- **結果**: 定額法により年間250万円（2,000万円÷8年）を償却

### ケース3: 賃貸用不動産の減損処理

- **前提条件**: 
  - 賃貸用建物の帳簿価額：8,000万円
  - 年間賃料収入：400万円（今後10年間継続見込み）
  - 10年後の正味売却価額：3,000万円
  - 割引率：5%
- **計算過程**: 
  1. 使用価値の計算：
     - 賃料収入の現在価値：400万円×年金現価係数(10年,5%)≒3,086万円
     - 売却価額の現在価値：3,000万円×現価係数(10年,5%)≒1,840万円
     - 使用価値：3,086万円 + 1,840万円 = 4,926万円
  2. 減損損失の計算：8,000万円 - 4,926万円 = 3,074万円
- **結果**: 減損損失3,074万円を計上

## 4. 減損処理の手続き・プロセス

### 減損処理の流れ
1. **ステップ1: 資産のグルーピング**
   - 詳細説明：他の資産または資産グループのキャッシュ・フローから概ね独立したキャッシュ・フローを生み出す最小の単位を識別
   - 必要書類：資産台帳、組織図、事業セグメント情報
   - 注意点：継続的に同一の単位でグルーピングを行う必要がある

2. **ステップ2: 減損の兆候の把握**
   - 詳細説明：営業損益の継続的なマイナス、市場価格の著しい下落などの兆候を把握
   - 必要書類：財務諸表、不動産鑑定評価書、市場調査レポート
   - 注意点：期末だけでなく、期中においても兆候の把握が必要

3. **ステップ3: 減損損失の認識の判定**
   - 詳細説明：割引前将来キャッシュ・フローと帳簿価額を比較
   - 必要書類：事業計画書、キャッシュ・フロー予測表
   - 注意点：楽観的すぎる将来予測は監査で指摘される可能性がある

4. **ステップ4: 減損損失の測定**
   - 詳細説明：回収可能価額まで帳簿価額を減額し、減損損失を算定
   - 必要書類：割引率算定資料、正味売却価額算定資料
   - 注意点：使用する割引率は理論的に説明可能なものを使用

5. **ステップ5: 減損損失の会計処理と開示**
   - 詳細説明：減損損失を特別損失として計上し、注記事項を開示
   - 必要書類：仕訳伝票、有価証券報告書の注記ドラフト
   - 注意点：重要な減損損失は適時開示の対象となる可能性がある

### 関連する制度・規則
- **根拠法令**: 企業会計基準第6号「固定資産の減損に係る会計基準」
- **所管官庁**: 金融庁（企業会計審議会）
- **関連制度**: 税効果会計、資産除去債務会計、賃貸等不動産の時価開示

## 5. 実務上の注意点

### 減損処理における重要ポイント
- **ポイント1**: 資産のグルーピングは経営管理上の区分との整合性を保つ
- **ポイント2**: 将来キャッシュ・フローの見積りは合理的で説明可能な仮定に基づく
- **ポイント3**: 減損の兆候の把握は形式的ではなく実質的に判断する
- **ポイント4**: 共用資産やのれんの配分は合理的な基準により行う
- **ポイント5**: 減損処理後の減価償却は残存耐用年数にわたって規則的に行う

### よくある誤解・トラブル
- **誤解1**: 「時価が下がったら必ず減損」→ 正しくは「回収可能価額が帳簿価額を下回った場合」
- **誤解2**: 「減損損失は翌期に戻し入れ可能」→ 日本基準では減損損失の戻し入れは禁止
- **誤解3**: 「税務上も同額の損金算入が可能」→ 税務上は別途判定が必要で、会計上の減損がそのまま損金にはならない

## 6. よくある質問（Q&A）

### Q1. 減損の兆候として「営業損益の継続的なマイナス」とありますが、何期連続でマイナスなら該当しますか？

**A1.** 一般的には「過去2期連続で営業損益がマイナスであり、当期も明らかにマイナスとなる見込み」の場合に減損の兆候があると判断されます。

#### 詳細説明
実務上は以下のような判断基準が用いられています：
- 過去2期連続マイナス ＋ 当期見込みマイナス → 減損の兆候あり
- 過去1期のみマイナス → 原則として減損の兆候なし
- ただし、事業の特性（立ち上げ期の事業など）を考慮した実質的な判断が必要
- 営業損益の算定においては、本社費の配賦方法にも注意が必要

### Q2. のれんの減損処理について、日本基準とIFRSの違いを教えてください。

**A2.** 日本基準では規則的償却＋減損テスト、IFRSでは非償却＋年次減損テストという大きな違いがあります。

#### 詳細説明
主な相違点は以下のとおりです：

| 項目 | 日本基準 | IFRS |
|------|----------|------|
| 規則的償却 | 20年以内で償却 | 償却しない |
| 減損テスト | 兆候がある場合 | 毎年実施 |
| 減損の戻入 | 禁止 | 禁止（のれん以外は戻入可） |
| 測定単位 | より小さな単位も可 | 資金生成単位 |

### Q3. 減損処理を行った場合の税務上の取扱いはどうなりますか？

**A3.** 会計上の減損損失がそのまま税務上の損金になるわけではなく、税務上は別途「評価損の損金算入要件」を満たす必要があります。

#### 詳細説明
税務上の取扱いのポイント：
- 会計上の減損損失 ≠ 税務上の損金
- 法人税法上の評価損の要件（災害による著しい損傷、1年以上の遊休など）を満たす場合のみ損金算入可
- 多くの場合、税効果会計により将来減算一時差異として処理
- 売却や除却時に税務上の損金として認識される

### Q4. 使用価値の算定における割引率はどのように決定すればよいですか？

**A4.** 割引率は、貨幣の時間価値と当該資産に固有のリスクを反映した税引前の利率を用いる必要があります。

#### 実務的な算定方法
1. **加重平均資本コスト（WACC）をベースとする方法**
   - 企業全体のWACCを出発点として資産固有のリスクを調整
   - 税引後WACCを税引前に換算する必要がある

2. **類似資産の市場利回りを参考にする方法**
   - 類似の資産や事業の取引事例から推定
   - 不動産であれば、類似物件の利回りを参考

3. **リスクフリーレート＋リスクプレミアムの方法**
   - 国債利回り等のリスクフリーレートに事業リスクを加算
   - リスクプレミアムの設定には十分な根拠が必要

## 7. まとめ・今後の展望

減損処理は、固定資産の実態を財務諸表に適切に反映させるための重要な会計処理です。その意義は、単に会計基準の要請に応えるだけでなく、企業の投資意思決定の適切性を事後的に検証し、経営の透明性を高めることにあります。

今後の展望として、以下の点が注目されます：
- **ESG投資の拡大**：環境規制の強化により、特定の資産の減損リスクが高まる可能性
- **デジタル化の進展**：技術革新により既存設備の陳腐化が加速し、減損の頻度が増加する可能性
- **国際的な基準の収斂**：日本基準とIFRSの差異が縮小していく方向での議論の進展
- **AIやビッグデータの活用**：将来キャッシュ・フローの予測精度向上による減損判定の高度化

企業には、減損処理を単なるコンプライアンス対応としてではなく、経営管理の一環として積極的に活用していくことが求められています。

## 8. 理解度確認クイズ（4択問題20問）

### 問題1
減損処理の定義として最も適切なものはどれか。

- A) 固定資産の時価が下落した場合に、帳簿価額を時価まで切り下げる処理
- B) 資産の収益性の低下により投資額の回収が見込めなくなった場合に、回収可能価額まで帳簿価額を減額する処理
- C) 固定資産が物理的に損傷した場合に、修繕費を計上する処理
- D) 固定資産の耐用年数を見直して、減価償却費を変更する処理

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
減損処理は、単に時価が下落しただけでなく、資産の収益性が低下して投資額の回収が見込めなくなった場合に行う処理です。Aは時価の下落のみに着目しており不正確、Cは物理的損傷に対する修繕の処理、Dは会計上の見積りの変更に関する処理であり、いずれも減損処理の定義とは異なります。
</details>

### 問題2
減損の兆候として該当しないものはどれか。

- A) 営業活動から生ずる損益が継続してマイナス
- B) 使用範囲または使用方法について回収可能価額を著しく低下させる変化
- C) 経営環境の著しい悪化
- D) 固定資産の取得原価の上昇

<details>
<summary>解答</summary>
<strong>正解: D</strong><br>
固定資産の取得原価の上昇は減損の兆候には該当しません。減損の兆候は、既に保有している資産の収益性の低下を示す事象であり、A、B、Cはいずれも「固定資産の減損に係る会計基準」に定められた減損の兆候の例示です。取得原価の上昇は将来の投資判断には影響しますが、既存資産の減損とは無関係です。
</details>

### 問題3
回収可能価額の定義として正しいものはどれか。

- A) 正味売却価額と使用価値のいずれか低い金額
- B) 正味売却価額と使用価値のいずれか高い金額
- C) 正味売却価額と取得原価のいずれか低い金額
- D) 使用価値と帳簿価額のいずれか高い金額

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
回収可能価額は、正味売却価額と使用価値のいずれか高い金額と定義されています。これは、資産を売却する場合と使用し続ける場合のどちらか有利な方を選択できるという経済合理性を反映したものです。Aのように低い方を選択すると、企業価値を過小評価することになります。
</details>

### 問題4
使用価値の算定において使用する割引率として適切なものはどれか。

- A) 税引後の市場利子率
- B) 税引前の利率で貨幣の時間価値と資産固有のリスクを反映したもの
- C) 過去の投資時点での期待収益率
- D) 無リスク利子率のみ

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
使用価値の算定に用いる割引率は、税引前の利率で、貨幣の時間価値と当該資産または資産グループに固有のリスクを反映したものでなければなりません。Aは税引後であり不適切、Cは過去の率であり将来キャッシュ・フローの割引には不適切、Dはリスクを反映していないため不十分です。
</details>

### 問題5
日本基準におけるのれんの会計処理として正しいものはどれか。

- A) 規則的な償却は行わず、減損の兆候がある場合のみ減損テストを実施
- B) 20年以内の期間で規則的に償却し、減損の兆候がある場合は減損テストを実施
- C) 5年以内の期間で規則的に償却し、毎期必ず減損テストを実施
- D) 規則的な償却は行わず、毎期必ず減損テストを実施

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
日本基準では、のれんは20年以内のその効果の及ぶ期間にわたって規則的に償却し、減損の兆候がある場合には減損テストを実施します。AとDはIFRSの処理に近く、Cは償却期間が短すぎます。この点は日本基準とIFRSの重要な相違点の一つです。
</details>

### 問題6
減損損失の認識の判定で用いる将来キャッシュ・フローの特徴として正しいものはどれか。

- A) 割引後の金額を使用する
- B) 割引前の金額を使用する
- C) 過去のキャッシュ・フローの平均値を使用する
- D) 最も保守的なシナリオでの金額を使用する

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
減損損失の認識の判定においては、割引前の将来キャッシュ・フローの総額を使用します。これは、認識の判定と測定を区別し、認識のハードルを適度に設定するためです。割引計算は、認識後の測定段階（使用価値の算定）で行います。
</details>

### 問題7
共用資産の減損処理における取扱いとして適切なものはどれか。

- B) 共用資産単独で減損テストを実施する

<summary>解答</summary>

</details>

### 問題15
