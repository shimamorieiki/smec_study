# 原価計算の種類について

## 概要
原価計算は、製品やサービスのコストを正確に把握し、経営の意思決定に役立てるための重要な管理会計手法です。本資料では、6つの主要な原価計算方式（個別原価計算、総合原価計算、実際原価計算、標準原価計算、全部原価計算、直接原価計算）について、その特徴と計算方法を詳しく解説します。

## 1. 基本概念・原価計算の分類体系

### 原価計算の目的
- **価格決定**: 製品の販売価格を決定するための基礎データ提供
- **原価管理**: コストの削減・効率化のための情報提供
- **経営意思決定**: 生産計画、投資判断などの意思決定支援
- **財務諸表作成**: 棚卸資産評価、売上原価の算定

### 原価計算の分類軸
原価計算は以下の3つの軸で分類されます：

1. **生産形態による分類**
   - 個別原価計算（受注生産）
   - 総合原価計算（大量生産）

2. **計算時期による分類**
   - 実際原価計算（事後計算）
   - 標準原価計算（事前計算）

3. **原価範囲による分類**
   - 全部原価計算（固定費含む）
   - 直接原価計算（変動費のみ）

## 2. 個別原価計算

### 定義と特徴
個別原価計算は、製造指図書ごとに原価を集計する方法で、主に受注生産企業で採用されます。

**特徴:**
- 製造指図書単位で原価を集計
- 直接費は各指図書に直課
- 間接費は配賦基準により配賦
- 仕掛品は指図書別に把握

### 計算手順
1. 製造指図書の発行
2. 直接材料費・直接労務費の賦課
3. 製造間接費の配賦
4. 完成品原価の算定

### 📊 計算例1: 基本的な個別原価計算

**設例1-1: A社の個別原価計算**
A社は3月に以下の3つの製造指図書を発行した。

**基礎データ:**
- 製造指図書No.101: 直接材料費 300,000円、直接労務費 200,000円
- 製造指図書No.102: 直接材料費 450,000円、直接労務費 300,000円
- 製造指図書No.103: 直接材料費 600,000円、直接労務費 400,000円
- 当月製造間接費: 900,000円
- 配賦基準: 直接労務費

**計算過程:**
```
Step1: 配賦率の計算
直接労務費合計 = 200,000 + 300,000 + 400,000 = 900,000円
製造間接費配賦率 = 900,000 ÷ 900,000 = 1.0（100%）

Step2: 各指図書への製造間接費配賦
No.101: 200,000 × 1.0 = 200,000円
No.102: 300,000 × 1.0 = 300,000円
No.103: 400,000 × 1.0 = 400,000円

Step3: 製品原価の算定
No.101: 300,000 + 200,000 + 200,000 = 700,000円
No.102: 450,000 + 300,000 + 300,000 = 1,050,000円
No.103: 600,000 + 400,000 + 400,000 = 1,400,000円
```

### 📊 計算例2: 仕掛品がある場合

**設例1-2: 月初仕掛品を考慮した計算**
B社の4月の状況は以下の通り。

**基礎データ:**
- 月初仕掛品（No.201）: 直接材料費 150,000円、直接労務費 100,000円、製造間接費 80,000円
- 当月投入（No.201）: 直接材料費 250,000円、直接労務費 200,000円
- 新規着手（No.202）: 直接材料費 500,000円、直接労務費 350,000円
- 当月製造間接費: 440,000円
- 配賦基準: 直接労務費

**計算過程:**
```
Step1: 配賦率の計算
当月直接労務費 = 200,000 + 350,000 = 550,000円
製造間接費配賦率 = 440,000 ÷ 550,000 = 0.8（80%）

Step2: 製造間接費の配賦
No.201（当月分）: 200,000 × 0.8 = 160,000円
No.202: 350,000 × 0.8 = 280,000円

Step3: 完成品原価（No.201のみ完成と仮定）
月初仕掛品: 150,000 + 100,000 + 80,000 = 330,000円
当月製造費: 250,000 + 200,000 + 160,000 = 610,000円
完成品原価: 330,000 + 610,000 = 940,000円

月末仕掛品（No.202）: 500,000 + 350,000 + 280,000 = 1,130,000円
```

### 📊 計算例3: 複数の配賦基準を使用する場合

**設例1-3: 部門別配賦率を使用する計算**
C社は切削部門と組立部門を持ち、部門別に異なる配賦基準を使用している。

**基礎データ:**
- 製造指図書No.301: 
  - 直接材料費 400,000円
  - 切削部門: 直接作業時間 50時間、機械運転時間 100時間
  - 組立部門: 直接作業時間 80時間
- 製造指図書No.302:
  - 直接材料費 600,000円
  - 切削部門: 直接作業時間 30時間、機械運転時間 150時間
  - 組立部門: 直接作業時間 120時間
- 切削部門製造間接費: 500,000円（配賦基準: 機械運転時間）
- 組立部門製造間接費: 400,000円（配賦基準: 直接作業時間）
- 直接労務費率: 2,000円/時間

**計算過程:**
```
Step1: 部門別配賦率の計算
切削部門配賦率 = 500,000 ÷ (100 + 150) = 2,000円/時間
組立部門配賦率 = 400,000 ÷ (80 + 120) = 2,000円/時間

Step2: 直接労務費の計算
No.301: (50 + 80) × 2,000 = 260,000円
No.302: (30 + 120) × 2,000 = 300,000円

Step3: 製造間接費の配賦
No.301:
  切削部門: 100 × 2,000 = 200,000円
  組立部門: 80 × 2,000 = 160,000円
  合計: 360,000円

No.302:
  切削部門: 150 × 2,000 = 300,000円
  組立部門: 120 × 2,000 = 240,000円
  合計: 540,000円

Step4: 製品原価の算定
No.301: 400,000 + 260,000 + 360,000 = 1,020,000円
No.302: 600,000 + 300,000 + 540,000 = 1,440,000円
```

### 📊 計算例4: 材料の追加投入がある場合

**設例1-4: 工程の途中で材料を追加投入する場合**
D社は製造指図書No.401について、以下の状況である。

**基礎データ:**
- 月初仕掛品（進捗度40%）:
  - 直接材料費 120,000円（始点投入分）
  - 加工費 80,000円
- 当月投入:
  - 直接材料費（始点投入）200,000円
  - 直接材料費（進捗度60%で投入）150,000円
  - 直接労務費 180,000円
  - 製造間接費 144,000円（直接労務費の80%）
- 月末仕掛品: 進捗度80%、数量100個
- 完成品: 数量200個

**計算過程:**
```
Step1: 完成品換算量の計算
始点投入材料:
  月初仕掛品 100個 × (1 - 0.4) = 60個
  当月着手完成 200個
  月末仕掛品 100個
  合計 360個

60%投入材料:
  完成品 200個
  月末仕掛品 100個（80% > 60%なので全量）
  合計 300個

加工費:
  月初仕掛品 100個 × (1 - 0.4) = 60個
  当月着手完成 200個
  月末仕掛品 100個 × 0.8 = 80個
  合計 340個

Step2: 単価の計算
始点投入材料: (120,000 + 200,000) ÷ 360 = 889円/個
60%投入材料: 150,000 ÷ 300 = 500円/個
加工費: (80,000 + 180,000 + 144,000) ÷ 340 = 1,188円/個

Step3: 完成品原価
(889 + 500 + 1,188) × 200個 = 515,400円

Step4: 月末仕掛品原価
始点投入材料: 889 × 100 = 88,900円
60%投入材料: 500 × 100 = 50,000円
加工費: 1,188 × 80 = 95,040円
合計: 233,940円
```

### 📊 計算例5: 作業屑が発生する場合

**設例1-5: 作業屑の評価を含む個別原価計算**
E社の製造指図書No.501の状況は以下の通り。

```
50kg × 200円 = 10,000円

```

## 3. 総合原価計算

### 定義と特徴
総合原価計算は、一定期間の製造費用を製品種類ごとに集計し、生産量で除して単位原価を算定する方法です。

**特徴:**
- 大量生産に適用
- 期間原価計算
- 仕掛品は完成品換算量で評価
- 単純総合原価計算、工程別総合原価計算、組別総合原価計算、等級別総合原価計算がある

### 📊 計算例6: 単純総合原価計算（先入先出法）

**設例2-1: 単一製品の総合原価計算**
F社は単一製品を大量生産している。5月の生産データは以下の通り。

**基礎データ:**
- 月初仕掛品: 200個（進捗度40%）
  - 直接材料費 160,000円
  - 加工費 64,000円
- 当月投入量: 1,000個
- 当月製造費用:
  - 直接材料費 800,000円
  - 加工費 736,000円
- 完成品: 1,000個
- 月末仕掛品: 200個（進捗度60%）
- 直接材料は始点投入

**計算過程:**
```
Step1: 完成品換算量（先入先出法）
直接材料費:
  月初仕掛品充当分 0個（始点投入済）
  当月投入充当分 1,000個
  月末仕掛品 200個
  合計 1,200個

加工費:
  月初仕掛品充当分 200 × (1 - 0.4) = 120個
  当月着手完成分 800個
  月末仕掛品 200 × 0.6 = 120個
  合計 1,040個

Step2: 当月投入分の単価
直接材料費: 800,000 ÷ 1,200 = 667円/個
加工費: 736,000 ÷ 1,040 = 708円/個

Step3: 完成品原価
月初仕掛品原価: 160,000 + 64,000 = 224,000円
月初仕掛品加工費: 708 × 120 = 84,960円
当月着手完成分: (667 + 708) × 800 = 1,100,000円
完成品原価合計: 224,000 + 84,960 + 1,100,000 = 1,408,960円

Step4: 月末仕掛品原価
直接材料費: 667 × 200 = 133,400円
加工費: 708 × 120 = 84,960円
合計: 218,360円
```

### 📊 計算例8: 工程別総合原価計算

**設例2-3: 2工程の総合原価計算**
H社は第1工程と第2工程で製品を製造している。

**基礎データ（第1工程）:**
- 月初仕掛品: なし
- 当月投入: 500個
- 当月製造費用: 1,000,000円
- 完成品（第2工程へ）: 400個
- 月末仕掛品: 100個（進捗度50%）

**基礎データ（第2工程）:**
- 月初仕掛品: 50個（進捗度40%）
  - 前工程費 125,000円
  - 加工費 40,000円
- 前工程からの振替: 400個
- 当月加工費: 720,000円
- 完成品: 350個
- 月末仕掛品: 100個（進捗度60%）

**計算過程:**
```
第1工程:
Step1: 完成品換算量
400 + (100 × 0.5) = 450個

Step2: 単価計算
1,000,000 ÷ 450 = 2,222円/個

Step3: 原価計算
完成品: 2,222 × 400 = 888,800円
月末仕掛品: 2,222 × 50 = 111,100円

第2工程（先入先出法）:
Step1: 前工程費単価
888,800 ÷ 400 = 2,222円/個

Step2: 加工費の完成品換算量
月初分 50 × (1 - 0.4) = 30個
当月着手完成 300個
月末仕掛品 100 × 0.6 = 60個
合計 390個

Step3: 加工費単価
720,000 ÷ 390 = 1,846円/個

Step4: 完成品原価
月初仕掛品分: 125,000 + 40,000 + (1,846 × 30) = 220,380円
当月着手完成分: (2,222 + 1,846) × 300 = 1,220,400円
合計: 1,440,780円

Step5: 月末仕掛品原価
前工程費: 2,222 × 100 = 222,200円
加工費: 1,846 × 60 = 110,760円
合計: 332,960円
```

### 📊 計算例9: 組別総合原価計算


## 4. 実際原価計算

### 定義と特徴
実際原価計算は、実際に発生した原価を集計して製品原価を算定する方法です。

**特徴:**
- 事後的に原価を計算
- 実際の消費量×実際価格
- 期間比較が困難
- 原価管理には不向き

### 📊 計算例13: 実際原価による製品原価計算

**設例3-1: 実際原価計算の基本**
M社の8月の実際原価データは以下の通り。

**基礎データ:**
- 生産量: 500個
- 直接材料費:
  - 材料A: 1,000kg × 850円/kg = 850,000円
  - 材料B: 500kg × 1,200円/kg = 600,000円
- 直接労務費:
  - 直接作業時間 2,500時間
  - 平均賃率 2,100円/時間
  - 直接労務費 5,250,000円
- 製造間接費実際発生額: 3,150,000円

**計算過程:**
```
Step1: 総製造原価
直接材料費: 850,000 + 600,000 = 1,450,000円
直接労務費: 5,250,000円
製造間接費: 3,150,000円
合計: 9,850,000円

Step2: 単位原価
9,850,000 ÷ 500 = 19,700円/個
```

### 📊 計算例14: 実際配賦率による計算

**設例3-2: 部門別実際配賦率の計算**

## 5. 標準原価計算

### 定義と特徴
標準原価計算は、科学的・統計的に設定された標準原価を用いて原価計算を行い、実際原価との差異を分析する方法です。

**特徴:**
- 事前に標準を設定
- 原価管理に有効
- 差異分析により改善点を把握
- 記帳の簡素化

### 📊 計算例16: 標準原価カードの作成

```
  切削作業: 1.5時間 × 2,000円/時間 = 3,000円

  小計: 7,000円
```

### 📊 計算例17: 直接材料費差異の分析

**設例4-2: 価格差異と数量差異の計算**
Q社の9月の実績は以下の通り。

**基礎データ:**
- 生産量: 1,000個
- 標準: 材料2kg/個 × 500円/kg = 1,000円/個
- 実際: 材料2,100kg購入、1,071,000円（510円/kg）

```

(実際価格 - 標準価格) × 実際購入量
= (510 - 500) × 2,100
= 21,000円（不利差異）

Step2: 数量差異（消費時点）
(実際数量 - 標準数量) × 標準価格
= (1,950 - 2,000) × 500
= △25,000円（有利差異）

Step3: 総差異
実際原価: 510 × 1,950 = 994,500円
標準原価: 500 × 2,000 = 1,000,000円
総差異: △5,500円（有利差異）

検証: 21,000 + (△25,000) = △4,000円
（在庫差異: 150kg × 10円 = 1,500円を考慮すると一致）
```

### 📊 計算例19: 製造間接費差異の3分法

**設例4-4: 予算差異、能率差異、操業度差異**

```
実際発生額: 2,950,000円
標準原価: 850 × 3,000 = 2,550,000円
```


## 6. 全部原価計算

### 定義と特徴
全部原価計算は、製造原価に変動費と固定費の両方を含めて製品原価を計算する方法です。

**特徴:**
- 固定製造間接費も製品原価に含める
- 財務会計の要請に適合
- 期間損益が生産量に影響される
- 在庫が固定費を吸収

```
(実際時間 - 標準時間) × 固定費率
固定費率 = 2,000,000 ÷ 1,000 = 2,000円/時間

(実際時間 - 基準操業度) × 固定費率
= (950 - 1,000) × 2,000
= △100,000円（不利）
```
