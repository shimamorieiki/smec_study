# 株主資本等変動計算書について

## 概要

株主資本等変動計算書は、事業年度における株主資本の各項目の変動事由を明瞭に表示する財務諸表の一つです。2006年の会社法施行により、従来の利益処分計算書に代わって導入された重要な計算書類で、企業の純資産の部の変動を包括的に示します。この計算書は、株主や投資家が企業の資本政策や利益配分方針を理解する上で不可欠な情報を提供します。

## 1. 基本概念・定義

### 株主資本等変動計算書とは

株主資本等変動計算書は、貸借対照表の純資産の部の一会計期間における変動額のうち、主として株主に帰属する部分である株主資本の各項目の変動事由を報告するために作成される財務諸表です。

### 主要な構成要素

#### 株主資本
- **定義**: 企業の純資産のうち、株主に帰属する部分
- **特徴**: 資本金、資本剰余金、利益剰余金、自己株式から構成
- **重要性**: 企業の財務的基盤を示す最も基本的な指標

#### 評価・換算差額等
- **定義**: その他有価証券評価差額金、繰延ヘッジ損益、土地再評価差額金など
- **特徴**: 包括利益概念に基づく純資産の構成要素
- **重要性**: 企業の保有資産の時価変動を反映

#### 新株予約権
- **定義**: 企業が発行した新株予約権の価値
- **特徴**: 将来の株式発行可能性を示す
- **重要性**: 潜在的な株式希薄化の指標

## 2. 株主資本の変動要因

### 資本金の変動要因

| 増加要因 | 減少要因 |
|---------|---------|
| 新株発行 | 減資 |
| 転換社債の転換 | 欠損填補のための減資 |
| 新株予約権の行使 | 組織再編による減少 |

### 資本剰余金の変動要因

| 項目 | 内容 |
|------|------|
| 資本準備金 | 株式払込剰余金、合併差益など |
| その他資本剰余金 | 自己株式処分差益、資本金・資本準備金減少差益など |
| 注意点 | 配当財源として使用可能（一定の制限あり） |

### 利益剰余金の変動要因

| 項目 | 内容 |
|------|------|
| 利益準備金 | 会社法により積立が義務付けられている準備金 |
| その他利益剰余金 | 任意積立金、繰越利益剰余金など |
| 主な変動要因 | 当期純利益の計上、配当金の支払い |

## 3. 具体的計算例・事例

### ケース1: 標準的な株主資本等変動計算書の作成

#### 前提条件
- 期首残高：資本金1,000万円、資本剰余金500万円、利益剰余金2,000万円
- 当期の取引：
  - 新株発行：300万円（資本金150万円、資本準備金150万円）
  - 当期純利益：800万円
  - 配当金支払：200万円
  - 自己株式取得：100万円

#### 計算過程

**1. 資本金の変動**
```
期首残高：1,000万円
新株発行：+150万円
期末残高：1,150万円
```

**2. 資本剰余金の変動**
```
期首残高：500万円
新株発行による資本準備金：+150万円
期末残高：650万円
```

**3. 利益剰余金の変動**
```
期首残高：2,000万円
当期純利益：+800万円
配当金：-200万円
期末残高：2,600万円
```

**4. 自己株式**
```
期首残高：0円
取得：-100万円
期末残高：-100万円
```

**5. 株主資本合計**
```
期末残高：1,150万円 + 650万円 + 2,600万円 - 100万円 = 4,300万円
```

### ケース2: 包括利益を含む変動計算

#### 前提条件
- 上記ケース1の条件に加えて
- その他有価証券評価差額金の変動：+50万円
- 繰延ヘッジ損益：-20万円

#### 包括利益の計算
```
当期純利益：800万円
その他の包括利益：
  その他有価証券評価差額金：+50万円
  繰延ヘッジ損益：-20万円
包括利益合計：800万円 + 50万円 - 20万円 = 830万円
```

### ケース3: 準備金の取崩しを伴う変動

#### 前提条件
- 資本準備金1,000万円を取崩して配当財源とする
- その他資本剰余金に振替後、500万円を配当

#### 計算過程
```
1. 資本準備金の取崩し
   資本準備金：1,000万円 → 0円
   その他資本剰余金：0円 → 1,000万円

2. 配当の実施
   その他資本剰余金：1,000万円 - 500万円 = 500万円
```

## 4. 作成手順・様式

### 株主資本等変動計算書の作成手順

1. **期首残高の確定**
   - 前期末の貸借対照表から各項目の残高を転記
   - 会計方針の変更がある場合は遡及適用
   - 誤謬の訂正がある場合は修正再表示

2. **当期変動額の集計**
   - 各取引を変動事由別に分類
   - 株主資本の各項目への影響を整理
   - 評価・換算差額等の変動を把握

3. **変動事由の記載**
   - 剰余金の配当
   - 当期純利益
   - 自己株式の取得・処分
   - 株主資本以外の項目の変動

4. **期末残高の算出**
   - 期首残高＋当期変動額＝期末残高
   - 貸借対照表の純資産の部と一致を確認

### 様式の種類

#### 縦型様式（標準様式）
- 各項目を縦に配置
- 変動事由を横に展開
- 日本で最も一般的な様式

#### 横型様式
- 各項目を横に配置
- 変動事由を縦に展開
- 項目数が多い場合に有効

## 5. 実務上の注意点

### 作成時の重要ポイント

- **ポイント1**: 貸借対照表との整合性確保
  - 期末残高は必ず貸借対照表の純資産の部と一致
  - 勘定科目の名称も統一する

- **ポイント2**: 変動事由の適切な区分
  - 株主との直接的な取引（配当、自己株式取得等）
  - 損益取引（当期純利益）
  - その他の包括利益

- **ポイント3**: 注記事項の充実
  - 重要な変動事由の詳細説明
  - 会計方針の変更の影響額
  - 誤謬の訂正の内容

### よくある誤解・トラブル

- **誤解1**: 資本剰余金は配当できない
  - 正しい理解：その他資本剰余金は一定の条件下で配当可能

- **誤解2**: 評価・換算差額等は株主資本に含まれる
  - 正しい理解：純資産には含まれるが、株主資本とは区別される

- **誤解3**: 当期純損失の場合は作成不要
  - 正しい理解：損失の場合も必ず作成が必要

## 6. よくある質問（Q&A）

### Q1. 株主資本等変動計算書と損益計算書の関係は？

**A1.** 損益計算書で計算された当期純利益（純損失）が、株主資本等変動計算書の利益剰余金の変動要因として反映されます。

#### 詳細説明
損益計算書は一会計期間の経営成績を示し、その最終的な成果である当期純利益が株主資本等変動計算書に引き継がれます。これにより、フロー（損益）とストック（純資産）の関係が明確になります。

### Q2. 包括利益と当期純利益の違いは？

**A2.** 当期純利益は損益計算書で認識される利益ですが、包括利益はこれに「その他の包括利益」を加えた概念です。

#### 詳細説明
包括利益＝当期純利益＋その他の包括利益

その他の包括利益には以下が含まれます：
- その他有価証券評価差額金の変動
- 繰延ヘッジ損益の変動
- 為替換算調整勘定の変動
- 退職給付に係る調整額

### Q3. 自己株式の取得・処分はどう表示する？

**A3.** 自己株式の取得は株主資本の控除項目として表示し、処分時は処分差額をその他資本剰余金で処理します。

#### 詳細説明
- 取得時：自己株式（控除項目）として取得価額で計上
- 処分時：
  - 処分価額＞帳簿価額：差額はその他資本剰余金に計上
  - 処分価額＜帳簿価額：差額はその他資本剰余金から減額（不足時は利益剰余金から減額）

## 7. まとめ・今後の展望

株主資本等変動計算書は、企業の資本政策や財務戦略を理解する上で不可欠な財務諸表です。国際的な会計基準のコンバージェンスが進む中、包括利益概念の重要性が高まっており、今後はより詳細な開示が求められる傾向にあります。また、統合報告書の普及に伴い、財務情報と非財務情報を結びつける役割も期待されています。

- B) 繰延ヘッジ損益

### 問題14

<summary>解答</summary>
<strong>正解: B</strong><br>
自己株式を取得価額より低い価額で処分した場合、差額20万円はその他資本剰余金から減額します。<br>
処理：自己株式100万円の減少、現金80万円の増加、その他資本剰余金20万円の減少
</details>

### 問題16
連結株主資本等変動計算書に特有の項目はどれか？

- A) 非支配株主持分
- B) 資本金
- C) 利益剰余金
- D) 自己株式

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
非支配株主持分は連結財務諸表特有の項目で、子会社の純資産のうち親会社に帰属しない部分を表します。<br>
B、C、Dは個別財務諸表でも存在する項目です。
</details>

### 問題17
配当可能限度額がマイナスになった場合の対応として適切なものは？

- A) 配当を実施できない
- B) 資本金から配当する
- C) 借入により配当原資を確保する
- D) 将来の利益を見込んで配当する

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
配当可能限度額がマイナスの場合、会社法により配当を実施することはできません。<br>
Bは誤り：資本金は配当財源にできない<br>
Cは誤り：借入金は配当財源にならない<br>
Dは誤り：実際の配当可能額に基づく必要がある
</details>

### 問題18
会計方針の変更があった場合の株主資本等変動計算書での表示方法は？

- A) 前期末残高を遡及修正する
- B) 当期の変動額として表示する
- C) 注記のみで対応する
- D) 表示の必要はない

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
会計方針の変更による累積的影響額は、前期末残高を遡及修正して表示します。これにより比較可能性が確保されます。<br>
B、C、Dはいずれも適切な処理ではありません。
</details>

### 問題19
株主資本等変動計算書の作成頻度について正しいものは？

- A) 四半期ごとに作成が必要
- B) 半期ごとに作成が必要
- C) 年度ごとに作成が必要
- D) 3年ごとに作成が必要

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
株主資本等変動計算書は年度財務諸表の一部として、事業年度ごとに作成が必要です。<br>
Aは誤り：四半期財務諸表では原則不要<br>
Bは誤り：中間財務諸表でも原則不要<br>
Dは誤り：毎年度の作成が必要
</details>

### 問題20
D社の包括利益計算：当期純利益500万円、その他有価証券評価差額金の増加100万円、繰延ヘッジ損益の減少30万円、配当金支払200万円。包括利益の額は？

- A) 370万円
- B) 570万円
- C) 770万円
- D) 800万円

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
包括利益の計算：<br>
当期純利益：500万円<br>
その他有価証券評価差額金：+100万円<br>
繰延ヘッジ損益：-30万円<br>
包括利益：500万円＋100万円－30万円＝570万円<br>
（注）配当金は株主との直接取引のため包括利益には含まれません
</details>

## 9. 専門用語集

### あ行

**委員会設置会社（いいんかいせっちかいしゃ）**
- **読み方**: いいんかいせっちかいしゃ
- **意味**: 指名委員会、報酬委員会、監査委員会を設置し、執行と監督を分離した会社形態
- **関連用語**: 監査役会設置会社、監査等委員会設置会社

**一株当たり純資産（いっかぶあたりじゅんしさん）**
- **読み方**: いっかぶあたりじゅんしさん
- **意味**: 純資産額を発行済株式数（自己株式を除く）で除した指標
- **関連用語**: 一株当たり当期純利益、株価純資産倍率（PBR）

### か行

**株主資本（かぶぬししほん）**
- **読み方**: かぶぬししほん
- **意味**: 純資産のうち株主に帰属する部分で、資本金、資本剰余金、利益剰余金、自己株式から構成
- **関連用語**: 純資産、自己資本

**株主資本等変動計算書（かぶぬししほんとうへんどうけいさんしょ）**
- **読み方**: かぶぬししほんとうへんどうけいさんしょ
- **意味**: 純資産の部の一会計期間における変動額を表示する財務諸表
- **関連用語**: 貸借対照表、損益計算書

**会社法（かいしゃほう）**
- **読み方**: かいしゃほう
- **意味**: 2006年施行の会社の設立、組織、運営、管理について定めた法律
- **関連用語**: 商法、金融商品取引法

**株式分割（かぶしきぶんかつ）**
- **読み方**: かぶしきぶんかつ
- **意味**: 1株を複数株に分割することで、株式の流動性向上を図る行為
- **関連用語**: 株式併合、無償割当

### さ行

**資本金（しほんきん）**
- **読み方**: しほんきん
- **意味**: 株主が会社に払い込んだ金額のうち、資本金として計上された額
- **関連用語**: 資本準備金、払込資本金

**資本剰余金（しほんじょうよきん）**
- **読み方**: しほんじょうよきん
- **意味**: 資本取引から生じた剰余金で、資本準備金とその他資本剰余金から構成
- **関連用語**: 利益剰余金、資本準備金

**資本準備金（しほんじゅんびきん）**
- **読み方**: しほんじゅんびきん
- **意味**: 株式払込剰余金など、会社法で積立が定められた準備金
- **関連用語**: 利益準備金、その他資本剰余金

**自己株式（じこかぶしき）**
- **読み方**: じこかぶしき
- **意味**: 会社が自己の発行した株式を取得し保有しているもの
- **関連用語**: 金庫株、自己株式の消却

**純資産（じゅんしさん）**
- **読み方**: じゅんしさん
- **意味**: 資産から負債を控除した額で、株主資本と評価・換算差額等、新株予約権から構成
- **関連用語**: 総資産、株主資本

**剰余金の配当（じょうよきんのはいとう）**
- **読み方**: じょうよきんのはいとう
- **意味**: 会社が株主に対して剰余金を分配する行為
- **関連用語**: 配当金、配当可能限度額

### た行

**当期純利益（とうきじゅんりえき）**
- **読み方**: とうきじゅんりえき
- **意味**: 一会計期間の最終的な利益で、税引後の利益
- **関連用語**: 営業利益、経常利益、包括利益

### は行

**配当可能限度額（はいとうかのうげんどがく）**
- **読み方**: はいとうかのうげんどがく
- **意味**: 会社法により定められた配当として分配可能な剰余金の限度額
- **関連用語**: 分配可能額、剰余金の配当

**評価・換算差額等（ひょうか・かんさんさがくとう）**
- **読み方**: ひょうか・かんさんさがくとう
- **意味**: その他有価証券評価差額金など、資産負債の評価差額を純資産に直接計上したもの
- **関連用語**: 包括利益、その他の包括利益

**包括利益（ほうかつりえき）**
- **読み方**: ほうかつりえき
- **意味**: 当期純利益にその他の包括利益を加えた概念
- **関連用語**: 当期純利益、その他の包括利益

### ま行

**無償割当（むしょうわりあて）**
- **読み方**: むしょうわりあて
- **意味**: 株主に対価なしで新株を割り当てる行為
- **関連用語**: 株式分割、有償増資

### ら行

**利益剰余金（りえきじょうよきん）**
- **読み方**: りえきじょうよきん
- **意味**: 過去の利益の蓄積額で、利益準備金とその他利益剰余金から構成
- **関連用語**: 資本剰余金、繰越利益剰余金

**利益準備金（りえきじゅんびきん）**
- **読み方**: りえきじゅんびきん
- **意味**: 配当時に会社法により積立が義務付けられている準備金
- **関連用語**: 資本準備金、法定準備金

**連結株主資本等変動計算書（れんけつかぶぬししほんとうへんどうけいさんしょ）**
- **読み方**: れんけつかぶぬししほんとうへんどうけいさんしょ
- **意味**: 連結ベースでの純資産の変動を表示する計算書
- **関連用語**: 個別株主資本等変動計算書、非支配株主持分

### アルファベット

**IFRS（International Financial Reporting Standards）**
- **読み方**: アイエフアールエス
- **意味**: 国際財務報告基準。国際的な会計基準
- **関連用語**: 日本基準、US-GAAP

**PBR（Price Book-value Ratio）**
- **読み方**: ピービーアール
- **意味**: 株価純資産倍率。株価を一株当たり純資産で除した指標
- **関連用語**: PER、ROE
