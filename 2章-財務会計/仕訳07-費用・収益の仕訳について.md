# 費用・収益の仕訳について

## 費用・収益の概要

費用と収益は企業の経営成績を表す重要な要素であり、損益計算書の構成要素となります。費用は企業が収益を獲得するために消費した経済的価値、収益は企業の経済活動により獲得した経済的価値を表します。適正な期間損益計算のためには、発生主義に基づく費用・収益の認識と、費用収益対応の原則に基づく計上が重要です。また、前払費用・前受収益、未払費用・未収収益などの経過勘定の理解も不可欠です。

## 1. 費用・収益の基本概念

### 費用の分類
- **売上原価**: 商品の仕入原価、製造原価
- **販売費及び一般管理費**: 給料、広告宣伝費、減価償却費等
- **営業外費用**: 支払利息、手形売却損等
- **特別損失**: 固定資産売却損、災害損失等

### 収益の分類
- **売上高**: 主たる営業活動による収益
- **営業外収益**: 受取利息、受取配当金、雑収入等
- **特別利益**: 固定資産売却益、保険差益等

### 費用収益の認識基準
| 原則 | 内容 |
|------|------|
| 発生主義 | 現金の収支に関係なく発生時点で認識 |
| 実現主義 | 収益は実現した時点で認識 |
| 費用収益対応の原則 | 収益とそれを得るための費用を対応させる |
| 保守主義 | 費用は早めに、収益は遅めに認識 |

## 2. 主要な費用・収益項目

### 人件費関連
| 項目 | 内容 |
|------|------|
| 給料手当 | 従業員への給与 |
| 賞与 | ボーナス |
| 法定福利費 | 社会保険料の会社負担分 |
| 福利厚生費 | その他の従業員福利 |

### 経費関連
| 項目 | 内容 |
|------|------|
| 水道光熱費 | 電気、ガス、水道料金 |
| 通信費 | 電話、インターネット料金 |
| 消耗品費 | 事務用品等の消耗品 |
| 旅費交通費 | 出張旅費、交通費 |

### 金融関連
- **支払利息**: 借入金等の利息
- **受取利息**: 預金、貸付金等の利息
- **受取配当金**: 株式の配当金
- **有価証券評価損益**: 時価評価による損益

## 3. 具体的計算例・事例

### ケース1: 給料・賞与の支払い

#### パターンA: 給料1,000,000円から源泉所得税80,000円、社会保険料120,000円を控除して支払った
- **前提条件**: 給与支払時の各種控除
- **仕訳**:
  ```
  (借) 給料手当 1,000,000 / (貸) 現金 800,000
                          / (貸) 預り金（源泉税） 80,000
                          / (貸) 預り金（社保） 120,000
  ```
- **結果**: 費用は総額計上、控除額は預り金

#### パターンB: 賞与500,000円を支給し、社会保険料（会社負担分）75,000円を計上
- **前提条件**: 会社負担の社会保険料
- **仕訳**:
  ```
  (借) 賞与 500,000 / (貸) 現金 425,000
  (借) 法定福利費 75,000 / (貸) 預り金 75,000
                          / (貸) 未払金 75,000
  ```
- **結果**: 会社負担分は法定福利費として計上

### ケース2: 広告宣伝費・販売促進費

#### パターンA: 新聞広告料300,000円を掛けで依頼した
- **前提条件**: 広告の掲載と費用計上
- **仕訳**:
  ```
  (借) 広告宣伝費 300,000 / (貸) 未払金 300,000
  ```
- **結果**: 広告掲載時点で費用認識

#### パターンB: 販売促進のため商品券50,000円分を配布した
- **前提条件**: 販促用商品券の配布
- **仕訳**:
  ```
  (借) 販売促進費 50,000 / (貸) 他店商品券 50,000
  ```
- **結果**: 配布時点で費用計上

### ケース3: 保険料の処理

#### パターンA: 1年分の火災保険料120,000円を現金で支払った（4月1日支払、3月決算）
- **前提条件**: 前払費用の発生
- **仕訳**:
  ```
  支払時：(借) 保険料 120,000 / (貸) 現金 120,000
  決算時：(借) 前払費用 30,000 / (貸) 保険料 30,000
  ```
- **結果**: 翌期分3か月分を前払費用に振替

#### パターンB: 前期に前払費用に計上した保険料40,000円の振替
- **前提条件**: 期首の再振替
- **仕訳**:
  ```
  (借) 保険料 40,000 / (貸) 前払費用 40,000
  ```
- **結果**: 当期の費用として認識

### ケース4: 家賃・リース料

#### パターンA: 事務所家賃200,000円を翌月分として前払いした
- **前提条件**: 翌月分の前払い
- **仕訳**:
  ```
  (借) 前払費用 200,000 / (貸) 現金 200,000
  ```
- **結果**: 翌月分は前払費用として処理

#### パターンB: コピー機リース料月額30,000円の3か月分を後払い
- **前提条件**: 未払費用の計上
- **仕訳**:
  ```
  (借) リース料 90,000 / (貸) 未払費用 90,000
  ```
- **結果**: 発生主義により費用計上

### ケース5: 支払利息・受取利息

#### パターンA: 借入金5,000,000円に対する利息75,000円を支払った（年利3%、6か月分）
- **前提条件**: 借入金利息の支払い
- **仕訳**:
  ```
  (借) 支払利息 75,000 / (貸) 現金 75,000
  ```
- **計算**: 5,000,000円 × 3% × 6/12 = 75,000円

#### パターンB: 貸付金2,000,000円に対する利息20,000円を受け取った（年利2%、6か月分）
- **前提条件**: 貸付金利息の受取
- **仕訳**:
  ```
  (借) 現金 20,000 / (貸) 受取利息 20,000
  ```
- **計算**: 2,000,000円 × 2% × 6/12 = 20,000円

### ケース6: 租税公課

#### パターンA: 固定資産税400,000円の納税通知を受け、現金で納付した
- **前提条件**: 固定資産税の納付
- **仕訳**:
  ```
  (借) 租税公課 400,000 / (貸) 現金 400,000
  ```
- **結果**: 費用として処理

#### パターンB: 法人税、住民税及び事業税800,000円を計上した
- **前提条件**: 決算時の税金計上
- **仕訳**:
  ```
  (借) 法人税、住民税及び事業税 800,000 / (貸) 未払法人税等 800,000
  ```
- **結果**: 未払計上

### ケース7: 経過勘定項目

#### パターンA: 12月分の給料600,000円を翌年1月に支払う（12月決算）
- **前提条件**: 未払費用の計上
- **仕訳**:
  ```
  決算時：(借) 給料手当 600,000 / (貸) 未払費用 600,000
  支払時：(借) 未払費用 600,000 / (貸) 現金 600,000
  ```

#### パターンB: 3月分の家賃収入150,000円を2月に前受けした（3月決算）
- **前提条件**: 前受収益の処理
- **仕訳**:
  ```
  受取時：(借) 現金 150,000 / (貸) 前受収益 150,000
  期末時：(借) 前受収益 150,000 / (貸) 受取家賃 150,000
  ```

## 4. 特殊な費用・収益

### 貸倒引当金繰入
1. **差額補充法**
   ```
   必要額 - 期首残高 = 繰入額
   ```

2. **洗替法**
   ```
   期首：戻入処理
   期末：必要額を繰入
   ```

### 退職給付費用
- **退職一時金**: 支払時に費用処理
- **退職給付引当金**: 期末に引当金計上
- **確定拠出年金**: 拠出時に費用処理

### 減損損失
- **認識**: 収益性の低下により回収可能価額まで減額
- **測定**: 帳簿価額と回収可能価額の差額
- **表示**: 特別損失として計上

## 5. 実務上の注意点

### 費用・収益計上の重要ポイント
- **ポイント1**: 発生主義の原則を遵守（現金主義は不可）
- **ポイント2**: 費用収益対応の原則により適切に対応させる
- **ポイント3**: 継続性の原則により処理方法を統一する
- **ポイント4**: 重要性の原則により金額的重要性を判断
- **ポイント5**: 証憑書類に基づいて適切に計上する

### よくある誤解・トラブル
- **誤解1**: 現金支出時にすべて費用計上してしまう
  - 正しい理解: 発生主義により期間対応させる
- **誤解2**: 前払費用と前払金を混同する
  - 正しい理解: 前払費用は時の経過により費用化、前払金は物の引渡しで費用化
- **誤解3**: 交際費と会議費の区分が曖昧
  - 正しい理解: 1人5,000円以下の飲食は会議費として処理可能

## 6. よくある質問（Q&A）

### Q1. 発生主義と現金主義の違いは何ですか？

**A1.** 発生主義は取引の発生時点、現金主義は現金の収支時点で認識します。

#### 詳細説明
**発生主義**：
- 費用・収益の発生の事実に基づいて計上
- 期間損益を正確に把握可能
- 企業会計の大原則

**現金主義**：
- 現金の収入・支出時点で計上
- 簡便だが期間損益が歪む
- 個人事業者の所得計算で一部採用

例：12月分給料を1月支払い
- 発生主義：12月に費用計上
- 現金主義：1月に費用計上

### Q2. 前払費用と前払金の違いは？

**A2.** 前払費用は継続的な役務提供、前払金は物品等の引渡しに関する前払いです。

#### 詳細説明
**前払費用**：
- 時の経過により費用となるもの
- 例：保険料、家賃、利息
- 決算時に翌期分を資産計上

**前払金**：
- 商品等の引渡しにより費用となるもの
- 例：商品の手付金、工事の前渡金
- 引渡し時に費用振替

会計処理の時期と方法が異なるため、正確な区分が必要です。

### Q3. 未払費用と未払金の違いは？

**A3.** 未払費用は継続的な役務の対価、未払金は確定債務です。

#### 詳細説明
**未払費用**：
- 継続的な契約による役務提供の対価
- 例：給料、家賃、利息の未払分
- 時の経過により確定

**未払金**：
- 確定している債務の未払い
- 例：備品購入代金、広告費の未払い
- 既に債務額が確定

決算整理では、未払費用の計上漏れがないよう注意が必要です。

## 7. まとめ・今後の展望

費用・収益の適正な計上は、企業の経営成績を正確に表示するために不可欠です。今後は、収益認識基準の国際的な統一化、サブスクリプションモデルなど新しいビジネスモデルへの対応、ESG関連費用の開示要求など、より複雑で多様な会計処理が求められます。また、AI・自動化の進展により、定型的な処理は自動化され、判断を要する処理により注力することになるでしょう。
