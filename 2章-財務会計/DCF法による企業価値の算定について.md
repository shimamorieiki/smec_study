# DCF法による企業価値の算定について

## 概要

DCF法（Discounted Cash Flow法、割引現在価値法）は、企業が将来生み出すキャッシュフローを現在価値に割り引いて企業価値を算定する手法です。理論的に最も優れた企業価値評価手法の一つとされ、M&Aや投資判断、事業評価など幅広い場面で活用されています。「企業の価値は、その企業が将来生み出すキャッシュフローの現在価値の総和である」という考え方に基づいています。

## 1. 基本概念・定義

DCF法は、将来のフリーキャッシュフロー（FCF）を適切な割引率で現在価値に割り引き、それらを合計することで企業価値を算定する手法です。

### フリーキャッシュフロー（FCF）
- **定義**: 企業が事業活動から生み出した現金のうち、必要な投資を行った後に自由に使える現金
- **特徴**: 会計上の利益とは異なり、実際の現金の流れを表す
- **重要性**: 企業の真の収益力を示す指標として投資判断に不可欠

### 現在価値（Present Value）
- **定義**: 将来受け取る金額を現在の価値に換算した金額
- **特徴**: 時間価値を考慮（今日の1円は明日の1円より価値が高い）
- **重要性**: 異なる時点のキャッシュフローを比較可能にする

### 割引率（Discount Rate）
- **定義**: 将来のキャッシュフローを現在価値に割り引く際に使用する率
- **特徴**: 通常はWACC（加重平均資本コスト）を使用
- **重要性**: 企業のリスクを反映し、投資の要求収益率を表す

## 2. DCF法の種類・アプローチ

### 評価アプローチによる分類
DCF法には主に2つのアプローチがあります。

### エンタープライズDCF法
| 項目 | 内容 |
|------|------|
| 特徴 | 企業全体の価値を算定後、有利子負債を控除して株式価値を算出 |
| 使用するFCF | 企業全体のFCF（FCFF: Free Cash Flow to Firm） |
| 割引率 | WACC（加重平均資本コスト） |
| 適用範囲 | M&A、事業評価で最も一般的 |
| 注意点 | 資本構成の変化を考慮する必要がある |

### エクイティDCF法
| 項目 | 内容 |
|------|------|
| 特徴 | 株主に帰属するキャッシュフローから直接株式価値を算定 |
| 使用するFCF | 株主へのFCF（FCFE: Free Cash Flow to Equity） |
| 割引率 | 株主資本コスト |
| 適用範囲 | 金融機関の評価、レバレッジが大きく変動する企業 |
| 注意点 | 負債の返済スケジュールを詳細に把握する必要がある |

## 3. 具体的計算例・事例

### ケース1: 製造業A社の企業価値評価

#### 前提条件の設定
- **評価対象**: 製造業A社
- **評価基準日**: 2024年3月31日
- **予測期間**: 5年間（2024年度～2028年度）
- **売上高成長率**: 年率5%
- **EBITDA率**: 15%
- **法人税率**: 30%
- **設備投資**: 減価償却費の120%
- **運転資本増加額**: 売上高増加額の10%
- **WACC**: 8%
- **永続成長率**: 2%

#### ステップ1: フリーキャッシュフローの予測
```
2024年度の計算例：
売上高: 1,000億円
EBITDA: 150億円（売上高×15%）
減価償却費: 50億円
EBIT: 100億円
税引後EBIT: 70億円（EBIT×(1-30%)）
設備投資: 60億円（減価償却費×120%）
運転資本増加: 5億円（売上高増加額50億円×10%）

FCF = 税引後EBIT + 減価償却費 - 設備投資 - 運転資本増加
    = 70億円 + 50億円 - 60億円 - 5億円
    = 55億円
```

| 年度 | 2024 | 2025 | 2026 | 2027 | 2028 |
|------|------|------|------|------|------|
| 売上高（億円） | 1,000 | 1,050 | 1,103 | 1,158 | 1,216 |
| FCF（億円） | 55 | 58 | 61 | 64 | 67 |

#### ステップ2: ターミナルバリューの算出
```
ターミナルバリュー = FCF2028 × (1 + 永続成長率) ÷ (WACC - 永続成長率)
                   = 67億円 × 1.02 ÷ (0.08 - 0.02)
                   = 68.34億円 ÷ 0.06
                   = 1,139億円
```

#### ステップ3: 現在価値への割引
```
各年度のFCFの現在価値：
PV(2024) = 55 ÷ (1.08)^1 = 50.9億円
PV(2025) = 58 ÷ (1.08)^2 = 49.7億円
PV(2026) = 61 ÷ (1.08)^3 = 48.4億円
PV(2027) = 64 ÷ (1.08)^4 = 47.1億円
PV(2028) = 67 ÷ (1.08)^5 = 45.6億円

ターミナルバリューの現在価値：
PV(TV) = 1,139 ÷ (1.08)^5 = 775.0億円
```

#### ステップ4: 企業価値・株式価値の算定
```
事業価値 = Σ FCFの現在価値 + ターミナルバリューの現在価値
        = 241.7億円 + 775.0億円
        = 1,016.7億円

企業価値 = 事業価値 + 非事業用資産
        = 1,016.7億円 + 50億円（現預金等）
        = 1,066.7億円

株式価値 = 企業価値 - 有利子負債
        = 1,066.7億円 - 300億円
        = 766.7億円
```

### ケース2: IT企業B社の高成長シナリオ評価

#### パターンA: 基本シナリオ
- **売上高成長率**: 1-3年目20%、4-5年目10%
- **EBITDA率**: 段階的に改善（10%→15%）
- **WACC**: 10%（高成長企業のため高めに設定）
- **永続成長率**: 3%

```
企業価値算定結果：
事業価値: 850億円
企業価値: 900億円
株式価値: 800億円（有利子負債100億円を控除）
```

#### パターンB: 楽観シナリオ
- **売上高成長率**: 1-3年目30%、4-5年目15%
- **EBITDA率**: 段階的に改善（10%→20%）
- **その他条件は同じ**

```
企業価値算定結果：
事業価値: 1,250億円
企業価値: 1,300億円
株式価値: 1,200億円
```

## 4. 計算プロセスの詳細

### WACC（加重平均資本コスト）の算出
1. **株主資本コストの算出**
   - CAPM（資本資産価格モデル）を使用
   - 株主資本コスト = リスクフリーレート + β × 市場リスクプレミアム
   - 例：1.0% + 1.2 × 6.0% = 8.2%

2. **負債コストの算出**
   - 社債利回りまたは借入金利を使用
   - 税効果を考慮：税引後負債コスト = 負債コスト × (1 - 法人税率)
   - 例：3.0% × (1 - 0.30) = 2.1%

3. **WACCの計算**
   ```
   WACC = E/(E+D) × 株主資本コスト + D/(E+D) × 税引後負債コスト
   
   E: 株式時価総額
   D: 有利子負債時価
   
   例：E=700億円、D=300億円の場合
   WACC = 700/1000 × 8.2% + 300/1000 × 2.1%
        = 5.74% + 0.63%
        = 6.37%
   ```

### フリーキャッシュフローの詳細計算
```
営業利益（EBIT）
- 法人税等（実効税率ベース）
= 税引後営業利益（NOPAT）
+ 減価償却費
- 設備投資額
- 運転資本増加額
= フリーキャッシュフロー（FCF）
```

## 5. 実務上の注意点

### DCF法適用時の重要ポイント
- **ポイント1**: 事業計画の妥当性検証（市場成長率、競合状況との整合性）
- **ポイント2**: 感度分析の実施（主要パラメータの変動による影響度測定）
- **ポイント3**: 複数シナリオの検討（基本・楽観・悲観シナリオ）
- **ポイント4**: 類似企業比較による検証（マルチプル法との併用）
- **ポイント5**: 継続価値の割合確認（全体の70%超は要注意）

### よくある誤解・トラブル
- **誤解1**: 「詳細な予測ほど正確」→ 長期予測の不確実性を過小評価
- **誤解2**: 「WACCは一定でよい」→ 資本構成の変化を無視
- **誤解3**: 「永続成長率は高いほうが保守的」→ 非現実的な仮定は逆効果

## 6. よくある質問（Q&A）

### Q1. なぜDCF法は他の評価方法より優れているとされるのですか？

**A1.** DCF法は企業の本源的価値を理論的に算定できる唯一の方法だからです。

#### 詳細説明
DCF法の優位性は以下の点にあります：
1. **将来キャッシュフローに基づく評価**: 過去の業績ではなく、将来の収益力を評価
2. **時間価値の考慮**: 異なる時点のキャッシュフローを適切に評価
3. **企業固有の状況を反映**: 各企業の事業計画やリスクを詳細に織り込める
4. **理論的根拠が明確**: ファイナンス理論に裏付けられた手法

ただし、マルチプル法などと併用することで、より多角的な評価が可能になります。

### Q2. 永続成長率はどのように設定すべきですか？

**A2.** 一般的にはGDP成長率を上限とし、業界の長期成長見通しを考慮して設定します。

#### 詳細説明
永続成長率の設定における考慮事項：
1. **理論的上限**: 長期的には経済全体の成長率を超えることは不可能
2. **実務的な目安**: 
   - 成熟企業：0～2%
   - 成長企業：2～3%
   - 新興国企業：3～4%
3. **インフレ率との関係**: 名目成長率にはインフレ率が含まれることに注意
4. **感度分析の実施**: ±0.5%の変動による企業価値への影響を必ず確認

## 7. まとめ・今後の展望

DCF法は理論的に優れた企業価値評価手法ですが、将来予測の不確実性という本質的な課題を抱えています。実務では、複数の評価手法を組み合わせ、感度分析やシナリオ分析を通じて評価の幅を把握することが重要です。今後は、AI・機械学習を活用した予測精度の向上や、ESG要素を織り込んだ評価手法の発展が期待されています。

### 問題1
DCF法における「フリーキャッシュフロー」の定義として最も適切なものはどれか？

- A) 営業活動によるキャッシュフロー
- B) 当期純利益に減価償却費を加えたもの
- C) 事業活動から生み出された現金から必要な投資を差し引いた余剰現金
- D) 配当金と自社株買いの合計額

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
フリーキャッシュフローは、事業活動から生み出された現金（営業CF）から、事業の維持・成長に必要な投資（投資CF）を差し引いた、自由に使える余剰現金を指します。<br>
<br>
Aが間違いの理由：営業CFだけでは投資支出が考慮されていない<br>
Bが間違いの理由：これはEBITDAの簡易的な計算方法で、FCFとは異なる<br>
Dが間違いの理由：これは株主還元額であり、FCFの使途の一部に過ぎない<br>
<br>
【補足】実務では、FCF = 税引後営業利益 + 減価償却費 - 設備投資 - 運転資本増加額で計算します。
</details>

### 問題2
エンタープライズDCF法とエクイティDCF法の違いとして正しいものはどれか？

- A) エンタープライズDCF法は上場企業のみに適用可能
- B) エクイティDCF法は株主資本コストを割引率として使用する
- C) エンタープライズDCF法は配当金のみを評価対象とする
- D) 両者に本質的な違いはなく、同じ結果になる

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
エクイティDCF法は株主に帰属するキャッシュフロー（FCFE）を株主資本コストで割り引くのに対し、エンタープライズDCF法は企業全体のキャッシュフロー（FCFF）をWACCで割り引きます。<br>
<br>
Aが間違いの理由：両手法とも上場・非上場を問わず適用可能<br>
Cが間違いの理由：配当割引モデル（DDM）の説明であり、DCF法とは異なる<br>
Dが間違いの理由：使用するキャッシュフローと割引率が異なるため、アプローチが異なる<br>
<br>
【補足】実務では、資本構成が安定している企業にはエンタープライズDCF法が一般的に使用されます。
</details>

### 問題3
WACC（加重平均資本コスト）が8%、永続成長率が3%の場合、5年目のFCFが100億円の企業のターミナルバリューはいくらか？

- A) 1,250億円
- B) 2,000億円
- C) 2,060億円
- D) 3,333億円

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
ターミナルバリュー = FCF × (1 + 永続成長率) ÷ (WACC - 永続成長率)<br>
= 100億円 × 1.03 ÷ (0.08 - 0.03)<br>
= 103億円 ÷ 0.05<br>
= 2,060億円<br>
<br>
Aが間違いの理由：成長率を考慮せずに計算（100÷0.08=1,250）<br>
Bが間違いの理由：計算式の分母を間違えている（100÷0.05=2,000）<br>
Dが間違いの理由：計算式の分母を間違えている（100÷0.03=3,333）<br>
<br>
【補足】ターミナルバリューは企業価値の大部分を占めることが多いため、永続成長率の設定は慎重に行う必要があります。
</details>

### 問題4
DCF法による企業価値評価において、株式価値を算出する正しい手順はどれか？

- A) 事業価値 - 非事業用資産 + 有利子負債 = 株式価値
- B) 事業価値 + 非事業用資産 - 有利子負債 = 株式価値
- C) 事業価値 + 有利子負債 - 非事業用資産 = 株式価値
- D) 事業価値のみが株式価値となる

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
株式価値は、DCF法で算出した事業価値に非事業用資産（余剰現金等）を加え、有利子負債を控除して算出します。これは企業価値から債権者に帰属する価値を差し引いて、株主に帰属する価値を求める計算です。<br>
<br>
Aが間違いの理由：非事業用資産を減算し、有利子負債を加算している点が逆<br>
Cが間違いの理由：有利子負債を加算している点が誤り<br>
Dが間違いの理由：非事業用資産と有利子負債の調整が考慮されていない<br>
<br>
【補足】実務では、非事業用資産には余剰現金、遊休不動産、持分法適用会社株式などが含まれます。
</details>

### 問題6
CAPMモデルにおいて、リスクフリーレートが1%、市場リスクプレミアムが6%、ベータが1.5の場合、株主資本コストはいくらか？

- A) 7.0%
- B) 8.5%
- C) 9.0%
- D) 10.0%

<details>
<summary>解答</summary>
<strong>正解: D</strong><br>
株主資本コスト = リスクフリーレート + ベータ × 市場リスクプレミアム<br>
= 1% + 1.5 × 6%<br>
= 1% + 9%<br>
= 10%<br>
<br>
Aが間違いの理由：ベータを考慮していない（1+6=7）<br>
Bが間違いの理由：計算を間違えている<br>

<br>
【補足】ベータは個別企業の株価変動と市場全体の変動の関係を示す指標で、1より大きいとハイリスク・ハイリターンを意味します。
</details>

### 問題7
DCF法の感度分析において、最も企業価値への影響が大きいパラメータは一般的にどれか？

- A) 初年度の売上高
- B) 法人税率
- C) 永続成長率
- D) 運転資本回転率

<details>
<summary>解答</summary>

永続成長率は、ターミナルバリューの計算に直接影響し、企業価値の60-80%を占めることが多いターミナルバリューを大きく左右するため、最も影響が大きいパラメータです。<br>

### 問題8
企業価値評価において「サンクコスト」の取り扱いとして正しいものはどれか？

- A) 将来キャッシュフローに含めて評価する
- B) 過去の投資額として企業価値に加算する
- C) DCF法の計算には含めない
- D) 減価償却費として毎期計上する

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
サンクコスト（埋没費用）は既に支出済みで回収不可能な費用であり、将来の意思決定には影響しないため、DCF法の計算には含めません。<br>
<br>
Aが間違いの理由：サンクコストは将来のキャッシュフローに影響しない<br>
Bが間違いの理由：過去の投資額は企業価値評価には無関係<br>
Dが間違いの理由：既に支出済みの費用を将来の費用として計上するのは誤り<br>
<br>
【補足】企業価値評価では「将来」のキャッシュフローのみが重要であり、過去の投資判断の是非は評価に影響しません。
</details>

### 問題9
株式時価総額700億円、有利子負債300億円、株主資本コスト10%、税引後負債コスト3%の企業のWACCはいくらか？

- A) 6.5%
- B) 7.9%
- C) 8.5%
- D) 9.1%

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
WACC = E/(E+D) × 株主資本コスト + D/(E+D) × 税引後負債コスト<br>
= 700/1000 × 10% + 300/1000 × 3%<br>
= 0.7 × 10% + 0.3 × 3%<br>
= 7% + 0.9%<br>
= 7.9%<br>
<br>
Aが間違いの理由：計算を間違えている<br>
Cが間違いの理由：単純平均を取っている（(10+3)/2=6.5ではない）<br>
Dが間違いの理由：ウェイトを逆にしている（0.3×10%+0.7×3%=5.1%）<br>
<br>
【補足】WACCは企業の資金調達コストを表し、これを上回る収益率の投資のみが企業価値を高めます。
</details>

### 問題10
マルチプル法と比較したDCF法の短所として最も適切なものはどれか？

- A) 理論的根拠が不明確である
- B) 将来予測に依存し主観的になりやすい

- D) 企業固有の事情を反映できない

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
DCF法は将来の事業計画に基づくため、予測の精度や前提条件の設定により結果が大きく変動し、評価者の主観が入りやすいという短所があります。<br>
<br>
Aが間違いの理由：DCF法は理論的根拠が最も明確な評価手法<br>
Cが間違いの理由：時間価値を考慮することがDCF法の特徴<br>
Dが間違いの理由：企業固有の事情を最も詳細に反映できるのがDCF法<br>

</details>

### 問題11
事業価値が1,000億円、余剰現金が50億円、有価証券が30億円、有利子負債が400億円の企業の株式価値はいくらか？

- A) 580億円
- B) 650億円
- C) 680億円
- D) 1,080億円

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
株式価値 = 事業価値 + 非事業用資産 - 有利子負債<br>
= 1,000億円 + (50億円 + 30億円) - 400億円<br>
= 1,000億円 + 80億円 - 400億円<br>
= 680億円<br>
<br>
Aが間違いの理由：非事業用資産を考慮していない（1,000-400=600ではない）<br>
Bが間違いの理由：有価証券を考慮していない（1,000+50-400=650）<br>
Dが間違いの理由：有利子負債を減算していない（1,000+80=1,080）<br>
<br>
【補足】余剰現金と有価証券は典型的な非事業用資産であり、事業価値に加算する必要があります。
</details>

### 問題12

- B) 運転資本が増加するとFCFは減少する
- C) 運転資本の増減はFCFに影響しない

運転資本（売掛金+在庫-買掛金）が増加すると、現金が運転資本に拘束されるため、フリーキャッシュフローは減少します。<br>
<br>
Aが間違いの理由：運転資本増加は現金の使用を意味し、FCFを減少させる<br>
Cが間違いの理由：運転資本の増減は直接FCFに影響する<br>
Dが間違いの理由：在庫の増加や買掛金の減少もFCFを減少させる<br>
<br>
【補足】成長企業では売上増加に伴い運転資本も増加するため、この影響を適切に織り込むことが重要です。
</details>

## 9. 専門用語集

このドキュメントで使用された専門用語について、アルファベット順・50音順で解説します。

### アルファベット

**CAPM（Capital Asset Pricing Model）**
- **読み方**: キャップエム、資本資産価格モデル
- **意味**: 株主資本コストを算定するためのモデル。リスクフリーレート、ベータ、市場リスクプレミアムから期待収益率を計算する
- **関連用語**: 株主資本コスト、ベータ、市場リスクプレミアム

**DCF（Discounted Cash Flow）**
- **読み方**: ディーシーエフ
- **意味**: 将来のキャッシュフローを現在価値に割り引いて企業価値を算定する手法
- **関連用語**: NPV、IRR、現在価値

**EBIT（Earnings Before Interest and Tax）**
- **読み方**: イービット
- **意味**: 金利・税引前利益。営業利益にほぼ等しい
- **関連用語**: EBITDA、営業利益、NOPAT

**EBITDA（Earnings Before Interest, Tax, Depreciation and Amortization）**
- **読み方**: イービットディーエー、イービターダ
- **意味**: 金利・税金・減価償却前利益。企業の収益力を示す指標
- **関連用語**: EBIT、営業キャッシュフロー

**EV（Enterprise Value）**
- **読み方**: イーブイ、エンタープライズバリュー
- **意味**: 企業価値。株式時価総額に純有利子負債を加えた値
- **関連用語**: 株式価値、時価総額、マルチプル

**FCF（Free Cash Flow）**
- **読み方**: エフシーエフ、フリーキャッシュフロー
- **意味**: 企業が自由に使える現金流量
- **関連用語**: FCFF、FCFE、営業キャッシュフロー

**FCFE（Free Cash Flow to Equity）**
- **読み方**: エフシーエフイー
- **意味**: 株主に帰属するフリーキャッシュフロー
- **関連用語**: FCF、FCFF、エクイティDCF法

**FCFF（Free Cash Flow to Firm）**
- **読み方**: エフシーエフエフ
- **意味**: 企業全体のフリーキャッシュフロー
- **関連用語**: FCF、FCFE、エンタープライズDCF法

**IRR（Internal Rate of Return）**
- **読み方**: アイアールアール
- **意味**: 内部収益率。投資の収益性を示す指標
- **関連用語**: NPV、DCF、投資判断

**NPV（Net Present Value）**
- **読み方**: エヌピーブイ
- **意味**: 正味現在価値。投資の価値を示す指標
- **関連用語**: DCF、IRR、現在価値

**NOPAT（Net Operating Profit After Tax）**
- **読み方**: ノーパット
- **意味**: 税引後営業利益
- **関連用語**: EBIT、実効税率、FCF

**PER（Price Earnings Ratio）**
- **読み方**: ピーイーアール、ピーイーレシオ
- **意味**: 株価収益率。株価を1株当たり純利益で除した値
- **関連用語**: マルチプル、EV/EBITDA、株式価値

**WACC（Weighted Average Cost of Capital）**
- **読み方**: ワック
- **意味**: 加重平均資本コスト。企業の資金調達コスト
- **関連用語**: 株主資本コスト、負債コスト、資本構成

### あ行

**永続価値（ターミナルバリュー）**
- **読み方**: えいぞくかち
- **意味**: 予測期間後の企業価値。永続成長モデルで算定
- **関連用語**: 永続成長率、継続価値、残存価値

**永続成長率**
- **読み方**: えいぞくせいちょうりつ
- **意味**: 企業が永続的に成長すると仮定する成長率
- **関連用語**: ターミナルバリュー、GDP成長率

**営業キャッシュフロー**
- **読み方**: えいぎょうきゃっしゅふろー
- **意味**: 営業活動から生み出される現金流量
- **関連用語**: FCF、運転資本、EBITDA

### か行

**加重平均資本コスト**
- **読み方**: かじゅうへいきんしほんこすと
- **意味**: WACCの日本語訳。企業の平均的な資金調達コスト
- **関連用語**: WACC、資本構成、割引率

**株主資本コスト**
- **読み方**: かぶぬししほんこすと
- **意味**: 株主が要求する期待収益率
- **関連用語**: CAPM、ベータ、リスクプレミアム

**感度分析**
- **読み方**: かんどぶんせき
- **意味**: パラメータの変化が結果に与える影響を分析する手法
- **関連用語**: シナリオ分析、モンテカルロシミュレーション

**企業価値**
- **読み方**: きぎょうかち
- **意味**: 事業価値に非事業用資産を加えた企業全体の価値
- **関連用語**: EV、事業価値、株式価値

**現在価値**
- **読み方**: げんざいかち
- **意味**: 将来の金額を現在時点の価値に換算した値
- **関連用語**: 割引率、時間価値、将来価値

### さ行

**サンクコスト**
- **読み方**: さんくこすと
- **意味**: 埋没費用。既に支出し回収不可能な費用
- **関連用語**: 機会費用、意思決定

**事業価値**
- **読み方**: じぎょうかち
- **意味**: 事業活動から生み出される価値。FCFの現在価値の合計
- **関連用語**: 企業価値、非事業用資産

**市場リスクプレミアム**
- **読み方**: しじょうりすくぷれみあむ
- **意味**: 市場全体の期待収益率とリスクフリーレートの差
- **関連用語**: CAPM、エクイティプレミアム

**純有利子負債**
- **読み方**: じゅんゆうりしふさい
- **意味**: 有利子負債から現預金を控除した実質的な負債
- **関連用語**: ネットデット、有利子負債、現預金

### た行

**ターミナルバリュー**
- **読み方**: たーみなるばりゅー
- **意味**: 予測期間終了後の事業価値。永続価値とも呼ぶ
- **関連用語**: 永続価値、継続価値、永続成長率

### な行

**ネットデット**
- **読み方**: ねっとでっと
- **意味**: 純有利子負債の英語表記
- **関連用語**: 純有利子負債、グロスデット

### は行

**非事業用資産**
- **読み方**: ひじぎょうようしさん
- **意味**: 事業活動に直接使用されない資産（余剰現金、遊休不動産等）
- **関連用語**: 事業用資産、企業価値

**ベータ**
- **読み方**: べーた
- **意味**: 個別株式の収益率と市場全体の収益率の相関を示す指標
- **関連用語**: CAPM、システマティックリスク、株主資本コスト

### ま行

**マルチプル法**
- **読み方**: まるちぷるほう
- **意味**: 類似企業の取引倍率を用いて企業価値を算定する手法
- **関連用語**: EV/EBITDA、PER、類似企業比較法

### や行

**有利子負債**
- **読み方**: ゆうりしふさい
- **意味**: 利息の支払いが必要な負債（借入金、社債等）
- **関連用語**: 純有利子負債、負債コスト

### ら行

**リスクフリーレート**
- **読み方**: りすくふりーれーと
- **意味**: 無リスク資産の収益率。通常は国債利回りを使用
- **関連用語**: CAPM、国債利回り、株主資本コスト

**類似企業比較法**
- **読み方**: るいじきぎょうひかくほう
- **意味**: 類似する上場企業の評価倍率を用いる企業価値評価手法
- **関連用語**: マルチプル法、コンパラブル法

### わ行

**割引率**
- **読み方**: わりびきりつ
- **意味**: 将来価値を現在価値に換算する際に使用する率
- **関連用語**: WACC、現在価値、時間価値
