# 資本利益率について

## 概要

資本利益率とは、企業が投下した資本に対してどれだけの利益を生み出したかを示す財務指標です。企業の収益性を評価する重要な指標であり、経営効率や投資効率を測定するために用いられます。資本利益率には複数の種類があり、それぞれ異なる視点から企業の収益性を分析できます。

## 1. 基本概念・定義

資本利益率は、利益を資本で除した比率として計算されます。使用する利益と資本の種類によって、様々な資本利益率が存在します。

### 資本利益率の基本公式
- **基本公式**: 資本利益率（％）＝ 利益 ÷ 資本 × 100
- **特徴**: 投下資本に対する収益性を示す
- **重要性**: 企業の経営効率、投資効率を評価する基本指標

### 資本利益率の種類
- **総資本経常利益率**: 企業全体の収益性を示す
- **総資本事業利益率**: 本業の収益性を示す
- **経営資本営業利益率**: 経営活動の効率性を示す
- **自己資本利益率（ROE）**: 株主視点での収益性を示す

## 2. 各資本利益率の詳細

### 総資本経常利益率

| 項目 | 内容 |
|------|------|
| 定義 | 経常利益を総資本で除した比率 |
| 計算式 | 総資本経常利益率（％）＝ 経常利益 ÷ 総資本（平均）× 100 |
| 意味 | 企業が保有する全ての資本に対する経常的な収益力 |
| 特徴 | 財務活動を含めた企業全体の収益性を評価 |
| 使用場面 | 企業の総合的な収益性評価、同業他社比較 |

### 総資本事業利益率

| 項目 | 内容 |
|------|------|
| 定義 | 事業利益を総資本で除した比率 |
| 計算式 | 総資本事業利益率（％）＝ 事業利益 ÷ 総資本（平均）× 100 |
| 事業利益 | 営業利益 ＋ 受取利息・配当金 |
| 意味 | 事業活動全体の収益性を示す |
| 特徴 | 本業と金融収益を合わせた事業活動の効率性を評価 |

### 経営資本営業利益率

| 項目 | 内容 |
|------|------|
| 定義 | 営業利益を経営資本で除した比率 |
| 計算式 | 経営資本営業利益率（％）＝ 営業利益 ÷ 経営資本（平均）× 100 |
| 経営資本 | 総資本 － 建設仮勘定 － 投資その他の資産 |
| 意味 | 実際の経営活動に使用される資本の効率性 |
| 特徴 | 本業の収益性を純粋に評価できる |

### 自己資本利益率（ROE）

| 項目 | 内容 |
|------|------|
| 定義 | 当期純利益を自己資本で除した比率 |
| 計算式 | ROE（％）＝ 当期純利益 ÷ 自己資本（平均）× 100 |
| 意味 | 株主が投下した資本に対する収益性 |
| 特徴 | 株主視点での投資効率を示す最重要指標 |
| 目標水準 | 一般的に8～10％以上が望ましい |

## 3. 具体的計算例

### ケース1: A社の資本利益率計算

#### 前提条件
- 総資本（期首）: 10,000百万円
- 総資本（期末）: 11,000百万円
- 自己資本（期首）: 4,000百万円
- 自己資本（期末）: 4,400百万円
- 経常利益: 800百万円
- 営業利益: 700百万円
- 受取利息・配当金: 50百万円
- 当期純利益: 500百万円
- 建設仮勘定: 200百万円
- 投資その他の資産: 800百万円

#### 各種資本利益率の計算

**1. 総資本経常利益率**
- 総資本（平均）= (10,000 + 11,000) ÷ 2 = 10,500百万円
- 総資本経常利益率 = 800 ÷ 10,500 × 100 = 7.62％

**2. 総資本事業利益率**
- 事業利益 = 700 + 50 = 750百万円
- 総資本事業利益率 = 750 ÷ 10,500 × 100 = 7.14％

**3. 経営資本営業利益率**
- 経営資本（期首）= 10,000 - 200 - 800 = 9,000百万円
- 経営資本（期末）= 11,000 - 200 - 800 = 10,000百万円
- 経営資本（平均）= (9,000 + 10,000) ÷ 2 = 9,500百万円
- 経営資本営業利益率 = 700 ÷ 9,500 × 100 = 7.37％

**4. 自己資本利益率（ROE）**
- 自己資本（平均）= (4,000 + 4,400) ÷ 2 = 4,200百万円
- ROE = 500 ÷ 4,200 × 100 = 11.90％

### ケース2: B社の期間比較分析

#### 前年度データ
- 総資本（平均）: 8,000百万円
- 自己資本（平均）: 3,000百万円
- 経常利益: 400百万円
- 当期純利益: 240百万円

#### 当年度データ
- 総資本（平均）: 9,000百万円
- 自己資本（平均）: 3,500百万円
- 経常利益: 540百万円
- 当期純利益: 350百万円

#### 比較分析

| 指標 | 前年度 | 当年度 | 増減 |
|------|--------|--------|------|
| 総資本経常利益率 | 5.00％ | 6.00％ | +1.00％ |
| ROE | 8.00％ | 10.00％ | +2.00％ |

**分析結果**
- 総資本経常利益率、ROEともに改善
- 特にROEの改善幅が大きく、株主価値向上に貢献
- 収益性の改善により、経営効率が向上したと評価できる

## 4. 資本利益率の分析手法

### デュポン分析（ROEの要因分解）

ROEは以下の3つの要素に分解できます：

```
ROE = 売上高純利益率 × 総資本回転率 × 財務レバレッジ

ROE = (当期純利益/売上高) × (売上高/総資本) × (総資本/自己資本)
```

#### 計算例：C社のROE分析
- 売上高: 10,000百万円
- 当期純利益: 400百万円
- 総資本: 8,000百万円
- 自己資本: 4,000百万円

**要因分解**
- 売上高純利益率 = 400 ÷ 10,000 = 4.0％
- 総資本回転率 = 10,000 ÷ 8,000 = 1.25回
- 財務レバレッジ = 8,000 ÷ 4,000 = 2.0倍
- ROE = 4.0％ × 1.25 × 2.0 = 10.0％

### 業界比較分析

| 業界 | 総資本経常利益率 | ROE | 特徴 |
|------|------------------|-----|------|
| 製造業 | 5～7％ | 8～10％ | 設備投資が大きく、資本利益率は中程度 |
| 小売業 | 3～5％ | 6～8％ | 薄利多売で回転率重視 |
| IT業 | 8～12％ | 12～15％ | 資本効率が高い |
| 不動産業 | 4～6％ | 8～12％ | レバレッジ効果を活用 |

## 5. 実務上の注意点

### 資本利益率分析の重要ポイント

- **平均値の使用**: 期首・期末の平均値を使用することで、期中の変動を考慮
- **継続性**: 同じ計算方法を継続的に使用し、時系列比較を可能にする
- **業界特性**: 業界によって適正水準が異なるため、同業他社比較が重要
- **財務レバレッジ**: ROEが高くても過度な借入による場合は注意が必要

### よくある誤解・トラブル

- **誤解1**: ROEが高ければ必ず良い企業
  - 正しい理解: 過度な借入や自己資本の減少でもROEは上昇する
- **誤解2**: 資本利益率は高いほど良い
  - 正しい理解: 持続可能性や安全性とのバランスが重要
- **誤解3**: 単年度の数値だけで判断
  - 正しい理解: 3～5年の推移を見て傾向を把握すべき

## 6. よくある質問（Q&A）

### Q1. 総資本経常利益率と総資本事業利益率の使い分けは？

**A1.** 分析の目的によって使い分けます。

#### 詳細説明
- **総資本経常利益率**: 企業の総合的な収益性を見る場合に使用。財務活動も含めた全体評価に適している
- **総資本事業利益率**: 本業と金融収益に焦点を当てる場合に使用。事業活動の効率性評価に適している
- 一般的には総資本経常利益率がより広く使用される

### Q2. ROEが低い場合の改善方法は？

**A2.** デュポン分析で要因を特定し、各要素を改善します。

#### 改善アプローチ
1. **売上高純利益率の改善**
   - コスト削減、付加価値向上、価格戦略の見直し
   
2. **総資本回転率の改善**
   - 在庫回転率向上、売掛金回収期間短縮、遊休資産の処分
   
3. **財務レバレッジの活用**
   - 適度な借入による資本効率向上（ただしリスク管理が必要）

### Q3. 経営資本営業利益率が重要な理由は？

**A3.** 本業の収益性を純粋に評価できるためです。

#### 詳細説明
- 建設仮勘定や投資その他の資産を除外することで、実際の営業活動に使用される資本の効率性を測定
- 事業の実力を正確に把握でき、経営改善の指標として有効
- 特に製造業など設備投資が大きい業種で重要視される

## 7. まとめ・今後の展望

資本利益率は企業の収益性を評価する基本的かつ重要な指標です。総資本経常利益率、総資本事業利益率、経営資本営業利益率、自己資本利益率（ROE）それぞれに特徴があり、分析目的に応じて使い分けることが重要です。

今後は、ESG投資の普及により、単純な財務的収益性だけでなく、持続可能性を考慮した新たな収益性指標の開発が期待されます。また、無形資産の重要性が高まる中、知的資本や人的資本を考慮した資本利益率の概念も発展していくでしょう。

## 9. 専門用語集

このスライドで使用された専門用語について、50音順で解説します。

### あ行

**売上高純利益率（うりあげだかじゅんりえきりつ）**
- **読み方**: うりあげだかじゅんりえきりつ
- **意味**: 当期純利益を売上高で除した比率。売上高に対する最終的な利益の割合を示す
- **関連用語**: 売上高総利益率、売上高営業利益率、売上高経常利益率

**売上高経常利益率（うりあげだかけいじょうりえきりつ）**
- **読み方**: うりあげだかけいじょうりえきりつ
- **意味**: 経常利益を売上高で除した比率。通常の企業活動による収益性を示す
- **関連用語**: 経常利益、売上高純利益率

**営業利益（えいぎょうりえき）**
- **読み方**: えいぎょうりえき
- **意味**: 売上高から売上原価と販売費及び一般管理費を差し引いた利益。本業の収益力を示す
- **関連用語**: 売上総利益、経常利益、事業利益

### か行

**経営資本（けいえいしほん）**
- **読み方**: けいえいしほん
- **意味**: 総資本から建設仮勘定と投資その他の資産を控除したもの。実際の営業活動に使用される資本
- **関連用語**: 総資本、経営資本営業利益率

**経営資本営業利益率（けいえいしほんえいぎょうりえきりつ）**
- **読み方**: けいえいしほんえいぎょうりえきりつ
- **意味**: 営業利益を経営資本で除した比率。本業における資本効率を示す
- **関連用語**: 営業利益、経営資本、総資本営業利益率

**経常利益（けいじょうりえき）**
- **読み方**: けいじょうりえき
- **意味**: 営業利益に営業外収益を加え、営業外費用を差し引いた利益。企業の通常の活動による利益
- **関連用語**: 営業利益、税引前当期純利益

**建設仮勘定（けんせつかりかんじょう）**
- **読み方**: けんせつかりかんじょう
- **意味**: 建設中の有形固定資産への支出を一時的に計上する勘定科目
- **関連用語**: 有形固定資産、経営資本

### さ行

**財務レバレッジ（ざいむればれっじ）**
- **読み方**: ざいむればれっじ
- **意味**: 総資本を自己資本で除した倍率。借入金の活用度を示す
- **関連用語**: 自己資本比率、負債比率、ROE

**事業利益（じぎょうりえき）**
- **読み方**: じぎょうりえき
- **意味**: 営業利益に受取利息・配当金を加えた利益。事業活動全体の収益を示す
- **関連用語**: 営業利益、総資本事業利益率

**自己資本（じこしほん）**
- **読み方**: じこしほん
- **意味**: 株主資本と評価・換算差額等の合計。返済義務のない資本
- **関連用語**: 株主資本、純資産、他人資本

**自己資本比率（じこしほんひりつ）**
- **読み方**: じこしほんひりつ
- **意味**: 自己資本を総資本で除した比率。財務の安全性を示す
- **関連用語**: 自己資本、総資本、財務レバレッジ

**自己資本利益率（じこしほんりえきりつ）**
- **読み方**: じこしほんりえきりつ
- **意味**: ROEとも呼ばれ、当期純利益を自己資本で除した比率。株主の投資収益率を示す
- **関連用語**: ROE、当期純利益、自己資本

**受取利息・配当金（うけとりりそく・はいとうきん）**
- **読み方**: うけとりりそく・はいとうきん
- **意味**: 企業が保有する預金や有価証券から得る利息や配当金収入
- **関連用語**: 営業外収益、事業利益

**総資本（そうしほん）**
- **読み方**: そうしほん
- **意味**: 貸借対照表の資産合計額。企業が運用している全ての資本
- **関連用語**: 総資産、自己資本、他人資本

**総資本回転率（そうしほんかいてんりつ）**
- **読み方**: そうしほんかいてんりつ
- **意味**: 売上高を総資本で除した回転数。資本の効率的な活用度を示す
- **関連用語**: 総資本、売上高、資産回転率

**総資本経常利益率（そうしほんけいじょうりえきりつ）**
- **読み方**: そうしほんけいじょうりえきりつ
- **意味**: 経常利益を総資本で除した比率。企業全体の収益性を示す基本指標
- **関連用語**: 経常利益、総資本、ROA

**総資本事業利益率（そうしほんじぎょうりえきりつ）**
- **読み方**: そうしほんじぎょうりえきりつ
- **意味**: 事業利益を総資本で除した比率。事業活動の収益性を示す
- **関連用語**: 事業利益、総資本、総資本経常利益率

### た行

- **意味**: ROEを売上高純利益率、総資本回転率、財務レバレッジに分解する分析手法
