# 株式各種指標について

## 概要
株式投資における各種指標は、企業の財務状況、収益性、成長性、市場評価を数値化したものであり、投資判断の重要な根拠となる。これらの指標を適切に理解し活用することで、企業の本質的価値と市場価格の乖離を見極め、合理的な投資判断が可能となる。本資料では、主要な株式指標を体系的に解説し、実務での活用方法を具体的な計算例と共に説明する。

## 1. 株価評価指標（バリュエーション指標）

### PER（株価収益率）
- **定義**: 株価が1株当たり純利益（EPS）の何倍で取引されているかを示す指標
- **算出方法**: PER = 株価 ÷ EPS（1株当たり純利益）
- **特徴**: 企業の収益力に対する市場の評価を表し、一般的に15～20倍が適正とされる

### PBR（株価純資産倍率）
- **定義**: 株価が1株当たり純資産（BPS）の何倍で取引されているかを示す指標
- **算出方法**: PBR = 株価 ÷ BPS（1株当たり純資産）
- **特徴**: 1倍を下回ると解散価値を下回っており、割安と判断される場合が多い

### PSR（株価売上高倍率）
- **定義**: 株価が1株当たり売上高の何倍で取引されているかを示す指標
- **算出方法**: PSR = 時価総額 ÷ 売上高 = 株価 ÷ 1株当たり売上高
- **特徴**: 赤字企業でも算出可能で、成長企業の評価に適している

## 2. 株価評価指標の詳細分析

### PCFR（株価キャッシュフロー倍率）
**特徴:**
- キャッシュフローベースで企業価値を評価
- 会計操作の影響を受けにくい
- 設備投資が多い企業の評価に適している

**算出方法:**
```
PCFR = 株価 ÷ 1株当たり営業キャッシュフロー
```

**📊 具体的な計算例**
**例: A社の株価評価**
- 株価: 2,500円
- 発行済株式数: 1,000万株
- 営業キャッシュフロー: 100億円

**ステップ1: 1株当たり営業キャッシュフローの計算**
```
1株当たり営業CF = 100億円 ÷ 1,000万株 = 1,000円
```

**ステップ2: PCFRの計算**
```
PCFR = 2,500円 ÷ 1,000円 = 2.5倍
```

**結果: PCFRは2.5倍となり、比較的低水準で割安と判断できる**

💡 **実際の現場では**: 業界平均と比較し、同業他社のPCFRが5～8倍の場合、相対的に割安と判断される

### EV/EBITDA倍率
**特徴:**
- 企業価値全体を評価する指標
- 資本構成の違いを排除して比較可能
- M&Aでの企業価値評価に頻繁に使用

**算出方法:**
```
EV（企業価値） = 時価総額 + 有利子負債 - 現金及び現金同等物
EV/EBITDA = EV ÷ EBITDA
```

**📊 具体的な計算例**
**例: B社の企業価値評価**
- 時価総額: 5,000億円
- 有利子負債: 2,000億円
- 現金及び現金同等物: 500億円
- EBITDA: 800億円

**ステップ1: 企業価値（EV）の計算**
```
EV = 5,000億円 + 2,000億円 - 500億円 = 6,500億円
```

**ステップ2: EV/EBITDA倍率の計算**
```
EV/EBITDA = 6,500億円 ÷ 800億円 = 8.125倍
```

**結果: EV/EBITDA倍率は8.125倍となり、業界平均と比較して判断**

💡 **実際の現場では**: 一般的に10倍以下は割安、15倍以上は割高とされるが、業界により基準は異なる

## 3. 収益性指標

### ROE（自己資本利益率）
**定義**: 株主が投資した資本に対してどれだけの利益を生み出したかを示す指標

**算出方法:**
```
ROE = 当期純利益 ÷ 自己資本 × 100
```

**デュポン分解:**
```
ROE = 売上高純利益率 × 総資産回転率 × 財務レバレッジ
    = (純利益/売上高) × (売上高/総資産) × (総資産/自己資本)
```

**📊 具体的な計算例**
**例: C社のROE分析**
- 当期純利益: 150億円
- 売上高: 3,000億円
- 総資産: 2,000億円
- 自己資本: 1,000億円

**ステップ1: 基本的なROE計算**
```
ROE = 150億円 ÷ 1,000億円 × 100 = 15%
```

**ステップ2: デュポン分解による詳細分析**
```
売上高純利益率 = 150億円 ÷ 3,000億円 = 5%
総資産回転率 = 3,000億円 ÷ 2,000億円 = 1.5回
財務レバレッジ = 2,000億円 ÷ 1,000億円 = 2倍

ROE = 5% × 1.5 × 2 = 15%
```

**結果: ROE15%は日本企業の平均（8-10%）を上回り、優良企業と判断できる**

### ROA（総資産利益率）
**定義**: 企業が保有する総資産をどれだけ効率的に活用して利益を生み出しているかを示す指標

**算出方法:**
```
ROA = 当期純利益 ÷ 総資産 × 100
または
ROA = 営業利益 ÷ 総資産 × 100（営業ROA）
```

**📊 具体的な計算例**
**例: D社のROA計算**
- 当期純利益: 80億円
- 営業利益: 120億円
- 総資産: 2,000億円

**ステップ1: 純利益ベースのROA**
```
ROA（純利益） = 80億円 ÷ 2,000億円 × 100 = 4%
```

**ステップ2: 営業利益ベースのROA**
```
ROA（営業利益） = 120億円 ÷ 2,000億円 × 100 = 6%
```

**結果: 営業ROA6%は業界平均を上回り、資産効率が良好**

### ROIC（投下資本利益率）
**定義**: 事業に投下した資本に対してどれだけの利益を生み出したかを示す指標

**算出方法:**
```
ROIC = 税引後営業利益（NOPAT） ÷ 投下資本 × 100
投下資本 = 有利子負債 + 株主資本
```

**📊 具体的な計算例**
**例: E社のROIC計算**
- 営業利益: 200億円
- 実効税率: 30%
- 有利子負債: 500億円
- 株主資本: 1,000億円

**ステップ1: NOPATの計算**
```
NOPAT = 200億円 × (1 - 0.3) = 140億円
```

**ステップ2: ROICの計算**
```
投下資本 = 500億円 + 1,000億円 = 1,500億円
ROIC = 140億円 ÷ 1,500億円 × 100 = 9.33%
```

**結果: ROIC9.33%は資本コストを上回れば価値創造企業**

## 4. 財務健全性指標

### 流動比率
**定義**: 短期的な支払能力を示す指標

**算出方法:**
```
流動比率 = 流動資産 ÷ 流動負債 × 100
```

**📊 具体的な計算例**
**例: F社の流動性分析**
- 流動資産: 800億円
  - 現金預金: 200億円
  - 売上債権: 300億円
  - 棚卸資産: 250億円
  - その他: 50億円
- 流動負債: 500億円

**ステップ1: 流動比率の計算**
```
流動比率 = 800億円 ÷ 500億円 × 100 = 160%
```

**ステップ2: 当座比率の計算（参考）**
```
当座資産 = 800億円 - 250億円 = 550億円
当座比率 = 550億円 ÷ 500億円 × 100 = 110%
```

**結果: 流動比率160%、当座比率110%で短期的な支払能力は良好**

### 自己資本比率
**定義**: 総資産に占める自己資本の割合を示す指標

**算出方法:**
```
自己資本比率 = 自己資本 ÷ 総資産 × 100
```

**📊 具体的な計算例**
**例: G社の財務安定性評価**
- 総資産: 3,000億円
- 自己資本: 1,500億円
- 他人資本: 1,500億円

**ステップ1: 自己資本比率の計算**
```
自己資本比率 = 1,500億円 ÷ 3,000億円 × 100 = 50%
```

**ステップ2: D/Eレシオの計算（参考）**
```
D/Eレシオ = 1,500億円 ÷ 1,500億円 = 1.0倍
```

**結果: 自己資本比率50%は安定的な水準**

## 5. 効率性指標

### 総資産回転率
**定義**: 総資産をどれだけ効率的に活用して売上を生み出しているかを示す指標

**算出方法:**
```
総資産回転率 = 売上高 ÷ 総資産
```

**📊 具体的な計算例**
**例: H社の資産効率分析**
- 売上高: 4,000億円
- 期首総資産: 2,400億円
- 期末総資産: 2,600億円

**ステップ1: 平均総資産の計算**
```
平均総資産 = (2,400億円 + 2,600億円) ÷ 2 = 2,500億円
```

**ステップ2: 総資産回転率の計算**
```
総資産回転率 = 4,000億円 ÷ 2,500億円 = 1.6回
```

**結果: 総資産を年1.6回転させて売上を生成**

### 棚卸資産回転率
**定義**: 在庫がどれだけ効率的に販売されているかを示す指標

**算出方法:**
```
棚卸資産回転率 = 売上原価 ÷ 平均棚卸資産
棚卸資産回転日数 = 365日 ÷ 棚卸資産回転率
```

**📊 具体的な計算例**
**例: I社の在庫管理効率**
- 売上原価: 2,400億円
- 期首棚卸資産: 180億円
- 期末棚卸資産: 220億円

**ステップ1: 平均棚卸資産と回転率の計算**
```
平均棚卸資産 = (180億円 + 220億円) ÷ 2 = 200億円
棚卸資産回転率 = 2,400億円 ÷ 200億円 = 12回
```

**ステップ2: 回転日数の計算**
```
棚卸資産回転日数 = 365日 ÷ 12回 = 30.4日
```

**結果: 在庫は約30日で1回転し、効率的な在庫管理を実現**

## 6. 配当関連指標

### 配当利回り
**定義**: 株価に対する年間配当金の割合

**算出方法:**
```
配当利回り = 年間配当金 ÷ 株価 × 100
```

**📊 具体的な計算例**
**例: J社の配当分析**
- 株価: 3,000円
- 年間配当金: 90円
- 当期純利益: 150億円
- 発行済株式数: 1億株

**ステップ1: 配当利回りの計算**
```
配当利回り = 90円 ÷ 3,000円 × 100 = 3.0%
```

**ステップ2: 配当性向の計算**
```
EPS = 150億円 ÷ 1億株 = 150円
配当性向 = 90円 ÷ 150円 × 100 = 60%
```

**結果: 配当利回り3.0%、配当性向60%で株主還元に積極的**

### 配当性向
**定義**: 当期純利益のうち配当金として支払われる割合

**算出方法:**
```
配当性向 = 配当金総額 ÷ 当期純利益 × 100
または
配当性向 = 1株当たり配当金 ÷ EPS × 100
```

### 総還元性向
**定義**: 配当と自社株買いを合わせた株主還元の割合

**算出方法:**
```
総還元性向 = (配当総額 + 自社株買い金額) ÷ 当期純利益 × 100
```

## 7. 成長性指標

### 売上高成長率
**定義**: 売上高の前年比成長率

**算出方法:**
```
売上高成長率 = (当期売上高 - 前期売上高) ÷ 前期売上高 × 100
```

### EPS成長率
**定義**: 1株当たり純利益の成長率

**算出方法:**
```
EPS成長率 = (当期EPS - 前期EPS) ÷ 前期EPS × 100
```

### PEGレシオ
**定義**: PERを利益成長率で割った指標

**算出方法:**
```
PEGレシオ = PER ÷ 予想EPS成長率
```

**📊 具体的な計算例**
**例: K社の成長性評価**
- 現在の株価: 4,000円
- 現在のEPS: 200円
- 予想EPS成長率: 15%

**ステップ1: PERの計算**
```
PER = 4,000円 ÷ 200円 = 20倍
```

**ステップ2: PEGレシオの計算**
```
PEGレシオ = 20倍 ÷ 15% = 1.33
```

**結果: PEGレシオ1.33は若干割高だが、成長を考慮すると妥当な水準**

- A) 株価 ÷ BPS
- B) 株価 ÷ EPS
- C) EPS ÷ 株価
- D) 時価総額 ÷ 売上高

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
PER（Price Earnings Ratio）は株価を1株当たり純利益（EPS）で割った値です。<br>

## 10. 専門用語集

このスライドで使用された専門用語について、アルファベット順・50音順で解説します。

### アルファベット

**BPS (Book Value Per Share)**
- **読み方**: ビーピーエス
- **意味**: 1株当たり純資産。企業の純資産を発行済株式数で除した値で、株主に帰属する1株当たりの資産価値を示す
- **関連用語**: PBR、純資産、株主資本

**D/Eレシオ (Debt Equity Ratio)**
- **読み方**: ディーイーレシオ
- **意味**: 負債資本倍率。有利子負債を自己資本で除した値で、財務レバレッジの程度を示す
- **関連用語**: 財務レバレッジ、自己資本比率、負債比率

**EBIT (Earnings Before Interest and Taxes)**
- **読み方**: イービット
- **意味**: 支払利息・税引前利益。金利と税金の影響を除いた事業利益を示す
- **関連用語**: EBITDA、営業利益、EV/EBIT倍率

**EBITDA (Earnings Before Interest, Taxes, Depreciation and Amortization)**
- **読み方**: イービットディーエー
- **意味**: 支払利息・税金・減価償却前利益。現金創出力を示す指標
- **関連用語**: EBIT、営業キャッシュフロー、EV/EBITDA倍率

**EPS (Earnings Per Share)**
- **読み方**: イーピーエス
- **意味**: 1株当たり純利益。当期純利益を発行済株式数で除した値
- **関連用語**: PER、配当性向、EPS成長率

**EV (Enterprise Value)**
- **読み方**: イーブイ、エンタープライズバリュー
- **意味**: 企業価値。時価総額に有利子負債を加え、現金を差し引いた値
- **関連用語**: 時価総額、EV/EBITDA倍率、買収価格

**FCF (Free Cash Flow)**
- **読み方**: エフシーエフ、フリーキャッシュフロー
- **意味**: 企業が自由に使える現金流量。営業CFから設備投資を差し引いた値
- **関連用語**: 営業キャッシュフロー、投資キャッシュフロー

**NOPAT (Net Operating Profit After Tax)**
- **読み方**: ノーパット
- **意味**: 税引後営業利益。営業利益に実効税率を適用した値
- **関連用語**: ROIC、営業利益、実効税率

**PBR (Price Book-value Ratio)**
- **読み方**: ピービーアール
- **意味**: 株価純資産倍率。株価をBPSで除した値
- **関連用語**: BPS、PER、解散価値

**PCFR (Price Cash Flow Ratio)**
- **読み方**: ピーシーエフアール
- **意味**: 株価キャッシュフロー倍率。株価を1株当たり営業CFで除した値
- **関連用語**: 営業キャッシュフロー、PER、キャッシュフロー

**PEGレシオ (Price Earnings Growth Ratio)**
- **読み方**: ペグレシオ
- **意味**: PERを予想利益成長率で除した値。成長性を考慮した割安度指標
- **関連用語**: PER、EPS成長率、成長株投資

**PER (Price Earnings Ratio)**
- **読み方**: ピーイーアール、パー
- **意味**: 株価収益率。株価をEPSで除した値で、利益に対する株価の割高・割安を示す
- **関連用語**: EPS、PEGレシオ、益回り

**PSR (Price Sales Ratio)**
- **読み方**: ピーエスアール
- **意味**: 株価売上高倍率。時価総額を売上高で除した値
- **関連用語**: 売上高、時価総額、PER

**ROA (Return On Assets)**
- **読み方**: アールオーエー
- **意味**: 総資産利益率。純利益を総資産で除した値で、資産効率を示す
- **関連用語**: ROE、総資産回転率、営業ROA

**ROE (Return On Equity)**
- **読み方**: アールオーイー
- **意味**: 自己資本利益率。純利益を自己資本で除した値で、株主資本の効率性を示す
- **関連用語**: ROA、デュポン分解、財務レバレッジ

**ROIC (Return On Invested Capital)**
- **読み方**: アールオーアイシー
- **意味**: 投下資本利益率。NOPATを投下資本で除した値
- **関連用語**: NOPAT、WACC、投下資本

**WACC (Weighted Average Cost of Capital)**
- **読み方**: ワック
- **意味**: 加重平均資本コスト。負債と株主資本のコストを加重平均した値
- **関連用語**: ROIC、資本コスト、企業価値評価

### あ行

**売上高成長率（うりあげだかせいちょうりつ）**
- **意味**: 売上高の前年比増減率。企業の成長性を測る基本指標
- **関連用語**: EPS成長率、営業利益成長率、CAGR

**売上債権回転率（うりあげさいけんかいてんりつ）**
- **意味**: 売上高を平均売上債権で除した値。債権回収の効率性を示す
- **関連用語**: 回収期間、棚卸資産回転率、買入債務回転率

**営業キャッシュフロー（えいぎょうキャッシュフロー）**
- **意味**: 営業活動から生み出される現金流量
- **関連用語**: フリーキャッシュフロー、PCFR、キャッシュフロー計算書

**営業利益率（えいぎょうりえきりつ）**
- **意味**: 営業利益を売上高で除した値。本業の収益性を示す
- **関連用語**: 売上高総利益率、経常利益率、純利益率

### か行

**買入債務回転率（かいいれさいむかいてんりつ）**
- **意味**: 売上原価を平均買入債務で除した値。支払いの効率性を示す
- **関連用語**: 支払期間、売上債権回転率、CCC

**解散価値（かいさんかち）**
- **意味**: 企業を解散した場合の株主への分配可能額。通常はBPSに近い
- **関連用語**: PBR、BPS、清算価値

**株価収益率（かぶかしゅうえきりつ）**
- **意味**: PERの日本語表記。株価をEPSで除した値
- **関連用語**: PER、EPS、益回り

**株主資本（かぶぬししほん）**
- **意味**: 株主に帰属する資本。資本金、資本剰余金、利益剰余金等の合計
- **関連用語**: 自己資本、純資産、ROE

**企業価値（きぎょうかち）**
- **意味**: EVの日本語表記。事業価値と非事業資産の合計
- **関連用語**: EV、時価総額、買収価格

**キャッシュ・コンバージョン・サイクル（キャッシュ・コンバージョン・サイクル）**
- **意味**: 運転資本が現金に変換されるまでの日数。CCC
- **関連用語**: 売上債権回収期間、棚卸資産回転日数、買入債務支払期間

**減価償却費（げんかしょうきゃくひ）**
- **意味**: 固定資産の取得原価を使用期間に配分した費用
- **関連用語**: EBITDA、営業キャッシュフロー、設備投資

**現金同等物（げんきんどうとうぶつ）**
- **意味**: 容易に換金可能で価値変動リスクが小さい短期投資
- **関連用語**: 手元流動性、流動資産、EV

### さ行

**財務レバレッジ（ざいむレバレッジ）**
- **意味**: 総資産を自己資本で除した値。借入による資産拡大の程度
- **関連用語**: D/Eレシオ、ROE、デュポン分解

**時価総額（じかそうがく）**
- **意味**: 株価に発行済株式数を乗じた値。市場での企業評価額
- **関連用語**: EV、株価、発行済株式数

**自己資本（じこしほん）**
- **意味**: 株主資本と同義。返済義務のない資本
- **関連用語**: 株主資本、純資産、自己資本比率

**自己資本比率（じこしほんひりつ）**
- **意味**: 自己資本を総資産で除した値。財務安定性を示す
- **関連用語**: 負債比率、D/Eレシオ、財務レバレッジ

**純資産（じゅんしさん）**
- **意味**: 総資産から総負債を差し引いた値。株主に帰属する資産
- **関連用語**: 自己資本、株主資本、BPS

**総資産回転率（そうしさんかいてんりつ）**
- **意味**: 売上高を総資産で除した値。資産の効率的活用度を示す
- **関連用語**: ROA、デュポン分解、固定資産回転率

**総還元性向（そうかんげんせいこう）**
- **意味**: 配当と自社株買いの合計を純利益で除した値
- **関連用語**: 配当性向、自社株買い、株主還元

### た行

**棚卸資産回転率（たなおろししさんかいてんりつ）**
- **意味**: 売上原価を平均棚卸資産で除した値。在庫効率を示す
- **関連用語**: 回転日数、在庫日数、運転資本

**デュポン分解（デュポンぶんかい）**
- **意味**: ROEを3つの要素（利益率・回転率・レバレッジ）に分解する分析手法
- **関連用語**: ROE、売上高純利益率、総資産回転率

**当座比率（とうざひりつ）**
- **意味**: 当座資産を流動負債で除した値。即座の支払能力を示す
- **関連用語**: 流動比率、当座資産、流動負債

**投下資本（とうかしほん）**
- **意味**: 事業活動に投下された資本。有利子負債と株主資本の合計
- **関連用語**: ROIC、有利子負債、株主資本

### な行

**内部留保（ないぶりゅうほ）**
- **意味**: 企業が稼いだ利益のうち配当されずに社内に留保された部分
- **関連用語**: 利益剰余金、配当性向、自己資本

### は行

**配当性向（はいとうせいこう）**
- **意味**: 配当金総額を当期純利益で除した値。利益還元率を示す
- **関連用語**: 配当利回り、総還元性向、DPS

**配当利回り（はいとうりまわり）**
- **意味**: 年間配当金を株価で除した値。投資収益率を示す
- **関連用語**: 配当性向、DPS、株主還元

**売上高純利益率（ばいじょうだかじゅんりえきりつ）**
- **意味**: 純利益を売上高で除した値。最終的な収益性を示す
- **関連用語**: 営業利益率、経常利益率、デュポン分解

**負債比率（ふさいひりつ）**
- **意味**: 負債を総資産で除した値。他人資本への依存度を示す
- **関連用語**: 自己資本比率、D/Eレシオ、財務安定性

### ま行

**益回り（えきまわり）**
- **意味**: PERの逆数。EPSを株価で除した値で、利益利回りを示す
- **関連用語**: PER、EPS、配当利回り

### や行

**有利子負債（ゆうりしふさい）**
- **意味**: 利息の支払いが必要な負債。借入金、社債など
- **関連用語**: D/Eレシオ、EV、インタレスト・カバレッジ

### ら行

**流動比率（りゅうどうひりつ）**
- **意味**: 流動資産を流動負債で除した値。短期支払能力を示す
- **関連用語**: 当座比率、運転資本、流動性

**利益剰余金（りえきじょうよきん）**
- **意味**: 過去の利益の蓄積から配当を差し引いた残額
- **関連用語**: 内部留保、自己資本、株主資本
