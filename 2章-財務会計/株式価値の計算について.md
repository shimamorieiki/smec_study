# 株式価値の計算について

## 概要

株式価値の計算（株式評価）は、企業の価値を算定し、その企業の株式の適正価格を導き出すプロセスです。M&A、事業承継、投資判断、財務報告など様々な場面で必要とされる重要な手法です。主にコストアプローチ、インカムアプローチ、マーケットアプローチの3つの評価方法があり、それぞれ異なる観点から企業価値を測定します。

## 1. 基本概念・定義

### 株式価値とは
- **定義**: 企業の株式1株あたりの経済的価値、または企業全体の株式の総価値
- **特徴**: 企業の財務状況、収益性、成長性、市場環境などを反映
- **重要性**: 投資判断、M&A価格決定、相続税評価などの基礎となる

### 企業価値と株式価値の関係
- **企業価値（EV: Enterprise Value）**: 事業価値＋非事業用資産
- **株式価値（Equity Value）**: 企業価値－有利子負債等
- **計算式**: 株式価値 = 企業価値 - 純有利子負債

## 2. 評価アプローチの分類

### 分類基準
株式価値の評価手法は、評価の着眼点により以下の3つのアプローチに分類されます。

### 1. コストアプローチ（Cost Approach）
| 項目 | 内容 |
|------|------|
| 特徴 | 企業の純資産に着目して評価 |
| 適用範囲 | 清算価値の算定、資産保有型企業の評価 |
| 主な手法 | 簿価純資産法、時価純資産法 |
| 注意点 | 将来の収益力を反映しない |

### 2. インカムアプローチ（Income Approach）
| 項目 | 内容 |
|------|------|
| 特徴 | 将来の収益やキャッシュフローに着目して評価 |
| 適用範囲 | 継続企業の評価、投資判断 |
| 主な手法 | DCF法、収益還元法、配当還元法 |
| 注意点 | 将来予測の不確実性がある |

### 3. マーケットアプローチ（Market Approach）
| 項目 | 内容 |
|------|------|
| 特徴 | 市場での取引価格や類似企業との比較により評価 |
| 適用範囲 | 上場企業の評価、M&A価格の参考 |
| 主な手法 | 市場株価法、類似会社比較法、類似取引比較法 |
| 注意点 | 適切な比較対象の選定が重要 |

## 3. 各アプローチの詳細と計算例

### コストアプローチの詳細

#### 簿価純資産法
- **計算式**: 株式価値 = 簿価純資産 ÷ 発行済株式数
- **特徴**: 最も簡便だが、含み損益を反映しない

#### 時価純資産法
- **計算式**: 株式価値 = (時価総資産 - 時価総負債) ÷ 発行済株式数
- **特徴**: 資産・負債を時価評価するため、より実態に近い

**📊 具体的な計算例（時価純資産法）**

**例: A社の株式価値評価**
- 簿価総資産: 10億円
- 簿価総負債: 6億円
- 土地の含み益: 2億円
- 有価証券の含み益: 0.5億円
- 発行済株式数: 100万株

**ステップ1: 時価純資産の算定**
```
時価総資産 = 10億円 + 2億円 + 0.5億円 = 12.5億円
時価総負債 = 6億円（変更なし）
時価純資産 = 12.5億円 - 6億円 = 6.5億円
```

**ステップ2: 1株当たり株式価値の算定**
```
株式価値（1株） = 6.5億円 ÷ 100万株 = 6,500円
```

**結果: 1株当たり6,500円**

💡 **実際の現場では**: 不動産鑑定評価や有価証券の時価評価など、専門家による評価が必要となることが多い

### インカムアプローチの詳細

#### DCF法（Discounted Cash Flow法）
- **計算式**: 企業価値 = Σ(FCF ÷ (1+WACC)^n) + TV ÷ (1+WACC)^n
- **特徴**: 最も理論的だが、前提条件の設定が難しい

#### 収益還元法
- **計算式**: 株式価値 = 予想利益 ÷ 資本還元率
- **特徴**: シンプルだが、成長性を考慮しにくい

**📊 具体的な計算例（DCF法）**

**例: B社の企業価値評価**
- 今後5年間のFCF予測: 1年目100百万円、2年目120百万円、3年目140百万円、4年目160百万円、5年目180百万円
- WACC: 8%
- 永続成長率: 2%
- 有利子負債: 500百万円
- 現金: 100百万円
- 発行済株式数: 10万株

**ステップ1: 各年度のFCFの現在価値算定**
```
1年目PV = 100 ÷ (1.08)^1 = 92.6百万円
2年目PV = 120 ÷ (1.08)^2 = 102.9百万円
3年目PV = 140 ÷ (1.08)^3 = 111.1百万円
4年目PV = 160 ÷ (1.08)^4 = 117.6百万円
5年目PV = 180 ÷ (1.08)^5 = 122.5百万円
合計 = 546.7百万円
```

**ステップ2: ターミナルバリューの算定**
```
6年目FCF = 180 × 1.02 = 183.6百万円
TV = 183.6 ÷ (0.08 - 0.02) = 3,060百万円
TV現在価値 = 3,060 ÷ (1.08)^5 = 2,082.7百万円
```

**ステップ3: 企業価値と株式価値の算定**
```
企業価値 = 546.7 + 2,082.7 = 2,629.4百万円
株式価値 = 2,629.4 - 500 + 100 = 2,229.4百万円
1株価値 = 2,229.4百万円 ÷ 10万株 = 22,294円
```

**結果: 1株当たり22,294円**

💡 **実際の現場では**: 事業計画の妥当性検証、感度分析、シナリオ分析なども併せて実施

### マーケットアプローチの詳細

#### 市場株価法
- **計算式**: 株式価値 = 市場株価（一定期間の平均値）
- **特徴**: 客観的だが、市場の需給や投機的要因の影響を受ける

#### 類似会社比較法（マルチプル法）
- **計算式**: 株式価値 = 財務指標 × 類似会社の倍率（マルチプル）
- **特徴**: 実務で広く使用されるが、類似会社の選定が重要

**📊 具体的な計算例（類似会社比較法）**

**例: C社の株式価値評価（PER法）**
- C社の予想純利益: 300百万円
- 類似上場企業3社のPER: A社15倍、B社18倍、C社20倍
- 発行済株式数: 50万株

**ステップ1: 類似会社PERの分析**
```
平均PER = (15 + 18 + 20) ÷ 3 = 17.7倍
中央値PER = 18倍
```

**ステップ2: 株式価値の算定**
```
株式価値（平均値使用） = 300百万円 × 17.7倍 = 5,310百万円
1株価値 = 5,310百万円 ÷ 50万株 = 10,620円
```

**結果: 1株当たり10,620円**

💡 **実際の現場では**: PER以外にもPBR、EV/EBITDA倍率など複数の指標を用いて総合的に判断

## 4. 評価手法の選択と併用

### 評価手法選択の判断基準
| 評価目的 | 推奨アプローチ | 理由 |
|----------|--------------|------|
| M&A | インカム＋マーケット | 将来性と市場評価の両面を考慮 |
| 事業承継（非上場） | コスト＋インカム | 税務上の要請と経済合理性 |
| 投資判断 | インカム＋マーケット | リターンとリスクの評価 |
| 清算 | コスト | 換金価値の把握が重要 |

### 総合評価の方法
1. **加重平均法**: 各手法の結果を一定の比率で加重平均
2. **レンジ法**: 各手法の結果から評価レンジを設定
3. **優先順位法**: 状況に応じて最も適切な手法を優先

## 5. 実務上の注意点

### 評価実施時の重要ポイント
- **目的の明確化**: 評価目的により適切な手法が異なる
- **前提条件の文書化**: 評価の前提条件を明確に記録
- **複数手法の併用**: 単一手法に依存せず、複数の観点から評価
- **専門家の活用**: 複雑な評価では専門家の助言を得る

### よくある誤解・トラブル
- **誤解1**: 「株式価値は唯一の正解がある」→ 評価手法により結果は異なる
- **誤解2**: 「簿価純資産が株式価値」→ 含み損益や収益力を考慮すべき
- **誤解3**: 「市場株価が絶対的」→ 市場の歪みや流動性の問題がある

## 6. よくある質問（Q&A）

### Q1. 非上場企業の株式価値評価で最も適切な方法は？

**A1.** 非上場企業の場合、目的に応じて複数の手法を併用することが一般的です。

#### 詳細説明
- **税務目的（相続・贈与）**: 財産評価基本通達に基づく評価（純資産価額方式、類似業種比準方式、配当還元方式）
- **M&A目的**: DCF法を中心に、類似会社比較法やコストアプローチを併用
- **少数株主間の売買**: 配当還元法や純資産法が使われることが多い

### Q2. DCF法でWACCはどのように決定すべきか？

**A2.** WACCは以下の要素を考慮して算定します。

#### 計算式と構成要素
```
WACC = E/(E+D) × Re + D/(E+D) × Rd × (1-Tc)
```
- E: 株式時価総額
- D: 有利子負債時価
- Re: 株主資本コスト（CAPMで算定）
- Rd: 負債コスト
- Tc: 実効税率

実務では業界平均や類似企業のWACCを参考にすることも多い。

## 7. まとめ・今後の展望

株式価値評価は、企業活動の様々な場面で必要となる重要なスキルです。コストアプローチ、インカムアプローチ、マーケットアプローチそれぞれに長所と短所があり、評価目的や対象企業の特性に応じて適切に選択・併用することが重要です。今後は、ESG要素の反映、無形資産の評価、AIを活用した評価手法の高度化などが進展すると予想されます。

### 問題1
株式価値と企業価値の関係として正しいものはどれか。

- A) 株式価値 = 企業価値 + 有利子負債
- B) 株式価値 = 企業価値 - 純有利子負債
- C) 株式価値 = 企業価値 × 発行済株式数
- D) 株式価値 = 企業価値 ÷ 純資産

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
株式価値は企業価値から純有利子負債（有利子負債-現預金）を控除して算定します。企業価値は事業全体の価値であり、それから債権者に帰属する部分を差し引いたものが株主に帰属する株式価値となります。<br>
<br>
Aが間違いの理由：有利子負債を加算するのではなく控除する<br>
Cが間違いの理由：発行済株式数を乗じるのではなく、企業価値から負債を控除する<br>
Dが間違いの理由：純資産で除するという関係ではない
</details>

- D) 資産保有型企業の評価に向いている

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
コストアプローチは現在の資産・負債の価値に着目する手法であり、将来の収益力を十分に反映しないことが特徴（欠点）です。<br>
<br>
Aが正しい理由：コストアプローチは純資産価値に基づく評価手法<br>
Cが正しい理由：清算時の換金価値を把握するのに適している<br>
Dが正しい理由：不動産保有会社など資産価値が重要な企業に適している
</details>

### 問題8

- A) 株主資本コスト

- C) 実効税率
- D) 売上高成長率

<details>
<summary>解答</summary>
<strong>正解: D</strong><br>

</details>

### 問題9

- A) 市場での流動性のみ
- B) 税務上の評価と経済的評価の両面

【補足】税務上の評価が低くても、実際の価値が高い場合は後継者の資金負担を考慮する必要があり、逆の場合は税務リスクを検討する必要があります。
</details>

### 問題10
DCF法によるFCF100、WACC10%、永続成長率2%の場合のターミナルバリューはいくらか。

- A) 1,000
- B) 1,250
- C) 1,275
- D) 1,500

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
ターミナルバリュー = FCF × (1+g) ÷ (WACC-g) = 100 × 1.02 ÷ (0.10-0.02) = 102 ÷ 0.08 = 1,275<br>
<br>
計算の詳細：<br>
1. 翌年のFCF：100 × (1+0.02) = 102<br>
2. 資本コストと成長率の差：0.10 - 0.02 = 0.08<br>
3. ターミナルバリュー：102 ÷ 0.08 = 1,275
</details>

- B) 株式価値 = 年間配当金 × 配当性向
- C) 株式価値 = 年間配当金 ÷ 純利益
- D) 株式価値 = 年間配当金 × PER

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>

株式価値 = 100円 ÷ 0.05 = 2,000円
</details>

### 問題15
EV/EBITDA倍率を用いた評価で、EBITDA10億円、倍率8倍、純有利子負債20億円の場合の株式価値はいくらか。

- A) 60億円
- B) 80億円
- C) 100億円
- D) 120億円

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
企業価値(EV) = EBITDA × 倍率 = 10億円 × 8倍 = 80億円<br>
株式価値 = 企業価値 - 純有利子負債 = 80億円 - 20億円 = 60億円<br>
<br>
計算プロセス：<br>
1. 企業価値の算定：10億円 × 8 = 80億円<br>
2. 株式価値への変換：80億円 - 20億円 = 60億円
</details>

## 9. 専門用語集

このスライドで使用された専門用語について、50音順で解説します。

### アルファベット

**DCF法（Discounted Cash Flow Method）**
- **読み方**: ディーシーエフほう
- **意味**: 将来のフリーキャッシュフローを現在価値に割り引いて企業価値を算定する手法
- **関連用語**: NPV（正味現在価値）、IRR（内部収益率）

**EBITDA（Earnings Before Interest, Taxes, Depreciation and Amortization）**
- **読み方**: イービットディーエー、イービッダ
- **意味**: 利息・税金・減価償却前利益。企業の本業での稼ぐ力を示す指標
- **関連用語**: EBIT、営業利益

**EV（Enterprise Value）**
- **読み方**: イーブイ、エンタープライズバリュー
- **意味**: 企業価値。事業価値に非事業用資産を加えた企業全体の価値
- **関連用語**: 株式価値、時価総額

**FCF（Free Cash Flow）**
- **読み方**: エフシーエフ、フリーキャッシュフロー
- **意味**: 企業が事業活動から生み出す自由に使える現金流量
- **関連用語**: 営業キャッシュフロー、投資キャッシュフロー

**PBR（Price Book-value Ratio）**
- **読み方**: ピービーアール
- **意味**: 株価純資産倍率。株価が1株当たり純資産の何倍かを示す指標
- **関連用語**: PER、ROE

**PER（Price Earnings Ratio）**
- **読み方**: ピーイーアール、パー
- **意味**: 株価収益率。株価が1株当たり利益の何倍かを示す指標
- **関連用語**: EPS、益回り

**WACC（Weighted Average Cost of Capital）**
- **読み方**: ワック
- **意味**: 加重平均資本コスト。企業の資金調達コストを加重平均したもの
- **関連用語**: 株主資本コスト、負債コスト

### あ行

**インカムアプローチ**
- **読み方**: いんかむあぷろーち
- **意味**: 将来の収益やキャッシュフローに基づいて企業価値を評価する手法
- **関連用語**: DCF法、収益還元法、配当還元法

**永続成長率（えいぞくせいちょうりつ）**
- **読み方**: えいぞくせいちょうりつ
- **意味**: DCF法において、予測期間以降の永続的な成長率の仮定
- **関連用語**: ターミナルバリュー、ゴーイングコンサーン

**益回り（えきまわり）**
- **読み方**: えきまわり
- **意味**: 1株当たり利益を株価で除した値。PERの逆数
- **関連用語**: PER、配当利回り

### か行

**加重平均（かじゅうへいきん）**
- **読み方**: かじゅうへいきん
- **意味**: 各要素の重要度（ウェイト）を考慮した平均値
- **関連用語**: 単純平均、WACC

**株式価値（かぶしきかち）**
- **読み方**: かぶしきかち
- **意味**: 企業の株式の経済的価値。企業価値から負債価値を控除したもの
- **関連用語**: 企業価値、時価総額

**株主資本コスト（かぶぬししほんこすと）**
- **読み方**: かぶぬししほんこすと
- **意味**: 株主が要求する期待収益率。CAPMなどで算定
- **関連用語**: WACC、CAPM、リスクプレミアム

**企業価値（きぎょうかち）**
- **読み方**: きぎょうかち
- **意味**: 企業全体の経済的価値。株式価値と負債価値の合計
- **関連用語**: EV、株式価値、事業価値

**コストアプローチ**
- **読み方**: こすとあぷろーち
- **意味**: 企業の純資産に着目して価値を評価する手法
- **関連用語**: 簿価純資産法、時価純資産法

### さ行

**財産評価基本通達（ざいさんひょうかきほんつうたつ）**
- **読み方**: ざいさんひょうかきほんつうたつ
- **意味**: 相続税・贈与税の課税価格計算の基準を定めた国税庁通達
- **関連用語**: 純資産価額方式、類似業種比準方式

**時価純資産法（じかじゅんしさんほう）**
- **読み方**: じかじゅんしさんほう
- **意味**: 資産・負債を時価評価して純資産価値を算定する手法
- **関連用語**: 簿価純資産法、含み損益

**収益還元法（しゅうえきかんげんほう）**
- **読み方**: しゅうえきかんげんほう
- **意味**: 将来の収益を資本還元率で除して価値を算定する手法
- **関連用語**: 配当還元法、インカムアプローチ

**純資産価額方式（じゅんしさんかがくほうしき）**
- **読み方**: じゅんしさんかがくほうしき
- **意味**: 財産評価基本通達における評価方式の一つ
- **関連用語**: 財産評価基本通達、相続税評価

**純有利子負債（じゅんゆうりしふさい）**
- **読み方**: じゅんゆうりしふさい
- **意味**: 有利子負債から現預金を控除した実質的な負債額
- **関連用語**: ネットデット、有利子負債

### た行

**ターミナルバリュー**
- **読み方**: たーみなるばりゅー
- **意味**: DCF法における予測期間以降の価値。継続価値、残存価値とも呼ばれる
- **関連用語**: 永続成長率、DCF法

**ディスカウント**
- **読み方**: でぃすかうんと
- **意味**: 割引。将来価値を現在価値に換算すること、または価値の減額
- **関連用語**: 現在価値、割引率、少数株主ディスカウント

### は行

**配当還元法（はいとうかんげんほう）**
- **読み方**: はいとうかんげんほう
- **意味**: 将来の配当金を還元利回りで除して株式価値を算定する手法
- **関連用語**: 配当利回り、インカムアプローチ

**配当還元方式（はいとうかんげんほうしき）**
- **読み方**: はいとうかんげんほうしき
- **意味**: 財産評価基本通達における少数株主の株式評価方式
- **関連用語**: 財産評価基本通達、少数株主

**簿価純資産法（ぼかじゅんしさんほう）**
- **読み方**: ぼかじゅんしさんほう
- **意味**: 会計上の簿価ベースで純資産価値を算定する手法
- **関連用語**: 時価純資産法、コストアプローチ

**プレミアム**
- **読み方**: ぷれみあむ
- **意味**: 割増価値。支配権プレミアムなど、特定の価値に対する上乗せ分
- **関連用語**: 支配権プレミアム、コントロールプレミアム

### ま行

**マーケットアプローチ**
- **読み方**: まーけっとあぷろーち
- **意味**: 市場での取引価格や類似企業との比較により価値を評価する手法
- **関連用語**: 市場株価法、類似会社比較法、マルチプル法

**マルチプル**
- **読み方**: まるちぷる
- **意味**: 評価倍率。PER、PBR、EV/EBITDA倍率などの総称
- **関連用語**: 類似会社比較法、PER、PBR

### や行

**有利子負債（ゆうりしふさい）**
- **読み方**: ゆうりしふさい
- **意味**: 利息の支払いが必要な負債。借入金、社債など
- **関連用語**: 純有利子負債、負債コスト

### ら行

**類似会社比較法（るいじがいしゃひかくほう）**
- **読み方**: るいじがいしゃひかくほう
- **意味**: 類似した上場企業の評価倍率を用いて価値を算定する手法
- **関連用語**: マルチプル法、マーケットアプローチ

**類似業種比準方式（るいじぎょうしゅひじゅんほうしき）**
- **読み方**: るいじぎょうしゅひじゅんほうしき
- **意味**: 財産評価基本通達における評価方式の一つ。類似業種の上場企業を参考に評価
- **関連用語**: 財産評価基本通達、相続税評価

### わ行

**割引率（わりびきりつ）**
- **読み方**: わりびきりつ
- **意味**: 将来価値を現在価値に換算する際に使用する率
- **関連用語**: WACC、現在価値、DCF法
