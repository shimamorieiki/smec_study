# MM理論について

## 概要

MM理論（Modigliani-Miller theorem）は、1958年にフランコ・モディリアーニとマートン・ミラーによって提唱された企業財務の基礎理論です。企業価値と資本構成の関係を理論的に説明した画期的な理論で、現代ファイナンス理論の礎となっています。

## 1. 基本概念・定義

### MM理論の前提条件
MM理論は以下の完全資本市場の仮定の下で成立します：

1. **取引費用がゼロ**: 証券の売買に手数料などのコストがかからない
2. **税金が存在しない**: 法人税、所得税などが存在しない（初期の理論）
3. **情報の非対称性がない**: すべての投資家が同じ情報を持っている
4. **破産コストがない**: 企業が倒産しても追加的なコストが発生しない
5. **借入利子率が同一**: 企業も個人も同じ利子率で借入可能
6. **投資政策は固定**: 資本構成の変更が投資決定に影響しない

### 企業価値の定義
- **企業価値（V）**: 負債価値（D）+ 株式価値（E）
- **総資産**: 企業が保有する資産の合計
- **レバレッジ**: 負債比率（D/V）

## 2. MM命題I（無税の場合）

### 命題の内容
「完全資本市場においては、企業価値は資本構成に依存しない」

**数式表現:**
```
VL = VU
```
- VL: レバレッジ企業（負債を利用する企業）の価値
- VU: アンレバレッジ企業（負債を利用しない企業）の価値

### 理論的説明
投資家は企業のレバレッジを「自家製レバレッジ」で複製できるため、企業の資本構成は企業価値に影響しません。

### 具体的計算例

#### ケース1: 企業比較による証明

**前提条件:**
- 企業A（アンレバレッジ企業）と企業B（レバレッジ企業）
- 両企業の営業利益（EBIT）: 1,000万円
- 企業Bの負債: 5,000万円（利子率5%）
- 資本還元率: 10%

**企業Aの価値計算:**
```
VU = EBIT / 資本還元率
VU = 1,000万円 / 0.10 = 10,000万円
```

**企業Bの価値計算（MM理論による）:**
```
VL = VU = 10,000万円
```

**検証:**
- 企業Bの利払い: 5,000万円 × 0.05 = 250万円
- 企業Bの株主への配当: 1,000万円 - 250万円 = 750万円
- 企業Bの株式価値: VL - D = 10,000万円 - 5,000万円 = 5,000万円

#### ケース2: 裁定取引による証明

**状況設定:**
仮に企業Bの価値が11,000万円だった場合（過大評価）

**裁定取引の手順:**
1. 企業Bの株式を1%売却: 60万円を得る（株式価値6,000万円の1%）
2. 企業Aの株式を1%購入: 100万円必要
3. 個人で借入: 50万円（企業Bの負債5,000万円の1%）
4. 差額: 60万円 + 50万円 - 100万円 = 10万円の利益

この裁定取引により、企業価値は均衡します。

## 3. MM命題II（無税の場合）

### 命題の内容
「株主の期待収益率は、企業の負債比率の増加に伴い直線的に上昇する」

**数式表現:**
```
rE = rA + (rA - rD) × (D/E)
```
- rE: 株主の期待収益率
- rA: 総資産利益率（WACC）
- rD: 負債利子率
- D/E: 負債・株主資本比率

### 理論的説明
レバレッジの増加は財務リスクを高めるため、株主はより高い収益率を要求します。

### 具体的計算例

#### ケース: レバレッジ変化による株主期待収益率の変化

**前提条件:**
- 総資産利益率（rA）: 10%
- 負債利子率（rD）: 5%
- 企業価値: 10,000万円

**パターンA: 負債比率30%の場合**
- 負債（D）: 3,000万円
- 株式（E）: 7,000万円
- D/E: 3,000/7,000 = 0.43

```
rE = 0.10 + (0.10 - 0.05) × 0.43
rE = 0.10 + 0.05 × 0.43
rE = 0.10 + 0.0215
rE = 0.1215 = 12.15%
```

**パターンB: 負債比率50%の場合**
- 負債（D）: 5,000万円
- 株式（E）: 5,000万円
- D/E: 5,000/5,000 = 1.0

```
rE = 0.10 + (0.10 - 0.05) × 1.0
rE = 0.10 + 0.05 × 1.0
rE = 0.10 + 0.05
rE = 0.15 = 15%
```

**WACC（加重平均資本コスト）の確認:**
```
WACC = rE × (E/V) + rD × (D/V)
パターンA: 0.1215 × 0.7 + 0.05 × 0.3 = 0.10
パターンB: 0.15 × 0.5 + 0.05 × 0.5 = 0.10
```

両パターンでWACCは10%で一定です。

## 4. 法人税を考慮した場合

### 修正MM命題I（法人税考慮）
「法人税が存在する場合、レバレッジ企業の価値は負債の節税効果分だけ高くなる」

**数式表現:**
```
VL = VU + T × D
```
- T: 法人税率
- T × D: 節税効果の現在価値

### 節税効果の仕組み
支払利息は税務上の損金となるため、法人税を節約できます。

### 具体的計算例

**前提条件:**
- EBIT: 1,000万円
- 法人税率: 30%
- 負債: 5,000万円（利子率5%）

**アンレバレッジ企業の価値:**
```
税引後利益 = EBIT × (1 - T) = 1,000万円 × 0.7 = 700万円
VU = 700万円 / 0.10 = 7,000万円
```

**レバレッジ企業の価値:**
```
VL = VU + T × D
VL = 7,000万円 + 0.3 × 5,000万円
VL = 7,000万円 + 1,500万円
VL = 8,500万円
```

**節税効果の詳細計算:**
```
年間節税額 = 支払利息 × 税率
年間節税額 = 250万円 × 0.3 = 75万円
節税効果の現在価値 = 75万円 / 0.05 = 1,500万円
```

## 5. 実務上の注意点

### MM理論の限界
1. **破産コスト**: 実際には倒産時に追加コストが発生
2. **エージェンシーコスト**: 株主と債権者の利害対立によるコスト
3. **情報の非対称性**: 経営者と投資家の情報格差
4. **取引コスト**: 実際の市場では各種手数料が存在
5. **税制の複雑性**: 個人所得税、キャピタルゲイン税なども影響

### 実務での活用
1. **最適資本構成の探索**: 節税効果と破産コストのトレードオフ
2. **企業価値評価**: M&A時の理論的基準
3. **資金調達戦略**: 負債と株式の選択基準
4. **投資判断**: レバレッジ効果の理解

### トレードオフ理論
実務では、MM理論を発展させたトレードオフ理論が使用されます：
- 最適負債比率 = 節税効果の限界便益 = 財務困難コストの限界費用

## 6. よくある質問（Q&A）

### Q1. なぜ完全市場の仮定が必要なのですか？

**A1.** 完全市場の仮定は、資本構成以外の要因を排除し、純粋に資本構成が企業価値に与える影響を分析するために必要です。

#### 詳細説明
現実の市場には様々な摩擦要因（取引コスト、税金、情報の非対称性など）が存在します。これらをすべて考慮すると、資本構成の純粋な効果を見極めることが困難になります。完全市場の仮定により、まず理論的な基準点を確立し、その後に現実的な要因を追加していくアプローチが可能になります。

### Q2. 自家製レバレッジとは何ですか？

**A2.** 投資家が個人的に借入を行うことで、企業のレバレッジと同じ効果を作り出すことです。

#### 詳細説明
例えば、レバレッジのない企業の株式を購入する際に、個人で借入を行えば、レバレッジ企業への投資と同じリスク・リターンプロファイルを実現できます。逆に、レバレッジ企業の株式と社債を適切な比率で購入すれば、アンレバレッジ企業への投資と同等になります。

### Q3. 実際の企業はどの程度の負債比率を選択すべきですか？

**A3.** 業界特性、事業の安定性、成長段階などを考慮し、節税効果と財務リスクのバランスを取る必要があります。

#### 実務的な判断基準
1. **安定した業界**: 負債比率40-60%程度
2. **成長産業**: 負債比率20-40%程度
3. **成熟産業**: 負債比率50-70%程度
4. **景気敏感業種**: 負債比率は低めに設定

### Q4. MM理論は現実の企業財務に役立ちますか？

**A4.** MM理論は理想的な条件下での理論ですが、現実の意思決定の出発点として重要な示唆を提供します。

#### 実務での活用方法
1. **ベンチマーク**: 理論値からの乖離を分析
2. **感度分析**: 各種前提条件の変化による影響を評価
3. **戦略立案**: 資本構成変更の効果を予測
4. **企業価値評価**: M&Aや投資判断の基準

## 7. まとめ・今後の展望

MM理論は、企業財務理論の基礎として、以下の重要な洞察を提供しています：

1. **完全市場では資本構成は無関係**: 理論的な基準点の確立
2. **法人税の存在下では負債に価値**: 節税効果の定量化
3. **現実の市場では最適資本構成が存在**: 各種コストとのトレードオフ

今後は、行動ファイナンスやESG要因を組み込んだ、より現実的な資本構成理論の発展が期待されます。

MM理論は、M&Aや資本政策の検討において、企業価値評価の理論的基準として活用されます。現実との乖離を分析することで、より精緻な評価が可能となります。
</details>

### 問題18
破産コストには含まれないものは？

- A) 弁護士費用
- B) 顧客の信頼喪失
- C) 通常の支払利息
- D) 優秀な人材の流出

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
通常の支払利息は破産コストではなく、通常の事業運営における金融費用です。破産コストには直接費用（弁護士費用など）と間接費用（信頼喪失、人材流出など）が含まれます。
</details>

### 問題19
法人税率が上昇した場合、最適負債比率はどうなるか？

- A) 上昇する
- B) 低下する
- C) 変化しない
- D) 企業規模による

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
法人税率の上昇は負債の節税効果を増大させるため、トレードオフ理論によれば最適負債比率は上昇します。より多くの負債を利用することが有利になります。
</details>

### 問題20
MM理論の貢献として最も重要なものは？

- A) 完全な資本構成の決定方法を示した
- B) 企業財務の理論的分析枠組みを確立した
- C) すべての企業に適用可能な公式を提供した
- D) 税金の影響を完全に解明した

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
MM理論の最大の貢献は、企業財務を理論的に分析する枠組みを確立したことです。完全市場の仮定から出発し、現実的な要因を段階的に導入する分析手法は、現代ファイナンス理論の基礎となっています。
</details>

## 9. 専門用語集

### アルファベット

**D/E ratio（Debt-to-Equity ratio）**
- **読み方**: ディーイーレシオ
- **意味**: 負債株主資本比率。企業の負債を株主資本で割った値で、財務レバレッジの指標
- **関連用語**: 財務レバレッジ、資本構成

**EBIT（Earnings Before Interest and Taxes）**
- **読み方**: イービット
- **意味**: 利払前税引前利益。支払利息と税金を控除する前の利益で、営業利益とほぼ同義
- **関連用語**: 営業利益、EBITDA

**MM理論（Modigliani-Miller theorem）**
- **読み方**: エムエムりろん
- **意味**: モディリアーニとミラーが提唱した、企業価値と資本構成の関係に関する理論
- **関連用語**: 資本構成、企業価値

**ROE（Return on Equity）**
- **読み方**: アールオーイー
- **意味**: 株主資本利益率。純利益を株主資本で割った値で、株主にとっての収益性指標
- **関連用語**: ROA、財務レバレッジ

**WACC（Weighted Average Cost of Capital）**
- **読み方**: ワック
- **意味**: 加重平均資本コスト。負債コストと株主資本コストを資本構成で加重平均した値
- **関連用語**: 資本コスト、割引率

### あ行

**アンレバレッジ企業（あんればれっじきぎょう）**
- **意味**: 負債を利用せず、すべて株主資本で資金調達している企業
- **関連用語**: レバレッジ企業、無借金経営

**エージェンシーコスト（えーじぇんしーこすと）**
- **意味**: 利害関係者間の利益相反から生じるコスト。株主と経営者、株主と債権者の間で発生
- **関連用語**: コーポレートガバナンス、利害対立

### か行

**加重平均資本コスト（かじゅうへいきんしほんこすと）**
- **意味**: 企業の資金調達コストを資本構成で加重平均したもの。WACCとも呼ばれる
- **関連用語**: 資本コスト、割引率

**株主資本コスト（かぶぬししほんこすと）**
- **意味**: 株主が要求する期待収益率。企業が株主資本を使用するためのコスト
- **関連用語**: 負債コスト、CAPM

**企業価値（きぎょうかち）**
- **意味**: 企業全体の価値。理論的には将来キャッシュフローの現在価値の合計
- **関連用語**: 株式価値、時価総額

### さ行

**財務困難コスト（ざいむこんなんこすと）**
- **意味**: 企業が財務的困難に陥った際に発生する直接・間接のコスト
- **関連用語**: 破産コスト、倒産リスク

**財務レバレッジ（ざいむればれっじ）**
- **意味**: 負債を利用して投資収益率を高める効果。総資産/株主資本で測定
- **関連用語**: D/E比率、レバレッジ効果

**自家製レバレッジ（じかせいればれっじ）**
- **意味**: 投資家が個人的に借入を行い、企業のレバレッジと同じ効果を作り出すこと
- **関連用語**: 裁定取引、MM理論

**資本構成（しほんこうせい）**
- **意味**: 企業の資金調達源泉（負債と株主資本）の構成比率
- **関連用語**: 最適資本構成、財務政策

**節税効果（せつぜいこうか）**
- **意味**: 負債利用により支払利息が損金算入され、法人税が軽減される効果
- **関連用語**: タックスシールド、税務メリット

### た行

**タックスシールド（たっくすしーるど）**
- **意味**: 支払利息などの損金算入により得られる節税効果。税の盾とも呼ばれる
- **関連用語**: 節税効果、法人税

**トレードオフ理論（とれーどおふりろん）**
- **意味**: 負債の節税効果と財務困難コストのバランスで最適資本構成が決まるという理論
- **関連用語**: MM理論、最適資本構成

### は行

**破産コスト（はさんこすと）**
- **意味**: 企業が倒産する際に発生する直接費用（法的費用など）と間接費用（信用失墜など）
- **関連用語**: 財務困難コスト、倒産リスク

**ペッキングオーダー理論（ぺっきんぐおーだーりろん）**
- **意味**: 情報の非対称性により、内部留保→負債→株式の順で資金調達するという理論
- **関連用語**: 情報の非対称性、資金調達順位

### ま行

**ミラーの修正モデル（みらーのしゅうせいもでる）**
- **意味**: 個人所得税を考慮したMM理論の拡張。Miller（1977）により提案
- **関連用語**: MM理論、個人所得税

### ら行

**レバレッジ企業（ればれっじきぎょう）**
- **意味**: 負債を利用して資金調達を行っている企業
- **関連用語**: アンレバレッジ企業、財務レバレッジ

**レバレッジ効果（ればれっじこうか）**
- **意味**: 負債利用により株主資本利益率が増幅される効果。正負両方向に作用
- **関連用語**: 財務レバレッジ、リスク・リターン
