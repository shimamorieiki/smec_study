# 商品売買の仕訳について

## 商品売買取引の概要

商品売買は企業活動の中核をなす取引であり、商品の仕入れから販売、そして代金の回収まで一連の流れがあります。商品売買の仕訳は、企業の主要な収益源である売上高と、その原価である仕入高を正確に記録するために重要です。現代の商取引では、現金取引だけでなく、掛取引、手形取引、クレジットカード取引など多様な決済方法が用いられています。

## 1. 商品売買の記帳方法

### 三分法
- **定義**: 商品勘定を「仕入」「売上」「繰越商品」の3つに分けて記帳する方法
- **特徴**: 最も一般的な方法で、期中は仕入原価と売価で記録し、期末に売上原価を算定
- **重要性**: 中小企業で広く採用され、日商簿記検定でも基本となる方法

### 分記法
- **定義**: 商品の売買時に売上原価と商品売買益を分けて記帳する方法
- **特徴**: 取引ごとに利益が把握できるが、実務では使用頻度が低い
- **重要性**: 理論的には正確だが、商品の原価管理が必要

### 売上原価対立法
- **定義**: 売上と売上原価を対応させて記帳する方法
- **特徴**: 売上総利益が常に把握できる
- **重要性**: 大企業や上場企業で採用されることが多い

## 2. 商品売買の基本仕訳

### 仕入取引の仕訳パターン
| 取引内容 | 借方 | 貸方 |
|----------|------|------|
| 現金仕入 | 仕入 | 現金 |
| 掛仕入 | 仕入 | 買掛金 |
| 手形仕入 | 仕入 | 支払手形 |
| 前払仕入 | 前払金→仕入 | 現金→前払金 |

### 売上取引の仕訳パターン
| 取引内容 | 借方 | 貸方 |
|----------|------|------|
| 現金売上 | 現金 | 売上 |
| 掛売上 | 売掛金 | 売上 |
| 手形売上 | 受取手形 | 売上 |
| 前受売上 | 前受金→現金 | 売上→前受金 |

### 値引・返品・割戻の処理
| 取引内容 | 処理方法 |
|----------|----------|
| 仕入値引 | 仕入の減少として処理 |
| 売上値引 | 売上の減少として処理 |
| 仕入返品 | 仕入の減少として処理 |
| 売上返品 | 売上の減少として処理 |
| 仕入割戻 | 仕入の減少として処理 |
| 売上割戻 | 売上の減少として処理 |

## 3. 具体的計算例・事例

### ケース1: 商品の仕入取引

#### パターンA: 商品500,000円を仕入れ、代金のうち200,000円を現金で支払い、残額は掛けとした
- **前提条件**: 一部現金、一部掛けの複合取引
- **仕訳**:
  ```
  (借) 仕入 500,000 / (貸) 現金 200,000
                     / (貸) 買掛金 300,000
  ```
- **結果**: 仕入（費用）が増加し、現金（資産）が減少、買掛金（負債）が増加

#### パターンB: 商品800,000円を仕入れ、約束手形を振り出した。ただし、引取運賃5,000円を現金で支払った
- **前提条件**: 引取運賃は仕入原価に含める
- **仕訳**:
  ```
  (借) 仕入 805,000 / (貸) 支払手形 800,000
                     / (貸) 現金 5,000
  ```
- **結果**: 仕入原価に引取運賃を含めて計上

### ケース2: 商品の売上取引

#### パターンA: 商品1,000,000円を販売し、代金のうち400,000円を現金で受け取り、残額は掛けとした
- **前提条件**: 一部現金、一部掛けの複合取引
- **仕訳**:
  ```
  (借) 現金 400,000 / (貸) 売上 1,000,000
  (借) 売掛金 600,000
  ```
- **結果**: 現金と売掛金（資産）が増加し、売上（収益）が発生

#### パターンB: 商品1,200,000円を販売し、得意先振出の約束手形を受け取った。発送運賃10,000円を現金で支払った
- **前提条件**: 発送運賃は販売費として処理
- **仕訳**:
  ```
  (借) 受取手形 1,200,000 / (貸) 売上 1,200,000
  (借) 発送費 10,000 / (貸) 現金 10,000
  ```
- **結果**: 発送運賃は売上から控除せず、別途費用処理

### ケース3: 仕入値引・返品

#### パターンA: 買掛金500,000円のうち、品質不良により50,000円の値引きを受けた
- **前提条件**: 仕入後の値引き
- **仕訳**:
  ```
  (借) 買掛金 50,000 / (貸) 仕入 50,000
  ```
- **結果**: 買掛金（負債）が減少し、仕入（費用）が減少

#### パターンB: 仕入れた商品300,000円のうち100,000円分を品違いのため返品した（掛仕入）
- **前提条件**: 掛けで仕入れた商品の一部返品
- **仕訳**:
  ```
  (借) 買掛金 100,000 / (貸) 仕入 100,000
  ```
- **結果**: 返品により仕入と買掛金が同額減少

### ケース4: 売上値引・返品

#### パターンA: 売掛金800,000円のうち、80,000円の値引きを行った
- **前提条件**: 売上後の値引き
- **仕訳**:
  ```
  (借) 売上 80,000 / (貸) 売掛金 80,000
  ```
- **結果**: 売上（収益）が減少し、売掛金（資産）が減少

#### パターンB: 販売した商品600,000円のうち150,000円分が品違いのため返品された（掛売上）
- **前提条件**: 掛けで販売した商品の一部返品
- **仕訳**:
  ```
  (借) 売上 150,000 / (貸) 売掛金 150,000
  ```
- **結果**: 返品により売上と売掛金が同額減少

### ケース5: 仕入割戻・売上割戻

#### パターンA: 年間仕入高3,000,000円に対して3%の仕入割戻90,000円を現金で受け取った
- **前提条件**: リベートとして現金受取
- **仕訳**:
  ```
  (借) 現金 90,000 / (貸) 仕入 90,000
  ```
- **結果**: 現金（資産）が増加し、仕入（費用）が減少

#### パターンB: 年間売上高5,000,000円に対して2%の売上割戻100,000円を現金で支払った
- **前提条件**: 得意先へのリベート支払い
- **仕訳**:
  ```
  (借) 売上 100,000 / (貸) 現金 100,000
  ```
- **結果**: 売上（収益）が減少し、現金（資産）が減少

### ケース6: 諸掛りの処理

#### パターンA: 商品400,000円を仕入れ、引取運賃8,000円を現金で支払った（当社負担）
- **前提条件**: 引取運賃は仕入原価に算入
- **仕訳**:
  ```
  (借) 仕入 408,000 / (貸) 買掛金 400,000
                     / (貸) 現金 8,000
  ```
- **結果**: 引取運賃を含めた金額を仕入原価とする

#### パターンB: 商品700,000円を販売し、発送運賃15,000円を現金で立替払いした（先方負担）
- **前提条件**: 発送運賃は得意先負担
- **仕訳**:
  ```
  (借) 売掛金 715,000 / (貸) 売上 700,000
                       / (貸) 現金 15,000
  ```
- **結果**: 立替分を売掛金に含めて請求

## 4. 特殊な商品売買取引

### 委託販売
1. **委託品の発送時**: 
   ```
   (借) 積送品 xxx / (貸) 仕入 xxx
   ```
2. **売上計算書受取時**:
   ```
   (借) 売掛金 xxx / (貸) 積送品売上 xxx
   (借) 積送諸掛 xxx / (貸) 売掛金 xxx
   ```

### 受託販売
1. **委託品の受取時**: 仕訳なし（備忘記録のみ）
2. **委託品の販売時**:
   ```
   (借) 現金 xxx / (貸) 受託販売 xxx
   ```
3. **委託者への送金時**:
   ```
   (借) 受託販売 xxx / (貸) 現金 xxx（送金額）
                      / (貸) 受取手数料 xxx
   ```

### 試用販売
1. **試用品の発送時**:
   ```
   (借) 試用品 xxx / (貸) 仕入 xxx
   ```
2. **買取意思表示時**:
   ```
   (借) 売掛金 xxx / (貸) 試用品売上 xxx
   ```

### 予約販売
1. **予約金受取時**:
   ```
   (借) 現金 xxx / (貸) 前受金 xxx
   ```
2. **商品引渡時**:
   ```
   (借) 前受金 xxx / (貸) 売上 xxx
   ```

## 5. 実務上の注意点

### 商品売買仕訳の重要ポイント
- **ポイント1**: 仕入諸掛（引取運賃等）は仕入原価に含める
- **ポイント2**: 売上諸掛（発送運賃等）は売上から控除せず別途費用処理
- **ポイント3**: 値引・返品・割戻は総額から控除する純額処理
- **ポイント4**: 内税方式の場合は、税込価格で仕訳を行う
- **ポイント5**: 外税方式の場合は、本体価格と消費税を分けて処理

### よくある誤解・トラブル
- **誤解1**: 発送運賃を仕入原価に含めてしまう
  - 正しい理解: 発送運賃は販売費として処理（当社負担の場合）
- **誤解2**: 仕入値引を雑収入で処理してしまう
  - 正しい理解: 仕入値引は仕入の減少として処理
- **誤解3**: 売上割戻を販売費で処理してしまう
  - 正しい理解: 売上割戻は売上の減少として処理

## 6. よくある質問（Q&A）

### Q1. 仕入諸掛と売上諸掛の処理の違いは何ですか？

**A1.** 仕入諸掛は仕入原価に含め、売上諸掛は別途費用処理します。

#### 詳細説明
- **仕入諸掛（当社負担）**: 引取運賃、運送保険料、関税など商品を仕入れるために必要な費用は、すべて仕入原価に含めます。これは取得原価主義の考え方に基づきます。
- **売上諸掛（当社負担）**: 発送運賃、荷造費などは売上から控除せず、販売費として処理します。
- **理由**: 仕入諸掛は商品の取得に不可欠な費用であり、売上諸掛は販売活動に伴う費用だからです。

### Q2. 三分法で期末商品の評価はどのように行いますか？

**A2.** 決算整理で期首商品を仕入に振り替え、期末商品を仕入から繰越商品に振り替えます。

#### 詳細説明
決算整理仕訳：
1. 期首商品の振替: `(借) 仕入 xxx / (貸) 繰越商品 xxx`
2. 期末商品の振替: `(借) 繰越商品 xxx / (貸) 仕入 xxx`

この処理により、仕入勘定の残高が当期の売上原価となります。
売上原価 = 期首商品棚卸高 + 当期仕入高 - 期末商品棚卸高

### Q3. 消費税の処理方法による仕訳の違いは？

**A3.** 税込経理方式と税抜経理方式で仕訳が異なります。

#### 詳細説明
例：商品100,000円（税抜）を現金で仕入れた場合（消費税率10%）

**税込経理方式**:
```
(借) 仕入 110,000 / (貸) 現金 110,000
```

**税抜経理方式**:
```
(借) 仕入 100,000 / (貸) 現金 110,000
(借) 仮払消費税 10,000
```

税込経理方式は処理が簡単ですが、税抜経理方式は消費税額を明確に把握できる利点があります。

## 7. まとめ・今後の展望

商品売買の仕訳は、企業会計の中で最も頻繁に発生する取引であり、正確な処理が企業の業績把握に直結します。今後は、電子商取引の普及により、リアルタイムでの在庫管理や売上原価の把握がさらに重要になるでしょう。また、国際取引の増加に伴い、為替差損益の処理や輸出入に関する特殊な仕訳の理解も必要となってきています。

### 問題1
商品600,000円を仕入れ、引取運賃10,000円を現金で支払った場合の仕訳はどれか？

- A) (借) 仕入 600,000、引取運賃 10,000 / (貸) 買掛金 600,000、現金 10,000
- B) (借) 仕入 610,000 / (貸) 買掛金 600,000、現金 10,000
- C) (借) 仕入 600,000 / (貸) 買掛金 600,000、(借) 発送費 10,000 / (貸) 現金 10,000
- D) (借) 仕入 600,000、発送費 10,000 / (貸) 買掛金 610,000

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
引取運賃は仕入諸掛として仕入原価に含めるため、仕入610,000円（商品代金600,000円＋引取運賃10,000円）を借方に記録します。<br>
<br>
Aが間違いの理由：引取運賃を別勘定で処理している<br>
Cが間違いの理由：引取運賃を発送費として処理している<br>
Dが間違いの理由：買掛金に引取運賃を含めている
</details>

### 問題2
商品800,000円を販売し、発送運賃12,000円を現金で支払った場合の仕訳はどれか？（当社負担）

- A) (借) 売掛金 800,000、発送費 12,000 / (貸) 売上 800,000、現金 12,000
- B) (借) 売掛金 788,000 / (貸) 売上 788,000
- C) (借) 売掛金 800,000 / (貸) 売上 812,000、(借) 現金 12,000
- D) (借) 売掛金 812,000 / (貸) 売上 800,000、現金 12,000

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
売上諸掛（発送運賃）は売上から控除せず、販売費として別途処理します。売掛金800,000円と発送費12,000円を借方に、売上800,000円と現金12,000円を貸方に記録します。<br>
<br>
Bが間違いの理由：売上から発送運賃を控除している<br>
Cが間違いの理由：借方貸方の記述が不適切<br>
Dが間違いの理由：売掛金に発送運賃を含めている
</details>

### 問題3
買掛金1,000,000円のうち、品質不良により100,000円の値引きを受けた場合の仕訳はどれか？

- A) (借) 買掛金 100,000 / (貸) 仕入 100,000
- B) (借) 仕入 100,000 / (貸) 買掛金 100,000
- C) (借) 買掛金 100,000 / (貸) 雑収入 100,000
- D) (借) 仕入値引 100,000 / (貸) 買掛金 100,000

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
仕入値引は仕入の減少として処理します。買掛金（負債）の減少100,000円を借方に、仕入（費用）の減少100,000円を貸方に記録します。<br>
<br>
Bが間違いの理由：借方と貸方が逆<br>
Cが間違いの理由：仕入値引を雑収入で処理している<br>
Dが間違いの理由：仕入値引という勘定科目は使用しない
</details>

### 問題4
商品1,500,000円を仕入れ、代金の30%を現金で支払い、40%は約束手形を振り出し、残額は掛けとした場合の仕訳はどれか？

- A) (借) 仕入 1,500,000 / (貸) 現金 450,000、支払手形 600,000、買掛金 450,000
- B) (借) 仕入 1,500,000 / (貸) 現金 450,000、支払手形 450,000、買掛金 600,000
- C) (借) 仕入 1,500,000 / (貸) 現金 600,000、支払手形 450,000、買掛金 450,000
- D) (借) 仕入 1,500,000 / (貸) 現金 500,000、支払手形 500,000、買掛金 500,000

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
現金：1,500,000円×30%＝450,000円<br>
支払手形：1,500,000円×40%＝600,000円<br>
買掛金：1,500,000円×30%＝450,000円<br>
<br>
Bが間違いの理由：支払手形と買掛金の金額が逆<br>
Cが間違いの理由：現金の金額が40%で計算されている<br>
Dが間違いの理由：各支払方法の割合が正しく計算されていない
</details>

### 問題5
売掛金2,000,000円を回収し、2%の売上割引30,000円を認めて、差額を現金で受け取った場合の仕訳はどれか？（売上割引は売上の控除として処理）

- A) (借) 現金 1,970,000、売上 30,000 / (貸) 売掛金 2,000,000
- B) (借) 現金 1,970,000、売上割引 30,000 / (貸) 売掛金 2,000,000
- C) (借) 現金 1,970,000、支払利息 30,000 / (貸) 売掛金 2,000,000
- D) (借) 現金 2,000,000 / (貸) 売掛金 1,970,000、売上 30,000

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
売上割引を売上の控除として処理する場合、現金1,970,000円と売上30,000円を借方に、売掛金2,000,000円を貸方に記録します。計算：2,000,000円×2%＝40,000円ではなく、30,000円が正しい割引額です。<br>
<br>
Bが間違いの理由：売上割引勘定は売上の控除として処理する場合使用しない<br>
Cが間違いの理由：売上割引を支払利息で処理している<br>
Dが間違いの理由：借方貸方の金額配分が誤り
</details>

### 問題6
商品900,000円を販売し、代金として得意先振出の約束手形500,000円と、為替手形400,000円（当社が名宛人）を受け取った場合の仕訳はどれか？

- A) (借) 受取手形 900,000 / (貸) 売上 900,000
- B) (借) 受取手形 500,000、支払手形 400,000 / (貸) 売上 900,000
- C) (借) 約束手形 500,000、為替手形 400,000 / (貸) 売上 900,000
- D) (借) 受取手形 500,000、売掛金 400,000 / (貸) 売上 900,000

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>
約束手形も為替手形（引受済）も、受け取った場合はすべて受取手形勘定で処理します。受取手形（資産）900,000円を借方に、売上（収益）900,000円を貸方に記録します。<br>
<br>
Bが間違いの理由：為替手形の受取を支払手形で処理している<br>
Cが間違いの理由：約束手形、為替手形という勘定科目は使用しない<br>
Dが間違いの理由：為替手形の受取を売掛金で処理している
</details>

### 問題7
前期に仕入れた商品300,000円が品違いのため返品された場合の仕訳はどれか？（掛売上）

## 9. 専門用語集

### あ行
**委託販売（いたくはんばい）**
- **読み方**: いたくはんばい
- **意味**: 商品の所有権を保持したまま、他の業者に販売を委託する取引形態
- **関連用語**: 積送品、受託販売、売上計算書

**受取手形（うけとりてがた）**
- **読み方**: うけとりてがた
- **意味**: 約束手形や為替手形を受け取ったことによる債権
- **関連用語**: 支払手形、手形割引、裏書譲渡

**受託販売（じゅたくはんばい）**
- **読み方**: じゅたくはんばい
- **意味**: 他社から商品の販売を受託し、手数料を得る取引
- **関連用語**: 委託販売、受取手数料

**売上（うりあげ）**
- **読み方**: うりあげ
- **意味**: 商品やサービスの販売により得られる収益
- **関連用語**: 売上高、売上原価、売上総利益

**売上原価（うりあげげんか）**
- **読み方**: うりあげげんか
- **意味**: 売上に対応する商品の原価
- **関連用語**: 期首商品棚卸高、当期仕入高、期末商品棚卸高

**売上総利益（うりあげそうりえき）**
- **読み方**: うりあげそうりえき
- **意味**: 売上高から売上原価を差し引いた利益
- **関連用語**: 粗利益、売上高、売上原価

**売上値引（うりあげねびき）**
- **読み方**: うりあげねびき
- **意味**: 販売後に品質不良等の理由で認める価格の引下げ
- **関連用語**: 売上返品、売上割戻

**売上返品（うりあげへんぴん）**
- **読み方**: うりあげへんぴん
- **意味**: 販売した商品が品違い等で返品されること
- **関連用語**: 売上値引、返品

**売上割戻（うりあげわりもどし）**
- **読み方**: うりあげわりもどし
- **意味**: 一定期間の売上高に応じて支払うリベート
- **関連用語**: 売上値引、仕入割戻

### か行
**掛売上（かけうりあげ）**
- **読み方**: かけうりあげ
- **意味**: 商品を販売し、代金を後日受け取る取引
- **関連用語**: 売掛金、信用取引

**掛仕入（かけしいれ）**
- **読み方**: かけしいれ
- **意味**: 商品を仕入れ、代金を後日支払う取引
- **関連用語**: 買掛金、信用取引

**仮払消費税（かりばらいしょうひぜい）**
- **読み方**: かりばらいしょうひぜい
- **意味**: 仕入時に支払った消費税（税抜経理方式）
- **関連用語**: 仮受消費税、消費税

**仮受消費税（かりうけしょうひぜい）**
- **読み方**: かりうけしょうひぜい
- **意味**: 売上時に受け取った消費税（税抜経理方式）
- **関連用語**: 仮払消費税、消費税

**繰越商品（くりこししょうひん）**
- **読み方**: くりこししょうひん
- **意味**: 期末の商品在庫を表す勘定科目
- **関連用語**: 期首商品棚卸高、期末商品棚卸高

### さ行
**三分法（さんぶんほう）**
- **読み方**: さんぶんほう
- **意味**: 商品売買を仕入・売上・繰越商品の3つの勘定で記帳する方法
- **関連用語**: 分記法、売上原価対立法

**仕入（しいれ）**
- **読み方**: しいれ
- **意味**: 販売目的で商品を購入すること
- **関連用語**: 仕入高、売上原価

**仕入諸掛（しいれしょがかり）**
- **読み方**: しいれしょがかり
- **意味**: 引取運賃など仕入に付随して発生する費用
- **関連用語**: 引取運賃、仕入原価

**仕入値引（しいれねびき）**
- **読み方**: しいれねびき
- **意味**: 仕入後に品質不良等の理由で受ける価格の引下げ
- **関連用語**: 仕入返品、仕入割戻

**仕入返品（しいれへんぴん）**
- **読み方**: しいれへんぴん
- **意味**: 仕入れた商品を品違い等で返品すること
- **関連用語**: 仕入値引、返品

**仕入割戻（しいれわりもどし）**
- **読み方**: しいれわりもどし
- **意味**: 一定期間の仕入高に応じて受けるリベート
- **関連用語**: 仕入値引、売上割戻

**支払手形（しはらいてがた）**
- **読み方**: しはらいてがた
- **意味**: 約束手形や為替手形を振り出したことによる債務
- **関連用語**: 受取手形、手形

**試用販売（しようはんばい）**
- **読み方**: しようはんばい
- **意味**: 商品を試用させてから販売する方法
- **関連用語**: 試用品、買取意思表示

**商品売買益（しょうひんばいばいえき）**
- **読み方**: しょうひんばいばいえき
- **意味**: 商品の売価と原価の差額（分記法）
- **関連用語**: 分記法、売上総利益

**諸掛（しょがかり）**
- **読み方**: しょがかり
- **意味**: 運賃、保険料など取引に付随する費用
- **関連用語**: 仕入諸掛、売上諸掛

**税込経理方式（ぜいこみけいりほうしき）**
- **読み方**: ぜいこみけいりほうしき
- **意味**: 消費税を含めた金額で経理処理する方式
- **関連用語**: 税抜経理方式、消費税

**税抜経理方式（ぜいぬきけいりほうしき）**
- **読み方**: ぜいぬきけいりほうしき
- **意味**: 本体価格と消費税を分けて経理処理する方式
- **関連用語**: 税込経理方式、仮払消費税、仮受消費税

**積送品（せきそうひん）**
- **読み方**: せきそうひん
- **意味**: 委託販売のために発送した商品
- **関連用語**: 委託販売、積送品売上

### た行
**立替金（たてかえきん）**
- **読み方**: たてかえきん
- **意味**: 他者が負担すべき金額を一時的に支払った債権
- **関連用語**: 立替払い、預り金

**当期商品仕入高（とうきしょうひんしいれだか）**
- **読み方**: とうきしょうひんしいれだか
- **意味**: 当期中に仕入れた商品の総額
- **関連用語**: 売上原価、期首商品棚卸高、期末商品棚卸高

### は行
**発送費（はっそうひ）**
- **読み方**: はっそうひ
- **意味**: 商品の発送にかかる運賃等の費用
- **関連用語**: 売上諸掛、引取運賃

**引取運賃（ひきとりうんちん）**
- **読み方**: ひきとりうんちん
- **意味**: 仕入商品の運送にかかる費用
- **関連用語**: 仕入諸掛、発送費

**分記法（ぶんきほう）**
- **読み方**: ぶんきほう
- **意味**: 商品売買時に原価と利益を分けて記帳する方法
- **関連用語**: 三分法、商品売買益

### ま行
**前受金（まえうけきん）**
- **読み方**: まえうけきん
- **意味**: 商品引渡前に受け取った代金
- **関連用語**: 前払金、予約販売

**前払金（まえばらいきん）**
- **読み方**: まえばらいきん
- **意味**: 商品受取前に支払った代金
- **関連用語**: 前受金、手付金

### や行
**約束手形（やくそくてがた）**
- **読み方**: やくそくてがた
- **意味**: 振出人が名宛人に一定期日に支払うことを約束した証券
- **関連用語**: 為替手形、受取手形、支払手形

**予約販売（よやくはんばい）**
- **読み方**: よやくはんばい
- **意味**: 商品引渡前に注文を受けて行う販売
- **関連用語**: 前受金、予約金

### ら行
**リベート**
- **読み方**: りべーと
- **意味**: 取引高に応じて支払われる割戻金
- **関連用語**: 仕入割戻、売上割戻

### わ行
**割引（わりびき）**
- **読み方**: わりびき
- **意味**: 早期決済等の条件により認める代金の減額
- **関連用語**: 現金割引、売上割引

**割戻（わりもどし）**
- **読み方**: わりもどし
- **意味**: 一定期間の取引高に応じて行う事後的な値引き
- **関連用語**: リベート、仕入割戻、売上割戻
