# 決算整理仕訳について

## 決算整理仕訳の概要

決算整理仕訳は、期中の取引記録を決算日現在の正しい財政状態と経営成績を表示するために行う修正仕訳です。日々の取引では記録されない減価償却費の計上、売上原価の算定、経過勘定の調整、引当金の設定、棚卸資産の評価など、適正な期間損益計算と財政状態の表示に不可欠な処理を行います。これらの処理により、発生主義会計の原則に基づいた財務諸表が作成されます。

## 1. 決算整理の目的と種類

### 決算整理の目的
- **期間損益の適正化**: 当期に属する収益・費用を正確に計算
- **資産評価の適正化**: 決算日現在の適正な評価額を反映
- **債権債務の確定**: 未確定の債権債務を整理
- **法令・会計基準への準拠**: 各種規定に従った処理

### 主要な決算整理項目
| 分類 | 項目 |
|------|------|
| 売上原価の算定 | 期末商品棚卸高の計上（三分法） |
| 減価償却 | 有形・無形固定資産の減価償却 |
| 評価関連 | 有価証券評価、棚卸資産評価 |
| 引当金 | 貸倒引当金、賞与引当金、退職給付引当金 |
| 経過勘定 | 前払費用、未払費用、前受収益、未収収益 |
| その他 | 現金過不足、消耗品、法人税等 |

## 2. 決算整理仕訳の手順

### 決算整理前残高試算表の作成
1. **期中取引の集計**: すべての仕訳を総勘定元帳に転記
2. **残高試算表作成**: 各勘定の残高を一覧化
3. **貸借一致の確認**: 借方合計＝貸方合計を確認

### 決算整理仕訳の実施
1. **整理事項の把握**: 必要な決算整理を洗い出し
2. **必要情報の収集**: 棚卸表、固定資産台帳等
3. **仕訳の作成**: 各項目の決算整理仕訳
4. **転記と集計**: 総勘定元帳への転記

### 決算整理後残高試算表の作成
- **最終確認**: すべての整理仕訳を反映
- **財務諸表作成**: 貸借対照表、損益計算書の基礎

## 3. 具体的計算例・事例

### ケース1: 売上原価の算定（三分法）

#### パターンA: 期首商品300,000円、当期仕入2,000,000円、期末商品400,000円
- **前提条件**: 三分法による売上原価算定
- **仕訳**:
  ```
  (借) 仕入 300,000 / (貸) 繰越商品 300,000
  (借) 繰越商品 400,000 / (貸) 仕入 400,000
  ```
- **計算**: 売上原価 = 300,000 + 2,000,000 - 400,000 = 1,900,000円

#### パターンB: 期末商品の評価損50,000円がある場合（期末商品時価350,000円）
- **前提条件**: 低価法の適用
- **仕訳**:
  ```
  (借) 仕入 300,000 / (貸) 繰越商品 300,000
  (借) 繰越商品 350,000 / (貸) 仕入 350,000
  (借) 商品評価損 50,000 / (貸) 商品 50,000
  ```

### ケース2: 減価償却費の計上

#### パターンA: 建物（取得原価10,000,000円、残存価額10%、耐用年数20年、定額法）
- **前提条件**: 1年間の減価償却
- **計算**:
  ```
  年間償却額 = (10,000,000円 - 1,000,000円) ÷ 20年 = 450,000円
  ```
- **仕訳**:
  ```
  (借) 減価償却費 450,000 / (貸) 建物減価償却累計額 450,000
  ```

#### パターンB: 期中取得（7月1日）の機械（取得原価3,000,000円、償却率0.25、定率法）
- **前提条件**: 月割計算
- **計算**:
  ```
  当期償却額 = 3,000,000円 × 0.25 × 9/12 = 562,500円
  ```
- **仕訳**:
  ```
  (借) 減価償却費 562,500 / (貸) 機械装置減価償却累計額 562,500
  ```

### ケース3: 貸倒引当金の設定

#### パターンA: 売掛金残高3,000,000円、受取手形残高1,000,000円に対して2%設定（差額補充法、期首残高60,000円）
- **前提条件**: 一般債権に対する引当
- **計算**:
  ```
  必要額 = (3,000,000円 + 1,000,000円) × 2% = 80,000円
  繰入額 = 80,000円 - 60,000円 = 20,000円
  ```
- **仕訳**:
  ```
  (借) 貸倒引当金繰入 20,000 / (貸) 貸倒引当金 20,000
  ```

#### パターンB: 洗替法による処理（上記と同条件）
- **前提条件**: 洗替法の採用
- **仕訳**:
  ```
  (借) 貸倒引当金 60,000 / (貸) 貸倒引当金戻入 60,000
  (借) 貸倒引当金繰入 80,000 / (貸) 貸倒引当金 80,000
  ```

### ケース4: 経過勘定の整理

#### パターンA: 保険料年額120,000円を4月1日に支払済み（3月決算）
- **前提条件**: 翌期分の前払費用計上
- **計算**:
  ```
  前払分 = 120,000円 × 3/12 = 30,000円
  ```
- **仕訳**:
  ```
  (借) 前払費用 30,000 / (貸) 保険料 30,000
  ```

#### パターンB: 12月〜3月分の家賃400,000円が未払い（月額100,000円）
- **前提条件**: 未払費用の計上
- **仕訳**:
  ```
  (借) 地代家賃 400,000 / (貸) 未払費用 400,000
  ```

### ケース5: 有価証券の評価

#### パターンA: 売買目的有価証券（取得原価1,000,000円、時価1,200,000円）
- **前提条件**: 時価評価
- **仕訳**:
  ```
  (借) 売買目的有価証券 200,000 / (貸) 有価証券評価益 200,000
  ```

#### パターンB: その他有価証券（取得原価2,000,000円、時価1,800,000円）
- **前提条件**: 時価評価、税効果なし
- **仕訳**:
  ```
  (借) その他有価証券評価差額金 200,000 / (貸) その他有価証券 200,000
  ```

### ケース6: 引当金の計上

#### パターンA: 賞与引当金600,000円を計上（6月・12月支給、3月決算）
- **前提条件**: 4か月分（12月〜3月）を計上
- **仕訳**:
  ```
  (借) 賞与引当金繰入 600,000 / (貸) 賞与引当金 600,000
  ```

#### パターンB: 退職給付引当金800,000円を追加計上
- **前提条件**: 期末要支給額基準
- **仕訳**:
  ```
  (借) 退職給付費用 800,000 / (貸) 退職給付引当金 800,000
  ```

### ケース7: その他の決算整理

#### パターンA: 現金過不足（借方残高）5,000円の処理
- **前提条件**: 原因不明のまま決算
- **仕訳**:
  ```
  (借) 雑損失 5,000 / (貸) 現金過不足 5,000
  ```

#### パターンB: 消耗品の期末在庫30,000円（購入時に消耗品費処理）
- **前提条件**: 貯蔵品への振替
- **仕訳**:
  ```
  (借) 貯蔵品 30,000 / (貸) 消耗品費 30,000
  ```

## 4. 決算整理の実務

### 決算スケジュール
1. **実地棚卸**: 商品、製品、原材料等の数量確認
2. **残高確認**: 現金、預金、債権債務の照合
3. **評価作業**: 時価評価、減損判定等
4. **仕訳作成**: 各種決算整理仕訳
5. **帳簿締切**: 損益振替、資本振替

### 精算表の作成
| 項目 | 残高試算表 | 決算整理 | 損益計算書 | 貸借対照表 |
|------|------------|----------|------------|------------|
| 各勘定科目 | 期中残高 | 整理仕訳 | 収益・費用 | 資産・負債・純資産 |

### 税務調整
- **税効果会計**: 会計上と税務上の差異調整
- **申告調整**: 損金不算入項目等の調整
- **別表作成**: 法人税申告書の作成

## 5. 実務上の注意点

### 決算整理の重要ポイント
- **ポイント1**: 決算整理事項のチェックリストを作成し、漏れを防ぐ
- **ポイント2**: 前期の決算整理仕訳を参考に、継続性を保つ
- **ポイント3**: 監査や税務調査に備え、根拠資料を整備する
- **ポイント4**: 重要性の原則を考慮し、効率的に処理する
- **ポイント5**: 決算日後の後発事象にも注意を払う

### よくある誤解・トラブル
- **誤解1**: 決算整理は決算日に行うものと考える
  - 正しい理解: 決算日後の決算作業期間中に行う
- **誤解2**: 前期と同じ金額で引当金を計上する
  - 正しい理解: 毎期、適正額を見積もる必要がある
- **誤解3**: 売上原価を売上高から逆算して求める
  - 正しい理解: 棚卸資産の実地棚卸に基づいて計算する

## 6. よくある質問（Q&A）

### Q1. なぜ決算整理仕訳が必要なのですか？

**A1.** 期中の記録だけでは正確な財政状態と経営成績を表示できないためです。

#### 詳細説明
決算整理が必要な理由：
1. **発生主義の適用**: 現金の動きがなくても発生している損益の計上
2. **期間対応**: 費用と収益を適切な会計期間に配分
3. **資産の評価**: 決算日現在の適正な価値を反映
4. **将来の支出に備える**: 引当金により将来の支出に備える

例えば、減価償却費は日々の取引では記録されませんが、資産の価値減少を適切に反映するために決算整理で計上します。

### Q2. 三分法による売上原価の算定方法を教えてください。

**A2.** 期首商品を仕入に振り替え、期末商品を仕入から繰越商品に振り替えます。

#### 詳細説明
三分法の仕訳：
1. **期首商品の振替**
   ```
   (借) 仕入 xxx / (貸) 繰越商品 xxx
   ```
2. **期末商品の振替**
   ```
   (借) 繰越商品 xxx / (貸) 仕入 xxx
   ```

この結果、仕入勘定の残高が売上原価となります：
売上原価 = 期首商品棚卸高 + 当期仕入高 - 期末商品棚卸高

### Q3. 決算整理後の帳簿の締切り方は？

**A3.** 損益勘定への振替→当期純損益の確定→繰越利益剰余金への振替の順で行います。

#### 詳細説明
帳簿の締切手順：
1. **収益・費用の損益勘定への振替**
   - 収益：借方から損益勘定の貸方へ
   - 費用：貸方から損益勘定の借方へ

2. **当期純損益の振替**
   - 利益：損益勘定から繰越利益剰余金へ
   - 損失：繰越利益剰余金から損益勘定へ

3. **資産・負債・純資産の次期繰越**
   - 各勘定の残高を次期に繰り越す

## 7. まとめ・今後の展望

決算整理仕訳は、適正な財務諸表作成の要となる重要な手続きです。今後は、四半期決算の定着により年4回の決算整理が必要となり、より迅速で正確な処理が求められます。また、IFRS適用企業の増加により、のれんの非償却、開発費の資産計上など、日本基準とは異なる決算整理も必要となってきています。AIやRPAの活用により定型的な決算整理作業は自動化が進むと考えられます。

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>

### 問題2

- A) (借) 繰越商品 800,000 / (貸) 仕入 800,000
- B) (借) 仕入 800,000 / (貸) 繰越商品 800,000
- C) (借) 商品 800,000 / (貸) 仕入 800,000
- D) (借) 期末商品棚卸高 800,000 / (貸) 仕入 800,000

<details>
<summary>解答</summary>
<strong>正解: A</strong><br>

<br>

Dが間違いの理由：期末商品棚卸高という勘定は使用しない
</details>

## 9. 専門用語集

### あ行
**洗替法（あらいがえほう）**
- **読み方**: あらいがえほう
- **意味**: 引当金を期首に全額戻入し、期末に改めて設定する方法
- **関連用語**: 差額補充法、引当金

### か行
**仮受金（かりうけきん）**
- **読み方**: かりうけきん
- **意味**: 内容不明の入金を一時的に処理する勘定
- **関連用語**: 仮払金、未決算勘定

**仮払金（かりばらいきん）**
- **読み方**: かりばらいきん
- **意味**: 内容不明の支出を一時的に処理する勘定
- **関連用語**: 仮受金、未決算勘定

**期末商品棚卸高（きまつしょうひんたなおろしだか）**
- **読み方**: きまつしょうひんたなおろしだか
- **意味**: 決算日現在の商品在庫金額
- **関連用語**: 期首商品棚卸高、棚卸資産

**期首商品棚卸高（きしゅしょうひんたなおろしだか）**
- **読み方**: きしゅしょうひんたなおろしだか
- **意味**: 期首（前期末）の商品在庫金額
- **関連用語**: 期末商品棚卸高、繰越商品

**決算整理仕訳（けっさんせいりしわけ）**
- **読み方**: けっさんせいりしわけ
- **意味**: 決算時に行う修正・調整のための仕訳
- **関連用語**: 決算、期末整理

**決算整理前残高試算表（けっさんせいりまえざんだかしさんひょう）**
- **読み方**: けっさんせいりまえざんだかしさんひょう
- **意味**: 決算整理を行う前の各勘定の残高一覧
- **関連用語**: 決算整理後残高試算表、試算表

**決算整理後残高試算表（けっさんせいりござんだかしさんひょう）**
- **読み方**: けっさんせいりござんだかしさんひょう
- **意味**: 決算整理後の各勘定の残高一覧
- **関連用語**: 決算整理前残高試算表、財務諸表

**減損損失（げんそんそんしつ）**
- **読み方**: げんそんそんしつ
- **意味**: 固定資産の収益性低下による評価損
- **関連用語**: 減損会計、特別損失

### さ行
**差額補充法（さがくほじゅうほう）**
- **読み方**: さがくほじゅうほう
- **意味**: 引当金の不足分のみを追加計上する方法
- **関連用語**: 洗替法、引当金

**財務諸表（ざいむしょひょう）**
- **読み方**: ざいむしょひょう
- **意味**: 貸借対照表、損益計算書等の決算書類
- **関連用語**: 決算書、計算書類

**三分法（さんぶんほう）**
- **読み方**: さんぶんほう
- **意味**: 商品売買を仕入・売上・繰越商品で処理する方法
- **関連用語**: 売上原価、商品勘定

**精算表（せいさんひょう）**
- **読み方**: せいさんひょう
- **意味**: 決算整理を一覧できる作業用の表
- **関連用語**: 8桁精算表、10桁精算表

**税効果会計（ぜいこうかかいけい）**
- **読み方**: ぜいこうかかいけい
- **意味**: 会計上と税務上の差異を調整する会計処理
- **関連用語**: 繰延税金資産、繰延税金負債

### た行
**棚卸（たなおろし）**
- **読み方**: たなおろし
- **意味**: 商品・製品等の在庫数量と金額を確認する作業
- **関連用語**: 実地棚卸、帳簿棚卸

**棚卸資産（たなおろししさん）**
- **読み方**: たなおろししさん
- **意味**: 商品、製品、原材料等の在庫資産
- **関連用語**: 商品、製品、仕掛品
