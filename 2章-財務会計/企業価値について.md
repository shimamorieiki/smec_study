# 企業価値について

## 概要

企業価値（Enterprise Value, EV）とは、企業全体の経済的価値を表す指標であり、株主にとっての価値（株式価値）と債権者にとっての価値（負債価値）の合計として定義されます。M&A、企業評価、投資判断などの場面で重要な役割を果たし、企業の真の価値を多角的に評価するための基礎となる概念です。

企業価値は単なる株式時価総額とは異なり、企業が抱える負債も含めた総合的な価値を表すため、より包括的な企業評価が可能となります。特に買収や合併の際には、買収側が引き継ぐことになる負債も含めた総額を把握する必要があるため、企業価値の算定が不可欠です。

## 1. 基本概念・定義

### 企業価値の構成要素

企業価値は以下の基本式で表されます：

**企業価値（EV） = 株式価値 + 負債価値 - 現金及び現金同等物**

または

**企業価値（EV） = 時価総額 + 有利子負債 - 現金及び現金同等物**

### 株式価値（Equity Value）

- **定義**: 株主に帰属する企業の価値。上場企業の場合は株式時価総額として市場で評価される
- **特徴**: 
  - 株主の持分を表す
  - 市場の期待値を反映
  - 日々変動する
- **重要性**: 株主にとっての投資価値を直接的に示す指標

### 負債価値（Debt Value）

- **定義**: 債権者に帰属する企業の価値。主に有利子負債の総額として計算される
- **特徴**:
  - 固定的な返済義務
  - 優先弁済権を持つ
  - 利息支払いが発生
- **重要性**: 企業の財務リスクと資本構成を理解する上で不可欠

### 現金及び現金同等物の控除

- **理由**: 現金は負債の返済に充当可能であり、実質的な負債負担を軽減するため
- **対象**: 現金、預金、短期有価証券など流動性の高い資産
- **注意点**: 事業運営に必要な運転資金は控除しない場合もある

## 2. 株式価値の計算方法

### 市場価値法（上場企業の場合）

**株式価値 = 株価 × 発行済株式総数**

#### 計算例1: 基本的な計算
- 株価: 2,500円
- 発行済株式総数: 1,000万株
- 株式価値 = 2,500円 × 10,000,000株 = 250億円

#### 希薄化証券の考慮
新株予約権やCB（転換社債）がある場合は、完全希薄化ベースで計算：

**完全希薄化後株式価値 = 株価 × (発行済株式総数 + 潜在株式数)**

#### 計算例2: 希薄化を考慮した計算
- 現在の株価: 3,000円
- 発行済株式総数: 500万株
- 新株予約権による潜在株式: 50万株
- 完全希薄化後株式価値 = 3,000円 × 5,500,000株 = 165億円

### DCF法（割引キャッシュフロー法）

#### 基本公式
**企業価値 = Σ(FCF_t / (1+WACC)^t) + TV / (1+WACC)^n**

ここで：
- FCF_t: t期のフリーキャッシュフロー
- WACC: 加重平均資本コスト
- TV: ターミナルバリュー（最終価値）
- n: 予測期間

**株式価値 = 企業価値 - 純有利子負債**

#### 詳細計算例3: DCF法による評価
**前提条件：**
- 予測期間: 5年
- WACC: 8%
- 永続成長率: 2%
- 純有利子負債: 100億円

**フリーキャッシュフロー予測：**
- 1年目: 30億円
- 2年目: 35億円
- 3年目: 40億円
- 4年目: 45億円
- 5年目: 50億円

**ステップ1: 各年のFCFを現在価値に割引**
- PV(1年目) = 30 / (1.08)^1 = 27.78億円
- PV(2年目) = 35 / (1.08)^2 = 30.01億円
- PV(3年目) = 40 / (1.08)^3 = 31.75億円
- PV(4年目) = 45 / (1.08)^4 = 33.08億円
- PV(5年目) = 50 / (1.08)^5 = 34.03億円

**ステップ2: ターミナルバリューの計算**
- TV = FCF_5 × (1+g) / (WACC-g)
- TV = 50 × 1.02 / (0.08-0.02) = 850億円
- PV(TV) = 850 / (1.08)^5 = 578.51億円

**ステップ3: 企業価値と株式価値の算出**
- 企業価値 = 156.65 + 578.51 = 735.16億円
- 株式価値 = 735.16 - 100 = 635.16億円

### 類似企業比較法（マルチプル法）

#### PER（株価収益率）を使用した方法
**株式価値 = 純利益 × 業界平均PER**

#### 計算例4: PER法
- 当期純利益: 50億円
- 業界平均PER: 15倍
- 株式価値 = 50億円 × 15 = 750億円

#### EV/EBITDA倍率を使用した方法
**企業価値 = EBITDA × 業界平均EV/EBITDA倍率**
**株式価値 = 企業価値 - 純有利子負債**

#### 計算例5: EV/EBITDA法
- EBITDA: 100億円
- 業界平均EV/EBITDA: 8倍
- 純有利子負債: 200億円
- 企業価値 = 100億円 × 8 = 800億円
- 株式価値 = 800億円 - 200億円 = 600億円

## 3. 負債価値の計算方法

### 簿価による評価（最も一般的）

負債価値は通常、貸借対照表上の有利子負債の簿価を使用します。

#### 有利子負債の内訳
- 短期借入金
- 長期借入金
- 社債
- リース債務
- その他の金利が発生する負債

#### 計算例6: 簿価による負債価値
**貸借対照表データ：**
- 短期借入金: 50億円
- 長期借入金: 150億円
- 社債: 100億円
- リース債務: 20億円
- 合計有利子負債: 320億円

### 市場価値による評価（社債の場合）

上場社債がある場合は、市場価格を使用してより正確な評価が可能です。

#### 計算例7: 社債の市場価値評価
- 社債額面: 100億円
- 市場価格: 額面の95%
- 社債の市場価値 = 100億円 × 0.95 = 95億円

### 現在価値法による評価

将来の元利返済額を現在価値に割り引いて計算する方法です。

#### 計算例8: 借入金の現在価値評価
**借入条件：**
- 借入額: 100億円
- 金利: 3%（固定）
- 期間: 5年（期末一括返済）
- 市場金利: 2%

**計算：**
- 毎年の利息: 3億円
- 5年後の元本返済: 100億円

**現在価値計算：**
- PV = Σ(3/(1.02)^t) + 100/(1.02)^5
- PV = 14.14 + 90.57 = 104.71億円

この場合、簿価100億円に対して市場価値は104.71億円となります。

## 4. 具体的な企業価値計算例

### ケース1: 上場企業のM&A評価

#### シナリオ設定
A社がB社の買収を検討しており、B社の企業価値を算定する。

**B社の財務データ：**
- 株価: 1,500円
- 発行済株式数: 2,000万株
- 短期借入金: 50億円
- 長期借入金: 100億円
- 社債: 50億円
- 現金及び預金: 80億円
- 短期有価証券: 20億円

**ステップ1: 株式価値の計算**
- 株式価値 = 1,500円 × 20,000,000株 = 300億円

**ステップ2: 有利子負債の計算**
- 有利子負債 = 50 + 100 + 50 = 200億円

**ステップ3: 現金同等物の計算**
- 現金同等物 = 80 + 20 = 100億円

**ステップ4: 企業価値の算出**
- 企業価値 = 300 + 200 - 100 = 400億円

### ケース2: 非上場企業の評価（DCF法とマルチプル法の併用）

#### シナリオ設定
ベンチャーキャピタルが非上場のC社への投資を検討。

**C社の財務データと予測：**
- 当期EBITDA: 10億円
- 当期純利益: 5億円
- 純有利子負債: 15億円
- 業界平均EV/EBITDA: 10倍
- 業界平均PER: 20倍
- 5年間のFCF予測: [8, 10, 12, 14, 16]億円
- WACC: 10%
- 永続成長率: 3%

**マルチプル法による評価：**

*EV/EBITDA法:*
- 企業価値 = 10億円 × 10倍 = 100億円
- 株式価値 = 100億円 - 15億円 = 85億円

*PER法:*
- 株式価値 = 5億円 × 20倍 = 100億円

**DCF法による評価：**

*現在価値計算:*
- PV(1年目) = 8 / (1.10)^1 = 7.27億円
- PV(2年目) = 10 / (1.10)^2 = 8.26億円
- PV(3年目) = 12 / (1.10)^3 = 9.02億円
- PV(4年目) = 14 / (1.10)^4 = 9.56億円
- PV(5年目) = 16 / (1.10)^5 = 9.93億円
- 合計PV = 44.04億円

*ターミナルバリュー:*
- TV = 16 × 1.03 / (0.10 - 0.03) = 235.43億円
- PV(TV) = 235.43 / (1.10)^5 = 146.21億円

*企業価値と株式価値:*
- 企業価値 = 44.04 + 146.21 = 190.25億円
- 株式価値 = 190.25 - 15 = 175.25億円

**総合評価：**
- マルチプル法平均: (85 + 100) / 2 = 92.5億円
- DCF法: 175.25億円
- 評価レンジ: 85億円～175億円

### ケース3: 負債比率が高い企業の評価

#### シナリオ設定
高レバレッジ企業D社の企業価値評価。

**D社の財務データ：**
- 時価総額: 50億円
- 短期借入金: 100億円
- 長期借入金: 200億円
- 社債（市場価格80%）: 額面100億円
- 優先株式: 50億円
- 現金: 30億円
- EBITDA: 80億円

**詳細計算：**

*負債の市場価値:*
- 短期借入金: 100億円（簿価＝市場価値と仮定）
- 長期借入金: 200億円（簿価＝市場価値と仮定）
- 社債市場価値: 100億円 × 0.80 = 80億円
- 優先株式: 50億円
- 負債価値合計: 430億円

*企業価値:*
- EV = 50 + 430 - 30 = 450億円

*EV/EBITDA倍率:*
- EV/EBITDA = 450 / 80 = 5.625倍

この倍率は業界平均と比較して、企業の相対的な評価を判断する材料となります。

## 5. 実務上の注意点

### 企業価値評価における重要ポイント

- **ポイント1: 一貫性の確保**
  評価方法や前提条件は一貫性を持たせる必要があります。例えば、FCFの予測とWACCの計算で使用する成長率や資本構成は整合的でなければなりません。

- **ポイント2: 市場環境の考慮**
  株価や金利などの市場データは日々変動するため、評価時点を明確にし、その時点での適切なデータを使用することが重要です。

- **ポイント3: 非事業用資産の取り扱い**
  遊休不動産や関係会社株式などの非事業用資産は、企業価値に別途加算する必要があります。

- **ポイント4: オフバランス項目の考慮**
  年金債務、リース債務（新リース会計基準適用前）、偶発債務なども負債価値に含める必要があります。

- **ポイント5: 少数株主持分の取り扱い**
  連結子会社がある場合、少数株主持分を企業価値から控除するか、別途考慮する必要があります。

### よくある誤解・トラブル

- **誤解1: 企業価値＝時価総額**
  正しい理解：企業価値は時価総額に純有利子負債を加えたものです。負債も含めた企業全体の価値を表します。

- **誤解2: 現金はすべて控除する**
  正しい理解：事業運営に必要な運転資金は控除しません。余剰現金のみを控除対象とする場合があります。

- **誤解3: 簿価と市場価値は同じ**
  正しい理解：特に社債や優先株式では、市場価格が簿価と大きく乖離することがあります。可能な限り市場価値を使用すべきです。

- **誤解4: DCF法が常に最も正確**
  正しい理解：DCF法は理論的には優れていますが、将来予測の不確実性が高く、前提条件に大きく依存します。複数の手法を併用することが重要です。

## 6. よくある質問（Q&A）

### Q1. なぜ企業価値から現金を控除するのですか？

**A1.** 現金を控除する理由は、企業買収の際の実質的な買収コストを把握するためです。

#### 詳細説明
企業を買収する際、買収企業は対象企業の現金も手に入れることになります。例えば、企業価値1,000億円の企業が200億円の現金を保有している場合、実質的な買収コストは800億円となります。これは、200億円の現金を使って負債を返済したり、買収資金の一部を回収したりできるためです。

ただし、以下の点に注意が必要です：
- 運転資金として必要な現金は控除しない
- 海外子会社の現金で本国に還流できないものは控除対象から除外
- 使途が制限されている現金（担保提供など）は控除しない

### Q2. 優先株式は負債価値に含めるべきですか、それとも株式価値に含めるべきですか？

**A2.** 優先株式の性質によって異なりますが、一般的には負債価値に含めることが多いです。

#### 詳細説明
優先株式の取り扱いは、その条項によって決定されます：

**負債として扱う場合（一般的）：**
- 償還義務がある
- 累積的配当がある
- 転換権がない
- 議決権がない

**株式として扱う場合：**
- 永久優先株式
- 普通株式への転換権がある
- 議決権がある

実務では、優先株式を「メザニン（中間的）」な資本として、株式価値と負債価値の間に位置付けることもあります。企業価値の計算では、通常は負債に含めて計算し、普通株主に帰属する価値を求める際に控除します。

### Q3. 営業外の投資有価証券はどのように扱うべきですか？

**A3.** 営業外の投資有価証券は、非事業用資産として企業価値に別途加算します。

#### 詳細説明
企業価値評価において、事業に直接関係しない資産は以下のように扱います：

**非事業用資産の例：**
- 上場株式（持ち合い株式など）
- 非連結の関係会社株式
- 遊休不動産
- 美術品・ゴルフ会員権など

**計算方法：**
1. 事業価値をDCF法やマルチプル法で算出
2. 非事業用資産の時価を別途評価
3. 企業価値 = 事業価値 + 非事業用資産価値
4. 株式価値 = 企業価値 - 純有利子負債

これにより、純粋な事業活動から生み出される価値と、その他の資産価値を区別して評価できます。

### Q4. リース債務は有利子負債に含めるべきですか？

**A4.** 新リース会計基準適用後は含めますが、適用前は状況によって判断が必要です。

#### 詳細説明

**新リース会計基準適用後（IFRS16、ASC842、日本基準）：**
- オペレーティングリースも原則としてオンバランス化
- リース債務は有利子負債に含める
- 使用権資産も考慮する必要がある

**旧基準での取り扱い：**
- ファイナンスリース：有利子負債に含める
- オペレーティングリース：
  - 原則として含めない
  - ただし、実質的に負債と同等の場合は調整が必要
  - 年間リース料×適切な倍数（通常5-8倍）で資本化することもある

**実務上の注意点：**
- 比較対象企業との一貫性を保つ
- 業界慣行を考慮する
- 重要性の原則に基づいて判断する

## 7. まとめ・今後の展望

企業価値評価は、M&A、投資判断、経営戦略の立案など、様々な場面で重要な役割を果たします。基本的な計算式は「企業価値＝株式価値＋負債価値－現金」とシンプルですが、実務では多くの調整項目や判断が必要となります。

### 今後のトレンド

1. **ESG要素の組み込み**
   環境・社会・ガバナンス要因が企業価値に与える影響の定量化が進んでいます。

2. **無形資産の評価**
   ブランド価値、知的財産、データ資産などの無形資産の重要性が高まっています。

3. **リアルオプション評価**
   不確実性の高い事業環境において、経営の柔軟性の価値を評価する手法が注目されています。

4. **AI・機械学習の活用**
   大量のデータを活用した企業価値予測モデルの開発が進んでいます。

企業価値評価は、財務理論と実務経験の両方が求められる分野です。基本を押さえた上で、常に最新の動向をキャッチアップし、多角的な視点で企業を評価することが重要です。

### 問題10

- D) 税率

<details>
<summary>解答</summary>

</details>

### 問題11

## 9. 専門用語集

### アルファベット

**DCF（Discounted Cash Flow）法**
- **読み方**: ディーシーエフほう
- **意味**: 将来のキャッシュフローを現在価値に割り引いて企業価値を算出する評価手法。理論的に最も優れているとされるが、将来予測の精度に依存する
- **関連用語**: WACC、FCF、ターミナルバリュー

**EBITDA（Earnings Before Interest, Taxes, Depreciation and Amortization）**
- **読み方**: イービットディーエー、イービットダー
- **意味**: 利払い前・税引き前・減価償却前・償却前利益。企業の本業の収益力を示す指標として企業価値評価で広く使用される
- **関連用語**: EBIT、営業利益、EV/EBITDA倍率

**EV（Enterprise Value）**
- **読み方**: イーブイ、エンタープライズバリュー
- **意味**: 企業価値。株式価値と負債価値の合計から現金を控除したもの。企業全体の価値を表す
- **関連用語**: 株式価値、負債価値、時価総額

**FCF（Free Cash Flow）**
- **読み方**: エフシーエフ、フリーキャッシュフロー
- **意味**: 企業が事業活動から生み出し、自由に使えるキャッシュフロー。営業CF－設備投資で計算される
- **関連用語**: 営業キャッシュフロー、投資キャッシュフロー、FCFF、FCFE

**M&A（Mergers and Acquisitions）**
- **読み方**: エムアンドエー
- **意味**: 企業の合併・買収。企業価値評価が最も重要となる取引の一つ
- **関連用語**: デューデリジェンス、バリュエーション、PMI

**PER（Price Earnings Ratio）**
- **読み方**: ピーイーアール、ピーイーレシオ
- **意味**: 株価収益率。株価が1株当たり利益の何倍で取引されているかを示す指標
- **関連用語**: EPS、PBR、配当利回り

**WACC（Weighted Average Cost of Capital）**
- **読み方**: ワック、ダブリューエーシーシー
- **意味**: 加重平均資本コスト。企業の資金調達コストを負債と株式の加重平均で表したもの
- **関連用語**: 資本コスト、負債コスト、株主資本コスト

### あ行

**永続成長率（えいぞくせいちょうりつ）**
- **意味**: DCF法のターミナルバリュー計算で使用する、企業が永続的に成長し続ける率。通常0-3%程度に設定
- **関連用語**: ターミナルバリュー、GDP成長率

**営業キャッシュフロー（えいぎょうきゃっしゅふろー）**
- **意味**: 企業の本業から生み出されるキャッシュフロー。利益に減価償却費を加え、運転資本の増減を調整して算出
- **関連用語**: FCF、投資キャッシュフロー、財務キャッシュフロー

### か行

**加重平均資本コスト（かじゅうへいきんしほんこすと）**
- **意味**: WACCの日本語訳。企業の資金調達コストを負債と株式の構成比で加重平均したもの
- **関連用語**: WACC、資本構成、最適資本構成

**株式価値（かぶしきかち）**
- **意味**: 株主に帰属する企業の価値。上場企業では時価総額、非上場企業では各種評価手法により算定
- **関連用語**: 時価総額、企業価値、負債価値

**企業価値（きぎょうかち）**
- **意味**: 企業全体の経済的価値。株式価値と負債価値の合計から現金を控除して計算
- **関連用語**: EV、事業価値、株式価値

**現金同等物（げんきんどうとうぶつ）**
- **意味**: 現金および容易に現金化可能で価値変動リスクが小さい短期投資。3ヶ月以内に満期の到来する定期預金など
- **関連用語**: 流動資産、運転資金、余剰現金

### さ行

**時価総額（じかそうがく）**
- **意味**: 上場企業の株式価値。株価×発行済株式総数で計算される
- **関連用語**: 株式価値、株価、発行済株式総数

**純有利子負債（じゅんゆうりしふさい）**
- **意味**: 有利子負債から現金及び現金同等物を控除した純額。Net Debtとも呼ばれる
- **関連用語**: 有利子負債、ネットデット、財務レバレッジ

### た行

**ターミナルバリュー（たーみなるばりゅー）**
- **意味**: DCF法において、予測期間以降の価値を表す最終価値。継続価値、残存価値とも呼ばれる
- **関連用語**: 永続成長率、出口倍率、DCF法

**デューデリジェンス（でゅーでりじぇんす）**
- **意味**: 企業買収等の際に行う詳細な調査。財務、法務、ビジネス等の観点から対象企業を精査
- **関連用語**: M&A、買収監査、DD

### な行

**ネットキャッシュ（ねっときゃっしゅ）**
- **意味**: 現金及び現金同等物から有利子負債を控除した純額。プラスの場合は実質無借金経営
- **関連用語**: 純有利子負債、キャッシュリッチ、財務健全性

### は行

**バリュエーション（ばりゅえーしょん）**
- **意味**: 企業価値評価。様々な手法を用いて企業や事業の価値を算定すること
- **関連用語**: 企業価値、株式価値、評価手法

**フリーキャッシュフロー（ふりーきゃっしゅふろー）**
- **意味**: FCFの日本語訳。企業が自由に使えるキャッシュフロー
- **関連用語**: FCF、FCFF、FCFE

**負債価値（ふさいかち）**
- **意味**: 債権者に帰属する企業の価値。通常は有利子負債の簿価または市場価値
- **関連用語**: 有利子負債、企業価値、株式価値

### ま行

**マルチプル法（まるちぷるほう）**
- **意味**: 類似企業の財務指標倍率を用いて企業価値を評価する手法。倍率法とも呼ばれる
- **関連用語**: PER、EV/EBITDA、類似企業比較法

### や行

**有利子負債（ゆうりしふさい）**
- **意味**: 利息の支払いを伴う負債。借入金、社債、リース債務などが含まれる
- **関連用語**: 負債価値、純有利子負債、無利子負債

**優先株式（ゆうせんかぶしき）**
- **意味**: 普通株式に優先して配当や残余財産の分配を受ける権利を持つ株式
- **関連用語**: 普通株式、種類株式、メザニン

### ら行

**類似企業比較法（るいじきぎょうひかくほう）**
- **意味**: 事業内容等が類似する上場企業の評価倍率を用いて、対象企業の価値を推定する手法
- **関連用語**: マルチプル法、比準方式、相対評価

**リスクフリーレート（りすくふりーれーと）**
- **意味**: 無リスク金利。理論上リスクがゼロとされる投資の利回り。通常は国債利回りを使用
- **関連用語**: リスクプレミアム、CAPM、WACC

### わ行

**割引率（わりびきりつ）**
- **意味**: 将来のキャッシュフローを現在価値に換算する際に使用する率。通常はWACCを使用
- **関連用語**: 現在価値、WACC、資本コスト
