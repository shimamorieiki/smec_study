# 直接法によるキャッシュフロー計算書の作成について

## 概要
キャッシュフロー計算書は、企業の一定期間における現金及び現金同等物の増減を示す財務諸表の一つです。作成方法には「直接法」と「間接法」があり、直接法は営業活動によるキャッシュフローを主要な取引ごとに総額で表示する方法です。

## 1. 基本概念・定義

### キャッシュフロー計算書とは
- **定義**: 一会計期間における現金及び現金同等物の増減を、営業活動・投資活動・財務活動の3つの区分で表示する財務諸表
- **目的**: 企業の資金の流れを明確にし、支払能力や資金調達力を評価する
- **重要性**: 損益計算書では把握できない実際の現金の動きを把握できる

### 直接法の特徴
- **定義**: 営業活動によるキャッシュフローを、営業収入、原材料の仕入支出など主要な取引ごとに総額で表示する方法
- **特徴**: 現金の流入・流出を取引種類別に把握でき、資金繰りの実態が明確になる
- **採用状況**: 作成に手間がかかるため、実務では間接法が主流だが、より詳細な情報提供が可能

### 現金及び現金同等物の範囲
- **現金**: 手許現金、要求払預金
- **現金同等物**: 容易に換金可能かつ価値変動リスクが僅少な短期投資（取得日から満期日まで3ヶ月以内の定期預金、コマーシャルペーパー等）

## 2. キャッシュフローの3つの区分

### 営業活動によるキャッシュフロー
営業活動によるキャッシュフローは、企業の本業から生じる現金の流れを示します。

| 項目 | 内容 | 計算例 |
|------|------|---------|
| 営業収入 | 売上代金の回収 | 売上高＋売掛金減少（－売掛金増加） |
| 原材料仕入支出 | 仕入代金の支払 | 仕入高＋買掛金減少（－買掛金増加） |
| 人件費支出 | 給与・賞与の支払 | 人件費＋未払給与減少（－未払給与増加） |
| その他営業支出 | 経費の支払 | 販管費＋前払費用増加（－前払費用減少） |

### 投資活動によるキャッシュフロー
投資活動によるキャッシュフローは、将来の利益獲得及び資金運用のための支出と、その売却等による収入を示します。

| 項目 | 内容 |
|------|------|
| 有形固定資産の取得による支出 | 設備投資による支出 |
| 有形固定資産の売却による収入 | 設備売却による収入 |
| 投資有価証券の取得による支出 | 株式・債券の購入 |
| 投資有価証券の売却による収入 | 株式・債券の売却 |

### 財務活動によるキャッシュフロー
財務活動によるキャッシュフローは、資金調達及び返済による現金の流れを示します。

| 項目 | 内容 |
|------|------|
| 短期借入による収入 | 短期借入金の調達 |
| 短期借入金の返済による支出 | 短期借入金の返済 |
| 長期借入による収入 | 長期借入金の調達 |
| 長期借入金の返済による支出 | 長期借入金の返済 |
| 株式の発行による収入 | 増資による資金調達 |
| 配当金の支払額 | 株主への配当支払 |

## 3. 具体的計算例・事例

### ケース1: 製造業A社の営業活動によるキャッシュフロー計算

#### 前提条件
- 売上高: 1,000百万円
- 売掛金: 期首200百万円 → 期末250百万円（増加50百万円）
- 仕入高: 600百万円
- 買掛金: 期首150百万円 → 期末130百万円（減少20百万円）
- 人件費: 200百万円
- 未払給与: 期首20百万円 → 期末25百万円（増加5百万円）
- その他販管費: 100百万円（全額現金支出）

#### 計算過程
```
営業収入 = 売上高 － 売掛金増加額
        = 1,000 － 50 = 950百万円

原材料仕入支出 = 仕入高 ＋ 買掛金減少額
               = 600 ＋ 20 = 620百万円

人件費支出 = 人件費 － 未払給与増加額
          = 200 － 5 = 195百万円

その他営業支出 = 100百万円

営業活動によるキャッシュフロー = 950 － 620 － 195 － 100 = 35百万円
```

#### 結果
営業活動により35百万円の現金が増加した。

### ケース2: 小売業B社の包括的なキャッシュフロー計算

#### 前提条件
**営業活動関連**
- 売上高: 500百万円（売掛金増加10百万円）
- 商品仕入: 300百万円（買掛金増加15百万円）
- 人件費: 80百万円（未払給与変動なし）
- 家賃・光熱費等: 50百万円（全額現金支出）
- 法人税等支払: 20百万円

**投資活動関連**
- 店舗改装による支出: 30百万円
- 旧設備売却収入: 5百万円

**財務活動関連**
- 長期借入金返済: 40百万円
- 配当金支払: 10百万円

#### 計算過程
**営業活動によるキャッシュフロー**
```
営業収入 = 500 － 10 = 490百万円
商品仕入支出 = 300 － 15 = 285百万円
人件費支出 = 80百万円
その他営業支出 = 50百万円
法人税等支払額 = 20百万円
小計 = 490 － 285 － 80 － 50 － 20 = 55百万円
```

**投資活動によるキャッシュフロー**
```
有形固定資産の取得 = －30百万円
有形固定資産の売却 = 5百万円
小計 = －30 ＋ 5 = －25百万円
```

**財務活動によるキャッシュフロー**
```
長期借入金の返済 = －40百万円
配当金の支払 = －10百万円
小計 = －40 － 10 = －50百万円
```

**現金及び現金同等物の増減額**
```
55 ＋ (－25) ＋ (－50) = －20百万円
```

#### 結果
期中に現金及び現金同等物が20百万円減少した。営業活動では55百万円の収入があったが、投資活動と財務活動での支出がそれを上回った。

## 4. 直接法によるキャッシュフロー計算書の作成手順

### 作成プロセス
1. **基礎データの収集**
   - 損益計算書の各項目
   - 貸借対照表の期首・期末残高
   - 取引の詳細情報

2. **営業活動によるキャッシュフローの計算**
   - 営業収入の算定
   - 各種支出の算定
   - 小計の計算

3. **投資活動によるキャッシュフローの計算**
   - 固定資産関連の収支
   - 投資有価証券関連の収支

4. **財務活動によるキャッシュフローの計算**
   - 借入金関連の収支
   - 株式関連の収支
   - 配当金の支払

5. **現金及び現金同等物の増減額の算定**
   - 3区分の合計
   - 期首残高との照合

### 必要な調整項目
- **売上債権の増減**: 売掛金、受取手形の変動を調整
- **棚卸資産の増減**: 在庫の変動を考慮
- **仕入債務の増減**: 買掛金、支払手形の変動を調整
- **その他流動資産・負債の増減**: 前払費用、未払費用等の調整

## 5. 実務上の注意点

### 直接法採用時の重要ポイント
- **詳細な取引記録の必要性**: 現金収支を取引種類別に把握する必要がある
- **システム対応**: 会計システムで直接法に対応した仕訳が必要
- **作成コスト**: 間接法より作成に時間とコストがかかる

### よくある誤解・トラブル
- **誤解1**: 「売上高＝営業収入」と考えてしまう
  - 正しい理解: 売上高から売掛金の増減を調整する必要がある
- **誤解2**: 減価償却費を営業支出に含めてしまう
  - 正しい理解: 減価償却費は非現金支出なので直接法では表示されない

### 間接法との使い分け
- **直接法のメリット**: 資金繰りの実態が明確、取引先別の分析が可能
- **間接法のメリット**: 作成が簡便、利益と現金の関係が明確
- **実務での選択**: 多くの企業は作成の簡便性から間接法を採用

## 6. よくある質問（Q&A）

### Q1. 直接法と間接法の最大の違いは何ですか？

**A1.** 営業活動によるキャッシュフローの表示方法が異なります。直接法は営業収入や各種支出を総額で表示しますが、間接法は税引前当期純利益から非現金項目等を調整して表示します。

#### 詳細説明
直接法では「営業収入500百万円、原材料仕入支出300百万円」のように実際の現金の流れを表示しますが、間接法では「税引前当期純利益100百万円、減価償却費加算20百万円、売掛金増加減算10百万円」のように利益からの調整計算を表示します。最終的な営業活動によるキャッシュフローの金額は同じになります。

### Q2. なぜ実務では間接法が主流なのですか？

**A2.** 作成の容易性とコストの問題が主な理由です。

#### 詳細説明
間接法は既存の財務諸表（損益計算書と貸借対照表）から比較的簡単に作成できますが、直接法は取引ごとの現金収支を把握する必要があり、詳細な会計記録とシステム対応が必要です。また、国際的にも間接法が一般的であることから、比較可能性の観点でも間接法が選ばれています。

### Q3. 売掛金が増加した場合、なぜ営業収入から差し引くのですか？

**A3.** 売掛金の増加は、売上のうち現金回収されていない部分を表すためです。

#### 詳細説明
例えば、売上高1,000百万円で売掛金が100百万円増加した場合、実際に現金で回収したのは900百万円です。損益計算書の売上高は発生主義で計上されるため、現金主義のキャッシュフロー計算書では、未回収分（売掛金増加額）を差し引く必要があります。

## 7. まとめ・今後の展望

### 直接法の重要性
直接法によるキャッシュフロー計算書は、企業の現金創出能力を詳細に把握できる重要な財務情報です。特に資金繰りが重要な中小企業や、投資家への詳細な情報開示を重視する企業にとって有用です。

### 今後の動向
- **IFRS（国際財務報告基準）の影響**: IFRSでは直接法を推奨しており、今後採用企業が増える可能性
- **デジタル化の進展**: 会計システムの高度化により、直接法の作成コストが低下する可能性
- **ESG投資の観点**: より詳細な資金の流れの開示要求が高まる可能性

## 9. 専門用語集

### あ行

**営業活動によるキャッシュフロー（えいぎょうかつどうによるきゃっしゅふろー）**
- **読み方**: えいぎょうかつどうによるきゃっしゅふろー
- **意味**: 企業の主たる営業活動から生じる現金及び現金同等物の増減を示す。商品・サービスの販売による収入、原材料の仕入による支出、人件費の支払等が含まれる
- **関連用語**: 投資活動によるキャッシュフロー、財務活動によるキャッシュフロー

**営業収入（えいぎょうしゅうにゅう）**
- **読み方**: えいぎょうしゅうにゅう
- **意味**: 直接法において、売上代金の現金回収額を示す。売上高から売掛金の増減を調整して算出される
- **関連用語**: 売上高、売掛金

### か行

**間接法（かんせつほう）**
- **読み方**: かんせつほう
- **意味**: 営業活動によるキャッシュフローを税引前当期純利益から非現金項目等を調整して算出する方法
- **関連用語**: 直接法、税引前当期純利益

**キャッシュフロー計算書（きゃっしゅふろーけいさんしょ）**
- **読み方**: きゃっしゅふろーけいさんしょ
- **意味**: 一会計期間における現金及び現金同等物の増減を、営業活動・投資活動・財務活動の3つの区分で表示する財務諸表
- **関連用語**: 貸借対照表、損益計算書

**現金及び現金同等物（げんきんおよびげんきんどうとうぶつ）**
- **読み方**: げんきんおよびげんきんどうとうぶつ
- **意味**: 手許現金、要求払預金及び容易に換金可能かつ価値変動リスクが僅少な短期投資（取得日から満期日まで3ヶ月以内）
- **関連用語**: 現金、現金同等物

**現金同等物（げんきんどうとうぶつ）**
- **読み方**: げんきんどうとうぶつ
- **意味**: 容易に換金可能で、かつ価値の変動について僅少なリスクしか負わない短期投資。取得日から満期日までが3ヶ月以内の定期預金等
- **関連用語**: 現金、コマーシャルペーパー

**原材料仕入支出（げんざいりょうしいれししゅつ）**
- **読み方**: げんざいりょうしいれししゅつ
- **意味**: 直接法において、原材料・商品の仕入に係る現金支出額。仕入高に買掛金の増減を調整して算出される
- **関連用語**: 仕入高、買掛金

### さ行

**財務活動によるキャッシュフロー（ざいむかつどうによるきゃっしゅふろー）**
- **読み方**: ざいむかつどうによるきゃっしゅふろー
- **意味**: 資金調達及び返済による現金の流れ。借入・返済、株式発行、配当支払等が含まれる
- **関連用語**: 営業活動によるキャッシュフロー、投資活動によるキャッシュフロー

### た行

**直接法（ちょくせつほう）**
- **読み方**: ちょくせつほう
- **意味**: 営業活動によるキャッシュフローを主要な取引ごとに総額で表示する方法。営業収入、仕入支出等を個別に表示する
- **関連用語**: 間接法、営業収入

**投資活動によるキャッシュフロー（とうしかつどうによるきゃっしゅふろー）**
- **読み方**: とうしかつどうによるきゃっしゅふろー
- **意味**: 将来の利益獲得及び資金運用のための支出とその売却等による収入。固定資産・有価証券の取得・売却等が含まれる
- **関連用語**: 営業活動によるキャッシュフロー、財務活動によるキャッシュフロー

### は行

**非現金項目（ひげんきんこうもく）**
- **読み方**: ひげんきんこうもく
- **意味**: 損益計算書に計上されるが、現金の収支を伴わない項目。減価償却費、引当金繰入額等
- **関連用語**: 減価償却費、間接法

**フリー・キャッシュフロー（ふりー・きゃっしゅふろー）**
- **読み方**: ふりー・きゃっしゅふろー
- **意味**: 企業が事業活動で稼いだ資金から、事業継続に必要な投資を差し引いた、自由に使える資金。一般的に営業活動CFと投資活動CFの合計
- **関連用語**: 営業活動によるキャッシュフロー、投資活動によるキャッシュフロー

### ま行

**未払費用（みばらいひよう）**
- **読み方**: みばらいひよう
- **意味**: すでに費用として計上されているが、まだ現金支出されていない項目。未払給与、未払利息等
- **関連用語**: 前払費用、経過勘定

### や行

**要求払預金（ようきゅうばらいよきん）**
- **読み方**: ようきゅうばらいよきん
- **意味**: 預金者の要求により、いつでも払い戻しができる預金。普通預金、当座預金等
- **関連用語**: 現金、定期預金

### ら行

**流動性（りゅうどうせい）**
- **読み方**: りゅうどうせい
- **意味**: 資産を現金に換金する容易さの程度。現金同等物は高い流動性を持つ
- **関連用語**: 現金同等物、換金可能性
