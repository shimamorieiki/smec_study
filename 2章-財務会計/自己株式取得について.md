# 自己株式取得について

## 概要

自己株式取得とは、株式会社が発行済みの自己の株式を株主から取得することを指します。これは企業の資本政策の重要な手段の一つであり、株主還元、資本効率の向上、敵対的買収への防衛など、様々な目的で実施されます。会社法では、財源規制などの一定の制限のもとで自己株式の取得が認められており、取得した自己株式は「金庫株」とも呼ばれます。

## 1. 基本概念・定義

### 自己株式とは
- **定義**: 株式会社が自ら発行した株式で、発行後に当該会社が取得し保有している株式
- **特徴**: 議決権がなく、配当も受けられない
- **重要性**: 資本政策の柔軟性を高める重要なツール

### 自己株式取得の意義
- **定義**: 会社が株主から自己の株式を買い取る行為
- **特徴**: 会社法の規制に従って実施される
- **重要性**: 株主価値向上や資本効率改善の手段

### 金庫株
- **定義**: 取得した自己株式の通称
- **特徴**: 会社の金庫に保管されているイメージから命名
- **重要性**: 将来の資本政策に活用可能な資源

## 2. 自己株式取得の方法・種類

### 取得方法による分類

会社法では、自己株式の取得方法について詳細な規定を設けています。

### 市場買付け
| 項目 | 内容 |
|------|------|
| 特徴 | 証券取引所の市場で買い付ける方法 |
| 適用範囲 | 上場会社のみ可能 |
| 注意点 | インサイダー取引規制に注意が必要 |

### 公開買付け（TOB）
| 項目 | 内容 |
|------|------|
| 特徴 | 不特定多数の株主に買付けの申込みを行う |
| 適用範囲 | 上場・非上場を問わず可能 |
| 注意点 | 金融商品取引法の規制を受ける |

### 相対取引
| 項目 | 内容 |
|------|------|
| 特徴 | 特定の株主との個別交渉による取得 |
| 適用範囲 | 主に非上場会社で利用 |
| 注意点 | 他の株主の売主追加請求権に配慮必要 |

### 取得請求権付株式の取得
| 項目 | 内容 |
|------|------|
| 特徴 | 株主からの請求により取得 |
| 適用範囲 | 取得請求権付株式を発行している場合 |
| 注意点 | 定款の定めに従う必要がある |

## 3. 具体的計算例・事例

### ケース1: 市場買付けによる自己株式取得

#### 前提条件
- A社（東証プライム上場）
- 発行済株式総数：1,000万株
- 現在の株価：2,000円
- 取得予定：100万株（発行済株式総数の10%）
- 分配可能額：300億円

#### 計算過程

**ステップ1: 取得に必要な資金の計算**
```
必要資金 = 取得株式数 × 株価
        = 100万株 × 2,000円
        = 20億円
```

**ステップ2: 財源規制の確認**
```
分配可能額：300億円 > 必要資金：20億円
→ 財源規制をクリア
```

**ステップ3: 取得後の状況**
```
発行済株式総数：1,000万株（変更なし）
自己株式数：100万株
実質的な流通株式数：900万株
```

💡 **実際の現場では**: 市場での大量買付けは株価を押し上げる可能性があるため、一定期間にわたって分散して買い付けることが一般的です。

### ケース2: 株主還元目的の自己株式取得と消却

#### 前提条件
- B社（東証スタンダード上場）
- 発行済株式総数：500万株
- 現在の株価：3,000円
- 自己株式保有：なし
- 純資産：200億円
- 分配可能額：80億円

#### パターンA: 50万株取得・消却の場合

**ステップ1: 取得コスト計算**
```
取得コスト = 50万株 × 3,000円 = 15億円
```

**ステップ2: 1株当たり純資産（BPS）への影響**
```
取得前BPS = 200億円 ÷ 500万株 = 4,000円

取得・消却後：
純資産 = 200億円 - 15億円 = 185億円
発行済株式総数 = 500万株 - 50万株 = 450万株
取得後BPS = 185億円 ÷ 450万株 = 4,111円

BPS上昇率 = (4,111円 - 4,000円) ÷ 4,000円 = 2.78%
```

#### パターンB: 100万株取得・保有の場合

**ステップ1: 取得コスト計算**
```
取得コスト = 100万株 × 3,000円 = 30億円
```

**ステップ2: 実質的な1株当たり指標への影響**
```
発行済株式総数：500万株（変更なし）
自己株式数：100万株
実質流通株式数：400万株

実質的EPS = 当期純利益 ÷ 400万株
（自己株式を除いて計算）
```

## 4. 手続き・プロセス

### 自己株式取得の手続きの流れ

1. **取締役会での決議**
   - 詳細説明：取得枠（株式数、取得価額の総額、取得期間）を決定
   - 必要書類：取締役会議事録
   - 注意点：株主総会決議が必要な場合もある

2. **適時開示**
   - 詳細説明：決議後速やかに証券取引所に開示
   - 必要書類：適時開示資料
   - 注意点：インサイダー取引規制に注意

3. **取得の実行**
   - 詳細説明：決議内容に従って取得を実施
   - 必要書類：売買報告書等
   - 注意点：市場の状況を見ながら執行

4. **取得結果の開示**
   - 詳細説明：月次で取得状況を開示
   - 必要書類：自己株式取得状況報告書
   - 注意点：適時適切な情報開示が必要

### 関連する制度・規則
- **根拠法令**: 会社法第155条以下、金融商品取引法
- **所管官庁**: 法務省、金融庁
- **関連制度**: インサイダー取引規制、公開買付規制

## 5. 実務上の注意点

### 財源規制への対応
- **ポイント1**: 分配可能額の範囲内での取得が必須
- **ポイント2**: 期中の業績変動により分配可能額が減少するリスクに注意
- **ポイント3**: 子会社からの自己株式取得には特別な配慮が必要

### 市場への影響
- **ポイント1**: 大量取得による株価への影響を考慮
- **ポイント2**: 流動性の低下に注意
- **ポイント3**: 需給バランスへの配慮が重要

### よくある誤解・トラブル
- **誤解1**: 「自己株式を取得すれば必ず株価が上がる」
  - 正しい理解：市場の評価次第であり、必ずしも株価上昇につながるとは限らない

- **誤解2**: 「取得した自己株式はすぐに処分できる」
  - 正しい理解：処分にも会社法上の手続きが必要であり、新株発行に準じた規制がある

## 6. よくある質問（Q&A）

### Q1. 自己株式の取得に株主総会決議は必要ですか？

**A1.** 原則として、市場取引による取得や公開買付けによる取得は取締役会決議で可能ですが、特定の株主からの取得（相対取引）の場合は株主総会の特別決議が必要です。

#### 詳細説明
会社法第156条により、市場価格のある株式を市場において行う取引による取得等は、定款で定めることにより取締役会決議で可能となっています。一方、特定の株主からの相対取引による取得は、株主平等の原則との関係で株主総会の特別決議が必要とされ、他の株主には売主追加請求権が認められています。

### Q2. 自己株式を保有し続けることのデメリットは何ですか？

**A2.** 自己株式は議決権がなく配当も受けられないため、資本効率の観点からは「死に金」となります。また、保有割合によっては他の株主の議決権比率に影響を与える可能性があります。

#### 実務的な観点からの補足説明
自己株式を長期保有する場合、その資金を事業投資や株主還元に使えないという機会損失が発生します。また、自己株式の保有割合が高くなると、実質的な流通株式数が減少し、株式の流動性が低下する可能性があります。そのため、多くの企業では取得後一定期間内に消却するか、ストックオプションの行使や M&A の対価として活用することを検討します。

### Q3. インサイダー取引規制との関係はどうなっていますか？

**A3.** 自己株式取得は重要事実に該当するため、決定事実として公表前の取引は禁止されます。また、決算情報などの重要事実を知っている期間中は自己株式取得を行えません。

#### 規制の具体的な内容
金融商品取引法により、上場会社が自己株式取得を行う場合、以下の期間は取得が制限されます：
- 決算発表前の一定期間（通常は決算期末から発表まで）
- 業績予想の修正など重要事実の発生から公表まで
- その他、未公表の重要事実を認識している期間

これらの規制により、自己株式取得を機動的に実施することが困難な場合があるため、年間を通じた取得計画を立てることが重要です。

## 7. まとめ・今後の展望

自己株式取得は、企業の資本政策における重要な選択肢の一つです。株主還元の強化、資本効率の向上、株価対策など、様々な目的で活用されています。近年では、ESG投資の観点から、単なる株主還元だけでなく、企業価値向上との両立が求められるようになっています。

今後は、デジタル化の進展により、ブロックチェーン技術を活用した自己株式管理や、AIを使った最適な取得タイミングの判断など、新たな手法の導入が期待されています。また、コーポレートガバナンス・コードの改訂により、自己株式取得を含む資本政策についての説明責任がより一層求められることになるでしょう。

## 8. 理解度確認クイズ（4択問題20問）

### 問題1
自己株式の基本的な特徴として、正しいものはどれか。

- A) 議決権を有し、配当も受けられる
- B) 議決権はないが、配当は受けられる
- C) 議決権はあるが、配当は受けられない
- D) 議決権がなく、配当も受けられない

<details>
<summary>解答</summary>
<strong>正解: D</strong><br>
自己株式は会社が自ら保有する株式であるため、議決権を行使することができません（会社法第308条第2項）。また、自己株式に配当することは会社から会社自身への利益移転となり意味がないため、配当も受けられません。<br>
<br>
Aが間違いの理由：自己株式は議決権も配当請求権も有しない<br>
Bが間違いの理由：配当を受けることはできない<br>
Cが間違いの理由：議決権を有しない
</details>

### 問題2
上場会社が市場買付けにより自己株式を取得する場合、原則として必要な機関決定はどれか。

- A) 株主総会の普通決議
- B) 株主総会の特別決議
- C) 取締役会決議
- D) 代表取締役の決定

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
会社法第156条および第165条により、市場価格のある株式を市場において行う取引による取得は、定款で定めることにより取締役会決議で行うことができます。多くの上場会社では定款でこの定めを置いているため、取締役会決議により機動的な自己株式取得が可能となっています。<br>
<br>
Aが間違いの理由：市場買付けの場合、株主総会決議は不要<br>
Bが間違いの理由：特別決議が必要なのは特定株主からの相対取引の場合<br>
Dが間違いの理由：取締役会設置会社では取締役会決議が必要
</details>

### 問題3
会社の分配可能額が50億円の場合、自己株式取得の上限額はいくらか。

- A) 25億円
- B) 50億円
- C) 100億円
- D) 上限なし

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
会社法第461条により、自己株式の取得は分配可能額の範囲内で行わなければなりません。従って、分配可能額が50億円の場合、自己株式取得の上限額も50億円となります。これは財源規制と呼ばれ、債権者保護の観点から設けられている重要な規制です。<br>
<br>
Aが間違いの理由：分配可能額の半分という制限はない<br>
Cが間違いの理由：分配可能額を超える取得はできない<br>
Dが間違いの理由：分配可能額による制限がある
</details>

### 問題4
特定の株主から相対取引で自己株式を取得する場合、他の株主に認められる権利は何か。

- A) 買取請求権
- B) 売主追加請求権
- C) 価格決定請求権
- D) 差止請求権

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
会社法第160条により、特定の株主から自己株式を取得する場合、他の株主は自己を売主に追加することを請求できる「売主追加請求権」が認められています。これは株主平等の原則を担保するための制度で、特定の株主だけが有利な条件で株式を売却することを防ぐ目的があります。<br>
<br>
Aが間違いの理由：買取請求権は組織再編等の場合に認められる権利<br>
Cが間違いの理由：価格決定請求権は別の制度<br>
Dが間違いの理由：差止請求権はこの場合認められない
</details>

### 問題5
自己株式の取得が「重要事実」に該当する理由として正しいものはどれか。

- A) 会社の業績に直接影響するため
- B) 需給関係を通じて株価に影響を与える可能性があるため
- C) 配当金の支払い総額が増加するため
- D) 会社の資産が増加するため

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
自己株式取得は市場での買い需要を生み出し、需給関係を通じて株価に影響を与える可能性があるため、金融商品取引法上の重要事実とされています。投資家の投資判断に重要な影響を与える情報として、適時開示が求められます。<br>
<br>
Aが間違いの理由：自己株式取得自体は業績に直接影響しない<br>
Cが間違いの理由：自己株式には配当しないため、配当総額はむしろ減少する<br>
Dが間違いの理由：自己株式取得により会社の資産（現金）は減少する
</details>

### 問題6
自己株式を消却した場合の会計処理として正しいものはどれか。

- A) 資本金を減少させる
- B) 資本剰余金を減少させる
- C) その他資本剰余金を減少させる
- D) 利益剰余金を減少させる

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
自己株式を消却する場合、会計上はその他資本剰余金から減額します。自己株式の取得原価がその他資本剰余金の残高を超える場合は、その超過額を利益剰余金から減額します。これは資本取引として処理されるため、損益には影響しません。<br>
<br>
Aが間違いの理由：資本金の減少には別途減資手続きが必要<br>
Bが間違いの理由：資本剰余金の中でも「その他資本剰余金」を減少させる<br>
Dが間違いの理由：原則としてその他資本剰余金から減額し、不足する場合のみ利益剰余金から減額
</details>

### 問題7
上場会社が自己株式取得を決議した場合の適時開示のタイミングはいつか。

- A) 決議の1週間前
- B) 決議後直ちに
- C) 取得開始時
- D) 取得完了時

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
証券取引所の適時開示規則により、上場会社が自己株式取得を決議した場合は、決議後直ちに開示することが求められています。これは投資家への公平な情報提供を確保し、インサイダー取引を防止するための重要な規制です。<br>
<br>
Aが間違いの理由：決議前の開示は不可能<br>
Cが間違いの理由：決議時点で開示が必要<br>
Dが間違いの理由：決議時点および取得状況の定期的な開示が必要
</details>

### 問題8
自己株式の処分が「新株発行」に準じて規制される理由は何か。

- A) 会社の資本金が増加するため
- B) 既存株主の持株比率を希釈化させるため
- C) 会社に新たな資金が入るため
- D) 発行済株式総数が増加するため

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
自己株式の処分は、実質的に流通株式数を増加させ、既存株主の持株比率を希釈化させる効果があります。この点で新株発行と同様の経済的効果を持つため、会社法では自己株式の処分を新株発行に準じて規制しています。<br>
<br>
Aが間違いの理由：自己株式の処分では資本金は増加しない<br>
Cが間違いの理由：対価によっては必ずしも資金が入るわけではない<br>
Dが間違いの理由：発行済株式総数は変わらない
</details>

### 問題9
発行済株式総数1,000万株、自己株式100万株を保有する会社において、実質的な流通株式数はいくらか。

- A) 1,100万株
- B) 1,000万株
- C) 900万株
- D) 100万株

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
実質的な流通株式数は、発行済株式総数から自己株式数を控除して計算します。<br>
計算式：1,000万株 - 100万株 = 900万株<br>
自己株式は会社が保有しており市場で流通しないため、実質的な流通株式数から除外されます。<br>
<br>
Aが間違いの理由：自己株式を加算するのは誤り<br>
Bが間違いの理由：自己株式を控除していない<br>
Dが間違いの理由：これは自己株式数であり、流通株式数ではない
</details>

### 問題10
TOB（公開買付け）による自己株式取得の特徴として誤っているものはどれか。

- A) 買付け価格を事前に公表する必要がある
- B) 買付け期間を定める必要がある
- C) 特定の株主だけから買い付けることができる
- D) 応募株式の全部または一部を買い付ける

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
TOB（公開買付け）は、不特定多数の株主に対して公平に買付けの機会を提供する制度です。特定の株主だけを対象とすることはできません。金融商品取引法により、買付け条件を公表し、すべての株主に平等に応募の機会を与えることが義務付けられています。<br>
<br>
Aが正しい理由：価格の事前公表は公開買付けの要件<br>
Bが正しい理由：20営業日以上60営業日以内の期間設定が必要<br>
Dが正しい理由：按分比例の方式により一部買付けも可能
</details>

## 9. 専門用語集

このスライドで使用された専門用語について、50音順で解説します。

### あ行

**インサイダー取引規制（いんさいだーとりひききせい）**
- **読み方**: インサイダートリヒキキセイ
- **意味**: 上場会社の重要事実を知った会社関係者が、その公表前に当該会社の株式等を売買することを禁止する規制
- **関連用語**: 重要事実、内部者取引

### か行

**株主還元（かぶぬしかんげん）**
- **読み方**: カブヌシカンゲン
- **意味**: 企業が獲得した利益を株主に還元すること。配当と自己株式取得が主な手段
- **関連用語**: 配当、自己株式取得、総還元性向

**金庫株（きんこかぶ）**
- **読み方**: キンコカブ
- **意味**: 企業が取得し保有している自己株式の通称。会社の金庫に保管されているイメージから
- **関連用語**: 自己株式

**議決権（ぎけつけん）**
- **読み方**: ギケツケン
- **意味**: 株主総会において議案に対して賛否の意思表示をする権利
- **関連用語**: 株主総会、株主権

**公開買付け（こうかいかいつけ）**
- **読み方**: コウカイカイツケ
- **意味**: 不特定多数の者に対し、公告により株式の買付けの申込みまたは売付けの申込みの勧誘を行い、取引所外で株式を買い付けること
- **関連用語**: TOB、自己株式取得

### さ行

**財源規制（ざいげんきせい）**
- **読み方**: ザイゲンキセイ
- **意味**: 会社法上、自己株式の取得や配当などの株主への分配を分配可能額の範囲内に制限する規制
- **関連用語**: 分配可能額、会社法

**市場買付け（しじょうかいつけ）**
- **読み方**: シジョウカイツケ
- **意味**: 証券取引所の市場において行う自己株式の取得方法
- **関連用語**: 自己株式取得、証券取引所

**自己株式（じこかぶしき）**
- **読み方**: ジコカブシキ
- **意味**: 株式会社が自ら発行した株式で、発行後に当該会社が取得し保有している株式
- **関連用語**: 金庫株、自己株式取得

**消却（しょうきゃく）**
- **読み方**: ショウキャク
- **意味**: 自己株式を消滅させること。発行済株式総数が減少する
- **関連用語**: 自己株式、発行済株式総数

**総還元性向（そうかんげんせいこう）**
- **読み方**: ソウカンゲンセイコウ
- **意味**: 配当と自己株式取得の合計額を当期純利益で除した比率。株主還元の積極性を示す指標
- **関連用語**: 配当性向、株主還元

**相対取引（あいたいとりひき）**
- **読み方**: アイタイトリヒキ
- **意味**: 特定の相手方と個別に交渉して行う株式の売買取引
- **関連用語**: 市場買付け、公開買付け

### た行

**適時開示（てきじかいじ）**
- **読み方**: テキジカイジ
- **意味**: 上場会社が投資判断に重要な影響を与える事実が発生した場合に、直ちに情報を開示すること
- **関連用語**: 重要事実、証券取引所

### は行

**配当（はいとう）**
- **読み方**: ハイトウ
- **意味**: 企業が株主に対して利益を分配すること
- **関連用語**: 剰余金の配当、株主還元

**発行済株式総数（はっこうずみかぶしきそうすう）**
- **読み方**: ハッコウズミカブシキソウスウ
- **意味**: 会社が発行している株式の総数。自己株式を含む
- **関連用語**: 自己株式、流通株式数

**分配可能額（ぶんぱいかのうがく）**
- **読み方**: ブンパイカノウガク
- **意味**: 会社法上、株主に分配できる財産の上限額。剰余金から一定の控除項目を差し引いて算定
- **関連用語**: 財源規制、剰余金

### ま行

**申込み（もうしこみ）**
- **読み方**: モウシコミ
- **意味**: 契約の成立に向けて、一方の当事者が相手方に対して行う意思表示
- **関連用語**: 公開買付け、売主追加請求権

### や行

**有価証券報告書（ゆうかしょうけんほうこくしょ）**
- **読み方**: ユウカショウケンホウコクショ
- **意味**: 上場会社等が事業年度ごとに提出する、企業内容の開示書類
- **関連用語**: 適時開示、金融商品取引法

### ら行

**流通株式数（りゅうつうかぶしきすう）**
- **読み方**: リュウツウカブシキスウ
- **意味**: 市場で実際に売買可能な株式数。発行済株式総数から自己株式や固定株等を除いたもの
- **関連用語**: 発行済株式総数、自己株式
