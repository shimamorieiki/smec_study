# CFの経済的効果について

## 概要
キャッシュフロー（CF: Cash Flow）の経済的効果は、企業価値評価や投資判断において最も重要な概念の一つです。本資料では、法人税を考慮しない場合と考慮する場合の両方について、CFの経済的効果を詳しく解説し、実務的な計算方法と具体例を提示します。

## 1. キャッシュフローの基本概念

### キャッシュフローとは
- **定義**: 一定期間における現金及び現金同等物の流入と流出の差額
- **特徴**: 会計上の利益とは異なり、実際の現金の動きを表す
- **重要性**: 企業の実質的な収益力と財務健全性を示す指標

### キャッシュフローの種類
1. **営業活動によるキャッシュフロー（OCF）**
   - 本業から生み出される現金流量
   - 売上収入、仕入支出、人件費支払い等

2. **投資活動によるキャッシュフロー（ICF）**
   - 設備投資や有価証券投資に関する現金流量
   - 固定資産の取得・売却、投資有価証券の取得・売却等

3. **財務活動によるキャッシュフロー（FCF）**
   - 資金調達・返済に関する現金流量
   - 借入金の調達・返済、株式の発行・配当支払い等

## 2. 法人税を考慮しない場合のCFの経済的効果

### 基本的な考え方
法人税を考慮しない場合、企業のキャッシュフローは営業収益から営業費用を差し引いた純額となります。

### 計算式
```
税引前CF = 売上高 - 現金営業費用 - 設備投資額
```

### 具体例1: 製造業A社のケース

#### 前提条件
- 売上高: 1,000百万円
- 現金営業費用: 600百万円
- 減価償却費: 100百万円
- 設備投資額: 150百万円

#### 計算過程
```
営業利益 = 1,000 - 600 - 100 = 300百万円
税引前CF = 営業利益 + 減価償却費 - 設備投資額
         = 300 + 100 - 150
         = 250百万円
```

### NPV（正味現在価値）による経済的効果の評価

#### 割引率10%、5年間のプロジェクトの場合
| 年次 | CF（百万円） | 割引係数 | 現在価値（百万円） |
|------|-------------|----------|-------------------|
| 0年目 | -1,000 | 1.000 | -1,000 |
| 1年目 | 250 | 0.909 | 227 |
| 2年目 | 250 | 0.826 | 207 |
| 3年目 | 250 | 0.751 | 188 |
| 4年目 | 250 | 0.683 | 171 |
| 5年目 | 250 | 0.621 | 155 |
| **NPV** | | | **-52** |

💡 **実務上の注意点**: 法人税を考慮しない場合、実際の企業価値よりも過大評価となる可能性があります。

## 3. 法人税を考慮する場合のCFの経済的効果

### 基本的な考え方
法人税を考慮する場合、税金支払いによる現金流出と、減価償却による税金軽減効果（タックスシールド）を考慮する必要があります。

### 計算式
```
税引後CF = (売上高 - 現金営業費用 - 減価償却費) × (1 - 税率) + 減価償却費 - 設備投資額
または
税引後CF = EBIT × (1 - 税率) + 減価償却費 - 設備投資額
```

### 具体例2: 製造業A社のケース（法人税率30%）

#### 計算過程
```
EBIT = 1,000 - 600 - 100 = 300百万円
税引後利益 = 300 × (1 - 0.3) = 210百万円
税引後CF = 210 + 100 - 150 = 160百万円
```

### タックスシールドの効果

#### 減価償却のタックスシールド
```
タックスシールド = 減価償却費 × 税率
                = 100 × 0.3
                = 30百万円
```

### NPVによる経済的効果の評価（税引後）

| 年次 | 税引後CF（百万円） | 割引係数 | 現在価値（百万円） |
|------|------------------|----------|-------------------|
| 0年目 | -1,000 | 1.000 | -1,000 |
| 1年目 | 160 | 0.909 | 145 |
| 2年目 | 160 | 0.826 | 132 |
| 3年目 | 160 | 0.751 | 120 |
| 4年目 | 160 | 0.683 | 109 |
| 5年目 | 160 | 0.621 | 99 |
| **NPV** | | | **-395** |

## 4. 法人税の有無による経済的効果の比較

### 比較表
| 項目 | 税考慮なし | 税考慮あり（税率30%） | 差額 |
|------|-----------|---------------------|------|
| 年間CF | 250百万円 | 160百万円 | 90百万円 |
| 5年間の累計CF | 1,250百万円 | 800百万円 | 450百万円 |
| NPV（割引率10%） | -52百万円 | -395百万円 | 343百万円 |
| IRR | 約8% | 約-7% | 約15% |

### 重要な示唆
1. **税負担の影響**: 法人税により年間CFが36%減少
2. **投資判断への影響**: 税考慮なしではNPVがわずかにマイナスだが、税考慮ありでは大幅なマイナス
3. **タックスシールドの重要性**: 減価償却による節税効果を考慮することが重要

## 5. 実務上の応用と注意点

### WACCを用いた割引率の設定
```
WACC = E/(E+D) × Re + D/(E+D) × Rd × (1-税率)
```
ここで、
- E: 株式の市場価値
- D: 負債の市場価値
- Re: 株主資本コスト
- Rd: 負債コスト

### 具体例3: WACC計算
- E/(E+D) = 0.6（株式比率60%）
- D/(E+D) = 0.4（負債比率40%）
- Re = 12%
- Rd = 4%
- 税率 = 30%

```
WACC = 0.6 × 12% + 0.4 × 4% × (1-0.3)
     = 7.2% + 1.12%
     = 8.32%
```

### 感度分析の重要性

#### 税率変化による影響
| 税率 | 年間税引後CF | NPV（@10%） |
|------|-------------|------------|
| 0% | 250百万円 | -52百万円 |
| 20% | 190百万円 | -262百万円 |
| 30% | 160百万円 | -395百万円 |
| 40% | 130百万円 | -527百万円 |

## 6. よくある質問（Q&A）

### Q1. なぜ減価償却費を足し戻すのですか？

**A1.** 減価償却費は会計上の費用であり、実際の現金支出を伴わないためです。

#### 詳細説明
キャッシュフロー計算では、以下の理由から減価償却費を足し戻します：
1. 利益計算時に減価償却費を差し引いているが、これは現金支出ではない
2. 実際の現金支出は設備投資時に既に発生している
3. したがって、CF計算では非現金費用である減価償却費を足し戻す必要がある

### Q2. タックスシールドとは何ですか？

**A2.** タックスシールドとは、費用計上により法人税が軽減される効果のことです。

#### 詳細説明
- 計算式: タックスシールド = 費用 × 税率
- 減価償却費100百万円、税率30%の場合: 100 × 0.3 = 30百万円の節税効果
- この節税効果により、実質的なキャッシュフローが改善される

### Q3. 法人税を考慮する場合としない場合、どちらを使うべきですか？

**A3.** 実務では必ず法人税を考慮すべきです。

#### 理由
1. **現実性**: 企業は実際に法人税を支払う必要がある
2. **正確性**: 税引後CFの方が実際の手元現金を正確に反映
3. **比較可能性**: 他社や他の投資案件との比較が可能
4. **意思決定**: より保守的で現実的な投資判断が可能

## 7. まとめ

### 法人税を考慮しない場合
- **メリット**: 計算が簡便、事業の収益力を純粋に評価できる
- **デメリット**: 実際のキャッシュフローと乖離、過大評価のリスク
- **使用場面**: 初期検討段階、異なる税制下での比較

### 法人税を考慮する場合
- **メリット**: 実際の手元現金を正確に反映、現実的な投資判断
- **デメリット**: 計算が複雑、税制変更の影響を受ける
- **使用場面**: 最終的な投資判断、企業価値評価

### 今後の展望
- **国際税制の変化**: BEPS対応等により税務の複雑性が増加
- **ESG投資の影響**: 環境投資等に対する税制優遇の考慮が必要
- **デジタル化**: リアルタイムでのCF管理と税効果シミュレーション

## 9. 専門用語集

### アルファベット

**CF (Cash Flow)**
- **読み方**: キャッシュフロー
- **意味**: 一定期間における現金及び現金同等物の流入と流出の差額。企業の資金繰りや収益力を示す重要指標
- **関連用語**: OCF（営業CF）、ICF（投資CF）、FCF（財務CF）

**DCF法 (Discounted Cash Flow)**
- **読み方**: ディーシーエフ法
- **意味**: 将来のキャッシュフローを現在価値に割り引いて企業価値や投資価値を評価する手法
- **関連用語**: NPV、IRR、割引率

**EBIT (Earnings Before Interest and Taxes)**
- **読み方**: イービット
- **意味**: 利息及び税金控除前利益。金利負担と税金の影響を除いた本業の収益力を示す
- **関連用語**: EBITDA、営業利益

**FCF (Free Cash Flow)**
- **読み方**: フリーキャッシュフロー
- **意味**: 営業活動から得られたキャッシュフローから、事業継続に必要な投資を差し引いた自由に使える現金
- **関連用語**: 営業CF、投資CF

**IRR (Internal Rate of Return)**
- **読み方**: アイアールアール、内部収益率
- **意味**: NPVがゼロとなる割引率。投資の収益性を示す指標
- **関連用語**: NPV、割引率、ハードルレート

**NPV (Net Present Value)**
- **読み方**: エヌピーブイ、正味現在価値
- **意味**: 将来のキャッシュフローの現在価値から初期投資額を差し引いた値
- **関連用語**: DCF法、割引率、現在価値

**ROE (Return on Equity)**
- **読み方**: アールオーイー、自己資本利益率
- **意味**: 株主資本に対する当期純利益の割合。株主資本の効率性を示す
- **関連用語**: ROA、自己資本、当期純利益

**WACC (Weighted Average Cost of Capital)**
- **読み方**: ワック、加重平均資本コスト
- **意味**: 企業の資金調達コストを負債と株主資本の構成比で加重平均した値
- **関連用語**: 資本コスト、負債コスト、株主資本コスト

### あ行

**営業キャッシュフロー**
- **読み方**: えいぎょうキャッシュフロー
- **意味**: 企業の本業から生み出される現金の流れ。売上収入から仕入・人件費等の支出を差し引いたもの
- **関連用語**: CF、投資CF、財務CF

**営業レバレッジ**
- **読み方**: えいぎょうレバレッジ
- **意味**: 固定費の存在により、売上高の変動に対して営業利益が大きく変動する度合い
- **関連用語**: 固定費、変動費、損益分岐点

### か行

**加重平均資本コスト**
- **読み方**: かじゅうへいきんしほんコスト
- **意味**: WACCの日本語訳。企業の資金調達コストの加重平均
- **関連用語**: WACC、資本構成、割引率

**割引率**
- **読み方**: わりびきりつ
- **意味**: 将来の金額を現在価値に換算する際に使用する率。リスクと時間価値を反映
- **関連用語**: 現在価値、WACC、リスクプレミアム

**感度分析**
- **読み方**: かんどぶんせき
- **意味**: 変数の変化が結果に与える影響を分析する手法
- **関連用語**: シナリオ分析、リスク分析

### さ行

**資本コスト**
- **読み方**: しほんコスト
- **意味**: 企業が資金調達する際に必要なコスト。投資家が要求する収益率
- **関連用語**: WACC、株主資本コスト、負債コスト

**正味現在価値**
- **読み方**: しょうみげんざいかち
- **意味**: NPVの日本語訳。投資の経済的価値を示す指標
- **関連用語**: NPV、DCF法、投資評価

### た行

**タックスシールド**
- **読み方**: タックスシールド
- **意味**: 費用計上により法人税が軽減される効果。特に減価償却費や支払利息による節税効果
- **関連用語**: 法人税、減価償却費、節税効果

**ターミナルバリュー**
- **読み方**: ターミナルバリュー
- **意味**: DCF法において、予測期間終了後の企業価値。永続価値とも呼ばれる
- **関連用語**: 永続成長率、出口価値、継続価値

### な行

**内部収益率**
- **読み方**: ないぶしゅうえきりつ
- **意味**: IRRの日本語訳。NPVがゼロとなる割引率
- **関連用語**: IRR、NPV、投資判断

### は行

**非現金費用**
- **読み方**: ひげんきんひよう
- **意味**: 会計上は費用として計上されるが、実際の現金支出を伴わない費用
- **関連用語**: 減価償却費、引当金繰入、のれん償却

**フリーキャッシュフロー**
- **読み方**: フリーキャッシュフロー
- **意味**: 事業活動から得られた資金のうち、自由に使える現金
- **関連用語**: FCF、営業CF、投資CF

### ま行

**貨幣の時間価値**
- **読み方**: かへいのじかんかち
- **意味**: 現在の1円と将来の1円では価値が異なるという概念。金利の存在により現在価値の方が高い
- **関連用語**: 現在価値、将来価値、割引率

### や行

**有利子負債**
- **読み方**: ゆうりしふさい
- **意味**: 利息の支払いが必要な負債。借入金、社債等
- **関連用語**: 負債コスト、支払利息、D/Eレシオ

### ら行

**リスクプレミアム**
- **読み方**: リスクプレミアム
- **意味**: リスクのある投資に対して、リスクフリーレート（無リスク金利）に上乗せされる追加的な収益率
- **関連用語**: 資本コスト、β（ベータ）、CAPM

### わ行

**割引現在価値**
- **読み方**: わりびきげんざいかち
- **意味**: 将来のキャッシュフローを現在の価値に割り引いた金額
- **関連用語**: PV、割引率、時間価値
