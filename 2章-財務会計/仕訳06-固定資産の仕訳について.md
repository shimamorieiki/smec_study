# 固定資産の仕訳について

## 固定資産の概要

固定資産は、企業が1年を超えて事業活動に使用する目的で保有する資産であり、有形固定資産（建物、機械、土地等）、無形固定資産（特許権、ソフトウェア等）、投資その他の資産（投資有価証券、長期貸付金等）に分類されます。固定資産の会計処理では、取得時の適正な取得原価の算定、使用期間にわたる減価償却、除却・売却時の処理が重要となります。特に減価償却は、費用配分の原則に基づく重要な会計処理です。

## 1. 固定資産の分類と特徴

### 有形固定資産
- **建物・構築物**: 事務所、工場、倉庫、塀、広告塔等
- **機械装置・運搬具**: 製造設備、車両運搬具、工具器具備品等
- **土地**: 事業用地（非償却資産）
- **建設仮勘定**: 建設中の固定資産

### 無形固定資産
- **法的権利**: 特許権、実用新案権、商標権、意匠権等
- **営業権**: のれん、営業権等
- **ソフトウェア**: 自社利用・販売目的のソフトウェア
- **その他**: 借地権、電話加入権等

### 投資その他の資産
| 項目 | 内容 |
|------|------|
| 投資有価証券 | 長期保有目的の株式・債券 |
| 長期貸付金 | 1年超の貸付金 |
| 長期前払費用 | 1年超の前払費用 |
| その他 | 敷金、保証金、出資金等 |

## 2. 固定資産の取得

### 取得原価の構成
| 費用項目 | 取得原価への算入 |
|----------|------------------|
| 購入代価 | ○（必ず算入） |
| 付随費用 | ○（原則算入） |
| 据付費用 | ○（算入） |
| 試運転費用 | ○（算入） |
| 登録免許税等 | ○（算入） |
| 不動産取得税 | △（選択可能） |

### 取得形態別の処理
- **現金購入**: 購入代価＋付随費用
- **割賦購入**: 現金購入価格＋利息（区分処理）
- **交換取得**: 譲渡資産の帳簿価額（例外あり）
- **自家建設**: 製造原価（適正な原価計算）
- **贈与取得**: 時価評価

## 3. 具体的計算例・事例

### ケース1: 固定資産の購入

#### パターンA: 機械3,000,000円を購入し、運送費50,000円、据付費100,000円を現金で支払った
- **前提条件**: 付随費用は取得原価に算入
- **仕訳**:
  ```
  (借) 機械装置 3,150,000 / (貸) 現金 3,150,000
  ```
- **結果**: 取得原価＝購入代価＋付随費用

#### パターンB: 土地5,000,000円、建物3,000,000円を一括8,000,000円で購入し、仲介手数料240,000円を支払った
- **前提条件**: 時価比率で按分（土地時価6,000,000円、建物時価3,000,000円）
- **計算**:
  ```
  土地：8,240,000円 × 6,000,000円÷9,000,000円 = 5,493,333円
  建物：8,240,000円 × 3,000,000円÷9,000,000円 = 2,746,667円
  ```
- **仕訳**:
  ```
  (借) 土地 5,493,333 / (貸) 現金 8,240,000
  (借) 建物 2,746,667
  ```

### ケース2: 減価償却（定額法）

#### パターンA: 取得原価2,000,000円、残存価額10%、耐用年数5年の備品の減価償却
- **前提条件**: 定額法による計算
- **計算**:
  ```
  年間償却額 = (2,000,000円 - 200,000円) ÷ 5年 = 360,000円
  ```
- **仕訳**:
  ```
  (借) 減価償却費 360,000 / (貸) 減価償却累計額 360,000
  ```

#### パターンB: 期中取得（4月1日）の場合の月割計算
- **前提条件**: 上記と同じ条件で4月1日取得
- **計算**:
  ```
  当期償却額 = 360,000円 × 9か月÷12か月 = 270,000円
  ```
- **仕訳**:
  ```
  (借) 減価償却費 270,000 / (貸) 減価償却累計額 270,000
  ```

### ケース3: 減価償却（定率法）

#### パターンA: 取得原価3,000,000円、償却率0.4の機械の減価償却（初年度）
- **前提条件**: 定率法による計算
- **計算**:
  ```
  初年度償却額 = 3,000,000円 × 0.4 = 1,200,000円
  ```
- **仕訳**:
  ```
  (借) 減価償却費 1,200,000 / (貸) 減価償却累計額 1,200,000
  ```

#### パターンB: 2年目の減価償却
- **前提条件**: 帳簿価額から計算
- **計算**:
  ```
  2年目償却額 = (3,000,000円 - 1,200,000円) × 0.4 = 720,000円
  ```
- **仕訳**:
  ```
  (借) 減価償却費 720,000 / (貸) 減価償却累計額 720,000
  ```

### ケース4: 固定資産の売却

#### パターンA: 帳簿価額1,000,000円（取得原価2,500,000円、減価償却累計額1,500,000円）の車両を1,200,000円で売却
- **前提条件**: 売却益の発生
- **仕訳**:
  ```
  (借) 現金 1,200,000 / (貸) 車両運搬具 2,500,000
  (借) 減価償却累計額 1,500,000 / (貸) 固定資産売却益 200,000
  ```

#### パターンB: 帳簿価額800,000円の機械を600,000円で売却
- **前提条件**: 売却損の発生（取得原価1,500,000円、減価償却累計額700,000円）
- **仕訳**:
  ```
  (借) 現金 600,000 / (貸) 機械装置 1,500,000
  (借) 減価償却累計額 700,000
  (借) 固定資産売却損 200,000
  ```

### ケース5: 固定資産の除却

#### パターンA: 帳簿価額300,000円（取得原価1,000,000円、減価償却累計額700,000円）の備品を除却
- **前提条件**: 処分価値なし
- **仕訳**:
  ```
  (借) 減価償却累計額 700,000 / (貸) 備品 1,000,000
  (借) 固定資産除却損 300,000
  ```

#### パターンB: 除却時に撤去費用50,000円を現金で支払った
- **前提条件**: 上記に撤去費用が追加
- **仕訳**:
  ```
  (借) 減価償却累計額 700,000 / (貸) 備品 1,000,000
  (借) 固定資産除却損 350,000 / (貸) 現金 50,000
  ```

### ケース6: 資本的支出と修繕費

#### パターンA: 建物の修繕に800,000円支出（通常の維持管理）
- **前提条件**: 収益的支出として処理
- **仕訳**:
  ```
  (借) 修繕費 800,000 / (貸) 現金 800,000
  ```

#### パターンB: 建物の増築工事に2,000,000円支出
- **前提条件**: 資本的支出として処理
- **仕訳**:
  ```
  (借) 建物 2,000,000 / (貸) 現金 2,000,000
  ```

### ケース7: 圧縮記帳

#### パターンA: 国庫補助金1,000,000円で機械2,500,000円を購入（直接減額方式）
- **前提条件**: 圧縮記帳の適用
- **仕訳**:
  ```
  購入時：(借) 機械装置 2,500,000 / (貸) 現金 2,500,000
  補助金受領：(借) 現金 1,000,000 / (貸) 国庫補助金収入 1,000,000
  圧縮記帳：(借) 機械装置圧縮損 1,000,000 / (貸) 機械装置 1,000,000
  ```

#### パターンB: 積立金方式による圧縮記帳
- **前提条件**: 間接的な処理
- **仕訳**:
  ```
  (借) 機械装置圧縮積立金 1,000,000 / (貸) 圧縮積立金 1,000,000
  ```

## 4. 特殊な固定資産の処理

### リース資産
1. **ファイナンス・リース**
   - 売買処理に準じた会計処理
   - リース資産・リース債務の計上
   - 減価償却の実施

2. **オペレーティング・リース**
   - 賃貸借処理
   - リース料の費用処理

### 減損会計
- **減損の兆候**: 営業損益の継続的マイナス等
- **減損損失の認識**: 割引前将来キャッシュフロー＜帳簿価額
- **減損損失の測定**: 帳簿価額を回収可能価額まで減額

### 資産除去債務
- **定義**: 有形固定資産の除去に関する法的義務
- **会計処理**: 取得時に負債計上、取得原価に加算
- **時の経過による調整**: 利息費用の計上

## 5. 実務上の注意点

### 固定資産管理の重要ポイント
- **ポイント1**: 固定資産台帳による個別管理の徹底
- **ポイント2**: 減価償却方法は継続適用（みだりに変更不可）
- **ポイント3**: 耐用年数は税法基準を参考に合理的に決定
- **ポイント4**: 少額資産（10万円未満等）は費用処理可能
- **ポイント5**: 遊休資産も減価償却を継続（減損の検討必要）

### よくある誤解・トラブル
- **誤解1**: 土地も減価償却すると考える
  - 正しい理解: 土地は非償却資産（借地権も同様）
- **誤解2**: 中古資産も新品と同じ耐用年数を適用
  - 正しい理解: 中古資産は残存耐用年数を見積もる
- **誤解3**: 建設仮勘定のまま減価償却を開始
  - 正しい理解: 完成・稼働開始時に本勘定に振替えてから償却

## 6. よくある質問（Q&A）

### Q1. 定額法と定率法はどのように使い分けますか？

**A1.** 資産の種類や使用状況に応じて選択しますが、建物は定額法が必須です。

#### 詳細説明
**法人税法上の取扱い**：
- 建物、建物附属設備、構築物：定額法のみ
- 機械装置、車両運搬具、備品等：定額法または定率法を選択

**選択の考え方**：
- 定額法：毎期均等に費用配分（安定的な使用）
- 定率法：初期に多額の費用配分（陳腐化が早い資産）

### Q2. 資本的支出と修繕費の区別はどのように行いますか？

**A2.** 資産価値を高めるか、耐用年数を延長するものは資本的支出です。

#### 詳細説明
**資本的支出**（固定資産計上）：
- 用途変更のための改造
- 機能向上のための部品取替
- 耐用年数延長のための補強

**修繕費**（費用処理）：
- 原状回復のための支出
- 定期的な保守点検
- 少額（20万円未満）または短期（3年以内）の修繕

形式基準により、60万円未満または前期末取得価額の10%以下は修繕費処理も可能です。

### Q3. 期中に売却した固定資産の減価償却はどう処理しますか？

**A3.** 売却月まで月割計算で減価償却を行った後、売却処理をします。

#### 詳細説明
例：9月30日に売却した場合（3月決算）
1. **当期の減価償却**（4月〜9月の6か月分）
   ```
   (借) 減価償却費 xxx / (貸) 減価償却累計額 xxx
   ```

2. **売却処理**
   ```
   (借) 現金等 xxx / (貸) 固定資産 xxx
   (借) 減価償却累計額 xxx / (貸) 固定資産売却益 xxx
   ```

間接法の場合は、減価償却累計額も同時に消去します。

## 7. まとめ・今後の展望

固定資産会計は、企業の生産能力や競争力の源泉となる資産の管理において重要な役割を果たします。今後は、IFRS（国際財務報告基準）との convergence により、公正価値評価の導入、コンポーネント・アカウンティング（構成要素別償却）の採用、リース会計基準の改正など、より精緻な会計処理が求められています。また、環境規制の強化に伴う資産除去債務の重要性も高まっています。
