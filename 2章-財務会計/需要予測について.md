# 需要予測について

## 概要
需要予測は、将来の製品やサービスの需要量を科学的手法により推定する経営管理技術です。適切な需要予測により、在庫管理の最適化、生産計画の効率化、資源配分の改善が可能となり、企業の収益性向上に大きく貢献します。本資料では、代表的な需要予測手法である移動平均法、指数平滑法、回帰分析、線形計画法について詳しく解説します。

## 1. 基本概念・定義

### 需要予測の定義
- **定義**: 過去のデータや現在の市場動向を分析し、将来の需要量を定量的に推定する手法
- **目的**: 在庫最適化、生産計画立案、資源配分、予算策定の基礎データ提供
- **重要性**: サプライチェーン全体の効率化、顧客満足度向上、コスト削減に直結

### 予測の時間軸による分類
- **短期予測**: 1週間～3ヶ月（日々の在庫管理、生産スケジューリング）
- **中期予測**: 3ヶ月～1年（季節変動対応、人員計画）
- **長期予測**: 1年以上（設備投資、新製品開発、市場戦略）

### 予測精度の評価指標
- **MAE（平均絶対誤差）**: 予測誤差の絶対値の平均
- **MAPE（平均絶対誤差率）**: 誤差率の平均（パーセント表示）
- **RMSE（二乗平均平方根誤差）**: 大きな誤差をより重視する指標

## 2. 主要な需要予測手法

### 2.1 移動平均法

#### 定義と特徴
移動平均法は、直近の一定期間のデータの平均値を次期の予測値とする最も基本的な手法です。

**特徴:**
- シンプルで理解しやすい
- 計算が容易
- 短期的な変動を平滑化
- トレンドへの追随が遅い

#### 計算方法

**単純移動平均（SMA）:**
```
予測値 = (直近n期間の実績値の合計) ÷ n
```

**📊 具体的な計算例**

**例: ある小売店の月別売上データ（単位：万円）**
| 月 | 1月 | 2月 | 3月 | 4月 | 5月 | 6月 |
|----|-----|-----|-----|-----|-----|-----|
| 売上 | 100 | 120 | 110 | 130 | 125 | ? |

**3ヶ月移動平均で6月を予測:**

**ステップ1: 直近3ヶ月のデータを特定**
- 3月: 110万円
- 4月: 130万円
- 5月: 125万円

**ステップ2: 平均値を計算**
```
6月予測値 = (110 + 130 + 125) ÷ 3 = 365 ÷ 3 = 121.7万円
```

**結果: 6月の予測売上は121.7万円**

💡 **実際の現場では**: 
- 曜日別、時間帯別など、より細かい単位で移動平均を計算
- 複数の移動平均期間（3日、7日、30日など）を比較検討
- 季節性がある場合は、前年同期のデータも参考にする

### 2.2 指数平滑法（指数平均法）

#### 定義と特徴
指数平滑法は、過去のデータに指数的に減少する重みを付けて予測する手法です。最新データほど重視され、古いデータほど影響が小さくなります。

**特徴:**
- 最新データを重視
- 必要なデータ量が少ない
- パラメータ（平滑化定数α）の調整が可能
- トレンドへの追随性が高い

#### 計算方法

**単純指数平滑法:**
```
予測値(t+1) = α × 実績値(t) + (1-α) × 予測値(t)
```
※ α: 平滑化定数（0 < α < 1）

**📊 具体的な計算例**

**例: 週別の製品出荷数予測（α = 0.3）**

| 週 | 実績値 | 予測値 | 計算過程 |
|----|---------|---------|----------|
| 1 | 100 | 100 | （初期値） |
| 2 | 120 | 100 | 前週の予測値 |
| 3 | 110 | 106 | 0.3×120 + 0.7×100 = 106 |
| 4 | 130 | 107.2 | 0.3×110 + 0.7×106 = 107.2 |
| 5 | ? | 115.04 | 0.3×130 + 0.7×107.2 = 115.04 |

💡 **実際の現場では**: 
- α値は通常0.1～0.3の範囲で設定（安定した需要の場合）
- 変動が激しい場合は0.4～0.6を使用
- 過去データでシミュレーションしてα値を最適化

### 2.3 回帰分析

#### 定義と特徴
回帰分析は、需要と関連する要因（説明変数）との関係を数式で表現し、予測する統計的手法です。

**特徴:**
- 因果関係を明確化
- 複数の要因を同時に考慮可能
- 予測の根拠が説明しやすい
- データ収集と前処理が重要

#### 計算方法

**単回帰分析（説明変数が1つ）:**
```
Y = a + bX
```
- Y: 需要量（目的変数）
- X: 影響要因（説明変数）
- a: 切片、b: 回帰係数

**📊 具体的な計算例**

**例: 気温とアイスクリーム売上の関係**

| 気温(℃) | 売上(個) |
|----------|----------|
| 20 | 100 |
| 25 | 150 |
| 30 | 200 |
| 35 | 250 |

**ステップ1: 回帰係数を計算**
最小二乗法により:
- b（傾き）= 10
- a（切片）= -100

**ステップ2: 回帰式を確立**
```
売上 = -100 + 10 × 気温
```

**ステップ3: 予測**
気温28℃の日の予測:
```
売上 = -100 + 10 × 28 = 180個
```

💡 **実際の現場では**: 
- 重回帰分析で複数要因（価格、プロモーション、競合状況など）を考慮
- 決定係数(R²)で予測精度を評価
- 外れ値の影響を慎重に検討

### 2.4 線形計画法

#### 定義と特徴
線形計画法は、制約条件の下で目的関数を最適化する数理計画手法です。需要予測では、複数の制約を考慮した最適な生産・在庫計画の策定に使用されます。

**特徴:**
- 複数の制約条件を同時に考慮
- 最適解が数学的に保証される
- 感度分析が可能
- 大規模問題にも適用可能

#### 定式化の方法

**基本構造:**
```
目的関数: 最大化（または最小化） Z = c₁x₁ + c₂x₂ + ... + cₙxₙ
制約条件: a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ ≤ b₁
          a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ ≤ b₂
          ...
非負条件: x₁, x₂, ..., xₙ ≥ 0
```

**📊 具体的な計算例**

**例: 2製品の生産計画最適化**

工場で製品AとBを生産。利益最大化を目指す。

**条件:**
- 製品A: 利益3万円/個、生産時間2時間/個、原材料1kg/個
- 製品B: 利益4万円/個、生産時間3時間/個、原材料2kg/個
- 制約: 生産時間120時間/週、原材料80kg/週

**ステップ1: 定式化**
```
目的関数: 最大化 Z = 3A + 4B （利益）
制約条件: 2A + 3B ≤ 120 （生産時間）
         A + 2B ≤ 80   （原材料）
         A, B ≥ 0      （非負条件）
```

**ステップ2: グラフ法で解く**
実行可能領域の頂点を調べ:
- (0, 0): Z = 0
- (60, 0): Z = 180
- (24, 24): Z = 168
- (0, 40): Z = 160

**結果: A=60個、B=0個で最大利益180万円**

💡 **実際の現場では**: 
- シンプレックス法やソルバーソフトを使用
- 需要制約、在庫制約なども追加
- what-if分析で複数シナリオを検討

## 3. 手法の比較と選択指針

### 各手法の比較表

| 項目 | 移動平均法 | 指数平滑法 | 回帰分析 | 線形計画法 |
|------|------------|------------|----------|------------|
| 複雑度 | ◎（低） | ○（中） | △（高） | △（高） |
| 必要データ量 | ○（中） | ◎（少） | △（多） | △（多） |
| トレンド対応 | △ | ○ | ◎ | - |
| 季節性対応 | △ | ○ | ◎ | ○ |
| 説明力 | △ | ○ | ◎ | ◎ |
| 計算時間 | ◎ | ◎ | ○ | △ |
| 最適化機能 | × | × | × | ◎ |

### 適用判断フローチャート

1. **データの特性を確認**
   - 安定的 → 移動平均法
   - トレンドあり → 次の判断へ

2. **説明変数の有無**
   - なし → 指数平滑法
   - あり → 次の判断へ

3. **制約条件の有無**
   - なし → 回帰分析
   - あり → 線形計画法

## 4. 実装例

### Pythonによる実装例

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression
from scipy.optimize import linprog

# 移動平均法
def moving_average(data, window):
    return pd.Series(data).rolling(window=window).mean()

# 指数平滑法
def exponential_smoothing(data, alpha):
    result = [data[0]]
    for i in range(1, len(data)):
        result.append(alpha * data[i] + (1 - alpha) * result[-1])
    return result

# 回帰分析
def regression_forecast(X, y, X_pred):
    model = LinearRegression()
    model.fit(X.reshape(-1, 1), y)
    return model.predict(X_pred.reshape(-1, 1))

# 線形計画法（シンプレックス法）
def linear_programming_example():
    # 係数（最小化問題として-1を掛ける）
    c = [-3, -4]  # 利益の係数
    A = [[2, 3], [1, 2]]  # 制約条件の係数
    b = [120, 80]  # 制約条件の右辺
    
    result = linprog(c, A_ub=A, b_ub=b, bounds=[(0, None), (0, None)])
    return result.x
```

## 5. 実務上の注意点

### データ品質の確保
- **欠損値処理**: 補間法の選択（線形補間、前方補完など）
- **外れ値検出**: 3σ法、箱ひげ図による識別
- **データクレンジング**: 重複除去、形式統一

### 予測精度の向上施策
- **複数手法の組み合わせ**: アンサンブル予測
- **定期的な再学習**: パラメータの更新
- **外部要因の考慮**: イベント、天候、経済指標

### よくある誤解とトラブル
- **誤解1**: 「複雑な手法ほど精度が高い」
  - 正解: データ特性に適した手法選択が重要
- **誤解2**: 「過去データが多いほど良い」
  - 正解: 市場環境の変化を考慮し、適切な期間を選択

## 6. よくある質問（Q&A）

### Q1. 新商品で過去データがない場合、どの手法を使うべきですか？

**A1.** 類似商品の販売データを参考にした回帰分析、または市場調査に基づく主観的予測との組み合わせを推奨します。

#### 詳細説明
新商品の需要予測では以下のアプローチが有効です：
1. **類似商品法**: 既存の類似商品の販売パターンを分析
2. **バスモデル**: 革新者と模倣者の割合から普及曲線を予測
3. **デルファイ法**: 専門家の意見を統合した定性的予測

### Q2. 季節変動が大きい商品の予測はどうすればよいですか？

**A2.** 季節調整を組み込んだ指数平滑法（ホルト・ウィンターズ法）や、季節ダミー変数を含む回帰分析が効果的です。

#### 詳細説明
季節指数の計算例：
```
季節指数 = 該当期の平均 ÷ 全期間の平均
予測値 = トレンド予測値 × 季節指数
```

### Q3. どの程度の予測精度を目標にすべきですか？

**A3.** 業界や商品特性により異なりますが、一般的にMAPE（平均絶対誤差率）で10-20%以内を目標とします。

#### 業界別の目安
- 日用消費財: MAPE 10-15%
- ファッション: MAPE 20-30%
- 生産財: MAPE 5-10%

### 問題1
移動平均法において、平均を取る期間を長くした場合の効果として最も適切なものはどれか？

- A) 予測の反応性が向上する
- B) 短期的な変動が平滑化される
- C) トレンドへの追随性が高まる
- D) 計算が複雑になる

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
移動平均の期間を長くすると、より多くのデータポイントで平均を取るため、短期的な変動（ノイズ）が平滑化されます。<br>
<br>
Aが間違いの理由：期間を長くすると反応性は低下します<br>
Cが間違いの理由：トレンドへの追随は遅くなります<br>
Dが間違いの理由：計算の複雑さは変わりません
</details>

### 問題2
指数平滑法の平滑化定数αが0.9の場合、どのような予測特性を持つか？

- A) 過去のデータを重視した安定的な予測
- B) 最新データを強く重視した反応的な予測
- C) 全期間のデータを均等に重視した予測
- D) 季節変動を考慮した予測

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
α=0.9は1に近い値であり、最新データの重みが90%、過去の予測値の重みが10%となるため、最新データを強く重視した反応的な予測となります。<br>
<br>
Aが間違いの理由：αが小さい値（0.1〜0.3）の場合の特性です<br>
Cが間違いの理由：指数平滑法は新しいデータほど重みが大きくなります<br>
Dが間違いの理由：単純指数平滑法では季節変動は考慮されません
</details>

### 問題3
回帰分析において決定係数R²=0.85が意味することは？

- A) 予測誤差が15%である
- B) 説明変数が目的変数の変動の85%を説明している
- C) 85%の確率で予測が当たる
- D) 相関係数が0.85である

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
決定係数R²=0.85は、説明変数（独立変数）が目的変数（従属変数）の変動の85%を説明できることを意味します。残りの15%は他の要因やランダムな変動によるものです。<br>
<br>
Aが間違いの理由：R²は誤差率を直接表すものではありません<br>
Cが間違いの理由：予測の的中確率を表すものではありません<br>
Dが間違いの理由：R²は相関係数rの2乗ですが、r=0.85ではありません（r≈0.92）
</details>

<summary>解答</summary>

<br>
Aが正しい理由：線形の不等式制約です<br>
Cが正しい理由：下限制約も線形計画法で扱えます<br>

</details>

### 問題9
線形計画法の最適解が複数存在する場合の特徴は？

- A) 制約条件が不足している
- B) 目的関数の係数が間違っている
- C) 目的関数の等高線と制約条件の境界線が平行
- D) 実行可能領域が存在しない

<details>
<summary>解答</summary>
<strong>正解: C</strong><br>
最適解が複数存在する（無限個の最適解）のは、目的関数の等高線と実行可能領域の境界線が平行な場合です。この時、境界線上の全ての点が同じ目的関数値を持ちます。<br>
<br>
Aが間違いの理由：制約条件の数とは無関係です<br>
Bが間違いの理由：係数が正しくても起こりえます<br>
Dが間違いの理由：実行可能領域がなければ解なしです
</details>

### 問題10
移動平均法と指数平滑法の共通点として正しいものは？

- A) パラメータの設定が不要
- B) 時系列データのみで予測可能
- C) トレンドの変化に即座に対応
- D) 季節変動を自動的に考慮

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
両手法とも過去の時系列データのみで予測でき、外部の説明変数を必要としません。<br>
<br>
Aが間違いの理由：移動平均は期間数、指数平滑法はαの設定が必要<br>
Cが間違いの理由：両手法ともトレンド変化への追随には遅れがあります<br>

</details>

<br>
Aが不十分な理由：7日移動平均では曜日効果が平均化されてしまいます<br>

</details>

### 問題14
需要予測の精度評価でMAPE=15%の意味は？

- A) 予測値が実績値の85%である
- B) 平均して実績値から15%の誤差がある
- C) 15%の確率で予測が外れる
- D) 標準偏差が15%である

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
MAPE（Mean Absolute Percentage Error）は平均絶対誤差率で、予測誤差の絶対値を実績値で割った値の平均です。15%は平均的に実績値の15%の誤差があることを示します。<br>
<br>
計算式：MAPE = (1/n) × Σ|実績値-予測値|/実績値 × 100%
</details>

## 9. 専門用語集

このスライドで使用された専門用語について、アルファベット順・50音順で解説します。

### アルファベット

**MAE (Mean Absolute Error)**
- **読み方**: エムエーイー
- **意味**: 平均絶対誤差。予測値と実績値の差の絶対値の平均。予測精度の評価指標として使用される。
- **関連用語**: MAPE, RMSE

**MAPE (Mean Absolute Percentage Error)**
- **読み方**: メイプ、マーペ
- **意味**: 平均絶対誤差率。誤差を実績値で割ってパーセント表示した値の平均。異なるスケールのデータ間で精度を比較する際に有用。
- **関連用語**: MAE, 予測精度

**RMSE (Root Mean Square Error)**
- **読み方**: アールエムエスイー
- **意味**: 二乗平均平方根誤差。予測誤差の二乗平均の平方根。大きな誤差により重いペナルティを課す評価指標。
- **関連用語**: MAE, 標準偏差

**R² (R-squared)**
- **読み方**: アールスクエア、決定係数
- **意味**: 回帰モデルの当てはまりの良さを表す指標。0から1の値を取り、1に近いほどモデルの説明力が高い。
- **関連用語**: 回帰分析、相関係数

### あ行

**移動平均法（いどうへいきんほう）**
- **意味**: 時系列データの一定期間の平均値を順次計算し、それを予測値とする手法。短期的な変動を平滑化する効果がある。
- **関連用語**: 単純移動平均、加重移動平均

**外れ値（はずれち）**
- **意味**: データセットの中で、他の値から大きく離れた異常な値。統計分析や予測精度に大きな影響を与える可能性がある。
- **関連用語**: 異常値、データクレンジング

### か行

**回帰分析（かいきぶんせき）**
- **意味**: 変数間の関係を数式で表現し、一つまたは複数の説明変数から目的変数を予測する統計手法。
- **関連用語**: 単回帰、重回帰、最小二乗法

**季節指数（きせつしすう）**
- **意味**: 季節変動を数値化した指標。各期間の値を全期間の平均で割った値で、1を基準として季節による需要の増減を表す。
- **関連用語**: 季節調整、季節変動

**決定係数（けっていけいすう）**
- **意味**: R²とも呼ばれ、回帰モデルが目的変数の変動をどの程度説明できるかを示す指標。0から1の値を取る。
- **関連用語**: 回帰分析、相関係数

### さ行

**最小二乗法（さいしょうじじょうほう）**
- **意味**: 回帰分析で回帰係数を推定する手法。予測値と実績値の差の二乗和を最小化する。
- **関連用語**: 回帰分析、正規方程式

**シャドープライス**
- **読み方**: しゃどーぷらいす
- **意味**: 線形計画法で、制約条件を1単位緩和したときの目的関数の改善量。潜在価格とも呼ばれる。
- **関連用語**: 線形計画法、感度分析

**指数平滑法（しすうへいかつほう）**
- **意味**: 過去のデータに指数的に減少する重みを付けて予測する手法。最新データほど重視される。
- **関連用語**: 平滑化定数、ホルト・ウィンターズ法

**重回帰分析（じゅうかいきぶんせき）**
- **意味**: 複数の説明変数を用いて目的変数を予測する回帰分析。より複雑な関係性を表現できる。
- **関連用語**: 単回帰分析、多重共線性

**シンプレックス法（しんぷれっくすほう）**
- **意味**: 線形計画問題を解くための反復的アルゴリズム。実行可能領域の頂点を移動しながら最適解を探索する。
- **関連用語**: 線形計画法、最適化

### た行

**多重共線性（たじゅうきょうせんせい）**
- **意味**: 重回帰分析で説明変数間に強い相関がある状態。回帰係数の推定が不安定になる問題。
- **関連用語**: VIF、重回帰分析

**単回帰分析（たんかいきぶんせき）**
- **意味**: 1つの説明変数で目的変数を予測する最も基本的な回帰分析。
- **関連用語**: 回帰分析、重回帰分析

### は行

**平滑化定数（へいかつかていすう）**
- **意味**: 指数平滑法で使用するパラメータα。0から1の値を取り、最新データの重みを決定する。
- **関連用語**: 指数平滑法、α（アルファ）

**ホルト・ウィンターズ法（ほると・うぃんたーずほう）**
- **意味**: トレンドと季節変動を考慮した指数平滑法の拡張版。より複雑な時系列パターンに対応可能。
- **関連用語**: 指数平滑法、季節調整

### ま行

**目的関数（もくてきかんすう）**
- **意味**: 線形計画法で最大化または最小化したい関数。利益やコストなどを数式で表現したもの。
- **関連用語**: 線形計画法、制約条件

### ら行

**リードタイム**
- **読み方**: りーどたいむ
- **意味**: 発注から納品までの所要時間。需要予測では、この期間分先の需要を予測する必要がある。
- **関連用語**: 在庫管理、発注点

**線形計画法（せんけいけいかくほう）**
- **意味**: 線形の目的関数を線形の制約条件の下で最適化する数理計画手法。
- **関連用語**: シンプレックス法、最適化問題

---

以上が需要予測に関する主要な4手法（移動平均法、指数平滑法、回帰分析、線形計画法）の詳細解説です。各手法の特徴を理解し、データや目的に応じて適切に選択・活用することが、精度の高い需要予測の実現につながります。
