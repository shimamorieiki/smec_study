# 間接法によるキャッシュフロー計算書の作成について

## 概要
キャッシュフロー計算書は、企業の一定期間における現金および現金同等物の増減を表示する財務諸表です。営業活動、投資活動、財務活動の3つの区分で現金の流れを示し、企業の資金繰りや財務健全性を評価する上で重要な役割を果たします。間接法は、営業活動によるキャッシュフローを純利益から調整して算出する方法で、実務上最も広く採用されています。

## 1. 基本概念・定義

### キャッシュフロー計算書の目的
- **定義**: 一会計期間における現金および現金同等物の増減を、その原因となる活動別に区分して表示する財務諸表
- **特徴**: 発生主義会計では把握できない実際の現金の動きを明確に示す
- **重要性**: 企業の支払能力、資金調達能力、将来キャッシュフロー創出能力の評価に不可欠

### 間接法の定義
- **定義**: 営業活動によるキャッシュフローを、純利益に非資金項目や営業活動に関連する資産・負債の増減を調整して算出する方法
- **特徴**: 純利益とキャッシュフローの関係が明確になる
- **重要性**: 損益計算書と貸借対照表から作成可能で、実務的に効率的

### 現金および現金同等物
- **定義**: 手許現金、要求払預金および容易に換金可能でかつ価値の変動リスクが僅少な短期投資
- **特徴**: 取得日から満期日または償還日までの期間が3ヶ月以内のものが該当
- **重要性**: キャッシュフロー計算書の対象となる資金の範囲を明確化

## 2. キャッシュフローの区分

### 活動区分の基準
キャッシュフロー計算書では、企業活動を性質に応じて3つに区分し、それぞれの現金の流れを表示します。

### 営業活動によるキャッシュフロー
| 項目 | 内容 |
|------|------|
| 特徴 | 企業の主たる営業活動から生じる現金の流れ |
| 適用範囲 | 商品・サービスの販売、仕入、人件費支払等 |
| 注意点 | 投資活動・財務活動に属さないものも含む |

### 投資活動によるキャッシュフロー
| 項目 | 内容 |
|------|------|
| 特徴 | 固定資産や有価証券の取得・売却等による現金の流れ |
| 適用範囲 | 設備投資、有価証券投資、貸付金等 |
| 注意点 | 将来の収益獲得や資金運用を目的とした活動 |

### 財務活動によるキャッシュフロー
| 項目 | 内容 |
|------|------|
| 特徴 | 資金調達・返済に関する現金の流れ |
| 適用範囲 | 借入金、社債、株式発行、配当金支払等 |
| 注意点 | 資本構成の変動を伴う活動 |

## 3. 具体的計算例・事例

### ケース1: 製造業A社の営業活動によるキャッシュフロー

#### 基本データ
- **当期純利益**: 1,500万円
- **減価償却費**: 800万円
- **売上債権の増加**: △300万円
- **棚卸資産の減少**: 200万円
- **仕入債務の増加**: 150万円

#### 計算過程
```
営業活動によるキャッシュフロー
＝ 当期純利益 1,500万円
＋ 減価償却費 800万円（非資金費用の加算）
－ 売上債権の増加 300万円（運転資本の増加）
＋ 棚卸資産の減少 200万円（運転資本の減少）
＋ 仕入債務の増加 150万円（運転資本の増加）
＝ 2,350万円
```

#### 結果
営業活動により2,350万円の現金が流入したことを示しています。

```

```

```
営業活動CF + 投資活動CF + 財務活動CF

```

## 4. 間接法による作成手順

### 作成プロセスの流れ
1. **ステップ1: 当期純利益の把握**
   - 詳細説明: 損益計算書から当期純利益を抽出
   - 必要書類: 損益計算書
   - 注意点: 税引後の最終利益を使用する

2. **ステップ2: 非資金損益項目の調整**
   - 詳細説明: 減価償却費等の非現金費用を加算、非現金収益を減算
   - 必要書類: 損益計算書の内訳明細
   - 注意点: すべての非資金項目を網羅的に把握する

3. **ステップ3: 営業活動関連項目の調整**
   - 詳細説明: 売上債権、棚卸資産、仕入債務等の増減を調整
   - 必要書類: 期首・期末の貸借対照表
   - 注意点: 増減の方向（プラス・マイナス）に注意

4. **ステップ4: 営業外・特別損益項目の調整**
   - 詳細説明: 投資・財務活動に関連する損益を調整
   - 必要書類: 損益計算書の内訳
   - 注意点: 適切な活動区分への振替が必要

5. **ステップ5: 利息・配当金・法人税等の処理**
   - 詳細説明: 実際の現金収支を別途記載
   - 必要書類: 現金出納帳、税務申告書
   - 注意点: 発生額と支払額の差異に留意

### 調整項目の詳細
- **加算項目**: 減価償却費、のれん償却費、貸倒引当金繰入額、退職給付費用等
- **減算項目**: 固定資産売却益、投資有価証券売却益、貸倒引当金戻入益等
- **運転資本の調整**: 資産の増加は減算、負債の増加は加算

## 5. 実務上の注意点

### 作成時の重要ポイント
- **ポイント1**: 非資金項目の網羅的な把握が重要
- **ポイント2**: 期首・期末の貸借対照表の正確な比較が必要
- **ポイント3**: 為替差損益等の適切な処理に注意

### よくある誤解・トラブル
- **誤解1**: 減価償却費を営業活動CFから減算してしまう → 非資金費用なので加算が正しい
- **誤解2**: 売上債権の増加を加算してしまう → 現金回収が遅れているので減算が正しい
- **誤解3**: 固定資産の取得を営業活動に含める → 投資活動に分類すべき

## 6. よくある質問（Q&A）

### Q1. なぜ減価償却費を加算するのですか？

**A1.** 減価償却費は損益計算書上では費用として純利益を減少させますが、実際には現金の支出を伴わない費用だからです。

#### 詳細説明
例えば、1,000万円の機械を購入し、10年間で償却する場合：
- 購入時: 現金1,000万円が減少（投資活動CF）
- 毎年の減価償却: 100万円の費用計上（現金支出なし）
- 間接法での調整: 純利益に100万円を加算して現金ベースに戻す

### Q2. 直接法と間接法のどちらを選ぶべきですか？

**A2.** 実務上は間接法が圧倒的に多く採用されています。

#### 理由の詳細
1. **作成の効率性**: 既存の財務諸表から作成可能
2. **情報の有用性**: 純利益との調整過程が明確
3. **国際的慣行**: 多くの国で間接法が主流
4. **監査の容易性**: 財務諸表間の整合性確認が容易

### Q3. 売掛金が増加した時になぜキャッシュフローから減算するのですか？

**A3.** 売掛金の増加は、売上は計上されたが現金回収がまだ行われていないことを意味するからです。

#### 具体例での説明
- 売上高1,000万円（すべて掛売り）
- 期首売掛金: 200万円、期末売掛金: 500万円
- 売掛金の増加: 300万円
- 現金回収額: 1,000万円 - 300万円 = 700万円
- したがって、営業CFでは300万円を減算

## 7. まとめ・今後の展望

間接法によるキャッシュフロー計算書は、企業の資金繰りを把握する上で不可欠なツールです。国際財務報告基準（IFRS）や日本の会計基準でも、その重要性は増しています。今後は、より詳細なセグメント別キャッシュフロー情報の開示や、予測キャッシュフロー情報の活用が進むと考えられます。また、ESG投資の観点から、持続可能性に関連するキャッシュフローの開示も重要になってくるでしょう。

### 問題3
売上高1,000万円、期首売掛金100万円、期末売掛金300万円の場合、間接法での売掛金の調整額は？

- A) +200万円
- B) -200万円
- C) +300万円
- D) -300万円

<details>
<summary>解答</summary>
<strong>正解: B</strong><br>
売掛金の増加額 = 期末売掛金300万円 - 期首売掛金100万円 = 200万円<br>

<br>
Aが間違いの理由：売掛金の増加は減算項目であり、加算ではありません<br>
Cが間違いの理由：期末残高そのものではなく、増減額で調整します<br>
Dが間違いの理由：調整額は増減額の200万円であり、300万円ではありません<br>
<br>
【補足】実務では、売掛金の回収サイトの管理がキャッシュフロー改善の重要なポイントとなります。
</details>

## 9. 専門用語集

このスライドで使用された専門用語について、50音順で解説します。

### あ行

**営業活動によるキャッシュフロー（えいぎょうかつどうによるきゃっしゅふろー）**
- **読み方**: えいぎょうかつどうによるきゃっしゅふろー
- **意味**: 企業の主たる営業活動から生じる現金および現金同等物の増減を示す。商品・サービスの販売、仕入、人件費の支払いなど、本業に関連する現金の流れを表す
- **関連用語**: 投資活動によるキャッシュフロー、財務活動によるキャッシュフロー

### か行

**間接法（かんせつほう）**
- **読み方**: かんせつほう
- **意味**: 営業活動によるキャッシュフローを算出する方法の一つで、当期純利益から出発し、非資金損益項目や営業活動に関連する資産・負債の増減を調整して求める方法
- **関連用語**: 直接法、キャッシュフロー計算書

**キャッシュフロー計算書（きゃっしゅふろーけいさんしょ）**
- **読み方**: きゃっしゅふろーけいさんしょ
- **意味**: 一会計期間における現金および現金同等物の増減を、営業活動、投資活動、財務活動の3つに区分して表示する財務諸表
- **関連用語**: 貸借対照表、損益計算書、株主資本等変動計算書

**現金同等物（げんきんどうとうぶつ）**
- **読み方**: げんきんどうとうぶつ
- **意味**: 容易に換金可能でかつ価値の変動リスクが僅少な短期投資。一般的に取得日から満期日まで3ヶ月以内の定期預金、譲渡性預金、コマーシャルペーパーなどが該当
- **関連用語**: 現金、短期投資

**減価償却費（げんかしょうきゃくひ）**
- **読み方**: げんかしょうきゃくひ
- **意味**: 固定資産の取得原価を、その使用期間にわたって費用配分したもの。現金支出を伴わない費用であるため、間接法では加算項目となる
- **関連用語**: 非資金費用、有形固定資産、無形固定資産

### さ行

**財務活動によるキャッシュフロー（ざいむかつどうによるきゃっしゅふろー）**
- **読み方**: ざいむかつどうによるきゃっしゅふろー
- **意味**: 資金調達および返済に関する現金の流れ。借入金、社債、株式の発行・償還、配当金の支払いなどが含まれる
- **関連用語**: 営業活動によるキャッシュフロー、投資活動によるキャッシュフロー

### た行

**直接法（ちょくせつほう）**
- **読み方**: ちょくせつほう
- **意味**: 営業活動によるキャッシュフローを、主要な取引ごとに総額で表示する方法。営業収入、商品仕入支出などを直接集計する
- **関連用語**: 間接法、キャッシュフロー計算書

**投資活動によるキャッシュフロー（とうしかつどうによるきゃっしゅふろー）**
- **読み方**: とうしかつどうによるきゃっしゅふろー
- **意味**: 固定資産や有価証券の取得・売却など、将来の利益獲得や資金運用を目的とした活動による現金の流れ
- **関連用語**: 営業活動によるキャッシュフロー、財務活動によるキャッシュフロー

### な行

**のれん償却費（のれんしょうきゃくひ）**
- **読み方**: のれんしょうきゃくひ
- **意味**: 企業買収時に発生したのれん（買収価額と純資産の差額）を一定期間で費用化したもの。非資金費用として間接法では加算項目
- **関連用語**: のれん、非資金費用、企業結合会計

### は行

**非資金費用（ひしきんひよう）**
- **読み方**: ひしきんひよう
- **意味**: 損益計算書に費用として計上されるが、実際の現金支出を伴わない費用。減価償却費、のれん償却費、貸倒引当金繰入額などが該当
- **関連用語**: 非資金収益、間接法

**非資金収益（ひしきんしゅうえき）**
- **読み方**: ひしきんしゅうえき
- **意味**: 損益計算書に収益として計上されるが、実際の現金収入を伴わない収益。貸倒引当金戻入益などが該当
- **関連用語**: 非資金費用、間接法

**フリー・キャッシュフロー（ふりー・きゃっしゅふろー）**
- **読み方**: ふりー・きゃっしゅふろー
- **意味**: 営業活動によるキャッシュフローから投資活動によるキャッシュフロー（維持投資分）を差し引いた、企業が自由に使える現金の額
- **関連用語**: 営業活動によるキャッシュフロー、投資活動によるキャッシュフロー

### ま行

**未収収益（みしゅうしゅうえき）**
- **読み方**: みしゅうしゅうえき
- **意味**: すでに収益として計上されているが、まだ現金を受け取っていない項目。間接法では、その増減を調整する必要がある
- **関連用語**: 未払費用、前受収益、前払費用

**未払費用（みばらいひよう）**
- **読み方**: みばらいひよう
- **意味**: すでに費用として計上されているが、まだ現金を支払っていない項目。間接法では、その増減を調整する必要がある
- **関連用語**: 未収収益、前受収益、前払費用

### や行

**譲渡性預金（ゆずりわたしせいよきん）**
- **読み方**: ゆずりわたしせいよきん
- **意味**: 銀行が発行する無記名の預金証書で、第三者に譲渡可能な定期預金。満期が3ヶ月以内のものは現金同等物に該当
- **関連用語**: 現金同等物、定期預金

### ら行

**利息の支払額（りそくのしはらいがく）**
- **読み方**: りそくのしはらいがく
- **意味**: 実際に現金で支払った利息の額。間接法では、小計後に実際の支払額を記載する
- **関連用語**: 支払利息、営業活動によるキャッシュフロー

### わ行

**ワーキング・キャピタル（わーきんぐ・きゃぴたる）**
- **読み方**: わーきんぐ・きゃぴたる
- **意味**: 運転資本とも呼ばれ、流動資産から流動負債を差し引いた額。売上債権、棚卸資産、仕入債務などの増減は営業CFに影響する
- **関連用語**: 運転資本、流動資産、流動負債
